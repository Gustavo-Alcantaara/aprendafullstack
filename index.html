Aprenda Full Stack

1.FUNDAMENTOS DA PROGRAMAÇÃO

É a base da programação. Aqui você desenvolve o raciocínio lógico, aprende a resolver problemas de forma estruturada e entende como um computador executa instruções. Todo desenvolvedor deve dominar esses conceitos antes de avançar para linguagens específicas.

Algoritmos
2.ENGENHARIA DE SOFTWARE

Estuda como planejar, desenvolver, documentar, testar e manter sistemas de qualidade. O foco é criar softwares organizados, escaláveis e fáceis de manter, utilizando boas práticas e metodologias de desenvolvimento.

Engenharia de Software
3.SEGURANÇA CIBERNÉTICA

Área da tecnologia focada na proteção de sistemas, redes e dados contra ameaças digitais. Abrange princípios de segurança, identificação de vulnerabilidades, prevenção de ataques e boas práticas para garantir a confidencialidade, integridade e disponibilidade das informações.

Segurança Cibernética
4.CONTROLE DE VERSÃO

Aprenda a utilizar ferramentas que registram o histórico do código, permitem trabalhar em equipe e facilitam o gerenciamento de versões. Git e GitHub são padrões da indústria e essenciais para qualquer desenvolvedor.

Git e Github
5.DESENVOLVIMENTO WEB(Front-end)

Responsável pela criação da interface visual de um site ou aplicação. Nesta etapa você aprende a estruturar páginas com HTML, estilizar com CSS e SASS e utilizar frameworks como Bootstrap para desenvolver interfaces modernas, responsivas e acessíveis.

HTML CSS SASS Bootstrap
6.JAVASCRIPT

É a principal linguagem de programação do navegador. Permite adicionar interatividade às páginas, manipular elementos da interface, consumir APIs, criar aplicações completas e utilizar recursos modernos da linguagem, além de bibliotecas como jQuery.

JavaScript ECMAScript 6 ECMAScript 2015 - 2022 Orientação à Objetos Js jQuery Ajax
7.BACK-END COM PHP

Área responsável pela lógica de negócio da aplicação. Você aprenderá a desenvolver sistemas utilizando PHP, criar APIs, trabalhar com orientação a objetos, seguir padrões arquiteturais como MVC e integrar aplicações com bancos de dados.

PHP PHP 8 ORIENTAÇÃO À OBJETOS PHP PHP com PDO e MySQL MVC COM PHP API COM SLIM FRAMEWORK
8.BANCO DE DADOS

Responsável pelo armazenamento e gerenciamento das informações de uma aplicação. Neste módulo você aprenderá modelagem de dados, linguagem SQL, consultas, relacionamentos e boas práticas utilizando MySQL.

MySQL
9.AMBIENTE DE DESENVOLVIMENTO

Ensina como configurar o ambiente necessário para desenvolver aplicações localmente. Inclui a instalação e utilização de servidores, bancos de dados e ferramentas como o Stack WAMP para simular um ambiente de produção.

Stack WAMP
10.CMS(Content Management System)

Apresenta plataformas prontas para criação e gerenciamento de sites, sendo o WordPress o principal exemplo. Você aprenderá a instalar, configurar, personalizar temas, utilizar plugins e desenvolver soluções para clientes de forma rápida.

WordPress
11.DESENVOLVIMENTO MOBILE

Introdução ao desenvolvimento de aplicativos móveis utilizando tecnologias web. Com o Ionic, você poderá criar aplicações para Android e iOS reutilizando conhecimentos de HTML, CSS e JavaScript.

IONIC
12.DEPLOY E INFRAESTRUTURA

Ensina como publicar uma aplicação na internet. Você aprenderá sobre hospedagem, domínios, configuração de servidores, HTTPS, segurança, variáveis de ambiente e boas práticas para disponibilizar sistemas em produção.

Publicação de Aplicações Web na Internet
