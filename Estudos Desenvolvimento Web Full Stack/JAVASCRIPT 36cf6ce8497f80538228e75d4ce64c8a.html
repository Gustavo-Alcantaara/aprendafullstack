O que é JavaScript?

JavaScript é uma linguagem de programação muito usada no desenvolvimento web para adicionar interatividade e funcionalidades aos sites e aplicações. Com ela, é possível criar animações, validar formulários, manipular elementos da página e desenvolver sistemas completos tanto no navegador quanto no servidor usando tecnologias como Node.js. Atualmente, JavaScript é uma das principais linguagens da programação moderna, sendo bastante utilizada em frameworks como React e React Native.
