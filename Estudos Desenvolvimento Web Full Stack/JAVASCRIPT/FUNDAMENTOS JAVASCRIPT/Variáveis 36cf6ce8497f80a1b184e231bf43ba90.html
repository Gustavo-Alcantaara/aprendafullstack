Variáveis

Em JavaScript, variáveis são usadas para armazenar informações na memória do programa, como textos, números ou valores que podem ser utilizados depois no código.

As principais formas de criar variáveis são:

let

Usada para valores que podem mudar:

let nome="Gustavo";
nome="Carlos";

const

Usada para valores que não devem ser alterados:

const idade=21;

var

Forma antiga de criar variáveis. Hoje é menos recomendada:

var cidade="Fortaleza";

As variáveis podem armazenar diferentes tipos de dados:

let nome= "Gustavo";// Texto
let idade= 21;// Número
let estudando= true;// Booleano

Elas são fundamentais para guardar e manipular dados dentro de aplicações e sistemas.

Em JavaScript, além de criar variáveis, é importante entender os tipos de dados, o conceito de case sensitive e as boas práticas de nomenclatura.

Tipos de variáveis (tipos de dados)

String

Representa textos:

let nome="Gustavo";

Number

Representa números:

let idade=21;

Boolean

Representa verdadeiro ou falso:

let aprovado=true;

Null

Representa ausência de valor:

let resposta=null;

Undefined

Quando a variável foi criada mas não recebeu valor:

let cidade;

Array

Lista de valores:

let frutas= ["Maçã","Banana","Uva"];

Object

Armazena várias informações em um único elemento:

let pessoa= {
  nome:"Gustavo",
  idade:21
};

Case Sensitive

JavaScript diferencia letras maiúsculas de minúsculas. Isso significa que variáveis com nomes parecidos podem ser totalmente diferentes:

let nome="Gustavo";
let Nome="Carlos";

Nesse caso, nome e Nome são variáveis diferentes.

Nomenclatura de variáveis

Existem algumas regras e boas práticas para nomear variáveis:

Regras

  • Não pode começar com número
  • Não pode ter espaços
  • Pode usar _ e $
  • Evite caracteres especiais

Exemplos válidos:

let nomeUsuario;
let idade;
let _total;

Exemplos inválidos:

let 1nome;
let meu nome;

Boas práticas

O mais comum em JavaScript é usar o padrão camelCase, onde a primeira palavra começa com letra minúscula e as próximas com maiúscula:

let nomeCompleto;
let valorTotalCompra;

Também é importante usar nomes claros e descritivos para facilitar a leitura do código.
