Eventos de Formulários

Em JavaScript, eventos de formulários permitem detectar e controlar interações do usuário com campos de entrada, botões e formulários HTML.

Eles são muito usados para:

  • validação
  • login
  • cadastro
  • busca
  • envio de dados
  • interfaces dinâmicas

submit

Executa quando o formulário é enviado.

HTML

<form id="formulario">
<input type="text" placeholder="Nome">
<button type="submit">Enviar</button>
</form>

JavaScript

const formulario = document.getElementById("formulario");

formulario.addEventListener("submit",function(evento) {
evento.preventDefault();

console.log("Formulário enviado");
});

preventDefault()

Impede o comportamento padrão do formulário.

Sem isso, a página normalmente recarrega.

evento.preventDefault();

Pegando valores dos campos

<input type="text"id="nome">
const nome = document.getElementById("nome");

console.log(nome.value);

input

Executa sempre que o valor muda:

nome.addEventListener("input",function() {
console.log(nome.value);
});

Muito usado para:

  • busca em tempo real
  • validações
  • autocomplete

change

Executa quando o valor muda e o campo perde foco.

nome.addEventListener("change",function() {
console.log("Mudou");
});

Diferença entre input e change

EventoQuando executa
inputEnquanto digita
changeApós concluir alteração

focus

Executa quando o campo recebe foco:

nome.addEventListener("focus",function() {
console.log("Campo ativo");
});

blur

Executa quando o campo perde foco:

nome.addEventListener("blur",function() {
console.log("Saiu do campo");
});

Muito usado em validações.

Exemplo de validação

nome.addEventListener("blur",function() {
if (nome.value === "") {
console.log("Campo obrigatório");
  }
});

reset

Executa quando o formulário é resetado:

formulario.addEventListener("reset",function() {
console.log("Resetou");
});

select

Executa quando texto é selecionado:

nome.addEventListener("select",function() {
console.log("Texto selecionado");
});

Checkbox

<input type="checkbox" id="aceitar">
const aceitar = document.getElementById("aceitar");

aceitar.addEventListener("change",function() {
console.log(aceitar.checked);
});

Radio buttons

console.log(radio.checked);

Select

<select id="cidade">
<option>Fortaleza</option>
<option>São Paulo</option>
</select>
cidade.addEventListener("change",function() {
console.log(cidade.value);
});

Trabalhando com múltiplos campos

const dados= {
  nome:nome.value,
  email:email.value

FormData

Objeto moderno para capturar dados:

const dados=newFormData(formulario);

Pegando valores do FormData

console.log(dados.get("nome"));

Validação HTML5

O próprio HTML possui validações:

<input type="email" required>

Verificando validade

console.log(formulario.checkValidity());

EventoUso

Resumindo

Eventos de formulários permitem:

  • capturar dados do usuário
  • validar informações
  • controlar envios
  • criar formulários dinâmicos
  • melhorar experiência do usuário

Eles são essenciais em aplicações feitas com React, sistemas de login, cadastros e APIs modernas.
