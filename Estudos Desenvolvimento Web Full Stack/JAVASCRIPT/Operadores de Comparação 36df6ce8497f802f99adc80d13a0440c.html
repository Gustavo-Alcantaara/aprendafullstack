Operadores de Comparação

Em JavaScript, operadores de comparação são usados para comparar valores. O resultado dessas comparações sempre será um valor booleano:

true

ou

false

Operadores de comparação

OperadorSignificado
==Igual
===Estritamente igual
!=Diferente
!==Estritamente diferente
>Maior que
<Menor que
>=Maior ou igual
<=Menor ou igual

== Igual

Compara apenas os valores:

console.log(10 == "10");

Resultado:

true

O JavaScript converte os tipos automaticamente.

=== Estritamente igual

Compara valor e tipo:

console.log(10 === "10");

Resultado:

false

Esse é o mais recomendado.

!= Diferente

console.log(5 != 10);

Resultado:

true

!== Estritamente diferente

console.log(10 !== "10");

Resultado:

true

Ordem de precedência

A ordem de precedência define quais operadores são executados primeiro em uma expressão.

Ordem básica mais comum

  1. Parênteses ()
  1. Operadores matemáticos (, /, +, )
  1. Comparações (>, <, ===)
  1. Operadores lógicos (&&, ||)

Exemplo

console.log(10 + 5 > 12);

O JavaScript executa assim:

15 > 12

Resultado:

true

Exemplo com operadores lógicos

console.log(true || false && false);

A precedência faz o && acontecer antes do ||:

true || (false && false)

Resultado:

true

Usando parênteses

Parênteses alteram a prioridade e deixam o código mais claro:

console.log((10 + 5) > 12);

Dica importante

Mesmo sabendo a precedência, muitos desenvolvedores usam parênteses para melhorar a legibilidade e evitar erros.
