Funções

Em JavaScript, funções são blocos de código reutilizáveis que executam uma tarefa específica. Elas ajudam a organizar o código, evitar repetição e facilitar a manutenção dos programas.

O que é uma função?

Uma função pode:

  • Receber valores (parâmetros)
  • Processar informações
  • Retornar um resultado

Criando uma função

Sintaxe básica

function saudacao() {
console.log("Olá!");
}

Para executar a função:

saudacao();

Parâmetros

Funções podem receber dados:

function saudar(nome) {
console.log("Olá, " + nome);
}

saudar("Gustavo");

Retorno (return)

Uma função pode devolver um valor:

function soma(a,b) {
return a + b;
}

let resultado = soma(10, 5);

console.log(resultado);

Diferença entre console.log e return

console.log

Apenas mostra algo na tela.

return

Entrega um valor para ser usado depois.

function dobrar(numero) {
return numero * 2;
}

let valor = dobrar(5);

Funções com vários parâmetros

function calcularMedia(n1, n2) {
return (n1 + n2) / 2;
}

Parâmetros padrão

function saudar(nome="Visitante") {
console.log(`Olá, ${nome}`);
}

saudar();

Resultado:

Olá, Visitante

Function Expression

Também é possível armazenar funções em variáveis:

const somar = function(a,b) {
return a + b;
};

Arrow Functions

Forma moderna e muito usada:

const somar = (a, b) => {
return a + b;
};

Versão reduzida:

const somar = (a, b) => a + b;

Escopo de variáveis

Variáveis criadas dentro da função só existem nela.

function teste() {
let mensagem = "Olá";
}

console.log(mensagem);

Isso gera erro.

Escopo global

Variáveis criadas fora da função podem ser acessadas dentro dela:

let nome="Gustavo";

function mostrarNome() {
console.log(nome);
}

Funções anônimas

Funções sem nome:

setTimeout(function() {
console.log("Executou");
},1000);

Callback Functions

Funções passadas como argumento para outra função:

function executar(callback) {
callback();
}

executar(function() {
console.log("Função executada");
});

Muito usadas em eventos e assincronismo.

Funções de alta ordem

Funções que:

  • recebem funções
  • ou retornam funções

Exemplo:

function multiplicador(valor) {
return function(numero) {
return numero * valor;
  };
}

IIFE (Immediately Invoked Function Expression)

Função executada imediatamente:

(function() {
console.log("Executou");
})();

Hoisting

Funções declaradas com function podem ser usadas antes da criação:

saudacao();

function saudacao() {
console.log("Olá");
}

Métodos

Quando funções pertencem a objetos:

const pessoa= {
  nome:"Gustavo",

  falar() {
console.log("Olá");
  }
};

Recursão

Função chamando ela mesma:

function contagem(numero) {
if (numero <= 0) return;

console.log(numero);

contagem(numero - 1);
}

Boas práticas

  • Use nomes claros
  • Faça funções pequenas
  • Evite repetir código
  • Prefira funções com uma única responsabilidade
  • Use const em arrow functions quando possível

Resumindo

Funções são fundamentais no JavaScript porque permitem:

  • reutilização de código
  • organização
  • modularização
  • criação de sistemas complexos
  • manipulação de eventos
  • assincronismo
  • programação funcional

Praticamente toda aplicação moderna feita com tecnologias como React, Node.js e Next.js depende fortemente de funções.
