Operações Matemáticas

Em JavaScript, existem várias funções nativas para realizar operações matemáticas. A maioria delas pertence ao objeto:

Esse objeto fornece métodos para cálculos, arredondamentos, potências, números aleatórios e muito mais.

Math.round()

Arredonda para o inteiro mais próximo:

console.log(Math.round(4.6));

Resultado:

5

Math.floor()

Arredonda para baixo:

console.log(Math.floor(4.9));

Resultado:

4

Math.ceil()

Arredonda para cima:

console.log(Math.ceil(4.1));

Resultado:

5

Math.trunc()

Remove a parte decimal:

console.log(Math.trunc(4.9));

Resultado:

4

Math.random()

Gera número aleatório entre 0 e 1:

console.log(Math.random());

Número aleatório inteiro

letnumero=Math.floor(Math.random() * 10);

console.log(numero);

Gera números de 0 a 9.

Math.max()

Retorna o maior número:

console.log(Math.max(10,50,30));

Resultado:

50

Math.min()

Retorna o menor número:

console.log(Math.min(10,50,30));

Math.pow()

Potenciação:

console.log(Math.pow(2,3));

Resultado:

8

Hoje também usamos:

console.log(2 ** 3);

Math.sqrt()

Raiz quadrada:

console.log(Math.sqrt(25));

Resultado:

5

Math.abs()

Valor absoluto:

console.log(Math.abs(-10));

Resultado:

10

Math.sign()

Retorna:

  • 1 → positivo
  • 1 → negativo
  • 0 → zero
console.log(Math.sign(-20));

Math.cbrt()

Raiz cúbica:

console.log(Math.cbrt(27));

Resultado:

3

Math.hypot()

Calcula hipotenusa:

console.log(Math.hypot(3,4));

Resultado:

5

Constantes matemáticas

PI

console.log(Math.PI);

Euler

console.log(Math.E);

Convertendo strings para número

parseInt()

console.log(parseInt("10"));

parseFloat()

console.log(parseFloat("10.5"));

Verificando números

isNaN()

Verifica se não é número:

console.log(isNaN("abc"));

Resultado:

true

Number.isInteger()

Verifica inteiro:

console.log(Number.isInteger(10));

Formatação decimal

toFixed()

Define casas decimais:

let preco = 19.999;

console.log(preco.toFixed(2));

Resultado:

20.00

Ordem de precedência matemática

JavaScript segue a matemática tradicional:

  1. Parênteses ()
  1. Potência *
  1. Multiplicação , divisão / e resto %
  1. Soma + e subtração

Exemplo

console.log(10 + 5 * 2);

Resultado:

20

Resumindo

As funções matemáticas nativas permitem:

  • arredondar números
  • gerar aleatórios
  • calcular potências e raízes
  • validar números
  • fazer operações complexas

Esses recursos são muito usados em jogos, sistemas financeiros, gráficos, animações e aplicações feitas com Node.js e React.
