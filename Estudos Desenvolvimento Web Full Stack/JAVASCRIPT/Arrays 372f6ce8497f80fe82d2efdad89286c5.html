Arrays

Em JavaScript, um array é uma estrutura de dados usada para armazenar vários valores em uma única variável.

Em vez de criar várias variáveis:

let fruta1 = "Maçã";
let fruta2 = "Banana";
let fruta3 = "Uva";

Podemos usar um array:

let frutas = ["Maçã","Banana","Uva"];

Características dos Arrays

  • Armazenam múltiplos valores
  • Mantêm a ordem dos elementos
  • São indexados a partir do zero
  • Podem armazenar diferentes tipos de dados

Exemplo:

let dados= [
"Gustavo",
21,
true,
null
];

Índices

Os elementos possuem posições numéricas:

let frutas = ["Maçã","Banana","Uva"];
ÍndiceValor
0Maçã
1Banana
2Uva

Acessando:

console.log(frutas[0]);

Resultado:

Maçã

Alterando valores

frutas[1] = "Laranja";

Resultado:

["Maçã","Laranja","Uva"]

Tamanho do array

Usamos a propriedade:

frutas.length

Exemplo:

console.log(frutas.length);

Resultado:

3

Adicionando elementos

push()

Adiciona ao final:

frutas.push("Morango");

Resultado:

["Maçã","Banana","Uva","Morango"]

unshift()

Adiciona no início:

frutas.unshift("Abacaxi");

Removendo elementos

pop()

Remove o último:

frutas.pop();

shift()

Remove o primeiro:

frutas.shift();

Encontrando posição

indexOf()

let frutas = ["Maçã","Banana","Uva"];

console.log(frutas.indexOf("Banana"));

Resultado:

1

Verificando existência

includes()

console.log(
frutas.includes("Uva")
);

Resultado:

true

Percorrendo arrays

for

for (let i = 0; i < frutas.length; i++) {
console.log(frutas[i]);
}

for...of

for (const fruta of frutas) {
console.log(fruta);
}

forEach()

frutas.forEach(function(fruta) {
console.log(fruta);
});

Arrow Function:

frutas.forEach(fruta => {
console.log(fruta);
});

Transformando arrays

map()

Cria um novo array:

const numeros= [1,2,3];

const dobrados=numeros.map(numero => {
return numero*2;
});

Resultado:

[2,4,6]

Filtrando elementos

filter()

const numeros = [10,20,30,40];

const maiores = numeros.filter(numero => {
return numero > 20;
});

Resultado:

[30,40]

Encontrando elemento

find()

const numeros = [10,20,30];

const resultado = numeros.find(numero => {
return numero > 15;
});

Resultado:

20

Unindo arrays

concat()

const a = [1,2];
const b = [3,4];

const resultado = a.concat(b);

Resultado:

[1,2,3,4]

Convertendo para string

join()

const nomes= ["Ana","Carlos","João"];

console.log(nomes.join(", "));

Resultado:

Ana, Carlos, João

Copiando parte do array

slice()

const numeros = [1,2,3,4,5];

console.log(numeros.slice(1,4));

Resultado:

[2,3,4]

Removendo ou inserindo elementos

splice()

const frutas = ["Maçã","Banana","Uva"];

frutas.splice(1,1);

Resultado:

["Maçã","Uva"]

Arrays multidimensionais

Array dentro de array:

const matriz = [
  [1,2],
  [3,4]
];

Acessando:

console.log(matriz[0][1]);

Resultado:

2

Spread Operator

Copiando arrays:

const numeros= [1,2,3];

const copia = [...numeros];

Juntando arrays:

const resultado = [...a, ...b];

Resumindo

Arrays são fundamentais para armazenar e manipular coleções de dados. Os métodos mais importantes para começar são:

  • push() → adiciona no final
  • pop() → remove do final
  • shift() → remove do início
  • unshift() → adiciona no início
  • forEach() → percorre elementos
  • map() → transforma elementos
  • filter() → filtra elementos
  • find() → encontra elemento
  • includes() → verifica existência

Arrays são uma das estruturas mais utilizadas no desenvolvimento web moderno com React, Node.js e APIs em geral.
