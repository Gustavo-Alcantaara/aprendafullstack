Flexibilidade de Parâmetros

Em JavaScript, funções possuem grande flexibilidade nos parâmetros. Isso significa que uma função pode receber quantos argumentos forem necessários — ou até nenhum — sem gerar erro automaticamente.

Parâmetros e argumentos

  • Parâmetro → variável declarada na função
  • Argumento → valor enviado para a função
function saudacao(nome) {
console.log(nome);
}

saudacao("Gustavo");

nome é o parâmetro.

"Gustavo" é o argumento.

JavaScript não exige quantidade exata

Uma função pode ser chamada com menos ou mais argumentos do que o esperado.

Menos argumentos

function soma(a,b) {
console.log(a+b);
}

soma(10);

Resultado:

NaN

Porque b ficou:

undefined

Mais argumentos

function nomePessoa(nome) {
console.log(nome);
}

nomePessoa("Gustavo",21,"Brasil");

Os argumentos extras são ignorados.

Parâmetros padrão

Evita problemas com valores ausentes:

function saudacao(nome="Visitante") {
console.log(`Olá,${nome}`);
}

saudacao();

Resultado:

Olá, Visitante

Rest Parameters (...)

Permitem receber vários argumentos em um array.

function soma(...numeros) {
console.log(numeros);
}

soma(1,2,3,4);

Resultado:

[1, 2, 3, 4]

Exemplo somando vários números

function soma(...numeros) {
let total=0;

for (let numero of numeros) {
total += numero;
  }

return total;
}

console.log(soma(10,20,30));

Spread Operator (...)

Também usa ..., mas serve para espalhar valores:

const numeros= [1,2,3];

console.log(...numeros);

Resultado:

1 2 3

Desestruturação em parâmetros

Permite extrair valores diretamente:

function mostrarNome({ nome }) {
console.log(nome);
}

const pessoa= {
  nome:"Gustavo"
};

mostrarNome(pessoa);

Funções aceitam qualquer tipo

Uma função pode receber:

  • números
  • strings
  • arrays
  • objetos
  • outras funções
function executar(funcao) {
funcao();
}

Arguments Object

Funções tradicionais possuem um objeto chamado:

argumentsargumentsarguments

function teste() {
console.log(arguments);
}

teste(1,2,3);

Arrow functions não possuem arguments.

Ordem dos parâmetros

A ordem importa:

function apresentar(nome,idade) {
console.log(nome,idade);
}

apresentar("Gustavo",21);

Resumindo

A flexibilidade de parâmetros no JavaScript permite:

  • enviar quantos argumentos quiser
  • usar valores padrão
  • capturar múltiplos valores
  • passar funções e objetos
  • criar funções mais reutilizáveis e dinâmicas

Essa flexibilidade é uma das características mais fortes da linguagem.
