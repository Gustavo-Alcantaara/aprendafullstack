DOM - Introdução

Em DOM, o navegador transforma o HTML da página em uma estrutura de objetos que pode ser manipulada com JavaScript.

Isso permite:

  • alterar textos
  • mudar estilos
  • adicionar elementos
  • remover elementos
  • responder a eventos
  • atualizar a página dinamicamente

O que é DOM?

O DOM representa o HTML como uma árvore de elementos.

Exemplo de HTML:

<body>
<h1>Título</h1>
<p>Texto</p>
</body>

Estrutura simplificada:

Document
 └── body
      ├── h1
      └── p

Cada elemento vira um objeto manipulável pelo JavaScript.

Acessando o DOM

O ponto de entrada principal é:

document

Selecionando elementos

getElementById()

Seleciona pelo ID:

<h1 id="titulo">Olá</h1>
const titulo = document.getElementById("titulo");

querySelector()

Seleciona usando CSS:

const titulo = document.querySelector("#titulo");

querySelectorAll()

Seleciona vários elementos:

const paragrafos = document.querySelectorAll("p");

Outros seletores

Classe

document.getElementsByClassName("card");

Tag

document.getElementsByTagName("div");

Alterando conteúdo

innerText

titulo.innerText = "Novo título";

innerHTML

Permite HTML:

titulo.innerHTML="<span>Olá</span>";

⚠️ Pode gerar riscos de segurança se usado incorretamente.

Alterando estilos

titulo.style.color="red";
titulo.style.fontSize="40px";

Manipulando classes

Adicionar classe

titulo.classList.add("ativo");

Remover classe

titulo.classList.remove("ativo");

Alternar classe

titulo.classList.toggle("ativo");

Criando elementos

const paragrafo=document.createElement("p");

Adicionando conteúdo

paragrafo.innerText="Novo texto";

Inserindo na página

document.body.appendChild(paragrafo);

Removendo elementos

paragrafo.remove();

Eventos no DOM

Muito usados com:

addEventListener()

Exemplo:

botao.addEventListener("click",function() {
console.log("Clicou");
});

Navegando pelos elementos

Pai

elemento.parentElement

Filhos

elemento.children

Primeiro filho

elemento.firstElementChild

Último filho

elemento.lastElementChild

Pegando atributos

link.getAttribute("href");

Alterando atributos

link.setAttribute("href","https://google.com");

Removendo atributos

link.removeAttribute("target");

DOMContentLoaded

Executa quando o HTML termina de carregar:

document.addEventListener("DOMContentLoaded",function() {
console.log("DOM carregado");
});

Virtual DOM

Bibliotecas como React usam:

Para otimizar atualizações da interface.

Resumindo

O DOM permite que o JavaScript:

  • controle elementos HTML
  • altere conteúdo e estilos
  • responda a eventos
  • crie interfaces dinâmicas

Ele é uma das bases do desenvolvimento web moderno e fundamental em aplicações feitas com React, Vue.js e Angular.
