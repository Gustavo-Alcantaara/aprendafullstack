Arrays Multidimensionais

Em JavaScript, arrays multidimensionais são arrays que contêm outros arrays como elementos.

Eles são muito usados para representar:

  • tabelas
  • matrizes matemáticas
  • tabuleiros de jogos
  • planilhas
  • estruturas de dados mais complexas

Array bidimensional (2D)

É o tipo mais comum.

const matriz= [
  [1,2,3],
  [4,5,6],
  [7,8,9]
];

Visualmente:

123
456
789

Acessando elementos

Primeiro informamos a linha e depois a coluna:

console.log(matriz[0][0]);

Resultado:

1
console.log(matriz[1][2]);

Resultado:

6

Entendendo os índices

const matriz= [
  ["A","B","C"],
  ["D","E","F"]
];
ÍndiceConteúdo
matriz[0]["A", "B", "C"]
matriz[1]["D", "E", "F"]

Depois:

matriz[0][1]

Resultado:

B

Alterando valores

matriz[1][1] = "X";

Resultado:

[
  ["A","B","C"],
  ["D","X","F"]
]

Percorrendo uma matriz

Com dois loops for

const matriz = [
  [1,2],
  [3,4]
];

for (let i = 0; i < matriz.length; i++) {

for (let j = 0; j < matriz[i].length; j++) {
console.log(matriz[i][j]);
  }

}

Resultado:

1
2
3
4

Usando for...of

for (const linhaofmatriz) {

for (const valoroflinha) {
console.log(valor);
  }

}

Adicionando linhas

matriz.push([10,11,12]);

Resultado:

[
  [1,2,3],
  [4,5,6],
  [10,11,12]
]

Adicionando colunas

matriz[0].push(4);

Resultado:

[1,2,3,4]

Exemplo prático: tabela de notas

const notas= [
  ["João", 8],
  ["Maria", 10],
  ["Carlos", 7]
];

Acessando:

console.log(notas[1][0]);

Resultado:

Maria

Exemplo prático: jogo da velha

const tabuleiro= [
  ["X","O","X"],
  ["O","X","O"],
  [" "," ","X"]
];

A posição central:

console.log(tabuleiro[1][1]);

Resultado:

X

Arrays tridimensionais (3D)

Também podem existir arrays dentro de arrays dentro de arrays.

const cubo= [
  [
    [1,2],
    [3,4]
  ],
  [
    [5,6],
    [7,8]
  ]
];

Acessando:

console.log(cubo[1][0][1]);

Resultado:

6

Método flat()

Transforma arrays multidimensionais em uma dimensão.

const numeros= [
  [1,2],
  [3,4]
];

console.log(numeros.flat());

Resultado:

[1,2,3,4]

Profundidade do flat()

const dados= [
  [1, [2,3]]
];

console.log(dados.flat(2));

Resultado:

[1,2,3]

Quando usar arrays multidimensionais?

São ideais para representar:

  • matrizes matemáticas
  • mapas de jogos
  • planilhas
  • calendários
  • tabelas de dados
  • assentos de cinema
  • tabuleiros

Resumindo

Arrays multidimensionais são arrays que armazenam outros arrays.

Conceitos principais:

  • matriz[linha][coluna]
  • podem ter 2, 3 ou mais dimensões
  • são ótimos para representar tabelas e estruturas organizadas
  • podem ser percorridos com loops aninhados
  • o método flat() ajuda a transformar uma matriz em um array simples

Eles aparecem com frequência em algoritmos, jogos, sistemas de gestão e aplicações desenvolvidas com Node.js e React.
