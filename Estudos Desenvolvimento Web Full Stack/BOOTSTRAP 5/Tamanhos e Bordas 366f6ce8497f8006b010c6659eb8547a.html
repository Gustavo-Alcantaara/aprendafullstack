Tamanhos e Bordas

Tamanhos e Bordas no Bootstrap

O Bootstrap possui várias classes utilitárias para controlar:

  • Largura
  • Altura
  • Bordas
  • Arredondamento
  • Espessura
  • Cores das bordas

Tudo isso sem precisar escrever CSS manualmente.

Tamanhos no Bootstrap

Bootstrap possui classes para controlar largura (width) e altura (height).

Largura (w)

Estrutura:

w-valor

Classes de largura

ClasseLargura
w-2525%
w-5050%
w-7575%
w-100100%
w-autoAutomática

Exemplo

<div class="w-50 bg-primary">

A div ocupará 50% da largura do elemento pai.

Altura (h)

Estrutura:

h-valor

Classes de altura

ClasseAltura
h-2525%
h-5050%
h-7575%
h-100100%
h-autoAutomática

Exemplo

<div class="h-100">

Altura da viewport

Bootstrap também possui:

ClasseFunção
vh-100100% da altura da tela
min-vh-100Altura mínima da tela

Exemplo

<div class="vh-100 d-flex justify-content-center align-items-center">

Muito usado para:

  • Centralização vertical
  • Telas de login
  • Hero sections

Bordas no Bootstrap

Bootstrap possui utilitários prontos para bordas.

Adicionar borda

<div class="border">

Remover borda

<div class="border-0">

Bordas por lado

ClasseLado
border-topSuperior
border-bottomInferior
border-startEsquerda
border-endDireita

Exemplo

<div class="border-bottom">

Cores das bordas

Estrutura:

border-cor

Principais cores

ClasseCor
border-primaryAzul
border-successVerde
border-dangerVermelho
border-warningAmarelo
border-darkPreto
border-lightBranco

Exemplo

<div class="border border-danger">

Espessura da borda

Bootstrap possui níveis de espessura.

ClasseEspessura
border-1Fina
border-2Média
border-3Grossa
border-4Muito grossa
border-5Extra grossa

Exemplo

<div class="border border-4">

Bordas arredondadas

Estrutura:

rounded

Classes de arredondamento

ClasseFunção
roundedArredondamento padrão
rounded-0Sem arredondamento
rounded-1 até rounded-5Intensidade
rounded-circleForma circular
rounded-pillFormato cápsula

Exemplo

<img class="rounded-circle">

Muito usado em:

  • Fotos de perfil
  • Avatares

Rounded Pill

<button class="btn btn-primary rounded-pill">

Cria um botão com formato arredondado.

Exemplo completo

<div class="container">

<div class="w-50 p-4 border border-primary rounded-3">

        Caixa estilizada com Bootstrap.

</div>

</div>

Combinações comuns

<div class="w-100 border rounded p-3">
  • w-100 → largura total
  • border → adiciona borda
  • rounded → arredonda
  • p-3 → espaçamento interno

Vantagens dos utilitários

  • Desenvolvimento rápido
  • Menos CSS manual
  • Padronização visual
  • Responsividade
  • Código mais limpo
