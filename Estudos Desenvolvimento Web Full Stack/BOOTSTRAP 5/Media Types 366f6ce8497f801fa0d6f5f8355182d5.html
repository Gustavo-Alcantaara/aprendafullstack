Media Types

Tipos de mídia (Media Types) no Bootstrap e CSS

No contexto do Bootstrap e das Media Queries, os tipos de mídia definem para qual tipo de dispositivo ou saída os estilos CSS serão aplicados.

Eles são usados junto com @media.

Sintaxe básica

@media tipo-de-midia {

}

Ou:

@media tipo-de-midiaand (condição) {

}

Principais tipos de mídia

TipoFunção
allTodos os dispositivos
screenTelas/dispositivos digitais
printImpressão
speechLeitores de voz

1. Screen

O tipo mais usado.

Aplica estilos para:

  • Monitores
  • Celulares
  • Tablets
  • Notebooks

Exemplo

@media screen {

body{
        background:lightblue;
    }

}

Screen com tamanho de tela

@media screen and (max-width:768px){

body{
        background:gray;
    }

}

Muito usado para:

  • Responsividade
  • Layout mobile
  • Breakpoints

2. Print

Usado para estilizar páginas impressas.

Muito útil para:

  • PDFs
  • Relatórios
  • Documentos
  • Impressão de páginas

Exemplo

@media print {

body{
        background:white;
    }

}

Exemplo prático

@media print {

nav,
footer,
button{

        display:none;

    }

}

Na impressão:

  • Menu desaparece
  • Rodapé desaparece
  • Botões desaparecem

Isso deixa a impressão mais limpa.

Mudar tamanho do texto na impressão

@media print {

body{
        font-size:12pt;
    }

}

3. Speech

Usado para leitores de tela e sintetizadores de voz.

Menos comum atualmente.

Exemplo

@media speech {

h1{
        voice-rate:slow;
    }

}

4. All

Aplica estilos para todos os tipos de mídia.

É o padrão do CSS.

Exemplo

@media all {

body{
        margin:0;
    }

}

Uso combinado

Você pode combinar:

  • Tipo de mídia
  • Tamanho de tela
  • Orientação

Exemplo completo

@media screen and (max-width:768px){

    .menu{
        display:none;
    }

}

Exemplo para impressão

@media print {

    .no-print{
        display:none;
    }

}

HTML:

<button class="no-print">
    Imprimir
</button>

O botão não aparecerá na impressão.

Relação com o Bootstrap

Bootstrap usa principalmente:

screen

Porque ele é focado em:

  • Responsividade
  • Layouts web
  • Dispositivos digitais

Os breakpoints do Bootstrap funcionam através de:

@media (min-width: ...)

Exemplo de breakpoint do Bootstrap

O breakpoint md equivale aproximadamente a:

@media screen and (min-width:768px){

}

Vantagens dos tipos de mídia

  • Melhor controle visual
  • Responsividade
  • Impressão otimizada
  • Adaptação para diferentes dispositivos
  • Melhor experiência do usuário
