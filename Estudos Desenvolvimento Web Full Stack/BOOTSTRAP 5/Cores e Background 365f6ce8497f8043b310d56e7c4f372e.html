Cores e Background

Cores e Background no Bootstrap

O Bootstrap possui várias classes utilitárias para aplicar cores em textos, fundos e elementos rapidamente, sem precisar criar CSS personalizado.

Essas classes ajudam a:

  • Padronizar o visual
  • Criar destaque
  • Melhorar a interface
  • Acelerar o desenvolvimento

Classes de cores de texto

Bootstrap usa a estrutura:

text-cor

Principais cores

ClasseCor
text-primaryAzul
text-secondaryCinza
text-successVerde
text-dangerVermelho
text-warningAmarelo
text-infoAzul claro
text-lightBranco
text-darkPreto escuro
text-mutedCinza claro

Exemplo

<p class="text-success">
    Texto verde
</p>

Background

Para fundos, Bootstrap usa:

bg-cor

Classes de background

ClasseFundo
bg-primaryAzul
bg-successVerde
bg-dangerVermelho
bg-warningAmarelo
bg-infoAzul claro
bg-darkPreto escuro
bg-lightBranco/cinza claro

Exemplo

<div class="bg-primary text-light">
    Fundo azul
</div>

Normalmente, quando o fundo é escuro, usa-se:

  • text-light

Quando o fundo é claro:

  • text-dark

Background com transparência

Bootstrap possui opacidade pronta.

Exemplos

<div class="bg-primary bg-opacity-50">

Níveis de opacidade

ClasseOpacidade
bg-opacity-1010%
bg-opacity-2525%
bg-opacity-5050%
bg-opacity-7575%
bg-opacity-100100%

Gradiente

Bootstrap possui fundo gradiente pronto:

<div class="bg-primary bg-gradient">

Background em botões

As cores também são usadas nos botões.

Exemplo:

<button class="btn btn-danger">
    Excluir
</button>

Background em cards

<div class="card bg-dark text-light">

Muito usado para:

  • Cards
  • Seções
  • Alertas

Alertas coloridos

<div class="alert alert-success">
    Operação realizada!
</div>

Combinação de cores

Bootstrap já possui combinações harmoniosas para UI.

Exemplo:

FundoTexto recomendado
bg-darktext-light
bg-warningtext-dark
bg-primarytext-light

Exemplo completo

<div class="container">

<h1 class="text-primary">
        Bootstrap
</h1>

<div class="bg-dark text-light p-3 rounded">

<p>
            Caixa com fundo escuro.
</p>

</div>

</div>

Background responsivo

As classes podem ser combinadas com:

  • Padding
  • Margin
  • Flexbox
  • Grid
  • Breakpoints

Exemplo:

<div class="bg-primary p-5 text-center">

Vantagens das cores no Bootstrap

  • Padronização visual
  • Rapidez no desenvolvimento
  • Menos CSS manual
  • Interface mais profissional
  • Responsividade integrada
