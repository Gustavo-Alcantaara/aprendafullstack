Dimensões de caixa

As dimensões de caixas no CSS controlam o tamanho dos elementos na página, principalmente largura e altura. Isso é muito usado em div, imagens, cards, botões, containers etc.

Todo elemento HTML pode ser tratado como uma caixa (modelo de caixa).

Principais propriedades

width

Define a largura da caixa.

.caixa {
  width:300px;
}

height

Define a altura da caixa.

.caixa {
  height:150px;
}

Valores possíveis

Pixels (px)

Tamanho fixo.

width: 300px;

Porcentagem (%)

Baseado no tamanho do elemento pai.

width: 50%;

Ocupa metade da largura do container pai.

Viewport (vw e vh)

Relacionado à tela.

width: 100vw;
height: 100vh;
  • 100vw = largura total da tela
  • 100vh = altura total da tela

auto

O navegador calcula automaticamente.

width:auto;

Limites de tamanho

max-width

Largura máxima.

max-width: 500px;

Muito usado em layouts responsivos.

min-width

Largura mínima.

min-width: 200px;

max-height e min-height

max-height: 400px;
min-height: 100px;

Exemplo prático

.card {
  width:300px;
  min-height:200px;
  max-width:100%;
}

Responsividade

Muito comum usar:

.container {
  width:90%;
  max-width:1200px;
}

Assim o elemento se adapta em telas pequenas, mas não cresce demais em telas grandes.

Importante: padding e border influenciam

Sem box-sizing: border-box, o tamanho total pode aumentar.

box-sizing:border-box;

Isso faz width e height incluírem padding e borda.

Resumo rápido

PropriedadeFunção

Dica prática

Para layouts modernos:

* {
  box-sizing:border-box;
}

Ajuda muito no controle das dimensões.

Resumo final

Dimensões de caixas servem para controlar o espaço que cada elemento ocupa na tela, permitindo criar layouts organizados, responsivos e bonitos.
