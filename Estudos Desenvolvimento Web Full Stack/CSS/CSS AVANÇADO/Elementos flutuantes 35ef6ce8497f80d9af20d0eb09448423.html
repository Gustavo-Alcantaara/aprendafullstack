Elementos flutuantes

Elementos flutuantes em CSS usam a propriedade float, criada originalmente para fazer textos contornarem imagens, mas que também foi muito usada em layouts antigos.

Hoje flexbox e grid substituem muitos usos, porém float ainda aparece em projetos e conteúdos antigos.

Propriedade principal: float

Define para qual lado o elemento vai “flutuar”.

float:valor;

Valores principais

left

Faz o elemento ir para a esquerda e permite conteúdo ao redor.

img {
  float:left;
}

right

Faz o elemento ir para a direita.

img {
  float:right;
}

none

Valor padrão. O elemento não flutua.

float:none;

Exemplo prático

img {
  float:left;
  margin-right:10px;
}

O texto ficará ao lado da imagem.

Problema comum: pai “colapsa”

Quando todos os filhos estão com float, o elemento pai pode parecer sem altura.

Exemplo:

.caixa-filho {
  float:left;
}

O container pai pode não envolver corretamente os filhos.

Propriedade para resolver: clear

Usada para impedir que elementos fiquem ao lado de flutuantes.

clear:valor;

Valores:

ValorFunção
leftlimpa floats à esquerda
rightlimpa floats à direita
bothlimpa ambos os lados
nonepadrão

Exemplo:

.rodape {
  clear:both;
}

O rodapé vai aparecer abaixo dos elementos flutuantes.

Técnica famosa: clearfix

Usada para fazer o pai reconhecer filhos flutuantes.

.container::after {
  content:"";
  display:block;
  clear:both;
}

Muito usado antigamente para:

  • menus horizontais
  • colunas de layout
  • imagens com texto ao redor
  • grids antigos

Hoje em dia prefira:

Para alinhamento e layout:

display:flex;

ou

display:grid;

Mais modernos e fáceis.

Resumo rápido

PropriedadeFunção
floatflutua elemento
clearlimpa flutuação
clearfixcorrige colapso do pai

Resumo final

Elementos flutuantes movem itens para esquerda ou direita e permitem conteúdo ao redor. Foram muito usados em layouts antigos, mas hoje flexbox e grid são melhores opções.

Dica prática

Use float principalmente para texto envolvendo imagem, exemplo:

img {
  float:left;
}
