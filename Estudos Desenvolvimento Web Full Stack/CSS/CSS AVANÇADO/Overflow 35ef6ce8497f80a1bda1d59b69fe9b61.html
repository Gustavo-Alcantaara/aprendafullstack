Overflow

overflow no CSS controla o que acontece quando o conteúdo de um elemento ultrapassa o tamanho definido dele (largura ou altura).

Isso acontece muito em caixas com texto grande, imagens grandes ou listas extensas.

Sintaxe básica

overflow:valor;

Exemplo:

.caixa {
  width:200px;
  height:100px;
  overflow:hidden;
}

Principais valores

visible (padrão)

O conteúdo que passar do limite continua aparecendo para fora da caixa.

overflow:visible;

✔ Valor padrão.

hidden

Esconde tudo que ultrapassar o tamanho do elemento.

overflow:hidden;

✔ Muito usado para cortar excesso de imagem ou texto.

scroll

Adiciona barra de rolagem sempre, mesmo se não precisar.

overflow:scroll;

✔ Barra horizontal e/ou vertical.

auto

Adiciona barra de rolagem somente se necessário.

overflow:auto;

✔ Um dos mais usados.

Controle separado

overflow-x

Controla eixo horizontal.

overflow-x:scroll;

overflow-y

Controla eixo vertical.

overflow-y:auto;

Exemplo:

.caixa {
  height:150px;
  overflow-y:scroll;
}

Exemplo prático

.lista {
  width:300px;
  height:200px;
  overflow:auto;
}

Se tiver conteúdo demais, aparece rolagem.

Muito usado com imagens

.card {
  overflow:hidden;
  border-radius:10px;
}

Isso impede a imagem de sair para fora das bordas arredondadas.

Resumo rápido

ValorResultado
visibleconteúdo sai da caixa
hiddenconteúdo escondido
scrollbarra sempre visível
autobarra só se precisar

Dica importante

Para overflow funcionar bem, geralmente o elemento precisa ter:

  • width
  • height
  • ou max-height

Sem limite de tamanho, dificilmente haverá "estouro".

Exemplo comum em sites

body {
  overflow-x:hidden;
}

Usado para evitar rolagem lateral indesejada.
