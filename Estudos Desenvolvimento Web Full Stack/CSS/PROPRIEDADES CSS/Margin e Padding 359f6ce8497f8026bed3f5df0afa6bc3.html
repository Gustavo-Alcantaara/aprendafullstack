Margin e Padding

Margin e Padding são espaçamentos do box model (modelo de caixa) do CSS.

  • Padding: espaço interno, entre o conteúdo e a borda.
  • Margin: espaço externo, fora da borda, que separa um elemento dos outros.

Padding

O que é e por que usar

  • Cria “respiro” dentro do elemento, deixando o conteúdo mais legível.
  • Aumenta a área clicável (bom para botões e links).
  • Ajuda a manter alinhamentos e espaçamento interno consistente.

Exemplo

.card {
  padding: 16px;
  border: 1px solid #ddd;
}

Margin

O que é e por que usar

  • Cria afastamento entre elementos.
  • Ajuda a organizar layout e ritmo visual (títulos, parágrafos, seções).
  • É a forma mais comum de separar componentes sem “mexer” no conteúdo interno.

Exemplo

h2 {
  margin-bottom: 12px;
}

.card {
  margin: 24px 0;
}

Shorthand (forma reduzida)

1 valor

Aplica em todos os lados.

padding: 16px;
margin: 24px;

2 valores

vertical horizontal.

padding: 12px 20px; /* topo/baixo = 12px, esquerda/direita = 20px */
margin: 8px 0;      /* topo/baixo = 8px, esquerda/direita = 0 */

3 valores

topo horizontal baixo.

margin: 16px 0 24px;

4 valores

topo direita baixo esquerda (sentido horário).

padding: 8px 12px 10px 12px;

Forma “bruta” (propriedades separadas)

Padding

padding-top: 8px;
padding-right: 12px;
padding-bottom: 8px;
padding-left: 12px;

Margin

margin-top: 16px;
margin-right: 0;
margin-bottom: 24px;
margin-left: 0;

Dicas práticas (como escolher)

  • Use padding para espaçamento interno de componentes: botões, cards, inputs.
  • Use margin para separar blocos/componentes entre si: seções, cards empilhados, títulos.
  • Prefira shorthand quando o padrão é simples. Use a forma “bruta” quando precisar ajustar um lado específico.

Padrões e boas práticas (espaçamentos e formatação)

Espaçamentos “padrão” do navegador (user agent stylesheet)

  • Tags como h1, h2, p, ul/ol e body vêm com margens padrão aplicadas pelo navegador.
  • Por isso, às vezes você vê espaços “do nada” mesmo sem ter colocado margin.

Reset básico (opcional)

Se quiser começar com controle total do layout, um reset comum é:

* {
  box-sizing: border-box;
}

body {
  margin: 0;
}
  • box-sizing: border-box; faz padding e border entrarem no cálculo da largura/altura, o que facilita muito.

Formatação “padrão” do box model

  • Por padrão, width e height não incluem padding e border quando box-sizing está em content-box (padrão).
  • Na prática, isso pode fazer um elemento “crescer” quando você adiciona padding.

Recomendações

  • Use box-sizing: border-box; globalmente.
  • Evite misturar muitos valores diferentes sem um padrão (ex.: 7px, 13px, 19px). Prefira uma escala consistente.

Dicas práticas de uso (do dia a dia)

1) Use padding para “conforto” do componente

  • Botões e inputs ficam melhores com padding consistente.
  • Um alvo clicável confortável costuma ter altura mínima de ~44px (referência comum em mobile).

2) Use margin para separar blocos

  • Para listas de cards, seções e títulos, margin geralmente é a escolha certa.
  • Se o espaço vertical estiver estranho, verifique margin collapsing.

3) Prefira gap em layouts com flex/grid

Em vez de ficar colocando margin-right em cada item:

.list {
  display: flex;
  gap: 16px;
}
  • gap é mais limpo e evita “margem no último item”.

4) Cuidado com margin em elementos inline

  • margin-top e margin-bottom em elementos display: inline normalmente não se comportam como você espera.
  • Se precisar de controle de espaçamento, use display: inline-block ou block.

5) Centralização e espaçamento horizontal

  • Para centralizar um bloco com largura definida: margin: 0 auto;.
  • Para espaçar lateralmente dentro do container: padding-left/right no container (comum em layouts responsivos).

“Receitas” rápidas

/* Base comum em projetos */
* { box-sizing: border-box; }
body { margin: 0; }

/* Card padrão */
.card {
  padding: 16px;
  border: 1px solid #e5e7eb;
  border-radius: 12px;
}

/* Lista vertical de seções */
.section + .section {
  margin-top: 24px;
}
