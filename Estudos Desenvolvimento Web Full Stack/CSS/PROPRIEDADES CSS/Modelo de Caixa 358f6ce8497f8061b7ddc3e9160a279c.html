Modelo de Caixa

O modelo de caixa (Box Model) em CSS é a forma como o navegador organiza e calcula o espaço de todo elemento HTML na página. Cada elemento é tratado como uma caixa retangular.

Estrutura do Box Model

De dentro para fora:

1. Content (conteúdo)

É a área onde fica o texto, imagem ou conteúdo do elemento.

width: 200px;
height: 100px;

Define o tamanho da área interna (por padrão).

2. Padding (preenchimento interno)

Espaço entre o conteúdo e a borda.

padding: 20px;
  • Aumenta o espaço interno.
  • A cor de fundo também cobre o padding.

Exemplo:

padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

Ou resumido:

padding: 10px 20px;

Ordem de definição

padding: 10px 20px 10px 20px;
topo, direita, baixo, esquerda.

3. Border (borda)

Linha ao redor do padding/conteúdo.

border: 2px solid black;

Pode ter:

  • espessura
  • estilo
  • cor

4. Margin (margem externa)

Espaço entre o elemento e outros elementos.

margin: 30px;

Não recebe cor de fundo.

Visualmente

Margin
 └ Border
    └ Padding
       └ Content

Exemplo completo

div{
   width:200px;
   padding:20px;
   border:5px solid blue;
   margin:30px;
}

Tamanho total horizontal:

200 + 20 + 20 + 5 + 5 = 250px

(sem contar margin)

box-sizing

box-sizing define como o navegador calcula width e height de um elemento no Box Model.

Valores principais

content-box (padrão)

width/height contam só o conteúdo.

Padding e borda entram por fora, aumentando o tamanho final.

div {
  width: 200px;
  padding: 20px;
  border: 2px solid #000;
}
/* largura final > 200px */

border-box (mais usado em layout)

width/height já incluem conteúdo + padding + borda.

O tamanho final fica previsível (não “estoura” a largura).

div {
  width: 200px;
  padding: 20px;
  border: 2px solid #000;
  box-sizing: border-box;
}
/* largura final = 200px */

Por que usar?

  • Evita ficar fazendo conta (conteúdo + padding + borda).
  • Facilita grids/colunas (ex.: 50% + padding não quebra linha do nada).
  • Deixa componentes mais previsíveis quando você adiciona padding/borda.

Como e onde usar (recomendado)

Aplicar globalmente (padrão “moderno”):

*,
*::before,
*::after {
  box-sizing: border-box;
}

Casos típicos:

  • Layouts com cards, botões, inputs, colunas, containers com width definida.
  • Componentes onde você muda padding/border com frequência (hover/focus/variantes).

Resumo rápido

  • content-box: width = só conteúdo (padding/borda aumentam por fora)
  • border-box: width = conteúdo + padding + borda (tamanho final previsível)

Dicas importantes

  • margin: auto; centraliza horizontalmente blocos com largura definida.
  • Margens verticais podem se juntar (margin collapse).

    Margin collapse acontece quando margens verticais (margin-top e margin-bottom) de elementos encostados se juntam em vez de somar.

    Exemplo:

    div1 { margin-bottom:30px; }
div2 { margin-top:20px; }

    O espaço entre eles será 30px, não 50px.

    Quando acontece:

    • Entre elementos blocos empilhados verticalmente
    • Entre pai e primeiro/último filho (em alguns casos)

    Como evitar:

    Use:

    • padding
    • border
    • overflow: hidden
    • display: flex
    • display: grid

    Resumo:

    Duas margens verticais podem virar uma só, valendo a maior.

  • padding aumenta o tamanho visível da caixa.
  • border-box é o mais prático hoje.
  • margin collapse não acontece horizontalmente.

Resumo rápido

Todo elemento HTML = caixa com:

conteúdo → padding → border → margin

Entender isso é essencial para alinhar, espaçar e montar layouts em CSS.
