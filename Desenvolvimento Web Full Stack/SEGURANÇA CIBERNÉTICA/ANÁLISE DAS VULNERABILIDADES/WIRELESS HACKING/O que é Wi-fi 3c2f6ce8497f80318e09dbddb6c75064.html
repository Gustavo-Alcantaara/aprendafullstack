O que é Wi-Fi?

Wi-Fi é uma tecnologia de comunicação sem fio que permite conectar dispositivos a uma rede utilizando ondas de rádio, sem a necessidade de cabos físicos.

O termo é utilizado no dia a dia para representar redes sem fio usadas para conectar:

  • Computadores;
  • Smartphones;
  • Tablets;
  • Smart TVs;
  • Impressoras;
  • Videogames;
  • Câmeras;
  • Dispositivos IoT;
  • Outros equipamentos.

O Wi-Fi é uma tecnologia fundamental para redes domésticas, empresariais e públicas.

1. Como funciona o Wi-Fi?

O funcionamento básico pode ser representado assim:

Dispositivo → Ondas de rádio → Roteador/Ponto de acesso → Rede → Internet

Por exemplo, quando um celular se conecta ao Wi-Fi de uma residência:

  1. O celular procura redes disponíveis.
  1. O usuário escolhe uma rede.
  1. O dispositivo realiza o processo de autenticação.
  1. O roteador permite a conexão.
  1. O celular recebe configurações de rede, como um endereço IP.
  1. O dispositivo pode então se comunicar com outros equipamentos e, normalmente, acessar a Internet.

2. Wi-Fi não é a mesma coisa que Internet

Essa diferença é muito importante.

Wi-Fi é uma tecnologia de conexão sem fio a uma rede.

Internet é uma grande rede mundial que conecta redes e dispositivos.

É possível ter:

Wi-Fi sem Internet

Por exemplo:

Celular → Wi-Fi → Roteador

Mas o roteador pode estar sem conexão com a operadora.

Nesse caso, existe Wi-Fi, mas não há acesso à Internet.

Também é possível acessar uma rede local através de Wi-Fi sem utilizar a Internet.

3. O que é um roteador?

O roteador é um equipamento responsável por conectar redes e encaminhar dados entre elas.

Em uma residência, ele normalmente pode desempenhar várias funções ao mesmo tempo:

  • Roteador;
  • Ponto de acesso Wi-Fi;
  • Switch;
  • Servidor DHCP;
  • Firewall básico;
  • NAT.

Por isso, é comum chamar simplesmente de "roteador Wi-Fi".

4. O que é um Access Point?

Access Point (AP) significa ponto de acesso.

É o equipamento responsável por fornecer acesso à rede através de uma conexão sem fio.

Em uma rede empresarial, por exemplo, podem existir vários Access Points distribuídos pelo prédio.

Um modelo simplificado seria:

Internet

↓

Roteador/Firewall

↓

Switch

↓

Access Points

↓

Celulares / notebooks / outros dispositivos

5. Como os dispositivos se comunicam?

O Wi-Fi utiliza ondas eletromagnéticas, principalmente nas bandas de:

  • 2,4 GHz
  • 5 GHz
  • 6 GHz

Cada banda possui características diferentes.

6. Wi-Fi 2,4 GHz

A frequência de 2,4 GHz possui uma característica importante: geralmente apresenta maior alcance e melhor capacidade de atravessar determinados obstáculos do que frequências mais altas.

Porém, existe maior possibilidade de interferência porque muitos dispositivos utilizam essa faixa.

Exemplos:

  • Alguns dispositivos Bluetooth;
  • Equipamentos IoT;
  • Redes Wi-Fi próximas;
  • Outros dispositivos que operam nessa faixa.

Vantagem

Maior alcance.

Desvantagem

Maior possibilidade de interferência e congestionamento.

7. Wi-Fi 5 GHz

A banda de 5 GHz normalmente oferece:

  • Mais canais disponíveis;
  • Menor congestionamento em muitos ambientes;
  • Maior capacidade de transmissão;
  • Menor alcance que 2,4 GHz em condições semelhantes.

É bastante utilizada para atividades que exigem maior desempenho.

Vantagem

Maior desempenho em distâncias menores.

Desvantagem

Menor alcance e maior dificuldade para atravessar obstáculos em comparação com 2,4 GHz.

8. Wi-Fi 6 GHz

A banda de 6 GHz foi incorporada às gerações mais recentes de Wi-Fi, especialmente com o Wi-Fi 6E e tecnologias posteriores.

Ela oferece uma faixa adicional de espectro e pode proporcionar:

  • Mais canais;
  • Menos congestionamento;
  • Maior capacidade;
  • Melhor desempenho em ambientes com muitas redes.

Entretanto, o alcance tende a ser menor que em frequências mais baixas.

Além disso, o dispositivo e o roteador precisam oferecer suporte à banda.

Algumas gerações importantes são:

10. O que significa SSID?

SSID (Service Set Identifier) é o nome utilizado para identificar uma rede Wi-Fi.

Quando você abre a lista de redes disponíveis no celular e vê:

MinhaCasa
WiFi_5G
Empresa

esses nomes são SSIDs.

O SSID não é a senha.

Exemplo

SSID: MinhaCasa

Senha: MinhaSenha123

O primeiro identifica a rede; o segundo é utilizado para autenticação.

11. Senha do Wi-Fi

A senha é utilizada para controlar o acesso à rede sem fio quando mecanismos de segurança apropriados estão configurados.

Uma senha forte deve ser:

  • Longa;
  • Difícil de adivinhar;
  • Única;
  • Sem informações pessoais óbvias.

Evite senhas como:

12345678

senha123

internet

ou informações facilmente relacionadas ao proprietário.

12. Segurança do Wi-Fi

A segurança de uma rede Wi-Fi depende principalmente do protocolo de segurança utilizado.

Os principais padrões encontrados historicamente são:

  • WEP;
  • WPA;
  • WPA2;
  • WPA3.

13. WEP

WEP (Wired Equivalent Privacy) foi um dos primeiros mecanismos de segurança utilizados em redes Wi-Fi.

Atualmente, é considerado inseguro e obsoleto.

Suas limitações criptográficas permitem que redes WEP sejam comprometidas com relativa facilidade.

Recomendação

Não utilizar WEP.

14. WPA

O WPA (Wi-Fi Protected Access) foi desenvolvido como uma melhoria em relação ao WEP.

Entretanto, atualmente existem opções mais modernas e seguras.

Recomendação

Preferir protocolos mais atuais, especialmente WPA2 ou WPA3, dependendo da compatibilidade dos dispositivos.

15. WPA2

O WPA2 tornou-se durante muitos anos um dos principais padrões de segurança para redes Wi-Fi.

Pode utilizar AES/CCMP para proteger a comunicação.

Existem diferentes modos de utilização.

WPA2-Personal

Utilizado normalmente em residências e pequenas redes.

Utiliza uma senha compartilhada.

WPA2-Enterprise

Utilizado em ambientes corporativos.

Pode utilizar um servidor de autenticação para controlar usuários individualmente.

16. WPA3

O WPA3 é uma geração mais recente de segurança para redes Wi-Fi.

Ele introduz melhorias em relação ao WPA2.

Uma característica importante no modo pessoal é o uso do SAE (Simultaneous Authentication of Equals), que melhora a proteção do processo de autenticação contra determinados tipos de ataques de senha.

Em redes domésticas

Quando todos os dispositivos são compatíveis, WPA3-Personal é uma opção moderna.

17. WPA-Personal × WPA-Enterprise

Essa diferença é importante em Segurança Cibernética.

Personal

Normalmente utiliza uma senha compartilhada.

Exemplo:

SSID: Empresa-WiFi

Senha: ********

Todos os usuários que possuem a senha podem tentar acessar a rede.

Enterprise

Cada usuário pode possuir suas próprias credenciais.

Exemplo:

João → usuário/senha

Maria → usuário/senha

Carlos → usuário/senha

Isso permite maior controle sobre:

  • Usuários;
  • Autenticação;
  • Revogação de acesso;
  • Auditoria.

18. Criptografia no Wi-Fi

Quando uma rede utiliza mecanismos modernos de segurança, a comunicação entre dispositivos e o ponto de acesso pode ser protegida por criptografia.

De forma simplificada:

Dados originais → Criptografia → Dados protegidos → Transmissão → Descriptografia

Isso dificulta que terceiros interceptem e compreendam o conteúdo da comunicação.

É importante destacar que criptografia Wi-Fi não substitui HTTPS, VPN ou outras camadas de segurança.

Cada tecnologia protege partes diferentes da comunicação.

19. Redes Wi-Fi públicas

Redes públicas podem ser encontradas em:

  • Aeroportos;
  • Hotéis;
  • Restaurantes;
  • Shoppings;
  • Universidades;
  • Praças;
  • Cafeterias.

O problema é que você possui menos controle sobre a infraestrutura.

Cuidados

Evite realizar ações extremamente sensíveis em redes públicas desconhecidas, principalmente quando o dispositivo ou serviço não possui proteções adicionais.

Prefira:

  • HTTPS;
  • MFA;
  • Aplicativos oficiais;
  • VPN quando apropriado;
  • Desativar compartilhamentos desnecessários.

20. Wi-Fi público × HTTPS

É comum pensar:

"Se estou usando Wi-Fi público, tudo que faço está exposto."

Isso não é necessariamente verdade.

Quando você acessa um site utilizando HTTPS, a comunicação entre o navegador e o servidor é protegida por TLS.

Porém, ainda existem riscos relacionados à própria rede, como:

  • Redes falsas;
  • Phishing;
  • Ataques contra dispositivos vulneráveis;
  • Redirecionamentos;
  • Configurações inseguras.

Por isso, o usuário deve utilizar várias camadas de proteção.

21. Evil Twin

Um Evil Twin é uma rede Wi-Fi maliciosa criada para se passar por uma rede legítima.

Imagine que exista:

Hotel_WiFi

Um atacante pode criar outra rede com nome semelhante:

Hotel_WiFi_Free

ou até tentar copiar o nome da rede legítima.

Um usuário pode se conectar pensando que está utilizando o Wi-Fi verdadeiro.

Risco

O atacante pode tentar:

  • Induzir a vítima a acessar páginas falsas;
  • Coletar informações;
  • Realizar ataques de engenharia social;
  • Explorar dispositivos vulneráveis.

22. Como proteger uma rede Wi-Fi doméstica?

Algumas medidas importantes são:

1. Utilize WPA2 ou WPA3

Evite protocolos antigos como WEP.

2. Use uma senha forte

Evite senhas óbvias.

3. Altere credenciais administrativas padrão

O painel de administração do roteador deve possuir credenciais fortes e diferentes das utilizadas para acesso ao Wi-Fi, quando possível.

4. Atualize o firmware

Fabricantes podem disponibilizar correções de segurança.

5. Desative recursos desnecessários

Quanto menos serviços expostos, menor a superfície de ataque.

6. Crie uma rede para convidados

Visitantes não precisam necessariamente ter acesso à mesma rede dos seus computadores pessoais.

23. Rede de convidados

A Guest Network, ou rede de convidados, permite criar uma rede separada para visitantes.

Por exemplo:

Rede principal

→ Computador

→ Celular

→ Servidor

→ Impressora

Rede de convidados

→ Celulares dos visitantes

A ideia é limitar o acesso dos convidados aos dispositivos da rede principal.

24. Segurança do roteador

O roteador é um equipamento extremamente importante porque funciona como uma porta de entrada para a rede.

Por isso:

  • Atualize seu firmware;
  • Utilize senha administrativa forte;
  • Não compartilhe credenciais administrativas;
  • Desative administração remota quando não for necessária;
  • Verifique dispositivos conectados;
  • Utilize configurações de segurança modernas.

Um roteador comprometido pode permitir que um atacante tenha uma posição privilegiada dentro da rede.

25. Wi-Fi e Segurança Cibernética

O Wi-Fi é especialmente importante na Segurança Cibernética porque representa uma interface de acesso à rede sem a necessidade de conexão física.

Isso significa que alguém dentro do alcance do sinal pode tentar detectar a existência da rede.

Por isso, a segurança deve considerar:

Autenticação + Criptografia + Senhas + Atualizações + Segmentação + Monitoramento

26. Wi-Fi não significa automaticamente segurança

Ter uma senha no Wi-Fi não significa que a rede está completamente protegida.

Por exemplo:

Wi-Fi com senha fraca + roteador desatualizado = risco

Enquanto:

WPA3 + senha forte + firmware atualizado + rede segmentada = proteção muito maior

Segurança é resultado da combinação de várias medidas.

Resumo final

Wi-Fi é uma tecnologia que permite conectar dispositivos a uma rede utilizando comunicação sem fio por ondas de rádio.

Seu funcionamento envolve elementos como:

Dispositivo → Access Point/Roteador → Rede → Internet

As principais frequências utilizadas atualmente são 2,4 GHz, 5 GHz e 6 GHz, enquanto as gerações mais recentes incluem Wi-Fi 6, Wi-Fi 6E e Wi-Fi 7.

Na perspectiva de Segurança Cibernética, é fundamental utilizar:

WPA2/WPA3 + senha forte + firmware atualizado + configuração segura + segmentação + rede de convidados quando necessário.

O ponto principal para memorizar é:

Wi-Fi é o meio de comunicação sem fio; segurança Wi-Fi é o conjunto de mecanismos que protege o acesso e a comunicação nessa rede.
