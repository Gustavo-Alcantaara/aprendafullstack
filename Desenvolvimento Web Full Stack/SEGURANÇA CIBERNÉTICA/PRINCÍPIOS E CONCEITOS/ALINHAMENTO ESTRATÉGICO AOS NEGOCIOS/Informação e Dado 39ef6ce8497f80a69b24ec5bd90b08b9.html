Informação e Dado

Informação e Dado

Os termos dado e informação são frequentemente usados como sinônimos no dia a dia, mas, em Tecnologia da Informação e Segurança da Informação, eles possuem significados diferentes.

Compreender essa diferença é fundamental, pois a Segurança da Informação existe justamente para proteger os dados e as informações de uma organização.

De forma simples:

  • Dado é um fato ou valor isolado, que por si só pode não ter significado.
  • Informação é o resultado da organização, interpretação e contextualização dos dados, gerando conhecimento útil.

O que é um Dado?

Um dado é a menor unidade de informação.

Ele representa um valor, fato ou registro bruto que ainda não foi interpretado ou colocado em contexto.

Os dados podem ser:

  • Números
  • Letras
  • Símbolos
  • Imagens
  • Sons
  • Datas
  • Coordenadas
  • Valores armazenados em um banco de dados

Sozinho, um dado pode não dizer muita coisa.

Exemplos de dados

21

O número 21, sozinho, não informa seu significado.

Pode representar:

  • Idade
  • Quantidade
  • Temperatura
  • Número de uma casa
  • Código de um produto

Sem contexto, continua sendo apenas um dado.

Outro exemplo:

Carlos

Esse nome isolado também é apenas um dado.

Pode ser:

  • Nome de um cliente
  • Funcionário
  • Médico
  • Aluno

Ainda não sabemos.

Características dos Dados

Os dados normalmente possuem as seguintes características:

  • São registros brutos.
  • Não possuem contexto.
  • Podem ser coletados automaticamente.
  • São armazenados em bancos de dados.
  • Servem como matéria-prima para gerar informações.

Tipos de Dados

Os dados podem assumir diversas formas.

Dados Numéricos

Representam valores matemáticos.

Exemplos:

  • 18
  • 3,14
  • 4500
  • 99%

Dados Textuais

Representam palavras ou frases.

Exemplos:

  • Gustavo
  • Segurança
  • Brasil

Dados Booleanos

Representam apenas dois estados.

Exemplos:

  • Verdadeiro (True)
  • Falso (False)

Muito utilizados em programação.

Dados Temporais

Representam datas e horários.

Exemplos:

  • 15/07/2026
  • 14:30

Dados Multimídia

Incluem:

  • Fotos
  • Vídeos
  • Áudios
  • Imagens
  • Animações

O que é Informação?

A informação é um conjunto de dados organizados, interpretados e contextualizados de forma que possuam significado e possam apoiar uma decisão ou compreensão.

Ela responde perguntas como:

  • O quê?
  • Quem?
  • Quando?
  • Onde?
  • Como?
  • Por quê?

Enquanto o dado é apenas um registro, a informação transmite conhecimento.

Exemplo

Imagine os seguintes dados:

Nome: Gustavo

Idade: 21

Curso: Segurança Cibernética

Cada item isolado é um dado.

Quando organizados, temos uma informação:

"Gustavo tem 21 anos e estuda Segurança Cibernética."

Agora existe contexto e significado.

Outro exemplo

Dados:

38,5

João

Hospital

Separadamente, esses elementos não dizem muita coisa.

Organizados:

"João está no hospital com temperatura corporal de 38,5 °C."

Agora existe uma informação útil.

Esse processo ocorre em várias etapas.

Relação com Segurança da Informação

A Segurança da Informação protege tanto os dados quanto as informações.

Por exemplo:

Dados protegidos

  • CPF
  • Senha
  • Nome
  • Endereço
  • Número do cartão
  • Biometria
  • Endereço IP

Informações protegidas

  • Histórico financeiro de um cliente.
  • Relatório de vendas da empresa.
  • Diagnóstico médico de um paciente.
  • Projeto confidencial de um produto.
  • Estratégia de negócios.

Dados Sensíveis

Nem todos os dados possuem o mesmo nível de importância.

Alguns exigem proteção especial.

Exemplos:

  • Senhas
  • Impressões digitais
  • Reconhecimento facial
  • Dados bancários
  • Dados médicos
  • Informações fiscais
  • Chaves criptográficas

Esses dados são chamados de dados sensíveis e normalmente recebem controles de segurança mais rigorosos.

Valor da Informação

A informação possui valor para empresas, governos e pessoas.

Ela pode representar:

  • Dinheiro
  • Vantagem competitiva
  • Propriedade intelectual
  • Privacidade
  • Conhecimento estratégico

Quanto maior seu valor, maior deve ser seu nível de proteção.

Por isso, organizações costumam classificar as informações conforme sua sensibilidade.

Classificação da Informação

Uma prática comum é definir níveis de classificação para orientar os controles de segurança.

Exemplo:

ClassificaçãoCaracterísticas
PúblicaPode ser divulgada sem causar prejuízo.
Uso InternoDestinada apenas aos colaboradores da organização.
ConfidencialAcesso restrito a pessoas autorizadas; o vazamento pode causar impactos significativos.
SecretaInformações altamente sensíveis, cujo acesso é extremamente limitado devido ao grande impacto de um possível vazamento.

Cada organização pode adotar classificações diferentes conforme suas necessidades.

A importância dos Metadados

Além dos dados, existem os metadados, que são "dados sobre os dados".

Eles descrevem características de um dado ou arquivo.

Exemplos:

  • Data de criação de um documento.
  • Autor de um arquivo.
  • Local onde uma foto foi tirada (GPS).
  • Tamanho do arquivo.
  • Tipo de arquivo.
  • Data da última modificação.

Embora não sejam o conteúdo principal, metadados podem revelar informações sensíveis e também precisam ser protegidos em muitos contextos.

Exemplos práticos

Exemplo 1 – Banco

Dados:

  • Nome
  • CPF
  • Número da conta
  • Saldo

Informação:

"O cliente João possui saldo de R$ 5.000,00 em sua conta corrente."

Exemplo 2 – Hospital

Dados:

  • Nome
  • Pressão arterial
  • Temperatura
  • Exames

Informação:

"O paciente apresenta quadro compatível com uma infecção."

Exemplo 3 – Empresa

Dados:

  • Quantidade vendida
  • Valor das vendas
  • Custos

Informação:

"A empresa aumentou seu lucro em 15% neste trimestre."

Boas práticas para proteger Dados e Informações

  • Classificar as informações conforme seu nível de sensibilidade.
  • Aplicar o princípio do menor privilégio, concedendo apenas os acessos necessários.
  • Criptografar dados sensíveis, tanto em armazenamento quanto em trânsito.
  • Realizar backups periódicos.
  • Manter registros (logs) de acesso e alterações.
  • Descartar mídias e documentos de forma segura.
  • Treinar usuários sobre boas práticas de segurança e privacidade.
  • Revisar periodicamente as permissões de acesso.

Resumo

Dados são registros brutos, como números, textos, imagens ou datas, que isoladamente podem não possuir significado. Informações surgem quando esses dados são organizados, interpretados e colocados em contexto, tornando-se úteis para compreender situações e apoiar decisões. Na Segurança da Informação, ambos são ativos importantes: os dados representam a matéria-prima, enquanto as informações representam o conhecimento gerado a partir deles. Proteger ambos é essencial para garantir a confidencialidade, a integridade e a disponibilidade das informações de uma organização.
