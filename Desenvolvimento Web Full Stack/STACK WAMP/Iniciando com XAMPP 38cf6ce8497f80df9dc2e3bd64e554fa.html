Iniciando com XAMPP

Se você está começando no desenvolvimento web com XAMPP, o processo é bem simples. O XAMPP cria um ambiente local com Apache (servidor web), PHP (linguagem) e MySQL (banco de dados), permitindo desenvolver e testar aplicações sem precisar hospedá-las na internet.

1. Inicie o XAMPP

Após instalar:

  1. Abra o XAMPP Control Panel.
  1. Clique em Start ao lado de:
    • Apache
    • MySQL (caso utilize banco de dados)

Se tudo estiver correto, ambos ficarão com o fundo verde.

Você pode testar acessando:

http://localhost

Se aparecer a página do XAMPP, está funcionando.

2. Encontre a pasta do servidor

Todo projeto deve ficar dentro da pasta htdocs.

Normalmente ela fica em:

C:\xampp\htdocs

Imagine essa pasta como a raiz do seu servidor.

3. Crie seu projeto

Dentro do htdocs, crie uma pasta.

Exemplo:

htdocs
│
├── ghostware
│   ├── index.php
│   ├── css
│   ├── js
│   ├── img
│   └── includes

4. Crie a página inicial

Crie um arquivo chamado

index.php

Exemplo:

<!DOCTYPE html>
<html>

<head>
    <title>Ghostware</title>
</head>

<body>

<h1>Meu primeiro projeto PHP</h1>

<?php
echo "Olá Mundo!";
?>

</body>

</html>

5. Acesse o projeto

No navegador:

http://localhost/ghostware

O Apache procura automaticamente pelo arquivo

index.php

ou

index.html

6. Estrutura recomendada

Uma estrutura organizada seria:

ghostware
│
├── css
│   └── style.css
│
├── js
│   └── script.js
│
├── img
│
├── includes
│   ├── header.php
│   ├── footer.php
│   └── conexao.php
│
├── pages
│
├── uploads
│
├── index.php
│
└── .htaccess

Cada pasta possui uma responsabilidade específica.

7. Trabalhando com PHP

No PHP, qualquer código deve ficar entre:

<?php

// código

?>

Exemplo:

<?php

$nome = "Gustavo";

echo "Bem-vindo $nome";

?>

8. Criando um banco de dados

Com o MySQL iniciado, acesse:

http://localhost/phpmyadmin

Lá você poderá:

  • criar bancos
  • criar tabelas
  • inserir dados
  • executar comandos SQL

9. Conectando ao banco

Crie um arquivo chamado

conexao.php
<?php

$host = "localhost";
$user = "root";
$password = "";
$database = "ghostware";

$conexao = new mysqli($host, $user, $password, $database);

if ($conexao->connect_error) {
    die("Erro: " . $conexao->connect_error);
}

No XAMPP, o usuário padrão é:

Usuário:
root

Senha:
(vazia)

10. Importando arquivos

Sempre utilize:

include "includes/header.php";

ou

require "includes/header.php";

Isso evita repetir código.

11. Organização do projeto

Evite colocar tudo em um único arquivo.

Por exemplo:

index.php

↓

header.php

↓

footer.php

↓

menu.php

↓

conexao.php

Cada arquivo deve ter apenas uma responsabilidade.

12. URLs

Se sua pasta chama

ghostware

Você acessará:

localhost/ghostware

Se houver uma pasta:

pages/login.php

A URL será:

localhost/ghostware/pages/login.php

13. Arquivos estáticos

CSS:

<link rel="stylesheet" href="css/style.css">

JavaScript:

<script src="js/script.js"></script>

Imagem:

<img src="img/logo.png">

14. Fluxo de desenvolvimento

O ciclo típico é:

  1. Iniciar Apache e MySQL no XAMPP.
  1. Criar o projeto em htdocs.
  1. Desenvolver páginas HTML, CSS e JavaScript.
  1. Adicionar lógica em PHP.
  1. Criar o banco de dados no phpMyAdmin.
  1. Conectar a aplicação ao banco com mysqli ou PDO.
  1. Testar tudo acessando http://localhost/nome-do-projeto.

Estrutura profissional (MVC)

À medida que seus projetos crescerem, vale a pena adotar uma estrutura inspirada em MVC:

ghostware/
│
├── app/
│   ├── Controllers/
│   ├── Models/
│   ├── Views/
│
├── config/
│
├── database/
│
├── public/
│   ├── css/
│   ├── js/
│   ├── img/
│   └── index.php
│
├── routes/
│
└── vendor/

Essa organização facilita a manutenção e é semelhante à utilizada por frameworks como Laravel.

Como você está aprendendo, recomendo começar com uma estrutura simples (css, js, img, includes e index.php) e, conforme ganhar experiência, evoluir para uma arquitetura MVC. Isso torna a transição para projetos maiores muito mais natural.
