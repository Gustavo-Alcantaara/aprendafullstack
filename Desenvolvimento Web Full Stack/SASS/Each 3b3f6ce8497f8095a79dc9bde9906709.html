Each

Estrutura de Repetição @each no SASS

O que é o @each?

O @each é uma estrutura de repetição (loop) do SASS utilizada para percorrer listas (Lists) e mapas (Maps), executando um bloco de código para cada elemento encontrado.

Enquanto o @for trabalha com uma sequência numérica e o @while depende de uma condição, o @each percorre coleções de dados.

É uma das estruturas mais utilizadas em projetos profissionais, pois permite gerar automaticamente diversas classes CSS a partir de listas de cores, tamanhos, espaçamentos, ícones e outras coleções.

Objetivos do @each

O @each é utilizado para:

  • Percorrer listas.
  • Percorrer mapas (Maps).
  • Gerar classes automaticamente.
  • Reduzir repetição de código.
  • Facilitar manutenção.
  • Automatizar componentes.
  • Criar sistemas de temas.
  • Organizar melhor os estilos.

Como funciona?

O funcionamento é simples:

  1. Cria-se uma lista ou mapa.
  1. O @each percorre cada item.
  1. Em cada repetição, a variável recebe um valor diferente.
  1. O bloco é executado.
  1. Ao final da coleção, o laço termina.

Fluxo:

Lista ou Mapa
      ↓
Primeiro elemento
      ↓
Executa código
      ↓
Próximo elemento
      ↓
Executa código
      ↓
Último elemento
      ↓
Fim

Sintaxe para listas

@each $variavel in lista{

}

Exemplo:

$cores: red, blue, green;

@each $cor in $cores{

}

A variável $cor receberá:

red
blue
green

Primeiro exemplo

SCSS

$cores: red, blue, green;

@each $cor in $cores{

    .texto-#{$cor}{

        color:$cor;

    }

}

CSS gerado

.texto-red{

    color:red;

}

.texto-blue{

    color:blue;

}

.texto-green{

    color:green;

}

Observe como o @each criou automaticamente três classes.

Trabalhando com listas

Uma lista pode conter diversos tipos de dados.

$tamanhos: 12px, 16px, 20px;

Percorrendo:

@each $tamanho in $tamanhos{

    .fonte-#{$tamanho}{

        font-size:$tamanho;

    }

}

Resultado:

.fonte-12px{

    font-size:12px;

}

.fonte-16px{

    font-size:16px;

}

.fonte-20px{

    font-size:20px;

}

Trabalhando com Maps

Além das listas, o @each pode percorrer Maps, que funcionam como pares de chave e valor.

Exemplo:

$cores:(
    primary:blue,
    success:green,
    danger:red
);

Nesse mapa:

  • primary é a chave.
  • blue é o valor.

Sintaxe para Maps

@each $chave,$valor in mapa{

}

Exemplo

$cores:(

    primary:blue,

    success:green,

    danger:red

);

@each $nome,$cor in $cores{

    .btn-#{$nome}{

        background:$cor;

    }

}

Resultado:

.btn-primary{

    background:blue;

}

.btn-success{

    background:green;

}

.btn-danger{

    background:red;

}

Esse padrão é muito utilizado em frameworks CSS.

Exemplo completo com botões

$cores:(

    primary:#0d6efd,

    success:#198754,

    warning:#ffc107,

    danger:#dc3545

);

@each $tipo,$cor in $cores{

    .btn-#{$tipo}{

        background:$cor;
        color:white;
        padding:10px;
        border-radius:5px;

    }

}

Resultado:

.btn-primary{

    background:#0d6efd;

}

.btn-success{

    background:#198754;

}

.btn-warning{

    background:#ffc107;

}

.btn-danger{

    background:#dc3545;

}

Utilizando com Interpolação

O @each quase sempre é utilizado junto com a interpolação.

$cores:red,blue,green;

@each $cor in $cores{

    .texto-#{$cor}{

        color:$cor;

    }

}

Sem a interpolação (#{}), não seria possível gerar dinamicamente o nome da classe.

Utilizando dentro de Mixins

@mixin gerarBotoes($cores){

    @each $nome,$cor in $cores{

        .btn-#{$nome}{

            background:$cor;

        }

    }

}

Utilização:

$cores:(

    info:cyan,

    dark:black

);

@include gerarBotoes($cores);

Resultado:

.btn-info{

    background:cyan;

}

.btn-dark{

    background:black;

}

Comparação entre @for, @while e @each

EstruturaUtilização
@forRepetições numéricas conhecidas.
@whileRepetições condicionais.
@eachPercorrer listas e mapas.

Quando utilizar @each?

Utilize quando precisar percorrer:

  • Listas de cores.
  • Fontes.
  • Espaçamentos.
  • Ícones.
  • Temas.
  • Breakpoints.
  • Mapas.
  • Componentes.
  • Conjuntos de configurações.

Boas práticas

  • Utilize Maps quando houver relação entre chave e valor.
  • Utilize listas simples quando apenas os valores forem necessários.
  • Combine o @each com a interpolação (#{}).
  • Utilize nomes descritivos para as variáveis.
  • Organize listas e mapas em arquivos específicos, como _variables.scss.

Vantagens

  • Código limpo.
  • Redução de repetição.
  • Fácil manutenção.
  • Excelente para Design Systems.
  • Automatiza componentes.
  • Funciona perfeitamente com Maps.
  • Muito utilizado em frameworks modernos.

Desvantagens

  • Não é indicado para contagens numéricas; nesse caso, prefira o @for.
  • Listas e mapas muito grandes podem gerar um CSS compilado maior.
  • Um uso excessivo pode dificultar a leitura do código.

Casos de uso

O @each é muito utilizado para gerar:

  • Botões.
  • Alertas.
  • Temas.
  • Cores.
  • Tipografia.
  • Espaçamentos.
  • Ícones.
  • Classes utilitárias.
  • Componentes reutilizáveis.
  • Design Systems.

Resumo

O @each é uma estrutura de repetição do SASS utilizada para percorrer listas (Lists) e mapas (Maps), executando um bloco de código para cada elemento da coleção. É especialmente útil para gerar automaticamente classes CSS, como botões, temas, ícones e utilitários, reduzindo a repetição de código e facilitando a manutenção. Em conjunto com interpolação (#{}), variáveis e mixins, o @each permite criar estilos reutilizáveis e escaláveis, sendo uma das estruturas de repetição mais utilizadas em projetos modernos desenvolvidos com SASS.
