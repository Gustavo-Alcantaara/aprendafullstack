Variáveis

Variáveis no SASS

O que são Variáveis?

As variáveis são um dos recursos mais importantes do SASS. Elas permitem armazenar valores que podem ser reutilizados em diferentes partes do código, evitando repetição e facilitando a manutenção dos estilos.

Em vez de escrever o mesmo valor várias vezes, você o armazena em uma variável e utiliza essa variável sempre que necessário.

No SASS, toda variável começa com o símbolo $.

Exemplo:

$cor-principal: #3498db;

Nesse exemplo, a variável $cor-principal armazena a cor #3498db.

Objetivos das Variáveis

As variáveis têm como principais objetivos:

  • Evitar repetição de código.
  • Centralizar valores importantes.
  • Facilitar alterações no projeto.
  • Tornar o código mais organizado.
  • Melhorar a manutenção dos estilos.
  • Padronizar o design da aplicação.

Como funcionam?

Durante a compilação, o SASS substitui cada variável pelo seu valor correspondente.

SCSS

$cor-principal: blue;

body{
    background: $cor-principal;
}

CSS gerado

body{
    background: blue;
}

O navegador nunca vê a variável; ele recebe apenas o valor já substituído.

Sintaxe

A declaração de uma variável segue o formato:

$nome-da-variavel: valor;

Exemplos:

$cor: red;
$fonte: Arial;
$tamanho: 20px;

Regras para nomes de variáveis

Boas práticas para nomeação:

  • Utilize nomes descritivos.
  • Separe palavras com hífen ().
  • Evite nomes genéricos.
  • Não utilize espaços.

Correto

$cor-principal: blue;
$tamanho-fonte: 18px;
$cor-botao: green;

Evite

$c: blue;
$x: 20px;

Nomes claros tornam o código mais fácil de entender.

Armazenando diferentes tipos de valores

Uma variável pode armazenar diversos tipos de dados.

Cores

$cor-principal: royalblue;
$cor-texto: #333;
$cor-fundo: rgb(240,240,240);

Tamanhos

$largura: 1200px;
$altura: 300px;

Fontes

$fonte-principal: Arial;
$fonte-titulo: "Poppins";

Espaçamentos

$padding: 20px;
$margin: 15px;

Bordas

$borda: 1px solid black;

Sombras

$sombra: 0 0 10px rgba(0,0,0,.3);

Utilizando variáveis

Depois de declarar uma variável, ela pode ser utilizada em qualquer propriedade.

$cor: blue;

h1{

    color: $cor;

}

button{

    background: $cor;

}

Resultado:

h1{

    color: blue;

}

button{

    background: blue;

}

Exemplo prático

Sem variáveis:

h1{

    color:#0d6efd;

}

button{

    background:#0d6efd;

}

.menu{

    border-color:#0d6efd;

}

Se a cor mudar, será necessário alterar todas as ocorrências.

Com variáveis:

$azul: #0d6efd;

h1{

    color:$azul;

}

button{

    background:$azul;

}

.menu{

    border-color:$azul;

}

Agora basta alterar:

$azul: red;

Todo o projeto será atualizado após a compilação.

Variáveis em cálculos

As variáveis podem ser utilizadas em operações matemáticas.

$largura: 200px;

.card{

    width: $largura * 2;

}

Resultado:

.card{

    width:400px;

}

Outro exemplo:

$padding:10px;

.container{

    padding:$padding * 3;

}

Resultado:

.container{

    padding:30px;

}

Variáveis em strings

Também podem armazenar textos.

$fonte: "Roboto";

body{

    font-family:$fonte;

}

Resultado:

body{

    font-family:"Roboto";

}

Variáveis booleanas

O SASS aceita valores booleanos.

$modoEscuro: true;

São utilizadas principalmente em estruturas condicionais (@if).

Variáveis nulas

$cor: null;

O valor null representa ausência de valor e pode ser útil em lógicas condicionais.

Escopo das variáveis

Assim como em linguagens de programação, as variáveis possuem escopo.

Variável global

$cor: blue;

body{

    color:$cor;

}

h1{

    color:$cor;

}

Pode ser utilizada em todo o arquivo (ou módulo, dependendo do uso de @use).

Variável local

.card{

    $cor:red;

    color:$cor;

}

A variável existe apenas dentro do bloco .card.

Organização das variáveis

Em projetos profissionais, é comum centralizar todas as variáveis em um arquivo específico.

Exemplo:

scss/

_variables.scss

_buttons.scss

_header.scss

_footer.scss

style.scss

Arquivo de variáveis

$cor-principal:#0d6efd;
$cor-secundaria:#6610f2;
$cor-texto:#333;

$fonte-principal:"Arial";

$padding:20px;

Utilizando as variáveis

@use "variables";

body{

    color:variables.$cor-texto;

}

Essa organização facilita a manutenção do projeto.

Alterando temas

As variáveis permitem criar temas facilmente.

Tema claro:

$background:white;
$text:black;

Tema escuro:

$background:#222;
$text:white;

Depois:

body{

    background:$background;

    color:$text;

}

Basta alterar os valores das variáveis para mudar a aparência da aplicação.

Variáveis e Mixins

As variáveis podem ser utilizadas dentro de mixins.

$cor:white;

@mixin botao{

    color:$cor;

    padding:10px;

}

button{

    @include botao;

}

Variáveis e Funções

Também podem ser passadas como parâmetros.

$cor:red;

.box{

    background: lighten($cor,20%);

}

Boas práticas

  • Utilize nomes claros e descritivos.
  • Centralize variáveis em um arquivo (_variables.scss).
  • Agrupe variáveis por categoria (cores, fontes, espaçamentos etc.).
  • Evite criar variáveis para valores usados apenas uma vez.
  • Utilize variáveis para todos os valores reutilizados.
  • Padronize a nomenclatura em todo o projeto.

Vantagens

  • Reduzem a repetição de código.
  • Facilitam alterações globais.
  • Melhoram a organização.
  • Tornam o código mais legível.
  • Favorecem a criação de temas.
  • Aumentam a produtividade.
  • Facilitam o trabalho em equipe.

Desvantagens

  • Exigem uma boa organização para evitar excesso de variáveis.
  • Nomes mal escolhidos podem dificultar a compreensão do código.
  • Em projetos muito pequenos, podem ser desnecessárias.

Comparação entre CSS e SASS

CSS moderno

O CSS atual também possui variáveis (chamadas de Custom Properties).

:root{

    --cor-principal: blue;

}

button{

    background: var(--cor-principal);

}

Essas variáveis existem no navegador e podem ser alteradas em tempo de execução com JavaScript.

SASS

$cor-principal: blue;

button{

    background: $cor-principal;

}

As variáveis do SASS são resolvidas durante a compilação, antes de o CSS chegar ao navegador.

Diferenças principais

Variáveis do SASSVariáveis do CSS
Compiladas antes da execuçãoInterpretadas pelo navegador
Não existem no CSS finalPermanecem disponíveis no CSS
Não podem ser alteradas via JavaScriptPodem ser alteradas dinamicamente
Ideais para organização do códigoIdeais para temas dinâmicos e personalização

Em muitos projetos modernos, é comum utilizar SASS e variáveis CSS juntos, aproveitando as vantagens de cada abordagem.

Casos de uso

As variáveis são ideais para armazenar:

  • Cores da identidade visual.
  • Fontes.
  • Tamanhos de texto.
  • Espaçamentos.
  • Bordas.
  • Sombras.
  • Larguras e alturas padrão.
  • Breakpoints para responsividade.
  • Temas (claro e escuro).
  • Valores reutilizados em componentes.

Resumo

As variáveis no SASS permitem armazenar valores reutilizáveis, como cores, fontes, tamanhos e espaçamentos, utilizando a sintaxe $nome-da-variavel. Durante a compilação, o SASS substitui essas variáveis pelos seus valores, gerando um CSS comum. Elas reduzem a repetição de código, facilitam alterações globais, melhoram a organização dos estilos e tornam a manutenção muito mais simples. Em projetos profissionais, é recomendado centralizar as variáveis em um arquivo específico, como _variables.scss, e importá-lo nos demais módulos usando @use. Esse recurso é um dos pilares do SASS e contribui significativamente para a criação de estilos escaláveis e fáceis de manter.
