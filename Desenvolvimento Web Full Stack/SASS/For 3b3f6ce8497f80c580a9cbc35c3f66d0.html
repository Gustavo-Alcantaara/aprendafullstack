For

Estrutura de Repetição @for no SASS

O que é o @for?

O @for é uma estrutura de repetição (loop) do SASS que permite executar um bloco de código várias vezes, alterando automaticamente o valor de uma variável de controle a cada repetição.

Seu principal objetivo é gerar CSS automaticamente, evitando escrever várias regras semelhantes manualmente.

Imagine que você precisa criar 12 classes para um sistema de colunas (.col-1, .col-2, ..., .col-12). Em vez de escrever cada classe separadamente, você pode utilizar o @for para gerar todas elas automaticamente.

Objetivos do @for

O @for é utilizado para:

  • Evitar repetição de código.
  • Gerar classes automaticamente.
  • Criar sistemas de grid.
  • Produzir espaçamentos padronizados.
  • Gerar tamanhos, larguras e alturas sequenciais.
  • Aumentar a produtividade.
  • Facilitar a manutenção do projeto.

Como funciona?

O @for funciona de maneira semelhante aos laços for encontrados em linguagens como PHP, JavaScript, Java e C.

Durante a compilação, o SASS executa o bloco de código repetidas vezes e gera o CSS correspondente.

Fluxo:

Início
   ↓
Define valor inicial
   ↓
Executa o bloco
   ↓
Incrementa variável
   ↓
Ainda está no intervalo?
   ↓
Sim → repete
Não → encerra

Sintaxe

Existem duas formas de utilizar o @for.

Utilizando through

@for $variavel from valorInicial through valorFinal{

}

O through inclui o valor final.

Exemplo:

@for $i from 1 through 5{

    .numero-#{$i}{
        width: 100px;
    }

}

O laço executará:

1
2
3
4
5

Utilizando to

@for $variavel from valorInicial to valorFinal{

}

O to não inclui o valor final.

Exemplo:

@for $i from 1 to 5{

}

Executará:

1
2
3
4

O número 5 não será utilizado.

Diferença entre through e to

Through

@for $i from 1 through 3{

}

Executa:

1
2
3

To

@for $i from 1 to 3{

}

Executa:

1
2

Resumo:

PalavraInclui o último valor?
throughSim
toNão

Exemplo básico

@for $i from 1 through 3{

    .caixa-#{$i}{

        width:100px;

    }

}

CSS gerado:

.caixa-1{

    width:100px;

}

.caixa-2{

    width:100px;

}

.caixa-3{

    width:100px;

Criando um sistema de Grid

Um dos usos mais comuns do @for é gerar colunas.

@for $i from 1 through 12{

    .col-#{$i}{

        width: calc(100% / 12 * #{$i});

    }

}

Resultado simplificado:

.col-1{
    width:8.333%;
}

.col-2{
    width:16.666%;
}

...

.col-12{
    width:100%;
}

Esse conceito é utilizado em frameworks como Bootstrap.

Utilizando variáveis

$espaco:10px;

@for $i from 1 through 5{

    .margin-#{$i}{

        margin:$espaco * $i;

    }

}

Resultado:

.margin-1{
    margin:10px;
}

.margin-2{
    margin:20px;
}

.margin-3{
    margin:30px;
}

.margin-4{
    margin:40px;
}

.margin-5{
    margin:50px;
}

Utilizando dentro de Mixins

@mixin gerarColunas($quantidade){

    @for $i from 1 through $quantidade{

        .col-#{$i}{

            width: calc(100% / #{$quantidade} * #{$i});

        }

    }

}

@include gerarColunas(4);

Resultado:

.col-1{
    width:25%;
}

.col-2{
    width:50%;
}

.col-3{
    width:75%;
}

.col-4{
    width:100%;
}

Utilizando com Interpolação

O @for praticamente sempre é utilizado com interpolação.

    font-size:4px;
}

.texto-2{
    font-size:8px;
}

.texto-3{
    font-size:12px;
}

.texto-4{
    font-size:16px;
}

.texto-5{
    font-size:20px;

Casos de uso

O @for é muito utilizado para criar:

  • Sistemas de grid.
  • Classes utilitárias.
  • Espaçamentos.
  • Margens.
  • Paddings.
  • Tamanhos de fonte.
  • Larguras.
  • Alturas.
  • Bordas.
  • Opacidades.
  • Componentes repetitivos.

Boas práticas

  • Utilize o @for apenas quando houver repetição de padrões.
  • Combine o @for com a interpolação (#{}) para gerar nomes de classes.
  • Evite gerar centenas de classes que não serão utilizadas.
  • Prefira nomes de classes claros e padronizados.
  • Utilize variáveis para facilitar futuras alterações.

Vantagens

  • Elimina repetição de código.
  • Automatiza a criação de classes.
  • Facilita manutenção.
  • Gera CSS de forma rápida.
  • Melhora a produtividade.
  • Excelente para Design Systems.
  • Ideal para frameworks CSS.

Desvantagens

  • Pode gerar arquivos CSS muito grandes se usado em excesso.
  • Classes desnecessárias aumentam o tamanho do CSS final.
  • Exige planejamento para evitar geração de código que nunca será utilizado.

Comparação com outros laços

Resumo

O @for é uma estrutura de repetição do SASS utilizada para executar um bloco de código um número determinado de vezes, gerando CSS automaticamente. Ele possui duas variações: through, que inclui o valor final da sequência, e to, que o exclui. Combinado com interpolação (#{}), variáveis e mixins, o @for é amplamente utilizado para criar classes utilitárias, sistemas de grid, espaçamentos e componentes repetitivos, reduzindo a duplicação de código e tornando os estilos mais organizados, escaláveis e fáceis de manter.
