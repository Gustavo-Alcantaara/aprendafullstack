Funções no SASS

O que são Funções?

As funções (Functions) no SASS são blocos de código que recebem valores (parâmetros), realizam um processamento e retornam um resultado.

Seu principal objetivo é evitar repetição de cálculos, reutilizar lógica e tornar o código mais organizado.

Diferentemente dos Mixins, que retornam um conjunto de propriedades CSS, as funções retornam apenas um valor, que pode ser utilizado em qualquer propriedade CSS.

Objetivos das Funções

As funções são utilizadas para:

  • Reutilizar cálculos.
  • Evitar repetição de código.
  • Automatizar operações matemáticas.
  • Manipular cores.
  • Trabalhar com medidas.
  • Padronizar valores.
  • Melhorar a organização do projeto.

Como funcionam?

O funcionamento de uma função ocorre em três etapas:

  1. A função é declarada.
  1. Ela recebe um ou mais parâmetros.
  1. Processa esses parâmetros.
  1. Retorna um valor utilizando @return.

Fluxo:

Recebe parâmetros
        ↓
Executa cálculos
        ↓
Retorna um valor
        ↓
Valor utilizado no CSS

Sintaxe

A estrutura básica é:

@function nome-da-funcao($parametro){

    @return valor;

}

Exemplo simples:

@function dobro($valor){

    @return $valor * 2;

}

Utilização:

.box{

    width: dobro(100px);

}

Resultado:

.box{

    width:200px;

}

Criando a primeira função

SCSS

@function metade($valor){

    @return $valor / 2;

}

.card{

    width: metade(400px);

}

CSS gerado

.card{

    width:200px;

}

Funções com vários parâmetros

Uma função pode receber diversos parâmetros.

@function soma($a,$b){

    @return $a+$b;

}

Utilização:

.container{

    width:soma(100px,50px);

}

Resultado:

.container{

    width:150px;

}

Parâmetros com valores padrão

Também é possível definir valores padrão.

@function aumentar($valor,$incremento:10px){

    @return $valor+$incremento;

}

Uso:

.box{

    width:aumentar(100px);

}

Resultado:

.box{

    width:110px;

}

Se desejar outro incremento:

.box{

    width:aumentar(100px,30px);

}

Resultado:

.box{

    width:130px;

}

Funções com cálculos

Um dos usos mais comuns.

@function porcentagem($valor,$total){

    @return ($valor/$total)*100%;

}

Uso:

.coluna{

    width:porcentagem(3,12);

}

Resultado:

.coluna{

    width:25%;

}

Criando um sistema de Grid

@function coluna($numero){

    @return calc(100% / 12 * #{$numero});

}

Uso:

.col-3{

    width:coluna(3);

}

Resultado:

.col-3{

    width:calc(100% / 12 * 3);

}

Funções com Strings

Também podem retornar textos.

@function caminho($arquivo){

    @return "img/" + $arquivo;

}

Uso:

header{

    background-image:url(caminho("banner.jpg"));

}

Resultado:

header{

    background-image:url("img/banner.jpg");

}

Funções com Cores

@function corTema(){

    @return #3498db;

}

Uso:

button{

    background:corTema();

}

Resultado:

button{

    background:#3498db;

}

Funções com Condições

Funções podem utilizar estruturas condicionais.

@function tema($modo){

    @if $modo == claro{

        @return white;

    }

    @else{

        @return black;

    }

}

Uso:

body{

    background:tema(claro);

}

Resultado:

body{

    background:white;

}

Funções com Operadores

@function area($largura,$altura){

    @return $largura * $altura;

}

Uso:

.box{

    width:area(20px,5);

}

Resultado:

.box{

    width:100px;

}

Funções e Variáveis

$base:10px;

@function espacamento($multiplicador){

    @return $base * $multiplicador;

}

Uso:

.card{

    padding:espacamento(3);

}

Resultado:

.card{

    padding:30px;

}

Funções e Maps

É possível criar funções que recuperam valores de um mapa.

$cores:(

    primary:#0d6efd,

    success:#198754,

    danger:#dc3545

);

@function cor($nome){

    @return map-get($cores,$nome);

}

Uso:

button{

    background:cor(primary);

}

Resultado:

button{

    background:#0d6efd;

}
Observação: Nas versões mais recentes do SASS, a função global map-get() foi substituída pela função map.get() do módulo sass:map. Exemplo:
@use "sass:map";

@return map.get($cores, $nome);

Funções Nativas do SASS

O SASS já possui diversas funções prontas.

Manipulação de cores

lighten($cor,20%)

Clareia uma cor.

darken($cor,20%)

Escurece uma cor.

mix(red,blue)

Mistura duas cores.

rgba(red,.5)

Cria uma cor com transparência.

abs(-20)

Resultado:

20

Resultado:

3

Resultado:

3

Resultado:

Strings

to-upper-case("sass")

Resultado:

"SASS"
to-lower-case("CSS")

Listas

Retorna o número de elementos.

Maps

Retorna um valor.

Como mencionado anteriormente, a forma recomendada atualmente é:

@use "sass:map";

map.get($map, chave)

Funções x Mixins

Muitas pessoas confundem esses dois recursos.

Função

Retorna um valor.

@function dobro($n){

    @return $n*2;

}

Uso:

width:dobro(100px);

Mixin

Retorna um conjunto de propriedades.

@mixin botao{

    padding:10px;
    color:white;

}

Uso:

@include botao;

Diferença entre Função e Mixin

FunçãoMixin
Retorna um valorInsere um bloco de propriedades
Usa @returnUsa @include
Ideal para cálculosIdeal para reutilizar estilos
Pode ser utilizada em qualquer propriedadeGera CSS diretamente

Casos de uso

As funções são utilizadas para:

  • Cálculos matemáticos.
  • Sistemas de grid.
  • Espaçamentos.
  • Conversão de unidades.
  • Recuperação de valores de mapas.
  • Manipulação de cores.
  • Temas.
  • Design Systems.
  • Tipografia.
  • Layouts responsivos.

Boas práticas

  • Crie funções apenas quando houver reutilização de lógica.
  • Utilize nomes claros e objetivos.
  • Evite funções muito longas ou complexas.
  • Centralize funções em um arquivo como _functions.scss.
  • Prefira utilizar funções nativas sempre que possível.
  • Mantenha uma única responsabilidade por função.

Vantagens

  • Redução de repetição.
  • Código mais limpo.
  • Reutilização de lógica.
  • Facilita manutenção.
  • Organização do projeto.
  • Automatiza cálculos.
  • Excelente para Design Systems.

Desvantagens

  • Pode aumentar a complexidade se utilizada em excesso.
  • Funções muito grandes dificultam a leitura.
  • Algumas funções nativas podem ser suficientes, tornando funções personalizadas desnecessárias.

Estrutura recomendada

scss/
│
├── abstracts/
│   ├── _variables.scss
│   ├── _functions.scss
│   ├── _mixins.scss
│
├── components/
│
├── layout/
│
└── style.scss

Todas as funções ficam concentradas em _functions.scss.

Exemplo completo

_functions.scss

@function espacamento($nivel){

    @return $nivel * 8px;

}

style.scss

@use "functions";

.card{

    padding:functions.espacamento(3);

    margin:functions.espacamento(2);

}

CSS gerado

.card{

    padding:24px;

    margin:16px;

}

Resumo

As funções no SASS permitem criar rotinas reutilizáveis que recebem parâmetros, executam cálculos ou processamentos e retornam um único valor por meio da diretiva @return. Elas são ideais para cálculos matemáticos, manipulação de cores, recuperação de valores de mapas, conversão de unidades e padronização de valores em projetos grandes. Diferentemente dos Mixins, que inserem blocos de propriedades CSS, as funções retornam apenas um valor que pode ser utilizado em qualquer propriedade. Combinadas com variáveis, mapas e funções nativas do SASS, elas tornam o código mais organizado, reutilizável e fácil de manter.
