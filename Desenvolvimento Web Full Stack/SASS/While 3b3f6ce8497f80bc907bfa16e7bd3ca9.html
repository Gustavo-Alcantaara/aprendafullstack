Estrutura de Repetição @while no SASS

O que é o @while?

O @while é uma estrutura de repetição (loop) do SASS que executa um bloco de código enquanto uma condição for verdadeira.

Diferentemente do @for, no qual o número de repetições é conhecido desde o início, o @while continua executando até que a condição especificada se torne falsa.

Esse recurso é útil quando a quantidade de repetições depende de uma condição e não de um número fixo.

Objetivos do @while

O @while é utilizado para:

  • Executar repetições baseadas em condições.
  • Automatizar a geração de CSS.
  • Evitar repetição de código.
  • Criar classes sequenciais.
  • Realizar cálculos progressivos.
  • Gerar estilos dinâmicos.

Como funciona?

O funcionamento do @while segue a seguinte lógica:

  1. Define-se uma variável de controle.
  1. O SASS verifica se a condição é verdadeira.
  1. Se for verdadeira, executa o bloco de código.
  1. Atualiza a variável de controle.
  1. Volta ao início e verifica novamente a condição.
  1. Quando a condição se torna falsa, o laço termina.

Fluxo:

Inicializa variável
        ↓
Verifica condição
        ↓
Condição verdadeira?
     ↓         ↓
   Sim        Não
    ↓          ↓
Executa      Encerra
bloco
    ↓
Atualiza variável
    ↓
Volta para a condição

Sintaxe

A estrutura básica é:

@while condição{

}

Normalmente utiliza-se uma variável de controle.

Exemplo:

$i:1;

@while $i <= 5{

    .item-#{$i}{

        width:100px;

    }

    $i:$i+1;

}

Exemplo básico

SCSS

$i:1;

@while $i <= 3{

    .caixa-#{$i}{

        background:blue;

    }

    $i:$i+1;

}

CSS gerado

.caixa-1{

    background:blue;

}

.caixa-2{

    background:blue;

}

.caixa-3{

    background:blue;

}

Observe que o valor de $i é incrementado ao final de cada repetição.

Importância do incremento

O incremento da variável é essencial.

Exemplo correto:

$i:1;

@while $i <= 5{

    .teste-#{$i}{
        color:red;
    }

    $i:$i+1;

}

Sem o incremento:

$i:1;

@while $i <= 5{

    .teste{

        color:red;

    }

}

Nesse caso, a condição nunca deixará de ser verdadeira, gerando um loop infinito. O compilador do SASS detecta esse problema e interrompe a compilação com um erro.

Utilizando em Mixins

@mixin gerarClasses($quantidade){

    $i:1;

    @while $i <= $quantidade{

        .col-#{$i}{

        $i:$i+1;

    }

@include gerarClasses(4);

Comparação entre @for e @while

@for

@for $i from 1 through 5{

}

Utilizado quando o número de repetições é conhecido.

@while

$i:1;

@while $i<=5{

    $i:$i+1;

}

Utilizado quando a repetição depende de uma condição.

Quando utilizar o @while?

O @while é recomendado quando:

  • A quantidade de repetições não é fixa.
  • O encerramento depende de uma condição.
  • O valor de controle pode variar durante a execução.
  • É necessário realizar cálculos progressivos.

Quando a quantidade de repetições é conhecida previamente, normalmente o @for é mais simples e legível.

Casos de uso

O @while pode ser utilizado para gerar:

  • Classes utilitárias.
  • Sistemas de grid.
  • Espaçamentos.
  • Fontes.
  • Tamanhos.
  • Larguras.
  • Alturas.
  • Opacidades.
  • Sistemas responsivos.
  • Componentes personalizados.

Boas práticas

  • Sempre atualize a variável de controle dentro do laço.
  • Certifique-se de que a condição se tornará falsa em algum momento.
  • Utilize nomes de variáveis claros.
  • Evite laços muito longos que gerem CSS desnecessário.
  • Prefira o @for quando o número de repetições já for conhecido.

Vantagens

  • Grande flexibilidade.
  • Permite criar repetições baseadas em condições.
  • Automatiza a geração de CSS.
  • Reduz a duplicação de código.
  • Pode trabalhar com incrementos e decrementos.
  • Facilita cálculos progressivos.

Desvantagens

  • Mais fácil de cometer erros de lógica.
  • Pode gerar loops infinitos se a variável de controle não for atualizada.
  • Em muitos casos, o @for oferece uma solução mais simples e legível.

Resumo

O @while é uma estrutura de repetição do SASS que executa um bloco de código enquanto uma condição permanecer verdadeira. Diferentemente do @for, ele não exige que o número de repetições seja conhecido antecipadamente, sendo ideal para situações em que a repetição depende de uma condição lógica. Seu uso requer atenção especial à atualização da variável de controle para evitar loops infinitos. Combinado com interpolação (#{}), variáveis e mixins, o @while permite gerar CSS de forma dinâmica, automatizando tarefas repetitivas e tornando os estilos mais flexíveis e organizados.
