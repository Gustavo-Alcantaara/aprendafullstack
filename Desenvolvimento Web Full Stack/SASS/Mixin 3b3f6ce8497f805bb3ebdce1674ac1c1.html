Mixin

Mixins no SASS

O que são Mixins?

Os Mixins são um dos recursos mais poderosos do SASS. Eles permitem agrupar um conjunto de propriedades CSS em um bloco reutilizável, que pode ser inserido em qualquer parte do projeto.

Em outras palavras, um mixin funciona como uma "receita de estilos": você define um conjunto de propriedades uma única vez e o reutiliza sempre que precisar.

Os Mixins ajudam a eliminar a repetição de código, tornando os estilos mais organizados, reutilizáveis e fáceis de manter.

Objetivos dos Mixins

Os Mixins são utilizados para:

  • Reutilizar blocos de estilos.
  • Evitar repetição de código.
  • Facilitar manutenção.
  • Criar componentes reutilizáveis.
  • Automatizar estilos.
  • Receber parâmetros para personalização.
  • Melhorar a organização do projeto.

Como funcionam?

O funcionamento de um Mixin ocorre em três etapas:

  1. O Mixin é criado utilizando @mixin.
  1. Sempre que necessário, ele é chamado utilizando @include.
  1. Durante a compilação, o SASS substitui a chamada pelo conjunto de propriedades definido no Mixin.

Fluxo:

Cria o Mixin
      ↓
Chama com @include
      ↓
SASS copia os estilos
      ↓
CSS gerado

Sintaxe

A estrutura básica é:

@mixin nome{

}

Para utilizá-lo:

@include nome;

Primeiro exemplo

SCSS

@mixin botao{

    padding:10px;
    background:blue;
    color:white;
    border:none;
    border-radius:5px;

}

button{

    @include botao;

}

CSS gerado

button{

    padding:10px;
    background:blue;
    color:white;
    border:none;
    border-radius:5px;

}

Todo o conteúdo do mixin foi inserido dentro do seletor button.

Reutilizando um Mixin

O mesmo mixin pode ser utilizado em vários elementos.

@mixin sombra{

    box-shadow:0 0 10px rgba(0,0,0,.3);

}

.card{

    @include sombra;

}

.modal{

    @include sombra;

}

Resultado:

.card{

    box-shadow:0 0 10px rgba(0,0,0,.3);

}

.modal{

    box-shadow:0 0 10px rgba(0,0,0,.3);

}

Mixins com parâmetros

Assim como funções, os Mixins podem receber parâmetros.

@mixin tamanho($largura,$altura){

    width:$largura;
    height:$altura;

}

Uso:

.box{

    @include tamanho(200px,100px);

}

Resultado:

.box{

    width:200px;
    height:100px;

}

Parâmetros com valores padrão

Também é possível definir valores padrão.

@mixin botao($cor:blue){

    background:$cor;
    color:white;

}

Uso:

button{

    @include botao;

}

Resultado:

button{

    background:blue;
    color:white;

}

Passando outro valor:

button{

    @include botao(red);

}

Resultado:

button{

    background:red;
    color:white;

}

Mixins com vários parâmetros

@mixin caixa($largura,$altura,$cor){

    width:$largura;
    height:$altura;
    background:$cor;

}

Uso:

.card{

    @include caixa(300px,200px,#3498db);

}

Resultado:

.card{

    width:300px;
    height:200px;
    background:#3498db;

}

Mixins com Condições

Os Mixins podem utilizar estruturas condicionais.

@mixin tema($modo){

    @if $modo == claro{

        background:white;
        color:black;

    }

    @else{

        background:black;
        color:white;

    }

}

Uso:

body{

    @include tema(claro);

}

Resultado:

body{

    background:white;
    color:black;

}

Mixins com Laços

Também podem utilizar estruturas de repetição.

@mixin colunas($quantidade){

    @for $i from 1 through $quantidade{

        .col-#{$i}{

            width:calc(100% / $quantidade * #{$i});

        }

    }

}

Uso:

@include colunas(4);

Resultado:

.col-1{
    width:25%;
}

.col-2{
    width:50%;
}

.col-3{
    width:75%;
}

.col-4{
    width:100%;
}

Mixins com Interpolação

Os Mixins podem gerar classes dinamicamente.

@mixin margem($lado,$valor){

    margin-#{$lado}:$valor;

}

Uso:

.box{

    @include margem(left,20px);

}

Resultado:

.box{

    margin-left:20px;

}

Mixins com Variáveis

$cor-principal:#3498db;

@mixin botao{

    background:$cor-principal;
    color:white;

}

Uso:

button{

    @include botao;

}

Resultado:

button{

    background:#3498db;
    color:white;

}

Mixins reutilizando outros Mixins

Um Mixin pode incluir outro.

@mixin borda{

    border:1px solid black;

}

@mixin card{

    @include borda;

    padding:20px;

}

Uso:

.card{

    @include card;

}

Resultado:

.card{

    border:1px solid black;
    padding:20px;

}

Mixins e Media Queries

Uma das aplicações mais comuns é criar Media Queries reutilizáveis.

@mixin mobile{

    @media(max-width:768px){

        @content;

    }

}

Uso:

.menu{

    width:300px;

    @include mobile{

        width:100%;

    }

}

Resultado:

.menu{

    width:300px;

}

@media(max-width:768px){

    .menu{

        width:100%;

    }

}

O que é @content?

A diretiva @content permite que o Mixin receba um bloco de código durante sua utilização.

No exemplo anterior, tudo o que foi escrito dentro de:

@include mobile{

    width:100%;

}

foi inserido no lugar de @content, tornando o Mixin extremamente flexível para criar Media Queries e outros blocos reutilizáveis.

Organização dos Mixins

Em projetos profissionais, é comum armazenar todos os Mixins em um arquivo específico.

scss/

_mixins.scss

_variables.scss

_functions.scss

style.scss

Depois:

@use "mixins";

button{

    @include mixins.botao;

}

Mixins x Funções

Esses dois recursos são frequentemente confundidos.

Função

Retorna um valor.

@function dobro($valor){

    @return $valor*2;

}

Uso:

width:dobro(100px);

Mixin

Retorna um conjunto de propriedades.

@mixin botao{

    padding:10px;
    color:white;

}

Uso:

@include botao;

Diferença entre Mixin e Função

MixinFunção
Gera propriedades CSSRetorna um valor
Utiliza @includeUtiliza @return
Ideal para componentesIdeal para cálculos
Pode conter várias propriedadesRetorna apenas um resultado

Casos de uso

Os Mixins são muito utilizados para criar:

  • Botões.
  • Cards.
  • Formulários.
  • Sombras.
  • Bordas.
  • Espaçamentos.
  • Layouts.
  • Flexbox.
  • Grid.
  • Media Queries.
  • Componentes reutilizáveis.

Boas práticas

  • Utilize Mixins apenas quando houver repetição de blocos de estilos.
  • Dê nomes claros e descritivos.
  • Utilize parâmetros para tornar os Mixins flexíveis.
  • Armazene-os em um arquivo como _mixins.scss.
  • Evite criar Mixins muito grandes ou com muitas responsabilidades.
  • Prefira funções quando o objetivo for apenas retornar um valor.

Vantagens

  • Redução de repetição de código.
  • Reutilização de estilos.
  • Fácil manutenção.
  • Componentes padronizados.
  • Código mais organizado.
  • Excelente para Design Systems.
  • Grande flexibilidade com parâmetros e @content.

Desvantagens

  • O uso excessivo pode gerar CSS compilado maior, já que o conteúdo é copiado para cada @include.
  • Mixins muito complexos podem dificultar a leitura do código.
  • Em alguns casos, classes utilitárias podem ser uma alternativa mais eficiente.

Exemplo completo

SCSS

@mixin botao($cor,$padding:10px){

    background:$cor;
    color:white;
    padding:$padding;
    border:none;
    border-radius:5px;
    cursor:pointer;

}

.btn-primary{

    @include botao(#0d6efd);

}

.btn-success{

    @include botao(#198754,15px);

}

CSS gerado

.btn-primary{

    background:#0d6efd;
    color:white;
    padding:10px;
    border:none;
    border-radius:5px;
    cursor:pointer;

}

.btn-success{

    background:#198754;
    color:white;
    padding:15px;
    border:none;
    border-radius:5px;
    cursor:pointer;

}

Resumo

Os Mixins são um recurso do SASS que permite agrupar e reutilizar conjuntos de propriedades CSS por meio das diretivas @mixin e @include. Eles podem receber parâmetros, utilizar valores padrão, estruturas condicionais, laços de repetição, interpolação e até outros Mixins, tornando o código altamente reutilizável e flexível. Além disso, com a diretiva @content, é possível criar Mixins capazes de receber blocos de código, sendo muito utilizados para Media Queries e componentes personalizados. Em projetos modernos, os Mixins são fundamentais para reduzir a duplicação de código, padronizar estilos e facilitar a manutenção de aplicações desenvolvidas com SASS.
