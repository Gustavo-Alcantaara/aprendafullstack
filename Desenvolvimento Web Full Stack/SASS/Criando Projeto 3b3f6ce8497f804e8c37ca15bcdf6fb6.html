Criando um Projeto com SASS

Introdução

Criar um projeto com SASS (Syntactically Awesome Style Sheets) significa configurar um ambiente de desenvolvimento onde os arquivos de estilo são escritos em SCSS (ou na sintaxe .sass) e posteriormente compilados para CSS, que será interpretado pelos navegadores.

Em projetos pequenos é possível utilizar apenas um arquivo SCSS, mas em projetos profissionais é recomendado organizar os estilos em vários arquivos e pastas, facilitando a manutenção e o trabalho em equipe.

Objetivos de um projeto com SASS

Ao utilizar o SASS em um projeto, busca-se:

  • Organizar melhor os arquivos de estilo.
  • Reduzir a repetição de código.
  • Facilitar a manutenção.
  • Reutilizar estilos através de variáveis e mixins.
  • Criar uma estrutura escalável.
  • Tornar o desenvolvimento mais produtivo.

Pré-requisitos

Antes de criar um projeto com SASS, é necessário ter instalado:

  • Node.js
  • npm (instalado junto com o Node.js)
  • Um editor de código (como o Visual Studio Code)

Verifique se o Node.js está instalado:

node -v

Verifique o npm:

npm -v

Passo 1 – Criar a pasta do projeto

Primeiro, crie uma pasta para armazenar o projeto.

Exemplo:

MeuProjetoSass/

Estrutura inicial:

MeuProjetoSass/

Entre na pasta pelo terminal:

cd MeuProjetoSass

Passo 2 – Inicializar o projeto Node

Execute:

npm init -y

Esse comando cria automaticamente o arquivo:

package.json

Exemplo:

{
  "name": "meuprojetosass",
  "version": "1.0.0"
}

O arquivo package.json controla as dependências e scripts do projeto.

Passo 3 – Instalar o SASS

Instale o SASS como dependência do projeto:

npm install sass

Será criada a pasta:

node_modules/

Além disso, o package.json será atualizado com a dependência.

Passo 4 – Criar a estrutura de pastas

Uma organização comum é:

MeuProjetoSass/
│
├── node_modules/
│
├── css/
│   └── style.css
│
├── scss/
│   ├── style.scss
│   ├── _variables.scss
│   ├── _mixins.scss
│   ├── _header.scss
│   ├── _footer.scss
│   └── _buttons.scss
│
├── index.html
│
└── package.json

Função de cada pasta

  • scss/ → arquivos escritos em SASS.
  • css/ → CSS compilado.
  • node_modules/ → dependências instaladas.
  • index.html → página HTML.
  • package.json → configurações do projeto.

Passo 5 – Criar o arquivo principal

Dentro da pasta scss, crie:

style.scss

Exemplo:

body{
    background: #f5f5f5;
}

Passo 6 – Criar o HTML

<!DOCTYPE html>
<html lang="pt-BR">

<head>

    <meta charset="UTF-8">

    <title>SASS</title>

    <link rel="stylesheet" href="css/style.css">

</head>

<body>

    <h1>Meu primeiro projeto SASS</h1>

</body>

</html>

Observe que o HTML referencia o arquivo CSS, e não o SCSS.

Passo 7 – Compilar o SASS

Execute:

sass scss/style.scss css/style.css

Será criado:

css/style.css

Conteúdo:

body{
    background:#f5f5f5;
}

Agora o navegador consegue interpretar os estilos.

Passo 8 – Compilação automática

Durante o desenvolvimento, é mais prático monitorar as alterações.

Execute:

sass --watch scss:css

Sempre que qualquer arquivo dentro da pasta scss for salvo, o CSS correspondente será atualizado automaticamente.

Fluxo:

Salvar arquivo SCSS
        ↓
Compilador SASS
        ↓
Atualiza CSS
        ↓
Navegador

Organizando o projeto com Partials

Projetos grandes não utilizam apenas um arquivo.

Por exemplo:

scss/

_variables.scss

_header.scss

_footer.scss

_buttons.scss

style.scss

Os arquivos iniciados com _ são chamados de partials.

Eles não são compilados individualmente.

Importando os arquivos

No arquivo principal:

@use "variables";
@use "header";
@use "footer";
@use "buttons";

Assim, todo o projeto é reunido em um único arquivo de entrada (style.scss), que será compilado para CSS.

Observação: Nas versões atuais do SASS, recomenda-se utilizar @use em vez de @import, pois @import está obsoleto (deprecated).

Exemplo de projeto simples

_variables.scss

$corPrincipal: royalblue;
$fonte: Arial;

_buttons.scss

@use "variables" as *;

button{

    background: $corPrincipal;

    color: white;

    padding:10px;

}

style.scss

@use "variables";
@use "buttons";

body{

    font-family: variables.$fonte;

}

Após a compilação:

body{
    font-family: Arial;
}

button{
    background: royalblue;
    color:white;
    padding:10px;
}

Criando scripts no package.json

Para evitar digitar comandos longos, podem ser criados scripts.

Exemplo:

{
  "scripts": {
    "sass": "sass --watch scss:css"
  }
}

Depois basta executar:

npm run sass

Isso inicia o monitoramento automático dos arquivos SCSS.

Estrutura profissional

Projetos maiores costumam seguir uma organização como esta:

scss/
│
├── abstracts/
│   ├── _variables.scss
│   ├── _functions.scss
│   └── _mixins.scss
│
├── base/
│   ├── _reset.scss
│   ├── _fonts.scss
│   └── _typography.scss
│
├── components/
│   ├── _button.scss
│   ├── _card.scss
│   ├── _navbar.scss
│   └── _modal.scss
│
├── layout/
│   ├── _header.scss
│   ├── _footer.scss
│   ├── _sidebar.scss
│   └── _grid.scss
│
├── pages/
│   ├── _home.scss
│   ├── _about.scss
│   └── _contact.scss
│
├── themes/
│   ├── _dark.scss
│   └── _light.scss
│
└── style.scss

Essa estrutura facilita a expansão do projeto sem comprometer a organização.

Boas práticas

  • Utilize a sintaxe SCSS, pois é a mais adotada atualmente.
  • Organize os estilos em arquivos menores (partials).
  • Utilize @use para importar módulos, evitando @import.
  • Crie uma estrutura de pastas lógica (base, componentes, layout, páginas etc.).
  • Centralize cores, fontes e espaçamentos em arquivos de variáveis.
  • Crie mixins para estilos repetitivos.
  • Configure scripts no package.json para simplificar a compilação.
  • Nunca edite o CSS compilado manualmente; faça alterações apenas nos arquivos .scss.
  • Utilize a compilação automática (-watch) durante o desenvolvimento.

Vantagens de criar projetos com SASS

  • Código mais organizado.
  • Maior reutilização de estilos.
  • Facilidade de manutenção.
  • Escalabilidade para projetos grandes.
  • Menor repetição de código.
  • Melhor integração com frameworks modernos.
  • Desenvolvimento mais rápido e produtivo.

Possíveis dificuldades

  • Necessidade de instalar e configurar o ambiente.
  • Curva de aprendizado para quem conhece apenas CSS.
  • Organização inicial exige planejamento.
  • Uso incorreto de @use e namespaces pode gerar erros até que o desenvolvedor se familiarize com o sistema de módulos.

Resumo

Criar um projeto com SASS envolve configurar um ambiente com Node.js, instalar o compilador do SASS via npm, organizar os arquivos em uma estrutura modular e compilar os arquivos .scss para .css. Em projetos modernos, recomenda-se utilizar @use, dividir os estilos em partials, automatizar a compilação com --watch e manter uma organização por componentes e responsabilidades. Essa abordagem torna o desenvolvimento mais produtivo, facilita a manutenção e permite que o projeto cresça de forma organizada e escalável.
