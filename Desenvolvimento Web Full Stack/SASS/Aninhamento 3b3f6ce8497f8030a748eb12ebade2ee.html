Aninhamento

Aninhamento (Nesting) no SASS

O que é Aninhamento?

O Aninhamento (Nesting) é um dos recursos mais conhecidos e utilizados do SASS. Ele permite escrever seletores CSS dentro de outros seletores, refletindo a mesma estrutura hierárquica do HTML.

No CSS tradicional, quando um elemento está dentro de outro, é necessário repetir o seletor pai várias vezes. Com o aninhamento, essa repetição é eliminada, deixando o código mais limpo, organizado e fácil de entender.

Exemplo da estrutura HTML

<nav>
    <ul>
        <li>
            <a href="#">Início</a>
        </li>
    </ul>
</nav>

Essa estrutura pode ser representada de forma semelhante no SCSS:

nav{
    ul{
        li{
            a{
                color: blue;
            }
        }
    }
}

Após a compilação, o SASS gera o CSS equivalente.

Objetivo do Aninhamento

O principal objetivo do aninhamento é:

  • Evitar repetição de seletores.
  • Organizar melhor o código.
  • Tornar o SCSS semelhante à estrutura do HTML.
  • Facilitar a leitura e a manutenção.
  • Agrupar estilos relacionados.

Como funciona?

Quando um seletor é colocado dentro de outro, o SASS combina automaticamente esses seletores ao gerar o CSS.

Exemplo

SCSS:

header{

    background: #333;

    h1{

        color: white;

    }

}

CSS gerado:

header{
    background: #333;
}

header h1{
    color: white;
}

Observe que o SASS adicionou automaticamente o seletor header antes de h1.

Comparação entre CSS e SCSS

CSS tradicional

nav{
    background: black;
}

nav ul{
    list-style: none;
}

nav ul li{
    display: inline-block;
}

nav ul li a{
    color: white;
}

Há bastante repetição.

SCSS com Aninhamento

nav{

    background: black;

    ul{

        list-style: none;

        li{

            display: inline-block;

            a{

                color: white;

            }

        }

    }

}

O resultado compilado será exatamente o mesmo CSS mostrado anteriormente.

Vantagens do Aninhamento

1. Código mais organizado

Os elementos ficam agrupados de acordo com sua hierarquia.

main{

    article{

        p{

            color: gray;

        }

    }

}

É fácil perceber que o <p> pertence ao <article>, que pertence ao <main>.

2. Menor repetição

Sem aninhamento:

.card{
}

.card h2{
}

.card p{
}

.card button{
}

Com aninhamento:

.card{

    h2{

    }

    p{

    }

    button{

    }

}

3. Fácil manutenção

Se um componente mudar, todos os estilos relacionados estarão agrupados em um único bloco.

4. Código mais legível

Projetos grandes possuem centenas de seletores.

O aninhamento facilita encontrar onde determinado estilo está definido.

Níveis de Aninhamento

Um nível

section{

    h1{

    }

}

Resultado:

section h1{

}

Dois níveis

section{

    article{

        h1{

        }

    }

}

Resultado:

section article h1{

}

Três níveis

section{

    article{

        div{

            p{

            }

        }

    }

}

Resultado:

section article div p{

}

Quanto maior o número de níveis, mais específico será o seletor gerado.

Aninhando Classes

Também funciona com classes.

SCSS:

.menu{

    .item{

        color: black;

    }

}

CSS:

.menu .item{

    color: black;

}

Aninhando IDs

#container{

    .card{

        h2{

            color: blue;

        }

    }

}

Resultado:

#container .card h2{

    color: blue;

}

Pseudo-classes com &

O caractere & representa o seletor atual e é muito utilizado para criar pseudo-classes e pseudo-elementos.

Exemplo

button{

    background: blue;

    &:hover{

        background: darkblue;

    }

}

CSS gerado:

button{
    background: blue;
}

button:hover{
    background: darkblue;
}

Sem o &, seria necessário escrever:

button:hover{

}

Pseudo-elementos

p{

    &::first-letter{

        font-size: 30px;

    }

}

Resultado:

p::first-letter{

    font-size: 30px;

}

Classes modificadoras com &

Muito utilizado na metodologia BEM (Block Element Modifier).

SCSS:

.botao{

    background: blue;

    &-grande{

        padding:20px;

    }

}

Resultado:

.botao{
    background: blue;
}

.botao-grande{
    padding:20px;
}

Outro exemplo:

.card{

    &-header{
        padding:15px;
    }

    &-body{
        padding:20px;
    }

    &-footer{
        padding:10px;
    }

}

Resultado:

.card-header{
    padding:15px;
}

.card-body{
    padding:20px;
}

.card-footer{
    padding:10px;
}

Aninhando Media Queries

É possível colocar media queries dentro de um seletor.

SCSS:

.container{

    width: 1200px;

    @media(max-width:768px){

        width:100%;

    }

}

CSS gerado:

.container{
    width:1200px;
}

@media(max-width:768px){

    .container{

        width:100%;

    }

}

Isso mantém os estilos responsivos próximos do componente ao qual pertencem.

Aninhando propriedades

O SASS também permite agrupar propriedades com o mesmo prefixo.

SCSS:

.box{

    border:{
        width:2px;
        style:solid;
        color:black;
    }

}

CSS gerado:

.box{

    border-width:2px;
    border-style:solid;
    border-color:black;

}

Outro exemplo:

.texto{

    font:{
        family:Arial;
        size:18px;
        weight:bold;
    }

}

Resultado:

.texto{

    font-family:Arial;
    font-size:18px;
    font-weight:bold;

}

Cuidados com o Aninhamento

Embora seja muito útil, o uso excessivo pode gerar problemas.

Exemplo ruim

body{

    main{

        section{

            article{

                div{

                    ul{

                        li{

                            a{

                                span{

                                    color:red;

                                }

                            }

                        }

                    }

                }

            }

        }

    }

}

CSS gerado:

body main section article div ul li a span{

    color:red;

}

Esse seletor é extremamente específico, difícil de manter e pode prejudicar o desempenho do CSS.

Recomendação

O ideal é limitar o aninhamento a 3 ou 4 níveis.

Exemplo recomendado:

.card{

    h2{

    }

    p{

    }

    button{

    }

}

Esse código permanece organizado e fácil de manter.

Boas práticas

  • Utilize o aninhamento apenas quando houver relação direta entre os elementos.
  • Evite criar seletores muito longos.
  • Prefira no máximo 3 ou 4 níveis de profundidade.
  • Use o operador & para pseudo-classes, pseudo-elementos e modificadores.
  • Organize os estilos por componente.
  • Não utilize o aninhamento apenas porque ele existe; avalie se ele realmente melhora a legibilidade.

Vantagens

  • Código mais limpo.
  • Menor repetição de seletores.
  • Melhor organização.
  • Fácil manutenção.
  • Aproxima a estrutura do SCSS da estrutura do HTML.
  • Facilita a criação de componentes reutilizáveis.
  • Excelente integração com metodologias como BEM.

Desvantagens

  • O uso excessivo gera CSS muito específico.
  • Pode dificultar a sobrescrita de estilos.
  • Seletores muito longos tornam a manutenção mais complexa.
  • Desenvolvedores iniciantes tendem a exagerar na profundidade do aninhamento.

Casos de uso

O aninhamento é especialmente útil em:

  • Menus de navegação.
  • Cards.
  • Formulários.
  • Componentes reutilizáveis.
  • Cabeçalhos e rodapés.
  • Barras laterais.
  • Componentes responsivos com media queries.
  • Projetos organizados por componentes.

Resumo

O Aninhamento (Nesting) é um recurso do SASS que permite escrever seletores dentro de outros seletores, reproduzindo a hierarquia do HTML e reduzindo a repetição de código. Durante a compilação, o SASS transforma essa estrutura em CSS comum. Além de permitir o aninhamento de seletores, ele também suporta o uso do operador & para pseudo-classes, pseudo-elementos e modificadores, bem como o agrupamento de propriedades e media queries. Quando utilizado com moderação — geralmente até três ou quatro níveis de profundidade — o aninhamento torna o código mais organizado, legível e fácil de manter.
