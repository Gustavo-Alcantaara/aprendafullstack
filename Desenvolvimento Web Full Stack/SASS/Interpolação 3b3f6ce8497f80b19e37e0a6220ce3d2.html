Interpolação

Interpolação no SASS

O que é Interpolação?

A Interpolação é um recurso do SASS que permite inserir dinamicamente o valor de uma variável, expressão ou resultado de uma função dentro de seletores, propriedades, nomes de classes, IDs, valores ou strings.

Ela é representada pela sintaxe:

#{$variavel}

ou

#{expressão}

A interpolação torna o código mais flexível e evita a repetição de estruturas semelhantes, sendo muito utilizada para gerar classes automaticamente, criar seletores dinâmicos e construir nomes de propriedades.

Objetivos da Interpolação

A interpolação é utilizada para:

  • Criar classes dinamicamente.
  • Criar IDs automaticamente.
  • Gerar seletores personalizados.
  • Construir nomes de propriedades.
  • Concatenar textos e variáveis.
  • Automatizar a criação de estilos repetitivos.
  • Tornar o código mais reutilizável.

Como funciona?

Durante a compilação, o SASS substitui a expressão interpolada pelo seu valor.

SCSS

$cor: blue;

.texto-#{$cor}{
    color: $cor;
}

CSS gerado

.texto-blue{
    color: blue;
}

Observe que o valor da variável foi utilizado tanto no nome da classe quanto no valor da propriedade.

Sintaxe

A sintaxe geral é:

#{$variavel}

ou

#{expressão}

Exemplo:

$nome: destaque;

.#{$nome}{
    color: red;
}

Resultado:

.destaque{
    color: red;
}

Interpolação em Seletores

Um dos usos mais comuns é criar seletores dinamicamente.

Exemplo

$classe: menu;

.#{$classe}{
    background: black;
}

Resultado:

.menu{
    background: black;
}

Interpolação em IDs

Também funciona com IDs.

$id: principal;

##{$id}{
    width: 100%;
}

Resultado:

#principal{
    width: 100%;
}

Interpolação em nomes de classes

$tipo: sucesso;

.alerta-#{$tipo}{
    background: green;
}

Resultado:

.alerta-sucesso{
    background: green;
}

Outro exemplo:

$tamanho: grande;

.botao-#{$tamanho}{
    padding: 20px;
}

Resultado:

.botao-grande{
    padding: 20px;
}

Interpolação em propriedades

Além de seletores, a interpolação pode ser utilizada para criar nomes de propriedades.

Exemplo

$lado: left;

.box{
    margin-#{$lado}: 20px;
}

Resultado:

.box{
    margin-left: 20px;
}

Outro exemplo:

$direcao: top;

.card{
    border-#{$direcao}: 2px solid black;
}

Resultado:

.card{
    border-top: 2px solid black;
}

Interpolação em valores

Também pode ser utilizada em valores.

$imagem: "banner.jpg";

header{
    background-image: url("img/#{$imagem}");
}

Resultado:

header{
    background-image: url("img/banner.jpg");
}

Interpolação com Strings

É possível concatenar textos.

$tema: dark;

body{

    background-image: url("images/#{$tema}/background.png");

}

Resultado:

body{

    background-image: url("images/dark/background.png");

}

Interpolação com números

$numero: 5;

.coluna-#{$numero}{
    width: 50%;
}

Resultado:

.coluna-5{
    width: 50%;
}

Interpolação em Laços de Repetição

A interpolação é muito utilizada junto com estruturas de repetição.

Exemplo com @for

@for $i from 1 through 4{

    .col-#{$i}{

        width: 25% * $i;

    }

}

Resultado:

.col-1{
    width:25%;
}

.col-2{
    width:50%;
}

.col-3{
    width:75%;
}

.col-4{
    width:100%;
}

Esse recurso é bastante utilizado em sistemas de grids.

Interpolação com @each

$cores: red, blue, green;

@each $cor in $cores{

    .texto-#{$cor}{

        color:$cor;

    }

}

Resultado:

.texto-red{
    color:red;
}

.texto-blue{
    color:blue;
}

.texto-green{
    color:green;
}

Interpolação com Mapas

A interpolação funciona muito bem com Maps.

$cores:(
    sucesso:green,
    erro:red,
    aviso:orange
);

@each $nome,$valor in $cores{

    .#{$nome}{

        background:$valor;

    }

}

Resultado:

.sucesso{
    background:green;
}

.erro{
    background:red;
}

.aviso{
    background:orange;
}

Interpolação em Mixins

Também pode ser utilizada dentro de mixins.

@mixin margem($lado){

    margin-#{$lado}:20px;

}

.box{

    @include margem(left);

}

Resultado:

.box{

    margin-left:20px;

}

Outro exemplo:

@mixin borda($lado){

    border-#{$lado}:2px solid black;

}

.card{

    @include borda(bottom);

}

Resultado:

.card{

    border-bottom:2px solid black;

}

Interpolação com Funções

$cor: red;

.texto{

    color: lighten(#{$cor},20%);

}

Embora a interpolação funcione, nesse caso ela é desnecessária. O correto seria:

$cor: red;

.texto{

    color: lighten($cor,20%);

}

Importante: utilize interpolação apenas quando precisar inserir um valor em um contexto onde o SASS espera texto (como nomes de classes, propriedades ou seletores). Para passar variáveis como valores de propriedades ou funções, use diretamente a variável.

Interpolação com o operador &

A interpolação também pode ser combinada com o seletor pai (&).

$estado: ativo;

.botao{

    &-#{$estado}{

        background:green;

    }

}

Resultado:

.botao-ativo{

    background:green;

}

Esse padrão é muito utilizado na metodologia BEM (Block Element Modifier).

Casos práticos

Sistema de botões

$cores:(
    primary:blue,
    success:green,
    danger:red
);

@each $nome,$cor in $cores{

    .btn-#{$nome}{

        background:$cor;
        color:white;

    }

}

Resultado:

.btn-primary{
    background:blue;
    color:white;
}

.btn-success{
    background:green;
    color:white;
}

.btn-danger{
    background:red;
    color:white;
}

Sistema de margens

@for $i from 1 through 5{

    .m-#{$i}{

        margin:$i * 10px;

    }

}

Resultado:

.m-1{margin:10px;}
.m-2{margin:20px;}
.m-3{margin:30px;}
.m-4{margin:40px;}
.m-5{margin:50px;}

Boas práticas

  • Utilize a interpolação apenas quando realmente precisar construir nomes dinamicamente.
  • Prefira nomes de variáveis descritivos.
  • Combine a interpolação com @for, @each e @while para gerar código repetitivo automaticamente.
  • Evite interpolação desnecessária em valores simples.
  • Organize as variáveis em arquivos específicos (_variables.scss) para facilitar a reutilização.

Vantagens

  • Reduz a repetição de código.
  • Automatiza a criação de seletores.
  • Permite gerar classes e IDs dinamicamente.
  • Facilita a criação de sistemas de componentes.
  • Funciona em conjunto com laços de repetição e mapas.
  • Aumenta a flexibilidade do código.
  • Torna o SCSS mais reutilizável.

Desvantagens

  • O uso excessivo pode dificultar a leitura do código.
  • Pode gerar muitas classes automaticamente, aumentando o tamanho do CSS compilado.
  • Utilizada de forma inadequada, pode tornar o código mais complexo do que o necessário.

Casos de uso

A interpolação é muito utilizada em:

  • Sistemas de grids.
  • Frameworks CSS.
  • Design Systems.
  • Componentes reutilizáveis.
  • Geração automática de classes utilitárias.
  • Sistemas de temas.
  • Metodologia BEM.
  • Mixins reutilizáveis.
  • Projetos com grande quantidade de componentes.

Resumo

A Interpolação é um recurso do SASS que utiliza a sintaxe #{} para inserir dinamicamente o valor de variáveis ou expressões em seletores, nomes de classes, IDs, propriedades, valores e strings. Ela é especialmente útil para automatizar a geração de código, reduzindo repetições e aumentando a flexibilidade dos estilos. Em conjunto com recursos como laços de repetição (@for, @each), mapas (Maps), mixins e o operador &, a interpolação permite criar componentes reutilizáveis, sistemas de grids, classes utilitárias e estruturas escaláveis, sendo um recurso essencial para projetos modernos desenvolvidos com SASS.
