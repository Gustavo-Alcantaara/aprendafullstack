Diretivas de Controle

Diretivas de Controle no SASS

O que são Diretivas de Controle?

As Diretivas de Controle são estruturas do SASS que permitem controlar o fluxo de execução do código, tornando os estilos mais inteligentes e dinâmicos.

Com elas, é possível tomar decisões, repetir blocos de código, percorrer listas e mapas e criar estilos de forma automatizada.

Essas diretivas são semelhantes às estruturas de controle existentes em linguagens de programação como PHP, JavaScript, Java e Python.

Objetivos das Diretivas de Controle

As diretivas de controle são utilizadas para:

  • Automatizar a geração de CSS.
  • Evitar repetição de código.
  • Criar componentes reutilizáveis.
  • Trabalhar com condições.
  • Percorrer listas e mapas.
  • Executar laços de repetição.
  • Facilitar manutenção do projeto.

Principais Diretivas de Controle

O SASS possui as seguintes diretivas principais:

DiretivaFinalidade
@ifExecuta um bloco se uma condição for verdadeira.
@elseExecuta um bloco alternativo quando a condição for falsa.
@else ifPermite testar várias condições em sequência.
@forExecuta um bloco um número conhecido de vezes.
@whileExecuta um bloco enquanto uma condição for verdadeira.
@eachPercorre listas e mapas.

Diretiva @if

A diretiva @if executa um bloco apenas quando uma condição é verdadeira.

Sintaxe

@if condição{

}

Exemplo

$tema: escuro;

body{

    @if $tema == escuro{

        background:black;
        color:white;

    }

}

CSS gerado

body{

    background:black;
    color:white;

}

Diretiva @else

Permite executar um bloco alternativo quando a condição for falsa.

Exemplo

$tema: claro;

body{

    @if $tema == escuro{

        background:black;
        color:white;

    }

    @else{

        background:white;
        color:black;

    }

}

CSS gerado

body{

    background:white;
    color:black;

}

Diretiva @else if

Permite verificar várias condições.

$cor: sucesso;

.botao{

    @if $cor == primary{

        background:blue;

    }

    @else if $cor == sucesso{

        background:green;

    }

    @else{

        background:red;

    }

}

Resultado:

.botao{

    background:green;

}

Diretiva @for

Executa um bloco um número determinado de vezes.

Exemplo

@for $i from 1 through 3{

    .col-#{$i}{

        width:33.33%;

    }

}

Resultado:

.col-1{

    width:33.33%;

}

.col-2{

    width:33.33%;

}

.col-3{

    width:33.33%;

}

Características:

  • Trabalha com números.
  • Utiliza through ou to.
  • Muito utilizada para grids e classes utilitárias.

Diretiva @while

Executa um bloco enquanto uma condição permanecer verdadeira.

Exemplo

$i:1;

@while $i <=3{

    .item-#{$i}{

        margin:$i * 10px;

    }

    $i:$i+1;

}

Resultado:

.item-1{

    margin:10px;

}

.item-2{

    margin:20px;

}

.item-3{

    margin:30px;

}

Características:

  • Baseada em condições.
  • Exige atualização da variável de controle.
  • Deve ser utilizada com cuidado para evitar loops infinitos.

Diretiva @each

Percorre listas ou mapas.

Lista

$cores:red,blue,green;

@each $cor in $cores{

    .texto-#{$cor}{

        color:$cor;

    }

}

Resultado:

.texto-red{

    color:red;

}

.texto-blue{

    color:blue;

}

.texto-green{

    color:green;

}

Mapa

$cores:(

    sucesso:green,

    erro:red

);

@each $nome,$cor in $cores{

    .#{$nome}{

        background:$cor;

    }

}

Resultado:

.sucesso{

    background:green;

}

.erro{

    background:red;

}

Utilizando Diretivas dentro de Mixins

As diretivas podem ser utilizadas dentro de Mixins.

@mixin tema($modo){

    @if $modo == claro{

        background:white;

    }

    @else{

        background:black;

    }

}

Uso:

body{

    @include tema(claro);

}

Utilizando Diretivas em Funções

Também podem ser utilizadas em funções.

@function corTema($modo){

    @if $modo == claro{

        @return white;

    }

    @return black;

}

Uso:

body{

    background:corTema(claro);

}

Diretivas com Interpolação

As diretivas podem ser combinadas com interpolação.

@for $i from 1 through 4{

    .col-#{$i}{

        width:25% * $i;

    }

}

Resultado:

.col-1{

    width:25%;

}

.col-2{

    width:50%;

}

.col-3{

    width:75%;

}

.col-4{

    width:100%;

}

Exemplo prático: Sistema de Botões

$cores:(

    primary:#0d6efd,

    success:#198754,

    danger:#dc3545

);

@each $tipo,$cor in $cores{

    .btn-#{$tipo}{

        background:$cor;

    }

}

Resultado:

.btn-primary{

    background:#0d6efd;

}

.btn-success{

    background:#198754;

}

.btn-danger{

    background:#dc3545;

}

Exemplo prático: Espaçamentos

@for $i from 1 through 5{

    .m-#{$i}{

        margin:$i * 10px;

    }

}

Resultado:

.m-1{

    margin:10px;

}

.m-2{

    margin:20px;

}

.m-3{

    margin:30px;

}

.m-4{

    margin:40px;

}

.m-5{

    margin:50px;

}

Boas práticas

  • Utilize @if para decisões simples.
  • Prefira @for quando souber a quantidade de repetições.
  • Utilize @each para listas e mapas.
  • Use @while apenas quando a repetição depender de uma condição.
  • Evite criar loops que gerem CSS desnecessário.
  • Organize a lógica em Mixins e Funções quando possível.

Vantagens

  • Reduz repetição de código.
  • Automatiza a geração de CSS.
  • Facilita manutenção.
  • Permite criar componentes reutilizáveis.
  • Torna o código mais organizado.
  • Excelente para Design Systems.

Desvantagens

  • O uso excessivo pode dificultar a leitura do código.
  • Loops grandes podem gerar arquivos CSS muito extensos.
  • O uso incorreto de @while pode causar loops infinitos.
  • Lógicas muito complexas podem tornar o SCSS difícil de manter.

Comparação das Diretivas

DiretivaMelhor utilização
@ifDecisões simples.
@elseBloco alternativo.
@else ifMúltiplas condições.
@forRepetições numéricas.
@whileRepetições condicionais.
@eachPercorrer listas e mapas.

Casos de uso

As diretivas de controle são amplamente utilizadas para:

  • Sistemas de Grid.
  • Classes utilitárias.
  • Botões.
  • Cards.
  • Temas claro/escuro.
  • Design Systems.
  • Layouts responsivos.
  • Geração automática de componentes.
  • Manipulação de listas e mapas.
  • Automatização de estilos.

Resumo

As Diretivas de Controle do SASS são estruturas que permitem controlar o fluxo de execução do código, tornando os estilos mais dinâmicos e reutilizáveis. Elas incluem as diretivas @if, @else e @else if para decisões condicionais, @for para repetições numéricas, @while para repetições baseadas em condições e @each para percorrer listas e mapas. Em conjunto com recursos como variáveis, mixins, funções e interpolação, essas diretivas automatizam a geração de CSS, reduzem a duplicação de código e facilitam a criação de componentes escaláveis e de fácil manutenção, sendo fundamentais no desenvolvimento de projetos modernos com SASS.
