Botões

Botões no Bootstrap

O Bootstrap possui um sistema completo de botões prontos, permitindo criar interfaces modernas rapidamente usando apenas classes.

Os botões podem ter:

  • Cores
  • Tamanhos
  • Bordas
  • Estados
  • Ícones
  • Responsividade

Classe básica

Todo botão Bootstrap utiliza:

<button class="btn">

A classe btn aplica o estilo base do botão.

Cores dos botões

Bootstrap possui várias variações prontas.

ClasseCor
btn-primaryAzul
btn-secondaryCinza
btn-successVerde
btn-dangerVermelho
btn-warningAmarelo
btn-infoAzul claro
btn-darkPreto
btn-lightBranco/cinza
btn-linkEstilo de link

Exemplo

<button class="btn btn-primary">
    Botão
</button>

Botões outline

São botões transparentes com borda colorida.

Estrutura:

btn-outline-cor

Exemplo

<button class="btn btn-outline-success">
    Sucesso
</button>

Tamanhos de botões

ClasseTamanho
btn-smPequeno
padrãoMédio
btn-lgGrande

Exemplo

<button class="btn btn-primary btn-lg">

Botão ocupando largura total

<button class="btn btn-dark w-100">

Muito usado em:

  • Formulários
  • Login
  • Mobile

Botões desabilitados

<button class="btn btn-secondary"disabled>

O botão:

  • Fica apagado
  • Não pode ser clicado

Estado ativo

<button class="btn btn-primary active">

Grupo de botões

Bootstrap possui agrupamento pronto.

<div class="btn-group">

<button class="btn btn-primary">
        Esquerda
</button>

<button class="btn btn-primary">
        Centro
</button>

<button class="btn btn-primary">
        Direita
</button>

</div>

Toolbar de botões

<div class="btn-toolbar">

Usado para conjuntos maiores de ações.

Botões com ícones

Pode combinar Bootstrap com bibliotecas de ícones.

Exemplo:

<button class="btn btn-success">

    ✓ Salvar

</button>

Botões responsivos

Os botões podem usar:

  • Breakpoints
  • Flexbox
  • Width utilities

Exemplo:

<button class="btn btn-primary w-100 w-md-auto">

Botões em links

Também é possível estilizar links como botão.

<a href="#" class="btn btn-danger">
    Acessar
</a>

Botões toggle

Bootstrap possui integração com:

  • Checkbox
  • Radio
  • Toggle states

Exemplo:

<input type="checkbox" class="btn-check" id="btncheck">

<label class="btn btn-outline-primary"
for="btncheck">

    Ativar

</label>

Exemplo completo

<div class="container">

<button class="btn btn-primary">
        Primário
</button>

<button class="btn btn-success">
        Sucesso
</button>

<button class="btn btn-outline-danger">
        Excluir
</button>

<button class="btn btn-dark btn-lg">
        Grande
</button>

</div>
