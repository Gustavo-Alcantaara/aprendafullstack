Margin e Wrap

Margin no Bootstrap

As margins no Bootstrap são usadas para criar espaço externo entre elementos.

Elas ajudam a:

  • Separar componentes
  • Organizar layouts
  • Melhorar o espaçamento visual

Bootstrap possui classes prontas para margin.

Estrutura das classes

m-direção-tamanho

Partes da estrutura

ParteFunção
mMargin
direçãoLado da margin
tamanhoIntensidade

Direções

ClasseDireção
mTodos os lados
mtTopo
mbBottom
msStart (esquerda)
meEnd (direita)
mxHorizontal
myVertical

Exemplos

Margin em todos os lados

<div class="m-3">

Margin superior

<div class="mt-5">

Margin horizontal

<div class="mx-4">

Tamanhos

ClasseEspaço
0Sem margin
1Pequena
2Média pequena
3Média
4Grande
5Muito grande

Exemplo completo

<div class="bg-primary text-light p-3 mb-4">

    Caixa 1

</div>

<div class="bg-success text-light p-3">

    Caixa 2

</div>

Margin automática

Bootstrap possui:

mx-auto

Muito usada para centralizar elementos.

Exemplo

<div class="w-50 mx-auto">

Margin responsiva

Pode usar breakpoints.

Exemplo

<div class="mt-md-5">

Significa:

  • Mobile → margin normal
  • Medium para cima → margin maior

Wrap no Bootstrap

O wrap controla se os elementos podem quebrar linha quando não houver espaço suficiente.

Ele é muito usado com:

  • Flexbox
  • Grid
  • Layouts responsivos

Classe principal

flex-wrap

Como funciona

Sem wrap:

  • Os itens tentam ficar na mesma linha

Com wrap:

  • Os itens quebram para a próxima linha

Classes de wrap

ClasseFunção
flex-wrapPermite quebra
flex-nowrapImpede quebra
flex-wrap-reverseQuebra invertida

Exemplo com wrap

<div class="d-flex flex-wrap">

Exemplo completo

<div class="d-flex flex-wrap gap-3">

<div class="bg-primary text-light p-3">
        Item 1
</div>

<div class="bg-success text-light p-3">
        Item 2
</div>

<div class="bg-danger text-light p-3">
        Item 3
</div>

<div class="bg-dark text-light p-3">
        Item 4
</div>

</div>

Quando faltar espaço:

  • Os itens irão para a linha de baixo.

Wrap invertido

<div class="d-flex flex-wrap-reverse">

Os itens quebram em ordem invertida.

Sem wrap

<div class="d-flex flex-nowrap">

Todos os elementos ficam na mesma linha.

Wrap responsivo

Bootstrap permite controlar wrap por breakpoint.

Exemplo

<div class="d-flex flex-md-wrap">

Combinação com alinhamento

Wrap normalmente é usado junto com:

  • justify-content-*
  • align-items-*
  • gap-*

Exemplo moderno

<div class="d-flex
            flex-wrap
            justify-content-center
            gap-4">

<div class="card p-3">
        Card 1
</div>

<div class="card p-3">
        Card 2
</div>

<div class="card p-3">
        Card 3
</div>

</div>

Vantagens do Margin e Wrap

Margin

  • Melhor espaçamento
  • Organização visual
  • Layout mais limpo

Wrap

  • Responsividade
  • Flexibilidade
  • Melhor adaptação em telas pequenas
