Listas

Listas no Bootstrap

O Bootstrap possui várias classes e componentes para estilizar listas de forma moderna e responsiva.

As listas podem ser usadas para:

  • Menus
  • Navegação
  • Cards
  • Grupos de itens
  • Informações organizadas

Listas padrão

As listas HTML continuam funcionando normalmente.

Lista não ordenada

<ul>
<li>Item 1</li>
<li>Item 2</li>
</ul>

Remover estilo da lista

Bootstrap possui:

<ul class="list-unstyled">

Remove:

  • Marcadores
  • Espaçamento padrão

Exemplo

<ul class="list-unstyled">

<li>Home</li>
<li>Sobre</li>
<li>Contato</li>

</ul>

Lista inline

Transforma os itens em linha.

<ul class="list-inline">

<li class="list-inline-item">
        Home
</li>

<li class="list-inline-item">
        Serviços
</li>

</ul>

Muito usado em:

  • Menus simples
  • Rodapés
  • Redes sociais

List Group

O Bootstrap possui o componente:

list-group

Usado para listas estilizadas e interativas.

Estrutura básica

<ul class="list-group">

<li class="list-group-item">
        Item 1
</li>

<li class="list-group-item">
        Item 2
</li>

</ul>

Resultado

Cada item recebe:

  • Borda
  • Padding
  • Organização visual

Item ativo

<li class="list-group-item active">

Item desabilitado

<li class="list-group-item disabled">

Cores nas listas

Bootstrap permite aplicar cores.

<li class="list-group-item list-group-item-success">

Principais cores

ClasseCor
list-group-item-primaryAzul
list-group-item-successVerde
list-group-item-dangerVermelho
list-group-item-warningAmarelo
list-group-item-darkEscuro

Listas clicáveis

Também é possível usar links.

<div class="list-group">

<a href="#"
class="list-group-item list-group-item-action">

        Home

</a>

</div>

list-group-item-action

Adiciona:

  • Hover
  • Clique
  • Feedback visual

Listas horizontais

<ul class="list-group list-group-horizontal">

Os itens ficam lado a lado.

Responsividade horizontal

<ul class="list-group list-group-horizontal-md">

Horizontal apenas em telas médias ou maiores.

Flush List

Remove bordas externas.

<ul class="list-group list-group-flush">

Muito usado em:

  • Cards
  • Sidebars

Listas com badges

<ul class="list-group">

<li class="list-group-item d-flex justify-content-between">

        Mensagens

<span class="badge bg-primary">
            5
</span>

</li>

</ul>

Exemplo completo

<div class="container">

<ul class="list-group">

<li class="list-group-item active">
            Dashboard
</li>

<li class="list-group-item">
            Usuários
</li>

<li class="list-group-item list-group-item-success">
            Configurações
</li>

</ul>

</div>
