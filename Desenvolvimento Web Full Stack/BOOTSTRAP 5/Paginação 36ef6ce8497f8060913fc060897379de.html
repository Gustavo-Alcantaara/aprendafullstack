Paginação

Paginação no Bootstrap

A paginação no Bootstrap é um componente usado para navegar entre várias páginas ou conjuntos de dados.

Ela é muito utilizada em:

  • Listagens
  • Blogs
  • Tabelas
  • Sistemas
  • E-commerces

A paginação melhora:

  • Organização
  • Navegação
  • Experiência do usuário

Estrutura básica

A paginação usa:

  • pagination
  • page-item
  • page-link

Exemplo básico

<nav>

<ul class="pagination">

<li class="page-item">

<a class="page-link"href="#">
                1
</a>

</li>

<li class="page-item">

<a class="page-link"href="#">
                2
</a>

</li>

</ul>

</nav>

Classes principais

ClasseFunção
paginationContainer
page-itemItem da página
page-linkLink da página

Página ativa

<li class="page-item active">

Exemplo

<li class="page-item active">

<a class="page-link">
        1
</a>

</li>

A página atual fica destacada.

Página desabilitada

<li class="page-item disabled">

Exemplo

<li class="page-item disabled">

<a class="page-link">
        Anterior
</a>

</li>

Muito usado quando:

  • Não há página anterior
  • Não há próxima página

Uso com JavaScript e Backend

A paginação normalmente é integrada com:

  • PHP
  • Node.js
  • React
  • APIs
  • Bancos de dados

Ela pode:

  • Carregar novas páginas
  • Buscar dados dinamicamente
  • Controlar listas grandes

Responsividade

A paginação Bootstrap já é responsiva e funciona bem em:

  • Celulares
  • Tablets
  • Desktop
