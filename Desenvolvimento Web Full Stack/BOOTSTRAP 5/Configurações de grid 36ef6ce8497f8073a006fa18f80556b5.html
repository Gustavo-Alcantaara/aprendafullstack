Configurações de grid

Configurações de Grid no Bootstrap

O sistema de Grid do Bootstrap possui várias configurações que permitem controlar:

  • Tamanho das colunas
  • Responsividade
  • Espaçamento
  • Alinhamento
  • Ordem dos elementos
  • Distribuição do layout

Essas configurações tornam o Grid extremamente flexível.

Estrutura do Grid

O Grid Bootstrap funciona em:

container → row → col

Exemplo básico

<div class="container">

<div class="row">

<div class="col">

            Conteúdo

</div>

</div>

</div>

Sistema de 12 colunas

Bootstrap divide cada linha em:

12 colunas

Você pode distribuir essas colunas livremente.

Configuração de largura das colunas

col-*

Define quantas colunas o elemento ocupará.

Exemplo

<div class="col-6">

Ocupa:

  • 6 de 12 colunas
  • 50% da largura

Outros exemplos

ClasseTamanho
col-12100%
col-650%
col-433%
col-325%

Colunas automáticas

<div class="col">

Bootstrap divide o espaço automaticamente.

Exemplo

<div class="row">

<div class="col">1</div>
<div class="col">2</div>
<div class="col">3</div>

</div>

Resultado:

  • 3 colunas iguais

Configurações responsivas

Estrutura:

col-breakpoint-tamanho

Exemplo

<div class="col-md-6">

Significa:

  • Mobile → largura total
  • Médio para cima → 6 colunas

Breakpoints do Grid

ClasseTela
col-sm-*≥ 576px
col-md-*≥ 768px
col-lg-*≥ 992px
col-xl-*≥ 1200px
col-xxl-*≥ 1400px

Exemplo responsivo completo

<div class="col-12 col-md-6 col-lg-4">

Resultado:

  • Mobile → 12 colunas
  • Tablet → 6 colunas
  • Desktop → 4 colunas

Espaçamento (Gutters)

Bootstrap usa:

  • g
  • gx
  • gy

Espaçamento geral

<div class="row g-3">

Horizontal

<div class="row gx-5">

Vertical

<div class="row gy-2">

Valores de espaçamento

ClasseEspaço
g-0Nenhum
g-1 até g-5Crescente

Alinhamento vertical

align-items

ClasseFunção
align-items-startTopo
align-items-centerCentro
align-items-endFinal

Exemplo

<div class="row align-items-center">

Alinhamento horizontal

justify-content

ClasseFunção
justify-content-startInício
justify-content-centerCentro
justify-content-endFinal
justify-content-betweenEspaço entre
justify-content-aroundEspaço ao redor

Exemplo

<div class="row justify-content-between">

Ordem das colunas

Bootstrap permite mudar a ordem visual.

Exemplo

<div class="col order-1">

Classes de ordem

ClasseOrdem
order-1Primeiro
order-2Segundo
order-3Terceiro
order-lastÚltimo

Offset

Offset cria espaço vazio antes da coluna.

Exemplo

<div class="col-4 offset-4">

Resultado:

  • Centraliza a coluna

Auto margin

<div class="col-4 mx-auto">

Grid aninhado

Você pode criar grids dentro de grids.

Exemplo

<div class="row">

<div class="col-6">

<div class="row">

<div class="col">
 
                Subcoluna

</div>

</div>

</div>

</div>

Exemplo completo

<div class="container">

<div class="row g-4 justify-content-center">

<div class="col-12 col-md-6 col-lg-4">

<div class="bg-primary text-light p-4">

                Coluna 1

</div>

</div>

<div class="col-12 col-md-6 col-lg-4">

<div class="bg-success text-light p-4">

                Coluna 2

</div>

</div>

</div>

</div>
