Estrutura do projeto

Estrutura de um projeto com Bootstrap

A estrutura de um projeto é a forma como os arquivos e pastas são organizados. Em projetos que utilizam o Bootstrap, essa organização ajuda na manutenção, leitura do código e desenvolvimento do site.

Estrutura básica

projeto/
│
├── index.html
├── paginas/
│   ├── sobre.html
│   └── contato.html
│
├── css/
│   ├── bootstrap.min.css
│   └── style.css
│
├── js/
│   ├── bootstrap.bundle.min.js
│   └── script.js
│
├── img/
│
├── fonts/
│
└── assets/

Explicação da estrutura

Pasta principal do projeto

projeto/

É a raiz do projeto, onde todos os arquivos ficam organizados.

Arquivos HTML

index.html

É a página principal do site.

Outras páginas normalmente ficam em uma pasta separada:

paginas/

Exemplos:

  • sobre.html
  • contato.html
  • serviços.html

Isso evita deixar muitos arquivos soltos na raiz.

Pasta CSS

css/

Contém os arquivos de estilo.

bootstrap.min.css

Arquivo original do Bootstrap.

Responsável pelos:

  • Componentes
  • Grid system
  • Responsividade
  • Classes utilitárias

style.css

Arquivo de personalização do desenvolvedor.

Nele ficam:

  • Cores próprias
  • Ajustes de layout
  • Animações
  • Sobrescritas do Bootstrap

Pasta JavaScript

js/

Armazena scripts do projeto.

bootstrap.bundle.min.js

Arquivo JavaScript do Bootstrap.

Controla:

  • Dropdowns
  • Modais
  • Menu responsivo
  • Carousel
  • Collapse

script.js

Arquivo JavaScript personalizado.

Usado para:

  • Eventos
  • Interações
  • Manipulação do DOM
  • Funções próprias

Pasta de imagens

img/

Organiza imagens do site:

  • Logos
  • Fotos
  • Ícones
  • Backgrounds
  • Banners

Pasta de fontes

fonts/

Usada para:

  • Fontes personalizadas
  • Ícones locais
  • Tipografias baixadas

Pasta assets

assets/

Muitos desenvolvedores usam essa pasta para reunir recursos gerais do projeto.

Exemplo:

assets/
│
├── css/
├── js/
├── img/
└── fonts/

Essa abordagem deixa o projeto ainda mais organizado.

Estrutura interna do HTML

Além das pastas, o HTML também segue uma estrutura padrão:

<!DOCTYPE html>
<html lang="pt-br">

<head>
<meta charset="UTF-8">

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<link rel="stylesheet"
href="css/bootstrap.min.css">

<link rel="stylesheet"
href="css/style.css">

<title>Projeto Bootstrap</title>
</head>

<body>

<div class="container">
<h1 class="text-primary">
            Meu Projeto
</h1>
</div>

<script src="js/bootstrap.bundle.min.js"></script>

<script src="js/script.js"></script>

</body>
</html>

Importância da organização

Uma boa estrutura:

  • Facilita manutenção
  • Deixa o projeto mais profissional
  • Evita arquivos bagunçados
  • Ajuda no trabalho em equipe
  • Melhora a escalabilidade do sistema

Organização recomendada

Pequenos projetos

css/
js/
img/

Projetos maiores

assets/
components/
pages/
services/

Projetos grandes costumam separar:

  • Componentes
  • Páginas
  • APIs
  • Recursos visuais
  • Scripts específicos
