Container

Container no Bootstrap

No Bootstrap, o container é um elemento usado para organizar e centralizar o conteúdo da página.

Ele funciona como uma “caixa principal” que controla:

  • Largura do conteúdo
  • Espaçamento lateral
  • Responsividade do layout

Classe .container

A classe mais comum é:

<div class="container">

Ela cria uma área centralizada com largura automática dependendo do tamanho da tela.

Exemplo:

<div class="container">
<h1>Meu Site</h1>
<p>Conteúdo da página</p>
</div>

Como o container funciona

O Bootstrap possui tamanhos máximos definidos para cada resolução.

Em telas grandes:

  • O conteúdo fica centralizado
  • Não ocupa 100% da tela

Em telas pequenas:

  • O container ocupa quase toda a largura

Isso melhora:

  • Leitura
  • Organização
  • Responsividade

Tipos de container

1. .container

Container responsivo com largura fixa adaptável.

<div class="container">

A largura muda conforme o tamanho da tela.

2. .container-fluid

Ocupa 100% da largura da tela.

<div class="container-fluid">

Muito usado em:

  • Banners
  • Seções grandes
  • Layouts full width

Exemplo:

<div class="container-fluid bg-dark text-white">
<h1>Banner</h1>
</div>

3. Containers responsivos

O Bootstrap também possui containers específicos para breakpoints.

Exemplo:

<div class="container-md">

Significa:

  • Até certo tamanho → ocupa 100%
  • A partir do breakpoint md → largura fixa centralizada

Breakpoints principais

ClasseTamanho
sm≥ 576px
md≥ 768px
lg≥ 992px
xl≥ 1200px
xxl≥ 1400px

Exemplo prático

<div class="container">
<div class="row">

<div class="col">
            Coluna 1
</div>

<div class="col">
            Coluna 2
</div>

</div>
</div>

Nesse exemplo:

  • container centraliza
  • row cria uma linha
  • col cria colunas

Relação com o Grid System

O container é a base do sistema de grid do Bootstrap.

Estrutura padrão:

container
   └── row
          └── col

Ou seja:

  1. Container envolve tudo
  1. Row cria linhas
  1. Col cria colunas

Vantagens do container

  • Centralização automática
  • Layout responsivo
  • Melhor organização
  • Compatibilidade com Grid System
  • Facilidade no alinhamento

Exemplo completo

<div class="container">

<h1 class="text-primary">
        Meu Projeto Bootstrap
</h1>

<p>
        Conteúdo centralizado usando container.
</p>

</div>
