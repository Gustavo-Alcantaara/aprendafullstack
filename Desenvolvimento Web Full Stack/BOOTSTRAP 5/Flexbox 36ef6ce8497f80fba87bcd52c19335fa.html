Flexbox

Flexbox no Bootstrap

O Bootstrap utiliza o sistema Flexbox para criar layouts modernos, flexíveis e responsivos.

Flexbox é um modelo de layout do CSS usado para:

  • Alinhar elementos
  • Distribuir espaço
  • Organizar componentes
  • Criar layouts responsivos facilmente

Bootstrap possui várias classes utilitárias prontas para Flexbox.

Ativando o Flexbox

A principal classe é:

d-flex

Ela transforma o elemento em um container flexível.

Exemplo básico

<div class="d-flex">

<div>Item 1</div>
<div>Item 2</div>

</div>

Os itens ficam lado a lado.

Direção dos elementos

Controla como os itens serão organizados.

Classes de direção

ClasseDireção
flex-rowLinha
flex-row-reverseLinha invertida
flex-columnColuna
flex-column-reverseColuna invertida

Exemplo coluna

<div class="d-flex flex-column">

Os itens ficam um abaixo do outro.

Alinhamento horizontal

Usa:

justify-content

Classes horizontais

ClasseFunção
justify-content-startInício
justify-content-centerCentro
justify-content-endFinal
justify-content-betweenEspaço entre
justify-content-aroundEspaço ao redor
justify-content-evenlyEspaço igual

Exemplo

<div class="d-flex justify-content-center">

Alinhamento vertical

Usa:

align-items

Classes verticais

ClasseFunção
align-items-startTopo
align-items-centerCentro
align-items-endFinal
align-items-stretchEstica

Exemplo

<div class="d-flex align-items-center">

Centralização completa

<div class="d-flex
            justify-content-center
            align-items-center">

Muito usado em:

  • Login
  • Hero sections
  • Loading screens

Flex Wrap

Controla quebra de linha.

Classes

ClasseFunção
flex-wrapPermite quebra
flex-nowrapNão quebra
flex-wrap-reverseQuebra invertida

Exemplo

<div class="d-flex flex-wrap">

Gap no Flexbox

Bootstrap possui espaçamento entre itens.

Exemplo

<div class="d-flex gap-3">

Valores de gap

ClasseEspaço
gap-0Sem espaço
gap-1 até gap-5Espaçamento crescente

Crescimento dos elementos

flex-fill

<div class="flex-fill">

Faz o item ocupar o espaço disponível.

Exemplo

<div class="d-flex">

<div class="flex-fill">
        Item 1
</div>

<div>
        Item 2
</div>

</div>

Ordem dos elementos

Bootstrap permite alterar a ordem visual.

Classes

ClasseOrdem
order-1Primeiro
order-2Segundo
order-lastÚltimo

Exemplo

<div class="order-1">

Auto margin

Muito usado em Flexbox.

Exemplo

<div class="ms-auto">

Empurra o elemento para a direita.

Flexbox responsivo

Bootstrap permite Flexbox por breakpoint.

Exemplo

<div class="d-flex flex-column flex-md-row">

Resultado:

  • Mobile → coluna
  • Desktop → linha

Exemplo completo

<div class="container">

<div class="d-flex
                justify-content-between
                align-items-center
                bg-dark
                text-light
                p-3">

<h3>
            GhostGrid
</h3>

<button class="btn btn-primary">

            Entrar

</button>

</div>

</div>
