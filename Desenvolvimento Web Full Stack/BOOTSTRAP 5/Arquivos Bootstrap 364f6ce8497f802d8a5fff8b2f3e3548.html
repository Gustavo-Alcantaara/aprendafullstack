Arquivos Bootstrap

Arquivos que compõem um projeto com Bootstrap

Um projeto utilizando o Bootstrap normalmente é organizado em pastas e arquivos separados para facilitar manutenção, organização e reutilização do código.

Estrutura básica de um projeto

projeto/
│
├── index.html
├── sobre.html
│
├── css/
│   ├── bootstrap.min.css
│   └── style.css
│
├── js/
│   ├── bootstrap.bundle.min.js
│   └── script.js
│
├── img/
│   ├── logo.png
│   └── banner.jpg
│
└── fonts/

Explicação de cada arquivo/pasta

1. Arquivos HTML

Exemplo:

index.html
sobre.html
contato.html

São as páginas do site.

Neles ficam:

  • Estrutura do conteúdo
  • Componentes Bootstrap
  • Textos
  • Imagens
  • Links

Exemplo:

<h1 class="text-primary">Meu Site</h1>

2. Pasta CSS

css/

Armazena arquivos de estilo.

bootstrap.min.css

Arquivo principal do Bootstrap.

Contém:

  • Grid system
  • Botões
  • Cards
  • Utilitários
  • Responsividade
  • Estilos prontos

O .min significa “minificado”, ou seja:

  • Código compactado
  • Mais leve
  • Carregamento mais rápido

style.css

Arquivo criado pelo desenvolvedor para personalizações.

Exemplo:

body{
    background-color: #f5f5f5;
}

Normalmente é importado após o Bootstrap:

<link rel="stylesheet"href="css/bootstrap.min.css">
<link rel="stylesheet"href="css/style.css">

Assim, seus estilos podem sobrescrever os do Bootstrap.

3. Pasta JavaScript

js/

Contém scripts do projeto.

bootstrap.bundle.min.js

Responsável pelos componentes interativos do Bootstrap:

  • Menu responsivo
  • Modal
  • Carousel
  • Dropdown
  • Collapse
  • Tooltips

Sem esse arquivo, vários componentes visuais não funcionam corretamente.

script.js

Arquivo JavaScript do desenvolvedor.

Usado para:

  • Interações personalizadas
  • Eventos
  • Validações
  • Animações
  • Manipulação do DOM

Exemplo:

console.log("Projeto iniciado");

4. Pasta de imagens

img/

Armazena:

  • Logos
  • Ícones
  • Fotos
  • Backgrounds
  • Banners

Exemplo:

<img src="img/logo.png"alt="Logo">

5. Pasta de fontes

fonts/

Usada para:

  • Fontes personalizadas
  • Ícones locais
  • Tipografias externas baixadas

Organização do projeto

Separar arquivos em pastas ajuda a:

  • Facilitar manutenção
  • Melhorar organização
  • Tornar o projeto mais profissional
  • Evitar bagunça no código
  • Facilitar trabalho em equipe

Ordem correta de carregamento

No <head>

<link rel="stylesheet" href="css/bootstrap.min.css">
<link rel="stylesheet" href="css/style.css">

Antes do </body>

<script src="js/bootstrap.bundle.min.js"></script>
<script src="js/script.js"></script>

Bootstrap primeiro, seus arquivos depois.
