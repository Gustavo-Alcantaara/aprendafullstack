Formas de usar o Bootstrap

O Bootstrap pode ser integrado ao projeto de duas maneiras principais:

  • Externa (CDN/link do site)
  • Interna (arquivos baixados)

1. Forma Externa — CDN

CDN (Content Delivery Network) significa usar os arquivos do Bootstrap diretamente da internet.

Você apenas adiciona links no HTML, sem precisar baixar nada.

Vantagens

  • Mais rápido de configurar
  • Não ocupa espaço no projeto
  • Fácil para projetos simples e estudos

Desvantagens

  • Precisa de internet
  • Depende do servidor da CDN

Como usar

Adicione o CSS na <head>

<link
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
rel="stylesheet">

Adicione o JavaScript antes do </body>

<script
src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">
</script>

Exemplo completo

<!DOCTYPE html>
<html lang="pt-br">
<head>
<meta charset="UTF-8">

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<link
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
rel="stylesheet">

<title>Bootstrap CDN</title>
</head>
<body>

<button class="btn btn-primary">
        Botão Bootstrap
</button>

<script
src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">
</script>

</body>
</html>

2. Forma Interna — Arquivos Baixados

Nessa forma, você baixa os arquivos do Bootstrap e coloca dentro do projeto.

Muito usado quando:

  • O projeto precisa funcionar offline
  • Você quer mais controle dos arquivos
  • Ambientes sem internet

Como baixar

Você pode baixar no site oficial:

Bootstrap Official Website

Estrutura dos arquivos

Depois de baixar:

projeto/
│
├── css/
│   └── bootstrap.min.css
│
├── js/
│   └── bootstrap.bundle.min.js
│
├── index.html

Como importar

CSS

<link rel="stylesheet"href="css/bootstrap.min.css">

JavaScript

<script src="js/bootstrap.bundle.min.js"></script>

Exemplo completo

<!DOCTYPE html>
<html lang="pt-br">
<head>
<meta charset="UTF-8">

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<link rel="stylesheet"
href="css/bootstrap.min.css">

<title>Bootstrap Local</title>
</head>
<body>

<h1 class="text-success">
        Bootstrap Local
</h1>

<script src="js/bootstrap.bundle.min.js"></script>

</body>
</html>

Diferença entre as duas formas

CDN (Externa)Arquivos Locais (Interna)
Usa internetFunciona offline
Mais simplesMais controle
Configuração rápidaPrecisa baixar arquivos
Ideal para estudosIdeal para projetos maiores

O que é bootstrap.bundle.min.js

Esse arquivo já inclui:

  • JavaScript do Bootstrap
  • Popper.js (usado em dropdowns, tooltips etc.)

Por isso normalmente ele é o mais usado.
