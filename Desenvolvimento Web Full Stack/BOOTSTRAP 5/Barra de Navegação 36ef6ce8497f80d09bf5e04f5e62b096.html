Barra de Navegação no Bootstrap

A barra de navegação (Navbar) no Bootstrap é um componente usado para criar menus responsivos e organizados em sites e aplicações web.

Ela normalmente contém:

  • Logo
  • Links
  • Menus
  • Botões
  • Campo de busca

O Bootstrap já fornece uma estrutura pronta e responsiva para navegação.

Classe principal

Toda navbar começa com:

<nav class="navbar">

Exemplo básico

<nav class="navbar navbar-light bg-light">

<div class="container">

<a class="navbar-brand"href="#">
            MeuSite
</a>

</div>

</nav>

Navbar responsiva (Hamburger Menu)

Bootstrap possui menu mobile automático.

Exemplo completo responsivo

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">

<div class="container">

<a class="navbar-brand"href="#">
            GhostGrid
</a>

<button class="navbar-toggler"
type="button"
data-bs-toggle="collapse"
data-bs-target="#menu">

<span class="navbar-toggler-icon"></span>

</button>

<div class="collapse navbar-collapse"
id="menu">

<ul class="navbar-nav ms-auto">

<li class="nav-item">
<a class="nav-link"href="#">
                        Home
</a>
</li>

<li class="nav-item">
<a class="nav-link"href="#">
                        Sobre
</a>
</li>

<li class="nav-item">
<a class="nav-link"href="#">
                        Contato
</a>
</li>

</ul>

</div>

</div>

</nav>

Explicação do menu responsivo

navbar-toggler

Botão do menu mobile.

collapse navbar-collapse

Área que será escondida/exibida.

data-bs-toggle

Controla o comportamento do Bootstrap via JavaScript.

Listas Ordenadas

Sim. O Bootstrap também pode ser usado com listas ordenadas, utilizando a tag HTML:

<ol>

A diferença é que a lista ordenada exibe numeração automática.

Exemplo básico

<ol>

<li>HTML</li>
<li>CSS</li>
<li>Bootstrap</li>

</ol>

Resultado:

  1. HTML
  1. CSS
  1. Bootstrap

Bootstrap em listas ordenadas

O Bootstrap não cria uma classe específica apenas para listas ordenadas, mas suas utilidades funcionam normalmente nelas.

Removendo estilos

<ol class="list-unstyled">

Remove:

  • Numeração
  • Espaçamento padrão

Lista inline ordenada

<ol class="list-inline">

<li class="list-inline-item">
        Home
</li>

<li class="list-inline-item">
        Produtos
</li>

</ol>

Os itens ficam em linha.

List Group com numeração

Bootstrap possui uma classe específica para listas numeradas:

<ol class="list-group list-group-numbered">

<li class="list-group-item">
        Primeiro item
</li>

<li class="list-group-item">
        Segundo item
</li>

</ol>

list-group-numbered

Essa classe:

  • Adiciona numeração automática
  • Mantém o visual moderno do List Group

Exemplo completo

<div class="container">

<ol class="list-group list-group-numbered">

<li class="list-group-item">
            Instalar Bootstrap
</li>

<li class="list-group-item">
            Criar estrutura HTML
</li>

<li class="list-group-item">
            Aplicar estilos
</li>

</ol>

</div>

Combinação com cores

<li class="list-group-item list-group-item-success">

Exemplo estilizado

<ol class="list-group list-group-numbered">

<li class="list-group-item active">
        Cadastro
</li>

<li class="list-group-item">
        Pagamento
</li>

<li class="list-group-item">
        Finalização
</li>

</ol>

Diferença entre UL e OL

TagTipo
<ul>Lista não ordenada
<ol>Lista ordenada

Quando usar listas ordenadas

As listas ordenadas são recomendadas para:

  • Passo a passo
  • Rankings
  • Tutoriais
  • Sequências
  • Processos numerados

Vantagens no Bootstrap

  • Visual moderno
  • Numeração automática
  • Responsividade
  • Fácil personalização
  • Integração com List Group
