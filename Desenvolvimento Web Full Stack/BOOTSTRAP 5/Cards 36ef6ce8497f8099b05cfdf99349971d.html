Cards

Cartões (Cards) no Bootstrap

Os cartões (Cards) no Bootstrap são componentes flexíveis usados para organizar conteúdos em blocos visuais.

Eles são muito utilizados para:

  • Produtos
  • Posts
  • Perfis
  • Serviços
  • Dashboards
  • Portfólios

Os cards podem conter:

  • Imagens
  • Títulos
  • Textos
  • Botões
  • Links
  • Listas

Classe principal

Todo card utiliza:

<div class="card">

Estrutura básica

<div class="card">

<div class="card-body">

        Conteúdo

</div>

</div>

card-body

Área principal do conteúdo do cartão.

Exemplo simples

<div class="card"style="width:18rem;">

<div class="card-body">

<h5 class="card-title">

            Bootstrap

</h5>

<p class="card-text">

            Framework front-end.

</p>

</div>

</div>
