Alinhamentos Grid

Alinhamentos no Grid do Bootstrap

O sistema de Grid do Bootstrap utiliza o Flexbox internamente, permitindo alinhar elementos de forma simples e responsiva.

Os alinhamentos no Grid controlam:

  • Posição horizontal
  • Posição vertical
  • Distribuição das colunas
  • Organização do layout

Tipos de alinhamento

Bootstrap possui dois grupos principais:

TipoClasse
Horizontaljustify-content-*
Verticalalign-items-*

Alinhamento horizontal

Controla como as colunas ficam distribuídas na linha (row).

Estrutura

<div class="row justify-content-*">

Classes horizontais

ClasseFunção
justify-content-startInício
justify-content-centerCentro
justify-content-endFinal
justify-content-betweenEspaço entre
justify-content-aroundEspaço ao redor
justify-content-evenlyEspaço igual

Centralizar colunas

<div class="row justify-content-center">

Exemplo

<div class="row justify-content-center">

<div class="col-4">

        Conteúdo

</div>

</div>

A coluna ficará centralizada horizontalmente.

Alinhar à direita

<div class="row justify-content-end">

Espaço entre elementos

<div class="row justify-content-between">

Resultado:

  • Um item fica à esquerda
  • Outro à direita

Espaçamento uniforme

<div class="row justify-content-evenly">

Distribui espaços iguais.

Alinhamento vertical

Controla a posição vertical das colunas dentro da linha.

Estrutura

<div class="row align-items-*">

Classes verticais

ClasseFunção
align-items-startTopo
align-items-centerCentro
align-items-endFinal
align-items-stretchEstica
align-items-baselineLinha base

Centralizar verticalmente

<div class="row align-items-center">

Exemplo

<div class="row
            align-items-center"
style="height:200px;">

<div class="col-4">

        Conteúdo

</div>

</div>

Alinhamento individual

Também é possível alinhar apenas uma coluna.

Estrutura

<div class="col align-self-*">

Classes individuais

ClasseFunção
align-self-startTopo
align-self-centerCentro
align-self-endFinal

Exemplo

<div class="col align-self-end">

Centralização completa

Para centralizar horizontalmente e verticalmente:

<div class="row
            justify-content-center
            align-items-center">

Exemplo completo

<div class="container">

<div class="row
                justify-content-center
                align-items-center"
style="height:300px;">

<div class="col-4">

<div class="bg-primary text-light p-4">

                Conteúdo centralizado

</div>

</div>

</div>

</div>

Alinhamentos responsivos

Bootstrap permite alinhamentos por breakpoint.

Exemplo

<div class="row justify-content-md-center">

Significa:

  • Mobile → alinhamento padrão
  • Médio para cima → centralizado

Exemplos responsivos

ClasseFunção
justify-content-lg-centerCentraliza em telas grandes
align-items-md-centerCentraliza verticalmente em telas médias

Ordem visual com alinhamento

Pode combinar alinhamento com:

  • order-*
  • offset-*
  • mx-auto

Exemplo com auto margin

<div class="col-4 mx-auto">

Centraliza automaticamente.

Classes importantes

ClasseFunção
justify-content-centerCentro horizontal
justify-content-betweenEspaço entre
align-items-centerCentro vertical
align-self-centerCentro individual
mx-autoCentralização automática

Vantagens dos alinhamentos Grid

  • Layout flexível
  • Centralização fácil
  • Responsividade automática
  • Menos CSS manual
  • Compatibilidade com Flexbox
