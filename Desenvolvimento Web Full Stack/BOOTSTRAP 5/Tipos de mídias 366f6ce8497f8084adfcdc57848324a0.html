Tipos de mídias

Tipos de mídias no Bootstrap

No Bootstrap, mídias são elementos visuais e multimídia usados no site, como:

  • Imagens
  • Vídeos
  • Áudios
  • Iframes
  • Conteúdo responsivo

O Bootstrap possui classes utilitárias para deixar essas mídias responsivas e bem organizadas.

Imagens

Bootstrap oferece classes prontas para estilizar imagens.

Imagem responsiva

Classe img-fluid

<img src="img/foto.jpg"class="img-fluid">

Equivale a:

max-width: 100%;
height:auto;

A imagem:

  • Nunca ultrapassa o tamanho do container
  • Redimensiona automaticamente

Imagem com borda arredondada

<img class="rounded">

Imagem circular

<img class="rounded-circle">

Muito usada em:

  • Avatares
  • Perfis
  • Logos

Thumbnail

<img class="img-thumbnail">

Adiciona:

  • Borda
  • Padding
  • Aparência de miniatura

Alinhamento de imagens

Centralizar

<img class="mx-auto d-block">

Float

<img class="float-start">

ou

<img class="float-end">

Vídeos responsivos

Bootstrap possui suporte para vídeos adaptáveis.

Classe ratio

Estrutura:

ratio

Exemplo de vídeo responsivo

<div class="ratio ratio-16x9">

<iframe
src="https://www.youtube.com/embed/VIDEO">
</iframe>

</div>

O vídeo:

  • Mantém proporção
  • Fica responsivo
  • Se adapta à tela

Proporções disponíveis

ClasseProporção
ratio-1x1Quadrado
ratio-4x3Tradicional
ratio-16x9Widescreen
ratio-21x9Ultrawide

Iframes responsivos

Também usados para:

  • Mapas
  • Sites incorporados
  • Players
  • Conteúdos externos

Exemplo:

<div class="ratio ratio-4x3">

<iframe src="https://maps.google.com"></iframe>

</div>

Áudios

Bootstrap não possui estilização própria para áudio, mas pode ser combinado com utilitários.

Exemplo:

<audio controls class="w-100">

Media Object

Versões antigas do Bootstrap possuíam o componente:

media object

Usado para:

  • Comentários
  • Posts
  • Perfis
  • Conteúdo com imagem lateral

Hoje isso normalmente é feito usando:

  • Flexbox
  • Grid

Exemplo moderno com Flexbox

<div class="d-flex">

<img src="img/user.jpg"
class="rounded-circle me-3"
width="80">

<div>

<h5>Usuário</h5>

<p>Comentário...</p>

</div>

</div>

Responsividade das mídias

Bootstrap ajuda a:

  • Evitar imagens quebradas
  • Adaptar vídeos
  • Melhorar visual em celulares
  • Ajustar conteúdos automaticamente

Exemplo completo

<div class="container">

<img src="img/banner.jpg"
class="img-fluid rounded mb-4">

<div class="ratio ratio-16x9">

<iframe
src="https://www.youtube.com/embed/VIDEO">
</iframe>

</div>

</div>

Vantagens das classes de mídia

  • Responsividade automática
  • Menos CSS manual
  • Melhor experiência visual
  • Facilidade no alinhamento
  • Compatibilidade com vários dispositivos
