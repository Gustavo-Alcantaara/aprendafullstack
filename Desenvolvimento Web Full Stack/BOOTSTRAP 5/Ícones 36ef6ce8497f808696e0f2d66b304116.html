Ícones

Ícones no Bootstrap

Os ícones no Bootstrap são usados para representar ações, menus e informações visualmente.

Eles ajudam a:

  • Melhorar a interface
  • Facilitar navegação
  • Deixar o design mais moderno
  • Economizar espaço

O Bootstrap possui a biblioteca oficial chamada:

Bootstrap Icons

O que são Bootstrap Icons?

Bootstrap Icons é uma coleção de ícones SVG criada pela equipe do Bootstrap.

Ela possui:

  • Ícones de interface
  • Redes sociais
  • Navegação
  • Botões
  • Sistemas
  • E-commerce

Como adicionar Bootstrap Icons

Via CDN

Adicionar no <head>:

<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

Estrutura do ícone

<i class="bi bi-nome-do-icone"></i>

Exemplo simples

<i class="bi bi-house"></i>

Ícone de casa.

Exemplo com botão

<button class="btn btn-primary">

<i class="bi bi-search"></i>

    Buscar

</button>

Alterar tamanho

Pode usar CSS:

<i class="bi bi-heart"
style="font-size:40px;">
</i>

Alterar cor

<i class="bi bi-star-fill text-warning"></i>

Usa as classes de cores do Bootstrap.

<span class="input-group-text">

<i class="bi bi-person"></i>

class="form-control">

Ícones animados

Bootstrap Icons não possuem animação própria, mas podem usar:

  • CSS
  • Hover
  • Transform
  • Animate.css

Exemplo com hover

i:hover{

    transform:scale(1.2);

}

Exemplo completo

<!DOCTYPE html>

<html lang="pt-br">

<head>

<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

</head>

<body>

<div class="container mt-4">

<button class="btn btn-success">

<i class="bi bi-check-circle"></i>

        Confirmar

</button>

<button class="btn btn-danger">

<i class="bi bi-trash"></i>

        Excluir

</button>

</div>

</body>
</html>
