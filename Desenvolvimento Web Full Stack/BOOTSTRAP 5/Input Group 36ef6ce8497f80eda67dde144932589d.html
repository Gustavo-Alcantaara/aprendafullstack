Input Group

Input Group no Bootstrap

O Input Group do Bootstrap é um componente usado para combinar campos de formulário com:

  • Textos
  • Ícones
  • Botões
  • Labels
  • Prefixos e sufixos

Ele é muito utilizado para melhorar a aparência e organização dos formulários.

Classe principal

A estrutura básica usa:

<div class="input-group">

Exemplo simples

<div class="input-group">

<span class="input-group-text">
        @
</span>

<input type="text"
class="form-control">

</div>

Resultado

O símbolo @ aparece integrado ao campo de texto.

Muito usado para:

  • Usuário
  • Email
  • Redes sociais
