Float

Float no Bootstrap

No Bootstrap, as classes de float são usadas para posicionar elementos à esquerda ou à direita dentro do layout.

O float vem do CSS tradicional:

float:left;
float:right;

No Bootstrap, isso é feito através de classes prontas.

Classes de Float

ClasseFunção
float-startFlutua à esquerda
float-endFlutua à direita
float-noneRemove o float

Float à esquerda

<div class="float-start">
    Esquerda
</div>

O elemento ficará alinhado no lado esquerdo.

Float à direita

<div class="float-end">
    Direita
</div>

O elemento vai para o lado direito.

Remover float

<div class="float-none">

Remove qualquer flutuação aplicada.

Exemplo prático

<div class="container">

<img src="img/foto.jpg"
class="float-start"
width="200">

<p>
        Texto ao lado da imagem...
</p>

</div>

A imagem ficará à esquerda e o texto se ajustará ao redor dela.

Float responsivo

Bootstrap permite aplicar float dependendo do tamanho da tela.

Estrutura:

float-breakpoint-direção

Exemplos

Float apenas em telas médias

<div class="float-md-end">

Significa:

  • Celular → sem float
  • Tablet/Desktop → float à direita

Exemplos responsivos

ClasseFuncionamento
float-sm-startFloat à esquerda em telas pequenas
float-md-endFloat à direita em telas médias
float-lg-noneRemove float em telas grandes

Clearfix

Quando usamos float, às vezes o elemento pai “perde” altura.

Bootstrap resolve isso com:

<div class="clearfix">

Exemplo:

<div class="clearfix">

<div class="float-start">
        Esquerda
</div>

<div class="float-end">
        Direita
</div>

</div>

O clearfix corrige problemas de layout.

Float vs Flexbox

Atualmente, o Float é menos usado para layouts completos.

Hoje o mais recomendado é:

  • Flexbox
  • CSS Grid

O float ainda é útil para:

  • Imagens ao lado de texto
  • Pequenos alinhamentos
  • Compatibilidade com layouts antigos

Comparação

FloatFlexbox
Mais antigoMais moderno
Menos flexívelMais poderoso
Bom para textos/imagensMelhor para layouts
Pode causar bugsMais organizado

Exemplo moderno com Flexbox

Em vez de:

<div class="float-end">

Hoje normalmente usa-se:

<div class="d-flex justify-content-end">

Exemplo completo

<div class="container clearfix">

<button class="btn btn-primary float-start">
        Voltar
</button>

<button class="btn btn-success float-end">
        Avançar
</button>

</div>

Vantagens das classes Float

  • Fácil alinhamento rápido
  • Menos CSS manual
  • Responsividade integrada
  • Útil para elementos simples
  • Compatível com layouts antigos
