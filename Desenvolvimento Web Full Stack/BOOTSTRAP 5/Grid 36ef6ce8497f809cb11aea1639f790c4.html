Grid System no Bootstrap

O Grid System do Bootstrap é um sistema de layout responsivo baseado em linhas e colunas.

Ele é usado para organizar elementos na página de forma flexível e adaptável a diferentes tamanhos de tela.

O Grid do Bootstrap funciona com:

  • Containers
  • Rows
  • Columns

Estrutura básica

<div class="container">

<div class="row">

<div class="col">

</div>

</div>

</div>

Componentes principais

ClasseFunção
containerÁrea principal
rowLinha
colColuna

Como funciona

O Bootstrap divide a tela em:

12 colunas

Você pode distribuir essas colunas como quiser.

Exemplo simples

<div class="row">

<div class="col">

        Coluna 1

</div>

<div class="col">

        Coluna 2

</div>

</div>

Resultado:

  • 2 colunas com largura igual

Colunas específicas

Você pode definir quantas colunas cada elemento ocupa.

Exemplo

<div class="row">

<div class="col-4">

        4 colunas

</div>

<div class="col-8">

        8 colunas

</div>

</div>

Total:

  • 4 + 8 = 12

Exemplo visual

|----4----|--------8--------|

Breakpoints responsivos

Bootstrap permite definir tamanhos para cada tela.

Estrutura

col-breakpoint-tamanho

Exemplo

<div class="col-md-6">

Significa:

  • Mobile → ocupa largura total
  • Médio para cima → 6 colunas

Principais breakpoints

ClasseTela
col-sm-*≥ 576px
col-md-*≥ 768px
col-lg-*≥ 992px
col-xl-*≥ 1200px
col-xxl-*≥ 1400px

Exemplo responsivo

<div class="row">

<div class="col-12 col-md-6">

        Coluna 1

</div>

<div class="col-12 col-md-6">

        Coluna 2

</div>

</div>

Resultado:

  • Mobile → uma embaixo da outra
  • Desktop → lado a lado

Colunas automáticas

<div class="col">

Bootstrap divide automaticamente o espaço disponível.

Espaçamento entre colunas

Bootstrap usa:

g

De:

  • gap
  • gutter

Exemplo

<div class="row g-3">

Níveis de espaçamento

ClasseEspaço
g-0Sem espaço
g-1 até g-5Espaçamento crescente

Espaçamento horizontal e vertical

ClasseFunção
gx-*Horizontal
gy-*Vertical

Exemplo

<div class="row gx-5 gy-3">

Alinhamento vertical

Centralizar verticalmente

<div class="row align-items-center">

Alinhamento horizontal

<div class="row justify-content-center">

Grid aninhado

Você pode colocar grids dentro de grids.

Exemplo

<div class="row">

<div class="col-6">

<div class="row">

<div class="col">

                Subcoluna

</div>

</div>

</div>

</div>

Exemplo completo

<div class="container mt-4">

<div class="row g-3">

<div class="col-12 col-md-6 col-lg-4">

<div class="bg-primary text-light p-3">

                Coluna 1

</div>

</div>

<div class="col-12 col-md-6 col-lg-4">

<div class="bg-success text-light p-3">

                Coluna 2

</div>

</div>

<div class="col-12 col-lg-4">

<div class="bg-dark text-light p-3">

                Coluna 3

</div>

</div>

</div>

</div>
