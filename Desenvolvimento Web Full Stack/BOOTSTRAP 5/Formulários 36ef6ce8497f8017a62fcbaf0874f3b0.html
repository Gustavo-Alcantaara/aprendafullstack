Formulários no Bootstrap

Os formulários no Bootstrap permitem criar interfaces modernas, organizadas e responsivas para entrada de dados.

O Bootstrap fornece estilos prontos para:

  • Inputs
  • Labels
  • Selects
  • Checkboxes
  • Radios
  • Botões
  • Validação
  • Layout responsivo

Estrutura básica

Um formulário HTML comum:

<form>

</form>

No Bootstrap, usamos classes para estilização.

Campo de texto

A principal classe é:

class="form-control"

Exemplo

<form>

<label class="form-label">
        Nome
</label>

<input type="text"
class="form-control">

</form>

form-control

Aplica:

  • Largura responsiva
  • Padding
  • Bordas
  • Estilo moderno

Labels

<label class="form-label">

Melhora:

  • Organização
  • Espaçamento
  • Legibilidade

Placeholder

<input type="email"
class="form-control"
placeholder="Digite seu email">

Tipos de input

TipoUso

Campo de senha

<input type="password"
class="form-control">

Textarea

<textarea class="form-control"></textarea>

Usado para:

  • Mensagens
  • Comentários
  • Descrições

Select

<select class="form-select">

<option>HTML</option>
<option>Bootstrap</option>

</select>

Checkbox

<div class="form-check">

<input class="form-check-input"
type="checkbox">

<label class="form-check-label">

        Aceito os termos

</label>

</div>

Radio Button

<div class="form-check">

<input class="form-check-input"
type="radio"
name="sexo">

<label class="form-check-label">

        Masculino

</label>

</div>

Switch

Bootstrap possui interruptor estilo mobile.

<div class="form-check form-switch">

<input class="form-check-input"
type="checkbox">

</div>

Input Group

Permite adicionar:

  • Ícones
  • Texto
  • Botões

Exemplo

<div class="input-group">

<span class="input-group-text">
        @
</span>

<input type="text"
class="form-control">

</div>

Formulário responsivo

Bootstrap usa Grid System.

Exemplo

<div class="row">

<div class="col-md-6">

<input type="text"
class="form-control">

</div>

<div class="col-md-6">

<input type="email"
class="form-control">

</div>

</div>

Botões no formulário

<button class="btn btn-primary">
    Enviar
</button>

Validação

Campo válido

<input class="form-control is-valid">

Campo inválido

<input class="form-control is-invalid">

Mensagem de feedback

<div class="invalid-feedback">

    Campo obrigatório

</div>
