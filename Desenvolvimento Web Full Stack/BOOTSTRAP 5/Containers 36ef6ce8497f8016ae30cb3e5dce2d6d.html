Containers

Containers no Bootstrap

Os containers no Bootstrap são estruturas usadas para organizar e centralizar o conteúdo da página.

Eles funcionam como a base do layout responsivo do Bootstrap.

Os containers ajudam a:

  • Centralizar conteúdo
  • Controlar largura
  • Criar espaçamento
  • Organizar grids e componentes

Classe principal

O container básico usa:

<div class="container">

Exemplo simples

<div class="container">

<h1>
        Meu Site
</h1>

</div>

Como funciona

O container:

  • Centraliza o conteúdo
  • Adiciona padding lateral
  • Ajusta largura automaticamente conforme a tela

Tipos de containers

Bootstrap possui vários tipos.

ClasseFunção
containerResponsivo com largura fixa
container-fluidLargura total
container-smResponsivo a partir do small
container-mdResponsivo a partir do medium
container-lgResponsivo a partir do large
container-xlResponsivo a partir do extra large
container-xxlMuito grandes

1. Container padrão

<div class="container">

Possui largura máxima variável conforme o breakpoint.

2. Container Fluid

<div class="container-fluid">

Ocupa:

  • 100% da largura da tela

Muito usado em:

  • Hero sections
  • Layouts modernos
  • Backgrounds

Exemplo

<div class="container-fluid bg-dark text-light">

    Conteúdo

</div>

3. Containers responsivos

Bootstrap permite definir quando o container começa a ter largura fixa.

Exemplo

<div class="container-md">

Significa:

  • Pequenas telas → largura total
  • A partir de md → largura fixa centralizada

Breakpoints dos containers

ClasseBreakpoint
container-sm≥ 576px
container-md≥ 768px
container-lg≥ 992px
container-xl≥ 1200px
container-xxl≥ 1400px

Container com Grid

Muito usado junto com:

  • row
  • col

Exemplo

<div class="container">

<div class="row">

<div class="col">

            Coluna 1

</div>

<div class="col">

            Coluna 2

</div>

</div>

</div>

Container com espaçamento

Pode usar:

  • Margin
  • Padding
  • Background
  • Flexbox

Exemplo:

<div class="container p-5 bg-light">

Container centralizado

O container já centraliza automaticamente o conteúdo horizontalmente.

Exemplo completo

<div class="container mt-5">

<h1 class="text-primary">

        Bootstrap

</h1>

<p>

        Exemplo de container responsivo.

</p>

<button class="btn btn-success">

        Acessar

</button>

</div>

Diferença entre container e container-fluid

ClasseLargura
containerLimitada e centralizada
container-fluid100% da tela

Quando usar cada um

container

Ideal para:

  • Sites institucionais
  • Blogs
  • Formulários
  • Dashboards

container-fluid

Ideal para:

  • Layouts modernos
  • Seções grandes
  • Landing pages
  • Backgrounds amplos

Vantagens dos containers Bootstrap

  • Responsividade automática
  • Organização do layout
  • Centralização fácil
  • Compatibilidade com Grid System
  • Menos CSS manual
