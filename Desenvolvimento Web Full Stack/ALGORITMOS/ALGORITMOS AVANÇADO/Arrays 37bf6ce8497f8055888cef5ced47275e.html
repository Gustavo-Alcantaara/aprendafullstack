Arrays

O que são Arrays?

Um Array (vetor ou matriz unidimensional) é uma estrutura de dados utilizada para armazenar múltiplos valores em uma única variável.

Em vez de criar várias variáveis para guardar informações relacionadas, podemos armazená-las em um único array e acessar cada elemento por meio de sua posição (índice).

Sem Arrays

let nome1 = "João";
let nome2 = "Maria";
let nome3 = "Pedro";

Com Array

let nomes = ["João", "Maria", "Pedro"];

O segundo exemplo é mais organizado, fácil de manipular e escalável.

Por que utilizar Arrays?

Os arrays são utilizados para armazenar conjuntos de dados relacionados, como:

  • Lista de alunos;
  • Produtos de uma loja;
  • Notas de uma prova;
  • Mensagens de um chat;
  • Números para cálculos;
  • Resultados de pesquisas.

Praticamente todo sistema utiliza arrays de alguma forma.

Estrutura de um Array

Um array é formado por elementos armazenados em posições numeradas chamadas índices.

Exemplo:

let frutas = ["Maçã", "Banana", "Laranja"];

Representação:

Índice     Valor

0          Maçã
1          Banana
2          Laranja

Observe que os índices começam em 0, não em 1.

Criando Arrays

Utilizando colchetes

A forma mais comum:

let numeros = [10, 20, 30, 40];

Array vazio

let lista = [];

Utilizando o construtor Array

let nomes = new Array("Ana", "Carlos", "Pedro");

Embora funcione, a sintaxe com colchetes é a mais utilizada.

Acessando Elementos

Para acessar um elemento, informamos seu índice.

let cores = ["Azul", "Verde", "Vermelho"];

console.log(cores[0]);

Resultado:

Azul
console.log(cores[2]);

Resultado:

Vermelho

Alterando Valores

Podemos modificar qualquer posição.

let frutas = ["Maçã", "Banana", "Laranja"];

frutas[1] = "Uva";

console.log(frutas);

Resultado:

["Maçã", "Uva", "Laranja"]

Descobrindo o Tamanho do Array

Utilizamos a propriedade length.

let numeros = [10, 20, 30, 40];

console.log(numeros.length);

Resultado:

4

Percorrendo Arrays

Utilizando for

let frutas = ["Maçã", "Banana", "Laranja"];

for(let i = 0; i < frutas.length; i++) {
    console.log(frutas[i]);
}

Resultado:

Maçã
Banana
Laranja

Utilizando for...of

for(let fruta of frutas) {
    console.log(fruta);
}

Resultado:

Maçã
Banana
Laranja

O for...of é mais simples quando precisamos apenas dos valores.

Utilizando forEach

frutas.forEach(function(fruta) {
    console.log(fruta);
});

Ou com Arrow Function:

frutas.forEach(fruta => console.log(fruta));

Principais Métodos de Arrays

push()

Adiciona um elemento ao final.

let numeros = [1, 2, 3];

numeros.push(4);

console.log(numeros);

Resultado:

[1, 2, 3, 4]

pop()

Remove o último elemento.

numeros.pop();

Resultado:

[1, 2, 3]

unshift()

Adiciona no início.

numeros.unshift(0);

Resultado:

[0, 1, 2, 3]

shift()

Remove o primeiro elemento.

numeros.shift();

Resultado:

[1, 2, 3]

includes()

Verifica se um valor existe.

let nomes = ["Ana", "Carlos", "Pedro"];

console.log(nomes.includes("Carlos"));

Resultado:

true

indexOf()

Retorna a posição de um elemento.

console.log(nomes.indexOf("Pedro"));

Resultado:

2

Se não existir:

-1

join()

Transforma um array em string.

let letras = ["A", "B", "C"];

console.log(letras.join("-"));

Resultado:

A-B-C

reverse()

Inverte a ordem.

let numeros = [1, 2, 3];

numeros.reverse();

console.log(numeros);

Resultado:

[3, 2, 1]

sort()

Ordena os elementos.

let nomes = ["Carlos", "Ana", "Pedro"];

nomes.sort();

console.log(nomes);

Resultado:

["Ana", "Carlos", "Pedro"]

Arrays de Números

let notas = [7.5, 8.0, 9.2, 6.8];

Podemos realizar cálculos:

let soma = 0;

for(let nota of notas) {
    soma += nota;
}

let media = soma / notas.length;

console.log(media);

Arrays de Objetos

Muito comuns em aplicações reais.

let alunos = [
    {nome: "Ana", nota: 8},
    {nome: "Carlos", nota: 7},
    {nome: "Pedro", nota: 9}
];

Acessando:

console.log(alunos[0].nome);

Resultado:

Ana

Arrays Multidimensionais

Um array pode conter outros arrays.

let matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

Representação:

1 2 3
4 5 6
7 8 9

Acessando:

console.log(matriz[1][2]);

Resultado:

6

Vantagens dos Arrays

  • Fáceis de utilizar;
  • Permitem armazenar muitos dados;
  • Acesso rápido por índice;
  • Amplamente suportados por linguagens de programação;
  • Possuem diversos métodos prontos.

Desvantagens dos Arrays

  • Buscas podem ser lentas em arrays grandes;
  • Inserções e remoções no início são custosas;
  • Tamanho pode se tornar um problema em algumas linguagens;
  • Nem sempre são a melhor estrutura para grandes volumes de dados.

Aplicações dos Arrays

Os arrays estão presentes em praticamente todos os sistemas:

  • Listas de usuários;
  • Carrinhos de compras;
  • Catálogos de produtos;
  • Jogos;
  • Sistemas bancários;
  • Redes sociais;
  • Bancos de dados em memória;
  • Algoritmos de ordenação e busca.

Resumo

Os Arrays são estruturas de dados que permitem armazenar múltiplos valores em uma única variável, organizados por índices numéricos. Eles são uma das estruturas mais importantes da programação, servindo como base para algoritmos, estruturas de dados mais avançadas e aplicações do mundo real. Em JavaScript, os arrays oferecem diversos métodos que facilitam a manipulação, busca, ordenação e processamento de dados, tornando-os uma ferramenta indispensável para qualquer programador.
