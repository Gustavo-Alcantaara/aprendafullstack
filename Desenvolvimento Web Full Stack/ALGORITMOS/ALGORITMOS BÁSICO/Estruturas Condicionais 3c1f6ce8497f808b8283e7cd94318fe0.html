Estruturas Condicionais

Estruturas Condicionais

As estruturas condicionais são mecanismos utilizados em algoritmos para permitir que um programa tome decisões de acordo com determinadas condições.

Na vida real, constantemente tomamos decisões baseadas em condições:

Se estiver chovendo, levo um guarda-chuva.
Se a nota for maior ou igual a 7, o aluno será aprovado.
Se o usuário informar a senha correta, o acesso será permitido.

Nos algoritmos, esse mesmo conceito é representado por estruturas condicionais.

1. O que são estruturas condicionais?

Uma estrutura condicional permite que o algoritmo avalie uma condição e escolha qual instrução deverá ser executada.

A estrutura básica pode ser representada assim:

SE condição ENTÃO
    instruções
FIMSE

O algoritmo verifica a condição.

  • Se for verdadeira, executa as instruções.
  • Se for falsa, não executa essas instruções.

Por exemplo:

se idade >= 18 então
    escreva("Maior de idade.")
fimse

Se idade for 20:

20 >= 18

Resultado:

Verdadeiro

Então será exibido:

Maior de idade.

2. Por que utilizar estruturas condicionais?

Sem estruturas condicionais, um algoritmo teria muita dificuldade para reagir de maneira diferente dependendo dos dados recebidos.

Imagine um sistema de notas.

Sem uma condição, o programa poderia simplesmente exibir:

Aluno aprovado.

para todos os alunos.

Com uma estrutura condicional:

se media >= 7 então
    escreva("Aprovado.")
senao
    escreva("Reprovado.")
fimse

o programa consegue analisar a média e tomar uma decisão automaticamente.

3. Condições

Uma condição é uma expressão que pode produzir:

  • Verdadeiro
  • Falso

Normalmente, utilizamos operadores relacionais e operadores lógicos para construir essas condições.

Exemplo:

idade >= 18

Outro exemplo:

nota >= 7

Com operador lógico:

nota >= 7 E frequencia >= 75

A condição pode ser simples ou composta.

4. Estrutura SE

A estrutura SE é a forma mais básica de estrutura condicional.

Sua função é executar um conjunto de instruções somente quando uma condição for verdadeira.

Sintaxe:

se condição então
    instruções
fimse

Exemplo:

se idade >= 18 então
    escreva("Você é maior de idade.")
fimse

Se idade for 21:

21 >= 18

é verdadeiro.

Portanto:

Você é maior de idade.

será exibido.

5. O que acontece quando a condição é falsa?

Se a condição for falsa, o bloco do SE simplesmente não será executado.

Exemplo:

idade <- 15

se idade >= 18 então
    escreva("Maior de idade.")
fimse

A condição:

15 >= 18

é falsa.

Portanto, nada será exibido pelo SE.

Essa é uma característica importante:

O SE sozinho executa alguma coisa apenas quando a condição é verdadeira.

6. Estrutura SE...SENÃO

Quando queremos executar uma ação quando a condição é verdadeira e outra ação quando ela é falsa, utilizamos SENÃO.

Estrutura:

se condição então
    instruções quando verdadeiro
senao
    instruções quando falso
fimse

Exemplo:

se idade >= 18 então
    escreva("Maior de idade.")
senao
    escreva("Menor de idade.")
fimse

Se:

idade = 20

resultado:

Maior de idade.

Se:

idade = 15

resultado:

Menor de idade.

7. Exemplo com notas

Um exemplo muito comum é verificar se um aluno foi aprovado.

algoritmo "Aprovacao"

var
    nota: real

inicio
    escreva("Digite a nota: ")
    leia(nota)

    se nota >= 7 então
        escreva("Aluno aprovado.")
    senao
        escreva("Aluno reprovado.")
    fimse

fimalgoritmo

Se o usuário informar:

8

o algoritmo verifica:

8 >= 7

Resultado:

Verdadeiro

Então:

Aluno aprovado.

Se informar:

5

temos:

5 >= 7

Resultado:

Falso

Então:

Aluno reprovado.

8. Condições encadeadas

Existem situações em que apenas duas possibilidades não são suficientes.

Por exemplo, imagine um sistema de classificação de notas:

  • 0 a 4,9 → Reprovado
  • 5 a 6,9 → Recuperação
  • 7 a 10 → Aprovado

Nesse caso, podemos utilizar várias condições.

se nota >= 7 então
    escreva("Aprovado.")
senao se nota >= 5 então
    escreva("Recuperação.")
senao
    escreva("Reprovado.")
fimse

O algoritmo testa as condições em sequência.

9. Como funciona o SENÃO SE

Considere:

nota = 6

Primeiro:

nota >= 7

é falso.

Então o algoritmo verifica:

nota >= 5

que é verdadeiro.

Resultado:

Recuperação.

Se:

nota = 8

a primeira condição já será verdadeira:

8 >= 7

Então o programa executará:

Aprovado.

e não precisará executar as condições seguintes.

10. Múltiplas condições

Podemos combinar operadores relacionais e lógicos dentro de uma estrutura condicional.

Por exemplo:

se idade >= 18 E possuiDocumento então
    escreva("Entrada permitida.")
senao
    escreva("Entrada negada.")
fimse

Nesse caso, duas condições precisam ser verdadeiras:

idade >= 18

e:

possuiDocumento

O operador E determina que ambas precisam ser verdadeiras.

11. Utilizando OU

Também podemos utilizar o operador OU.

Exemplo:

se idade < 18 OU idade > 60 então
    escreva("Desconto especial.")
fimse

Nesse caso, basta uma das condições ser verdadeira.

Se:

idade = 15

temos:

15 < 18 → Verdadeiro

Então o desconto será aplicado.

Se:

idade = 70

temos:

70 > 60 → Verdadeiro

Também será aplicado.

12. Utilizando NÃO

O operador NÃO pode inverter uma condição.

Exemplo:

se nao autorizado então
    escreva("Acesso negado.")
fimse

Se autorizado for:

falso

então:

nao autorizado

será:

verdadeiro

e o acesso será negado.

13. Estruturas condicionais aninhadas

Uma estrutura condicional pode existir dentro de outra estrutura condicional.

Isso é chamado de condicional aninhada.

Exemplo:

se idade >= 18 então

    se possuiDocumento então
        escreva("Entrada permitida.")
    senao
        escreva("Documento necessário.")
    fimse

senao
    escreva("Menor de idade.")
fimse

O algoritmo primeiro verifica a idade.

Se a pessoa for maior de idade, ele realiza uma segunda verificação:

possuiDocumento

Isso permite criar regras mais detalhadas.

14. Exemplo de condicional aninhada

Imagine um sistema de login:

se usuarioExiste então

    se senhaCorreta então
        escreva("Login realizado.")
    senao
        escreva("Senha incorreta.")
    fimse

senao
    escreva("Usuário não encontrado.")
fimse

Existem duas etapas:

Primeira condição

usuarioExiste

Segunda condição

senhaCorreta

Somente se o usuário existir será necessário verificar a senha.

15. Estrutura ESCOLHA/CASO

Além do SE, alguns pseudocódigos possuem uma estrutura chamada ESCOLHA, CASO ou SWITCH.

Ela é utilizada quando precisamos comparar uma variável com vários valores específicos.

Por exemplo, um menu:

escolha opcao

    caso 1:
        escreva("Cadastrar usuário.")

    caso 2:
        escreva("Consultar usuário.")

    caso 3:
        escreva("Excluir usuário.")

    caso contrario:
        escreva("Opção inválida.")

fimescolha

Se:

opcao = 2

será executado:

Consultar usuário.

16. Quando usar SE e quando usar ESCOLHA

As duas estruturas podem realizar decisões, mas possuem usos diferentes.

SE

É mais apropriado para condições e comparações:

se idade >= 18 então

ou:

se nota >= 7 E frequencia >= 75 então

ESCOLHA/CASO

É mais apropriado quando temos vários valores específicos:

caso 1
caso 2
caso 3
caso 4

Por exemplo:

escolha opcao
    caso 1:
        ...
    caso 2:
        ...
    caso 3:
        ...
fimescolha

17. Estruturas condicionais em fluxogramas

As estruturas condicionais também podem ser representadas por fluxogramas.

O elemento mais importante é o losango, que representa uma decisão.

A lógica pode ser representada assim:

       Início
          |
          v
   [Verificar condição]
       /          \
    Sim            Não
     |              |
     v              v
 [Ação 1]        [Ação 2]
     |              |
     \______  ______/
            \/
           Fim

Por exemplo:

        Início
          |
          v
      idade >= 18?
       /       \
     Sim       Não
      |          |
      v          v
   Adulto     Menor
      \          /
       \        /
         Fim

O fluxograma facilita a visualização do caminho que o algoritmo seguirá.

18. Estruturas condicionais e fluxo de execução

Normalmente, um algoritmo executa as instruções de cima para baixo.

Por exemplo:

leia(idade)

se idade >= 18 então
    escreva("Adulto.")
senao
    escreva("Menor.")
fimse

escreva("Fim.")

Se idade = 20, a execução será:

1. Receber idade
2. Verificar idade >= 18
3. Executar "Adulto"
4. Executar "Fim"

Se idade = 15:

1. Receber idade
2. Verificar idade >= 18
3. Executar "Menor"
4. Executar "Fim"

Portanto, a estrutura condicional altera o caminho de execução do algoritmo.

19. Exemplo completo: classificação de idade

algoritmo "Classificacao"

var
    idade: inteiro

inicio

    escreva("Digite sua idade: ")
    leia(idade)

    se idade < 12 então
        escreva("Criança.")

    senao se idade < 18 então
        escreva("Adolescente.")

    senao se idade < 60 então
        escreva("Adulto.")

    senao
        escreva("Idoso.")

    fimse

fimalgoritmo

Se o usuário informar:

10

resultado:

Criança.

Se informar:

15

resultado:

Adolescente.

Se informar:

30

resultado:

Adulto.

Se informar:

70

resultado:

Idoso.

20. Validação de dados

Uma das aplicações mais importantes das estruturas condicionais é a validação de informações.

Por exemplo, verificar se uma idade é válida:

se idade < 0 OU idade > 120 então
    escreva("Idade inválida.")
senao
    escreva("Idade válida.")
fimse

Outro exemplo:

se senha == "" então
    escreva("A senha não pode ficar vazia.")
fimse

Ou:

se salario <= 0 então
    escreva("Salário inválido.")
fimse

Isso é muito importante em sistemas reais porque impede que informações incorretas sejam processadas.

21. Estruturas condicionais em problemas reais

As estruturas condicionais aparecem em praticamente todos os sistemas.

Sistema bancário

se saldo >= valorSaque então
    realizarSaque()
senao

fimse

Loja virtual

se estoque > 0 então
    permitirCompra()
senao

Sistema escolar

    aprovado()
senao
    reprovado()
fimse

Sistema de login

    permitirAcesso()

se valorCompra >= 500 então
    desconto <- 10%

fimse

22. Erros comuns

22.1 Confundir = com ==

Em várias linguagens:

=

é usado para atribuição, enquanto:

==

é usado para comparação de igualdade.

Por exemplo:

idade = 18

pode significar atribuição dependendo da linguagem.

Já:

idade == 18

normalmente significa:

Verificar se idade é igual a 18.

22.2 Esquecer os limites

Considere:

se nota > 7 então

Isso significa que uma nota exatamente igual a 7 não será aceita.

Se a intenção é aceitar 7, devemos utilizar:

se nota >= 7 então

Essa diferença é pequena na escrita, mas pode alterar completamente o resultado do algoritmo.

22.3 Criar condições desnecessariamente complexas

Uma condição como:

se idade >= 18 E idade > 20 E idade > 30 então

pode indicar uma lógica mal planejada.

É importante analisar se todas as condições realmente são necessárias.

22.4 Não utilizar parênteses quando necessário

Em condições complexas, os parênteses podem tornar a lógica muito mais clara.

Em vez de:

idade >= 18 E possuiDocumento OU autorizado

podemos escrever:

(idade >= 18 E possuiDocumento) OU autorizado

Assim, fica mais fácil entender a intenção.

23. Vantagens das estruturas condicionais

As estruturas condicionais permitem:

  • Tomar decisões automaticamente;
  • Criar diferentes caminhos de execução;
  • Validar dados;
  • Implementar regras de negócio;
  • Criar sistemas mais inteligentes;
  • Responder a diferentes situações;
  • Controlar o comportamento do programa;
  • Evitar operações inválidas.

25. Resumo final

As estruturas condicionais são responsáveis por permitir que um algoritmo tome decisões com base em condições.

A estrutura mais básica é:

se condição então
    ação
fimse

Quando existem duas possibilidades:

se condição então
    ação 1
senao
    ação 2
fimse

Quando existem várias possibilidades:

se condição1 então
    ação 1
senao se condição2 então
    ação 2
senao
    ação 3
fimse

E quando temos vários valores específicos, podemos utilizar:

escolha valor
    caso 1:
        ação 1
    caso 2:
        ação 2
    caso 3:
        ação 3
fimescolha

Portanto, as estruturas condicionais são uma das bases da lógica de programação. Elas transformam um algoritmo de uma simples sequência de instruções em um sistema capaz de analisar situações, escolher caminhos e executar ações diferentes de acordo com os dados recebidos.
