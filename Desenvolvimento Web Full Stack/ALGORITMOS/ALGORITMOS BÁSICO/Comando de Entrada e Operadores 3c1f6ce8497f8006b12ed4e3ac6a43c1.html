Comando de Entrada e Operadores

Em Algoritmos, os comandos de entrada e os operadores são conceitos fundamentais para construir programas capazes de receber informações, processá-las e produzir resultados.

De maneira simplificada, podemos pensar em um algoritmo como um processo:

Entrada → Processamento → Saída

  • Entrada: recebe os dados fornecidos pelo usuário.
  • Processamento: utiliza operadores e outras instruções para manipular os dados.
  • Saída: apresenta o resultado ao usuário.

1. Comando de Entrada

O comando de entrada é utilizado para permitir que um algoritmo receba dados externos, normalmente fornecidos pelo usuário.

Esses dados podem ser:

  • Números inteiros;
  • Números reais;
  • Textos;
  • Caracteres;
  • Valores lógicos (verdadeiro ou falso).

Por exemplo, imagine um algoritmo que calcula a soma de dois números. Antes de realizar a soma, precisamos receber esses dois números.

Exemplo em pseudocódigo

algoritmo "Soma"

var
   numero1, numero2, resultado: inteiro

inicio
   leia(numero1)
   leia(numero2)

   resultado <- numero1 + numero2

   escreva(resultado)
fimalgoritmo

Nesse exemplo:

  1. leia(numero1) recebe o primeiro número.
  1. leia(numero2) recebe o segundo número.
  1. numero1 + numero2 realiza a soma.
  1. escreva(resultado) apresenta o resultado.

2. A instrução leia

Em muitos ambientes de pseudocódigo, especialmente no Portugol, utiliza-se o comando:

leia()

para receber informações.

Exemplo

leia(nome)

O algoritmo aguarda o usuário informar um valor e armazena esse valor na variável nome.

Outro exemplo:

leia(idade)

Se o usuário digitar:

21

a variável idade passará a armazenar o valor 21.

3. Entrada de vários valores

Podemos utilizar vários comandos de entrada:

leia(nome)
leia(idade)
leia(cidade)

Ou, dependendo do pseudocódigo utilizado:

leia(nome, idade, cidade)

O objetivo é o mesmo: obter dados para que o algoritmo possa trabalhar com eles.

4. Exemplo prático de entrada

Considere um algoritmo que calcula a média de um aluno.

algoritmo "Media"

var
   nota1, nota2, media: real

inicio
   leia(nota1)
   leia(nota2)

   media <- (nota1 + nota2) / 2

   escreva("Média: ", media)
fimalgoritmo

Se o usuário informar:

Nota 1: 8
Nota 2: 6

O algoritmo executará:

media = (8 + 6) / 2
media = 14 / 2
media = 7

Resultado:

Média: 7

Observe que o comando de entrada apenas recebe os dados. O cálculo é realizado posteriormente utilizando operadores.

5. O que são operadores?

Os operadores são símbolos ou palavras utilizados para realizar operações sobre valores e variáveis.

Eles permitem que um algoritmo:

  • Faça cálculos;
  • Compare valores;
  • Tome decisões;
  • Combine condições;
  • Modifique valores;
  • Realize operações lógicas.

Por exemplo:

10 + 5

O símbolo + é um operador aritmético.

O resultado é:

15

6. Principais tipos de operadores

Em algoritmos, os principais tipos são:

  1. Operadores aritméticos
  1. Operadores relacionais
  1. Operadores lógicos
  1. Operadores de atribuição

Cada grupo possui uma finalidade diferente.

7. Operadores aritméticos

Os operadores aritméticos são utilizados para realizar operações matemáticas.

Módulo ou resto da divisão

O operador % retorna o resto de uma divisão inteira.

resultado <- 10 % 3

Como:

10 ÷ 3 = 3

com resto:

1

então:

resultado = 1

Esse operador é muito utilizado para descobrir se um número é par ou ímpar.

Exemplo:

numero <- 8

se numero % 2 = 0 então
   escreva("Número par")
fimse

Como 8 % 2 é 0, o número é par.

Os operadores relacionais são utilizados para comparar valores.

O resultado de uma comparação normalmente será um valor lógico:

verdadeiro

ou

falso

9. Operadores lógicos

Os operadores lógicos permitem combinar ou modificar condições.

Os principais são:

  • E (E / AND)
  • OU (OU / OR)
  • NÃO (NÃO / NOT)

9.1 Operador E

O operador E exige que todas as condições sejam verdadeiras.

Exemplo:

idade >= 18 E possui_carteira = verdadeiro

Para o resultado ser verdadeiro:

  • A pessoa precisa ter 18 anos ou mais;
  • E precisa possuir carteira.

Tabela:

FVF
FFF

9.2 Operador OU

O operador OU retorna verdadeiro quando pelo menos uma condição é verdadeira.

Exemplo:

idade < 12 OU idade > 60

Nesse caso, a condição será verdadeira se:

  • A pessoa tiver menos de 12 anos; ou
  • tiver mais de 60 anos.

Tabela:

9.3 Operador NÃO

O operador NÃO inverte o resultado lógico.

Se:

verdadeiro

passa a ser:

falso

E vice-versa.

Exemplo:

nao aprovado

Se aprovado for verdadeiro:

NÃO verdadeiro = falso

10. Operador de atribuição

O operador de atribuição é utilizado para armazenar um valor dentro de uma variável.

Em pseudocódigo, é comum utilizar:

<-

Por exemplo:

idade <- 21

Isso significa:

A variável idade recebe o valor 21.

Outro exemplo:

nome <- "Gusta"

Agora nome contém:

"Gusta"

Também podemos atribuir o resultado de uma operação:

soma <- numero1 + numero2

Nesse caso, o algoritmo calcula:

numero1 + numero2

e armazena o resultado na variável soma.

11. Diferença entre atribuição e comparação

Essa é uma distinção muito importante em programação.

Atribuição

idade <- 21

Significa:

Coloque 21 dentro de idade.

Comparação

idade = 21

Significa:

idade é igual a 21?

Dependendo da linguagem, a comparação pode utilizar ==:

idade == 21

Portanto, é importante não confundir armazenar um valor com comparar valores.

12. Utilizando entrada e operadores juntos

Uma das aplicações mais importantes desses conceitos é receber dados do usuário e depois processá-los.

Exemplo: calcular o dobro

algoritmo "Dobro"

var
   numero, dobro: real

inicio
   escreva("Digite um número: ")
   leia(numero)

   dobro <- numero * 2

   escreva("O dobro é: ", dobro)
fimalgoritmo

Se o usuário digitar:

10

o algoritmo fará:

dobro <- 10 * 2

Resultado:

O dobro é: 20

13. Exemplo utilizando vários operadores

Podemos combinar entrada, atribuição e operadores aritméticos.

algoritmo "Calculadora"

var
   a, b, soma, subtracao, multiplicacao, divisao: real

inicio
   leia(a)
   leia(b)

   soma <- a + b
   subtracao <- a - b
   multiplicacao <- a * b
   divisao <- a / b

   escreva("Soma: ", soma)
   escreva("Subtração: ", subtracao)
   escreva("Multiplicação: ", multiplicacao)
   escreva("Divisão: ", divisao)
fimalgoritmo

Se:

a = 10
b = 2

teremos:

Soma: 15
Subtração: 8
Multiplicação: 20
Divisão: 5

14. Precedência dos operadores

Quando uma expressão possui vários operadores, o algoritmo precisa determinar qual operação será realizada primeiro.

Por exemplo:

2 + 3 * 4

A multiplicação é realizada antes da soma:

2 + 12

Resultado:

14

Se quisermos realizar a soma primeiro, usamos parênteses:

(2 + 3) * 4

Agora:

5 * 4

Resultado:

20

De forma geral, temos:

  1. Parênteses
  1. Multiplicação, divisão e módulo
  1. Adição e subtração
  1. Operadores relacionais
  1. Operadores lógicos

A precedência exata pode variar entre linguagens, portanto é importante consultar as regras da linguagem utilizada.

15. Exemplo completo

Considere um algoritmo que recebe duas notas e verifica se o aluno foi aprovado.

algoritmo "Aprovacao"

var
   nota1, nota2, media: real

inicio
   escreva("Digite a primeira nota: ")
   leia(nota1)

   escreva("Digite a segunda nota: ")
   leia(nota2)

   media <- (nota1 + nota2) / 2

   escreva("Média: ", media)

   se media >= 7 então
      escreva("Aluno aprovado!")
   senao
      escreva("Aluno reprovado!")
   fimse

fimalgoritmo

Nesse algoritmo temos vários conceitos trabalhando juntos:

Entrada:

leia(nota1)
leia(nota2)

Operadores aritméticos:

+
/

Atribuição:

media <- ...

Operador relacional:

>=

Saída:

escreva()

Isso demonstra como os comandos de entrada e os operadores fazem parte do processamento de informações dentro de um algoritmo.

16. Importância desses conceitos

Os comandos de entrada e os operadores são essenciais porque permitem que os algoritmos deixem de trabalhar apenas com valores fixos e passem a interagir com dados reais.

Por exemplo, em vez de criar:

soma <- 10 + 20

podemos criar:

leia(numero1)
leia(numero2)

soma <- numero1 + numero2

Assim, o mesmo algoritmo pode trabalhar com:

5 e 8

ou:

100 e 250

ou quaisquer outros valores fornecidos pelo usuário.
