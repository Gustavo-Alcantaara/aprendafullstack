Vetores

Vetores

Os vetores são estruturas de dados fundamentais na programação e nos algoritmos. Eles permitem armazenar vários valores dentro de uma única estrutura, utilizando posições ou índices para acessar cada elemento.

Imagine que precisamos armazenar as notas de cinco alunos.

Sem um vetor, poderíamos criar:

nota1 <- 8
nota2 <- 7
nota3 <- 9
nota4 <- 6
nota5 <- 10

Com um vetor:

notas[1] <- 8
notas[2] <- 7
notas[3] <- 9
notas[4] <- 6
notas[5] <- 10

Assim, todas as notas ficam organizadas dentro de uma única estrutura chamada notas.

1. O que é um vetor?

Um vetor é uma estrutura de dados capaz de armazenar uma sequência de elementos, normalmente do mesmo tipo, que podem ser acessados individualmente através de um índice.

Podemos imaginar um vetor como uma sequência de caixas:

+-----+-----+-----+-----+-----+
|  8  |  7  |  9  |  6  | 10  |
+-----+-----+-----+-----+-----+
   1     2     3     4     5

Cada caixa representa uma posição do vetor.

Por exemplo:

notas[3]

representa o terceiro elemento.

Nesse exemplo:

notas[3] = 9

2. Por que utilizar vetores?

Os vetores são úteis quando precisamos trabalhar com vários valores relacionados.

Imagine um sistema que precisa armazenar:

  • 100 nomes;
  • 50 notas;
  • 1.000 preços;
  • 500 códigos de produtos;
  • 365 temperaturas.

Seria impraticável criar uma variável para cada valor.

Em vez disso:

temperaturas[1]
temperaturas[2]
temperaturas[3]
...
temperaturas[365]

Dessa forma, conseguimos organizar e processar grandes quantidades de dados.

3. Exemplo simples

Podemos criar um vetor para armazenar cinco números:

numeros[1] <- 10
numeros[2] <- 20
numeros[3] <- 30
numeros[4] <- 40
numeros[5] <- 50

Visualmente:

Índice:     1    2    3    4    5
            ↓    ↓    ↓    ↓    ↓
Valor:     10   20   30   40   50

Para acessar o terceiro elemento:

escreva(numeros[3])

Resultado:

30

4. Índices

O índice é o número utilizado para identificar a posição de um elemento dentro do vetor.

Por exemplo:

numeros[1] = 10
numeros[2] = 20
numeros[3] = 30

Nesse caso:

  • 1 → índice do primeiro elemento;
  • 2 → índice do segundo;
  • 3 → índice do terceiro.

Atenção

A forma de iniciar os índices depende da linguagem.

Algumas linguagens começam em:

0

Então teríamos:

Índice:    0    1    2    3    4
Valor:    10   20   30   40   50

Outras abordagens ou pseudocódigos podem utilizar:

1

Portanto, é importante conhecer a convenção utilizada pela linguagem.

5. Declaração de um vetor

Em pseudocódigo, podemos declarar um vetor assim:

vetor numeros[1..5] de inteiro

Isso significa:

Criar um vetor chamado numeros, com cinco posições, que armazenará números inteiros.

Podemos então atribuir valores:

numeros[1] <- 10
numeros[2] <- 20
numeros[3] <- 30
numeros[4] <- 40
numeros[5] <- 50

6. Vetores e tipos de dados

Um vetor normalmente é definido para armazenar elementos de determinado tipo.

Inteiros

idades[1..5] de inteiro

Reais

precos[1..10] de real

Caracteres/textos

nomes[1..20] de caractere

Lógicos

respostas[1..10] de logico

O tipo dependerá dos dados que queremos armazenar.

7. Atribuindo valores

Podemos preencher um vetor manualmente:

notas[1] <- 8
notas[2] <- 7
notas[3] <- 10
notas[4] <- 6
notas[5] <- 9

Agora temos:

+---+---+----+---+---+
| 8 | 7 | 10 | 6 | 9 |
+---+---+----+---+---+
  1   2    3   4   5

8. Lendo valores para um vetor

Em situações reais, normalmente os valores são fornecidos pelo usuário ou obtidos de outra fonte.

Podemos utilizar uma estrutura de repetição:

para i de 1 até 5 faça
    escreva("Digite a nota ", i, ": ")
    leia(notas[i])
fimpara

Se o usuário informar:

8
7
10
6
9

o vetor ficará:

notas[1] = 8
notas[2] = 7
notas[3] = 10
notas[4] = 6
notas[5] = 9

Essa combinação entre vetores e estruturas de repetição é extremamente importante.

9. Percorrendo um vetor

Para acessar todos os elementos de um vetor, normalmente utilizamos uma estrutura de repetição.

Exemplo:

para i de 1 até 5 faça
    escreva(numeros[i])
fimpara

Se o vetor for:

10
20
30
40
50

o programa exibirá:

10
20
30
40
50

A variável i funciona como um índice.

10. Vetor e PARA

A estrutura PARA é muito utilizada para percorrer vetores.

Exemplo:

para i de 1 até 10 faça
    escreva(vetor[i])
fimpara

Podemos visualizar:

i = 1 → vetor[1]
i = 2 → vetor[2]
i = 3 → vetor[3]
...
i = 10 → vetor[10]

Assim, uma única estrutura de repetição consegue acessar todas as posições.

11. Calculando a soma dos elementos

Podemos utilizar um vetor para armazenar números e depois calcular sua soma.

soma <- 0

para i de 1 até 5 faça
    soma <- soma + numeros[i]
fimpara

Se:

numeros = [10, 20, 30, 40, 50]

teremos:

10 + 20 + 30 + 40 + 50

Resultado:

150

12. Calculando a média

Podemos calcular a média dos valores armazenados:

soma <- 0

para i de 1 até 5 faça
    soma <- soma + notas[i]
fimpara

media <- soma / 5

Por exemplo:

notas = [8, 7, 10, 6, 9]

A soma será:

40

E:

40 / 5 = 8

Portanto:

media = 8

13. Encontrando o maior valor

Os vetores também podem ser utilizados para encontrar o maior elemento.

Exemplo:

maior <- numeros[1]

para i de 2 até 5 faça

    se numeros[i] > maior então
        maior <- numeros[i]
    fimse

fimpara

Se:

numeros = [15, 8, 32, 20, 10]

o algoritmo encontrará:

32

14. Encontrando o menor valor

O mesmo princípio pode ser utilizado para encontrar o menor.

menor <- numeros[1]

para i de 2 até 5 faça

    se numeros[i] < menor então
        menor <- numeros[i]
    fimse

fimpara

Para:

[15, 8, 32, 20, 10]

o resultado será:

8

15. Pesquisa em um vetor

Podemos procurar um determinado valor dentro do vetor.

Por exemplo:

numeros = [10, 20, 30, 40, 50]

Queremos encontrar 30.

Podemos utilizar:

encontrado <- falso

para i de 1 até 5 faça

    se numeros[i] == 30 então
        encontrado <- verdadeiro
    fimse

fimpara

No final:

encontrado = verdadeiro

16. Descobrindo a posição de um elemento

Podemos também descobrir onde o elemento está.

posicao <- -1

para i de 1 até 5 faça

    se numeros[i] == 30 então
        posicao <- i
    fimse

fimpara

Se:

numeros = [10, 20, 30, 40, 50]

teremos:

posicao = 3

Isso significa que 30 está na terceira posição.

17. Contando elementos que atendem a uma condição

Podemos utilizar um vetor para descobrir quantos valores são maiores que determinado número.

contador <- 0

para i de 1 até 10 faça

    se numeros[i] > 50 então
        contador <- contador + 1
    fimse

fimpara

Aqui utilizamos:

  • Vetor;
  • Estrutura de repetição;
  • Estrutura condicional;
  • Contador.

Essa combinação é muito comum em algoritmos.

18. Exemplo: notas dos alunos

Imagine:

notas = [8, 5, 9, 4, 7]

Podemos verificar quais alunos foram aprovados:

para i de 1 até 5 faça

    se notas[i] >= 7 então
        escreva("Aluno ", i, ": aprovado")
    senao
        escreva("Aluno ", i, ": reprovado")
    fimse

fimpara

Resultado:

Aluno 1: aprovado
Aluno 2: reprovado
Aluno 3: aprovado
Aluno 4: reprovado
Aluno 5: aprovado

19. Alterando um elemento

Podemos modificar uma posição específica.

Inicialmente:

numeros = [10, 20, 30, 40, 50]

Podemos fazer:

numeros[3] <- 100

Agora:

numeros = [10, 20, 100, 40, 50]

Somente o terceiro elemento foi alterado.

20. Vetores e memória

Um vetor normalmente armazena seus elementos em posições relacionadas na memória.

Podemos imaginar:

+------+-------+
| Índice | Valor |
+------+-------+
|  0   |  10   |
|  1   |  20   |
|  2   |  30   |
|  3   |  40   |
|  4   |  50   |
+------+-------+

Isso permite que o programa identifique cada elemento por meio de seu índice.

Em muitas linguagens, o acesso direto a uma posição de um vetor é muito eficiente.

21. Vetores de caracteres

Um vetor também pode armazenar textos ou caracteres, dependendo da linguagem.

Por exemplo:

nomes[1] <- "Ana"
nomes[2] <- "Carlos"
nomes[3] <- "Gusta"
nomes[4] <- "João"

Podemos percorrê-lo:

para i de 1 até 4 faça
    escreva(nomes[i])
fimpara

Resultado:

Ana
Carlos
Gusta
João

22. Vetores e funções

Podemos enviar vetores para funções ou procedimentos.

Por exemplo:

função calcularMedia(notas, quantidade)

    soma <- 0

    para i de 1 até quantidade faça
        soma <- soma + notas[i]
    fimpara

    retorne soma / quantidade

fimfunção

Podemos então utilizar:

notas = [8, 7, 9, 10]

media <- calcularMedia(notas, 4)

Resultado:

8,5

Isso permite criar funções bastante reutilizáveis.

23. Vetores e procedimentos

Também podemos criar procedimentos para exibir os elementos:

procedimento mostrarVetor(vetor, quantidade)

    para i de 1 até quantidade faça
        escreva(vetor[i])
    fimpara

fimprocedimento

Chamada:

mostrarVetor(numeros, 5)

24. Vetores de tamanho fixo

Em algumas linguagens, podemos criar vetores com tamanho definido.

Por exemplo:

notas[1..10]

Nesse caso, existem 10 posições.

Podemos representar:

[ _ ][ _ ][ _ ][ _ ][ _ ][ _ ][ _ ][ _ ][ _ ][ _ ]

Cada posição poderá receber um valor.

25. Vetores dinâmicos

Algumas linguagens possuem estruturas semelhantes aos vetores que podem aumentar ou diminuir de tamanho durante a execução.

Por exemplo, em JavaScript:

let numeros = [10, 20, 30];

numeros.push(40);

Agora:

[10, 20, 30, 40]

Em Python:

numeros = [10, 20, 30]

numeros.append(40)

Resultado:

[10, 20, 30, 40]

Portanto, o conceito de vetor pode ser implementado de maneiras diferentes dependendo da linguagem.

26. Vetores e listas

É importante entender que vetor e lista não são necessariamente a mesma estrutura, embora muitas vezes sejam usados de maneira semelhante.

Um vetor tradicional geralmente possui:

  • Elementos organizados por índice;
  • Tamanho definido ou características mais rígidas;
  • Elementos normalmente do mesmo tipo em linguagens tipadas.

Uma lista geralmente possui maior flexibilidade, dependendo da linguagem.

Por exemplo, Python utiliza principalmente a estrutura list:

numeros = [10, 20, 30]

Java possui arrays tradicionais:

int[] numeros = {10, 20, 30};

E também possui estruturas como ArrayList.

27. Vetores e algoritmos de busca

Os vetores são fundamentais para algoritmos de busca.

A busca mais simples é a busca linear.

Imagine:

[15, 8, 20, 30, 42]

Queremos encontrar:

30

O algoritmo verifica:

15 → não
8  → não
20 → não
30 → sim

Quando encontra o valor, podemos interromper a busca.

Pseudocódigo:

para i de 1 até 5 faça

    se vetor[i] == valorProcurado então
        escreva("Encontrado na posição ", i)
        pare
    fimse

fimpara

A busca linear é um dos primeiros algoritmos importantes que utilizam vetores.

28. Vetores e ordenação

Também podemos utilizar vetores para implementar algoritmos de ordenação.

Por exemplo:

[5, 2, 8, 1, 3]

Pode ser ordenado para:

[1, 2, 3, 5, 8]

Algoritmos clássicos de ordenação incluem:

  • Bubble Sort;
  • Selection Sort;
  • Insertion Sort;
  • Merge Sort;
  • Quick Sort.

Os vetores são estruturas fundamentais para estudar esses algoritmos.

29. Vetores multidimensionais

Quando temos mais de uma dimensão, passamos a trabalhar com estruturas como matrizes.

Um vetor possui uma dimensão:

[10, 20, 30, 40]

Uma matriz possui duas:

[ 10  20  30 ]
[ 40  50  60 ]
[ 70  80  90 ]

Podemos acessar utilizando dois índices:

matriz[linha][coluna]

Por exemplo:

matriz[2][3]

representaria a segunda linha e terceira coluna, dependendo da convenção de índices da linguagem.

As matrizes são, portanto, uma extensão do conceito de estruturas indexadas para mais de uma dimensão.

30. Vetores e estruturas de repetição

Uma das combinações mais importantes da lógica de programação é:

Vetor + Repetição + Condição

Por exemplo:

para i de 1 até 10 faça

    se numeros[i] > 0 então
        escreva("Positivo")
    senao
        escreva("Negativo")
    fimse

fimpara

Essa combinação permite resolver uma enorme quantidade de problemas.

31. Exemplo completo

Vamos criar um algoritmo que:

  1. Recebe 5 números;
  1. Armazena-os em um vetor;
  1. Calcula a soma;
  1. Calcula a média;
  1. Encontra o maior número;
  1. Encontra o menor número.
algoritmo "AnaliseVetor"

var
    numeros: vetor[1..5] de inteiro
    i, soma, maior, menor: inteiro
    media: real

inicio

    soma <- 0

    para i de 1 até 5 faça
        escreva("Digite o ", i, "º número: ")
        leia(numeros[i])
    fimpara

    maior <- numeros[1]
    menor <- numeros[1]

    para i de 1 até 5 faça

        soma <- soma + numeros[i]

        se numeros[i] > maior então
            maior <- numeros[i]
        fimse

        se numeros[i] < menor então
            menor <- numeros[i]
        fimse

    fimpara

    media <- soma / 5

    escreva("Soma: ", soma)
    escreva("Média: ", media)
    escreva("Maior: ", maior)
    escreva("Menor: ", menor)

fimalgoritmo

Esse exemplo reúne vários conceitos:

Vetor
  +
Repetição
  +
Condição
  +
Acumulador
  +
Comparação

32. Erros comuns ao trabalhar com vetores

32.1 Acessar uma posição inexistente

Se temos:

numeros[1..5]

não podemos acessar:

numeros[6]

Isso representa uma posição que não existe.

Dependendo da linguagem, isso pode gerar um erro ou comportamento inesperado.

32.2 Confundir índice com valor

Considere:

[10, 20, 30]

O índice não é o valor.

Por exemplo:

vetor[2]

significa:

A posição 2.

O valor armazenado nessa posição pode ser:

20

32.3 Erro de limite

Um erro muito comum é percorrer o vetor além do seu tamanho.

Por exemplo:

para i de 1 até 10

quando o vetor possui somente 5 elementos.

Isso pode causar acesso inválido.

32.4 Esquecer a inicialização

Se queremos calcular uma soma:

soma <- 0

é importante inicializar o acumulador antes de começar a repetição.

33. Vantagens dos vetores

Os vetores oferecem várias vantagens:

  • Permitem armazenar muitos valores em uma única estrutura;
  • Facilitam o processamento de grandes quantidades de dados;
  • Permitem acesso por índice;
  • Funcionam muito bem com estruturas de repetição;
  • Facilitam algoritmos de busca;
  • Facilitam algoritmos de ordenação;
  • Melhoram a organização dos dados;
  • Permitem criar estruturas mais complexas.

34. Limitações dos vetores

Dependendo da implementação, os vetores tradicionais também podem apresentar limitações.

Tamanho fixo

Em algumas linguagens, o tamanho precisa ser definido no momento da criação.

Tipo dos elementos

Em linguagens fortemente tipadas, os elementos geralmente precisam possuir o mesmo tipo.

Inserções e remoções

Inserir ou remover elementos no meio de um vetor pode exigir movimentação de outros elementos, dependendo da implementação.

Por isso, existem outras estruturas de dados, como:

  • Listas;
  • Pilhas;
  • Filas;
  • Árvores;
  • Tabelas hash;
  • Grafos.

Cada uma é adequada para diferentes tipos de problemas.

35. Vetores na programação

O conceito de vetor aparece praticamente em todas as linguagens.

PHP

$numeros = [10, 20, 30, 40];
echo $numeros[2];

JavaScript

let numeros = [10, 20, 30, 40];

console.log(numeros[2]);

Python

numeros = [10, 20, 30, 40]

print(numeros[2])

Java

int[] numeros = {10, 20, 30, 40};

System.out.println(numeros[2]);

Nas linguagens que utilizam índices começando em 0, o resultado de [2] será 30.

37. Resumo final

Os vetores são estruturas de dados utilizadas para armazenar vários valores relacionados em uma única estrutura, permitindo que cada elemento seja acessado por meio de um índice.

Por exemplo:

notas = [8, 7, 10, 6, 9]

Podemos acessar:

notas[1]
notas[2]
notas[3]
...

E podemos percorrer todos os elementos:

para i de 1 até 5 faça
    escreva(notas[i])
fimpara

Os vetores são especialmente importantes porque trabalham muito bem em conjunto com:

Vetores
   ↓
Estruturas de repetição
   ↓
Estruturas condicionais
   ↓
Funções
   ↓
Algoritmos de busca e ordenação

Por isso, o estudo de vetores é uma etapa fundamental da lógica de programação e das estruturas de dados. Depois de dominar vetores, conceitos como matrizes, busca linear, busca binária, ordenação, listas e outras estruturas de dados tornam-se muito mais fáceis de compreender.
