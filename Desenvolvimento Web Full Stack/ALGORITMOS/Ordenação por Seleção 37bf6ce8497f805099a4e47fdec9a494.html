Ordenação por Seleção (Selection Sort)

O que é a Ordenação por Seleção?

A Ordenação por Seleção (Selection Sort) é um algoritmo de ordenação simples que organiza os elementos de uma lista encontrando repetidamente o menor elemento da parte não ordenada e colocando-o na posição correta.

A ideia é semelhante ao que fazemos ao organizar cartas de baralho na mão: procuramos a menor carta e a colocamos na primeira posição, depois procuramos a segunda menor e a colocamos na segunda posição, e assim sucessivamente.

Embora não seja um algoritmo muito eficiente para grandes volumes de dados, ele é bastante utilizado no ensino de algoritmos porque ajuda a compreender os conceitos fundamentais de ordenação.

Como o Selection Sort Funciona?

O algoritmo divide a lista em duas partes:

  • Parte ordenada;
  • Parte não ordenada.

Inicialmente:

[64, 25, 12, 22, 11]
 ↑
ordenada: vazia

A cada iteração:

  1. Procura o menor elemento da parte não ordenada;
  1. Troca esse elemento com a primeira posição disponível;
  1. Expande a parte ordenada.

Exemplo Passo a Passo

Vamos ordenar:

[64, 25, 12, 22, 11]

Primeira Passagem

Procuramos o menor valor:

64, 25, 12, 22, 11
                ↑
              menor

O menor valor é:

11

Trocamos com o primeiro elemento:

[11, 25, 12, 22, 64]

Parte ordenada:

[11]

Segunda Passagem

Agora procuramos o menor valor a partir da posição 1:

[11, 25, 12, 22, 64]
      ↑

Menor valor:

12

Troca:

[11, 12, 25, 22, 64]

Parte ordenada:

[11, 12]

Terceira Passagem

Procuramos o menor valor restante:

[11, 12, 25, 22, 64]

Menor:

22

Troca:

[11, 12, 22, 25, 64]

Quarta Passagem

Restam:

25, 64

Já estão em ordem.

Resultado final:

[11, 12, 22, 25, 64]

Implementação em JavaScript

function selectionSort(vetor) {
    let tamanho = vetor.length;

    for (let i = 0; i < tamanho - 1; i++) {

        let menorIndice = i;

        for (let j = i + 1; j < tamanho; j++) {

            if (vetor[j] < vetor[menorIndice]) {
                menorIndice = j;
            }

        }

        let temp = vetor[i];
        vetor[i] = vetor[menorIndice];
        vetor[menorIndice] = temp;
    }

    return vetor;
}

Utilizando:

let numeros = [64, 25, 12, 22, 11];

console.log(selectionSort(numeros));

Resultado:

[11, 12, 22, 25, 64]

Entendendo o Código

Laço Externo

for (let i = 0; i < tamanho - 1; i++)

Percorre cada posição onde o próximo menor elemento será colocado.

Menor Índice

let menorIndice = i;

Assumimos inicialmente que o menor valor é o elemento atual.

Laço Interno

for (let j = i + 1; j < tamanho; j++)

Percorre a parte não ordenada procurando um valor menor.

Comparação

if (vetor[j] < vetor[menorIndice])

Se encontrar um valor menor, atualiza a posição do menor elemento.

Troca

let temp = vetor[i];
vetor[i] = vetor[menorIndice];
vetor[menorIndice] = temp;

Move o menor elemento para sua posição correta.

Complexidade Big O

Número de Comparações

Para um vetor com n elementos, o algoritmo realiza aproximadamente:

(n - 1) + (n - 2) + (n - 3) + ...

Essa soma resulta em:

n² / 2

Portanto:

Melhor Caso

O(n²)

Caso Médio

O(n²)

Pior Caso

O(n²)

Diferente de alguns algoritmos, o Selection Sort sempre percorre praticamente todos os elementos.

Complexidade Espacial

O algoritmo utiliza apenas algumas variáveis auxiliares.

O(1)

Isso significa que ele consome uma quantidade constante de memória.

Vantagens do Selection Sort

Fácil de entender

Sua lógica é simples e didática.

Pouca utilização de memória

Opera diretamente sobre o vetor.

Poucas trocas

Enquanto outros algoritmos realizam muitas trocas, o Selection Sort troca apenas quando encontra o menor elemento.

Desvantagens do Selection Sort

Lento para grandes conjuntos de dados

Sua complexidade:

O(n²)

torna-o ineficiente para listas muito grandes.

Não aproveita listas parcialmente ordenadas

Mesmo que o vetor esteja quase organizado, ele continua realizando praticamente a mesma quantidade de comparações.

Comparação com Outros Algoritmos

Por isso, na prática, algoritmos como Merge Sort e Quick Sort costumam ser preferidos para grandes volumes de dados.

Quando Utilizar o Selection Sort?

O Selection Sort é mais indicado para:

  • Aprender conceitos de ordenação;
  • Estudar análise de algoritmos;
  • Trabalhar com conjuntos pequenos de dados;
  • Situações onde o número de trocas precisa ser minimizado.

Não é recomendado para aplicações que manipulam milhares ou milhões de registros.

Resumo

A Ordenação por Seleção (Selection Sort) é um algoritmo que organiza uma lista encontrando repetidamente o menor elemento da parte não ordenada e colocando-o na posição correta. Sua implementação é simples, utiliza pouca memória e realiza poucas trocas, mas possui complexidade O(n²) em praticamente todos os cenários, tornando-o inadequado para grandes conjuntos de dados. Apesar disso, é um dos algoritmos mais importantes para o aprendizado de lógica, ordenação e análise de desempenho de algoritmos.
