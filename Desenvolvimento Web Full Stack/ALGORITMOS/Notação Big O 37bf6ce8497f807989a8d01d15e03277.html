Notação Big O

O que é a Notação Big O?

A Notação Big O é uma forma de medir a eficiência de um algoritmo. Ela descreve como o tempo de execução ou o consumo de memória de um algoritmo cresce à medida que a quantidade de dados processados aumenta.

Em vez de medir segundos ou milissegundos, a Big O analisa o comportamento do algoritmo em relação ao tamanho da entrada.

Por exemplo, imagine dois algoritmos que procuram um número em uma lista. Ambos podem ser rápidos para uma lista com 10 elementos, mas quando a lista possui 1 milhão de elementos, a diferença de desempenho pode ser enorme. A Notação Big O ajuda justamente a prever esse comportamento.

Por que a Big O é importante?

Ao desenvolver software, não basta que um algoritmo funcione; ele também deve ser eficiente.

A Notação Big O permite:

  • Comparar algoritmos;
  • Escolher a solução mais eficiente;
  • Identificar gargalos de desempenho;
  • Projetar sistemas escaláveis;
  • Entender o comportamento de estruturas de dados.

Ela é amplamente utilizada em entrevistas técnicas, estruturas de dados e desenvolvimento de software.

O que significa "n"?

Nas expressões da Big O, a letra n representa o tamanho da entrada.

Exemplos:

  • Quantidade de elementos de um vetor;
  • Número de registros de um banco de dados;
  • Quantidade de usuários processados;
  • Número de linhas de um arquivo.

Quanto maior for o valor de n, mais importante se torna a eficiência do algoritmo.

Complexidade de Tempo e Complexidade de Espaço

Complexidade de Tempo

Mede quantas operações um algoritmo realiza.

Exemplo:

for(let i = 0; i < n; i++) {
    console.log(i);
}

O laço executa n vezes.

Complexidade:

O(n)

Complexidade de Espaço

Mede a quantidade de memória utilizada.

Exemplo:

let numeros = [];

for(let i = 0; i < n; i++) {
    numeros.push(i);
}

À medida que n cresce, o vetor também cresce.

Complexidade espacial:

O(n)

Principais Complexidades

A melhor complexidade possível.

O tempo de execução não muda independentemente do tamanho da entrada.

Exemplo

Não importa se o vetor possui:

10 elementos
100 elementos

A operação continua sendo apenas uma.

Características

O(n) — Linear

O tempo cresce proporcionalmente ao tamanho da entrada.

Exemplo

for(let i = 0; i < vetor.length; i++) {
    console.log(vetor[i]);
}

Se houver:

10 elementos → 10 operações
100 elementos → 100 operações
1000 elementos → 1000 operações

Complexidade:

O(n)

O(n log n)

Muito comum em algoritmos de ordenação eficientes.

Exemplos

  • Merge Sort
  • Heap Sort
  • Quick Sort (caso médio)

Se tivermos:

1000 elementos

O algoritmo executará aproximadamente:

1000 × log₂(1000)

operações.

É uma complexidade considerada muito boa.

O(n²) — Quadrática

O tempo cresce ao quadrado.

Geralmente aparece quando existe um laço dentro de outro.

Exemplo

for(let i = 0; i < n; i++) {
    for(let j = 0; j < n; j++) {
        console.log(i, j);
    }
}

Quantidade de operações:

n × n

Complexidade:

O(n²)

Crescimento

Perceba como o crescimento é rápido.

O(n³) — Cúbica

Três laços aninhados.

Exemplo

for(let i = 0; i < n; i++) {
    for(let j = 0; j < n; j++) {
        for(let k = 0; k < n; k++) {
            console.log(i, j, k);
        }
    }
}

Complexidade:

O(n³)

Muito custosa para grandes conjuntos de dados.

O(2ⁿ) — Exponencial

Uma das piores complexidades.

Cada aumento em n praticamente dobra o trabalho.

Exemplo

Algoritmos recursivos ingênuos para calcular Fibonacci.

O(2ⁿ)

Cresce extremamente rápido.

O(n!)

Complexidade fatorial.

Aparece em problemas que testam todas as combinações possíveis.

Exemplo

Problema do Caixeiro Viajante (solução por força bruta).

O(n!)

É uma das complexidades mais caras existentes.

Regras para Calcular Big O

Ignorar constantes

Exemplo

for(let i = 0; i < n; i++) {
    console.log(i);
}

for(let i = 0; i < n; i++) {
    console.log(i);
}

Operações:

2n

Big O:

O(n)

A constante 2 é ignorada.

Considerar apenas o termo dominante

Exemplo

n² + n + 10

Big O:

O(n²)

O termo quadrático domina o crescimento.

Laços aninhados multiplicam

for(let i = 0; i < n; i++) {
    for(let j = 0; j < n; j++) {
    }
}

Resultado:

O(n²)

Laços separados somam

for(let i = 0; i < n; i++) {}

for(let j = 0; j < n; j++) {}

Resultado:

O(2n)

Simplificando:

O(n)

Exemplo Prático

Imagine um sistema com 10 usuários.

Uma busca linear pode parecer rápida.

Mas se o sistema crescer para:

10.000.000 usuários

Um algoritmo:

O(n²)

pode se tornar inviável.

Já um algoritmo:

O(log n)

continuará extremamente eficiente.

É justamente por isso que programadores estudam Big O: para garantir que seus sistemas continuem rápidos mesmo quando a quantidade de dados aumenta.

Resumo

A Notação Big O é uma forma de medir a eficiência de algoritmos analisando como seu tempo de execução ou consumo de memória cresce conforme o tamanho da entrada aumenta. Ela não mede tempo real, mas sim a taxa de crescimento do algoritmo. Compreender Big O é fundamental para comparar soluções, escolher estruturas de dados adequadas e desenvolver aplicações escaláveis e performáticas. Entre as complexidades mais importantes estão O(1), O(log n), O(n), O(n log n) e O(n²), que aparecem frequentemente no estudo de algoritmos e estruturas de dados.
