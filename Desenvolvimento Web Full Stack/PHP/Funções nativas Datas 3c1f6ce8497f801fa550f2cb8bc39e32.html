Funções Nativas para Manipular Datas no PHP

O PHP possui diversas funções nativas para trabalhar com datas e horários. Elas permitem obter a data atual, formatar datas, converter textos em datas, comparar períodos, adicionar ou remover intervalos de tempo e calcular diferenças entre datas.

Esse recurso é muito importante no desenvolvimento web, pois praticamente qualquer sistema utiliza datas: cadastros, pedidos, pagamentos, agendamentos, relatórios, mensagens, vencimentos, históricos, reservas, entre outros.

1. Data e hora no PHP

Antes de conhecer as funções, é importante entender que o PHP trabalha com dois conceitos relacionados:

  • Data → dia, mês e ano.
  • Hora → horas, minutos e segundos.

Por exemplo:

19/08/2026 15:30:45

Temos:

Data: 19/08/2026
Hora: 15:30:45

O PHP possui várias funções para manipular essas informações.

2. date() — Formatar uma data

Uma das funções mais importantes para trabalhar com datas no PHP é date().

Ela permite obter a data e/ou hora atual e formatá-la de acordo com o padrão desejado.

Sintaxe

date(formato);

Exemplo

<?php

echo date("d/m/Y");

Possível resultado:

19/08/2026

Nesse caso:

  • d → dia com dois dígitos
  • m → mês com dois dígitos
  • Y → ano com quatro dígitos

3. Principais caracteres de formatação

A função date() utiliza caracteres especiais para determinar o que será exibido.

Por exemplo:

echo date("d/m/Y");

Resultado:

Com hora:

echo date("d/m/Y H:i:s");

4. Exibindo uma data por extenso

Podemos utilizar date() para montar uma data mais legível:

echo date("d") . " de " . date("F") . " de " . date("Y");

Porém, os nomes dos meses retornados por date() dependem do formato e não são automaticamente traduzidos para português.

Para sistemas em português, normalmente é melhor criar uma conversão própria ou utilizar recursos de internacionalização.

5. time() — Timestamp atual

A função time() retorna o timestamp Unix atual.

echo time();

O resultado será um número semelhante a:

1787152245

Esse número representa a quantidade de segundos desde o início da Unix Epoch, que começa em:

01/01/1970 00:00:00 UTC

O timestamp é muito útil para realizar cálculos e comparações envolvendo datas.

6. Utilizando time() com date()

Podemos passar um timestamp para date():

$agora = time();

echo date("d/m/Y", $agora);

Isso permite transformar um timestamp em uma data legível.

Também podemos mostrar a hora:

echo date("H:i:s", time());

7. mktime() — Criar um timestamp

A função mktime() cria um timestamp a partir de uma determinada hora e data.

Sintaxe

mktime(hora, minuto, segundo, mes, dia, ano);

Exemplo

$data = mktime(15, 30, 0, 8, 19, 2026);

echo date("d/m/Y H:i:s", $data);

Resultado:

19/08/2026 15:30:00

Isso pode ser útil quando precisamos trabalhar com uma data específica.

8. strtotime() — Converter texto em timestamp

strtotime() é uma das funções mais úteis para manipulação de datas.

Ela tenta interpretar uma string contendo uma data ou expressão relacionada a tempo e transforma essa informação em timestamp.

Exemplo

$data = strtotime("19 August 2026");

echo date("d/m/Y", $data);

Resultado:

19/08/2026

9. Usando expressões relativas

Uma das grandes vantagens de strtotime() é aceitar expressões como:

strtotime("tomorrow");
strtotime("yesterday");
strtotime("+1 day");
strtotime("+7 days");
strtotime("-1 month");

Por exemplo:

$amanha = strtotime("+1 day");

echo date("d/m/Y", $amanha);

10. Obtendo amanhã

Podemos fazer:

$amanha = strtotime("tomorrow");

echo date("d/m/Y", $amanha);

Outra possibilidade:

$amanha = strtotime("+1 day");

echo date("d/m/Y", $amanha);

Ambas expressam a ideia de obter o dia seguinte.

11. Obtendo ontem

$ontem = strtotime("yesterday");

echo date("d/m/Y", $ontem);

Também:

$ontem = strtotime("-1 day");

echo date("d/m/Y", $ontem);

12. Adicionando dias

Podemos adicionar vários dias:

$data = strtotime("+30 days");

echo date("d/m/Y", $data);

Isso é muito útil para situações como:

  • vencimento;
  • prazo de pagamento;
  • validade;
  • período de teste;
  • prazo de entrega.

Por exemplo:

$inicio = time();

$vencimento = strtotime("+30 days");

echo "Vencimento: " . date("d/m/Y", $vencimento);

13. strtotime() com meses e anos

Também podemos trabalhar com meses:

$data = strtotime("+2 months");

echo date("d/m/Y", $data);

Ou anos:

$data = strtotime("+1 year");

echo date("d/m/Y", $data);

Também podemos subtrair:

$data = strtotime("-3 months");

echo date("d/m/Y", $data);

14. checkdate() — Verificar uma data

A função checkdate() verifica se uma determinada data é válida.

Sintaxe

checkdate(mes, dia, ano);

Exemplo

if (checkdate(8, 19, 2026)) {
    echo "Data válida";
} else {
    echo "Data inválida";
}

Resultado:

Data válida

15. Verificando uma data inválida

Por exemplo:

if (checkdate(2, 31, 2026)) {
    echo "Data válida";
} else {
    echo "Data inválida";
}

Resultado:

Data inválida

Isso acontece porque fevereiro não possui 31 dias.

Essa função é especialmente útil na validação de informações recebidas de formulários.

16. Ano bissexto

O PHP possui a função date() e outras ferramentas para determinar características do calendário.

Uma forma simples de verificar um ano bissexto é:

$ano = 2028;

if (date("L", strtotime("$ano-01-01"))) {
    echo "Ano bissexto";
} else {
    echo "Ano não bissexto";
}

O formato L retorna:

  • 1 → ano bissexto
  • 0 → ano não bissexto

Por exemplo:

2028 → bissexto
2027 → não bissexto

17. date_default_timezone_set() — Definir fuso horário

Um sistema precisa saber qual fuso horário deve utilizar.

Podemos configurar isso com:

date_default_timezone_set("America/Fortaleza");

Depois:

echo date("d/m/Y H:i:s");

Para aplicações destinadas ao Brasil, é importante configurar explicitamente o fuso horário adequado ao contexto da aplicação.

Por exemplo:

date_default_timezone_set("America/Sao_Paulo");

A escolha do fuso deve considerar a região que o sistema realmente atende.

18. date_default_timezone_get() — Consultar o fuso horário

Podemos verificar qual fuso horário está configurado:

echo date_default_timezone_get();

Resultado, por exemplo:

America/Sao_Paulo

Isso pode ser útil durante testes e depuração.

19. gmdate() — Data em UTC

A função gmdate() funciona de maneira semelhante à date(), mas retorna a data/hora em UTC.

echo gmdate("d/m/Y H:i:s");

Isso é útil em sistemas que trabalham com servidores e usuários localizados em diferentes regiões.

Uma prática comum em sistemas distribuídos é armazenar horários em UTC e convertê-los para o fuso do usuário quando necessário.

20. getdate() — Obter informações detalhadas

A função getdate() retorna informações sobre uma determinada data em um array.

$data = getdate();

print_r($data);

O resultado contém informações como:

seconds
minutes
hours
mday
wday
mon
year
yday
weekday
month
0

Por exemplo:

$data = getdate();

echo $data["mday"];
echo $data["mon"];
echo $data["year"];

Isso permite acessar separadamente o dia, mês e ano.

21. date_parse() — Analisar uma data

A função date_parse() analisa uma string contendo uma data e retorna suas partes.

$data = date_parse("19-08-2026");

print_r($data);

Ela fornece informações como:

year
month
day
hour
minute
second

Podemos acessar:

$data = date_parse("19-08-2026");

echo $data["day"];
echo $data["month"];
echo $data["year"];

Resultado:

19
8
2026

22. date_create() — Criar um objeto de data

O PHP também permite trabalhar com datas através da API de objetos.

$data = date_create("2026-08-19");

echo date_format($data, "d/m/Y");

Resultado:

19/08/2026

Essa abordagem é especialmente interessante porque permite manipular datas de maneira mais organizada.

23. date_format() — Formatar um objeto de data

Depois de criar um objeto com date_create(), podemos formatá-lo usando date_format().

$data = date_create("2026-08-19");

echo date_format($data, "d/m/Y");

Também podemos incluir o horário:

$data = date_create("2026-08-19 15:30:00");

echo date_format($data, "d/m/Y H:i:s");

Resultado:

19/08/2026 15:30:00

24. date_modify() — Modificar uma data

A função date_modify() permite adicionar ou remover períodos de uma data.

$data = date_create("2026-08-19");

date_modify($data, "+10 days");

echo date_format($data, "d/m/Y");

Resultado:

29/08/2026

Também podemos remover:

$data = date_create("2026-08-19");

date_modify($data, "-5 days");

echo date_format($data, "d/m/Y");

Resultado:

14/08/2026

25. date_add() — Adicionar um intervalo

Também podemos utilizar date_add() com DateInterval.

$data = date_create("2026-08-19");

$intervalo = new DateInterval("P10D");

date_add($data, $intervalo);

echo date_format($data, "d/m/Y");

Resultado:

29/08/2026

O P10D significa:

P = período
10 = quantidade
D = dias

26. date_sub() — Subtrair um intervalo

Para remover um intervalo:

$data = date_create("2026-08-19");

$intervalo = new DateInterval("P10D");

date_sub($data, $intervalo);

echo date_format($data, "d/m/Y");

Resultado:

09/08/2026

27. date_diff() — Calcular diferença entre datas

Uma das funções mais importantes é date_diff().

Ela calcula a diferença entre duas datas.

$data1 = date_create("2026-08-01");
$data2 = date_create("2026-08-19");

$diferenca = date_diff($data1, $data2);

echo $diferenca->days;

Resultado:

18

Ou seja, existem 18 dias de diferença entre as duas datas.

28. Obtendo anos, meses e dias de diferença

O objeto retornado por date_diff() possui várias informações.

$data1 = date_create("2020-01-01");
$data2 = date_create("2026-08-19");

$diferenca = date_diff($data1, $data2);

echo "Anos: " . $diferenca->y . "<br>";
echo "Meses: " . $diferenca->m . "<br>";
echo "Dias: " . $diferenca->d;

Podemos trabalhar com:

y → anos
m → meses
d → dias
h → horas
i → minutos
s → segundos

29. Comparando duas datas

Datas criadas como objetos DateTime podem ser comparadas utilizando operadores.

$data1 = new DateTime("2026-08-19");
$data2 = new DateTime("2026-08-25");

if ($data1 < $data2) {
    echo "A primeira data é anterior.";
}

Resultado:

A primeira data é anterior.

Podemos também verificar:

if ($data1 > $data2) {
    echo "A primeira data é posterior.";
}

Ou:

if ($data1 == $data2) {
    echo "As datas são iguais.";
}

30. DateTime — Uma das formas mais importantes

Embora DateTime não seja uma função, ele é uma das principais ferramentas do PHP moderno para manipulação de datas.

Exemplo:

$data = new DateTime();

echo $data->format("d/m/Y H:i:s");

Isso retorna a data e hora atuais.

Podemos criar uma data específica:

$data = new DateTime("2026-12-25");

echo $data->format("d/m/Y");

Resultado:

25/12/2026

31. Adicionando tempo com DateTime

Podemos utilizar modify():

$data = new DateTime("2026-08-19");

$data->modify("+30 days");

echo $data->format("d/m/Y");

Resultado:

18/09/2026

Também:

$data->modify("+2 months");

ou:

$data->modify("-1 year");

32. DateInterval — Representar intervalos

DateInterval representa uma quantidade de tempo.

Por exemplo:

$intervalo = new DateInterval("P1Y");

Significa:

1 ano

Outro:

$intervalo = new DateInterval("P30D");

Significa:

30 dias

Também podemos representar horas e minutos:

$intervalo = new DateInterval("PT2H30M");

Significa:

2 horas e 30 minutos

33. Formato ISO 8601

Em aplicações web e APIs, é comum utilizar o padrão ISO 8601.

Exemplo:

2026-08-19T15:30:00-03:00

Com DateTime:

$data = new DateTime();

echo $data->format(DateTime::ATOM);

Isso gera uma representação adequada para troca de informações entre sistemas.

echo date("Y-m-d");

35. Datas no MySQL

Ao trabalhar com PHP e MySQL, um formato muito comum é:

YYYY-MM-DD

Por exemplo:

2026-08-19

Para data e hora:

2026-08-19 15:30:45

No PHP:

$data = date("Y-m-d");

E:

$dataHora = date("Y-m-d H:i:s");

Isso é muito utilizado ao inserir registros no banco de dados.

36. Exemplo prático: prazo de pagamento

Imagine um sistema que registra uma compra e determina que o pagamento deve ocorrer em 15 dias.

$dataCompra = new DateTime();

$dataVencimento = clone $dataCompra;

$dataVencimento->modify("+15 days");

echo "Compra: " . $dataCompra->format("d/m/Y") . "<br>";
echo "Vencimento: " . $dataVencimento->format("d/m/Y");

O resultado será semelhante a:

Compra: 19/08/2026
Vencimento: 03/09/2026

Esse tipo de cálculo aparece frequentemente em sistemas financeiros.

37. Exemplo prático: calcular idade

Podemos utilizar DateTime e diff() para calcular a idade.

$dataNascimento = new DateTime("2005-08-19");
$dataAtual = new DateTime();

$idade = $dataNascimento->diff($dataAtual);

echo "Idade: " . $idade->y . " anos";

O y representa a quantidade completa de anos entre as duas datas.

38. Exemplo prático: verificar vencimento

Podemos verificar se uma determinada data já passou:

$hoje = new DateTime();
$vencimento = new DateTime("2026-08-30");

if ($hoje > $vencimento) {
    echo "Vencido";
} else {
    echo "Ainda está dentro do prazo";
}

Isso pode ser usado em:

  • boletos;
  • assinaturas;
  • contratos;
  • mensalidades;
  • documentos;
  • promoções;
  • certificados.

39. Exemplo completo

Um pequeno sistema pode utilizar várias funcionalidades:

<?php

date_default_timezone_set("America/Fortaleza");

$hoje = new DateTime();

$vencimento = clone $hoje;
$vencimento->modify("+30 days");

$diferenca = $hoje->diff($vencimento);

echo "Data atual: " . $hoje->format("d/m/Y H:i:s") . "<br>";

echo "Vencimento: " . $vencimento->format("d/m/Y") . "<br>";

echo "Dias restantes: " . $diferenca->days;

Esse exemplo:

  1. Define o fuso horário;
  1. Obtém a data atual;
  1. Cria uma data de vencimento;
  1. Adiciona 30 dias;
  1. Calcula a diferença;
  1. Exibe as informações.
