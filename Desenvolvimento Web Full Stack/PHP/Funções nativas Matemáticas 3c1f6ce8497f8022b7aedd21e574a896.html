Funções Nativas para Tarefas Matemáticas no PHP

O PHP possui diversas funções nativas para realizar operações matemáticas, desde cálculos simples, como arredondamento e valor absoluto, até operações mais avançadas, como potência, raiz quadrada, logaritmos e funções trigonométricas.

Essas funções fazem parte da própria linguagem, portanto, normalmente não é necessário instalar nenhuma biblioteca adicional para utilizá-las.

1. abs() — Valor absoluto

A função abs() retorna o valor absoluto de um número, ou seja, elimina o sinal negativo quando ele existe.

Sintaxe

abs(numero);

Exemplo

<?php

echo abs(-50);

Resultado:

50

Outro exemplo:

$temperatura = -15;

echo abs($temperatura);

Resultado:

15

É útil quando precisamos trabalhar apenas com a distância ou magnitude de um valor.

2. pow() — Potência

A função pow() calcula uma potência.

Sintaxe

pow(base, expoente);

Exemplo

<?php

echo pow(2, 3);

Resultado:

8

Porque:

2³ = 2 × 2 × 2 = 8

Também podemos armazenar o resultado:

$base = 5;
$expoente = 2;

$resultado = pow($base, $expoente);

echo $resultado;

Resultado:

25

Operador *

No PHP também podemos utilizar o operador de exponenciação:

$resultado = 2 ** 3;

echo $resultado;

Resultado:

8

Para operações simples, ** costuma ser mais direto.

3. sqrt() — Raiz quadrada

A função sqrt() calcula a raiz quadrada de um número.

Sintaxe

sqrt(numero);

Exemplo

<?php

echo sqrt(25);

Resultado:

5

Outro exemplo:

$resultado = sqrt(81);

echo $resultado;

Resultado:

9

Também pode retornar números decimais:

echo sqrt(2);

Resultado aproximado:

1.4142135623731

4. round() — Arredondamento

A função round() arredonda um número para o valor inteiro mais próximo ou para uma quantidade determinada de casas decimais.

Sintaxe

round(numero, casas);

Exemplo simples

echo round(10.6);

Resultado:

11

Outro:

echo round(10.4);

Resultado:

10

Definindo casas decimais

$valor = 15.6789;

echo round($valor, 2);

Resultado:

15.68

Isso é bastante utilizado em cálculos financeiros e na apresentação de valores.

5. ceil() — Arredondamento para cima

A função ceil() sempre arredonda um número para cima.

Exemplo

echo ceil(10.1);

Resultado:

11

Mesmo que o valor esteja muito próximo de 10:

echo ceil(10.01);

Resultado:

11

Também funciona com números negativos:

echo ceil(-10.8);

Resultado:

-10

Isso acontece porque o arredondamento é feito em direção ao infinito positivo.

6. floor() — Arredondamento para baixo

A função floor() faz o contrário de ceil(): arredonda sempre para baixo.

echo floor(10.9);

Resultado:

10

Outro exemplo:

echo floor(10.1);

Resultado:

10

Com números negativos:

echo floor(-10.1);

Resultado:

-11

7. Diferença entre round(), ceil() e floor()

Essas três funções são muito importantes:

FunçãoCom 10.6Com 10.2
round()1110
ceil()1111
floor()1010

Em resumo:

  • round() → arredonda para o valor mais próximo.
  • ceil() → sempre para cima.
  • floor() → sempre para baixo.

8. intdiv() — Divisão inteira

A função intdiv() realiza uma divisão e retorna somente a parte inteira do resultado.

Exemplo

echo intdiv(10, 3);

Resultado:

3

A divisão normal seria:

10 / 3 = 3.333...

Mas intdiv() retorna apenas:

3

Outro exemplo:

$idade = 25;
$grupos = intdiv($idade, 5);

echo $grupos;

Resultado:

5

É bastante útil quando precisamos dividir elementos em grupos inteiros.

9. Operador % — Resto da divisão

O operador % retorna o resto de uma divisão inteira.

echo 10 % 3;

Resultado:

1

Porque:

10 ÷ 3 = 3
resto = 1

Um dos usos mais comuns é verificar se um número é par ou ímpar.

Verificando se é par

$numero = 10;

if ($numero % 2 == 0) {
    echo "Número par";
}

Verificando se é ímpar

$numero = 7;

if ($numero % 2 != 0) {
    echo "Número ímpar";
}

10. min() — Menor valor

A função min() retorna o menor valor entre os valores fornecidos.

echo min(10, 5, 20, 3, 8);

Resultado:

3

Também podemos utilizar arrays:

$numeros = [10, 5, 20, 3, 8];

echo min($numeros);

Resultado:

3

11. max() — Maior valor

A função max() retorna o maior valor.

echo max(10, 5, 20, 3, 8);

Resultado:

20

Com array:

$numeros = [10, 5, 20, 3, 8];

echo max($numeros);

Resultado:

20

12. random_int() — Número inteiro aleatório

random_int() gera um número inteiro aleatório dentro de um intervalo.

Sintaxe

random_int(minimo, maximo);

Exemplo

$numero = random_int(1, 100);

echo $numero;

Pode produzir, por exemplo:

57

Em outra execução:

12

É diferente de simplesmente escolher um número fixo, pois o resultado varia a cada execução.

É especialmente útil quando é necessário gerar valores aleatórios de maneira apropriada para situações que exigem segurança.

13. rand() — Número aleatório

Outra função tradicional para gerar números aleatórios é rand().

echo rand(1, 10);

Pode retornar:

7

ou:

3

ou qualquer outro número dentro do intervalo.

Entretanto, para geração de valores que tenham requisitos de segurança, é preferível utilizar random_int().

14. pi() — Valor de π

A função pi() retorna o valor da constante matemática π (pi).

echo pi();

Resultado aproximado:

3.1415926535898

Pode ser utilizada para calcular a área de um círculo.

Exemplo

$raio = 5;

$area = pi() * ($raio ** 2);

echo $area;

Resultado aproximado:

78.539816339745

15. Funções trigonométricas

O PHP também possui funções para cálculos de trigonometria.

Entre elas estão:

sin()
cos()
tan()

Por exemplo:

echo sin(0);

Resultado:

0

Importante

As funções trigonométricas do PHP trabalham com radianos, e não diretamente com graus.

Para converter graus para radianos:

$radianos = deg2rad(90);

echo sin($radianos);

Resultado aproximado:

1

16. asin(), acos() e atan()

Também existem funções trigonométricas inversas:

asin()
acos()
atan()

Elas são utilizadas para obter ângulos a partir de determinados valores.

Exemplo:

$resultado = asin(1);

echo $resultado;

Resultado aproximado:

1.5707963267949

Esse valor está em radianos.

Podemos convertê-lo para graus:

$angulo = rad2deg(asin(1));

echo $angulo;

Resultado:

90

17. log() — Logaritmo

A função log() calcula o logaritmo natural de um número.

echo log(10);

Também podemos especificar uma base:

echo log(100, 10);

Resultado:

2

Porque:

10² = 100

18. log10() — Logaritmo na base 10

Quando queremos especificamente o logaritmo na base 10, podemos utilizar log10().

echo log10(1000);

Resultado:

3

Porque:

10³ = 1000

19. exp() — Exponencial

A função exp() calcula e elevado à potência fornecida.

echo exp(1);

Resultado aproximado:

2.718281828459

Esse valor corresponde à constante matemática e.

Por exemplo:

echo exp(2);

É equivalente matematicamente a:

e²

20. fmod() — Resto de divisão com números decimais

O operador % trabalha principalmente com valores inteiros. Para obter o resto de uma divisão envolvendo números de ponto flutuante, podemos utilizar fmod().

echo fmod(10.5, 3);

Resultado:

1.5

Porque:

10.5 = 3 × 3 + 1.5

21. hypot() — Hipotenusa

A função hypot() calcula a hipotenusa de um triângulo retângulo.

echo hypot(3, 4);

Resultado:

5

Matematicamente:

√(3² + 4²)
= √(9 + 16)
= √25
= 5

Isso é útil em cálculos envolvendo geometria, distâncias e coordenadas.

22. is_finite(), is_infinite() e is_nan()

O PHP também possui funções para verificar determinados estados de números.

is_finite()

Verifica se o valor é um número finito:

$numero = 100;

var_dump(is_finite($numero));

Resultado:

bool(true)

is_infinite()

Verifica se o valor representa infinito:

var_dump(is_infinite(INF));

Resultado:

bool(true)

is_nan()

Verifica se o valor é NaN (Not a Number):

var_dump(is_nan(NAN));

Resultado:

bool(true)

Essas funções são úteis para validar resultados de cálculos matemáticos.

23. Exemplo prático completo

Podemos combinar várias funções matemáticas em um programa.

<?php

$numero = -25;

echo "Valor absoluto: " . abs($numero) . "<br>";

echo "Raiz quadrada: " . sqrt(25) . "<br>";

echo "Potência: " . pow(5, 2) . "<br>";

echo "Arredondamento: " . round(10.67) . "<br>";

echo "Arredondamento para cima: " . ceil(10.2) . "<br>";

echo "Arredondamento para baixo: " . floor(10.8) . "<br>";

echo "Menor valor: " . min(10, 20, 5, 30) . "<br>";

echo "Maior valor: " . max(10, 20, 5, 30) . "<br>";

echo "Número aleatório: " . random_int(1, 100) . "<br>";

echo "Valor de PI: " . pi();

Esse exemplo demonstra como as funções matemáticas podem ser utilizadas em conjunto em uma aplicação PHP.

Conclusão

As funções nativas para tarefas matemáticas tornam o PHP capaz de realizar desde cálculos básicos até operações matemáticas mais complexas sem a necessidade de implementar essas operações manualmente.

As mais importantes para dominar inicialmente são:

abs()
pow()
sqrt()
round()
ceil()
floor()
intdiv()
min()
max()
random_int()
pi()

Depois, conforme o nível aumenta, vale estudar também as funções trigonométricas, logarítmicas, exponenciais e de manipulação de números de ponto flutuante.
