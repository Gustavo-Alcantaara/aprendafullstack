Introdução ao PHP

O PHP (acrônimo recursivo para PHP: Hypertext Preprocessor) é uma linguagem de programação criada especialmente para o desenvolvimento web. Seu principal objetivo é gerar páginas dinâmicas, permitindo que um site responda de forma diferente dependendo das ações do usuário, dos dados armazenados em um banco de dados ou de outras informações.

Enquanto HTML define a estrutura de uma página e CSS define sua aparência, o PHP é responsável pela lógica do sistema.

Por exemplo:

  • autenticar usuários;
  • processar formulários;
  • acessar bancos de dados;
  • criar sistemas de login;
  • gerar relatórios;
  • controlar sessões de usuários;
  • construir APIs.

História do PHP

O PHP foi criado em 1994 por Rasmus Lerdorf.

Inicialmente, ele era apenas um conjunto de scripts chamado Personal Home Page Tools, usado para controlar visitas ao site pessoal de Rasmus.

Com o tempo, a linguagem foi evoluindo:

  • PHP/FI – adicionou processamento de formulários.
  • PHP 3 – tornou-se uma linguagem completa.
  • PHP 4 – trouxe melhorias de desempenho.
  • PHP 5 – introduziu recursos de Orientação a Objetos mais robustos.
  • PHP 7 – grande aumento de desempenho.
  • PHP 8 – adicionou novos recursos modernos, como JIT (Just-In-Time Compiler), atributos, union types, match expressions e diversas otimizações.

Hoje o PHP continua sendo uma das linguagens mais utilizadas na web.

O que é PHP?

PHP é uma linguagem:

  • Interpretada
  • Open Source
  • Multiparadigma
  • Executada no servidor (Server-Side)
  • Voltada principalmente para aplicações web

Sua função principal é produzir conteúdo que será enviado para o navegador.

O navegador nunca executa PHP.

Quem executa o PHP é o servidor.

Fluxo de funcionamento:

Cliente (Browser)
        │
        ▼
Solicitação HTTP
        │
        ▼
Servidor Web
(Apache/Nginx)
        │
        ▼
Arquivo PHP
        │
        ▼
PHP executa o código
        │
        ▼
Consulta banco de dados (se necessário)
        │
        ▼
Gera HTML
        │
        ▼
Resposta enviada ao navegador

O usuário recebe apenas o resultado.

Nunca o código PHP.

Como o PHP funciona

Imagine que exista um arquivo:

index.php

Seu conteúdo:

<?php

echo "Olá Mundo";

?>

Quando o navegador acessa:

http://localhost/index.php

Acontece:

  1. O navegador envia uma requisição.
  1. O servidor recebe.
  1. O PHP interpreta o código.
  1. O echo gera texto.
  1. O servidor envia:
Olá Mundo

O navegador nunca vê:

echo "Olá Mundo";

Apenas o resultado.

Linguagem Server-Side

Existem duas grandes categorias de linguagens web.

Client-Side

Executam no navegador.

Exemplos:

  • JavaScript
  • HTML
  • CSS

São responsáveis por:

  • interface;
  • animações;
  • validações simples;
  • interação com o usuário.

Server-Side

Executam no servidor.

Exemplos:

  • PHP
  • Java
  • C#
  • Python
  • Ruby
  • Node.js (JavaScript no servidor)

São responsáveis por:

  • segurança;
  • banco de dados;
  • autenticação;
  • regras de negócio;
  • geração de páginas.

Por que usar PHP?

O PHP oferece diversas vantagens.

Fácil de aprender

Sua sintaxe lembra C, Java e JavaScript.

Exemplo:

$nome = "João";
$idade = 20;

É simples e intuitivo.

Integração com HTML

PHP pode ser misturado diretamente ao HTML.

<h1>

<?php
echo "Bem-vindo!";
?>

</h1>

Resultado:

<h1>Bem-vindo!</h1>

Grande comunidade

Existem milhões de desenvolvedores usando PHP.

Isso significa:

  • muitos cursos;
  • documentação;
  • bibliotecas;
  • frameworks;
  • respostas em fóruns.

Excelente suporte a bancos de dados

PHP possui suporte nativo para:

  • MySQL
  • PostgreSQL
  • SQLite
  • MariaDB
  • Oracle
  • SQL Server

Alto desempenho

Desde o PHP 7, a linguagem ficou muito mais rápida.

Hoje consegue atender milhares de requisições por segundo dependendo do servidor.

Sintaxe básica

Todo código PHP começa com:

<?php

// código

?>

A tag de fechamento (?>) é opcional quando o arquivo contém apenas código PHP e costuma ser omitida em projetos modernos para evitar problemas com espaços em branco.

Primeira instrução

A instrução mais conhecida é:

<?php

echo "Olá Mundo";

?>

echo envia conteúdo para a saída (geralmente o navegador).

Também existe:

print "Olá";

Ambos exibem texto.

Comentários

Uma linha:

// comentário

ou

# comentário

Múltiplas linhas:

/*
comentário
comentário
comentário
*/

Variáveis

No PHP toda variável começa com $.

$nome = "Carlos";
$idade = 25;
$altura = 1.80;

Não é necessário declarar o tipo.

O PHP identifica automaticamente.

Tipos de dados

Os principais tipos são:

$string = "Texto";
$inteiro = 20;
$decimal = 5.6;
$booleano = true;
$array = [];
$objeto = new stdClass();
$nulo = null;

O PHP é:

  • Multiplataforma

Vantagens

Esses pontos podem ser minimizados com padrões modernos, como uso de frameworks, arquitetura em camadas e boas práticas de desenvolvimento.

Resumo

O PHP é uma linguagem de programação executada no servidor, criada para o desenvolvimento web. Diferentemente do JavaScript, que roda no navegador, o PHP processa a lógica da aplicação no servidor e envia apenas o resultado ao cliente, normalmente em forma de HTML ou JSON. Sua facilidade de aprendizado, integração nativa com HTML, excelente suporte a bancos de dados e ampla adoção no mercado fazem dele uma das tecnologias mais importantes para o desenvolvimento de aplicações web, desde sites simples até sistemas corporativos de grande porte.
