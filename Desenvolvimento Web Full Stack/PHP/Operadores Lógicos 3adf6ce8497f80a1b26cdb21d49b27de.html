Operadores Lógicos no PHP

Os operadores lógicos são utilizados para combinar ou modificar expressões booleanas. Eles permitem criar condições mais complexas, verificando duas ou mais expressões ao mesmo tempo.

O resultado de uma operação lógica é sempre um valor booleano:

  • true (verdadeiro)
  • false (falso)

Esses operadores são amplamente utilizados em estruturas condicionais (if, elseif, while, for) para controlar o fluxo de execução de um programa.

O que são operadores lógicos?

Imagine que um sistema permita o acesso apenas para usuários que:

  • sejam maiores de 18 anos e
  • estejam logados.

Nesse caso, é necessário verificar duas condições simultaneamente.

É exatamente para isso que servem os operadores lógicos.

Exemplo:

$idade >= 18 && $logado

A expressão será verdadeira apenas se as duas condições forem verdadeiras.

Operador AND (&&)

O operador AND significa "E".

A expressão será verdadeira somente se todas as condições forem verdadeiras.

Sintaxe:

condição1 && condição2

Exemplo:

<?php

$idade = 20;
$logado = true;

if ($idade >= 18 && $logado) {
    echo "Acesso permitido";
}

Resultado:

Acesso permitido

Operador OR (||)

O operador OR significa "OU".

A expressão será verdadeira quando pelo menos uma das condições for verdadeira.

Sintaxe:

condição1 || condição2

Exemplo:

<?php

$vip = false;
$admin = true;

if ($vip || $admin) {
    echo "Entrada permitida";
}

Resultado:

Entrada permitida

Operador NOT (!)

O operador NOT significa "NÃO".

Ele inverte o valor lógico de uma expressão.

Sintaxe:

!condição

Exemplo:

<?php

$logado = false;

if (!$logado) {
    echo "Faça login";
}

Resultado:

Faça login

Como $logado é false, o operador ! transforma o resultado em true, permitindo a execução do bloco.

Operador XOR (xor)

O operador XOR (Exclusive OR) retorna true apenas quando uma única condição é verdadeira.

Se ambas forem verdadeiras ou ambas falsas, o resultado será false.

Exemplo:

<?php

$a = true;
$b = false;

var_dump($a xor $b);

bool(true)

Combinando operadores

É possível utilizar vários operadores na mesma condição.

Exemplo:

<?php

$idade = 25;
$logado = true;
$admin = false;

if (($idade >= 18 && $logado) || $admin) {
    echo "Acesso permitido";
}

Resultado:

Acesso permitido

Os parênteses deixam a ordem de avaliação mais clara e ajudam a evitar erros.

Exemplos práticos

Sistema de login

<?php

$usuario = "admin";
$senha = "123456";

if ($usuario == "admin" && $senha == "123456") {
    echo "Login realizado";
}

Aprovação em concurso

<?php

$nota = 82;
$cotas = false;

if ($nota >= 80 || $cotas) {
    echo "Aprovado";
}

Verificando acesso

<?php

$bloqueado = false;

if (!$bloqueado) {
    echo "Acesso liberado";
}

Precedência dos operadores

Os operadores seguem uma ordem de prioridade.

Por exemplo:

<?php

$resultado = true || false && false;

O PHP executa primeiro:

false && false

e depois:

true || false

Resultado final:

true

Para evitar dúvidas, utilize parênteses:

<?php

if (($idade >= 18 && $logado) || $admin) {
    // código
}

Isso torna o código mais legível e previsível.

&& e and: qual a diferença?

O mesmo vale para || e or.

Embora tenham o mesmo significado lógico, eles possuem precedências diferentes.

Exemplo:

<?php

$resultado = true && false;

e

<?php

$resultado = true and false;

Podem produzir comportamentos diferentes quando usados junto com atribuições (=), devido à ordem de avaliação.

Por isso, a recomendação é utilizar && e ||, que são mais comuns e evitam confusões.

Boas práticas

  • Utilize &&, || e ! em vez de and e or.
  • Use parênteses para deixar condições complexas mais claras.
  • Evite criar expressões muito longas; se necessário, divida-as em partes.
  • Escolha nomes de variáveis que deixem a condição fácil de entender, como $usuarioLogado, $estoqueDisponivel e $pagamentoConfirmado.

Resumo

Os operadores lógicos permitem combinar ou modificar condições booleanas, tornando possível criar regras de decisão mais complexas. Os principais operadores são && (AND), que exige que todas as condições sejam verdadeiras; || (OR), que exige pelo menos uma condição verdadeira; e ! (NOT), que inverte o resultado lógico de uma expressão. O PHP também oferece xor, and e or, embora estes últimos sejam menos utilizados devido às diferenças de precedência. Os operadores lógicos são essenciais para implementar autenticação, validação de dados, controle de acesso, regras de negócio e diversas outras funcionalidades presentes em aplicações web.
