Array Multidimensional

Array Multidimensional em PHP

Um array multidimensional é um array que contém outros arrays como elementos. Ele é utilizado quando precisamos representar dados que possuem mais de uma dimensão ou estão organizados em diferentes níveis.

Enquanto um array simples pode representar uma lista:

$frutas = ["Maçã", "Banana", "Laranja"];

um array multidimensional pode representar uma tabela:

$alunos = [
    ["João", 8, 7],
    ["Maria", 9, 10],
    ["Pedro", 6, 8]
];

Nesse caso, temos vários arrays dentro do array $alunos.

1. Estrutura de um Array Multidimensional

Considere:

$alunos = [
    ["João", 8, 7],
    ["Maria", 9, 10],
    ["Pedro", 6, 8]
];

Podemos visualizar a estrutura assim:

ÍndiceNomeNota 1Nota 2
0João87
1Maria910
2Pedro68

Temos duas dimensões:

  • Primeira dimensão: identifica o aluno.
  • Segunda dimensão: identifica os dados daquele aluno.

Por isso, para acessar um determinado valor, utilizamos dois índices.

2. Acessando Elementos

Para acessar "João":

echo $alunos[0][0];

Resultado:

João

Para acessar a nota 8:

echo $alunos[0][1];

Para acessar a nota 10 da Maria:

echo $alunos[1][2];

A lógica é:

$array[linha][coluna]

Por exemplo:

$alunos[1][2]

significa:

  • 1 → segundo aluno;
  • 2 → terceiro elemento desse aluno.

3. Alterando Valores

Podemos modificar um elemento específico:

$alunos = [
    ["João", 8, 7],
    ["Maria", 9, 10]
];

$alunos[0][1] = 9;

Agora João possui:

João, 9, 7

Também podemos alterar o nome:

$alunos[1][0] = "Mariana";

4. Adicionando Elementos

Podemos adicionar um novo array ao array multidimensional:

$alunos[] = ["Carlos", 7, 8];

Agora temos:

$alunos = [
    ["João", 8, 7],
    ["Maria", 9, 10],
    ["Carlos", 7, 8]
];

Também podemos adicionar um novo valor dentro de um dos arrays:

$alunos[0][] = 10;

Agora João possui três notas:

João, 8, 7, 10

5. Percorrendo um Array Multidimensional

Para percorrer todas as informações, podemos utilizar foreach dentro de outro foreach.

$alunos = [
    ["João", 8, 7],
    ["Maria", 9, 10],
    ["Pedro", 6, 8]
];

foreach ($alunos as $aluno) {
    foreach ($aluno as $dado) {
        echo $dado . " ";
    }

    echo "<br>";
}

Resultado:

João 8 7
Maria 9 10
Pedro 6 8

O primeiro foreach percorre os alunos.

O segundo foreach percorre os dados de cada aluno.

6. Arrays Multidimensionais Associativos

Em aplicações reais, muitas vezes é melhor utilizar índices associativos em vez de depender de números.

Por exemplo:

$alunos = [
    [
        "nome" => "João",
        "idade" => 20,
        "nota" => 8
    ],
    [
        "nome" => "Maria",
        "idade" => 21,
        "nota" => 9
    ]
];

Agora podemos acessar os dados utilizando seus nomes:

echo $alunos[0]["nome"];

Resultado:

João

E:

echo $alunos[1]["nota"];

Resultado:

9

Essa abordagem costuma ser mais legível e organizada.

7. Percorrendo Arrays Associativos Multidimensionais

Podemos utilizar dois foreach:

foreach ($alunos as $aluno) {
    echo "Nome: " . $aluno["nome"] . "<br>";
    echo "Idade: " . $aluno["idade"] . "<br>";
    echo "Nota: " . $aluno["nota"] . "<br>";
    echo "<br>";
}

Resultado:

Nome: João
Idade: 20
Nota: 8

Nome: Maria
Idade: 21
Nota: 9

Essa estrutura é muito comum em sistemas PHP.

8. Array com Três Dimensões

PHP também permite criar arrays com três ou mais dimensões.

Por exemplo:

$escola = [
    [
        ["João", 8],
        ["Maria", 9]
    ],
    [
        ["Pedro", 7],
        ["Ana", 10]
    ]
];

Nesse caso, temos três níveis.

Podemos acessar um valor assim:

echo $escola[0][1][0];

Resultado:

Maria

A estrutura pode ser entendida como:

Escola
 ├── Grupo 0
 │    ├── João
 │    └── Maria
 │
 └── Grupo 1
      ├── Pedro
      └── Ana

Embora seja possível ter muitas dimensões, arrays excessivamente profundos podem tornar o código difícil de entender e manter.

9. Exemplo Prático: Produtos

Um exemplo bastante comum é armazenar produtos:

$produtos = [
    [
        "nome" => "Notebook",
        "preco" => 3500,
        "estoque" => 10
    ],
    [
        "nome" => "Mouse",
        "preco" => 80,
        "estoque" => 25
    ],
    [
        "nome" => "Teclado",
        "preco" => 150,
        "estoque" => 15
    ]
];

Podemos percorrer os produtos:

foreach ($produtos as $produto) {
    echo "Produto: " . $produto["nome"] . "<br>";
    echo "Preço: R$ " . $produto["preco"] . "<br>";
    echo "Estoque: " . $produto["estoque"] . "<br>";
    echo "<hr>";
}

Esse tipo de estrutura pode ser utilizado para representar informações que posteriormente vêm de um banco de dados, por exemplo.

10. Array Multidimensional e Banco de Dados

Arrays multidimensionais são bastante utilizados no desenvolvimento PHP porque dados retornados de bancos de dados frequentemente podem ser representados dessa maneira.

Imagine que uma consulta retorne:

ID | Nome   | Email
1  | João   | joao@email.com
2  | Maria  | maria@email.com
3  | Pedro  | pedro@email.com

Isso poderia ser representado em PHP como:

$usuarios = [
    [
        "id" => 1,
        "nome" => "João",
        "email" => "joao@email.com"
    ],
    [
        "id" => 2,
        "nome" => "Maria",
        "email" => "maria@email.com"
    ],
    [
        "id" => 3,
        "nome" => "Pedro",
        "email" => "pedro@email.com"
    ]
];

E então:

foreach ($usuarios as $usuario) {
    echo $usuario["nome"] . " - ";
    echo $usuario["email"] . "<br>";
}

Resultado:

João - joao@email.com
Maria - maria@email.com
Pedro - pedro@email.com

11. Principais Características

Os arrays multidimensionais permitem:

  • Armazenar arrays dentro de arrays;
  • Representar tabelas e estruturas complexas;
  • Organizar informações relacionadas;
  • Trabalhar com vários registros;
  • Utilizar índices numéricos ou associativos;
  • Percorrer dados utilizando foreach;
  • Representar estruturas semelhantes às informações retornadas por bancos de dados e APIs.

Resumo

Um array multidimensional possui a seguinte ideia básica:

$array = [
    ["valor1", "valor2"],
    ["valor3", "valor4"]
];

Para acessar:

$array[0][1];

Para percorrer:

foreach ($array as $linha) {
    foreach ($linha as $valor) {
        echo $valor;
    }
}

E uma estrutura associativa, geralmente mais prática em aplicações:

$usuarios = [
    [
        "nome" => "João",
        "idade" => 20
    ],
    [
        "nome" => "Maria",
        "idade" => 21
    ]
];

Em resumo: o array multidimensional é fundamental quando precisamos trabalhar com conjuntos de dados organizados em vários níveis, sendo muito utilizado em sistemas PHP, especialmente em conjunto com bancos de dados, APIs, formulários e sistemas de gerenciamento de informações.
