Embutindo PHP em páginas HTML

Embutindo blocos PHP em páginas HTML

Uma das principais características do PHP é sua capacidade de ser embutido diretamente em documentos HTML. Isso permite criar páginas dinâmicas, onde apenas algumas partes são geradas pelo PHP enquanto o restante continua sendo HTML comum.

Na prática, você escreve HTML normalmente e, quando precisar executar lógica no servidor, abre um bloco PHP com <?php e o fecha com ?>.

Como funciona

Quando o servidor encontra um bloco PHP, ele:

  1. Interrompe temporariamente a leitura do HTML.
  1. Executa o código PHP.
  1. Insere o resultado da execução no documento.
  1. Continua processando o restante do HTML.

Por exemplo:

<!DOCTYPE html>
<html>

<head>
    <title>Meu Site</title>
</head>

<body>

    <h1>Bem-vindo!</h1>

    <?php

    echo "<p>Esta mensagem foi gerada pelo PHP.</p>";

    ?>

</body>

</html>

O navegador receberá:

<!DOCTYPE html>
<html>

<head>
    <title>Meu Site</title>
</head>

<body>

    <h1>Bem-vindo!</h1>

    <p>Esta mensagem foi gerada pelo PHP.</p>

</body>

</html>

Observe que o navegador não recebe o código PHP, apenas o HTML gerado.

Delimitadores do PHP

Todo bloco PHP começa com:

<?php

e termina com:

?>

Exemplo:

<p>Texto em HTML</p>

<?php
echo "Texto produzido pelo PHP";
?>

<p>Outro texto HTML</p>

É possível abrir e fechar vários blocos PHP na mesma página.

<h1>

<?php
echo "Ghostware";
?>

</h1>

<p>

<?php
echo "Logic Above Limits";
?>

</p>

Misturando HTML e PHP

Na maioria dos projetos, apenas pequenas partes da página precisam ser dinâmicas.

Por exemplo:

<h2>Usuário</h2>

<p>

<?php
echo "Gustavo";
?>

</p>

Ou ainda:

<p>Hoje é:

<?php
echo date("d/m/Y");
?>

</p>

Resultado:

<p>Hoje é: 28/06/2026</p>

Inserindo variáveis

É muito comum exibir valores armazenados em variáveis.

<?php

$nome = "Carlos";

?>

<h1>

<?php
echo $nome;
?>

</h1>

Resultado:

<h1>Carlos</h1>

Outro exemplo:

<?php

$produto = "Notebook";
$preco = 3500;

?>

<p>Produto: <?php echo $produto; ?></p>

<p>Preço: R$ <?php echo $preco; ?></p>

Resultado:

<p>Produto: Notebook</p>

<p>Preço: R$ 3500</p>

Utilizando estruturas de decisão

Você pode controlar quais elementos HTML serão exibidos.

<?php

$logado = true;

?>

<?php if ($logado) { ?>

<h2>Bem-vindo!</h2>

<?php } ?>

Caso $logado seja false, o <h2> simplesmente não aparecerá na página.

Também é possível utilizar if e else.

<?php

$idade = 17;

?>

<?php if ($idade >= 18) { ?>

<p>Maior de idade</p>

<?php } else { ?>

<p>Menor de idade</p>

<?php } ?>

Utilizando laços de repetição

Uma das maiores vantagens é gerar HTML automaticamente.

Exemplo:

<ul>

<?php

for ($i = 1; $i <= 5; $i++) {

?>

    <li>Item <?php echo $i; ?></li>

<?php

}

?>

</ul>

Resultado:

<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
    <li>Item 4</li>
    <li>Item 5</li>
</ul>

Sem PHP, seria necessário escrever cada <li> manualmente.

Misturando HTML dentro do echo

Também é possível gerar HTML usando apenas echo.

<?php

echo "<h1>Ghostware</h1>";

echo "<p>Logic Above Limits</p>";

?>

Embora funcione, isso pode dificultar a leitura do código quando há muito HTML.

Qual abordagem é mais recomendada?

Em projetos modernos, normalmente evita-se colocar grandes blocos de HTML dentro de echo.

Em vez disso, escreve-se o HTML normalmente e utiliza-se PHP apenas onde for necessário.

Menos recomendado:

<?php

echo "<div>";
echo "<h1>Produto</h1>";
echo "<p>Notebook</p>";
echo "</div>";

?>

Mais recomendado:

<div>

    <h1>Produto</h1>

    <p><?php echo $produto; ?></p>

</div>

Essa abordagem deixa o código mais organizado e fácil de manter.

Sintaxe abreviada (<?= ?>)

O PHP possui uma forma curta para imprimir valores.

Em vez de escrever:

<?php echo $nome; ?>

Você pode escrever:

<?= $nome ?>

Exemplo:

<?php

$empresa = "Ghostware";

?>

<h1><?= $empresa ?></h1>

Resultado:

<h1>Ghostware</h1>

Essa sintaxe é amplamente utilizada em projetos modernos por ser mais concisa.

Quando usar apenas PHP?

Se um arquivo contém apenas código PHP (como uma classe, uma função ou uma API), normalmente não se utiliza HTML.

Exemplo:

<?php

function somar($a, $b)
{
    return $a + $b;
}

echo somar(5, 8);

Nesses casos, inclusive, é comum omitir a tag de fechamento ?>, evitando problemas com espaços em branco no final do arquivo.

Boas práticas

  • Escreva o HTML normalmente e utilize PHP apenas para inserir conteúdo dinâmico.
  • Evite grandes blocos de HTML dentro de echo.
  • Prefira <?= ?> para imprimir valores simples.
  • Mantenha a lógica da aplicação separada da apresentação sempre que possível.
  • Em projetos maiores, considere utilizar mecanismos de templates ou frameworks que ajudam a organizar melhor o código.

Resumo

A possibilidade de embutir blocos PHP em páginas HTML é um dos recursos que tornou o PHP tão popular no desenvolvimento web. Ela permite combinar a estrutura estática do HTML com a lógica dinâmica do PHP de forma simples e eficiente. O servidor executa o código PHP, substitui os blocos pelo resultado gerado e envia apenas o HTML final ao navegador, permitindo criar páginas personalizadas, exibir dados de bancos de dados, processar formulários e controlar o conteúdo exibido ao usuário.

Tag curta (Short Open Tag) no PHP

Além da tag padrão <?php, o PHP possui a chamada tag curta (Short Open Tag), que permite iniciar um bloco PHP usando apenas <?.

Exemplo:

<?
echo "Olá Mundo";
?>

Ela produz exatamente o mesmo resultado que:

<?php
echo "Olá Mundo";
?>

Por que ela existe?

A tag curta foi criada para tornar a escrita do código mais rápida e compacta, principalmente quando o PHP era muito utilizado em conjunto com HTML.

Exemplo:

<h1>

<?
echo "Ghostware";
?>

</h1>

Problemas da tag curta

Apesar de funcionar em alguns ambientes, não é recomendada.

O motivo é que ela depende da configuração do servidor.

Existe uma diretiva no arquivo php.ini chamada:

short_open_tag = On

Se ela estiver:

short_open_tag = Off

o código

<?
echo "Olá";
?>

não será interpretado como PHP. Em vez disso, o navegador exibirá literalmente:

<?
echo "Olá";
?>

Isso torna o código não portável, pois ele pode funcionar em um servidor e falhar em outro.

A recomendação oficial

A recomendação é utilizar sempre:

<?php

Essa sintaxe:

  • funciona em qualquer servidor;
  • segue o padrão oficial da linguagem;
  • evita problemas de compatibilidade;
  • é utilizada por frameworks e bibliotecas modernas.

A exceção: <?= ?>

Existe uma exceção importante.

A tag:

<?= $nome ?>

é chamada de tag curta de impressão (Short Echo Tag).

Ela equivale a:

<?php echo $nome; ?>

Diferentemente da tag <?, a sintaxe <?= ?> está sempre disponível desde o PHP 5.4, independentemente da configuração short_open_tag.

Exemplo:

<?php

$empresa = "Ghostware";

?>

<h1><?= $empresa ?></h1>

Resultado:

<h1>Ghostware</h1>

Comparação

SintaxeFunçãoRecomendada?
<?php ... ?>Bloco PHP padrão✅ Sim
<? ... ?>Tag curta❌ Não
<?= ... ?>Impressão abreviada (echo)✅ Sim

Quando usar cada uma?

Para escrever código PHP

Sempre utilize:

<?php

$nome = "Gustavo";

echo $nome;

Para imprimir uma variável em meio ao HTML

Pode utilizar:

<h1><?= $nome ?></h1>

Essa é uma prática muito comum e bastante legível.

Evite

<?

$nome = "Gustavo";

?>

Ela pode não funcionar dependendo da configuração do servidor.

Resumo

O PHP possui três formas de abrir blocos de código:

  • <?php → padrão oficial, compatível com todos os ambientes e recomendado para qualquer bloco PHP.
  • <? → tag curta, depende da configuração short_open_tag do servidor e deve ser evitada em projetos modernos.
  • <?= → tag curta de impressão, equivalente a <?php echo ... ?>, funciona por padrão desde o PHP 5.4 e é amplamente utilizada para inserir valores em páginas HTML.

Em projetos atuais, a combinação mais comum é usar <?php para a lógica da aplicação e <?= ?> para exibir dados dentro do HTML, garantindo legibilidade e compatibilidade.
