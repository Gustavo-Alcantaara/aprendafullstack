Casting de Tipos

Casting de Tipos no PHP

O casting de tipos (ou conversão de tipos) é o processo de converter um valor de um tipo de dado para outro.

Em PHP, essa conversão pode acontecer de duas formas:

  • Conversão implícita: realizada automaticamente pelo PHP.
  • Conversão explícita (casting): realizada pelo programador.

O casting é muito utilizado quando é necessário garantir que uma variável possua um tipo específico antes de realizar cálculos, comparações ou outras operações.

O que é um tipo de dado?

Antes de entender o casting, é importante lembrar que toda variável possui um tipo.

Exemplos:

TipoExemplo
Inteiro (int)10
Ponto flutuante (float)10.5
String"Olá"
Booleano (bool)true
Array[1,2,3]
Objetonew Pessoa()

Cada tipo possui características próprias e é tratado de maneira diferente pelo PHP.

Por que utilizar casting?

Imagine que um formulário envie a idade do usuário.

$idade = "20";

Embora pareça um número, ela é uma string.

Se você deseja garantir que essa informação seja tratada como número inteiro, pode utilizar um casting.

$idade = (int) "20";

Agora a variável passa a ser um inteiro.

Conversão implícita

O PHP possui tipagem dinâmica, ou seja, muitas conversões acontecem automaticamente.

Exemplo:

<?php

$numero = "10";

echo $numero + 5;

Resultado:

15

O PHP converte automaticamente "10" para inteiro antes da soma.

Outro exemplo:

<?php

$valor = 10;

echo "Preço: R$ " . $valor;

Resultado:

Preço: R$ 10

Nesse caso, o número foi convertido automaticamente para string durante a concatenação.

Essa conversão automática facilita o desenvolvimento, mas também pode causar comportamentos inesperados se o programador não souber como ela funciona.

Conversão explícita (Casting)

Na conversão explícita, o programador informa qual tipo deseja utilizar.

Sintaxe:

(tipo) valor

Exemplo:

(int) $numero

ou

(float) $preco

Casting para inteiro (int)

Converte o valor para um número inteiro.

<?php

$valor = 15.9;

$inteiro = (int) $valor;

echo $inteiro;

Resultado:

15

Observe que a parte decimal foi descartada, sem arredondamento.

Outro exemplo:

<?php

$numero = "50";

echo (int) $numero;

Resultado:

50

Casting para float (float)

Converte o valor para ponto flutuante.

<?php

$numero = 20;

echo (float) $numero;

Resultado:

20

Embora a saída pareça igual, internamente o valor agora é do tipo float.

Exemplo verificando o tipo:

<?php

$numero = (float) 20;

var_dump($numero);

Resultado:

float(20)

Casting para string (string)

Converte qualquer valor para texto.

<?php

$idade = 21;

$texto = (string) $idade;

var_dump($texto);

Resultado:

string(2) "21"

Casting para booleano (bool)

Converte um valor para verdadeiro ou falso.

Exemplo:

<?php

$valor = 100;

var_dump((bool) $valor);

Resultado:

bool(true)

Valores considerados false

Ao converter para booleano, os seguintes valores tornam-se false:

  • false
  • 0
  • 0.0
  • "" (string vazia)
  • "0"
  • null
  • [] (array vazio)

Qualquer outro valor será convertido para true.

Exemplo:

<?php

var_dump((bool) 0);
var_dump((bool) "");
var_dump((bool) "PHP");

Resultado:

bool(false)
bool(false)
bool(true)

Casting para array (array)

Converte um valor para um array.

<?php

$nome = "Carlos";

$array = (array) $nome;

print_r($array);

Resultado:

Array
(
    [0] => Carlos
)

Casting para objeto (object)

Converte um valor em um objeto da classe padrão (stdClass).

<?php

$dados = ["nome" => "Ana"];

$objeto = (object) $dados;

echo $objeto->nome;

Resultado:

Ana

Verificando o tipo após o casting

É possível utilizar gettype() ou var_dump().

Exemplo:

<?php

$numero = (int) "50";

echo gettype($numero);

Resultado:

integer

Outro exemplo:

<?php

var_dump((float) 25);

Resultado:

float(25)

Casting x Conversão automática

Considere:

<?php

$numero = "15";

echo $numero + 5;

O PHP converte automaticamente.

Agora com casting:

<?php

$numero = "15";

$numero = (int) $numero;

echo $numero + 5;

Resultado:

20

Ambos funcionam, mas no segundo caso o programador controla explicitamente o tipo da variável.

Cuidados com o casting

Nem toda conversão produz o resultado esperado.

Exemplo:

<?php

$texto = "123abc";

echo (int) $texto;

Resultado:

123

O PHP converte apenas a parte numérica inicial.

Agora:

<?php

$texto = "abc123";

echo (int) $texto;

Resultado:

0

Como a string não começa com um número, o resultado é 0.

Quando utilizar casting?

O casting é bastante utilizado em situações como:

  • Receber dados de formulários ($_GET e $_POST).
  • Trabalhar com cálculos matemáticos.
  • Validar entradas do usuário.
  • Manipular dados vindos de APIs.
  • Converter valores antes de gravar em banco de dados.
  • Garantir que funções recebam o tipo esperado.

Boas práticas

  • Utilize casting apenas quando houver necessidade.
  • Sempre valide os dados antes de convertê-los.
  • Evite depender apenas da conversão automática do PHP em aplicações críticas.
  • Utilize funções como is_int(), is_string(), is_float() e is_bool() para verificar o tipo quando necessário.

Resumo

O casting de tipos é o processo de converter um valor de um tipo de dado para outro. No PHP, essa conversão pode ocorrer automaticamente (conversão implícita) ou ser realizada de forma explícita pelo programador utilizando operadores como (int), (float), (string), (bool), (array) e (object). O uso do casting é importante para garantir que os dados sejam tratados corretamente em cálculos, comparações, validações e comunicação com bancos de dados ou APIs. Conhecer o funcionamento das conversões de tipos ajuda a evitar erros, torna o código mais previsível e contribui para o desenvolvimento de aplicações mais seguras e confiáveis.
