Comentários

Comentários no PHP

Os comentários são trechos de texto inseridos no código-fonte que não são executados pelo PHP. Eles servem para explicar o funcionamento do código, documentar decisões, deixar lembretes ou desativar temporariamente partes do programa durante os testes.

Embora sejam ignorados pelo interpretador, os comentários são muito importantes para manter o código organizado e facilitar sua manutenção.

Por que utilizar comentários?

Comentários ajudam a:

  • Explicar trechos complexos do código.
  • Tornar o código mais fácil de entender.
  • Documentar funções e algoritmos.
  • Deixar observações para outros desenvolvedores.
  • Facilitar a manutenção do sistema.
  • Desativar temporariamente linhas de código durante testes.

Tipos de comentários no PHP

O PHP oferece três formas de criar comentários:

  1. Comentário de uma linha com //
  1. Comentário de uma linha com #
  1. Comentário de múltiplas linhas com /* */

Comentário de uma linha (//)

É a forma mais utilizada.

Tudo o que estiver após // na mesma linha será ignorado.

<?php

// Exibe uma mensagem
echo "Olá, mundo!";

Também pode ser usado ao final de uma instrução:

<?php

echo "Ghostware"; // Nome da empresa

Comentário de uma linha (#)

O caractere # também cria um comentário de uma linha.

<?php

# Este também é um comentário

echo "PHP";

Embora funcione normalmente, ele é menos utilizado. Na maioria dos projetos modernos, prefere-se usar // por ser mais comum e familiar para quem programa em outras linguagens como Java, JavaScript e C#.

Comentário de múltiplas linhas (/* */)

Quando é necessário escrever um comentário maior, utiliza-se /* para iniciar e */ para finalizar.

<?php

/*
Este programa calcula
o valor total da compra
com base nos produtos
selecionados pelo usuário.
*/

echo "Sistema iniciado";

Todo o conteúdo entre /* e */ será ignorado pelo PHP.

Comentando blocos de código

Comentários de múltiplas linhas também podem ser usados para desativar temporariamente um trecho de código.

<?php

/*
echo "Linha 1";
echo "Linha 2";
echo "Linha 3";
*/

echo "Linha ativa";

Nesse exemplo, apenas "Linha ativa" será exibida.

Atenção: essa técnica é útil para testes rápidos, mas em projetos reais é preferível utilizar um sistema de controle de versão (como Git) em vez de manter grandes blocos comentados.

Comentando código HTML

Se o HTML estiver fora do PHP, utiliza-se o comentário próprio do HTML:

<!-- Este é um comentário HTML -->

Exemplo:

<!DOCTYPE html>
<html>

<body>

<!-- Cabeçalho da página -->

<h1>Bem-vindo</h1>

</body>

</html>

Esse comentário faz parte do HTML e não do PHP.

Comentários dentro do HTML usando PHP

Também é possível utilizar comentários PHP entre blocos HTML.

<h1>Ghostware</h1>

<?php

// Exibe o slogan da empresa

echo "<p>Logic Above Limits</p>";

?>

O comentário existe apenas no código-fonte do servidor e não é enviado ao navegador.

Comentários são enviados ao navegador?

Depende do tipo de comentário.

Comentários PHP

<?php

// Comentário PHP

echo "Olá!";

O navegador recebe apenas:

Olá!

O comentário é removido durante a execução.

Comentários HTML

<!-- Comentário HTML -->

<h1>Olá!</h1>

O navegador recebe:

<!-- Comentário HTML -->

<h1>Olá!</h1>

Embora o comentário não apareça visualmente na página, ele pode ser visto por qualquer pessoa ao visualizar o código-fonte do site.

Boas práticas

Comente o "porquê", não o "o quê"

Evite comentários que apenas repitam o que o código já deixa claro.

Ruim:

<?php

// Soma 1 à variável
$contador++;

O código já é autoexplicativo.

Melhor:

<?php

// Incrementa o contador para registrar uma nova tentativa de login
$contador++;

Agora o comentário explica a intenção do código.

Não comente código óbvio

Evite comentários desnecessários.

<?php

// Cria uma variável chamada nome
$nome = "Gustavo";

Esse comentário não acrescenta informação útil.

Mantenha os comentários atualizados

Comentários desatualizados podem causar confusão.

Se o código mudar, revise também os comentários.

Utilize comentários para documentar lógica complexa

Quando um algoritmo ou regra de negócio for difícil de entender, um comentário pode economizar muito tempo de manutenção.

<?php

// Calcula o desconto progressivo conforme a quantidade de produtos comprados

Resumo

Os comentários são partes do código que o PHP ignora durante a execução. Eles existem para documentar, explicar e facilitar a manutenção das aplicações. O PHP oferece comentários de uma linha (// e #) e de múltiplas linhas (/* ... */). Em projetos modernos, // é o formato mais utilizado para comentários curtos, enquanto /* ... */ é ideal para documentações maiores. Comentários bem escritos ajudam outros desenvolvedores — e até você mesmo no futuro — a entender rapidamente a lógica do sistema, tornando o código mais organizado, legível e fácil de manter.
