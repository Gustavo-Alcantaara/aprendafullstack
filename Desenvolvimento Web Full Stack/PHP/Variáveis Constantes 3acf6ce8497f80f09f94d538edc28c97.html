Variáveis Constantes

Variáveis Constantes (Constantes) no PHP

Apesar do nome "variáveis constantes" ser bastante utilizado em materiais didáticos, o termo tecnicamente correto é apenas constantes.

Enquanto uma variável pode ter seu valor alterado durante a execução do programa, uma constante recebe um valor apenas uma vez e não pode ser modificada.

As constantes são utilizadas para armazenar informações que devem permanecer iguais durante toda a execução da aplicação.

O que é uma constante?

Uma constante é um identificador que armazena um valor fixo.

Depois de criada:

  • seu valor não pode ser alterado;
  • ela não pode ser removida durante a execução;
  • pode ser utilizada em qualquer parte do código, respeitando seu escopo.

Exemplo:

PI = 3.14159

O valor de π nunca muda, por isso ele é um excelente exemplo de constante.

Diferença entre variável e constante

VariávelConstante
Pode mudar de valorNão pode mudar de valor
Começa com $Não utiliza $
Criada com atribuição (=)Criada com define() ou const
Utilizada para dados que mudamUtilizada para dados fixos

Exemplo:

<?php

$nome = "Gustavo";

$nome = "Carlos"; // permitido

Já uma constante:

<?php

const EMPRESA = "Ghostware";

Seu valor não poderá ser alterado.

Criando constantes com define()

A função define() é uma das formas de criar constantes.

Sintaxe:

define("NOME_DA_CONSTANTE", valor);

Exemplo:

<?php

define("EMPRESA", "Ghostware");

echo EMPRESA;

Resultado:

Ghostware

Observe que não existe $ antes do nome.

Criando constantes com const

Outra forma é utilizar a palavra-chave const.

<?php

const PI = 3.14159;

echo PI;

Resultado:

3.14159

Essa forma é muito utilizada em códigos modernos.

Diferença entre define() e const

define()const
É uma funçãoÉ uma palavra-chave da linguagem
Pode ser usada em diferentes contextosGeralmente usada na declaração do código
Muito utilizada em projetos antigosMais comum em projetos modernos

Na maioria das aplicações atuais, recomenda-se utilizar const quando possível.

Utilizando constantes

Depois de criada, basta informar seu nome.

<?php

const SITE = "Ghostware";

echo SITE;

Resultado:

Ghostware

Não utilize:

echo $SITE;

Isso causará erro, pois constantes não utilizam $.

Tentando alterar uma constante

Uma constante não pode receber um novo valor.

<?php

const PI = 3.14;

PI = 5;

Resultado:

Erro

O PHP gera um erro porque constantes são imutáveis.

Convenção de nomenclatura

Embora seja permitido utilizar outros formatos, a convenção mais comum é escrever constantes em letras maiúsculas.

Exemplo:

const NOME_EMPRESA = "Ghostware";
const VERSAO = "1.0";
const LIMITE_USUARIOS = 100;

Essa convenção facilita a identificação das constantes no código.

Exemplos práticos

Nome da empresa

<?php

const EMPRESA = "Ghostware";

echo EMPRESA;

Taxa fixa

<?php

const TAXA_ENTREGA = 15;

echo TAXA_ENTREGA;

Limite de tentativas

<?php

const MAX_TENTATIVAS = 3;

echo MAX_TENTATIVAS;

Versão do sistema

<?php

const VERSAO = "2.5";

echo VERSAO;

Quando utilizar constantes?

As constantes são ideais para informações que não devem mudar durante a execução do programa, como:

  • Nome da empresa.
  • Versão do sistema.
  • Valor de π.
  • Taxas fixas.
  • Limites máximos.
  • Configurações da aplicação.
  • Caminhos de diretórios.
  • Chaves de configuração.

Boas práticas

  • Utilize constantes apenas para valores que realmente são fixos.
  • Prefira nomes descritivos e escritos em letras maiúsculas.
  • Não utilize constantes para armazenar informações que podem mudar, como nome de usuário, saldo bancário ou quantidade em estoque.
  • Em projetos modernos, prefira const sempre que possível por ser mais integrado à linguagem.

Exemplo comparando variável e constante

<?php

$preco = 100;
$preco = 120;

const DESCONTO = 10;

// Correto
echo $preco;

// Correto
echo DESCONTO;

// Incorreto
// DESCONTO = 20;

Nesse exemplo:

  • $preco pode ser alterado de 100 para 120.
  • DESCONTO permanece sempre com o valor 10.

Resumo

As constantes são identificadores utilizados para armazenar valores que não devem ser modificados durante a execução do programa. Diferentemente das variáveis, elas não utilizam o símbolo $ e podem ser criadas com define() ou com a palavra-chave const. São amplamente utilizadas para representar informações fixas, como configurações, limites, versões e valores matemáticos. O uso de constantes torna o código mais seguro, organizado e fácil de manter, pois evita alterações acidentais em dados que devem permanecer inalterados durante toda a execução da aplicação.
