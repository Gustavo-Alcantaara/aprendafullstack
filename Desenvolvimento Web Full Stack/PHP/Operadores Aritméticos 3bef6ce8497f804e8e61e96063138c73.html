Operadores Aritméticos

Operadores Aritméticos no PHP

Os operadores aritméticos são utilizados para realizar operações matemáticas com valores numéricos. Eles são fundamentais em praticamente qualquer aplicação, principalmente em cálculos de preços, salários, notas, porcentagens, quantidades, datas e estatísticas.

Os principais operadores aritméticos do PHP são:

OperadorOperaçãoExemploResultado
+Adição10 + 515
-Subtração10 - 55
*Multiplicação10 * 550
/Divisão10 / 52
%Módulo (resto)10 % 31
**Exponenciação2 ** 38

1. Adição (+)

O operador + soma dois valores.

<?php

$a = 10;
$b = 5;

$resultado = $a + $b;

echo $resultado;

Resultado:

15

Também pode ser utilizado diretamente:

echo 20 + 30;

Resultado:

50

2. Subtração ()

O operador - realiza uma subtração.

<?php

$saldo = 1000;
$gasto = 250;

$saldo = $saldo - $gasto;

echo $saldo;

Resultado:

750

Também podemos utilizar a forma abreviada:

$saldo -= 250;

3. Multiplicação ()

O operador * multiplica valores.

<?php

$preco = 50;
$quantidade = 3;

$total = $preco * $quantidade;

echo $total;

Resultado:

150

Esse tipo de operação é muito comum em sistemas de vendas.

4. Divisão (/)

O operador / divide um valor pelo outro.

<?php

$total = 100;
$pessoas = 4;

$resultado = $total / $pessoas;

echo $resultado;

Resultado:

25

Cuidado com divisão por zero

Não é possível dividir um número por zero.

$resultado = 10 / 0;

Isso gera um erro.

Por isso, em aplicações reais, é importante verificar se o divisor é diferente de zero antes de realizar a operação.

5. Módulo (%)

O operador % retorna o resto de uma divisão inteira.

Exemplo:

<?php

$resultado = 10 % 3;

echo $resultado;

Resultado:

1

Isso acontece porque:

10 ÷ 3 = 3
resto = 1

O módulo é muito utilizado para descobrir, por exemplo, se um número é par ou ímpar.

Número par

<?php

$numero = 10;

if ($numero % 2 == 0) {
    echo "Par";
}

Resultado:

Par

Número ímpar

<?php

$numero = 7;

if ($numero % 2 != 0) {
    echo "Ímpar";
}

6. Exponenciação (*)

O operador ** realiza uma potenciação.

<?php

$resultado = 2 ** 3;

echo $resultado;

Resultado:

8

Isso corresponde a:

2 × 2 × 2 = 8

Outro exemplo:

echo 5 ** 2;

Resultado:

25

Ordem de precedência

Quando várias operações aparecem na mesma expressão, o PHP segue uma ordem de prioridade.

Por exemplo:

$resultado = 10 + 5 * 2;

Primeiro ocorre a multiplicação:

5 × 2 = 10

Depois a adição:

10 + 10 = 20

Portanto:

Resultado: 20

Se quisermos realizar a adição primeiro, podemos utilizar parênteses:

$resultado = (10 + 5) * 2;

Agora:

10 + 5 = 15

15 × 2 = 30

Resultado:

30

Regra geral

Uma forma simplificada de lembrar a ordem é:

  1. ()
  1. *
  1. , /, %
  1. +,

Quando houver dúvida, utilize parênteses.

Operadores de atribuição combinados

Os operadores aritméticos também podem ser combinados com o operador de atribuição =.

Por exemplo:

$numero = $numero + 10;

Pode ser escrito como:

$numero += 10;

O mesmo pode ser feito com outras operações:

$numero -= 5;
$numero *= 2;
$numero /= 4;
$numero %= 3;

Esses operadores são chamados de operadores de atribuição composta.

Incremento e decremento

O PHP também possui operadores específicos para aumentar ou diminuir uma variável em 1.

Incremento (++)

<?php

$contador = 5;

$contador++;

echo $contador;

Resultado:

6

Decremento (-)

<?php

$contador = 5;

$contador--;

echo $contador;

Resultado:

4

Esses operadores são muito utilizados em estruturas de repetição.

Exemplo prático: cálculo de compra

<?php

$preco = 80;
$quantidade = 3;
$desconto = 20;

$total = $preco * $quantidade;
$total = $total - $desconto;

echo "Total: R$ " . $total;

Resultado:

Total: R$ 220

O programa realizou:

80 × 3 = 240
240 - 20 = 220

Exemplo prático: média

<?php

$nota1 = 8;
$nota2 = 7;
$nota3 = 9;

$media = ($nota1 + $nota2 + $nota3) / 3;

echo "Média: " . $media;

Resultado:

Média: 8

Resumo

Os operadores aritméticos permitem realizar cálculos matemáticos no PHP. Os principais são + para adição, - para subtração, * para multiplicação, / para divisão, % para obter o resto da divisão e ** para exponenciação. Eles podem ser utilizados diretamente com valores, variáveis e expressões, além de poderem ser combinados com operadores de atribuição, como +=, -=, *= e /=. O domínio desses operadores é fundamental para desenvolver sistemas que realizam cálculos, como lojas virtuais, sistemas financeiros, escolares, de estoque e diversas outras aplicações.
