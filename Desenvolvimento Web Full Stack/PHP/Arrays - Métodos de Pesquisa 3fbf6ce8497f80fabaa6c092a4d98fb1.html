Arrays - Métodos de Pesquisa

Array — Métodos de Pesquisa em PHP

Os métodos de pesquisa em arrays são funções utilizadas para procurar valores, verificar se eles existem e descobrir suas posições dentro de um array.

Eles são muito úteis em situações como:

  • verificar se um usuário existe;
  • procurar um produto;
  • verificar se uma determinada opção foi selecionada;
  • descobrir a posição de um elemento;
  • procurar uma chave específica;
  • localizar informações dentro de um array.

Os principais métodos que você deve conhecer são:

  • in_array()
  • array_search()
  • array_key_exists()
  • isset()

1. in_array()

A função in_array() verifica se um determinado valor existe dentro de um array.

Sintaxe

in_array(valor, array);

Exemplo:

$frutas = ["Maçã", "Banana", "Laranja"];

if (in_array("Banana", $frutas)) {
    echo "Banana encontrada!";
}

Resultado:

Banana encontrada!

Se o valor não existir:

if (in_array("Uva", $frutas)) {
    echo "Uva encontrada!";
} else {
    echo "Uva não encontrada!";
}

Resultado:

Uva não encontrada!

2. Pesquisa com in_array() e tipos

Por padrão, in_array() não exige que o tipo seja exatamente igual.

Por exemplo:

$numeros = [10, 20, 30];

var_dump(in_array("10", $numeros));

Dependendo da comparação não estrita, valores de tipos diferentes podem ser considerados equivalentes.

Para exigir que valor e tipo sejam iguais, utilizamos o terceiro parâmetro true:

$numeros = [10, 20, 30];

var_dump(in_array("10", $numeros, true));

Resultado:

bool(false)

Já:

var_dump(in_array(10, $numeros, true));

resultará em:

bool(true)

Boa prática

Quando o tipo do valor é importante, prefira:

in_array($valor, $array, true);

3. array_search()

Enquanto in_array() responde basicamente:

"Esse valor existe?"

array_search() responde:

"Esse valor existe? E em qual posição/chave ele está?"

Exemplo:

$frutas = ["Maçã", "Banana", "Laranja"];

$posicao = array_search("Banana", $frutas);

echo $posicao;

Resultado:

1

Isso acontece porque:

Índice    Valor
  0       Maçã
  1       Banana
  2       Laranja

Portanto, "Banana" está no índice 1.

4. Verificando o resultado de array_search()

Podemos utilizar if:

$frutas = ["Maçã", "Banana", "Laranja"];

$posicao = array_search("Banana", $frutas);

if ($posicao !== false) {
    echo "Encontrado na posição: " . $posicao;
} else {
    echo "Não encontrado";
}

Resultado:

Encontrado na posição: 1

⚠️ Um detalhe importante

array_search() retorna false quando não encontra o valor.

Porém, 0 também é uma posição válida:

$frutas = ["Maçã", "Banana", "Laranja"];

$posicao = array_search("Maçã", $frutas);

O resultado será:

0

Por isso, não é recomendado fazer:

if ($posicao) {
    // ...
}

Porque 0 é considerado falso em uma condição.

Prefira:

if ($posicao !== false) {
    // encontrado
}

5. Pesquisa estrita com array_search()

Assim como in_array(), podemos utilizar o terceiro parâmetro true:

$numeros = [10, 20, 30];

$posicao = array_search("10", $numeros, true);

var_dump($posicao);

Resultado:

bool(false)

Porque "10" é uma string, enquanto 10 é um inteiro.

Com:

$posicao = array_search(10, $numeros, true);

teremos:

0

6. array_key_exists()

Enquanto in_array() pesquisa valores, array_key_exists() pesquisa chaves.

Considere:

$usuario = [
    "nome" => "Gustavo",
    "idade" => 20,
    "email" => "gustavo@email.com"
];

Podemos verificar se a chave "email" existe:

if (array_key_exists("email", $usuario)) {
    echo "A chave email existe!";
}

Resultado:

A chave email existe!

Podemos testar outra chave:

if (array_key_exists("telefone", $usuario)) {
    echo "Telefone cadastrado";
} else {
    echo "Telefone não cadastrado";
}

Resultado:

Telefone não cadastrado

7. array_key_exists() x in_array()

É importante não confundir os dois.

Considere:

$usuario = [
    "nome" => "Gustavo",
    "idade" => 20
];

Procurando um valor:

in_array("Gustavo", $usuario);

Estamos perguntando:

Existe "Gustavo" entre os valores?

Procurando uma chave:

array_key_exists("nome", $usuario);

Estamos perguntando:

Existe uma chave chamada "nome"?

Portanto:

in_array()        → pesquisa valores
array_search()    → pesquisa valores e retorna a chave
array_key_exists()→ pesquisa chaves

8. isset()

Outra forma muito utilizada para verificar se uma chave existe é isset():

$usuario = [
    "nome" => "Gustavo",
    "idade" => 20
];

if (isset($usuario["nome"])) {
    echo "Nome encontrado!";
}

Resultado:

Nome encontrado!

Porém, existe uma diferença importante entre isset() e array_key_exists().

9. isset() x array_key_exists()

Observe:

$usuario = [
    "nome" => null
];

A chave "nome" existe, mas seu valor é null.

Com:

var_dump(array_key_exists("nome", $usuario));

temos:

bool(true)

Mas:

var_dump(isset($usuario["nome"]));

resulta em:

bool(false)

Isso acontece porque isset() verifica se a variável/chave existe e não possui valor null.

Portanto:

FunçãoO que verifica
in_array()Se um valor existe
array_search()Valor existe e retorna sua chave
array_key_exists()Se uma chave existe
isset()Se existe e não é null

10. Pesquisando em Array Associativo

Imagine uma lista de usuários:

$usuarios = [
    [
        "id" => 1,
        "nome" => "João"
    ],
    [
        "id" => 2,
        "nome" => "Maria"
    ],
    [
        "id" => 3,
        "nome" => "Pedro"
    ]
];

Aqui temos um array multidimensional associativo.

O in_array() não é adequado para perguntar diretamente:

Existe algum usuário chamado Maria?

Podemos fazer isso percorrendo o array:

foreach ($usuarios as $usuario) {
    if ($usuario["nome"] === "Maria") {
        echo "Usuário encontrado!";
    }
}

Resultado:

Usuário encontrado!

Esse conceito será muito importante quando você começar a trabalhar com bancos de dados e registros.

11. Exemplo prático: verificar produto

Imagine um sistema de estoque:

$produtos = [
    "Notebook",
    "Mouse",
    "Teclado",
    "Monitor"
];

$produto = "Mouse";

if (in_array($produto, $produtos, true)) {
    echo "Produto encontrado no estoque.";
} else {
    echo "Produto não encontrado.";
}

Resultado:

Produto encontrado no estoque.

12. Exemplo prático: encontrar posição

Podemos descobrir onde um produto está:

$produtos = [
    "Notebook",
    "Mouse",
    "Teclado",
    "Monitor"
];

$produto = "Teclado";

$posicao = array_search($produto, $produtos, true);

if ($posicao !== false) {
    echo "Produto encontrado na posição: " . $posicao;
}

Resultado:

Produto encontrado na posição: 2

13. Pesquisa em Arrays Associativos

Também podemos usar array_search() em arrays associativos.

$idades = [
    "João" => 20,
    "Maria" => 25,
    "Pedro" => 30
];

$chave = array_search(25, $idades, true);

echo $chave;

Resultado:

Maria

Aqui:

array_search(25, $idades, true);

procura o valor 25 e retorna a chave correspondente:

Maria

14. Resumo dos métodos

in_array()

Procura um valor:

in_array("Maria", $nomes);

Retorna:

true / false

array_search()

Procura um valor e retorna sua chave/índice:

array_search("Maria", $nomes);

Retorna, por exemplo:

1

ou:

false

se não encontrar.

array_key_exists()

Procura uma chave:

array_key_exists("email", $usuario);

Retorna:

true / false

isset()

Verifica se uma chave/variável existe e não é null:

isset($usuario["email"]);

Retorna:

true / false

🧠 O mais importante para memorizar

Pense nas perguntas que você quer fazer ao array:

"Esse VALOR existe?"
        ↓
    in_array()


"Esse VALOR existe e onde está?"
        ↓
    array_search()


"Essa CHAVE existe?"
        ↓
    array_key_exists()


"Essa CHAVE existe e não é null?"
        ↓
       isset()

Essas funções formam a base da pesquisa de dados em arrays no PHP. Conforme você avançar, elas serão muito úteis em conjunto com foreach, arrays associativos, formulários, banco de dados e APIs.
