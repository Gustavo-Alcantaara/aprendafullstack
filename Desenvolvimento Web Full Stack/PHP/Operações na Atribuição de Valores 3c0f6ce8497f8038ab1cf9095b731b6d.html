Operações na Atribuição de Valores

Operações Aritméticas na Atribuição de Valores no PHP

As operações aritméticas na atribuição de valores acontecem quando utilizamos uma operação matemática para calcular um novo valor e armazená-lo em uma variável.

Esse conceito combina dois recursos importantes do PHP:

  • Operadores aritméticos, como +, , , / e %;
  • Operador de atribuição, =.

Por exemplo:

$valor = 10 + 5;

Nesse caso, o PHP primeiro realiza a operação:

10 + 5 = 15

Depois, atribui o resultado à variável:

$valor = 15

Atribuição com adição

Podemos realizar uma soma no momento em que atribuímos um valor.

<?php

$total = 100 + 50;

echo $total;

Resultado:

150

Também podemos utilizar variáveis:

<?php

$preco = 100;
$frete = 20;

$total = $preco + $frete;

echo $total;

Resultado:

120

Atribuição com subtração

Podemos calcular uma subtração e armazenar o resultado.

<?php

$saldo = 1000;
$gasto = 250;

$saldo = $saldo - $gasto;

echo $saldo;

Resultado:

750

O valor de $saldo passa de 1000 para 750.

Atribuição com multiplicação

Muito utilizada para calcular preços, quantidades e valores totais.

<?php

$preco = 50;
$quantidade = 4;

$total = $preco * $quantidade;

echo $total;

Resultado:

200

A operação pode ser representada por:

50 × 4 = 200

Atribuição com divisão

Também podemos atribuir o resultado de uma divisão:

<?php

$total = 100;
$pessoas = 4;

$valorPorPessoa = $total / $pessoas;

echo $valorPorPessoa;

Resultado:

25

Atribuição com módulo

O operador % pode ser utilizado para armazenar o resto de uma divisão.

<?php

$resto = 17 % 5;

echo $resto;

Resultado:

2

Isso pode ser útil, por exemplo, para verificar se um número é par:

<?php

$numero = 10;
$resto = $numero % 2;

if ($resto == 0) {
    echo "Número par";
}

Atribuição com exponenciação

Também podemos realizar uma potência antes de atribuir o resultado:

<?php

$resultado = 2 ** 3;

echo $resultado;

Resultado:

8

Atribuição utilizando a própria variável

Uma situação muito comum é utilizar o valor atual de uma variável para calcular seu novo valor.

Por exemplo:

<?php

$saldo = 1000;

$saldo = $saldo + 500;

echo $saldo;

Resultado:

1500

O funcionamento é:

$saldo = 1000

1000 + 500 = 1500

$saldo = 1500

Operadores de atribuição composta

O PHP oferece uma maneira mais curta de realizar essas operações.

Em vez de:

$saldo = $saldo + 500;

podemos escrever:

$saldo += 500;

O resultado é o mesmo.

+= — Adição

<?php

$saldo = 1000;

$saldo += 500;

echo $saldo;

Resultado:

1500

Equivale a:

$saldo = $saldo + 500;

= — Subtração

<?php

$saldo = 1000;

$saldo -= 300;

echo $saldo;

Resultado:

700

Equivale a:

$saldo = $saldo - 300;

= — Multiplicação

<?php

$valor = 100;

$valor *= 3;

echo $valor;

Resultado:

300

Equivale a:

$valor = $valor * 3;

/= — Divisão

<?php

$valor = 100;

$valor /= 4;

echo $valor;

Resultado:

25

Equivale a:

$valor = $valor / 4;

%= — Módulo

<?php

$numero = 17;

$numero %= 5;

echo $numero;

Resultado:

2

Equivale a:

$numero = $numero % 5;

*= — Exponenciação

Também podemos utilizar a atribuição composta com exponenciação:

<?php

$numero = 2;

$numero **= 3;

echo $numero;

Resultado:

8

Equivale a:

$numero = $numero ** 3;

Exemplo prático: sistema financeiro

Imagine uma conta com saldo inicial de R$ 1.000.

<?php

$saldo = 1000;

// Depósito
$saldo += 500;

// Compra
$saldo -= 200;

// Outro depósito
$saldo += 300;

echo "Saldo: R$ " . $saldo;

Resultado:

Saldo: R$ 1600

O saldo foi atualizado progressivamente:

1000
 ↓ +500
1500
 ↓ -200
1300
 ↓ +300
1600

Exemplo prático: estoque

<?php

$estoque = 50;

// Venda de 5 produtos
$estoque -= 5;

// Reposição de 20 produtos
$estoque += 20;

echo "Estoque: " . $estoque;

Resultado:

Estoque: 65

Exemplo prático: preço com desconto

<?php

$preco = 500;
$desconto = 50;

$preco -= $desconto;

echo "Preço final: R$ " . $preco;

Resultado:

Preço final: R$ 450

Também podemos calcular uma porcentagem:

<?php

$preco = 500;
$desconto = 10;

$preco -= $preco * ($desconto / 100);

echo "Preço final: R$ " . $preco;

Resultado:

Preço final: R$ 450

Diferença entre = e +=

É importante não confundir esses operadores.

=

Substitui o valor da variável:

$numero = 10;
$numero = 20;

Resultado:

20

O 10 foi substituído.

+=

Utiliza o valor existente e adiciona algo a ele:

$numero = 10;
$numero += 20;

Resultado:

30

O valor anterior foi utilizado no cálculo.

Resumo

As operações aritméticas na atribuição de valores permitem realizar cálculos e armazenar seus resultados em variáveis. Além da atribuição tradicional com =, o PHP oferece operadores de atribuição composta, como +=, -=, *=, /=, %= e **=, que permitem modificar diretamente o valor já armazenado em uma variável. Esses operadores são muito utilizados em sistemas que precisam atualizar valores continuamente, como saldos, estoques, contadores, preços, descontos, notas e quantidades. Conhecer essas operações é fundamental para trabalhar com cálculos e manipulação de dados em PHP.
