Funções

Funções no PHP

As funções são blocos de código criados para executar uma determinada tarefa. Elas permitem organizar o programa, evitar repetição de código e facilitar a manutenção da aplicação.

Em vez de escrever o mesmo código várias vezes, podemos criar uma função uma única vez e chamá-la sempre que precisarmos executar aquela tarefa.

O que é uma função?

Uma função pode ser entendida como uma pequena "unidade de trabalho" dentro do programa.

Por exemplo, podemos criar uma função para:

  • Calcular uma média;
  • Somar dois números;
  • Verificar se um usuário está logado;
  • Calcular um desconto;
  • Validar um formulário;
  • Exibir uma mensagem;
  • Consultar informações no banco de dados.

Uma função pode:

  1. Receber dados;
  1. Processar esses dados;
  1. Retornar um resultado.

Estrutura básica

Para criar uma função no PHP, utilizamos a palavra-chave function.

function nomeDaFuncao() {
    // código da função
}

Exemplo:

<?php

function mensagem() {
    echo "Olá, mundo!";
}

Nesse momento, a função foi apenas declarada. Para executá-la, precisamos chamá-la:

mensagem();

Resultado:

Olá, mundo!

Declaração e chamada de uma função

Existem duas etapas importantes.

1. Declaração

function saudacao() {
    echo "Olá!";
}

2. Chamada

saudacao();

Exemplo completo:

<?php

function saudacao() {
    echo "Olá!";
}

saudacao();

Funções com parâmetros

Uma função pode receber informações externas através de parâmetros.

Exemplo:

<?php

function saudacao($nome) {
    echo "Olá, " . $nome;
}

saudacao("Gusta");

Resultado:

Olá, Gusta

Nesse exemplo:

$nome

é o parâmetro da função.

Quando fazemos:

saudacao("Gusta");

"Gusta" é o argumento passado para a função.

Diferença

  • Parâmetro: variável definida na declaração da função.
  • Argumento: valor enviado quando a função é chamada.

Função com vários parâmetros

Uma função pode receber vários parâmetros.

<?php

function apresentar($nome, $idade) {
    echo "Nome: " . $nome . "<br>";
    echo "Idade: " . $idade;
}

apresentar("Gusta", 21);

Resultado:

Nome: Gusta
Idade: 21

Retorno de valores com return

Uma função pode retornar um valor utilizando return.

Exemplo:

<?php

function somar($a, $b) {
    return $a + $b;
}

$resultado = somar(10, 5);

echo $resultado;

Resultado:

15

Nesse caso, a função não imprime diretamente o resultado. Ela o devolve para quem chamou a função.

echo x return

É importante diferenciar os dois.

echo

Exibe algo na tela:

function somar($a, $b) {
    echo $a + $b;
}

return

Devolve o resultado para o código que chamou a função:

function somar($a, $b) {
    return $a + $b;
}

O return é geralmente mais flexível, pois permite armazenar e reutilizar o resultado:

$resultado = somar(10, 5);

$total = $resultado * 2;

Função sem parâmetros e sem retorno

<?php

function mensagem() {
    echo "Bem-vindo ao sistema!";
}

mensagem();

É uma função simples que apenas executa uma ação.

Função com parâmetros e sem retorno

<?php

function mostrarNome($nome) {
    echo "Usuário: " . $nome;
}

mostrarNome("Gusta");

Função sem parâmetros com retorno

<?php

function obterNome() {
    return "Gusta";
}

$nome = obterNome();

echo $nome;

Função com parâmetros e retorno

Esse é um dos formatos mais comuns:

<?php

function multiplicar($a, $b) {
    return $a * $b;
}

$resultado = multiplicar(5, 4);

echo $resultado;

Resultado:

20

Parâmetros com valores padrão

Podemos definir um valor padrão para um parâmetro.

<?php

function saudacao($nome = "Visitante") {
    echo "Olá, " . $nome;
}

saudacao();

Resultado:

Olá, Visitante

Se fornecermos um valor:

saudacao("Gusta");

Resultado:

Olá, Gusta

Tipagem dos parâmetros

O PHP permite especificar o tipo esperado para um parâmetro.

<?php

function somar(int $a, int $b) {
    return $a + $b;
}

echo somar(10, 20);

Nesse caso, a função espera valores do tipo int.

Podemos utilizar outros tipos:

function calcular(float $preco, int $quantidade) {
    return $preco * $quantidade;
}

Isso ajuda a tornar o código mais previsível.

Tipagem do retorno

Também podemos informar o tipo que a função deve retornar.

Utilizamos : após os parâmetros:

<?php

function somar(int $a, int $b): int {
    return $a + $b;
}

Nesse exemplo:

int $a
int $b

indica que os parâmetros devem ser inteiros.

Já:

): int

indica que a função deve retornar um inteiro.

Exemplo com float

<?php

function calcularMedia(float $nota1, float $nota2): float {
    return ($nota1 + $nota2) / 2;
}

$media = calcularMedia(8, 9);

echo $media;

Resultado:

8.5

Funções com vários parâmetros

Podemos criar funções que recebem diversas informações.

<?php

function calcularSalario($salario, $bonus, $desconto) {
    return $salario + $bonus - $desconto;
}

$resultado = calcularSalario(3000, 500, 200);

echo $resultado;

Resultado:

3300

Escopo das variáveis

As variáveis criadas dentro de uma função normalmente possuem escopo local.

Exemplo:

<?php

function teste() {
    $numero = 10;

    echo $numero;
}

teste();

A variável $numero existe dentro da função.

Ela não pode ser utilizada normalmente fora dela:

echo $numero;

Isso ocorre porque $numero pertence ao escopo da função.

Variáveis globais

Uma variável criada fora de uma função possui escopo global.

<?php

$nome = "Gusta";

function mostrarNome() {
    global $nome;

    echo $nome;
}

mostrarNome();

Embora seja possível utilizar global, em aplicações maiores geralmente é melhor evitar depender excessivamente de variáveis globais. É preferível passar os valores necessários como parâmetros.

Por exemplo:

function mostrarNome($nome) {
    echo $nome;
}

mostrarNome($nome);

Essa abordagem deixa a função mais independente e reutilizável.

Funções internas do PHP

O PHP já possui centenas de funções prontas, chamadas de funções internas (built-in functions).

Por exemplo:

strlen()

Retorna o tamanho de uma string:

<?php

$nome = "Gusta";

echo strlen($nome);

Resultado:

5

strtoupper()

Converte uma string para letras maiúsculas:

echo strtoupper("php");

Resultado:

PHP

count()

Conta elementos de um array:

$nomes = ["Ana", "Carlos", "João"];

echo count($nomes);

Resultado:

3

Funções personalizadas

Quando criamos nossas próprias funções, elas são chamadas de funções definidas pelo usuário.

Exemplo:

<?php

function calcularDesconto($preco, $percentual) {

    $desconto = $preco * ($percentual / 100);

    return $preco - $desconto;
}

echo calcularDesconto(100, 10);

Resultado:

90

Essa função pode ser reutilizada:

calcularDesconto(200, 10);
calcularDesconto(500, 20);
calcularDesconto(1000, 15);

Funções podem ser reutilizadas

Essa é uma das principais vantagens das funções.

Sem função:

$total1 = 100 * 1.10;
$total2 = 200 * 1.10;
$total3 = 300 * 1.10;

Com função:

function calcularPreco($valor) {
    return $valor * 1.10;
}

$total1 = calcularPreco(100);
$total2 = calcularPreco(200);
$total3 = calcularPreco(300);

O código fica mais organizado e evita repetição.

Funções anônimas

O PHP também permite criar funções sem nome, chamadas de funções anônimas.

Exemplo:

<?php

$somar = function($a, $b) {
    return $a + $b;
};

echo $somar(10, 5);

Resultado:

15

Nesse caso, a função foi armazenada na variável $somar.

Arrow Functions

O PHP também possui funções de seta, introduzidas no PHP 7.4.

Elas são uma forma compacta de escrever funções simples.

Em vez de:

$somar = function($a, $b) {
    return $a + $b;
};

podemos escrever:

$somar = fn($a, $b) => $a + $b;

E utilizar:

echo $somar(10, 5);

Resultado:

15

São especialmente úteis em operações curtas e funções de callback.

Por que utilizar funções?

As funções oferecem diversas vantagens:

1. Reutilização

Uma função pode ser chamada várias vezes.

2. Organização

O programa pode ser dividido em pequenas tarefas.

3. Manutenção

Se uma regra precisar ser alterada, podemos modificar a função em um único lugar.

4. Redução de repetição

Evita escrever o mesmo código várias vezes.

5. Legibilidade

Funções com bons nomes tornam o código mais fácil de entender.

Por exemplo:

calcularTotal();

é mais fácil de compreender do que encontrar várias linhas de cálculo espalhadas pelo código.

Exemplo completo

Imagine um sistema de vendas:

<?php

function calcularSubtotal(float $preco, int $quantidade): float {
    return $preco * $quantidade;
}

function aplicarDesconto(float $valor, float $percentual): float {
    return $valor - ($valor * ($percentual / 100));
}

$preco = 50;
$quantidade = 4;
$desconto = 10;

$subtotal = calcularSubtotal($preco, $quantidade);

$total = aplicarDesconto($subtotal, $desconto);

echo "Subtotal: R$ " . $subtotal . "<br>";
echo "Total com desconto: R$ " . $total;

Resultado:

Subtotal: R$ 200
Total com desconto: R$ 180

Observe como o programa foi dividido em tarefas:

calcularSubtotal()
        ↓
calcular o subtotal

aplicarDesconto()
        ↓
calcular o desconto

resultado
        ↓
exibir o total

Isso torna o código muito mais organizado.

Boas práticas

Ao criar funções:

  • Dê nomes claros e descritivos.
  • Faça cada função realizar uma tarefa bem definida.
  • Evite funções gigantes.
  • Utilize parâmetros em vez de depender de variáveis globais.
  • Utilize return quando precisar reutilizar o resultado.
  • Use tipagem de parâmetros e retorno quando apropriado.
  • Evite duplicação de código.
  • Mantenha as funções independentes sempre que possível.

Resumo

As funções são blocos de código reutilizáveis criados para executar tarefas específicas. Elas podem receber parâmetros, realizar operações e devolver resultados através do return. O PHP também possui diversas funções internas, como strlen(), count() e strtoupper(), além de permitir que o programador crie suas próprias funções.

O uso de funções é fundamental para desenvolver aplicações organizadas, pois permite reutilizar código, reduzir repetições, melhorar a legibilidade e facilitar a manutenção. Em PHP, também existem recursos mais avançados, como parâmetros tipados, tipos de retorno, funções anônimas e Arrow Functions, que tornam a programação mais estruturada e flexível.
