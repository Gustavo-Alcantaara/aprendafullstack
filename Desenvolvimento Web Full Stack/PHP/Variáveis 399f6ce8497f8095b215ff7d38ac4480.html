Variáveis

Variáveis no PHP

As variáveis são um dos conceitos mais importantes da programação. Elas funcionam como espaços na memória do computador utilizados para armazenar informações que poderão ser utilizadas, alteradas ou consultadas durante a execução do programa.

Em PHP, praticamente tudo o que a aplicação manipula passa por variáveis: nomes de usuários, senhas, preços, datas, resultados de cálculos, informações de formulários, dados do banco de dados, entre muitos outros.

O que é uma variável?

Uma variável pode ser comparada a uma caixa com uma etiqueta.

  • A etiqueta representa o nome da variável.
  • O conteúdo da caixa representa o valor armazenado.

Exemplo:

Variável

$nome
 ┌─────────────┐
 │  Gustavo    │
 └─────────────┘

Sempre que o programa precisar do nome do usuário, basta utilizar $nome.

Declarando uma variável

No PHP, toda variável começa obrigatoriamente com o símbolo $.

Sintaxe:

$nome = "Gustavo";

Estrutura:

$nome = "Gustavo";
│      │
│      └── Valor
│
└──────── Nome da variável

Exemplo simples

<?php

$nome = "Gustavo";

echo $nome;

Resultado:

Gustavo

Armazenando números

Variáveis não armazenam apenas textos.

<?php

$idade = 21;
$altura = 1.75;
$salario = 3500.50;

Armazenando texto

Textos (strings) devem ficar entre aspas.

<?php

$cidade = "Fortaleza";
$empresa = "Ghostware";

Armazenando valores booleanos

Variáveis também podem guardar valores lógicos.

<?php

$logado = true;
$ativo = false;

Esses valores normalmente representam respostas do tipo:

  • Sim ou Não
  • Verdadeiro ou Falso
  • Ligado ou Desligado

Alterando o valor de uma variável

Uma variável pode receber um novo valor a qualquer momento.

<?php

$idade = 20;

$idade = 21;

echo $idade;

Resultado:

21

O valor anterior foi substituído.

Variáveis podem receber outras variáveis

<?php

$nome = "Carlos";

$usuario = $nome;

echo $usuario;

Resultado:

Carlos

Utilizando variáveis em frases

É comum combinar textos e variáveis.

Usando concatenação:

<?php

$nome = "Ana";

echo "Olá, " . $nome;

Resultado:

Olá, Ana

Interpolação de variáveis

Quando a string utiliza aspas duplas (" "), o PHP substitui automaticamente o valor da variável.

<?php

$nome = "Ana";

echo "Olá, $nome";

Resultado:

Olá, Ana

Com aspas simples (' '), isso não acontece.

<?php

$nome = "Ana";

echo 'Olá, $nome';

Resultado:

Olá, $nome

Tipagem dinâmica

O PHP é uma linguagem de tipagem dinâmica.

Isso significa que você não precisa informar o tipo da variável.

Exemplo:

<?php

$nome = "Gustavo";
$idade = 21;
$altura = 1.75;
$ativo = true;

O próprio PHP identifica automaticamente cada tipo.

Regras para nomes de variáveis

Os nomes devem seguir algumas regras.

Deve começar com $

$nome

Após o $, deve começar com uma letra ou _

Correto:

$nome
$_idade

Incorreto:

$1nome

Pode conter

  • Letras
  • Números
  • _ (underscore)
$nomeCompleto
$idade2
$total_compra

Não pode conter espaços

Errado:

$nome completo

Correto:

$nomeCompleto

ou

$nome_completo

Não pode conter caracteres especiais

Errado:

$nome!
$preço
$valor#

PHP diferencia maiúsculas e minúsculas

Variáveis são case-sensitive.

Ou seja:

$nome

é diferente de

$Nome

e também diferente de

$NOME

Exemplo:

<?php

$nome = "Carlos";

$Nome = "Maria";

echo $nome;
echo $Nome;

Resultado:

CarlosMaria

São duas variáveis completamente diferentes.

Convenções de nomenclatura

Embora seja possível criar variáveis com praticamente qualquer nome válido, existem convenções para tornar o código mais legível.

camelCase

Muito utilizado em PHP.

$nomeCompleto
$dataNascimento
$totalPedido

snake_case

Também é bastante comum.

$nome_completo
$data_nascimento
$total_pedido

O importante é manter um padrão consistente em todo o projeto.

Boas práticas

Utilize nomes descritivos

Ruim:

$x = "Gustavo";

Melhor:

$nomeUsuario = "Gustavo";

Evite abreviações sem sentido

Ruim:

$vl

Melhor:

$valorTotal

Evite nomes muito longos

Ruim:

$valorTotalDaCompraDoClienteComDescontoEspecial

Prefira nomes claros e objetivos.

Dê nomes que representem o conteúdo

$precoProduto
$quantidade
$email
$telefone
$dataCadastro

Exemplos práticos

Cadastro de usuário

<?php

$nome = "Gustavo";
$email = "gustavo@email.com";
$idade = 21;

echo $nome;

Loja virtual

<?php

$produto = "Notebook";
$preco = 3500;
$estoque = 12;

Sistema escolar

<?php

$aluno = "Lucas";
$nota = 8.5;
$aprovado = true;

Resumo

As variáveis são estruturas utilizadas para armazenar informações durante a execução de um programa. No PHP, elas sempre começam com o símbolo $ e possuem tipagem dinâmica, ou seja, o tipo do dado é determinado automaticamente pelo interpretador. Uma variável pode armazenar textos, números, valores booleanos, arrays, objetos e diversos outros tipos de dados. Além de facilitar o armazenamento e a manipulação de informações, variáveis tornam o código mais reutilizável, organizado e flexível. Utilizar nomes claros e descritivos é uma boa prática que melhora significativamente a legibilidade e a manutenção de qualquer aplicação PHP.
