Operadores de Comparação

Operadores de Comparação no PHP

Os operadores de comparação são utilizados para comparar dois valores. O resultado dessa comparação é sempre um valor booleano:

  • true (verdadeiro)
  • false (falso)

Esses operadores são fundamentais nas estruturas de condição (if, else, switch), em laços de repetição (while, for) e em diversas outras situações onde é necessário tomar decisões.

O que são operadores de comparação?

Os operadores de comparação verificam a relação entre dois valores.

Por exemplo:

10 > 5

O PHP compara os dois números e retorna:

true

Já:

3 > 10

retorna:

false

Operador de igualdade (==)

Verifica se dois valores são iguais.

Sintaxe:

valor1 == valor2

Exemplo:

<?php

$idade = 18;

if ($idade == 18) {
    echo "Idade correta";
}

Resultado:

Idade correta

Comparação com tipos diferentes

O operador == compara apenas o valor, realizando conversão automática de tipos quando necessário.

<?php

var_dump(10 == "10");

Resultado:

bool(true)

Nesse caso, o PHP converte a string "10" para número antes da comparação.

Operador de igualdade estrita (===)

Compara o valor e o tipo.

Sintaxe:

valor1 === valor2

Exemplo:

<?php

var_dump(10 === "10");

Resultado:

bool(false)

Embora ambos representem o número 10, um é um inteiro e o outro é uma string.

Outro exemplo:

<?php

var_dump(10 === 10);

Resultado:

bool(true)
Boa prática: sempre que possível, prefira ===, pois ele evita resultados inesperados causados pela conversão automática de tipos.

Operador diferente (!=)

Verifica se dois valores são diferentes.

<?php

$idade = 20;

if ($idade != 18) {
    echo "Idade diferente";
}

Resultado:

Idade diferente

Assim como ==, esse operador também realiza conversão de tipos.

Operador diferente estrito (!==)

Compara valor e tipo.

Retorna true quando os valores ou os tipos são diferentes.

Exemplo:

<?php

var_dump(10 !== "10");

Resultado:

bool(true)

Operador maior que (>)

Verifica se o primeiro valor é maior que o segundo.

<?php

$nota = 9;

if ($nota > 7) {
    echo "Aprovado";
}

Resultado:

Aprovado

Operador menor que (<)

Verifica se o primeiro valor é menor que o segundo.

<?php

$idade = 16;

if ($idade < 18) {
    echo "Menor de idade";
}

Resultado:

Menor de idade

Operador maior ou igual (>=)

Retorna true se o primeiro valor for maior ou igual ao segundo.

<?php

$idade = 18;

if ($idade >= 18) {
    echo "Entrada permitida";
}

Resultado:

Entrada permitida

Operador menor ou igual (<=)

Retorna true se o primeiro valor for menor ou igual ao segundo.

<?php

$nota = 7;

if ($nota <= 7) {
    echo "Nota dentro do limite";
}

Resultado:

Nota dentro do limite

Operador Spaceship (<=>)

O operador Spaceship, introduzido no PHP 7, compara dois valores e retorna um número inteiro.

Sintaxe:

valor1 <=> valor2

Resultados possíveis:

  • 1 → o primeiro valor é menor.
  • 0 → os valores são iguais.
  • 1 → o primeiro valor é maior.

Exemplo:

<?php

echo 5 <=> 10;

Resultado:

-1

Outro exemplo:

<?php

echo 10 <=> 10;

Resultado:

0

E:

<?php

echo 20 <=> 10;

Resultado:

1

Esse operador é muito utilizado em funções de ordenação, como usort().

Utilizando operadores em condições

Os operadores de comparação são normalmente usados com estruturas condicionais.

<?php

$saldo = 500;

if ($saldo >= 100) {
    echo "Compra autorizada";
}

Comparando strings

Também é possível comparar textos.

<?php

$usuario = "admin";

if ($usuario == "admin") {
    echo "Acesso liberado";
}

Resultado:

Acesso liberado

Comparando variáveis

<?php

$a = 10;
$b = 20;

if ($a < $b) {
    echo "A é menor que B";
}

Resultado:

A é menor que B

Boas práticas

  • Prefira === e !== para evitar comparações inesperadas entre tipos diferentes.
  • Utilize nomes de variáveis claros para facilitar a leitura das condições.
  • Evite comparações desnecessariamente complexas; divida a lógica quando necessário.
  • Sempre considere o tipo de dado que está sendo comparado.

Resumo

Os operadores de comparação permitem verificar a relação entre dois valores, retornando sempre um resultado booleano (true ou false), exceto o operador Spaceship (<=>), que retorna -1, 0 ou 1. Eles são essenciais para controlar o fluxo de execução dos programas, sendo amplamente utilizados em estruturas condicionais, laços de repetição e validações. Entre os operadores disponíveis estão igualdade (==), igualdade estrita (===), diferença (!= e !==), maior (>), menor (<), maior ou igual (>=), menor ou igual (<=) e o operador Spaceship. Em projetos modernos, recomenda-se priorizar os operadores estritos (=== e !==) para tornar o código mais seguro e previsível.
