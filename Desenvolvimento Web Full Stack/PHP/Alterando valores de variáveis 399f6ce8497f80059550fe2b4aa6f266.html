Alterando valores de variáveis

Alteração de Valores de Variáveis

Uma das principais características das variáveis é que seus valores podem ser modificados durante a execução do programa. Essa flexibilidade permite que o PHP acompanhe mudanças de estado, realize cálculos, processe dados de usuários e atualize informações conforme necessário.

Sempre que uma variável recebe um novo valor, o valor anterior é substituído, a menos que ele seja utilizado em uma operação antes da alteração.

Como alterar o valor de uma variável

Para alterar uma variável, basta fazer uma nova atribuição utilizando o operador =.

Exemplo:

<?php

$nome = "Carlos";

$nome = "Gustavo";

echo $nome;

Resultado:

Gustavo

O valor "Carlos" foi substituído por "Gustavo".

Alterando números

<?php

$idade = 20;

$idade = 21;

echo $idade;

Resultado:

21

Alterando textos

<?php

$cidade = "Fortaleza";

$cidade = "São Paulo";

echo $cidade;

Resultado:

São Paulo

Alterando valores booleanos

<?php

$logado = false;

$logado = true;

var_dump($logado);

Resultado:

bool(true)

Alterando o tipo da variável

Como o PHP possui tipagem dinâmica, uma variável pode armazenar diferentes tipos de dados ao longo da execução.

<?php

$valor = 100;

$valor = "Cem";

echo $valor;

Resultado:

Cem

Outro exemplo:

<?php

$dados = "Gustavo";

$dados = true;

var_dump($dados);

Resultado:

bool(true)

O PHP altera automaticamente o tipo da variável conforme o novo valor atribuído.

Alterando usando o valor atual

É muito comum utilizar o valor já existente para calcular um novo.

<?php

$saldo = 1000;

$saldo = $saldo + 500;

echo $saldo;

Resultado:

1500

Nesse caso:

  1. $saldo vale 1000;
  1. Soma-se 500;
  1. O resultado (1500) é armazenado novamente em $saldo.

Operadores de atribuição

O PHP possui operadores que facilitam a alteração de valores.

Soma (+=)

Em vez de:

$saldo = $saldo + 500;

Pode-se escrever:

$saldo += 500;

Resultado:

1500

Subtração (=)

<?php

$estoque = 20;

$estoque -= 5;

echo $estoque;

Resultado:

15

Multiplicação (=)

<?php

$preco = 100;

$preco *= 2;

echo $preco;

Resultado:

200

Divisão (/=)

<?php

$total = 80;

$total /= 4;

echo $total;

Resultado:

20

Resto da divisão (%=)

<?php

$numero = 17;

$numero %= 5;

echo $numero;

Resultado:

2

Incrementando variáveis

Incrementar significa aumentar o valor da variável em 1.

Forma tradicional:

<?php

$contador = 5;

$contador = $contador + 1;

echo $contador;

Resultado:

6

Forma abreviada:

$contador++;

Também é possível utilizar:

++$contador;

Ambas aumentam o valor em 1, mas possuem diferenças de comportamento quando usadas dentro de expressões, assunto normalmente estudado junto aos operadores de incremento e decremento.

Decrementando variáveis

Decrementar significa diminuir o valor em 1.

Forma tradicional:

<?php

$vidas = 3;

$vidas = $vidas - 1;

echo $vidas;

Resultado:

2

Forma abreviada:

$vidas--;

ou

--$vidas;

Exemplo prático

Imagine um sistema bancário.

<?php

$saldo = 5000;

$saldo -= 1200; // Compra

$saldo += 800;  // Depósito

echo $saldo;

Resultado:

4600

O valor da variável muda conforme as operações realizadas.

Outro exemplo

Sistema de estoque:

<?php

$estoque = 50;

$estoque -= 3;

$estoque -= 10;

$estoque += 20;

echo $estoque;

Resultado:

57

Boas práticas

  • Utilize nomes de variáveis que representem claramente seu conteúdo.
  • Prefira operadores compostos (+=, =, =, /=) quando eles deixarem o código mais legível.
  • Evite alterar o tipo de uma variável sem necessidade, pois isso pode dificultar a compreensão do código.
  • Sempre verifique se a alteração faz sentido dentro da lógica da aplicação.

Resumo

As variáveis em PHP podem ter seus valores alterados quantas vezes forem necessárias durante a execução do programa. Basta realizar uma nova atribuição utilizando o operador =. Além disso, o PHP oferece operadores de atribuição composta, como +=, -=, *=, /= e %=``, que tornam operações comuns mais simples e legíveis. Também existem os operadores de incremento (++) e decremento (--`), utilizados para aumentar ou diminuir o valor de uma variável em uma unidade. A possibilidade de modificar variáveis é fundamental para o desenvolvimento de aplicações, pois permite atualizar informações, realizar cálculos e acompanhar o estado do sistema ao longo da execução.
