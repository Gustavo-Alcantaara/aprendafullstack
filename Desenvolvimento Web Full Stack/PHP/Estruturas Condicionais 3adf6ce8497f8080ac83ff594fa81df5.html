Estruturas Condicionais

Estruturas de Condição no PHP

As estruturas de condição são mecanismos utilizados para tomar decisões dentro de um programa. Elas permitem que o PHP execute diferentes blocos de código de acordo com o resultado de uma condição.

Em outras palavras, as estruturas condicionais permitem que o programa responda a perguntas como:

  • O usuário está logado?
  • A idade é maior que 18 anos?
  • O estoque é suficiente?
  • A senha está correta?
  • A nota é suficiente para aprovação?

Dependendo da resposta (verdadeiro ou falso), o programa executará uma ação diferente.

O que é uma condição?

Uma condição é uma expressão que resulta em um valor booleano:

  • true (verdadeiro)
  • false (falso)

Exemplo:

<?php

$idade = 20;

$idade >= 18

A expressão:

$idade >= 18

será avaliada como:

true

porque 20 é maior que 18.

Importância das estruturas condicionais

Sem estruturas de condição, um programa executaria todas as instruções na mesma ordem, sem considerar diferentes situações.

Com elas, é possível:

  • controlar o fluxo da aplicação;
  • validar informações;
  • restringir acesso;
  • exibir conteúdos específicos;
  • tratar diferentes cenários.

Principais estruturas condicionais do PHP

O PHP possui diversas estruturas para tomada de decisão.

As principais são:

  • if
  • if...else
  • if...elseif...else
  • switch
  • Operador ternário (?:)
  • Operador Null Coalescing (??)

Cada uma é indicada para um tipo de situação.

Estrutura if

O if executa um bloco de código somente se a condição for verdadeira.

Sintaxe:

if (condição) {

    // código

}

Exemplo:

<?php

$idade = 20;

if ($idade >= 18) {
    echo "Maior de idade";
}

Resultado:

Maior de idade

Se a condição for falsa, nada será executado.

Estrutura if...else

O else define o que deve acontecer quando a condição for falsa.

Sintaxe:

if (condição) {

    // verdadeiro

} else {

    // falso

}

Exemplo:

<?php

$idade = 16;

if ($idade >= 18) {
    echo "Maior de idade";
} else {
    echo "Menor de idade";
}

Resultado:

Menor de idade

Estrutura if...elseif...else

Quando existem várias possibilidades, utiliza-se elseif.

Exemplo:

<?php

$nota = 7;

if ($nota >= 9) {

    echo "Excelente";

} elseif ($nota >= 7) {

    echo "Aprovado";

} elseif ($nota >= 5) {

    echo "Recuperação";

} else {

    echo "Reprovado";

}

Resultado:

Aprovado

As condições são verificadas de cima para baixo. Assim que uma delas for verdadeira, as demais deixam de ser avaliadas.

Estruturas condicionais aninhadas

Também é possível colocar uma estrutura condicional dentro de outra.

<?php

$logado = true;
$admin = false;

if ($logado) {

    if ($admin) {

        echo "Área administrativa";

    } else {

        echo "Área do usuário";

    }

} else {

    echo "Faça login";

}

Esse recurso deve ser usado com cuidado, pois muitos níveis de aninhamento podem dificultar a leitura do código.

Estrutura switch

O switch é utilizado quando uma variável pode assumir diversos valores específicos.

Exemplo:

<?php

$dia = 3;

switch ($dia) {

    case 1:
        echo "Domingo";
        break;

    case 2:
        echo "Segunda-feira";
        break;

    case 3:
        echo "Terça-feira";
        break;

    default:
        echo "Dia inválido";

}

Resultado:

Terça-feira

O break interrompe a execução do switch. Sem ele, o PHP continuará executando os próximos casos.

Operador ternário

O operador ternário é uma forma reduzida de escrever um if...else simples.

Sintaxe:

condição ? valor_se_verdadeiro : valor_se_falso;

Exemplo:

<?php

$idade = 20;

echo ($idade >= 18) ? "Maior de idade" : "Menor de idade";

Resultado:

Maior de idade

É indicado para decisões simples.

Operador Null Coalescing (??)

Introduzido no PHP 7, o operador ?? verifica se uma variável existe e não é null.

Exemplo:

<?php

$nome = null;

echo $nome ?? "Visitante";

Resultado:

Visitante

Esse operador é muito utilizado para trabalhar com dados de formulários e parâmetros de requisições.

Operadores relacionais

As estruturas condicionais normalmente utilizam operadores relacionais.

OperadorSignificado
==Igual
===Igual em valor e tipo
!=Diferente
!==Diferente em valor ou tipo
>Maior que
<Menor que
>=Maior ou igual
<=Menor ou igual

Exemplo:

<?php

$idade = 21;

if ($idade >= 18) {
    echo "Permitido";
}

Operadores lógicos

Também é comum combinar várias condições.

OperadorSignificado
&&E (AND)
`
!Não (NOT)

Exemplo:

<?php

$idade = 22;
$habilitado = true;

if ($idade >= 18 && $habilitado) {
    echo "Pode dirigir";
}

Resultado:

Pode dirigir

Exemplos práticos

Sistema de login

<?php

$logado = true;

if ($logado) {

    echo "Bem-vindo!";

} else {

    echo "Faça login.";

}

Controle de estoque

<?php

$estoque = 8;

if ($estoque > 0) {

    echo "Produto disponível";

} else {

    echo "Produto indisponível";

}

Aprovação escolar

<?php

$nota = 6.5;

if ($nota >= 7) {

    echo "Aprovado";

} elseif ($nota >= 5) {

    echo "Recuperação";

} else {

    echo "Reprovado";

}

Boas práticas

  • Escreva condições simples e fáceis de entender.
  • Evite muitos níveis de if aninhados.
  • Utilize switch quando comparar uma mesma variável com vários valores fixos.
  • Utilize o operador ternário apenas para condições simples.
  • Sempre utilize indentação para melhorar a legibilidade.

Resumo

As estruturas de condição permitem que um programa tome decisões durante sua execução, executando diferentes blocos de código conforme o resultado de uma condição. No PHP, as principais estruturas são if, if...else, if...elseif...else e switch, além dos operadores ternário (?:) e Null Coalescing (??). Elas trabalham em conjunto com operadores relacionais e lógicos para avaliar expressões que resultam em verdadeiro ou falso. O uso correto dessas estruturas é essencial para desenvolver aplicações capazes de validar dados, controlar o fluxo do programa e responder de forma inteligente às ações do usuário.
