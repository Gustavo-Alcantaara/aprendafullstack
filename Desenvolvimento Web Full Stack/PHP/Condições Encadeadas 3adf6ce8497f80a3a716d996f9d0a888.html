Condições Encadeadas

Condições Encadeadas no PHP

As condições encadeadas são estruturas utilizadas quando um programa precisa avaliar várias condições diferentes, executando apenas o bloco de código correspondente à primeira condição verdadeira.

Em PHP, as condições encadeadas são implementadas principalmente com a estrutura:

  • if
  • elseif
  • else

Esse tipo de estrutura permite tratar diferentes situações de forma organizada e eficiente.

O que são condições encadeadas?

Uma condição encadeada ocorre quando existe mais de uma possibilidade de decisão.

Por exemplo, imagine um sistema escolar que precisa informar a situação de um aluno:

  • Nota maior ou igual a 9 → Excelente.
  • Nota maior ou igual a 7 → Aprovado.
  • Nota maior ou igual a 5 → Recuperação.
  • Qualquer outro valor → Reprovado.

Nesse caso, uma única condição não é suficiente. É necessário avaliar várias possibilidades em sequência.

Estrutura básica

A sintaxe é:

if (condição1) {

    // Código executado se condição1 for verdadeira

} elseif (condição2) {

    // Código executado se condição2 for verdadeira

} elseif (condição3) {

    // Código executado se condição3 for verdadeira

} else {

    // Código executado se nenhuma condição for verdadeira

}

O PHP analisa as condições de cima para baixo.

Quando encontra a primeira condição verdadeira, executa seu bloco de código e ignora todas as demais.

Funcionamento

Fluxo de execução:

Início
   │
   ▼
Condição 1?
   │
 ┌─┴──────────────┐
 │Sim             │Não
 ▼                ▼
Executa       Condição 2?
Bloco 1          │
                 │
             ┌───┴───────┐
             │Sim        │Não
             ▼           ▼
        Executa      Condição 3?
         Bloco 2         │
                          │
                     ┌────┴────┐
                     │Sim      │Não
                     ▼         ▼
                 Executa   Executa
                  Bloco 3   Else

Exemplo simples

<?php

$nota = 8;

if ($nota >= 9) {

    echo "Excelente";

} elseif ($nota >= 7) {

    echo "Aprovado";

} elseif ($nota >= 5) {

    echo "Recuperação";

} else {

    echo "Reprovado";

}

Resultado:

Aprovado

A primeira condição ($nota >= 9) é falsa.

A segunda ($nota >= 7) é verdadeira.

O PHP executa esse bloco e não verifica as demais condições.

Outro exemplo

Sistema de classificação de idade.

<?php

$idade = 15;

if ($idade < 12) {

    echo "Criança";

} elseif ($idade < 18) {

    echo "Adolescente";

} elseif ($idade < 60) {

    echo "Adulto";

} else {

    echo "Idoso";

}

Resultado:

Adolescente

Importância da ordem das condições

A ordem das condições é muito importante.

Observe este exemplo:

<?php

$idade = 20;

if ($idade >= 18) {

    echo "Maior de idade";

} elseif ($idade >= 60) {

    echo "Idoso";

}

Resultado:

Maior de idade

Embora uma pessoa com 60 anos também seja maior de idade, a condição >= 18 será verdadeira primeiro, impedindo que a segunda seja analisada.

O correto seria:

<?php

$idade = 65;

if ($idade >= 60) {

    echo "Idoso";

} elseif ($idade >= 18) {

    echo "Maior de idade";

}

Agora a classificação será feita corretamente.

Utilizando operadores lógicos

É comum utilizar operadores lógicos em condições encadeadas.

<?php

$idade = 25;
$habilitado = true;

if ($idade >= 18 && $habilitado) {

    echo "Pode dirigir";

} elseif ($idade >= 18) {

    echo "Maior de idade, mas sem habilitação";

} else {

    echo "Menor de idade";

}

Exemplo com sistema de login

<?php

$usuario = "admin";
$senha = "123456";

if ($usuario == "admin" && $senha == "123456") {

    echo "Login realizado";

} elseif ($usuario != "admin") {

    echo "Usuário inválido";

} else {

    echo "Senha incorreta";

}

Exemplo com notas

<?php

$nota = 9.5;

if ($nota >= 9) {

    echo "Excelente";

} elseif ($nota >= 7) {

    echo "Bom";

} elseif ($nota >= 5) {

    echo "Recuperação";

} else {

    echo "Reprovado";

}

Quando utilizar condições encadeadas?

As condições encadeadas são indicadas quando existem várias possibilidades mutuamente exclusivas, como:

  • Classificação de notas.
  • Faixa etária.
  • Nível de acesso.
  • Faixa de desconto.
  • Situação de pagamento.
  • Classificação de clientes.
  • Avaliação de desempenho.

Condições encadeadas x condições aninhadas

É importante não confundir esses dois conceitos.

Condições encadeadas

Utilizam if, elseif e else para verificar várias possibilidades em sequência.

<?php

if ($nota >= 7) {

    echo "Aprovado";

} elseif ($nota >= 5) {

    echo "Recuperação";

} else {

    echo "Reprovado";

}

Condições aninhadas

São estruturas if dentro de outro if.

<?php

if ($logado) {

    if ($admin) {

        echo "Administrador";

    } else {

        echo "Usuário comum";

    }

}

Enquanto as condições encadeadas escolhem entre várias alternativas, as condições aninhadas verificam uma nova condição somente após outra já ter sido satisfeita.

Boas práticas

  • Organize as condições da mais específica para a mais geral, quando necessário.
  • Evite criar muitos níveis de elseif; em alguns casos, um switch pode ser mais adequado.
  • Utilize indentação para melhorar a leitura do código.
  • Escreva condições simples e objetivas.
  • Sempre revise a ordem das comparações para evitar que uma condição mais ampla impeça a execução de uma condição mais específica.

Resumo

As condições encadeadas permitem que um programa avalie diversas possibilidades em sequência utilizando as estruturas if, elseif e else. O PHP verifica cada condição na ordem em que aparece e executa apenas o bloco correspondente à primeira condição verdadeira, ignorando as demais. Esse recurso é amplamente utilizado para classificar informações, validar dados, controlar níveis de acesso e implementar regras de negócio. A correta organização das condições é essencial para garantir que a lógica da aplicação funcione conforme esperado, tornando o código mais claro, eficiente e fácil de manter.
