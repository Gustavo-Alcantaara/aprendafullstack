Operador Ternário

Operador Ternário no PHP

O operador ternário é uma forma simplificada e compacta de escrever uma estrutura if...else quando há apenas duas possibilidades de resultado.

Seu principal objetivo é tornar o código mais curto e legível em situações simples, evitando a necessidade de escrever uma estrutura condicional completa.

O nome "ternário" vem do fato de que ele trabalha com três operandos:

  1. A condição a ser avaliada.
  1. O valor retornado caso a condição seja verdadeira.
  1. O valor retornado caso a condição seja falsa.

Quando utilizar?

O operador ternário é indicado quando existe apenas uma decisão simples.

Por exemplo:

  • Exibir "Aprovado" ou "Reprovado";
  • Informar se um usuário está logado;
  • Mostrar "Maior" ou "Menor de idade";
  • Definir um valor padrão.

Quando a lógica se torna complexa, é mais recomendável utilizar if...else, pois o código fica mais fácil de entender.

Sintaxe

A sintaxe do operador ternário é:

condição ? valor_se_verdadeiro : valor_se_falso;

A estrutura pode ser entendida da seguinte forma:

condição
    ?
verdadeiro
    :
falso

Se a condição for verdadeira, o PHP retorna o valor após ?.

Caso contrário, retorna o valor após :.

Comparação com o if...else

Utilizando if...else

<?php

$idade = 20;

if ($idade >= 18) {
    echo "Maior de idade";
} else {
    echo "Menor de idade";
}

Utilizando operador ternário

<?php

$idade = 20;

echo ($idade >= 18) ? "Maior de idade" : "Menor de idade";

Resultado:

Maior de idade

Observe que o operador ternário produz o mesmo resultado utilizando menos linhas de código.

Exemplo com variáveis

O resultado do operador ternário pode ser armazenado em uma variável.

<?php

$nota = 8;

$resultado = ($nota >= 7) ? "Aprovado" : "Reprovado";

echo $resultado;

Resultado:

Aprovado

Exemplo com login

<?php

$logado = true;

echo $logado ? "Bem-vindo!" : "Faça login.";

Resultado:

Bem-vindo!

Exemplo com estoque

<?php

$estoque = 12;

$status = ($estoque > 0) ? "Disponível" : "Indisponível";

echo $status;

Resultado:

Disponível

Utilizando operadores de comparação

O operador ternário normalmente trabalha em conjunto com operadores de comparação.

<?php

$idade = 16;

echo ($idade >= 18) ? "Entrada permitida" : "Entrada proibida";

Resultado:

Entrada proibida

Utilizando operadores lógicos

Também é possível utilizar condições compostas.

<?php

$idade = 20;
$habilitado = true;

echo ($idade >= 18 && $habilitado)
        ? "Pode dirigir"
        : "Não pode dirigir";

Resultado:

Pode dirigir

Operador ternário aninhado

É possível utilizar um operador ternário dentro de outro.

<?php

$nota = 6;

echo ($nota >= 9)
        ? "Excelente"
        : (($nota >= 7)
            ? "Aprovado"
            : "Reprovado");

Resultado:

Reprovado

Embora seja válido, não é recomendado utilizar muitos operadores ternários aninhados, pois eles dificultam a leitura do código.

Nesses casos, um if...elseif...else costuma ser uma escolha melhor.

Precedência e uso de parênteses

É uma boa prática utilizar parênteses para deixar a condição mais clara.

<?php

echo ($idade >= 18) ? "Maior" : "Menor";

Isso melhora a legibilidade e evita ambiguidades em expressões mais complexas.

Vantagens

  • Reduz a quantidade de código.
  • Torna decisões simples mais objetivas.
  • Facilita a atribuição de valores condicionais.
  • Pode deixar o código mais legível quando usado corretamente.

Desvantagens

  • Pode prejudicar a legibilidade quando usado em condições complexas.
  • Operadores ternários aninhados tornam o código difícil de compreender.
  • Não substitui estruturas if...else em lógicas mais elaboradas.

Quando usar o operador ternário?

Utilize quando:

  • A decisão possui apenas duas possibilidades.
  • A condição é simples.
  • O objetivo é atribuir um valor ou exibir uma mensagem.

Evite quando:

  • Existem muitas condições.
  • Há várias ações dentro de cada bloco.
  • A lógica é complexa.

Nesses casos, prefira if...elseif...else.

Boas práticas

  • Utilize o operador ternário apenas para condições simples.
  • Evite operadores ternários aninhados sempre que possível.
  • Use parênteses para melhorar a leitura da condição.
  • Prefira if...else quando a lógica envolver várias instruções.

Resumo

O operador ternário é uma forma abreviada da estrutura if...else, utilizada para tomar decisões simples em uma única linha de código. Sua sintaxe é condição ? valor_se_verdadeiro : valor_se_falso, permitindo retornar um valor diferente conforme o resultado da condição. É muito utilizado para atribuições condicionais e exibição de mensagens, tornando o código mais compacto. Entretanto, seu uso deve ser limitado a situações simples, pois condições complexas ou operadores ternários aninhados podem comprometer a legibilidade e dificultar a manutenção do código.
