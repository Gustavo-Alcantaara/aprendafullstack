Array Básico em PHP

Um array é uma estrutura de dados utilizada para armazenar vários valores dentro de uma única variável. Em PHP, arrays são muito importantes porque permitem trabalhar facilmente com listas de informações, como nomes, produtos, notas, usuários, preços etc.

Por exemplo, em vez de criar várias variáveis:

$nome1 = "João";
$nome2 = "Maria";
$nome3 = "Pedro";

podemos armazenar todos os nomes em um único array:

$nomes = ["João", "Maria", "Pedro"];

1. Criando um Array

A forma mais comum de criar um array em PHP é utilizando colchetes []:

$frutas = ["Maçã", "Banana", "Laranja"];

Também é possível utilizar a função array():

$frutas = array("Maçã", "Banana", "Laranja");

Porém, a sintaxe com [] é mais moderna e geralmente preferida.

2. Índices do Array

Quando criamos um array simples, o PHP atribui automaticamente um índice numérico para cada elemento.

$frutas = ["Maçã", "Banana", "Laranja"];

Os índices serão:

ÍndiceValor
0Maçã
1Banana
2Laranja

Atenção: em PHP, o primeiro índice normalmente é 0, e não 1.

Para acessar um elemento, utilizamos o índice:

echo $frutas[0];

Resultado:

Maçã

Outro exemplo:

echo $frutas[2];

Resultado:

Laranja

3. Alterando um Elemento

Podemos modificar um valor através do seu índice:

$frutas = ["Maçã", "Banana", "Laranja"];

$frutas[1] = "Uva";

print_r($frutas);

Resultado:

Array
(
    [0] => Maçã
    [1] => Uva
    [2] => Laranja
)

4. Adicionando Elementos

Para adicionar um elemento ao final do array, podemos utilizar []:

$frutas = ["Maçã", "Banana"];

$frutas[] = "Laranja";

Agora o array contém:

Maçã
Banana
Laranja

Também podemos adicionar vários elementos usando array_push():

$frutas = ["Maçã", "Banana"];

array_push($frutas, "Laranja", "Uva");

Entretanto, para simplesmente adicionar elementos ao final, $frutas[] = ... costuma ser mais simples e direto.

5. Removendo Elementos

Podemos utilizar unset() para remover um elemento específico:

$frutas = ["Maçã", "Banana", "Laranja"];

unset($frutas[1]);

O resultado será aproximadamente:

[0] => Maçã
[2] => Laranja

Observe que o índice 1 não é automaticamente reorganizado.

Se for necessário reorganizar os índices:

$frutas = array_values($frutas);

6. Descobrindo o Tamanho do Array

A função count() retorna a quantidade de elementos:

$frutas = ["Maçã", "Banana", "Laranja"];

echo count($frutas);

Resultado:

3

Isso é muito útil principalmente quando trabalhamos com estruturas de repetição.

7. Percorrendo um Array

Uma das principais utilidades dos arrays é poder percorrer todos os seus elementos.

Para isso, podemos utilizar o foreach:

$frutas = ["Maçã", "Banana", "Laranja"];

foreach ($frutas as $fruta) {
    echo $fruta . "<br>";
}

Resultado:

Maçã
Banana
Laranja

O foreach pega cada elemento do array e coloca temporariamente na variável $fruta.

Também podemos acessar o índice:

foreach ($frutas as $indice => $fruta) {
    echo $indice . " - " . $fruta . "<br>";
}

Resultado:

0 - Maçã
1 - Banana
2 - Laranja

8. Arrays com Diferentes Tipos de Dados

PHP permite que um array contenha valores de tipos diferentes:

$dados = [
    "Gustavo",
    20,
    1.75,
    true
];

Nesse exemplo temos:

  • "Gustavo" → string
  • 20 → inteiro
  • 1.75 → float
  • true → booleano

Embora seja possível, em aplicações reais é importante manter uma organização coerente dos dados.

9. Verificando se um Elemento Existe

A função in_array() verifica se determinado valor está presente no array:

$frutas = ["Maçã", "Banana", "Laranja"];

if (in_array("Banana", $frutas)) {
    echo "Banana encontrada!";
}

Resultado:

Banana encontrada!

Isso é bastante utilizado quando precisamos verificar se determinado item está cadastrado ou disponível.

10. Exibindo um Array

Utilizar:

echo $frutas;

não é a maneira adequada de visualizar o conteúdo completo de um array.

Para fins de teste e desenvolvimento, podemos utilizar:

print_r($frutas);

ou:

var_dump($frutas);

var_dump() fornece informações mais detalhadas, incluindo os tipos dos valores.

Exemplo:

$frutas = ["Maçã", "Banana"];

var_dump($frutas);

11. Exemplo Prático

Imagine um sistema que precisa armazenar as notas de um aluno:

$notas = [8, 7.5, 9, 6];

$soma = 0;

foreach ($notas as $nota) {
    $soma += $nota;
}

$media = $soma / count($notas);

echo "Média: " . $media;

Nesse exemplo, o array armazena várias notas e o foreach permite percorrer cada uma delas para calcular a média.

12. Principais Operações

As operações básicas que você deve conhecer são:

$nomes = ["João", "Maria", "Pedro"];

// Acessar
echo $nomes[0];

// Alterar
$nomes[1] = "Ana";

// Adicionar
$nomes[] = "Carlos";

// Quantidade
echo count($nomes);

// Verificar existência
if (in_array("Pedro", $nomes)) {
    echo "Encontrado";
}

// Percorrer
foreach ($nomes as $nome) {
    echo $nome;
}

// Remover
unset($nomes[0]);

Resumindo

O array básico em PHP permite armazenar e manipular vários valores em uma única variável. Os principais conceitos são:

  • [] → cria um array;
  • [0], [1], [2] → acessam os elementos pelos índices;
  • $array[] = valor → adiciona um elemento;
  • $array[indice] = valor → altera um elemento;
  • unset() → remove um elemento;
  • count() → conta os elementos;
  • foreach → percorre o array;
  • in_array() → verifica se um valor existe;
  • print_r() e var_dump() → ajudam a visualizar o conteúdo.

Esse é o fundamento para entender os próximos tipos de arrays em PHP, principalmente os arrays associativos e multidimensionais.
