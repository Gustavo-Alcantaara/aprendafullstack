Fontes e Cores

As cores são formadas por três cores principais. As chamadas RGB

R: Red = Vermelho

G: Green = Verde

B: Blue = Azul

Cores em CSS

As cores em CSS servem para estilizar textos, fundos, bordar, sombras e vários elementos visuais do site.

exemplo:


p{
color: blue;
}

Isso deixa o texto azul.

Onde usar cores

Texto

color:red;

Fundo

background-color:yellow;

Borda

border: 2pxsolidgreen;

Formas de usar cores no CSS

1. Nome da cor

Usa nomes prontos do CSS:

color:blue;
color:red;
color:black;
color:white;

Simples, mas limitado.

2. RGB

RGB significa:

  • R = Red (vermelho)
  • G = Green (verde)
  • B = Blue (azul)

Cada valor vai de 0 até 255.

color:rgb(255,0,0);

Vermelho puro.

color:rgb(0,255,0);

Verde puro.

color:rgb(0,0,255);

Azul puro.

Misturando:

color:rgb(255,255,0);

Amarelo (vermelho + verde)

3. RGBA

Mesmo RGB, mas com transparência.

background-color:rgba(255,0,0,0.5);

O último valor vai de:

  • 0 = totalmente transparente
  • 1 = totalmente visível

4. Hexadecimal (#)

Muito usado no front-end.

color:#ff0000;

Vermelho.

Formato:

#RRGGBB

Exemplos:

#000000 =preto
#ffffff =branco
#00ff00 =verde
#0000ff =azul

5. HSL

Baseado em:

  • H = Hue (tom)
  • S = Saturation
  • L = Lightness
color:hsl(0, 100%, 50%);

Vermelho.

Muito útil para criar variações de cor.

Opacidade geral

opacity: 0.5;

Deixa todo elemento transparente.

Exemplo completo

body{
  background-color: #121212;
}

h1{
  color:rgb(255,255,255);
}

p{
  color:rgba(255,255,255,0.7);
}

Dica prática

Use:

  • Hexadecimal → mais comum no mercado
  • RGB/RGBA → quando precisar transparência
  • HSL → ajustes rápidos de tons
  • Nome → testes simples

Resumo final

CSS permite usar cores em:

  • texto
  • fundo
  • borda
  • sombras

Principais formatos:

  • red
  • rgb(255,0,0)
  • rgba(255,0,0,0.5)
  • #ff0000
  • hsl(0,100%,50%)

Dominar cores melhora muito o visual do site.

Fontes CSS

Resumo sobre Fontes em CSS

As fontes em CSS controlam como o texto aparece no site: tipo da letra, tamanho, espessura, estilo e espaçamento. Uma boa tipografia melhora a leitura e deixa o visual mais profissional.

font-family

Define a fonte usada.

p{
  font-family:Arial, Verdana, sans-serif;
}

Se a primeira não existir, usa a próxima.

Se a próxima não existir, use uma da família definida(sans-serif).

Famílias genéricas:

  • serif → tradicional
  • sans-serif → moderna
  • monospace → letras com mesmo espaço (código)

Regra prática

Use aspas quando:

✅ tem espaço no nome

✅ fonte importada/customizada

✅ quer padronizar código

✅ pode usar aspas duplas ou simples

font-family: "Times New Roman", serif;
font-family: 'Open Sans', sans-serif;
font-family: Arial, sans-serif;

font-size

Define o tamanho da letra.

p{
  font-size:16px;
}

Unidades de medida da fonte

1. px (pixels)

Unidade fixa. Muito usada.

font-size: 18px;
  • Fácil de controlar
  • Valor exato

2. % (porcentagem)

Baseado no tamanho do elemento pai.

font-size: 120%;
  • 100% = tamanho normal herdado
  • 120% = 20% maior

3. em

Relativo ao tamanho do elemento pai.

font-size: 1.5em;

Se o pai tiver 20px:

  • 1em = 20px
  • 1.5em = 30px

Muito usado, mas pode acumular tamanhos em elementos aninhados.

4. rem

Relativo ao tamanho da fonte do elemento raiz (html).

font-size: 2rem;

Se html tiver 16px:

  • 1rem = 16px
  • 2rem = 32px

👉 Muito usado em projetos modernos porque é previsível.

5. vw

Baseado na largura da tela.

font-size: 5vw;

Bom para textos responsivos.

Regra:

  • 1vw = 1% da largura da tela
  • 100vw = largura total da tela

Então:

  • 5vw = 5% da largura da tela
  • Não é “5 vezes a tela”.

6. vh

Baseado na altura da tela.

font-size: 5vh;

Bom para textos responsivos.

Qual usar?

Melhor escolha na prática:

  • px → controle rápido e simples
  • rem → projetos profissionais e responsivos
  • em → componentes internos
  • % → herança
  • vw → títulos adaptáveis

font-weight

Espessura da letra.

font-weight:bold;

ou

font-weight: 700;
  • 400 = normal
  • 700 = negrito

font-style

font-style:italic;

Itálico.

text-align

Alinhamento do texto.

text-align:center;

Valores:

  • left
  • center
  • right
  • justify

line-height

Espaço entre linhas.

line-height: 1.6;

Melhora leitura.

Exemplo completo

html{
  font-size:16px;
}

h1{
  font-size:2rem;
}

p{
  font-size:1rem;
  line-height:1.6;
}

Resumo final

Principais propriedades:

  • font-family
  • font-size
  • font-weight
  • font-style
  • text-align
  • line-height

Unidades de tamanho:

  • px = fixo
  • em = relativo ao pai
  • rem = relativo ao html
  • % = porcentagem
  • vw = largura da tela
  • vh = altura da tela

👉 Hoje, rem é uma das melhores escolhas para sites modernos.
