Bordas

Bordas em CSS servem para criar contornos ao redor dos elementos (como div, button, img, etc.). Elas ficam entre o padding e a margin no modelo de caixa.

Propriedades principais

1. border

Forma resumida para definir:

  • espessura
  • estilo
  • cor
border: 2px solid black;

Exemplo:

div {
  border:2px solid blue;
}

2. Separadas

Espessura

border-width: 3px;

Estilo

border-style: solid;

Tipos comuns:

  • solid → linha contínua
  • dashed → tracejada
  • dotted → pontilhada
  • double → linha dupla
  • groove → efeito entalhado/3D
  • ridge → efeito elevado/3D
  • inset → parece afundada
  • outset → parece saltada
  • none → sem borda
  • hidden → escondida (parecida com none)

Exemplo:

div {
  border:3px dashed red;
}

Cor

border-color: red;

Bordas em lados específicos

border-top: 2px solid red;
border-right: 2px solid blue;
border-bottom: 2px solid green;
border-left: 2px solid black;

Bordas arredondadas

border-radius

Arredonda os cantos:

border-radius: 10px;

Círculo:

border-radius: 50%;

(Usado muito em imagens de perfil)

Podemos Definir o border-radius mais especificamente:

border-top-left-radius: 10px;

Define as bordas do topo e da esquerda.

Exemplo completo

button {
  border:2px solid black;
  border-radius:8px;
}

Outline

outline é um “contorno” que fica por fora da borda do elemento.

O que ele tem de diferente da border

  • Não ocupa espaço no layout (não entra no box model).

    Ou seja: colocar outline não aumenta o tamanho do elemento e não empurra nada ao redor.

  • Pode “passar por cima” de coisas ao redor, porque ele só desenha por fora.
  • É muito usado para foco (acessibilidade / navegação por teclado).

Onde usar (na prática)

  1. Indicar foco em inputs e botões

Quando você clica ou usa Tab para navegar, o navegador coloca um outline padrão (geralmente azul). Isso é ótimo para acessibilidade.

button:focus,
input:focus {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}
  • outline-offset afasta o outline do elemento, deixando mais bonito e legível.
  1. Destacar elementos sem “quebrar” o layout

Ex.: destacar um card selecionado/ativo sem mudar tamanho.

.card--selected {
  outline: 3px solid #22c55e;
  outline-offset: 4px;
}
  1. Debug rápido de layout

Às vezes é melhor que border para inspecionar sem alterar medidas.

* { outline: 1px solid rgba(255,0,0,.2); }

Propriedades mais comuns

  • outline: <largura> <estilo> <cor>; (shorthand)
  • outline-width, outline-style, outline-color
  • outline-offset

Exemplo:

input:focus {
  outline: 2px dashed red;
  outline-offset: 3px;
}

Atenção (muito importante)

Evite fazer isso:

*:focus { outline: none; }

porque você remove o indicador de foco e atrapalha quem navega com teclado.

Se quiser tirar o padrão, substitua por um foco personalizado (como no exemplo acima).

Resumo rápido

  • border = tudo em uma linha
  • border-width = grossura
  • border-style = estilo
  • border-color = cor
  • border-radius = arredondar cantos
  • Pode aplicar em lados específicos (top, left etc.)

Dica prática

Se a borda não aparecer, geralmente esqueceu o:

border-style

Sem estilo, a borda não renderiza.
