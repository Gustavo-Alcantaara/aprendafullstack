Backdrop-filter

backdrop-filter no CSS

Introdução

A propriedade backdrop-filter permite aplicar efeitos visuais ao conteúdo que está atrás de um elemento, e não ao próprio elemento.

Essa é a principal diferença em relação ao filter:

  • filter → modifica o próprio elemento.
  • backdrop-filter → modifica apenas o que está atrás dele.

Essa propriedade é muito utilizada para criar interfaces modernas com efeito de vidro fosco (Glassmorphism), painéis translúcidos, menus, modais e barras de navegação.

Como funciona

Imagine a seguinte estrutura:

Imagem de fundo
        ↓
---------------------
|                   |
|       Card        |
|                   |
---------------------

Sem backdrop-filter, o fundo aparece normalmente.

Com:

backdrop-filter: blur(10px);

o navegador faz o seguinte:

  1. Renderiza o fundo.
  1. Captura a parte do fundo que está atrás do elemento.
  1. Aplica o filtro nessa área.
  1. Desenha o elemento por cima.

Visualmente:

Antes

██████████████████

[ CARD ]

Depois

████▒▒▒▒████▒▒▒▒██

[ CARD ]

O conteúdo atrás do card fica desfocado, enquanto o card permanece nítido.

Sintaxe

backdrop-filter: função(valor);

Exemplo:

.card{
    backdrop-filter: blur(10px);
}

Também é possível combinar várias funções:

backdrop-filter:
blur(10px)
brightness(120%)
contrast(90%);

Diferença entre filter e backdrop-filter

filter

Aplica o efeito ao próprio elemento.

img{
    filter: blur(5px);
}

Resultado:

Imagem borrada

backdrop-filter

Aplica o efeito apenas ao fundo.

.card{
    backdrop-filter: blur(10px);
}

Resultado:

Imagem de fundo borrada

Card continua normal

Comparação

filterbackdrop-filter
Afeta o próprio elementoAfeta o conteúdo atrás do elemento
Imagens ficam borradasFundo fica borrado
Texto do elemento também recebe o filtroTexto permanece nítido
Muito usado em imagensMuito usado em painéis e cards

Importante: o elemento precisa ser transparente

Esse é o erro mais comum.

Se o elemento tiver um fundo totalmente opaco, o efeito não aparecerá.

Errado:

.card{
    background: white;
    backdrop-filter: blur(15px);
}

Como o fundo é totalmente branco, não há nada para enxergar atrás dele.

O correto é usar uma cor com transparência:

.card{
    background: rgba(255,255,255,.2);
    backdrop-filter: blur(15px);
}

Ou:

background: rgb(255 255 255 / 20%);

Assim, o fundo continua visível e pode receber o filtro.

Funções disponíveis

O backdrop-filter utiliza praticamente as mesmas funções do filter.

blur()

Desfoca o fundo.

backdrop-filter: blur(10px);

É a função mais utilizada.

brightness()

Altera o brilho do fundo.

backdrop-filter: brightness(150%);

contrast()

Altera o contraste do fundo.

backdrop-filter: contrast(80%);

grayscale()

Converte o fundo para tons de cinza.

backdrop-filter: grayscale(100%);

invert()

Inverte as cores do fundo.

backdrop-filter: invert(100%);

sepia()

Aplica efeito envelhecido.

backdrop-filter: sepia(100%);

saturate()

Aumenta ou reduz a intensidade das cores.

backdrop-filter: saturate(180%);

Muito usada junto com blur().

opacity()

Controla a opacidade do fundo filtrado.

backdrop-filter: opacity(50%);

hue-rotate()

Rotaciona as cores.

backdrop-filter: hue-rotate(90deg);

Combinando filtros

É possível aplicar vários efeitos simultaneamente.

.card{
    backdrop-filter:
    blur(15px)
    brightness(120%)
    saturate(180%);
}

Outro exemplo:

.card{
    backdrop-filter:
    blur(20px)
    contrast(80%)
    grayscale(20%);
}

Exemplos práticos

Card Glassmorphism

.card{
    width:300px;
    padding:20px;

    background:rgba(255,255,255,.15);

    border:1px solid rgba(255,255,255,.3);

    backdrop-filter:blur(15px);

    border-radius:20px;
}

Esse é o exemplo clássico do efeito de vidro fosco.

Navbar transparente

header{

    position:fixed;

    width:100%;

    background:rgba(20,20,20,.4);

    backdrop-filter:blur(12px);
}

Muito utilizada em sites modernos.

Modal

.modal{

    background:rgba(255,255,255,.2);

    backdrop-filter:blur(25px);

}

Cria um efeito sofisticado sem esconder totalmente o conteúdo atrás.

Painel lateral

.sidebar{

    background:rgba(0,0,0,.3);

    backdrop-filter:blur(18px);

}

Glassmorphism

O backdrop-filter é um dos pilares do estilo Glassmorphism, que busca simular vidro fosco.

Características comuns:

  • fundo transparente;
  • desfoque;
  • borda clara;
  • sombras suaves;
  • cantos arredondados.

Exemplo:

.card{

    background:rgba(255,255,255,.12);

    border:1px solid rgba(255,255,255,.2);

    backdrop-filter:blur(20px);

    box-shadow:
    0 8px 30px rgba(0,0,0,.2);

    border-radius:20px;
}

Casos de uso

O backdrop-filter é muito usado em:

  • menus;
  • barras de navegação;
  • modais;
  • pop-ups;
  • janelas flutuantes;
  • cards;
  • painéis laterais;
  • dashboards;
  • interfaces futuristas;
  • temas minimalistas.

Boas práticas

✔ Sempre utilize um fundo com transparência (rgba(), hsla() ou rgb() com canal alfa).

✔ Prefira valores de blur() entre 8px e 20px, que costumam oferecer um bom equilíbrio entre estética e desempenho.

✔ Combine com border-radius e box-shadow para reforçar o efeito de vidro.

✔ Garanta bom contraste entre o texto e o fundo desfocado para manter a legibilidade.

Erros comuns

1. Fundo totalmente opaco

background:white;

backdrop-filter:blur(10px);

O efeito praticamente não será percebido.

2. Esquecer a transparência

background:#ffffff;

Use:

background:rgba(255,255,255,.2);

3. Blur exagerado

backdrop-filter:blur(60px);

Além de pesar no desempenho, pode dificultar a leitura do conteúdo ao fundo.

Desempenho (Performance)

O backdrop-filter é mais custoso que muitas outras propriedades CSS, pois o navegador precisa:

  1. Renderizar o conteúdo de fundo.
  1. Capturar a área atrás do elemento.
  1. Aplicar o filtro.
  1. Renderizar novamente o elemento.

Isso pode impactar a fluidez em dispositivos mais simples, principalmente quando:

  • há muitos elementos com backdrop-filter;
  • o valor de blur() é muito alto;
  • o efeito é animado constantemente.

Sempre teste o desempenho em diferentes dispositivos.

Compatibilidade

Atualmente, o backdrop-filter é suportado pelos principais navegadores modernos, como:

  • Google Chrome
  • Microsoft Edge
  • Safari
  • Opera
  • Mozilla Firefox (em versões recentes)

Em navegadores antigos, o suporte era limitado ou exigia prefixos como -webkit-backdrop-filter. Hoje, o uso do prefixo raramente é necessário, mas é recomendável verificar o suporte caso seu projeto precise atender navegadores mais antigos.

Propriedades relacionadas

  • filter → aplica efeitos ao próprio elemento.
  • box-shadow → cria sombras ao redor da caixa do elemento.
  • text-shadow → cria sombras no texto.
  • background → define a cor, imagem ou gradiente de fundo.
  • opacity → controla a transparência do elemento inteiro.
  • border-radius → arredonda os cantos e melhora o efeito de vidro.

Resumo

  • backdrop-filter aplica efeitos ao conteúdo que está atrás do elemento.
  • É ideal para criar efeitos de vidro fosco (Glassmorphism).
  • O elemento precisa ter um fundo parcialmente transparente para que o efeito seja visível.
  • Aceita funções como blur(), brightness(), contrast(), grayscale(), invert(), sepia(), saturate(), opacity() e hue-rotate().
  • Pode combinar várias funções em uma única declaração.
  • Deve ser usado com cuidado, pois pode ter um custo maior de renderização, especialmente quando aplicado em muitos elementos ou com valores elevados de blur().
