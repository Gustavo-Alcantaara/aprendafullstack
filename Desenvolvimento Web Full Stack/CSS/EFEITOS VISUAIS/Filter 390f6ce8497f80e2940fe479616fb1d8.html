Filter

filter no CSS

Introdução

A propriedade filter permite aplicar efeitos gráficos a elementos HTML, como imagens, textos, vídeos e até elementos completos (div, section, button, etc.).

Com ela, é possível alterar a aparência de um elemento sem modificar sua imagem original. Os efeitos são aplicados em tempo real pelo navegador, tornando o filter uma ferramenta muito poderosa para criar interfaces modernas e interativas.

Alguns efeitos comuns são:

  • Desfoque (blur)
  • Brilho (brightness)
  • Contraste (contrast)
  • Escala de cinza (grayscale)
  • Rotação de matiz (hue-rotate)
  • Inversão de cores (invert)
  • Opacidade (opacity)
  • Saturação (saturate)
  • Sépia (sepia)
  • Sombra (drop-shadow)

Como funciona

O navegador renderiza normalmente o elemento e, em seguida, aplica uma ou mais funções de filtro sobre o resultado final.

Fluxo simplificado:

Elemento Original
        ↓
Renderização
        ↓
Aplicação do filter
        ↓
Elemento exibido na tela

Como o filtro é aplicado após a renderização, ele afeta todo o conteúdo do elemento, incluindo textos, imagens, bordas e sombras.

Sintaxe

filter: função(valor);

Exemplo:

img{
    filter: blur(5px);
}

Também é possível combinar várias funções:

img{
    filter: grayscale(100%) brightness(120%) contrast(110%);
}

As funções são aplicadas da esquerda para a direita.

Funções do filter

1. blur()

Aplica um desfoque ao elemento.

Sintaxe:

filter: blur(valor);

Exemplo:

filter: blur(5px);

Quanto maior o valor:

  • maior o desfoque;
  • menos nítido o elemento.

Valores comuns:

blur(2px)
blur(5px)
blur(10px)
blur(20px)

Muito utilizado para:

  • fundos desfocados;
  • efeito de vidro (glassmorphism);
  • carregamentos (loading);
  • esconder temporariamente conteúdo.

2. brightness()

Controla o brilho.

filter: brightness(150%);

ou

filter: brightness(1.5);

Valores:

0%   → completamente preto

100% → brilho original

200% → duas vezes mais brilho

Exemplo:

img:hover{
    filter: brightness(130%);
}

Muito usado em efeitos de hover.

3. contrast()

Controla o contraste.

filter: contrast(150%);

Valores:

0% → sem contraste

100% → original

200% → contraste dobrado

Quanto maior o contraste:

  • pretos ficam mais escuros;
  • brancos mais claros.

4. grayscale()

Converte a imagem para tons de cinza.

filter: grayscale(100%);

Valores:

0% → colorido

100% → preto e branco

Muito usado em galerias de imagens.

Exemplo:

img{
    filter: grayscale(100%);
}

img:hover{
    filter: grayscale(0%);
}

5. sepia()

Aplica um efeito sépia.

filter: sepia(100%);

Resultado semelhante a fotografias antigas.

6. invert()

Inverte as cores.

filter: invert(100%);

Muito usado para:

  • ícones SVG;
  • temas escuros;
  • efeitos especiais.

Exemplo:

img{
    filter: invert(1);
}

7. opacity()

Controla a transparência usando filter.

filter: opacity(50%);

Também aceita:

opacity(.5);

Diferença para a propriedade opacity:

  • opacity é uma propriedade CSS própria e costuma ser mais simples e eficiente para controlar transparência.
  • filter: opacity() faz parte da cadeia de filtros e pode ser útil quando você já está combinando outros efeitos em um único filter.

8. saturate()

Controla a intensidade das cores.

filter: saturate(200%);

Valores:

0% → sem cor

100% → original

200% → cores mais intensas

9. hue-rotate()

Rotaciona as cores no círculo cromático.

filter: hue-rotate(90deg);

Valores:

0deg

90deg

180deg

270deg

360deg

Muito usado em animações.

10. drop-shadow()

Adiciona uma sombra baseada na forma visível do elemento.

Sintaxe:

filter: drop-shadow(5px 5px 10px black);

É semelhante ao box-shadow, mas com diferenças importantes.

drop-shadow() x box-shadow

box-shadow

Baseia-se na caixa do elemento.

+------------+
|            |
|   imagem   |
|            |
+------------+

████████████

drop-shadow()

Baseia-se apenas na parte visível.

Ideal para:

  • PNG transparente;
  • SVG;
  • ícones;
  • logotipos.

Exemplo:

img{
    filter: drop-shadow(0 5px 10px rgba(0,0,0,.4));
}

Combinando filtros

Uma das maiores vantagens do filter é combinar vários efeitos.

Exemplo:

filter:
brightness(120%)
contrast(130%)
saturate(150%);

Outro exemplo:

filter:
blur(4px)
grayscale(50%)
brightness(120%);

Cada função é aplicada na ordem em que aparece.

Exemplos práticos

Blur em uma imagem

img{
    filter: blur(4px);
}

Hover com brilho

img{
    transition: .3s;
}

img:hover{
    filter: brightness(130%);
}

Galeria em preto e branco

img{
    filter: grayscale(100%);
    transition:.3s;
}

img:hover{
    filter: grayscale(0%);
}

Logo branca

img{
    filter: invert(100%);
}

Muito usada em temas escuros.

Glow

filter:
drop-shadow(0 0 20px cyan);

Ideal para interfaces cyberpunk.

Glassmorphism

backdrop-filter: blur(15px);

Embora pareça semelhante, backdrop-filter desfoca o que está atrás do elemento, enquanto filter desfoca o próprio elemento.

Casos de uso

O filter é muito utilizado em:

  • galerias de imagens;
  • banners;
  • efeitos de hover;
  • logotipos;
  • ícones;
  • SVGs;
  • botões;
  • cards;
  • interfaces futuristas;
  • dashboards;
  • temas escuros.

Boas práticas

✔ Use filtros com moderação para não comprometer a legibilidade.

✔ Prefira transições suaves:

transition: filter .3s ease;

✔ Utilize drop-shadow() para imagens transparentes.

✔ Use brightness() em vez de trocar manualmente a imagem em efeitos de hover.

✔ Combine filtros apenas quando necessário.

Erros comuns

1. Blur exagerado

filter: blur(30px);

Pode tornar o conteúdo ilegível.

2. Saturação excessiva

filter: saturate(500%);

As cores ficam artificiais.

3. Muitos filtros simultâneos

filter:
blur(5px)
brightness(150%)
contrast(200%)
sepia(100%)
grayscale(80%)
invert(100%);

Além de produzir um resultado visual confuso, muitos filtros podem aumentar o custo de renderização.

Desempenho (Performance)

Filtros são processados pelo navegador e podem exigir bastante da GPU, especialmente quando:

  • o blur() possui valores altos;
  • filtros são animados continuamente;
  • muitos elementos usam filtros ao mesmo tempo.

Em dispositivos mais simples, isso pode causar perda de desempenho. Sempre teste a interface em diferentes aparelhos.

Compatibilidade

A propriedade filter é suportada pelos principais navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Em projetos muito antigos, era comum usar o prefixo -webkit-filter, mas hoje ele raramente é necessário.

Propriedades relacionadas

  • backdrop-filter → aplica filtros ao conteúdo que está atrás do elemento.
  • box-shadow → adiciona sombras à caixa do elemento.
  • text-shadow → adiciona sombras ao texto.
  • opacity → controla a transparência do elemento.
  • transform → altera posição, rotação, escala e inclinação do elemento.
  • transition → cria animações suaves ao alterar filtros e outras propriedades.

Resumo

  • filter aplica efeitos gráficos ao resultado renderizado de um elemento.
  • É composto por funções como blur(), brightness(), contrast(), grayscale(), invert(), opacity(), saturate(), sepia(), hue-rotate() e drop-shadow().
  • É possível combinar várias funções em uma única propriedade.
  • drop-shadow() cria sombras baseadas na forma visível do elemento, sendo ideal para imagens transparentes.
  • filter é amplamente utilizado para criar efeitos visuais modernos, mas deve ser usado com equilíbrio para manter boa legibilidade e desempenho.
