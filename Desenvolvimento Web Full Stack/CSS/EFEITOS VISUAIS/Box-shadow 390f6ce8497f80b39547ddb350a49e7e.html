Box-shadow

box-shadow no CSS

Introdução

A propriedade box-shadow é utilizada para adicionar uma ou mais sombras à caixa (box) de um elemento HTML. Ela pode criar desde sombras discretas para dar sensação de profundidade até efeitos mais elaborados, como brilhos, contornos, sombras internas e elementos com aparência tridimensional.

É uma das propriedades mais utilizadas no desenvolvimento web moderno, principalmente em interfaces que seguem conceitos de Material Design, Neumorphism e outros estilos de design focados em profundidade.

Diferentemente do text-shadow, que aplica sombras aos caracteres de um texto, o box-shadow afeta toda a área do elemento, incluindo sua borda e respeitando o border-radius.

Como o navegador enxerga uma caixa

Todo elemento HTML é representado como uma caixa (CSS Box Model):

+---------------------------+
|         Margin            |
|  +---------------------+  |
|  |      Border         |  |
|  |  +---------------+  |  |
|  |  |    Padding    |  |  |
|  |  |  +---------+  |  |  |
|  |  |  | Content |  |  |  |
|  |  |  +---------+  |  |  |
|  |  +---------------+  |  |
|  +---------------------+  |
+---------------------------+

A sombra é desenhada ao redor dessa caixa.

Sintaxe

box-shadow: deslocamento-x deslocamento-y blur spread cor;

Exemplo:

div{
    box-shadow: 5px 5px 15px rgba(0,0,0,.3);
}

Estrutura completa

box-shadow:
inset
offset-x
offset-y
blur-radius
spread-radius
color;

Nem todos os valores são obrigatórios.

Componentes da propriedade

1. Offset Horizontal (offset-x)

Define o deslocamento da sombra no eixo X.

box-shadow: 10px 0 black;

Valores:

positivo → direita

negativo → esquerda

0 → sem deslocamento horizontal

Exemplo:

box-shadow: -10px 0 black;

2. Offset Vertical (offset-y)

Controla o deslocamento no eixo Y.

box-shadow: 0 10px black;

Valores:

positivo → baixo

negativo → cima

0 → sem deslocamento vertical

3. Blur Radius (Raio de Desfoque)

Controla o quão suave será a sombra.

box-shadow: 0 5px 15px black;

Quanto maior o valor:

  • mais desfocada;
  • mais natural;
  • mais espalhada visualmente.

Sem blur:

box-shadow: 5px 5px 0 black;

Com muito blur:

box-shadow: 5px 5px 40px black;

O valor não pode ser negativo.

4. Spread Radius (Raio de Expansão)

É um recurso exclusivo do box-shadow. Ele aumenta ou diminui o tamanho da sombra antes do desfoque ser aplicado.

box-shadow: 0 0 10px 5px black;

Valores positivos aumentam a sombra.

↓

████████

Valores negativos diminuem.

box-shadow: 0 0 10px -5px black;

Muito útil para controlar o "peso" da sombra sem alterar o desfoque.

5. Cor

Aceita qualquer formato de cor do CSS.

box-shadow: 0 0 10px black;
box-shadow: 0 0 10px #000;
box-shadow: 0 0 10px rgb(0,0,0);
box-shadow: 0 0 10px rgba(0,0,0,.4);
box-shadow: 0 0 10px hsl(220,50%,30%);

6. inset

Transforma a sombra externa em uma sombra interna.

Sem inset:

+---------+

██████████

Com inset:

+---------+
| ███████ |
| █     █ |
| ███████ |
+---------+

Exemplo:

box-shadow: inset 0 0 10px black;

É muito usado para:

  • campos de formulário;
  • botões pressionados;
  • efeitos de profundidade;
  • interfaces Neumorphism.

Valores obrigatórios

Apenas dois valores são obrigatórios:

box-shadow: x y;

Exemplo:

box-shadow: 5px 5px;

Nesse caso, o navegador usa a cor atual do texto (currentColor) para a sombra.

Na prática, é recomendado definir a cor explicitamente.

Múltiplas sombras

Assim como no text-shadow, é possível adicionar várias sombras separadas por vírgulas.

box-shadow:
0 2px 4px rgba(0,0,0,.2),
0 8px 20px rgba(0,0,0,.15);

Cada sombra é desenhada em sequência.

Isso permite criar efeitos mais realistas.

Exemplos práticos

Sombra simples

.card{
    box-shadow: 0 4px 10px rgba(0,0,0,.3);
}

Card moderno

.card{
    box-shadow:
    0 2px 4px rgba(0,0,0,.15),
    0 8px 20px rgba(0,0,0,.12);
}

Muito utilizado em dashboards e interfaces modernas.

Glow

.box{
    box-shadow: 0 0 20px cyan;
}

Ideal para temas futuristas e cyberpunk.

Botão elevado

button{
    box-shadow: 0 6px 15px rgba(0,0,0,.25);
}

Ao passar o mouse:

button:hover{
    box-shadow: 0 12px 25px rgba(0,0,0,.35);
}

Cria a sensação de que o botão está "subindo".

Sombra interna

input{
    box-shadow:
    inset 0 2px 6px rgba(0,0,0,.2);
}

Muito usada em formulários.

Neumorphism

box-shadow:
8px 8px 15px #bebebe,
-8px -8px 15px white;

Mistura uma sombra escura e uma clara para criar um efeito de relevo suave.

Interação com border-radius

O box-shadow respeita automaticamente o border-radius.

div{
    border-radius:20px;
    box-shadow:0 5px 15px rgba(0,0,0,.3);
}

Resultado:

╭────────────╮
│            │
╰────────────╯
   sombra

A sombra acompanha os cantos arredondados.

Casos de uso

O box-shadow é amplamente utilizado em:

  • botões;
  • cards;
  • menus;
  • janelas modais;
  • caixas de diálogo;
  • imagens;
  • avatares;
  • campos de formulário;
  • barras laterais;
  • componentes de interface.

Boas práticas

✔ Use sombras suaves para interfaces modernas.

box-shadow:0 2px 8px rgba(0,0,0,.15);

✔ Prefira rgba() ou hsla() para controlar a transparência.

✔ Combine várias sombras para um resultado mais natural.

✔ Em interfaces escuras, experimente sombras claras ou coloridas para criar destaque.

✔ Mantenha consistência: elementos do mesmo nível de importância devem ter sombras semelhantes.

Erros comuns

1. Sombras muito escuras

box-shadow:0 10px 20px black;

Pode deixar a interface pesada.

2. Blur exagerado

box-shadow:0 0 80px rgba(0,0,0,.5);

Perde definição e pode prejudicar a estética.

3. Uso excessivo

Aplicar sombras fortes em todos os elementos torna a interface poluída e reduz o destaque dos componentes realmente importantes.

Desempenho (Performance)

O box-shadow exige processamento gráfico, especialmente quando:

  • o blur-radius é muito alto;
  • há muitas sombras empilhadas;
  • existem animações envolvendo box-shadow.

Animar essa propriedade pode ser custoso, pois geralmente requer repintura (repaint) do elemento a cada quadro. Para animações mais suaves, muitas vezes é preferível animar propriedades como transform e opacity.

Diferença entre box-shadow e filter: drop-shadow()

box-shadowfilter: drop-shadow()
Baseia-se na caixa do elementoBaseia-se na forma visível do elemento
Respeita border-radiusRespeita a transparência da imagem ou do elemento renderizado
Possui spread-radius e insetNão possui spread-radius nem inset
Ideal para elementos como cards e botõesIdeal para imagens PNG, SVG e ícones com fundo transparente

Por exemplo, em um PNG com fundo transparente, box-shadow criará uma sombra ao redor da caixa inteira da imagem, enquanto drop-shadow() seguirá apenas o contorno da parte visível da imagem.

Compatibilidade

O box-shadow é totalmente suportado pelos navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Não é mais necessário utilizar prefixos como -webkit- ou -moz-.

Propriedades relacionadas

  • text-shadow → adiciona sombra ao texto.
  • border → define a borda do elemento.
  • border-radius → arredonda os cantos da caixa.
  • filter: drop-shadow() → cria sombras baseadas na forma visível do elemento.
  • outline → adiciona um contorno externo que não ocupa espaço no layout.

Resumo

  • box-shadow adiciona sombras à caixa de um elemento.
  • Sua sintaxe completa é box-shadow: inset offset-x offset-y blur-radius spread-radius color;.
  • offset-x e offset-y definem a posição da sombra.
  • blur-radius controla o desfoque.
  • spread-radius aumenta ou diminui o tamanho da sombra.
  • inset cria uma sombra interna.
  • É possível aplicar várias sombras separadas por vírgulas.
  • A propriedade respeita o border-radius e é amplamente utilizada para criar profundidade, destaque e interfaces mais modernas.
