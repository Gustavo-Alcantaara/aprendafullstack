Inset

inset no CSS

Introdução

A propriedade inset é uma propriedade abreviada (shorthand) utilizada para definir a posição de um elemento em relação ao seu elemento pai (contêiner de posicionamento).

Ela substitui as quatro propriedades:

  • top
  • right
  • bottom
  • left

Ou seja, em vez de escrever:

.caixa {
    top: 20px;
    right: 10px;
    bottom: 20px;
    left: 10px;
}

Você pode escrever:

.caixa {
    inset: 20px 10px;
}

Essa propriedade torna o código mais limpo e legível.

Quando usar?

O inset funciona apenas em elementos posicionados, ou seja, quando o elemento possui:

position: absolute;

ou

position: relative;

ou

position: fixed;

ou

position: sticky;

Se o elemento estiver com:

position: static;

(o padrão do CSS)

o inset será completamente ignorado.

Sintaxe

inset: valor;

Também aceita vários valores:

inset: top right bottom left;

Assim como acontece com margin e padding.

Como funciona

Imagine este HTML:

<div class="container">
    <div class="box"></div>
</div>
.container{
    position: relative;
    width:400px;
    height:300px;
    background:#ddd;
}

.box{
    position:absolute;
    width:100px;
    height:100px;
    background:purple;
}

Sem inset, a caixa fica na posição original.

Agora:

.box{
    position:absolute;
    inset:20px;
}

Resultado:

  • 20px do topo
  • 20px da direita
  • 20px da esquerda
  • 20px da parte inferior

A caixa será "presa" às quatro bordas do contêiner.

Um valor

inset:20px;

Equivale a:

top:20px;
right:20px;
bottom:20px;
left:20px;

Dois valores

inset:20px 40px;

Equivale a:

top:20px;
bottom:20px;

left:40px;
right:40px;

Primeiro valor → vertical

Segundo valor → horizontal

Três valores

inset:10px 20px 40px;

Equivale a:

top:10px;

left:20px;
right:20px;

bottom:40px;

Quatro valores

inset:10px 20px 30px 40px;

Ordem:

top
right
bottom
left

Igual ao margin.

Equivale a:

top:10px;
right:20px;
bottom:30px;
left:40px;

Valores aceitos

Pixels

inset:30px;

Porcentagem

inset:10%;

A porcentagem é calculada em relação ao tamanho do contêiner de posicionamento.

auto

inset:auto;

Significa que o navegador decidirá a posição, equivalente a deixar top, right, bottom e left como auto.

Também pode ser usado parcialmente:

inset:auto 20px;

calc()

Permite cálculos:

inset:calc(50% - 100px);

Muito usado para centralizações e layouts dinâmicos.

Exemplos práticos

Centralizar usando inset

.box{
    position:absolute;

    inset:0;

    margin:auto;

    width:150px;
    height:150px;
}

O elemento ficará centralizado no pai.

Preencher todo o elemento pai

.box{
    position:absolute;
    inset:0;
}

É equivalente a:

top:0;
right:0;
bottom:0;
left:0;

Muito usado para:

  • overlays
  • fundos
  • máscaras
  • efeitos de blur
  • gradientes
  • imagens cobrindo o pai

Overlay

.overlay{
    position:absolute;
    inset:0;

    background:rgba(0,0,0,.5);
}

Resultado:

A camada cobre exatamente todo o elemento pai.

Espaçamento interno do overlay

.overlay{
    position:absolute;
    inset:20px;
}

Agora a camada ficará afastada 20px de todas as bordas.

Valores negativos

Também são aceitos.

.box{
    inset:-20px;
}

Resultado:

A caixa cresce para fora do elemento pai, ficando 20px além de cada borda.

Isso é útil para criar sombras, bordas decorativas ou elementos que "escapam" do contêiner.

Propriedades relacionadas

Além de inset, existem abreviações direcionais:

  • inset-block
  • inset-inline
  • inset-block-start
  • inset-block-end
  • inset-inline-start
  • inset-inline-end

Essas utilizam o fluxo lógico da escrita (horizontal ou vertical) e são úteis para layouts internacionais, pois se adaptam a idiomas escritos da direita para a esquerda.

Boas práticas

  • Use inset quando precisar definir várias direções ao mesmo tempo, deixando o código mais enxuto.
  • Prefira inset: 0 para fazer um elemento ocupar toda a área do pai.
  • Lembre-se de definir um position diferente de static, caso contrário inset não terá efeito.
  • Em projetos que precisam suportar diferentes direções de escrita, considere as propriedades lógicas (inset-block e inset-inline).

Erros comuns

Esquecer o position

.box{
    inset:20px;
}

Não funcionará se:

position:static;

Não posicionar o elemento pai

.container{
    position:relative;
}

Sem isso, um elemento com position: absolute será posicionado em relação ao ancestral posicionado mais próximo (ou à janela, se não houver um).

Misturar inset com top, right, bottom e left

Evite fazer:

.box{
    inset:20px;
    left:50px;
}

Nesse caso, left: 50px sobrescreve apenas o valor de left definido por inset, o que pode dificultar a leitura do código.

Compatibilidade

A propriedade inset é suportada pelos principais navegadores modernos, como Chrome, Firefox, Edge e Safari. Para aplicações atuais, ela é considerada segura de usar.

Resumo

  • inset é a forma abreviada de top, right, bottom e left.
  • Funciona apenas em elementos posicionados (absolute, relative, fixed ou sticky).
  • Aceita de 1 a 4 valores, seguindo a mesma lógica de margin e padding.
  • É muito útil para overlays, preenchimento de contêineres, centralização e posicionamento preciso.
  • Torna o CSS mais limpo, reduzindo a necessidade de declarar quatro propriedades separadas.
