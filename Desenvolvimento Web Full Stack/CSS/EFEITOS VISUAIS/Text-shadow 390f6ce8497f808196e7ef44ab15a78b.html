Text-shadow

text-shadow no CSS

Introdução

A propriedade text-shadow é utilizada para adicionar uma ou mais sombras ao texto de um elemento HTML. Ela é um recurso visual muito usado para melhorar a legibilidade, criar efeitos de profundidade, destacar títulos e produzir estilos como brilho (glow), neon e textos em relevo.

Ao contrário da propriedade box-shadow, que cria sombras ao redor de um elemento inteiro (como uma <div> ou um botão), text-shadow aplica a sombra diretamente aos caracteres do texto.

Sintaxe

text-shadow: deslocamento-horizontal deslocamento-vertical desfoque cor;

Exemplo:

h1 {
    text-shadow: 2px 2px 5px black;
}

Nesse caso:

  • 2px → deslocamento horizontal
  • 2px → deslocamento vertical
  • 5px → raio de desfoque
  • black → cor da sombra

Como funciona

Sempre que o navegador desenha um texto, ele também pode desenhar uma sombra baseada em quatro informações principais:

text-shadow:
horizontal
vertical
blur
color;

Quanto maior o deslocamento, mais distante a sombra ficará do texto.

Componentes da propriedade

1. Deslocamento horizontal (Horizontal Offset)

Define quanto a sombra será movida para a esquerda ou direita.

text-shadow: 5px 0 black;

Resultado:

Texto█████

Valores:

positivo → direita

negativo → esquerda

zero → sem deslocamento horizontal

Exemplos:

text-shadow: 10px 0 black;

text-shadow: -10px 0 black;

text-shadow: 0 0 black;

2. Deslocamento vertical (Vertical Offset)

Define quanto a sombra será deslocada para cima ou para baixo.

text-shadow: 0 5px black;

Valores:

positivo → baixo

negativo → cima

0 → sem deslocamento vertical

Exemplo:

text-shadow: 0 -4px black;

3. Blur Radius (Raio de Desfoque)

Controla o quanto a sombra ficará borrada.

Quanto maior o valor:

  • mais suave
  • mais espalhada
  • menos definida

Exemplo:

text-shadow: 2px 2px 15px black;

Sem blur:

text-shadow: 2px 2px 0 black;

Com muito blur:

text-shadow: 2px 2px 25px black;

4. Cor

Pode ser definida usando qualquer formato aceito pelo CSS.

Exemplos:

text-shadow: 2px 2px 5px red;
text-shadow: 2px 2px 5px #000;
text-shadow: 2px 2px 5px rgb(0,0,0);
text-shadow: 2px 2px 5px rgba(0,0,0,.5);
text-shadow: 2px 2px 5px hsl(240,100%,50%);

Valores possíveis

A sintaxe completa é:

text-shadow: x y blur color;

O blur é opcional.

Exemplo:

text-shadow: 2px 2px red;

Também é possível inverter a ordem da cor:

text-shadow: red 2px 2px 5px;

O navegador reconhece a cor independentemente da posição, desde que a sintaxe permaneça válida.

Múltiplas sombras

Uma das características mais poderosas do text-shadow é permitir várias sombras ao mesmo tempo.

Basta separá-las por vírgulas.

Exemplo:

text-shadow:
2px 2px 5px black,
-2px -2px 5px red;

Cada sombra é desenhada individualmente.

Exemplos práticos

Sombra simples

h1{
    text-shadow: 2px 2px 5px black;
}

Sombra suave

h1{
    text-shadow: 1px 1px 8px rgba(0,0,0,.3);
}

Muito usada em sites modernos.

Efeito Glow

h1{
    color: white;
    text-shadow: 0 0 10px cyan;
}

Resultado:

Texto brilhando

Neon

text-shadow:
0 0 5px #fff,
0 0 10px #fff,
0 0 20px cyan,
0 0 40px cyan,
0 0 80px cyan;

Cria um efeito de letreiro neon.

Texto em relevo

text-shadow:
1px 1px white,
2px 2px gray;

Simula profundidade.

Contorno (outline)

O text-shadow pode simular um contorno aplicando sombras em várias direções.

text-shadow:
1px 0 black,
-1px 0 black,
0 1px black,
0 -1px black;

Também é possível adicionar as diagonais:

text-shadow:
1px 1px black,
-1px -1px black,
1px -1px black,
-1px 1px black;

Casos de uso

O text-shadow é muito utilizado para:

  • títulos de páginas;
  • banners;
  • landing pages;
  • textos sobre imagens;
  • botões;
  • logotipos;
  • efeitos neon;
  • jogos;
  • interfaces futuristas;
  • destaque de chamadas importantes.

Boas práticas

✔ Utilize sombras suaves para melhorar a legibilidade.

text-shadow: 0 1px 3px rgba(0,0,0,.4);

✔ Em fundos claros, prefira sombras escuras.

✔ Em fundos escuros, utilize sombras claras ou coloridas.

✔ Evite exagerar no desfoque, pois pode dificultar a leitura.

Erros comuns

1. Muito blur

text-shadow: 0 0 40px black;

Pode deixar o texto ilegível.

2. Muito deslocamento

text-shadow: 20px 20px black;

A sombra fica distante e perde o efeito natural.

3. Muitas sombras

text-shadow:
0 0 5px red,
0 0 10px blue,
0 0 20px green,
0 0 30px yellow,
0 0 50px pink;

Além de poluir visualmente, muitas sombras podem afetar o desempenho em páginas com grande quantidade de texto.

Diferença entre text-shadow e box-shadow

text-shadowbox-shadow
Aplica sombra ao textoAplica sombra ao elemento
Afeta apenas os caracteresAfeta toda a caixa do elemento
Ideal para títulos e parágrafosIdeal para botões, cards, imagens e containers

Compatibilidade

A propriedade text-shadow é amplamente suportada pelos navegadores modernos, incluindo:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Não é necessário utilizar prefixos como -webkit- ou -moz-.

Propriedades relacionadas

  • box-shadow → cria sombras em elementos.
  • color → define a cor do texto.
  • opacity → controla a transparência do elemento.
  • filter: drop-shadow() → aplica sombra a imagens e elementos renderizados, funcionando de maneira diferente do text-shadow.

Resumo

  • text-shadow adiciona sombras ao texto.
  • Sua sintaxe básica é text-shadow: x y blur color;.
  • É possível usar deslocamentos positivos e negativos.
  • O blur é opcional e controla o desfoque da sombra.
  • A propriedade aceita qualquer formato de cor válido em CSS.
  • É possível aplicar múltiplas sombras separadas por vírgulas, permitindo criar efeitos como brilho, neon, relevo e contornos.
  • É um recurso amplamente suportado pelos navegadores e muito utilizado para melhorar a estética e a legibilidade do texto quando aplicado com moderação.
