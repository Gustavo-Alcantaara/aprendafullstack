Opacity

opacity no CSS

Introdução

A propriedade opacity controla o nível de transparência de um elemento inteiro. Com ela, é possível tornar um elemento totalmente visível, parcialmente transparente ou completamente invisível, sem removê-lo do documento.

É uma propriedade muito utilizada para criar efeitos de:

  • fade in e fade out;
  • hover em botões e imagens;
  • elementos desabilitados;
  • sobreposições (overlays);
  • animações suaves;
  • interfaces modernas.

Diferentemente de alterar a transparência apenas da cor de fundo com rgba() ou hsla(), a opacity afeta todo o elemento, incluindo:

  • texto;
  • imagens;
  • bordas;
  • sombras;
  • ícones;
  • elementos filhos.

Como funciona

Quando um elemento é renderizado, o navegador desenha todos os seus componentes normalmente e, ao final, aplica um nível de transparência ao resultado completo.

Fluxo:

Elemento
     ↓
Renderização
     ↓
Aplicação da opacidade
     ↓
Resultado final

Isso significa que tudo dentro do elemento terá a mesma transparência.

Sintaxe

opacity: valor;

Exemplo:

.card{
    opacity: 0.5;
}

Valores possíveis

A propriedade aceita valores numéricos entre 0 e 1.

ValorResultado
0Totalmente transparente
0.2525% visível
0.550% visível
0.7575% visível
1Totalmente visível (padrão)

Exemplo:

opacity: 1;
opacity: .8;
opacity: .5;
opacity: .2;
opacity: 0;

Também é permitido escrever:

opacity: 0.65;

Valor padrão

opacity: 1;

Ou seja, o elemento é exibido normalmente.

Exemplos práticos

Elemento semitransparente

.card{
    opacity: .5;
}

Resultado:

O card inteiro ficará com 50% de transparência.

Efeito Hover

button{

    opacity:.7;

}

button:hover{

    opacity:1;

}

Muito utilizado para destacar botões quando o usuário passa o mouse.

Imagem transparente

img{

    opacity:.6;

}

Fade simples

.box{

    transition:opacity .3s;

}

.box:hover{

    opacity:.3;

}

O elemento desaparece suavemente.

opacity afeta todo o elemento

Este é um dos pontos mais importantes.

Considere:

<div class="card">
    <h2>Título</h2>
    <p>Texto</p>
</div>
.card{

    opacity:.5;

}

Resultado:

  • fundo transparente;
  • texto transparente;
  • borda transparente;
  • imagens transparentes.

Tudo recebe a mesma opacidade.

Como deixar apenas o fundo transparente?

Muitas pessoas tentam fazer isto:

.card{

    background:white;

    opacity:.5;

}

Mas isso também deixa o texto transparente.

O correto é usar uma cor com canal alfa:

.card{

    background:rgba(255,255,255,.5);

}

ou

background:rgb(255 255 255 / 50%);

Assim:

  • apenas o fundo fica transparente;
  • o texto continua totalmente visível.

opacity x visibility

Muita gente confunde essas propriedades.

opacity

opacity:0;

Resultado:

  • elemento invisível;
  • continua ocupando espaço;
  • ainda pode receber foco e eventos do mouse (a menos que você desabilite isso com outras propriedades).

visibility

visibility:hidden;

Resultado:

  • elemento invisível;
  • continua ocupando espaço;
  • não é exibido visualmente.

display:none

display:none;

Resultado:

  • elemento desaparece;
  • não ocupa espaço;
  • sai do fluxo do layout.

Comparação

PropriedadeVisívelOcupa espaçoRecebe eventos*
opacity:0NãoSimSim
visibility:hiddenNãoSimNão
display:noneNãoNãoNão
  • O comportamento em relação aos eventos pode ser ajustado com pointer-events.

Transições

Uma das propriedades mais utilizadas com opacity é transition.

.card{

    opacity:.5;

    transition:opacity .4s ease;

}

.card:hover{

    opacity:1;

}

Cria um efeito de fade muito suave.

Animações

Também pode ser usada com @keyframes.

@keyframes aparecer{

    from{

        opacity:0;

    }

    to{

        opacity:1;

    }

}

Aplicação:

.card{

    animation:aparecer .5s;

}

Casos de uso

A propriedade opacity é amplamente utilizada em:

  • efeitos de hover;
  • transições de entrada e saída;
  • modais;
  • menus;
  • overlays;
  • carregamentos (loading);
  • galerias de imagens;
  • botões desabilitados;
  • banners;
  • animações.

Boas práticas

✔ Use transition para tornar mudanças de opacidade mais suaves.

✔ Quando quiser transparência apenas no fundo, prefira rgba(), hsla() ou rgb() com canal alfa.

✔ Combine opacity com transform para criar animações elegantes de entrada e saída.

✔ Se um elemento invisível não deve ser clicável, utilize também:

pointer-events: none;

Erros comuns

1. Deixar o texto transparente sem querer

.card{

    opacity:.5;

}

Se a intenção era apenas clarear o fundo, use uma cor com transparência em vez de opacity.

2. Esquecer que o elemento continua clicável

opacity:0;

Mesmo invisível, ele ainda pode responder a cliques.

Se necessário:

pointer-events:none;

3. Usar opacity para esconder completamente um elemento

Se o objetivo é removê-lo do layout, display: none costuma ser a escolha mais adequada.

Desempenho (Performance)

A propriedade opacity é considerada uma das mais eficientes para animações. Em navegadores modernos, ela frequentemente pode ser acelerada por hardware (GPU), especialmente quando combinada com transform.

Por isso, é uma excelente escolha para criar efeitos de fade sem comprometer o desempenho.

Compatibilidade

A propriedade opacity é suportada por todos os navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Não requer prefixos.

Propriedades relacionadas

  • visibility → oculta o elemento mantendo seu espaço.
  • display → remove o elemento do layout.
  • background → pode usar transparência com rgba(), hsla() ou rgb() com canal alfa.
  • filter: opacity() → aplica opacidade como parte da cadeia de filtros.
  • transition → anima mudanças de opacidade.
  • animation → cria animações mais complexas usando opacity.
  • pointer-events → controla se um elemento pode receber eventos do mouse.

Resumo

  • opacity controla a transparência de todo o elemento.
  • Aceita valores entre 0 (invisível) e 1 (totalmente visível).
  • Afeta o elemento inteiro, incluindo texto, imagens, bordas e elementos filhos.
  • Para deixar apenas o fundo transparente, prefira usar cores com canal alfa (rgba(), hsla() ou rgb() com transparência).
  • É uma das propriedades mais utilizadas em animações e efeitos de fade devido ao seu bom desempenho e ampla compatibilidade com os navegadores modernos.
