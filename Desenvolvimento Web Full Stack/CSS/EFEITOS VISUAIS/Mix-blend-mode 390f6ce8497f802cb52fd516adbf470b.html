Mix-blend-mode

mix-blend-mode no CSS

Introdução

A propriedade mix-blend-mode controla como um elemento é mesclado visualmente com os elementos que estão atrás dele.

Em vez de apenas desenhar um elemento sobre outro, o navegador combina as cores dos dois utilizando diferentes algoritmos de mistura (blend modes), semelhantes aos encontrados em programas como:

  • Adobe Photoshop
  • Adobe Illustrator
  • Figma
  • GIMP
  • Canva

Com isso, é possível criar efeitos visuais avançados, como:

  • textos que mudam de cor conforme o fundo;
  • efeitos de luz;
  • sobreposição de imagens;
  • efeitos neon;
  • composições artísticas;
  • animações criativas.

Como funciona

Imagine dois elementos:

██████████████
█  Fundo     █
██████████████

██████████████
█ Elemento   █
██████████████

Normalmente, o navegador apenas desenha o elemento sobre o fundo.

Com mix-blend-mode, o navegador compara a cor de cada pixel do elemento com a cor do pixel que está atrás dele e gera uma nova cor.

Fluxo:

Cor do Fundo
       +
Cor do Elemento
       ↓
Algoritmo de Blend
       ↓
Cor Final

Cada modo utiliza um algoritmo diferente.

Sintaxe

mix-blend-mode: valor;

Exemplo:

img{
    mix-blend-mode: multiply;
}

Diferença entre mix-blend-mode e background-blend-mode

Essa é uma dúvida muito comum.

mix-blend-mode

Mistura um elemento inteiro com o que está atrás dele.

Imagem

↓

Mistura com o fundo

background-blend-mode

Mistura apenas as camadas de fundo (background) do próprio elemento.

background:
url(img.png),
linear-gradient(red, blue);

background-blend-mode: multiply;

O restante do elemento não é afetado.

Valor padrão

mix-blend-mode: normal;

Não há mistura.

O elemento é desenhado normalmente.

Principais modos

Existem diversos modos de mistura.

multiply

mix-blend-mode: multiply;

Multiplica as cores.

Resultado:

  • sempre escurece;
  • branco praticamente desaparece;
  • preto permanece preto.

Muito usado para:

  • sombras;
  • texturas;
  • envelhecimento de imagens.

screen

mix-blend-mode: screen;

É o oposto do multiply.

Resultado:

  • clareia a imagem;
  • preto praticamente desaparece;
  • branco permanece branco.

Muito utilizado para:

  • brilhos;
  • partículas;
  • luzes;
  • fogo.

overlay

mix-blend-mode: overlay;

Combina:

  • multiply
  • screen

Dependendo das cores.

Resultado:

  • aumenta o contraste;
  • deixa as cores mais vibrantes.

Muito usado em fotografias.

darken

mix-blend-mode: darken;

Mantém apenas a cor mais escura.

Exemplo:

Fundo = azul

Elemento = vermelho

↓

Cor mais escura vence

lighten

mix-blend-mode: lighten;

Mantém apenas a cor mais clara.

É o inverso de darken.

color-dodge

mix-blend-mode: color-dodge;

Aumenta bastante o brilho.

Muito utilizado em:

  • efeitos neon;
  • explosões;
  • magia;
  • interfaces futuristas.

color-burn

mix-blend-mode: color-burn;

Escurece bastante as cores.

Cria um efeito dramático.

difference

mix-blend-mode: difference;

Calcula a diferença entre as cores.

Um efeito muito conhecido é:

Texto branco sobre fundo branco:

↓

fica preto.

Texto branco sobre fundo preto:

↓

fica branco.

Isso faz com que o texto sempre tenha contraste.

exclusion

Semelhante ao difference, porém com contraste mais suave.

hard-light

Mistura luz intensa.

Muito usado em fotografias.

soft-light

Mistura luz suave.

Resultado mais natural.

color

Mantém:

  • matiz;
  • saturação.

Mas utiliza a luminosidade do fundo.

luminosity

Faz o contrário.

Mantém:

  • luminosidade.

Mas usa as cores do fundo.

hue

Mistura apenas a matiz.

saturation

Mistura apenas a saturação.

Exemplos práticos

Texto que muda conforme o fundo

h1{

    color:white;

    mix-blend-mode:difference;

}

Muito usado em sites modernos.

Logo integrada ao fundo

.logo{

    mix-blend-mode:multiply;

}

A logo parece "impressa" na imagem.

Luz Neon

.glow{

    mix-blend-mode:screen;

}

Muito usada em interfaces Cyberpunk.

Fotografia

img{

    mix-blend-mode:overlay;

}

Melhora o contraste.

Textura

.texture{

    mix-blend-mode:multiply;

}

Muito utilizada em posters.

Casos de uso

O mix-blend-mode aparece frequentemente em:

  • landing pages;
  • sites criativos;
  • portfólios;
  • interfaces futuristas;
  • temas cyberpunk;
  • galerias de imagens;
  • efeitos de iluminação;
  • logos;
  • banners;
  • animações.

Importante: contexto de empilhamento (Stacking Context)

O mix-blend-mode depende do conteúdo que está atrás do elemento.

Exemplo:

<div class="background"></div>

<h1>Título</h1>
h1{

    mix-blend-mode:difference;

}

Se não existir nenhum conteúdo visível atrás do <h1>, o efeito pode não ser percebido.

Além disso, propriedades como position, z-index, opacity, transform e isolation podem criar novos contextos de empilhamento e alterar o comportamento da mistura.

A propriedade isolation

Em alguns casos, o efeito acaba misturando com toda a página.

Para limitar a mistura apenas ao elemento pai, utiliza-se:

.container{

    isolation:isolate;

}

Isso cria um novo contexto de mistura.

É muito útil quando há vários elementos usando mix-blend-mode.

Desempenho (Performance)

Como o navegador precisa calcular a cor final de cada pixel comparando o elemento com o conteúdo atrás dele, mix-blend-mode pode exigir bastante processamento, especialmente quando:

  • há muitos elementos usando a propriedade;
  • ela é combinada com filter ou backdrop-filter;
  • existem animações contínuas;
  • o elemento ocupa uma grande área da tela.

Por isso, é recomendável utilizá-la com moderação e testar o desempenho em dispositivos menos potentes.

Compatibilidade

O mix-blend-mode é suportado pelos principais navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Em navegadores atuais, não é necessário utilizar prefixos.

Propriedades relacionadas

  • background-blend-mode → mistura apenas as camadas de fundo do elemento.
  • filter → aplica efeitos ao próprio elemento.
  • backdrop-filter → aplica efeitos ao conteúdo atrás do elemento.
  • opacity → controla a transparência.
  • isolation → define o contexto de mistura para mix-blend-mode.

Boas práticas

✔ Utilize mix-blend-mode apenas quando houver um efeito visual claro e intencional.

✔ Teste o resultado sobre diferentes fundos, pois o efeito depende diretamente das cores que estão atrás do elemento.

✔ Use isolation: isolate quando quiser limitar a mistura ao contêiner pai.

✔ Evite combinar muitos efeitos (mix-blend-mode, filter, backdrop-filter) no mesmo elemento para não comprometer o desempenho.

Erros comuns

1. Esperar um efeito sem conteúdo ao fundo

h1{
    mix-blend-mode: screen;
}

Se atrás do título houver apenas uma cor uniforme ou nenhum elemento visível, o resultado pode parecer igual ao modo normal.

2. Esquecer do isolation

Sem um contexto de isolamento, o elemento pode se misturar com toda a página, produzindo resultados inesperados.

.container{
    isolation: isolate;
}

3. Escolher um modo inadequado

Nem todo modo funciona bem com qualquer combinação de cores. Por exemplo, screen produz pouco efeito sobre fundos claros, enquanto multiply quase não altera fundos escuros.

Resumo

  • mix-blend-mode define como um elemento é mesclado com o conteúdo que está atrás dele.
  • Diferentemente de background-blend-mode, ele afeta todo o elemento, e não apenas seu fundo.
  • Possui diversos modos de mistura, como multiply, screen, overlay, difference, darken, lighten, soft-light e hard-light.
  • É muito utilizado em efeitos criativos, como textos adaptáveis, logos integradas ao fundo, composições de imagens e interfaces futuristas.
  • Para controlar melhor o efeito, é comum utilizar isolation: isolate.
  • Embora seja um recurso poderoso, seu uso excessivo pode aumentar o custo de renderização, por isso deve ser aplicado com critério.
