Transition

transition no CSS

Introdução

A propriedade transition permite criar animações suaves entre dois estados de um elemento. Em vez de uma mudança acontecer instantaneamente, o navegador realiza uma transição gradual durante um determinado tempo.

Ela é amplamente utilizada para melhorar a experiência do usuário (UX), tornando interfaces mais fluidas e agradáveis.

Alguns exemplos de uso:

  • botões que mudam de cor ao passar o mouse;
  • cards que aumentam de tamanho;
  • menus que aparecem suavemente;
  • imagens que aplicam filtros;
  • efeitos de foco (:focus) em campos de formulário;
  • animações de entrada e saída.

A transition não cria animações sozinha. Ela apenas anima uma mudança de valor quando uma propriedade CSS é alterada.

Como funciona

Imagine um botão:

O navegador calcula automaticamente todos os valores intermediários entre o estado inicial e o final.

Sintaxe

A sintaxe simplificada é:

transition: propriedade duração;

Exemplo:

button{

    transition: background-color .3s;

}

Sintaxe completa

transition:

property

duration

timing-function

delay;

Exemplo:

transition:

background-color

.5s

ease

.2s;

Componentes da transition

1. transition-property

Define qual propriedade será animada.

transition-property: background-color;

Exemplo:

button{

    transition-property:background-color;

}

Também pode ser:

transition-property:transform;

ou

transition-property:opacity;

all

Também é possível animar todas as propriedades compatíveis.

transition-property:all;

Ou simplesmente:

transition:all .3s;

Embora seja prático, nem sempre é a melhor opção para desempenho, pois qualquer propriedade alterada poderá ser animada.

2. transition-duration

Define quanto tempo a transição levará.

Sintaxe:

transition-duration:.5s;

Pode ser escrita em:

Segundos

1s

Milissegundos

300ms

Exemplos:

transition-duration:200ms;
transition-duration:1.5s;

Quanto maior o tempo, mais lenta será a animação.

3. transition-timing-function

Controla a velocidade da animação durante sua execução.

Não altera a duração total, apenas a forma como ela acelera ou desacelera.

ease

Padrão do CSS.

transition-timing-function:ease;

4. transition-delay

Define quanto tempo o navegador espera antes de iniciar a animação.

transition-delay:1s;

Exemplo:

button{

transition:

background-color

.5s

ease

1s;

}

O botão aguardará 1 segundo antes de começar a mudar de cor.

Animando várias propriedades

É possível animar várias propriedades ao mesmo tempo.

transition:

background-color .3s,

transform .5s,

box-shadow .4s;

Cada propriedade pode ter sua própria duração e curva de velocidade.

Exemplos práticos

Botão

button{

background:blue;

transition:background .3s;

}

button:hover{

background:red;

}

Escala

.card{

transition:

transform .3s;

}

.card:hover{

transform:scale(1.1);

}

Opacidade

img{

transition:

opacity .4s;

}

img:hover{

opacity:.5;

}

Sombra

.card{

transition:

box-shadow .4s;

}

.card:hover{

box-shadow:

0 15px 40px rgba(0,0,0,.3);

}

Múltiplas propriedades

.card{

transition:

transform .3s,

box-shadow .3s,

background .5s;

}

.card:hover{

transform:translateY(-10px);

box-shadow:

0 15px 40px rgba(0,0,0,.2);

background:#f5f5f5;

}

Quais propriedades podem ser animadas?

A maioria das propriedades numéricas pode ser animada.

Exemplos:

✔ opacity

✔ transform

✔ background-color

✔ color

✔ width

✔ height

✔ margin

✔ padding

✔ border-radius

✔ box-shadow

✔ filter

✔ letter-spacing

✔ font-size

Propriedades que não podem ser animadas

Algumas propriedades mudam de forma instantânea.

Exemplos:

display
position
background-image
float

O navegador não consegue interpolar esses valores.

transition x animation

Essa é uma diferença muito importante.

transition

  • depende de uma mudança de estado;
  • normalmente é acionada por :hover, :focus, JavaScript ou alteração de classes;
  • executa apenas quando o valor muda.

Exemplo:

button:hover{

background:red;

}

animation

  • pode iniciar automaticamente;
  • utiliza @keyframes;
  • pode repetir infinitamente;
  • permite várias etapas na animação.

Exemplo:

animation:

pulse

2s

infinite;

Casos de uso

A transition é muito utilizada em:

  • botões;
  • menus;
  • cards;
  • links;
  • formulários;
  • galerias;
  • barras laterais;
  • pop-ups;
  • modais;
  • dashboards.

Boas práticas

✔ Prefira animar transform e opacity, pois oferecem melhor desempenho.

✔ Use durações entre 200 ms e 500 ms para a maioria das interações.

✔ Escolha uma timing-function adequada ao efeito desejado; ease e ease-in-out costumam produzir resultados naturais.

✔ Evite usar transition: all quando apenas algumas propriedades precisam ser animadas.

Erros comuns

1. Colocar a transition apenas no :hover

Errado:

button:hover{

transition:.3s;

}

Ao retirar o mouse, a mudança ocorrerá instantaneamente.

O correto:

button{

transition:.3s;

}

button:hover{

background:red;

}

2. Animar propriedades pesadas

transition:

width 1s;

Em alguns casos, alterar width e height pode causar recálculos de layout. Quando possível, prefira:

transform:scale();

3. Usar transition: all

transition:all .5s;

Embora funcione, pode animar propriedades desnecessárias e impactar o desempenho.

Desempenho (Performance)

As propriedades mais eficientes para animações são:

  • transform
  • opacity

Elas geralmente podem ser aceleradas pela GPU, proporcionando animações mais suaves.

Já propriedades como width, height, top, left e margin podem exigir recálculos de layout e repinturas, tornando a animação menos eficiente.

Compatibilidade

A propriedade transition é totalmente suportada pelos navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Não é necessário utilizar prefixos.

Propriedades relacionadas

  • transition-property → define quais propriedades serão animadas.
  • transition-duration → define a duração da transição.
  • transition-timing-function → controla a curva de velocidade.
  • transition-delay → define o atraso antes do início.
  • animation → cria animações mais complexas com @keyframes.
  • transform → muito utilizada em conjunto com transition.
  • opacity → uma das propriedades mais comuns para criar efeitos de fade.

Resumo

  • transition cria mudanças suaves entre dois estados de um elemento.
  • Ela é composta por transition-property, transition-duration, transition-timing-function e transition-delay.
  • Funciona apenas quando uma propriedade CSS muda de valor.
  • É ideal para efeitos de hover, foco, abertura de menus e outras interações.
  • Para obter melhor desempenho, prefira animar transform e opacity em vez de propriedades que alteram o layout, como width e height.
