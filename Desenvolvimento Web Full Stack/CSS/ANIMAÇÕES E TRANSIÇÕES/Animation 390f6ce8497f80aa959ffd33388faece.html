Animation

animation no CSS

Introdução

A propriedade animation é utilizada para criar animações complexas em CSS, permitindo que um elemento passe por uma sequência de estados definidos pelo desenvolvedor.

Diferentemente da transition, que apenas anima a mudança entre dois estados (inicial e final), a animation pode conter várias etapas, repetir indefinidamente, iniciar automaticamente, alternar direções e controlar diversos aspectos da execução.

Ela é amplamente utilizada para criar:

  • loaders;
  • elementos pulsando;
  • menus animados;
  • banners;
  • efeitos de entrada e saída;
  • animações infinitas;
  • personagens;
  • efeitos neon;
  • interfaces interativas.

Como funciona

Uma animação CSS é composta por duas partes:

  1. @keyframes
    • Define o que acontecerá durante a animação.
  1. animation
    • Diz como essa animação será executada.

Fluxo:

@keyframes
        ↓
Define os movimentos
        ↓
animation
        ↓
Executa a animação

O que são @keyframes?

Os Keyframes ("quadros-chave") definem os estados da animação ao longo do tempo.

Sintaxe:

@keyframes nome{

}

Exemplo:

@keyframes aparecer{

    from{

        opacity:0;

    }

    to{

        opacity:1;

    }

}

Essa animação faz o elemento aparecer suavemente.

from e to

São equivalentes a:

0%

↓

100%

Portanto:

from{

}

é igual a:

0%{

}

E:

to{

}

é igual a:

100%{

}

Usando porcentagens

Podemos criar várias etapas.

@keyframes mover{

    0%{

        transform:translateX(0);

    }

    50%{

        transform:translateX(200px);

    }

    100%{

        transform:translateX(0);

    }

}

Resultado:

Início

↓

Vai para direita

↓

Volta

Aplicando a animação

Depois de criar os @keyframes:

.box{

    animation:mover 2s;

}

Sintaxe completa

animation:

name

duration

timing-function

delay

iteration-count

direction

fill-mode

play-state;

Nem todos são obrigatórios.

Componentes da animação

1. animation-name

Define qual animação será utilizada.

animation-name:mover;

2. animation-duration

Define quanto tempo dura uma execução.

animation-duration:2s;

ou

animation-duration:500ms;

Sem duração:

animation-duration:0s;

Nada será animado.

3. animation-timing-function

Controla a velocidade.

Valores:

ease
linear
ease-in
ease-out
ease-in-out
cubic-bezier(...)

Funciona exatamente como na transition.

4. animation-delay

Tempo antes de iniciar.

animation-delay:2s;

5. animation-iteration-count

Quantidade de repetições.

Uma vez:

animation-iteration-count:1;

Cinco vezes:

animation-iteration-count:5;

Infinitamente:

animation-iteration-count:infinite;

Muito utilizado em loaders.

6. animation-direction

Controla a direção.

normal

Padrão.

→

reverse

Executa ao contrário.

←

alternate

Vai e volta.

→ ← → ←

alternate-reverse

Começa voltando.

← → ← →

7. animation-fill-mode

Controla como o elemento fica antes e depois da animação.

none

Padrão.

forwards

Mantém o estado final.

animation-fill-mode:forwards;

Muito usado em animações de entrada.

backwards

Aplica imediatamente o primeiro quadro durante o delay.

both

Combina forwards e backwards.

8. animation-play-state

Controla a execução.

Executando:

animation-play-state:running;

Pausada:

animation-play-state:paused;

Exemplo:

.box:hover{

    animation-play-state:paused;

}

Múltiplas animações

É possível executar várias animações simultaneamente.

animation:

mover 2s linear,

piscar 1s infinite;

Exemplos práticos

Fade In

@keyframes aparecer{

    from{

        opacity:0;

    }

    to{

        opacity:1;

    }

}

.card{

    animation:aparecer .5s;

}

Movimento

@keyframes mover{

    from{

        transform:translateX(0);

    }

    to{

        transform:translateX(300px);

    }

}

Rotação

@keyframes girar{

    from{

        transform:rotate(0deg);

    }

    to{

        transform:rotate(360deg);

    }

}

.logo{

    animation:girar 2s linear infinite;

}

Pulsar

@keyframes pulse{

0%{

transform:scale(1);

}

50%{

transform:scale(1.1);

}

100%{

transform:scale(1);

}

}

Aplicação:

button{

animation:

pulse

1s

infinite;

}

Loader

.loader{

animation:

girar

1s

linear

infinite;

}

Muito utilizado em indicadores de carregamento.

Bounce

@keyframes bounce{

0%{

transform:translateY(0);

}

50%{

transform:translateY(-30px);

}

100%{

transform:translateY(0);

}

}

Casos de uso

A propriedade animation é muito utilizada em:

  • loaders;
  • logotipos girando;
  • banners;
  • efeitos de entrada;
  • efeitos de saída;
  • menus;
  • cards;
  • botões;
  • dashboards;
  • jogos;
  • interfaces futuristas.

Boas práticas

✔ Prefira animar transform e opacity, pois oferecem melhor desempenho.

✔ Utilize linear para rotações contínuas, como loaders.

✔ Evite animações muito rápidas ou excessivamente longas, pois podem prejudicar a experiência do usuário.

✔ Considere usuários com sensibilidade a movimento. É uma boa prática desativar ou reduzir animações quando o sistema indicar a preferência por movimento reduzido (prefers-reduced-motion).

Erros comuns

1. Esquecer de definir animation-duration

animation:mover;

Sem duração, a animação não será visível.

2. Não criar os @keyframes

animation:mover 2s;

Se a animação mover não existir, nada acontecerá.

3. Animar propriedades que afetam o layout

width

height

margin

left

top

Essas propriedades podem causar recálculos de layout. Sempre que possível, prefira:

transform

opacity

4. Exagerar em animações infinitas

Muitas animações contínuas podem distrair o usuário e aumentar o consumo de recursos.

Desempenho (Performance)

As animações mais eficientes utilizam:

  • transform
  • opacity

Essas propriedades geralmente são aceleradas por hardware (GPU), proporcionando movimentos mais suaves.

Já animar propriedades como width, height, margin, top e left pode causar recálculos de layout e repinturas, impactando o desempenho.

Compatibilidade

A propriedade animation é totalmente suportada pelos principais navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Não é necessário utilizar prefixos nas versões atuais.

Propriedades relacionadas

  • @keyframes → define os quadros da animação.
  • animation-name → nome da animação.
  • animation-duration → duração.
  • animation-delay → atraso antes do início.
  • animation-iteration-count → número de repetições.
  • animation-direction → direção da animação.
  • animation-fill-mode → comportamento antes e depois da execução.
  • animation-play-state → pausa ou executa a animação.
  • animation-timing-function → curva de velocidade.
  • transition → anima mudanças simples entre dois estados.
  • transform → frequentemente utilizada para mover, girar e escalar elementos animados.

Resumo

  • animation permite criar animações completas e independentes de interações do usuário.
  • Ela funciona em conjunto com @keyframes, que definem os estados da animação ao longo do tempo.
  • É composta por propriedades como animation-name, animation-duration, animation-delay, animation-iteration-count, animation-direction, animation-fill-mode, animation-play-state e animation-timing-function.
  • Pode repetir indefinidamente, alternar direções e conter várias etapas, oferecendo muito mais flexibilidade do que transition.
  • Para obter animações suaves e eficientes, prefira animar transform e opacity, evitando propriedades que exigem recálculos frequentes do layout.
