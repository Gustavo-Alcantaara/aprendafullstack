Keyframes

@keyframes no CSS

Introdução

O @keyframes é uma at-rule (regra especial) do CSS utilizada para definir uma sequência de quadros de uma animação. Ele especifica como um elemento deve mudar ao longo do tempo, indicando quais propriedades terão seus valores alterados em cada etapa da animação.

Por si só, o @keyframes não executa nenhuma animação. Ele apenas descreve a sequência de mudanças. Para que a animação aconteça, é necessário associá-lo à propriedade animation.

Podemos fazer uma analogia com um filme:

  • @keyframes → é o roteiro ou a sequência de cenas.
  • animation → é o projetor que reproduz esse roteiro.

Como funciona

Quando uma animação é iniciada, o navegador:

  1. Localiza o @keyframes correspondente.
  1. Lê todos os quadros definidos.
  1. Calcula automaticamente os valores intermediários entre um quadro e outro (interpolação).
  1. Atualiza o elemento continuamente até o final da animação.

Fluxo:

@keyframes
      ↓
Define os estados
      ↓
animation
      ↓
Executa a animação
      ↓
Navegador cria os quadros intermediários

Sintaxe

@keyframes nomeDaAnimacao{

}

Exemplo:

@keyframes aparecer{

    from{

        opacity:0;

    }

    to{

        opacity:1;

    }

}

Aplicação:

.box{

    animation:aparecer 1s;

}

Nome da animação

O nome é um identificador escolhido pelo desenvolvedor.

Exemplo:

@keyframes girar{

}
@keyframes pulse{

}
@keyframes mover{

}

Depois, ele deve ser utilizado em:

animation-name:girar;

ou

animation:girar 2s;

Os nomes devem seguir as regras de identificadores do CSS:

✔ podem conter letras;

✔ números (não podem começar com número);

✔ hífen (-);

✔ underline (_).

from e to

A forma mais simples de criar uma animação é utilizando:

from{

}

e

to{

}

Exemplo:

@keyframes aparecer{

from{

opacity:0;

}

to{

opacity:1;

}

}

Equivalência

Internamente:

from

é igual a

0%

E

to

é igual a

100%

Ou seja:

@keyframes aparecer{

0%{

opacity:0;

}

100%{

opacity:1;

}

}

Produz exatamente o mesmo resultado.

Utilizando porcentagens

As porcentagens representam o progresso da animação.

0%

↓

Início

50%

↓

Metade

100%

↓

Fim

Exemplo:

@keyframes mover{

0%{

transform:translateX(0);

}

50%{

transform:translateX(300px);

}

100%{

transform:translateX(0);

}

}

Resultado:

Início

↓

Vai para a direita

↓

Volta ao início

Vários quadros

Podemos criar quantos quadros forem necessários.

@keyframes arco{

0%{

}

20%{

}

40%{

}

60%{

}

80%{

}

100%{

}

}

Quanto mais quadros, maior o controle sobre a animação.

Exemplo de rotação

@keyframes girar{

0%{

transform:rotate(0deg);

}

100%{

transform:rotate(360deg);

}

}

Aplicação:

.logo{

animation:

girar

2s

linear

infinite;

}

Exemplo de escala

@keyframes crescer{

0%{

transform:scale(1);

}

50%{

transform:scale(1.3);

}

100%{

transform:scale(1);

}

}

Resultado:

Normal

↓

Maior

↓

Normal

Exemplo de mudança de cor

@keyframes cores{

0%{

background:red;

}

50%{

background:blue;

}

100%{

background:green;

}

}

Exemplo combinando propriedades

Em um mesmo quadro podemos alterar várias propriedades.

@keyframes entrada{

0%{

opacity:0;

transform:translateY(50px);

}

100%{

opacity:1;

transform:translateY(0);

}

}

O elemento:

  • aparece;
  • sobe;
  • tudo ao mesmo tempo.

O navegador cria os quadros intermediários

Considere:

0%{

opacity:0;

}

↓

100%{

opacity:1;

}

O navegador cria automaticamente:

0.1

0.2

0.3

0.4

...

0.9

Você não precisa definir esses valores.

Esse processo é chamado de interpolação.

Propriedades que podem ser animadas

As propriedades precisam ser animáveis.

Exemplos:

✔ opacity

✔ transform

✔ color

✔ background-color

✔ box-shadow

✔ border-radius

✔ filter

✔ letter-spacing

✔ font-size

✔ width

✔ height

Propriedades que não podem ser animadas

Algumas propriedades mudam instantaneamente.

Exemplo:

display
position
float
background-image

O navegador não consegue calcular estados intermediários para esses valores.

Reutilização

O mesmo @keyframes pode ser usado em vários elementos.

@keyframes pulse{

...

}
button{

animation:pulse 1s;

}
.card{

animation:pulse 2s;

}

Cada elemento pode ter:

  • duração diferente;
  • atraso diferente;
  • quantidade de repetições diferente.

Casos de uso

Os @keyframes são utilizados para criar:

  • loaders;
  • barras de progresso;
  • menus;
  • efeitos de entrada;
  • efeitos de saída;
  • botões pulsando;
  • logos girando;
  • animações de scroll;
  • interfaces futuristas;
  • jogos.

Boas práticas

✔ Dê nomes descritivos às animações.

Exemplo:

aparecer
fadeIn
slideLeft
pulse

Em vez de:

animacao1

✔ Utilize apenas os quadros necessários.

Não crie dezenas de porcentagens se duas ou três etapas já produzem o efeito desejado.

✔ Prefira animar:

transform

e

opacity

Essas propriedades oferecem melhor desempenho.

✔ Organize os @keyframes em uma seção específica do arquivo CSS, facilitando a manutenção.

Erros comuns

1. Criar o @keyframes e esquecer de usar animation

@keyframes mover{

...
}

Sem:

animation:mover 2s;

Nada acontece.

2. Escrever o nome errado

@keyframes mover{

}

Mas:

animation:movimento 2s;

Como os nomes são diferentes, a animação não será encontrada.

3. Animar propriedades pesadas

width

height

margin

left

top

Essas propriedades podem causar recálculos de layout.

Sempre que possível, prefira:

transform

e

opacity

Desempenho (Performance)

Os @keyframes em si não afetam o desempenho. O impacto depende das propriedades animadas.

As mais eficientes são:

  • transform
  • opacity

As mais custosas incluem:

  • width
  • height
  • margin
  • padding
  • top
  • left

Além disso, animações infinitas em muitos elementos podem aumentar o consumo de CPU e GPU.

Compatibilidade

O @keyframes é suportado por todos os navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Em navegadores atuais, não é necessário utilizar prefixos como @-webkit-keyframes.

Propriedades relacionadas

  • animation → executa a animação definida em @keyframes.
  • animation-name → especifica qual conjunto de @keyframes será utilizado.
  • animation-duration → define a duração da animação.
  • animation-delay → atraso antes do início.
  • animation-iteration-count → número de repetições.
  • animation-direction → controla a direção da animação.
  • animation-fill-mode → define o comportamento antes e depois da execução.
  • animation-play-state → pausa ou retoma a animação.
  • animation-timing-function → controla a velocidade entre os quadros.

Resumo

  • @keyframes define a sequência de estados de uma animação CSS.
  • Ele não executa a animação sozinho; precisa ser associado à propriedade animation.
  • Os quadros podem ser definidos com from/to ou com porcentagens (0% a 100%).
  • O navegador cria automaticamente os estados intermediários por meio da interpolação, tornando as transições suaves.
  • Um mesmo conjunto de @keyframes pode ser reutilizado em diferentes elementos com durações, atrasos e repetições distintas.
  • Para obter animações mais fluidas e eficientes, prefira animar transform e opacity, evitando propriedades que alteram diretamente o layout da página.
