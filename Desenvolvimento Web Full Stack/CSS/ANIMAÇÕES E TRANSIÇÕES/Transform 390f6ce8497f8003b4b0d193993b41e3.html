Transform

transform no CSS

Introdução

A propriedade transform é utilizada para modificar visualmente a posição, o tamanho, a rotação e a inclinação de um elemento, sem alterar seu espaço no layout da página.

Ela é uma das propriedades mais importantes do CSS moderno e é amplamente utilizada em:

  • animações;
  • efeitos de hover;
  • menus;
  • cards;
  • galerias;
  • interfaces modernas;
  • jogos;
  • efeitos 2D e 3D.

Uma das principais vantagens do transform é o seu excelente desempenho. Em navegadores modernos, suas animações geralmente são aceleradas pela GPU, tornando-as mais suaves do que animações que alteram propriedades como width, height, top ou left.

Como funciona

Quando usamos transform, o navegador não modifica a posição real do elemento no fluxo do documento. Em vez disso, ele aplica uma transformação visual após o elemento já ter sido renderizado.

Fluxo:

Elemento
      ↓
Renderização
      ↓
Aplicação do transform
      ↓
Resultado visual

Isso significa que o elemento continua ocupando o mesmo espaço original no layout.

Sintaxe

transform: função(valor);

Exemplo:

.card{
    transform: scale(1.2);
}

É possível utilizar várias funções ao mesmo tempo:

transform: translateX(100px) rotate(20deg) scale(1.1);

As transformações são aplicadas na ordem em que aparecem.

Principais funções do transform

O transform possui diversas funções. As mais utilizadas são:

  • translate()
  • scale()
  • rotate()
  • skew()
  • matrix()

Além disso, existem funções para transformações 3D.

translate()

Move o elemento de sua posição original.

Sintaxe:

transform: translate(x, y);

Exemplo:

transform: translate(100px, 50px);

Resultado:

Posição original

↓

100px para a direita

↓

50px para baixo

translateX()

Move apenas no eixo X.

transform: translateX(150px);

Valores negativos:

transform: translateX(-50px);

Movem o elemento para a esquerda.

translateY()

Move apenas no eixo Y.

transform: translateY(80px);

Valores negativos movem para cima.

translateZ()

Utilizado em transformações 3D.

transform: translateZ(100px);

Necessita de perspectiva (perspective) para que o efeito seja perceptível.

scale()

Altera o tamanho do elemento.

Sintaxe:

transform: scale(valor);

Exemplo:

transform: scale(1.5);

Resultado:

O elemento fica 50% maior.

Valores

scale(1)

Tamanho original.

scale(2)

200%.

scale(.5)

50%.

scaleX()

Escala apenas a largura.

transform: scaleX(2);

scaleY()

Escala apenas a altura.

transform: scaleY(.8);

rotate()

Rotaciona o elemento.

Sintaxe:

transform: rotate(45deg);

Resultado:

↗

Unidades

A unidade mais utilizada é:

deg

(graus)

Exemplos:

rotate(90deg)
rotate(180deg)
rotate(360deg)

Também existem outras unidades, como rad (radianos) e turn (voltas completas), mas deg é a mais comum.

skew()

Inclina o elemento.

transform: skew(20deg);

Resultado:

□□□□

↓

▱▱▱▱

skewX()

Inclinação horizontal.

transform: skewX(25deg);

skewY()

Inclinação vertical.

transform: skewY(-15deg);

matrix()

Permite combinar várias transformações em uma única função.

transform: matrix(a, b, c, d, tx, ty);

Ela é baseada em uma matriz matemática e é pouco utilizada manualmente. Ferramentas gráficas e navegadores costumam gerar esse valor automaticamente.

Transformações 3D

O CSS também oferece funções tridimensionais.

rotateX()

transform: rotateX(45deg);

Gira em torno do eixo X.

rotateY()

transform: rotateY(180deg);

Muito utilizada em efeitos de "virar cartão".

rotateZ()

Equivalente ao rotate() em 2D.

transform: rotateZ(90deg);

scale3d()

Escala nos três eixos.

transform: scale3d(1.2, 1.2, 1);

translate3d()

Move o elemento nos três eixos.

transform: translate3d(50px, 30px, 100px);

Combinando transformações

Podemos aplicar várias funções na mesma propriedade.

transform:

translateX(50px)

rotate(20deg)

scale(1.2);

Resultado:

  1. Move.
  1. Rotaciona.
  1. Aumenta.

A ordem influencia o resultado final.

transform-origin

Por padrão, as transformações acontecem a partir do centro do elemento.

transform-origin: center;

Podemos alterar esse ponto.

Exemplo:

transform-origin: top left;

Agora o elemento será transformado tomando o canto superior esquerdo como referência.

Também é possível utilizar valores em porcentagem ou unidades:

transform-origin: 50% 50%;
transform-origin: 20px 30px;

perspective

Para efeitos 3D, normalmente utilizamos:

perspective: 1000px;

Ela define a distância entre o observador e o elemento, criando sensação de profundidade.

Exemplo:

.container{
    perspective: 1000px;
}

Exemplos práticos

Aumentar ao passar o mouse

.card{

    transition: transform .3s;

}

.card:hover{

    transform: scale(1.05);

}

Girar um ícone

.icon{

    transition: transform .4s;

}

.icon:hover{

    transform: rotate(180deg);

}

Levantar um card

.card{

    transition: transform .3s;

}

.card:hover{

    transform: translateY(-10px);

}

Virar um cartão (Flip)

.card{

    transform: rotateY(180deg);

}

Muito utilizado em jogos da memória e cartões interativos.

Combinação

.card:hover{

transform:

translateY(-10px)

scale(1.05)

rotate(3deg);

}

transform x alterar posição

Considere:

left:100px;

O navegador precisa recalcular o layout.

Agora:

transform:translateX(100px);

O layout permanece o mesmo, sendo alterada apenas a representação visual do elemento.

Por isso, transform costuma oferecer melhor desempenho.

Casos de uso

O transform é utilizado em:

  • botões;
  • menus;
  • cards;
  • galerias;
  • sliders;
  • dashboards;
  • loaders;
  • jogos;
  • interfaces modernas;
  • animações.

Boas práticas

✔ Prefira transform em vez de top, left, width e height para animações.

✔ Combine transform com transition ou animation para obter movimentos suaves.

✔ Ajuste o transform-origin quando precisar de rotações ou escalas a partir de um ponto específico.

✔ Em efeitos 3D, utilize perspective para criar uma sensação realista de profundidade.

Erros comuns

1. Esquecer que transform substitui o valor anterior

Errado:

transform: translateX(20px);
transform: rotate(30deg);

Apenas o último será aplicado.

O correto é combinar:

transform: translateX(20px) rotate(30deg);

2. Esperar que o layout mude

transform não altera o espaço ocupado pelo elemento. Outros elementos continuarão posicionados como se ele estivesse em sua posição original.

3. Não definir perspective em efeitos 3D

Sem perspectiva, muitas transformações em 3D podem parecer "achatadas", sem profundidade.

Desempenho (Performance)

O transform é uma das propriedades mais rápidas para animações. Em navegadores modernos, ele geralmente é acelerado por hardware (GPU), reduzindo a necessidade de recálculos de layout e proporcionando movimentos suaves.

Por isso, é recomendado utilizá-lo em conjunto com opacity para criar animações eficientes.

Compatibilidade

A propriedade transform é suportada por todos os principais navegadores modernos:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Não é necessário utilizar prefixos nas versões atuais.

Propriedades relacionadas

  • transition → anima mudanças de transform.
  • animation → executa animações baseadas em @keyframes.
  • transform-origin → define o ponto de origem da transformação.
  • perspective → cria profundidade para transformações 3D.
  • backface-visibility → controla a visibilidade da face traseira em rotações 3D.
  • opacity → frequentemente combinada com transform em animações.

Resumo

  • transform modifica visualmente um elemento sem alterar seu espaço no layout.
  • As funções mais utilizadas são translate(), scale(), rotate() e skew(), além das versões 3D.
  • É possível combinar várias transformações em uma única declaração, respeitando a ordem de aplicação.
  • transform-origin controla o ponto de referência das transformações, enquanto perspective adiciona profundidade aos efeitos 3D.
  • Devido ao excelente desempenho, transform é uma das propriedades mais recomendadas para animações e interações modernas, especialmente quando combinada com transition ou animation.
