Flex Direction, Wrap e Flow

Essas propriedades são usadas no Flexbox para controlar direção e quebra de linha dos itens dentro de um container com:

display:flex;

🔹 flex-direction

Define a direção dos itens.

Valores principais:

ValorResultado
rowLinha (padrão)
row-reverseLinha invertida
columnColuna
column-reverseColuna invertida

Exemplos:

flex-direction:row;

➡️ Itens lado a lado

flex-direction:column;

⬇️ Itens um abaixo do outro

🔹 flex-wrap

Define se os itens vão quebrar linha quando faltar espaço.

Valores:

ValorResultado
nowrapNão quebra (padrão)
wrapQuebra linha
wrap-reverseQuebra invertida

Exemplo:

flex-wrap:wrap;

Se não couber:

[item][item][item]
[item][item]

🔹 flex-flow

É o atalho para usar:

  • flex-direction
  • flex-wrap

Tudo em uma linha.

Sintaxe:

flex-flow:direção quebra;

Exemplo:

flex-flow:row wrap;

Significa:

flex-direction:row;
flex-wrap:wrap;

🔥 Exemplo completo

.container {
  display:flex;
  flex-flow:row wrap;
  gap:10px;
}

Itens ficam em linha e quebram quando necessário.

✅ Resumo rápido

PropriedadeFunção
flex-directionDireção dos itens
flex-wrapQuebra linha
flex-flowJunta as duas

🎯 Pensamento fácil

  • direction = pra onde vai
  • wrap = quebra ou não
  • flow = os dois juntos

💡 Se decorar só isso:

flex-flow:row wrap;

É uma das combinações mais usadas.
