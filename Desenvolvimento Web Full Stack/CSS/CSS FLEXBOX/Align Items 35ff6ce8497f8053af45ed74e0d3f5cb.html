Align Items

A propriedade align-items é usada no Flexbox (e também no Grid) para alinhar os itens no eixo cruzado do container.

Ela funciona em elementos com:

display:flex;

🔹 O que é eixo cruzado?

É o eixo oposto ao principal.

Se for:

flex-direction:row;

➡️ eixo principal = horizontal

⬇️ eixo cruzado = vertical

Se for:

flex-direction:column;

⬇️ eixo principal = vertical

➡️ eixo cruzado = horizontal

🔹 Valores principais

ValorResultado
stretchEstica os itens (padrão)
flex-startInício do eixo cruzado
flex-endFinal do eixo cruzado
centerCentro
baselineAlinha pela linha do texto

🔹 Exemplos

flex-start

align-items:flex-start;

Itens ficam no topo.

center

align-items:center;

Itens centralizados verticalmente (se row).

flex-end

align-items:flex-end;

Itens ficam embaixo.

stretch

align-items:stretch;

Itens ocupam toda altura disponível.

🔥 Exemplo real

.container {
  display:flex;
  justify-content:center;
  align-items:center;
}

Resultado: itens centralizados no meio da caixa.

🔹 Diferença para justify-content

PropriedadeAtua em qual eixo?
justify-contentPrincipal
align-itemsCruzado

🎯 Se flex-direction: row

  • justify-content = horizontal
  • align-items = vertical

🎯 Se flex-direction: column

  • justify-content = vertical
  • align-items = horizontal

✅ Resumo rápido

align-items = alinha os itens atravessando a direção deles

💡 Se decorar só isso:

align-items:center;

Centraliza no eixo cruzado.

🔥 Combinação mais famosa:

display:flex;
justify-content:center;
align-items:center;

Centraliza tudo perfeitamente.
