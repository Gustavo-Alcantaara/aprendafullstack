Flex

A propriedade flex é um atalho (shorthand) do Flexbox que junta 3 propriedades em uma só:

  • flex-grow
  • flex-shrink
  • flex-basis

Ela é usada nos itens filhos de um container com:

display:flex;

🔹 Sintaxe completa

flex:grow shrink basis;

Exemplo:

flex: 1 1 200px;

Significa:

flex-grow: 1;
flex-shrink: 1;
flex-basis: 200px;

🔹 O que cada parte faz?

ParteFunção
growQuanto cresce
shrinkQuanto encolhe
basisTamanho inicial

🔹 Valor muito usado

flex: 1;

Normalmente equivale a:

flex-grow: 1;
flex-shrink: 1;
flex-basis: 0;

Resultado: item ocupa espaço disponível igualmente.

🔹 Exemplo prático

.container {
  display:flex;
}

.item {
  flex:1;
}

Todos os itens ficam com larguras iguais.

🔹 Divisão proporcional

.item1 {
  flex:1;
}

.item2 {
  flex:2;
}

Resultado:

  • item2 ocupa o dobro do item1

🔹 Tamanho fixo sem crescer

.item {
  flex:0 0 200px;
}

Significa:

  • não cresce
  • não encolhe
  • tamanho 200px

🔹 Muito usado em layouts

.sidebar {
  flex:1;
}

.content {
  flex:3;
}

Conteúdo ocupa mais espaço que a barra lateral.

🔥 Valores comuns

CódigoResultado
flex: 1;Divide espaço igualmente
flex: 2;Ocupa mais espaço
flex: auto;Cresce respeitando conteúdo
flex: none;Não cresce nem encolhe

✅ Resumo rápido

flex = forma rápida de controlar crescimento, encolhimento e tamanho base.

💡 Se decorar só isso:

flex: 1;

Item flexível e proporcional.

🎯 Pensamento fácil

flex = comando completo do item no Flexbox.

🔥 Regra prática

Use quando quiser layout limpo e rápido, em vez de escrever:

flex-grow
flex-shrink
flex-basis
