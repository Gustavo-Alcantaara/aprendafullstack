Flex Basis

A propriedade flex-basis é usada no Flexbox para definir o tamanho inicial/base de um item flexível antes que o espaço restante seja distribuído.

Ela funciona como uma largura ou altura inicial, dependendo da direção do container.

🔹 Onde usar?

Em itens dentro de um container com:

display:flex;

🔹 Ideia principal

Antes do Flexbox crescer (flex-grow) ou encolher (flex-shrink) os itens, ele olha para o valor do flex-basis.

Ou seja:

flex-basis = ponto de partida do tamanho

🔹 Exemplo básico

.item {
  flex-basis:200px;
}

Cada item começa com 200px.

🔹 Depende do flex-direction

Se for:

flex-direction:row;

➡️ flex-basis controla a largura

Se for:

flex-direction:column;

⬇️ flex-basis controla a altura

🔹 Valores possíveis

ValorFunção
autoUsa width/height ou conteúdo
pxValor fixo
%Porcentagem
0Sem tamanho base
contentBaseado no conteúdo (menos comum)

🔹 Exemplo prático

.container {
  display:flex;
}

.item {
  flex-basis:150px;
}

Todos começam com 150px.

🔹 Diferença para width

PropriedadeUso
widthlargura normal
flex-basislargura base no Flexbox

No Flexbox, flex-basis geralmente tem prioridade sobre width.

🔹 Muito usado com shorthand flex

flex: 1 1 200px;

Significa:

flex-grow: 1;
flex-shrink: 1;
flex-basis: 200px;

🔥 Exemplo visual

3 itens com:

flex-basis: 100px;

Começam com 100px cada, depois podem crescer ou diminuir.

✅ Resumo rápido

flex-basis = tamanho inicial do item no Flexbox.

💡 Se decorar só isso:

flex-basis: 200px;

Começa com 200px.

🎯 Pensamento fácil

  • width = largura comum
  • flex-basis = largura base flexível
