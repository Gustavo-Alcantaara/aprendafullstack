Justify e Align Items

As propriedades justify-items e align-items servem para alinhar os itens dentro de suas áreas/células no layout.

São muito usadas no CSS Grid, e align-items também funciona no Flexbox.

📌 Diferença Principal

PropriedadeAtua no eixoUso principal
justify-itemsHorizontal (inline)Grid
align-itemsVertical (block/cross axis)Grid e Flexbox

➡ Simplificando:

  • justify = lado a lado / horizontal
  • align = cima e baixo / vertical

🔹 justify-items

Alinha cada item dentro de sua célula horizontalmente.

📌 Funciona principalmente no CSS Grid.

.container {
  display:grid;
  justify-items:center;
}

Valores de justify-items

1. start

Itens vão para a esquerda.

justify-items:start;

2. end

Itens vão para a direita.

justify-items:end;

3. center

Itens centralizados horizontalmente.

justify-items:center;

4. stretch (padrão)

Item ocupa toda largura disponível.

justify-items:stretch;

📌 Exemplo Grid

.container {
  display:grid;
  grid-template-columns:repeat(3,150px);
  justify-items:center;
}

➡ Cada item ficará centralizado dentro da sua coluna.

🔹 align-items

Alinha os itens no eixo vertical (ou cruzado).

No Grid:

Alinha dentro da célula verticalmente.

No Flexbox:

Alinha os itens no eixo cruzado.

Valores de align-items

1. stretch (padrão)

Itens se esticam.

align-items:stretch;

2. start

Itens no topo.

align-items:start;

ou no Flexbox:

align-items:flex-start;

3. end

Itens embaixo.

align-items:end;

ou:

align-items:flex-end;

4. center

Itens centralizados verticalmente.

align-items:center;

5. baseline

Alinha pela linha base do texto.

align-items:baseline;

Muito útil quando textos têm tamanhos diferentes.

📌 Exemplo no Flexbox

.container {
  display:flex;
  height:300px;
  align-items:center;
}

➡ Os itens ficam centralizados verticalmente.

📌 Exemplo no Grid

.container {
  display:grid;
  height:300px;
  align-items:center;
}

➡ Os itens ficam centralizados verticalmente dentro das células.

📌 Diferença entre justify-content e justify-items

PropriedadeMove
justify-contentO grupo inteiro
justify-itemsCada item individualmente

📌 Diferença entre align-content e align-items

PropriedadeMove
align-contentLinhas / grade inteira
align-itemsCada item

📌 Resumo Visual (Grid)

.container {
  display:grid;
  justify-items:center;
  align-items:center;
}

➡ Centraliza os itens horizontal e verticalmente dentro das células.

📌 Resumo Visual (Flexbox)

.container {
  display:flex;
  justify-content:center;
  align-items:center;
}

➡ Centraliza horizontalmente e verticalmente no container.

📌 Resumo Final

justify-items

Alinha itens horizontalmente dentro da área.

Valores:

  • start
  • end
  • center
  • stretch

align-items

Alinha itens verticalmente / eixo cruzado.

Valores:

  • start
  • end
  • center
  • stretch
  • baseline

São propriedades essenciais para posicionamento em Grid e Flexbox.
