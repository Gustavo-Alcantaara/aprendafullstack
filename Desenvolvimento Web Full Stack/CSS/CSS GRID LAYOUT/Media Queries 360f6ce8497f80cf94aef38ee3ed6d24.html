Media Queries

As Media Queries são recursos do CSS usados para aplicar estilos diferentes dependendo das características do dispositivo ou da tela, como largura, altura, orientação e resolução. Elas são essenciais para criar sites responsivos, que se adaptam a celulares, tablets, notebooks e monitores grandes.

📌 Sintaxe Básica

@media condição {
seletor {
      propriedade:valor;
   }
}

Exemplo:

@media (max-width:600px) {
body {
      background:lightblue;
   }
}

➡ Isso significa: se a tela tiver 600px ou menos, o fundo ficará azul claro.

📌 Principais Tipos de Media

1. all

Aplica para todos os dispositivos.

@media all { }

2. screen

Usado para telas (celular, PC, tablet).

@media screen { }

3. print

Usado para impressão.

@media print {
body {
      color:black;
   }
}

📌 Principais Condições (Features)

🔹 max-width

Aplica estilos até determinada largura.

@media (max-width:768px)

➡ Telas de 768px para baixo.

🔹 min-width

Aplica estilos a partir de determinada largura.

@media (min-width:768px)

➡ Telas de 768px para cima.

🔹 width

Largura exata.

@media (width:1024px)

🔹 max-height

Altura máxima.

@media (max-height:700px)

🔹 min-height

Altura mínima.

@media (min-height:700px)

🔹 orientation

Detecta orientação da tela.

Landscape (horizontal)

@media (orientation:landscape)

Portrait (vertical)

@media (orientation:portrait)

🔹 resolution

Detecta densidade/resolução da tela.

@media (min-resolution:2dppx)

➡ Muito usado para telas Retina.

📌 Operadores Lógicos

and

Combina condições.

@media screen and (max-width:768px)

➡ Tela E largura menor que 768px.

, (vírgula)

Equivale a ou

@media (max-width:600px), (orientation:portrait)

➡ Tela pequena OU vertical.

not

Nega condição.

@media not screen

only

Usado antigamente para navegadores antigos.

@media only screen and (max-width:600px)

Hoje quase não é necessário.

📌 Exemplo Responsivo Completo

.container {
   width:1200px;
}

@media (max-width:992px) {
   .container {
      width:90%;
   }
}

@media (max-width:600px) {
   .container {
      width:100%;
   }
}

➡ O container diminui conforme a tela fica menor.

📌 Mobile First (Recomendado)

Criar o CSS primeiro para celular e depois aumentar.

.menu {
   display:block;
}

@media (min-width:768px) {
   .menu {
      display:flex;
   }
}

➡ Melhor performance e organização.

📌 Desktop First

Criar para PC e diminuir depois.

.menu {
   display:flex;
}

@media (max-width:768px) {
   .menu {
      display:block;
   }
}

📌 Onde usar Media Queries?

✅ Alterar tamanho de fonte

✅ Mudar layout

✅ Esconder elementos

✅ Trocar menu desktop/mobile

✅ Ajustar imagens

✅ Grid responsivo

✅ Sidebar virar menu inferior

📌 Boas Práticas

✅ Use poucos breakpoints

✅ Baseie nos conteúdos, não em aparelhos específicos

✅ Prefira min-width (mobile first)

✅ Teste em vários tamanhos

✅ Use %, vw, flex, grid junto

📌 Exemplo Real

.cards {
   display:grid;
   grid-template-columns:repeat(4,1fr);
}

@media (max-width:900px) {
   .cards {
      grid-template-columns:repeat(2,1fr);
   }
}

@media (max-width:500px) {
   .cards {
      grid-template-columns:1fr;
   }
}

➡ 4 colunas → 2 colunas → 1 coluna.

📌 Resumo Final

Media Queries servem para deixar sites adaptáveis.

Elas detectam largura, altura, orientação e outras características da tela para aplicar estilos diferentes.

As propriedades mais usadas são:

  • max-width
  • min-width
  • orientation
  • max-height
  • min-height
  • resolution

São fundamentais no Responsive Design.
