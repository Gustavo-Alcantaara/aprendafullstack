Justify e Align Content

As propriedades justify-content e align-content são usadas para alinhar e distribuir espaço entre itens em layouts Flexbox e CSS Grid.

Elas ajudam a posicionar elementos dentro do container, principalmente quando sobra espaço.

📌 Entendendo os Eixos

No Flexbox:

Depende do flex-direction.

Se flex-direction: row

  • Eixo principal (main axis) = horizontal
  • Eixo cruzado (cross axis) = vertical

Se flex-direction: column

  • Eixo principal = vertical
  • Eixo cruzado = horizontal

🔹 justify-content

Controla o alinhamento no eixo principal.

➡ Em row: horizontal

➡ Em column: vertical

Valores de justify-content

1. flex-start

Itens vão para o início.

.container {
  justify-content:flex-start;
}

⬅⬅⬅ Item Item Item

2. flex-end

Itens vão para o final.

justify-content:flex-end;

➡➡➡ Item Item Item

3. center

Centraliza os itens.

justify-content:center;

⬅ Item Item Item ➡

4. space-between

Primeiro no início, último no fim, espaço entre eles.

justify-content:space-between;

Item Item Item

5. space-around

Espaço ao redor de cada item.

justify-content:space-around;

Item Item Item

6. space-evenly

Espaços totalmente iguais.

justify-content:space-evenly;

Item Item Item `

📌 Exemplo

.container {
  display:flex;
  justify-content:center;
}

🔹 align-content

Controla o alinhamento das linhas/colunas inteiras no eixo cruzado.

⚠ Só funciona quando:

✅ Há quebra de linha (flex-wrap: wrap) no Flexbox

ou

✅ Há múltiplas linhas no Grid.

Se houver apenas uma linha, geralmente use align-items.

Valores de align-content

1. stretch (padrão)

Linhas ocupam todo espaço disponível.

align-content:stretch;

2. flex-start

Linhas agrupadas no início.

align-content:flex-start;

3. flex-end

Linhas no final.

align-content:flex-end;

4. center

Linhas centralizadas.

align-content:center;

5. space-between

Linhas separadas com espaço entre elas.

align-content:space-between;

6. space-around

Espaço ao redor das linhas.

align-content:space-around;

7. space-evenly

Espaços iguais entre linhas.

align-content:space-evenly;

📌 Exemplo com Wrap

.container {
  display:flex;
  flex-wrap:wrap;
  height:400px;
  align-content:center;
}

➡ As linhas de itens ficarão centralizadas verticalmente.

📌 Diferença entre align-items e align-content

PropriedadeAtua em
align-itemsItens individualmente
align-contentLinhas/conjunto de itens

📌 No CSS Grid

Também funcionam:

  • justify-content → move toda a grade horizontalmente
  • align-content → move toda a grade verticalmente

Exemplo Grid

.container {
  display:grid;
  width:600px;
  height:500px;
  grid-template-columns:100px100px;
  justify-content:center;
  align-content:center;
}

➡ A grade inteira ficará centralizada.

📌 Resumo Visual

justify-content

Controla no eixo principal:

  • start
  • end
  • center
  • between
  • around
  • evenly

align-content

Controla linhas no eixo cruzado:

  • start
  • end
  • center
  • stretch
  • between
  • around
  • evenly

📌 Resumo Final

Use justify-content para alinhar itens no eixo principal.

Use align-content para alinhar várias linhas quando sobra espaço.

São essenciais para criar layouts organizados no Flexbox e Grid.
