Colunas

CSS Grid permite criar layouts bidimensionais, ou seja, controlar linhas e colunas ao mesmo tempo. As colunas definem a divisão horizontal do container, organizando os elementos lado a lado.

Criando colunas

A principal propriedade é:

grid-template-columns

Ela define quantas colunas existirão e qual tamanho cada uma terá.

Exemplo:

.container {
  display:grid;
  grid-template-columns:200px 200px 200px;
}

Cria 3 colunas, cada uma com 200px.

Usando frações (fr)

A unidade fr representa uma fração do espaço disponível.

grid-template-columns: 1fr 1fr 1fr;

Cria 3 colunas com tamanhos iguais.

grid-template-columns: 2fr 1fr;

A primeira coluna ocupa o dobro da segunda.

Misturando unidades

Pode combinar valores fixos e flexíveis:

grid-template-columns: 200px 1fr 2fr;
  • 1ª coluna: 200px
  • 2ª: ocupa 1 parte do restante
  • 3ª: ocupa 2 partes do restante

Repetição com repeat()

Evita escrever valores repetidos:

grid-template-columns:repeat(3, 1fr);

Mesmo que:

1fr 1fr 1fr

Outro exemplo:

grid-template-columns:repeat(4, 150px);

Colunas automáticas

grid-template-columns:repeat(auto-fit,minmax(200px, 1fr));

Muito usado em layouts responsivos.

  • Cria quantas colunas couberem
  • Cada coluna terá no mínimo 200px
  • Crescem até ocupar o espaço disponível

Espaçamento entre colunas

Usa-se:

column-gap: 20px;

Ou:

gap: 20px;

(gap vale para linhas e colunas)

Fazer item ocupar várias colunas

Nos itens internos:

.item {
  grid-column:span2;
}

O elemento ocupa 2 colunas.

Ou:

grid-column: 1 / 3;

Vai da linha de coluna 1 até a 3.

Linhas de coluna (Grid Lines)

Cada coluna possui linhas numeradas:

grid-template-columns: 1fr 1fr 1fr;

Gera linhas:

1 | col1 | 2 | col2 | 3 | col3 | 4

Isso permite posicionar itens com precisão.

Responsividade

Pode mudar colunas com media query:

grid-template-columns: 1fr 1fr 1fr;

No celular:

grid-template-columns: 1fr;

Exemplo completo

.container {
  display:grid;
  grid-template-columns:repeat(3,1fr);
  gap:15px;
}

Cria:

  • 3 colunas iguais
  • Espaço de 15px entre itens

Resumo final

As colunas no CSS Grid são controladas principalmente por grid-template-columns. Elas podem ter tamanhos fixos (px), flexíveis (fr), automáticos (auto) ou responsivos (repeat, minmax, auto-fit). Também é possível espaçar colunas com gap e fazer elementos ocuparem várias colunas usando grid-column. Isso torna o Grid ideal para layouts modernos e organizados.
