Pseudo-Classes e Pseudo-Elementos

As pseudo-classes e pseudo-elementos em CSS permitem estilizar estados especiais ou partes específicas dos elementos HTML, sem precisar criar novas tags no HTML.

Elas deixam o site mais interativo e visualmente bonito.

🎯 Diferença principal

🔹 Pseudo-classes (:)

Estilizam situações/estados de um elemento.

Exemplo:

  • mouse em cima
  • campo selecionado
  • primeiro filho
  • último filho
button:hover

🔹 Pseudo-elementos (::)

Estilizam partes internas ou criam conteúdo visual.

Exemplo:

  • primeira letra
  • primeira linha
  • conteúdo antes/depois
p::first-letter

🔥 PSEUDO-CLASSES MAIS USADAS

🔹 :hover

Quando o mouse passa em cima.

button:hover{
  background:red;
}

➡ Muito usada em botões e links.

🔹 :active

Quando o elemento está sendo clicado.

button:active{
  transform:scale(0.95);
}

🔹 :focus

Quando input ou campo está selecionado.

input:focus{
  border:2px solid blue;
}

🔹 :visited

Links já visitados.

a:visited{
  color:purple;
}

🔹 :first-child

Seleciona primeiro filho.

li:first-child{
  color:red;
}

🔹 :last-child

Último filho.

li:last-child{
  color:blue;
}

🔹 :nth-child()

Seleciona posição específica.

li:nth-child(2){
  color:green;
}
li:nth-child(even)/* pares */
li:nth-child(odd)/* ímpares */

🔹 :not()

Seleciona tudo menos algo.

p:not(.especial){
  color:gray;
}

🎨 PSEUDO-ELEMENTOS MAIS USADOS

🔹 ::before

Cria conteúdo antes.

h1::before{
  content:"🔥 ";
}

🔹 ::after

Cria conteúdo depois.

h1::after{
  content:" 🚀";
}

🔹 ::first-letter

Primeira letra.

p::first-letter{
  font-size:30px;
  color:red;
}

🔹 ::first-line

Primeira linha.

p::first-line{
  font-weight:bold;
}

🔹 ::selection

Texto selecionado pelo mouse.

::selection{
  background:yellow;
  color:black;
}

📌 Propriedades que podem usar

Você usa propriedades normais do CSS:

  • color
  • background
  • font-size
  • border
  • padding
  • margin
  • transform
  • opacity
  • etc.

Exemplo:

button:hover{
  background:black;
  color:white;
  transform:scale(1.1);
}

🔥 Exemplo real completo

a{
  color:blue;
}

a:hover{
  color:red;
}

input:focus{
  border:2px solid green;
}

p::first-letter{
  font-size:40px;
}

h2::after{
  content:" ⭐";
}
