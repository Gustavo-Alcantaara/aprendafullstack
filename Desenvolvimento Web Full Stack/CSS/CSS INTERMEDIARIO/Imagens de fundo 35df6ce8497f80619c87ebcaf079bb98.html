Imagens de fundo

As cores e imagens de fundo em CSS servem para estilizar o plano de fundo dos elementos, deixando o site mais bonito, organizado e visualmente agradável.

Podem ser aplicadas em:

  • body
  • div
  • section
  • button
  • header
  • qualquer elemento HTML

🎨 Cores de Fundo

🔹 background-color

Define a cor de fundo.

background-color:red;
background-color:#ff0000;
background-color:rgb(255, 0, 0);
background-color:rgba(255, 0, 0, 0.5);

Formas de usar:

✅ Nome da cor

background-color:blue;

✅ Hexadecimal

background-color:#3498db;

✅ RGB

background-color:rgb(52, 152, 219);

✅ RGBA (com transparência)

background-color:rgba(52, 152, 219, 0.5);

➡ O último valor vai de 0 até 1.

🖼️ Imagem de Fundo

🔹 background-image

Define uma imagem no fundo.

background-image:url("imagem.jpg");

📏 Propriedades das Imagens de Fundo

🔹 background-repeat

Controla repetição da imagem.

background-repeat:repeat;
background-repeat:no-repeat;
background-repeat:repeat-x;
background-repeat:repeat-y;

Exemplos:

  • repeat → repete tudo (padrão)
  • no-repeat → não repete
  • repeat-x → só horizontal
  • repeat-y → só vertical

🔹 background-size

Controla tamanho da imagem.

background-size:cover;
background-size:contain;
background-size: 100% 100%;
background-size: 300px;

Mais usados:

  • cover → cobre toda área
  • contain → mostra inteira sem cortar

🔹 background-position

Posição da imagem.

background-position:center;
background-position:top;
background-position:bottom right;

➡ Muito usado com cover.

🔹 background-attachment

Define se fundo rola junto com a página.

background-attachment:scroll;
background-attachment:fixed;
  • scroll → normal
  • fixed → imagem parada (efeito parallax simples)

🔹 background

Forma abreviada de tudo.

background:#000 url("img.jpg") no-repeat center center /cover;

🔥 Exemplo completo

body{
  background-color: #111;
  background-image:url("academia.jpg");
  background-repeat:no-repeat;
  background-size:cover;
  background-position:center;
  background-attachment:fixed;
}

📌 Onde usar?

Body (site inteiro)

body{
  background-color: #f4f4f4;
}

Card / caixa

.card{
  background-color:white;
}

Banner

.banner{
  background-image:url("banner.jpg");
}

✅ Resumo Final

Use background-color para cores e background-image para imagens.

As propriedades mais importantes são:

  • background-size: cover
  • background-position: center
  • background-repeat: no-repeat
