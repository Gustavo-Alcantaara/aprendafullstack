Herança e Especificidade

Herança e especificidade são conceitos importantes do CSS que explicam como os estilos são aplicados e qual regra vence quando há conflito.

Eles ajudam a entender por que um estilo funciona ou não.

🌱 HERANÇA

A herança acontece quando alguns elementos filhos recebem automaticamente estilos do elemento pai.

Exemplo:

body{
  color:blue;
  font-family:Arial;
}
<body>
<p>Texto</p>
</body>

➡ O <p> herda:

  • color: blue
  • font-family: Arial

🔹 Propriedades que costumam herdar

Geralmente propriedades ligadas a texto:

  • color
  • font-family
  • font-size
  • line-height
  • text-align
  • visibility

🔹 Propriedades que NÃO herdam

Normalmente layout e caixa:

  • margin
  • padding
  • border
  • width
  • height
  • background

🔹 Forçar Herança

button{
  color:inherit;
}

➡ O botão herda a cor do pai.

🎯 ESPECIFICIDADE

Especificidade define qual seletor tem prioridade quando dois estilos tentam alterar a mesma coisa.

Exemplo:

p{
  color:blue;
}

.texto{
  color:red;
}
<p class="texto">Olá</p>

➡ Resultado: vermelho

Porque .classe é mais forte que tag.

📊 Ordem de força (menor para maior)

Tipo de seletorForça
* universal0
tag (p)1

atributo / pseudo-classe10

!importantmáxima

🔹 Exemplos

Tag perde para classe

p{ color:blue; }
.texto{ color:red; }

➡ vence .texto

Classe perde para ID

.texto{ color:blue; }
#titulo{ color:red; }

➡ vence #titulo

Inline style vence quase tudo

<p style="color:green;">

➡ vence CSS externo comum.

🔹 Empate de especificidade

Se dois seletores têm mesma força, vence o último escrito.

p{
 color:blue;
}

p{
 color:red;
}

➡ vermelho

⚠️ !important

Força prioridade máxima.

p{
  color:red !important;
}

➡ Deve usar pouco, pois dificulta manutenção.

🔥 Exemplo real

body{
  color: #333;
}

.card{
  color:blue;
}

#destaque{
  color:red;
}
<div class="card" id="destaque">
 Texto
</div>

➡ Cor final: vermelha

(ID vence classe)

✅ Resumo Final

  • Herança passa alguns estilos do pai para o filho (principalmente textos).
  • Especificidade decide qual seletor ganha em conflitos.

Ordem prática:

tag < classe < id < inline < !important
