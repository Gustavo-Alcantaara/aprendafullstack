Fontes Personalizadas

Usar fontes personalizadas em CSS permite que seu site tenha uma identidade visual própria, sem depender apenas das fontes instaladas no computador do usuário. Hoje, existem duas formas principais de fazer isso:

  • Utilizando uma fonte hospedada na internet (como Google Fonts).
  • Hospedando os arquivos da fonte no próprio projeto com @font-face.

O que são fontes personalizadas?

Por padrão, o navegador só consegue exibir fontes instaladas no sistema operacional do usuário, como:

  • Arial
  • Times New Roman
  • Verdana
  • Georgia

Se você quiser utilizar uma fonte diferente, precisa fornecê-la ao navegador.

Método 1 — Google Fonts (mais simples)

O Google Fonts disponibiliza centenas de fontes gratuitas.

Exemplo:

<head>
    <link
        href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;700&display=swap"
        rel="stylesheet">
</head>

Depois basta utilizar no CSS:

body{
    font-family: "Poppins", sans-serif;
}

Observe que sempre existe uma fonte de segurança:

font-family: "Poppins", sans-serif;

Caso a Poppins não carregue, será utilizada qualquer fonte da família sans-serif.

Método 2 — @font-face (recomendado para projetos próprios)

É o método usado quando você possui o arquivo da fonte.

Imagine a estrutura:

projeto/

    index.html

    css/
        style.css

    fonts/
        MinhaFonte.ttf

No CSS:

@font-face{
    font-family: "MinhaFonte";
    src: url("../fonts/MinhaFonte.ttf");
}

Agora ela pode ser usada normalmente:

h1{
    font-family: "MinhaFonte";
}

Como funciona o @font-face

A regra possui algumas propriedades importantes.

font-family

É o nome que você dará para a fonte.

font-family: "Ghost";

Esse nome é criado por você.

Depois basta usar:

font-family: "Ghost";

src

Indica onde está o arquivo.

src: url("../fonts/ghost.ttf");

Também é possível informar vários formatos:

src:
url("../fonts/ghost.woff2") format("woff2"),
url("../fonts/ghost.woff") format("woff"),
url("../fonts/ghost.ttf") format("truetype");

O navegador escolhe o formato que melhor suporta.

Formatos de fontes

Existem vários.

FormatoDescrição
WOFF2Mais moderno e recomendado
WOFFMuito utilizado
TTFTrueType Font
OTFOpenType Font
EOTAntigo (Internet Explorer)

Hoje a ordem recomendada é:

src:
url("fonte.woff2") format("woff2"),
url("fonte.woff") format("woff");

Definindo peso (font-weight)

Você pode registrar diferentes versões da mesma fonte.

Por exemplo:

Ghost-Light.ttf
Ghost-Regular.ttf
Ghost-Bold.ttf
@font-face{
    font-family: "Ghost";
    src: url("Ghost-Light.ttf");
    font-weight:300;
}

@font-face{
    font-family:"Ghost";
    src:url("Ghost-Regular.ttf");
    font-weight:400;
}

@font-face{
    font-family:"Ghost";
    src:url("Ghost-Bold.ttf");
    font-weight:700;
}

Depois basta escrever:

h1{
    font-family:"Ghost";
    font-weight:700;
}

p{
    font-family:"Ghost";
    font-weight:300;
}

O navegador automaticamente utilizará o arquivo correto.

Definindo estilo

Também é possível registrar versões em itálico.

@font-face{
    font-family:"Ghost";
    src:url("Ghost-Italic.ttf");
    font-style:italic;
}

Uso:

p{
    font-style: italic;
}

Fontes variáveis (Variable Fonts)

Hoje muitas fontes possuem um único arquivo que contém todos os pesos.

Exemplo:

Inter-Variable.ttf

Você registra apenas uma vez:

@font-face{
    font-family:"Inter";
    src:url("Inter-Variable.ttf");
}

Depois:

font-weight:100;
font-weight:250;
font-weight:430;
font-weight:800;

Tudo usando o mesmo arquivo.

Essa abordagem reduz o número de arquivos carregados e oferece mais flexibilidade.

Usando a fonte em diferentes elementos

body{
    font-family:"Ghost";
}

h1{
    font-weight:700;
}

p{
    font-weight:400;
}

button{
    font-weight:600;
}

Fontes de fallback

Nunca utilize apenas uma fonte.

Errado:

font-family:"Ghost";

Correto:

font-family:"Ghost", Arial, sans-serif;

Se a fonte não carregar:

  1. Ghost
  1. Arial
  1. qualquer sans-serif

Organização recomendada do projeto

Projeto

│
├── index.html
│
├── css
│     style.css
│
├── fonts
│     Ghost-Regular.woff2
│     Ghost-Bold.woff2
│
└── imagens

Exemplo completo

HTML

<!DOCTYPE html>
<html>

<head>
    <link rel="stylesheet" href="css/style.css">
</head>

<body>

<h1>Ghostware</h1>

<p>Logic Above Limits</p>

</body>
</html>

CSS

@font-face{
    font-family:"Ghost";
    src:url("../fonts/Ghost-Regular.woff2") format("woff2");
    font-weight:400;
}

@font-face{
    font-family:"Ghost";
    src:url("../fonts/Ghost-Bold.woff2") format("woff2");
    font-weight:700;
}

body{
    font-family:"Ghost", Arial, sans-serif;
}

h1{
    font-size:48px;
    font-weight:700;
}

p{
    font-size:20px;
    font-weight:400;
}

Boas práticas

  • Prefira os formatos WOFF2 e WOFF, pois são menores e carregam mais rapidamente.
  • Sempre forneça uma fonte de fallback (Arial, sans-serif, etc.).
  • Hospede as fontes localmente quando quiser maior controle e independência de serviços externos.
  • Utilize apenas os pesos e estilos realmente necessários para reduzir o tamanho dos arquivos e melhorar o desempenho.
  • Verifique a licença da fonte antes de utilizá-la em projetos comerciais; nem todas permitem uso livre.

Resumo

As duas formas mais comuns de usar fontes personalizadas são:

  • Google Fonts: ideal para começar rapidamente, bastando importar a fonte e aplicá-la com font-family.
  • @font-face: recomendado quando você deseja hospedar os arquivos da fonte no próprio projeto, oferecendo mais controle e independência.

Em ambos os casos, depois que a fonte é registrada, ela é utilizada da mesma maneira:

elemento{
    font-family: "NomeDaFonte", sans-serif;
}

Esse recurso é fundamental para criar uma identidade visual consistente e profissional em sites e aplicações web.
