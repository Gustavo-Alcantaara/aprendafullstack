Seletores CSS

Os seletores CSS servem para escolher quais elementos HTML receberão estilos.

Sem seletores, o CSS não saberia onde aplicar cor, tamanho, margem, etc.

Em resumo: seletor = alvo do estilo.

🎯 Estrutura básica

seletor {
   propriedade:valor;
}

Exemplo:

p{
   color:blue;
}

➡ Todos os <p> ficarão azuis.

🔹 Principais Seletores CSS

1. Seletor por Tag (Elemento)

Seleciona elementos pelo nome da tag HTML.

h1{
  color:red;
}

p{
  font-size:18px;
}

➡ Estiliza todos daquela tag.

2. Seletor por ID

Usa # e seleciona um elemento único.

HTML:

<div id="topo"></div>

CSS:

#topo{
  background-color:black;
}

➡ ID deve ser único na página.

3. Seletor por Classe

Usa . e pode repetir em vários elementos.

HTML:

<p class="texto"></p>
<div class="texto"></div>

CSS:

.texto{
  color:green;
}

➡ Muito usado no dia a dia.

4. Seletor Universal

Seleciona tudo.

*{
  margin:0;
  padding:0;
}

➡ Muito usado no reset CSS.

🔹 Seletores Agrupados

Aplica mesmo estilo em vários elementos.

h1,h2,p{
  font-family:Arial;
}

🔹 Seletores Descendentes

Seleciona elementos dentro de outro.

div p{
  color:red;
}

➡ Todo <p> dentro de div.

🔹 Filho Direto

div > p{
  color:blue;
}

➡ Apenas p filho direto de div.

🔹 Irmão Adjancente

h1 + p{
  color:green;
}

➡ Primeiro p logo após h1.

🔹 Atributo

Seleciona pelo atributo HTML.

input[type="text"]{
  border:1px solid black;
}

✨ Pseudo-classes

Mudam estado do elemento.

button:hover{
  background:red;
}

Exemplos:

  • :hover → mouse em cima
  • :focus → clicado/campo ativo
  • :first-child
  • :last-child

🎨 Pseudo-elementos

Selecionam parte do elemento.

p::first-letter{
  font-size:30px;
}

Exemplos:

  • ::before
  • ::after
  • ::first-letter
  • ::first-line

🔥 Exemplo real

body{
  margin:0;
}

#menu{
  background:black;
}

.link{
  color:white;
}

.link:hover{
  color:yellow;
}

✅ Resumo Final

Seletores CSS servem para dizer quem vai receber o estilo.

Os principais são:

  • tag → p
  • classe → .card
  • id → #menu
  • pseudo-classe → :hover

No desenvolvimento real, os mais usados são classe + hover + descendentes.
