Unidades de medida CSS

As unidades de medida em CSS servem para definir tamanhos, espaçamentos, posições e proporções dos elementos da página. Elas podem ser usadas em propriedades como:

  • width / height
  • margin / padding
  • font-size
  • border-radius
  • top, left, right, bottom
  • gap
  • max-width, min-height
  • entre outras

📏 Tipos de unidades CSS

🔹 1. Unidades Absolutas

São medidas fixas, que não mudam de acordo com tela ou elemento.

Principais:

  • px = pixels
    A mais usada. Define tamanho exato.
width: 300px;
font-size: 16px;

➡ Boa para controle preciso.

  • cm, mm, in (polegada), pt (ponto), pc

Mais comuns em impressão do que em sites.

width: 5cm;
font-size: 12pt;

➡ Pouco usadas na web moderna.

🔹 2. Unidades Relativas

Dependem de outro valor (tela, fonte, elemento pai etc). São melhores para responsividade.

🔸 em

Relativa ao tamanho da fonte do elemento pai.

font-size: 2em;

Se o pai tem 16px:

➡ 2em = 32px

Muito usada em espaçamentos também.

🔸 rem

Relativa ao tamanho da fonte raiz (html).

font-size: 2rem;

Se html { font-size:16px }

➡ 2rem = 32px

✅ Melhor que em para manter padrão geral.

🔸 %

Porcentagem do tamanho do elemento pai.

width: 50%;

➡ Metade da largura do pai.

Muito usada em layouts.

🔸 vw

Relativo à largura da tela (viewport width)

width: 50vw;

➡ 50% da largura da tela.

🔸 vh

Relativo à altura da tela.

height: 100vh;

➡ Tela inteira de altura.

Muito usada em páginas de entrada.

🔸 vmin / vmax

  • vmin = menor valor entre largura e altura da tela
  • vmax = maior valor
font-size: 5vmin;

🔹 Onde usar cada uma?

📌 Fontes

  • px → controle fixo
  • rem → recomendado
  • em → componentes internos
font-size: 1.2rem;

📌 Espaçamento (margin/padding)

  • px
  • rem
  • %
padding: 1rem;
margin: 20px;

📌 Largura / altura

  • %
  • vw
  • vh
  • px
width: 80%;
height: 100vh;

📌 Bordas arredondadas

border-radius: 10px;
border-radius: 50%;

🔥 Mais usadas no dia a dia

UnidadeUso
pxtamanhos fixos
%largura flexível
remfontes e espaçamentos
emescalável dentro do componente
vwlargura da tela
vhaltura da tela

✅ Recomendação moderna

Use bastante:

  • rem para fontes
  • % para layouts
  • vw/vh para telas
  • px para detalhes pequenos

Exemplo real

.container{
  width:80%;
  padding:2rem;
}

h1{
  font-size:3vw;
}

button{
  padding:10px20px;
  border-radius:8px;
}

Resumo final

Unidades CSS definem tamanhos.

As absolutas (px) são fixas.

As relativas (%, rem, vw) se adaptam melhor.

Hoje em dia, combinar unidades diferentes é o ideal para criar sites responsivos.
