Tags Semânticas

As tags header, nav, main e footer são tags semânticas do HTML5, ou seja, ajudam a organizar melhor a estrutura do site e facilitam leitura do código, SEO e acessibilidade.

🔹 <header>

Representa o cabeçalho da página ou de uma seção.

Geralmente contém:

  • título do site
  • logo
  • menu principal
  • barra de busca
  • introdução
<header>
<h1>Meu Site</h1>
</header>

📌 Pode existir mais de um header na página (ex: cabeçalho geral e cabeçalho de um artigo).

🔹 <nav>

Representa uma área de navegação, com links para outras páginas ou seções.

Usado para:

  • menu principal
  • menu lateral
  • links internos
<nav>
<a href="#">Início</a>
<a href="#">Sobre</a>
<a href="#">Contato</a>
</nav>

📌 Nem todo grupo de links precisa ser nav, apenas os importantes para navegação.

🔹 <main>

Representa o conteúdo principal da página.

É a parte única da página, excluindo:

  • cabeçalho
  • rodapé
  • menus laterais repetidos
<main>
<h2>Bem-vindo</h2>
<p>Conteúdo principal aqui.</p>
</main>

📌 Deve existir apenas um <main> por página.

🔹 <footer>

Representa o rodapé da página ou de uma seção.

Normalmente contém:

  • direitos autorais
  • contato
  • links extras
  • redes sociais
  • autor
<footer>
<p>© 2026 Meu Site</p>
</footer>

📌 Também pode existir mais de um footer.

🔥 Estrutura completa

<body>

<header>
<h1>Minha Página</h1>
</header>

<nav>
<a href="#">Home</a>
<a href="#">Produtos</a>
</nav>

<main>
<p>Conteúdo principal</p>
</main>

<footer>
<p>Rodapé</p>
</footer>

</body>

TagFunção

navNavegação/menu
mainConteúdo principal
footerRodapé

Essas tags podem ser independentes ou ficar dentro de outras tags, depende da estrutura da página. O objetivo delas é organizar semanticamente o conteúdo.

🔥 Regra geral:

Você usa onde fizer sentido no conteúdo.

🔹 <section>

Normalmente fica dentro do <main>, <article> ou até dentro de outra section.

Exemplo:

<main>
<section>
<h2>Sobre</h2>
<p>Texto...</p>
</section>

<section>
<h2>Contato</h2>
<p>Texto...</p>
</section>
</main>

📌 Serve para dividir partes da página.

🔹 <article>

Geralmente fica dentro de <main> ou <section>.

Exemplo blog:

<main>
<article>
<h2>Post 1</h2>
<p>Texto...</p>
</article>

<article>
<h2>Post 2</h2>
<p>Texto...</p>
</article>
</main>

📌 Cada article é algo independente.

🔹 <aside>

Normalmente fica ao lado de <main>, dentro dele, ou dentro de um article.

Exemplo:

<main>
<article>
<h2>Notícia</h2>
<p>Texto...</p>
</article>

<aside>
<h3>Leia também</h3>
<p>Outras notícias</p>
</aside>
</main>

📌 É conteúdo complementar.

🔹 <time>

Essa é diferente: ela costuma ficar dentro de textos, articles, sections etc.

<article>
<h2>Evento</h2>
<p>Data:<time datetime="2026-05-13">13/05/2026</time></p>
</article>

📌 Quase sempre usada dentro de outro elemento.

✅ Estrutura real

<body>

<header>...</header>
<nav>...</nav>

<main>

<section>
<article>
<h2>Título</h2>
<p>Publicado em<time>13/05</time></p>
</article>
</section>

<aside>
    Links extras
</aside>

</main>

<footer>...</footer>

</body>

🎯 Resumão

TagOnde usar
sectionDentro de main/article
articleDentro de main/section
asideDentro ou ao lado do main/article
timeDentro de textos

🔥 Pensamento fácil:

  • main = conteúdo principal
  • section = dividir partes
  • article = conteúdo completo
  • aside = conteúdo extra
  • time = datas/horas no texto
