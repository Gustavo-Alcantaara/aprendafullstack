z-index

z-index no CSS controla a ordem de empilhamento dos elementos, ou seja, quem fica na frente e quem fica atrás quando dois ou mais elementos se sobrepõem.

Pense no eixo Z como profundidade:

  • eixo X = horizontal
  • eixo Y = vertical
  • eixo Z = frente/trás

Sintaxe básica

z-index:valor;

Exemplo:

.caixa1 {
  z-index:1;
}

.caixa2 {
  z-index:2;
}

A .caixa2 ficará na frente da .caixa1.

Importante: precisa de position

Na maioria dos casos, z-index só funciona em elementos com:

position:relative;
position:absolute;
position:fixed;
position:sticky;

Exemplo:

.modal {
  position:fixed;
  z-index:999;
}

Valores possíveis

Número maior = mais na frente

z-index: 10;

fica na frente de:

z-index: 5;

Pode usar negativos

z-index: -1;

O elemento pode ficar atrás de outros.

auto (padrão)

z-index:auto;

Usa a ordem normal do HTML.

Exemplo prático

.menu {
  position:fixed;
  z-index:1000;
}

.banner {
  position:relative;
  z-index:1;
}

O menu ficará sobre o banner.

Muito usado em:

  • menus fixos
  • modais
  • popups
  • dropdowns
  • tooltips
  • overlays
  • elementos decorativos

Resumo rápido

ValorResultado
maior númeromais na frente
menor númeromais atrás
negativoatrás de outros
autopadrão

Dica importante

Às vezes z-index: 9999 não funciona porque o problema está no elemento pai ou no contexto de empilhamento (stacking context).

Exemplo:

.pai {
  position:relative;
  z-index:1;
}

O filho fica limitado ao pai.

Resumo final

z-index serve para controlar qual elemento aparece por cima de outro quando há sobreposição.

Exemplo clássico

.modal {
  position:fixed;
  z-index:999;
}

Faz a janela modal aparecer acima do site.
