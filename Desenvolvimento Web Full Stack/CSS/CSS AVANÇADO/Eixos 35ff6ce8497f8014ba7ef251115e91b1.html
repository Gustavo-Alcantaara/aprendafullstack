Eixos

No Flexbox, os elementos são organizados usando dois eixos principais:

  • Eixo principal (main axis)
  • Eixo cruzado (cross axis)

Entender isso é essencial para usar justify-content e align-items.

🔹 1. Eixo Principal (Main Axis)

É a direção em que os itens ficam alinhados.

Por padrão:

flex-direction:row;

➡️ O eixo principal fica horizontal (da esquerda para direita).

Exemplo:

[ item ] [ item ] [ item ]

🔹 2. Eixo Cruzado (Cross Axis)

É o eixo oposto ao principal.

Se o principal está horizontal, o cruzado será vertical.

🔥 Propriedades ligadas aos eixos

justify-content

Alinha no eixo principal

justify-content:center;

Centraliza no eixo principal.

align-items

Alinha no eixo cruzado

align-items:center;

Centraliza no eixo cruzado.

🔥 Exemplo real

.container {
  display:flex;
  justify-content:center;
  align-items:center;
}

Resultado: itens centralizados no meio da caixa.

✅ Resumo rápido

ConceitoDireção padrão
Main AxisHorizontal
Cross AxisVertical

🎯 Regra de ouro

Se flex-direction: row

  • justify-content = horizontal
  • align-items = vertical

Se flex-direction: column

  • justify-content = vertical
  • align-items = horizontal

💡 Pensamento fácil

justify = acompanha a direção dos itens

align = atravessa a direção dos itens
