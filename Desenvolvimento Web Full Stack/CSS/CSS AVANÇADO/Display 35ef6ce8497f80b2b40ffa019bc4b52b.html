Display

display no CSS define como um elemento será exibido na página e como ele se comporta no layout (ocupação de espaço, alinhamento, quebra de linha, etc.).

Principais valores de display

block

O elemento ocupa toda a largura disponível e quebra linha antes e depois.

Exemplos: div, p, h1

div {
  display:block;
}

✔ Pode definir largura, altura, margem e padding normalmente.

inline

O elemento fica na mesma linha de outros elementos e ocupa só o espaço do conteúdo.

Exemplos: span, a, strong

span {
  display:inline;
}

✔ Não quebra linha

❌ width e height geralmente não funcionam

inline-block

Mistura dos dois anteriores: fica na mesma linha, mas aceita largura e altura.

button {
  display:inline-block;
}

✔ Muito usado em botões e menus.

none

O elemento some da tela e não ocupa espaço.

.menu {
  display:none;
}

✔ Muito usado para esconder menus, modais, etc.

Layout modernos

flex

Transforma o elemento em container flexível, ótimo para alinhar itens.

.container {
  display:flex;
}

Permite:

  • alinhar horizontalmente
  • alinhar verticalmente
  • espaçar elementos
  • inverter ordem

Propriedades comuns:

justify-content
align-items
gap
flex-direction

grid

Cria um layout em grade (linhas e colunas).

.container {
  display:grid;
}

Muito usado para:

  • galerias
  • dashboards
  • páginas organizadas

Exemplo:

grid-template-columns: 1fr 1fr 1fr;
gap: 10px;

Outros valores úteis

contents

O elemento some visualmente, mas os filhos permanecem.

list-item

Faz o elemento agir como item de lista.

Resumo rápido

ValorComportamento
blockocupa linha toda
inlinefica na mesma linha
inline-blockmesma linha + aceita tamanho
noneesconde elemento
flexlayout flexível
gridlayout em grade

Dica prática

Hoje em dia os mais usados são:

  • block
  • inline
  • flex
  • grid
  • none

Exemplo real

.menu {
  display:flex;
  justify-content:space-between;
}

Cria um menu com itens separados.
