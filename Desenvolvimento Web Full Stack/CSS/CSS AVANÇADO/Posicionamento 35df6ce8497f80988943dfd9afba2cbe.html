Posicionamento

O posicionamento em CSS define como os elementos ficam organizados na página e como podem ser movidos em relação ao fluxo normal do documento.

Com ele, você controla onde cada item aparece: lado a lado, fixo na tela, sobreposto, centralizado etc.

🎯 Propriedade principal: position

A propriedade position determina o tipo de posicionamento do elemento.

position:valor;

Valores principais:

  • static
  • relative
  • absolute
  • fixed
  • sticky

🔹 1. static (padrão)

Todo elemento já vem com position: static.

div{
  position:static;
}

➡ Fica no fluxo normal da página.

➡ top, left, right, bottom não funcionam.

🔹 2. relative

Move o elemento a partir da posição original, sem tirar ele do fluxo.

div{
  position:relative;
  top:20px;
  left:30px;
}

➡ O espaço original continua reservado.

🔹 3. absolute

Tira o elemento do fluxo normal e posiciona livremente.

div{
  position:absolute;
  top:0;
  right:0;
}

➡ Fica relativo ao pai posicionado (relative, absolute, etc).

➡ Se não houver pai posicionado, usa a página.

🔹 4. fixed

Fica preso na tela mesmo rolando a página.

header{
  position:fixed;
  top:0;
  left:0;
}

➡ Muito usado em menus fixos.

🔹 5. sticky

Mistura relative + fixed.

nav{
  position:sticky;
  top:0;
}

➡ Normal no começo, fixa quando chega no topo ao rolar.

📏 Propriedades de posição

Funcionam com relative, absolute, fixed, sticky.

top
right
bottom
left

Exemplo:

top: 10px;
left: 20px;

🔢 Camadas: z-index

Controla quem fica na frente.

.box1{
  z-index:1;
}

.box2{
  z-index:2;
}

➡ Quanto maior, mais na frente.

Necessita elemento posicionado.

🔥 Exemplo completo

.container{
  position:relative;
}

.botao{
  position:absolute;
  bottom:10px;
  right:10px;
}

➡ O botão ficará no canto inferior direito da .container.

stickycabeçalho que gruda

🎯 Dica moderna

Para layouts principais, hoje se usa mais:

  • display: flex
  • display: grid

E position fica mais para:

  • menus fixos
  • badges
  • ícones
  • overlays
  • elementos sobrepostos

✅ Resumo Final

O posicionamento em CSS controla onde os elementos ficam.

Mais importantes:

  • relative → referência
  • absolute → livre dentro do pai
  • fixed → preso na tela
  • sticky → gruda ao rolar

Combinando isso com top, left e z-index, você controla praticamente qualquer posição na página.
