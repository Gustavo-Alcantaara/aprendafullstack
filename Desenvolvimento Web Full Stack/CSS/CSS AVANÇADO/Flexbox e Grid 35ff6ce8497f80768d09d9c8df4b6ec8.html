Flexbox e Grid

Flexbox e Grid são sistemas de layout do CSS usados para organizar elementos na página de forma moderna e responsiva.

  • Flexbox = ideal para organizar itens em uma direção (linha OU coluna).
  • Grid = ideal para layouts em duas dimensões (linhas E colunas).

🔹 Flexbox

Usado quando você quer alinhar, distribuir espaço e organizar itens em sequência.

Para ativar:

.container {
  display:flex;
}

Principais propriedades:

No container pai:

PropriedadeFunção
display: flexAtiva flexbox
flex-directionDireção dos itens
justify-contentAlinha no eixo principal
align-itemsAlinha no eixo cruzado
flex-wrapQuebra linha

Exemplos:

display:flex;
flex-direction:row;

Itens lado a lado.

flex-direction:column;

Itens em coluna.

justify-content:center;

Centraliza horizontalmente.

align-items:center;

Centraliza verticalmente.

Exemplo completo:

.container {
  display:flex;
  justify-content:center;
  align-items:center;
  gap:10px;
}

🔹 Grid

Usado para criar layouts com linhas e colunas.

Ativar:

.container {
  display:grid;
}

Principais propriedades:

PropriedadeFunção
grid-template-columnsNúmero/largura colunas
grid-template-rowsAltura linhas
gapEspaço entre itens
justify-itemsAlinha horizontalmente
align-itemsAlinha verticalmente

Exemplo:

.container {
  display:grid;
  grid-template-columns:1fr1fr1fr;
}

Cria 3 colunas iguais.

Outro exemplo:

.container {
  display:grid;
  grid-template-columns:repeat(3,1fr);
  gap:10px;
}

💡 Dica profissional

Use os dois juntos:

  • Grid para estrutura geral da página
  • Flexbox dentro dos elementos

Exemplo:

Página = Grid
Menu interno = Flexbox
Cards = Flexbox

🔥 Se decorar só isso:

  • Flex = linha ou coluna
  • Grid = linhas + colunas
