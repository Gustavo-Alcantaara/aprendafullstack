Instalação do Git

Introdução

Antes de utilizar o Git para controlar versões de projetos, é necessário instalá-lo no computador. A instalação é simples e está disponível para os principais sistemas operacionais: Windows, Linux e macOS.

Após a instalação, o Git pode ser utilizado tanto por meio da linha de comando (Git Bash ou Terminal) quanto integrado a diversas IDEs e editores de código, como Visual Studio Code, IntelliJ IDEA, Eclipse e outros.

Além da instalação, também é importante realizar uma configuração inicial, informando seu nome e e-mail, que serão associados aos commits.

Requisitos para Instalação

O Git possui requisitos mínimos e funciona na maioria dos computadores modernos.

Sistemas Operacionais Suportados

  • Windows 10 ou superior (também funciona em versões anteriores)
  • Linux (Ubuntu, Debian, Fedora, Arch, entre outras)
  • macOS

Instalando o Git no Windows

O Windows não possui o Git instalado por padrão.

Passo 1 – Baixar o Instalador

Acesse o site oficial do Git:

Git Downloads

O site identifica automaticamente o sistema operacional.

Passo 2 – Executar o Instalador

Após o download:

  • Clique duas vezes no arquivo baixado.
  • O assistente de instalação será aberto.

Passo 3 – Escolher o Diretório

Normalmente utiliza-se:

C:\Program Files\Git

Pode manter o diretório padrão.

Passo 4 – Selecionar Componentes

As opções padrão costumam ser suficientes.

Alguns componentes importantes:

  • Git Bash
  • Git GUI
  • Integração com Windows Explorer
  • Arquivos de documentação
  • Ícones

Na maioria dos casos, basta clicar em Next.

Passo 5 – Escolher o Editor Padrão

O Git utiliza um editor para escrever mensagens de commit mais longas, resolver conflitos e editar configurações.

As opções mais comuns são:

  • Visual Studio Code
  • Vim
  • Nano
  • Notepad++

Se você utiliza o Visual Studio Code, ele costuma ser a melhor opção.

Passo 6 – Escolher o Nome da Branch Inicial

Durante a instalação pode aparecer a opção:

Default branch name

Atualmente recomenda-se utilizar:

main

Em versões antigas era comum utilizar:

master

Hoje, a maioria dos serviços utiliza main como padrão.

Passo 7 – Configurar o PATH

A opção recomendada é:

Git from the command line and also from 3rd-party software

Essa configuração permite executar comandos Git no:

  • Prompt de Comando (CMD)
  • PowerShell
  • Terminal do VS Code
  • Git Bash

Passo 8 – Escolher o SSH

A recomendação para iniciantes é manter:

Use bundled OpenSSH

Passo 9 – Biblioteca HTTPS

Deixe selecionado:

Use the OpenSSL library

Passo 10 – Finalizar

Clique em:

Install

Após alguns segundos, a instalação será concluída.

Instalando o Git no Linux

Em muitas distribuições Linux, o Git já vem instalado.

Para verificar:

git --version

Se o comando retornar a versão instalada, nenhuma instalação adicional é necessária.

Ubuntu/Debian

Atualize a lista de pacotes:

sudo apt update

Instale o Git:

sudo apt install git

Verifique:

git --version

Fedora

sudo dnf install git

Arch Linux

sudo pacman -S git

openSUSE

sudo zypper install git

Instalando o Git no macOS

O Git pode ser instalado de diferentes formas.

Usando o Homebrew

Se o Homebrew estiver instalado:

brew install git

Depois:

git --version

Usando o Xcode Command Line Tools

Outra opção é executar:

git

Caso o Git não esteja instalado, o sistema oferecerá a instalação das ferramentas de linha de comando do Xcode, que incluem o Git.

Verificando a Instalação

Após instalar, abra o terminal ou Git Bash e execute:

git --version

Exemplo de saída:

git version 2.51.0

Se a versão for exibida, o Git foi instalado corretamente.

Primeira Configuração do Git

Após a instalação, configure sua identidade.

Configurando o Nome

git config --global user.name "João Silva"

Exemplo:

git config --global user.name "Maria Oliveira"

Configurando o E-mail

git config --global user.email "email@exemplo.com"

Exemplo:

git config --global user.email "maria@email.com"

Essas informações aparecerão como autoria dos commits.

Configuração Global x Local

O Git possui diferentes níveis de configuração.

Global

Vale para todos os projetos do computador.

git config --global user.name "João"

Local

Vale apenas para um repositório específico.

git config user.name "Equipe Backend"

Verificando as Configurações

Para listar todas as configurações:

git config --list

Saída de exemplo:

user.name=Maria Oliveira
user.email=maria@email.com
core.editor=code --wait
init.defaultBranch=main

Alterando uma Configuração

Caso seja necessário alterar o e-mail:

git config --global user.email "novo@email.com"

Ou o nome:

git config --global user.name "Novo Nome"

A nova configuração substituirá a anterior.

Onde as Configurações São Armazenadas?

No nível global, as configurações ficam em um arquivo de configuração do usuário:

Windows

C:\Users\SeuUsuario\.gitconfig

Linux e macOS

~/.gitconfig

Esse arquivo pode ser editado manualmente, embora o uso do comando git config seja o mais recomendado.

O Git Bash

O Git Bash é instalado junto com o Git no Windows.

Ele oferece um terminal semelhante ao do Linux, permitindo executar comandos Git e diversos comandos Unix, como:

pwd
ls
cd
mkdir
rm
cp
mv

Isso facilita o uso de tutoriais e comandos que funcionam da mesma forma em Linux e macOS.

Integrando o Git ao Visual Studio Code

Após instalar o Git:

  1. Abra o Visual Studio Code.
  1. Abra um projeto.
  1. Abra o terminal integrado (`Ctrl + ``).
  1. Digite:
git --version

Se a versão aparecer, a integração está funcionando corretamente.

Além disso, o VS Code reconhece automaticamente repositórios Git, exibindo alterações, permitindo criar commits e gerenciar branches pela interface gráfica.

Problemas Comuns na Instalação

"git is not recognized"

Mensagem comum no Windows:

'git' is not recognized as an internal or external command

Possíveis causas:

  • Git não foi instalado.
  • O PATH não foi configurado corretamente.
  • É necessário reiniciar o terminal após a instalação.

Versão Antiga

Se o comando mostrar uma versão muito antiga, recomenda-se baixar a versão mais recente no site oficial e atualizar a instalação.

Permissão Negada no Linux

Se ocorrer erro de permissão durante a instalação, verifique se o comando foi executado com sudo (quando necessário) e se o gerenciador de pacotes está configurado corretamente.

Boas Práticas

  • Baixe o Git sempre do site oficial ou pelos gerenciadores de pacotes da sua distribuição.
  • Configure user.name e user.email logo após a instalação.
  • Verifique a instalação com git --version.
  • Utilize um editor moderno, como o Visual Studio Code, para facilitar o trabalho com o Git.
  • Mantenha o Git atualizado para obter correções de segurança e novos recursos.

Erros Comuns

  • Esquecer de configurar nome e e-mail antes do primeiro commit.
  • Instalar o Git sem adicioná-lo ao PATH no Windows.
  • Confundir o Git com o GitHub: o Git é instalado no computador; o GitHub é uma plataforma para hospedar repositórios Git.
  • Editar manualmente o arquivo .gitconfig sem necessidade.

Resumo

A instalação do Git é o primeiro passo para utilizar controle de versão em projetos de software. O processo varia conforme o sistema operacional, mas em todos os casos é importante verificar a instalação com git --version e configurar user.name e user.email antes de começar a trabalhar. Com o Git instalado e configurado, você estará preparado para criar repositórios, registrar alterações com commits e colaborar em projetos de forma eficiente.
