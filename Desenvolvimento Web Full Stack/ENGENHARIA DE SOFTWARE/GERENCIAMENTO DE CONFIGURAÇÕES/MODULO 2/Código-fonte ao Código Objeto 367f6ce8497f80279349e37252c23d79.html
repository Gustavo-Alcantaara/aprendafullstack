Código-fonte ao Código Objeto

A ligação entre código-fonte e código-objeto é uma etapa do processo de construção de software que transforma o código escrito pelo programador em um formato executável pelo computador.

O que é código-fonte

É o código escrito pelo desenvolvedor em uma linguagem de programação, como:

  • Java
  • C
  • Python
  • JavaScript

Ele é legível para humanos, mas não diretamente executável pela máquina.

O que é código-objeto

O código-objeto é o resultado da tradução do código-fonte, geralmente em formato intermediário ou binário.

  • Não é legível para humanos
  • Já está mais próximo da linguagem de máquina
  • Ainda pode precisar de etapas finais para virar executável

O que é a ligação (linking)

A ligação (linking) é o processo que une o código-objeto com outras partes necessárias para formar um programa executável.

Tipos de ligação

1. Ligação estática

  • O código das bibliotecas é incorporado ao executável
  • O programa fica maior
  • Não depende de bibliotecas externas na execução

2. Ligação dinâmica

  • As bibliotecas são carregadas durante a execução
  • O programa fica menor
  • Depende de arquivos externos no sistema

Etapas relacionadas ao processo completo

  1. Código-fonte é escrito pelo programador
  1. O compilador transforma o código-fonte em código-objeto
  1. O linker (ligador) conecta os códigos-objeto e bibliotecas
  1. É gerado o código executável

Exemplo simples

Em um programa em C:

  • O arquivo .c é o código-fonte
  • O compilador gera arquivos .o (código-objeto)
  • O linker junta tudo e cria o executável final

Objetivo da ligação

  • Criar um programa executável funcional
  • Resolver referências entre arquivos e bibliotecas
  • Garantir que todas as partes do sistema funcionem juntas

Resumo

A ligação do código-fonte ao código-objeto é o processo que conecta e organiza os arquivos gerados pela compilação, juntando tudo com bibliotecas necessárias para formar o programa executável final.
