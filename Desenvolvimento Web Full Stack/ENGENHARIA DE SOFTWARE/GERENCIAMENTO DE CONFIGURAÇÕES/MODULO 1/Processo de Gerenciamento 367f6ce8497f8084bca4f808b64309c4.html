Processo de Gerenciamento

O Processo de Gerenciamento de Configuração de Software é um conjunto de atividades usadas para controlar e organizar todas as mudanças feitas nos artefatos de um sistema ao longo do seu ciclo de vida.

Ele garante que o software evolua de forma controlada, sem perder consistência entre versões, arquivos e documentos.

O que esse processo envolve

Ele cobre tudo o que precisa ser controlado no software, como:

  • Código-fonte
  • Documentação
  • Requisitos
  • Scripts de banco de dados
  • Arquivos de configuração
  • Versões do sistema

Objetivo principal

O principal objetivo é manter o software:

  • organizado
  • rastreável
  • consistente
  • seguro contra alterações descontroladas
  • recuperável em versões anteriores

Etapas do processo de gerenciamento de configuração

1. Identificação da configuração

Define quais itens serão controlados (os Itens de Configuração).

Exemplo: código, documentos, banco de dados.

2. Controle de versões

Cada item passa a ter versões controladas.

Exemplo:

  • versão 1.0
  • versão 1.1
  • versão 2.0

3. Controle de mudanças

Qualquer alteração precisa seguir um fluxo:

  • solicitação da mudança
  • análise do impacto
  • aprovação ou rejeição
  • implementação

4. Registro de status da configuração

Cada item tem um estado, como:

  • em desenvolvimento
  • em teste
  • aprovado
  • em produção

5. Auditoria de configuração

Verifica se tudo está correto e se as mudanças foram aplicadas conforme o processo.

Exemplo:

  • conferir se o código em produção é o mesmo aprovado

6. Controle de liberação (release)

Define como o sistema será entregue ao usuário.

Exemplo:

  • versão 1.0 liberada para produção
  • versão 2.0 em teste

Ferramentas comuns

  • Git (controle de versão)
  • GitHub / GitLab / Bitbucket
  • Jenkins (integração e entrega contínua)
  • Docker (ambientes padronizados)

Exemplo prático

Em um sistema de e-commerce:

  • O código do carrinho de compras é alterado
  • Essa mudança passa por aprovação
  • Uma nova versão é criada
  • A versão é testada
  • Depois é liberada para produção

Tudo isso segue o processo de gerenciamento de configuração.

Resumo

O processo de gerenciamento de configuração de software é o conjunto de etapas que controla, organiza e rastreia todas as mudanças feitas em um sistema, garantindo estabilidade, consistência e controle durante todo o ciclo de vida do software.
