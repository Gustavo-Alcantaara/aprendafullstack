ICS

O que são Itens de Configuração (ICs)

Itens de configuração são todos os componentes do software que precisam ser controlados ao longo do projeto. Eles podem ser:

  • Código-fonte
  • Documentação (requisitos, manuais, especificações)
  • Arquivos de teste
  • Scripts de banco de dados
  • Configurações de ambiente
  • Bibliotecas e dependências
  • Versões do sistema

Esses itens são chamados de ICs porque qualquer alteração neles pode afetar o sistema como um todo.

O que é a Gestão de ICS

A gestão de ICS é o processo de:

  • Identificar quais itens serão controlados
  • Organizar esses itens de forma estruturada
  • Controlar versões e mudanças
  • Garantir rastreabilidade de tudo o que foi alterado
  • Manter consistência entre os diferentes componentes do sistema

Objetivos principais

  • Evitar perda de controle sobre o software
  • Garantir que todas as alterações sejam registradas
  • Permitir voltar a versões anteriores quando necessário
  • Facilitar o trabalho em equipe sem conflitos
  • Manter o sistema sempre consistente e funcional

Como funciona na prática

Na prática, a gestão de ICS envolve:

  1. Identificação dos itens de configuração
    Definir o que faz parte do controle (ex: código, docs, banco de dados)
  1. Controle de versão
    Cada alteração gera uma nova versão do item
  1. Controle de mudanças
    Toda alteração precisa ser solicitada, analisada e aprovada
  1. Status dos itens
    Cada item pode estar em estados como: em desenvolvimento, em revisão ou aprovado
  1. Auditoria e rastreabilidade
    É possível saber quem alterou, o que alterou e quando alterou

Exemplo simples

Em um sistema com login:

  • O código do login é um IC
  • O arquivo de configuração do banco é um IC
  • A documentação de segurança também é um IC

Se alguém muda a regra de autenticação, essa alteração precisa ser registrada e versionada.

Ferramentas usadas

  • Git (controle de versão)
  • GitHub / GitLab (repositórios e controle de mudanças)
  • Jenkins (integração contínua)
  • Sistemas de gerenciamento de configuração corporativos

Resumo

A Gestão de Itens de Configuração de Software é o processo que identifica, controla e monitora todos os componentes importantes de um sistema, garantindo organização, rastreabilidade e segurança durante todo o ciclo de vida do software.
