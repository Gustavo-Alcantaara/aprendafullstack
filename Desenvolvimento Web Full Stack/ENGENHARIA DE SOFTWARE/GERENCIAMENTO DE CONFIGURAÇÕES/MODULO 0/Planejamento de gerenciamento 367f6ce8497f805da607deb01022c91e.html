Planejamento de gerenciamento

⚙️ Planejamento de Gerenciamento de Configuração (Engenharia de Software)

O Planejamento de Gerenciamento de Configuração é uma atividade da Engenharia de Software que define como o sistema e seus artefatos serão controlados ao longo do projeto.

Em outras palavras: ele garante que tudo o que muda no software (código, versões, documentos) seja organizado, rastreado e controlado.

🧠 O que é Gerenciamento de Configuração?

É o processo de controlar as mudanças feitas em um software durante seu ciclo de vida, garantindo que o sistema continue estável e consistente.

📌 O que é o planejamento disso?

É a fase onde você define as regras do controle de mudanças antes do projeto começar ou no início dele.

🧱 O que esse planejamento define?

1. Itens de configuração (ICs)

São os elementos que serão controlados, como:

  • Código-fonte
  • Documentação
  • Banco de dados
  • Arquivos de configuração
  • Versões do sistema

2. Controle de versões

Define como as versões serão organizadas:

  • v1.0, v1.1, v2.0 etc.
  • Uso de ferramentas como Git

3. Controle de mudanças

Define como alterações serão feitas:

  • Quem pode alterar
  • Como solicitar mudanças
  • Como aprovar mudanças

4. Controle de integração

Garante que mudanças de várias pessoas não “quebrem” o sistema.

5. Ferramentas usadas

Exemplos comuns:

  • Git / GitHub / GitLab
  • Jenkins (integração contínua)
  • Docker (ambientes consistentes)

👥 Papéis no gerenciamento de configuração

  • Gerente de configuração: define e controla o processo
  • Desenvolvedores: aplicam as regras
  • Revisores: aprovam mudanças

🎯 Objetivo principal

Garantir que o software:

  • não perca controle de versões
  • não tenha mudanças conflitantes
  • seja rastreável (saber quem mudou o quê e quando)
  • possa ser recuperado em versões anteriores

🔥 Resumo rápido

O planejamento de gerenciamento de configuração define como o projeto vai controlar versões, mudanças e arquivos do sistema, evitando caos no desenvolvimento e garantindo organização e segurança.
