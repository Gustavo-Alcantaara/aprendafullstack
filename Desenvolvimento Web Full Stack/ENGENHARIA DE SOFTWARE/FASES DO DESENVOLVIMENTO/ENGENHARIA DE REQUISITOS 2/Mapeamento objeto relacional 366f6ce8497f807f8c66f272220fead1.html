Mapeamento Objeto-Relacional (ORM)

O Mapeamento Objeto-Relacional é uma técnica usada para conectar a programação orientada a objetos com bancos de dados relacionais.

Ele resolve o chamado:

“impedância objeto-relacional”

ou seja, a diferença entre:

  • objetos da aplicação
  • tabelas do banco de dados

Ideia Principal

Em programação orientada a objetos usamos:

  • classes
  • objetos
  • herança
  • encapsulamento

Já bancos relacionais usam:

  • tabelas
  • linhas
  • colunas
  • relacionamentos

O ORM faz a conversão automática entre esses dois mundos.

Exemplo Básico

Classe na aplicação

classUsuario {
intid;
Stringnome;
Stringemail;
}

Tabela no banco

idnomeemail
1Gustavogustavo@email.com

O ORM faz o mapeamento:

  • classe → tabela
  • objeto → linha
  • atributo → coluna

Objetivos do ORM

  • facilitar acesso ao banco
  • reduzir SQL manual
  • aumentar produtividade
  • integrar POO ao banco relacional
  • melhorar manutenção
  • reduzir repetição de código

Como funciona o ORM

O desenvolvedor trabalha com objetos da linguagem.

O framework ORM:

  • gera SQL automaticamente
  • executa consultas
  • salva objetos
  • atualiza registros
  • remove dados

Mapeamentos Principais

Classe → Tabela

Cada classe representa uma tabela.

Exemplo:

Classe Usuario → tabela usuarios

Atributo → Coluna

nome → coluna nome
email → coluna email

Objeto → Registro

Cada objeto representa uma linha da tabela.

Relacionamentos no ORM

1. Um para Um (One-to-One)

Exemplo:

  • Usuário possui um Perfil
Usuario 1 ---- 1 Perfil

2. Um para Muitos (One-to-Many)

Exemplo:

  • Cliente possui vários pedidos
Cliente 1 ---- N Pedido

3. Muitos para Muitos (Many-to-Many)

Exemplo:

  • Alunos possuem várias disciplinas
  • Disciplinas possuem vários alunos
Aluno N ---- N Disciplina

Normalmente precisa de tabela intermediária.

Operações CRUD

Exemplo Conceitual

Criar usuário

usuario=Usuario(nome="Gustavo")
salvar(usuario)

O ORM transforma em SQL:

INSERTINTO usuarios (nome)VALUES ('Gustavo');

Chaves no ORM

Chave Primária (Primary Key)

Identifica registros únicos.

Exemplo:

id

Chave Estrangeira (Foreign Key)

Cria relacionamentos entre tabelas.

Exemplo:

pedido.cliente_id

Herança no ORM

O ORM também pode mapear herança da POO.

Estratégias comuns:

  • tabela única
  • tabela por classe
  • tabela por hierarquia

Conceitos Importantes

Persistência

Capacidade de salvar dados permanentemente.

Entidade

Classe que representa dados persistentes.

Exemplo:

  • Usuário
  • Produto
  • Pedido

Sessão/Contexto

Objeto responsável por controlar operações no banco.

Lazy Loading

Carrega dados apenas quando necessário.

Ajuda no desempenho.

Eager Loading

Carrega dados imediatamente.

Reduz consultas repetidas.

Resumo geral

O mapeamento objeto-relacional é uma técnica que integra programação orientada a objetos com bancos de dados relacionais.

Ele transforma:

  • classes em tabelas
  • objetos em registros
  • atributos em colunas

Seu objetivo é facilitar persistência de dados, aumentar produtividade e aproximar o modelo orientado a objetos do banco de dados relacional.
