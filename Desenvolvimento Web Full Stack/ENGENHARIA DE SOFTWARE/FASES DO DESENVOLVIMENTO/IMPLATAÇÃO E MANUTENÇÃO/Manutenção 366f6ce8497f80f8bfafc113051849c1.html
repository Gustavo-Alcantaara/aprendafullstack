Manutenção

Manutenção de Software

A Manutenção de Software é o processo de modificar, corrigir, adaptar ou melhorar um sistema após sua implantação.

Ela acontece porque softwares precisam:

  • corrigir erros
  • evoluir
  • adaptar-se a mudanças
  • melhorar desempenho
  • atender novas necessidades

Na prática, grande parte do ciclo de vida de um software é dedicada à manutenção.

Objetivos da Manutenção

  • corrigir falhas
  • melhorar qualidade
  • adaptar sistema a novos ambientes
  • adicionar funcionalidades
  • aumentar desempenho e segurança
  • prolongar vida útil do software

Importância da Manutenção

Mesmo após ser entregue, o software continua evoluindo.

Mudanças podem ocorrer por:

  • novos requisitos
  • atualização tecnológica
  • mudanças no negócio
  • falhas descobertas
  • melhorias solicitadas pelos usuários

Tipos de Manutenção

1. Manutenção Corretiva

Corrige erros e defeitos encontrados no sistema.

Exemplos:

  • bug no login
  • cálculo incorreto
  • falha no banco de dados

Objetivo:

restaurar funcionamento correto.

2. Manutenção Adaptativa

Adapta o software a mudanças externas.

Exemplos:

  • atualização de sistema operacional
  • mudança em API externa
  • nova legislação
  • migração para cloud

Objetivo:

manter compatibilidade do sistema.

3. Manutenção Evolutiva

Adiciona melhorias e novas funcionalidades.

Exemplos:

  • novo sistema de pagamento
  • dashboard administrativo
  • notificações em tempo real

Objetivo:

evoluir o software.

4. Manutenção Preventiva

Melhora estrutura interna para evitar problemas futuros.

Exemplos:

  • refatoração
  • otimização de código
  • atualização de bibliotecas

Objetivo:

reduzir riscos e facilitar manutenção futura.

Processo de Manutenção

1. Identificação do Problema

Detectar:

  • bugs
  • falhas
  • necessidade de melhoria

2. Análise

Avaliar:

  • impacto
  • causa
  • custo da alteração

3. Planejamento

Definir:

  • prioridade
  • cronograma
  • responsáveis

4. Implementação

Modificar o sistema.

5. Testes

Garantir que mudanças não causaram novos problemas.

Muito importante realizar:

  • testes de regressão

6. Implantação

Publicar alterações em produção.

Teste de Regressão

Muito utilizado na manutenção.

Objetivo:

verificar se alterações quebraram funcionalidades existentes.

Refatoração

Processo de melhorar código sem alterar comportamento.

Objetivos:

  • organização
  • desempenho
  • legibilidade
  • manutenção facilitada

Conceito associado ao Refactoring.

Dívida Técnica

Problemas acumulados por decisões rápidas ou código ruim.

Consequências:

  • dificuldade de manutenção
  • aumento de bugs
  • baixa produtividade

Manutenibilidade

Característica da Qualidade de Software relacionada à facilidade de modificar o sistema.

Um software manutenível possui:

  • código limpo
  • modularização
  • documentação
  • baixo acoplamento

Custos da Manutenção

A manutenção pode representar:

  • mais de 60% do custo total do software

Isso ocorre porque sistemas evoluem constantemente.

Resumo Geral

A manutenção de software é o processo de modificar e evoluir um sistema após sua implantação.

Ela envolve:

  • correções
  • adaptações
  • melhorias
  • prevenção de problemas

Seu objetivo é manter o software funcional, atualizado, seguro e alinhado às necessidades do negócio e dos usuários.
