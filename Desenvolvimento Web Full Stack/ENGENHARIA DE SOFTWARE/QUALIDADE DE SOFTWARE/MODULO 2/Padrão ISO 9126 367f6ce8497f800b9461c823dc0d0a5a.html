Padrão ISO 9126

O padrão ISO/IEC 9126 é uma norma internacional criada para definir um modelo de qualidade de software, ou seja, critérios para avaliar se um sistema possui boa qualidade tanto do ponto de vista técnico quanto do usuário.

Na Engenharia de Software, a ISO 9126 é muito importante porque ela ajuda a medir e analisar a qualidade do produto de software, servindo como referência para testes, validações e melhorias.

📌 O que é a ISO 9126?

A ISO/IEC 9126 define um conjunto de características e subcaracterísticas que um software deve ter para ser considerado de qualidade. Ela divide a qualidade em 6 grandes características principais.

⚙️ As 6 características da ISO 9126

1. Funcionalidade

Verifica se o software faz o que foi proposto corretamente.

Ex: cálculos corretos, regras de negócio funcionando.

2. Confiabilidade

Avalia se o sistema funciona sem falhas por um longo período.

Ex: estabilidade, recuperação após erros.

3. Usabilidade

Analisa se o sistema é fácil de usar e entender.

Ex: interface intuitiva, boa experiência do usuário.

4. Eficiência

Relaciona desempenho e uso de recursos.

Ex: rapidez, baixo consumo de memória e processamento.

5. Manutenibilidade

Verifica a facilidade de corrigir, atualizar e melhorar o software.

Ex: código organizado e bem estruturado.

6. Portabilidade

Avalia a capacidade do software de funcionar em diferentes ambientes.

Ex: Windows, Linux, mobile, nuvem.

🧩 Subcaracterísticas

Cada uma dessas categorias ainda pode ser dividida em aspectos menores, como:

  • precisão;
  • interoperabilidade;
  • segurança;
  • testabilidade;
  • adaptabilidade.

💻 Importância na Engenharia de Software

A ISO 9126 ajuda a:

  • definir critérios claros de qualidade;
  • padronizar avaliações de software;
  • orientar testes e validações;
  • melhorar o desenvolvimento de sistemas;
  • garantir que o software atenda às expectativas do usuário.

🔄 Atualização da norma

A ISO 9126 foi substituída pela ISO/IEC 25010, que é mais moderna e detalhada, mas seus conceitos ainda são amplamente estudados e usados como base.

🧾 Resumo final

A ISO 9126 é um modelo de qualidade de software que define seis características principais (funcionalidade, confiabilidade, usabilidade, eficiência, manutenibilidade e portabilidade). Ela serve para avaliar e garantir a qualidade de um sistema, ajudando na construção de softwares mais completos, estáveis e eficientes dentro da Engenharia de Software.
