ECMAScript 6 e POO

O ECMAScript 6 (ES6), também chamado de ECMAScript 2015 (ES2015), foi uma das maiores atualizações da linguagem JavaScript. Ele trouxe diversos recursos que tornaram o código mais moderno, legível e fácil de manter.

O que é ECMAScript?

ECMAScript é a especificação que define como o JavaScript deve funcionar. Em outras palavras:

  • ECMAScript = padrão da linguagem.
  • JavaScript = implementação desse padrão nos navegadores e ambientes como Node.js.

Principais novidades do ES6

1. let e const

Antes do ES6, as variáveis eram declaradas apenas com var.

const nome = "Gusta";
let idade = 21;

let

Permite alterar o valor:

let contador = 1;
contador = 2;

const

Não permite reatribuição:

const PI = 3.14;

// Erro
PI = 3.1415;

2. Arrow Functions

Uma forma mais curta de escrever funções.

Antes

function soma(a,b) {
return a + b;
}

ES6

const soma = (a,b) => a + b;

Outro exemplo:

const saudacao = nome => `Olá,${nome}!`;

3. Template Strings

Permitem interpolar variáveis diretamente em strings usando crases (`).

Antes

let nome = "Gusta";

console.log("Olá, "+nome);

ES6

let nome = "Gusta";

console.log(`Olá,${nome}`);

Também permitem múltiplas linhas:

let texto=`
Linha 1
Linha 2
Linha 3
`;

4. Destructuring

Permite extrair valores de objetos e arrays.

Objetos

const pessoa = {
    nome:"Gusta",
    idade:21
};

const { nome, idade }=pessoa;

console.log(nome);

Arrays

const numeros= [10,20,30];

const [a,b,c]=numeros;

5. Parâmetros Padrão

Defina valores padrão para parâmetros.

function saudar(nome = "Visitante") {
console.log(`Olá,${nome}`);
}

saudar();

Resultado:

Olá,Visitante

6. Operador Spread (...)

Espalha os elementos de um array ou objeto.

Arrays

const lista1 = [1,2,3];
const lista2 = [...lista1,4,5];

console.log(lista2);

Resultado:

[1,2,3,4,5]

Objetos

const pessoa = {
    nome:"Gusta"
};

const usuario = {
    ...pessoa,
    idade:21
};

7. Rest Parameters

Recebe vários argumentos em um único array.

function somar(...numeros) {
return numeros.reduce((total,n) => total + n,0);
}

console.log(somar(1,2,3,4));

Resultado:

10

8. Classes

Introduziu uma sintaxe mais organizada para Programação Orientada a Objetos.

class Pessoa {
    constructor(nome) {
this.nome = nome;
    }

    apresentar() {
console.log(`Meu nome é${this.nome}`);
    }
}

const pessoa = newPessoa("Gusta");
pessoa.apresentar();

9. Módulos

Permitem dividir o código em arquivos.

Exportando

export function soma(a,b) {
return a + b;
}

Importando

import {soma }from"./matematica.js";

10. Promises

Facilitam o trabalho com operações assíncronas.

const promessa = newPromise((resolve,reject) => {
resolve("Sucesso!");
});

promessa.then(resultado => {
console.log(resultado);
});

As Promises serviram de base para o async/await, que surgiu em versões posteriores.

Por que o ES6 foi tão importante?

Antes do ES6, muitos recursos precisavam ser implementados manualmente ou com bibliotecas externas. Com ele, o JavaScript ganhou:

  • Código mais limpo.
  • Melhor organização.
  • Mais produtividade.
  • Recursos modernos para aplicações web.
  • Base para frameworks como React, Angular e Vue.js.

Se você está estudando JavaScript, os recursos mais importantes para dominar primeiro são: let/const, template strings, arrow functions, destructuring, spread/rest, módulos e classes, pois eles aparecem em praticamente todos os projetos modernos.
