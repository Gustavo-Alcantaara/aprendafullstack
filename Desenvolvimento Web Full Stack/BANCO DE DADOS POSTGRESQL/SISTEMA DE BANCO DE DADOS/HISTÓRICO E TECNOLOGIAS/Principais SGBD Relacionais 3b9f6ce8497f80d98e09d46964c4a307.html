Principais SGBDs Relacionais

Os Sistemas Gerenciadores de Bancos de Dados Relacionais (SGBDs relacionais) são softwares responsáveis por criar, armazenar, organizar, consultar, modificar e proteger dados estruturados no modelo relacional.

Nesse modelo, os dados são normalmente organizados em tabelas, formadas por linhas e colunas, e as tabelas podem ser relacionadas por meio de chaves.

Exemplo:

Tabela clientes

idnomeemail
1Joãojoao@email.com
2Mariamaria@email.com

Tabela pedidos

idcliente_idvalor
1011250.00
1022180.00

O campo cliente_id pode estabelecer um relacionamento entre as duas tabelas.

1. O que é um SGBD Relacional?

Um SGBD Relacional é um software que permite administrar bancos de dados baseados no modelo relacional.

Ele fornece recursos para:

  • Criar bancos de dados;
  • Criar tabelas;
  • Inserir dados;
  • Consultar informações;
  • Alterar registros;
  • Excluir registros;
  • Criar relacionamentos;
  • Controlar usuários;
  • Definir permissões;
  • Fazer backups;
  • Recuperar dados;
  • Controlar transações;
  • Otimizar consultas.

A comunicação normalmente é feita por meio da SQL (Structured Query Language).

Exemplo:

SELECT *
FROM clientes;

2. Principais SGBDs relacionais

Entre os principais SGBDs relacionais estão:

  1. MySQL
  1. PostgreSQL
  1. Oracle Database
  1. Microsoft SQL Server
  1. MariaDB
  1. SQLite
  1. IBM Db2

Cada um possui características próprias e atende diferentes necessidades.

3. MySQL

O MySQL é um dos SGBDs relacionais mais conhecidos e utilizados no desenvolvimento de aplicações Web.

Ele utiliza SQL e possui grande integração com tecnologias de desenvolvimento Web.

É muito comum encontrar MySQL em aplicações desenvolvidas com:

  • PHP;
  • Java;
  • Python;
  • Node.js;
  • JavaScript;
  • C#.

Características

  • Código aberto;
  • Boa performance;
  • Fácil de aprender;
  • Grande comunidade;
  • Muito utilizado em hospedagem Web;
  • Suporte a transações;
  • Índices;
  • Chaves estrangeiras;
  • Replicação;
  • Procedimentos armazenados.

Exemplo

CREATE DATABASE loja;

USE loja;

CREATE TABLE produtos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100),
    preco DECIMAL(10,2)
);

Depois:

INSERT INTO produtos (nome, preco)
VALUES ('Notebook', 3500.00);

E:

SELECT * FROM produtos;

Onde é utilizado?

É bastante utilizado em:

  • Sites;
  • Sistemas Web;
  • E-commerce;
  • APIs;
  • Sistemas empresariais;
  • Aplicações de pequeno e grande porte.

4. PostgreSQL

O PostgreSQL é um SGBD relacional de código aberto conhecido por sua robustez, extensibilidade e conformidade com padrões SQL.

É frequentemente utilizado em aplicações que precisam de recursos avançados de banco de dados.

Características

  • Código aberto;
  • Excelente suporte a SQL;
  • Transações;
  • Integridade referencial;
  • Extensibilidade;
  • Views;
  • Triggers;
  • Funções;
  • Tipos de dados avançados;
  • Suporte a JSON/JSONB;
  • Recursos geoespaciais por meio de extensões como PostGIS.

Exemplo

CREATE TABLE funcionarios (
    id SERIAL PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    salario NUMERIC(10,2)
);

Consulta:

SELECT nome, salario
FROM funcionarios
WHERE salario > 3000;

Onde é utilizado?

Muito utilizado em:

  • Sistemas empresariais;
  • APIs;
  • Sistemas financeiros;
  • Aplicações Web;
  • Sistemas de análise de dados;
  • Aplicações que necessitam de recursos SQL avançados.

5. Oracle Database

O Oracle Database é um dos principais SGBDs utilizados em ambientes corporativos.

É desenvolvido pela Oracle.

Possui recursos voltados para ambientes que precisam de:

  • Alta disponibilidade;
  • Segurança;
  • Escalabilidade;
  • Grande volume de dados;
  • Processamento de transações;
  • Administração corporativa.

Características

  • Alta capacidade de processamento;
  • Controle avançado de transações;
  • Segurança;
  • Backup e recuperação;
  • Alta disponibilidade;
  • Replicação;
  • Particionamento;
  • Ferramentas administrativas avançadas.

O Oracle utiliza uma implementação própria da SQL chamada Oracle SQL, além de tecnologias como PL/SQL para programação no banco.

Exemplo:

SELECT nome, salario
FROM funcionarios
WHERE salario > 5000;

Onde é utilizado?

Principalmente em:

  • Grandes empresas;
  • Bancos;
  • Telecomunicações;
  • Governos;
  • Sistemas corporativos;
  • Sistemas críticos.

6. Microsoft SQL Server

O Microsoft SQL Server é o SGBD relacional desenvolvido pela Microsoft.

Possui forte integração com o ecossistema Microsoft.

É muito utilizado com:

  • .NET;
  • C#;
  • Windows Server;
  • Microsoft Azure;
  • Power BI.

Características

  • Transações;
  • Segurança;
  • Alta disponibilidade;
  • Backup e recuperação;
  • Ferramentas gráficas;
  • Procedures;
  • Triggers;
  • Views;
  • Índices;
  • Integração com ferramentas de análise.

Uma ferramenta bastante conhecida é o SQL Server Management Studio (SSMS).

Exemplo

CREATE TABLE clientes (
    id INT PRIMARY KEY,
    nome VARCHAR(100),
    email VARCHAR(150)
);

Consulta:

SELECT *
FROM clientes;

7. MariaDB

O MariaDB é um SGBD relacional de código aberto que surgiu como um fork do MySQL.

Ele mantém grande compatibilidade com o ecossistema MySQL, embora os dois projetos tenham evoluído de forma independente.

Características

  • Código aberto;
  • Compatibilidade com SQL;
  • Boa performance;
  • Suporte a transações;
  • Replicação;
  • Índices;
  • Chaves estrangeiras;
  • Diversos mecanismos de armazenamento.

É utilizado em:

  • Aplicações Web;
  • Sistemas empresariais;
  • Servidores Linux;
  • Hospedagem de sites.

8. SQLite

O SQLite é diferente dos SGBDs tradicionais porque é um banco de dados embutido (embedded).

Ele não precisa necessariamente de um servidor de banco de dados separado.

Os dados podem ser armazenados em um único arquivo.

Aplicação
    │
    ▼
SQLite
    │
    ▼
banco.db

Características

  • Leve;
  • Simples;
  • Código aberto;
  • Não exige servidor;
  • Fácil distribuição;
  • Suporte a SQL;
  • Banco armazenado em arquivo.

É muito utilizado em:

  • Aplicativos móveis;
  • Sistemas embarcados;
  • Aplicações desktop;
  • Protótipos;
  • Sistemas locais;
  • Testes.

9. IBM Db2

O IBM Db2 é um SGBD desenvolvido pela IBM.

É conhecido por sua utilização em ambientes corporativos e sistemas de grande escala.

Possui versões e tecnologias destinadas a diferentes ambientes computacionais.

Características

  • Alta disponibilidade;
  • Segurança;
  • Processamento de grandes volumes;
  • Transações;
  • Otimização;
  • Integração com ambientes corporativos.

É bastante associado a organizações que utilizam infraestrutura IBM e sistemas empresariais de grande porte.

13. SGBD × SQL

Também são conceitos diferentes.

SGBD é o software responsável por gerenciar o banco.

SQL é a linguagem utilizada para trabalhar com o banco.

Por exemplo:

SELECT *
FROM clientes;

O comando é SQL.

Quem interpreta e executa esse comando é o SGBD.

Identificam exclusivamente um registro.

Chaves estrangeiras

Criam relacionamentos entre tabelas.

cliente_id INT,
FOREIGN KEY (cliente_id)
REFERENCES clientes(id)

Índices

Ajudam a acelerar determinadas consultas.

CREATE INDEX idx_nome
ON clientes(nome);

Views

Criam consultas que podem ser utilizadas como uma espécie de tabela virtual.

CREATE VIEW clientes_ativos AS
SELECT *
FROM clientes
WHERE ativo = 1;

Triggers

Permitem executar ações automaticamente quando determinados eventos ocorrem.

Exemplo:

INSERT
   ↓

   ↓
Registrar alteração

Procedures

Permitem armazenar lógica diretamente no banco.

Transações

Permitem executar várias operações como uma unidade lógica.

BEGIN;

UPDATE contas
SET saldo = saldo - 500
WHERE id = 1;

UPDATE contas
SET saldo = saldo + 500
WHERE id = 2;

COMMIT;

Caso ocorra um problema, dependendo do SGBD e da situação, pode-se utilizar:

15. Como escolher um SGBD?

A escolha depende do projeto.

Para aprender SQL e desenvolvimento Web

MySQL é uma excelente opção.

Para recursos relacionais avançados

PostgreSQL é uma opção muito forte.

Para ambientes corporativos de grande escala

Oracle Database, SQL Server e Db2 são opções importantes.

Para aplicações locais e móveis

SQLite é extremamente conveniente.

Para aplicações que já utilizam o ecossistema MySQL

MariaDB pode ser uma alternativa interessante.

Resumo

Os SGBDs relacionais são softwares responsáveis por gerenciar bancos de dados estruturados no modelo relacional. Eles organizam informações principalmente em tabelas e permitem estabelecer relacionamentos entre elas utilizando chaves.

Entre os principais estão:

  • MySQL — muito utilizado em aplicações Web.
  • PostgreSQL — conhecido pelos recursos avançados e extensibilidade.
  • Oracle Database — muito utilizado em ambientes corporativos e críticos.
  • SQL Server — forte integração com o ecossistema Microsoft.
  • MariaDB — SGBD de código aberto derivado do projeto MySQL.
  • SQLite — leve e embutido, sem necessidade de um servidor separado.
  • IBM Db2 — voltado principalmente para ambientes corporativos e de grande escala.

Todos possuem diferenças de recursos, desempenho, administração, ecossistema e licenciamento, mas compartilham os principais conceitos do modelo relacional e utilizam SQL, com variações próprias de cada sistema.
