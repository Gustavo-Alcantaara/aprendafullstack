Atributo

Atributo em Banco de Dados

Um atributo é uma característica ou informação que descreve uma entidade dentro de um banco de dados.

Por exemplo, se temos a entidade CLIENTE, podemos armazenar informações como nome, e-mail, telefone e data de nascimento. Cada uma dessas informações é um atributo.

Exemplo

Imagine a entidade:

CLIENTE
├── id_cliente
├── nome
├── email
├── telefone
└── data_nascimento

Nesse caso:

  • id_cliente → identifica o cliente.
  • nome → armazena o nome.
  • email → armazena o e-mail.
  • telefone → armazena o telefone.
  • data_nascimento → armazena a data de nascimento.

Cada atributo possui um valor para cada registro.

CLIENTE
id_cliente | nome          | email
-----------|---------------|----------------------
1          | João Silva    | joao@email.com
2          | Maria Souza   | maria@email.com

nome, por exemplo, é o atributo, enquanto "João Silva" é o valor desse atributo.

Tipos de atributos

Durante a modelagem de um banco de dados, podemos encontrar diferentes tipos de atributos.

1. Atributo simples

É um atributo que não precisa ser dividido em partes menores.

Exemplo:

idade
sexo
salário

Por exemplo:

idade = 25

2. Atributo composto

Pode ser dividido em outros atributos menores.

Por exemplo, um endereço:

ENDEREÇO
├── rua
├── número
├── bairro
├── cidade
└── estado

Em vez de armazenar apenas:

endereco = "Rua A, 100, Centro, Fortaleza - CE"

podemos separar as informações.

Isso facilita consultas e organização dos dados.

3. Atributo multivalorado

É um atributo que pode possuir mais de um valor para a mesma entidade.

Por exemplo, um cliente pode possuir vários telefones:

CLIENTE
├── nome
└── telefones
    ├── 8899999-1111
    └── 8898888-2222

Em bancos relacionais, normalmente esse tipo de informação é representado criando uma tabela separada, em vez de colocar vários valores na mesma coluna.

4. Atributo derivado

É um atributo cujo valor pode ser calculado a partir de outros dados.

Exemplo:

data_nascimento → idade

Se sabemos que uma pessoa nasceu em 2000, podemos calcular sua idade.

Outro exemplo:

preço × quantidade → valor_total

Nesse caso, valor_total pode ser calculado, então muitas vezes não é necessário armazená-lo diretamente.

Atributo identificador

Um dos atributos mais importantes é o identificador, usado para distinguir cada registro.

Exemplo:

CLIENTE
├── id_cliente
├── nome
├── email
└── telefone

id_cliente pode ser o identificador:

id_cliente
1
2
3
4

Cada cliente possui um identificador único.

Quando o modelo conceitual é transformado em um banco relacional, esse atributo normalmente se torna uma chave primária (PRIMARY KEY).

CREATE TABLE cliente (
    id_cliente INT PRIMARY KEY,
    nome VARCHAR(100),
    email VARCHAR(150)
);

Atributo x Entidade

É importante não confundir os dois.

Entidade representa aquilo sobre o qual queremos armazenar informações.

Atributo representa uma característica dessa entidade.

Exemplo:

CLIENTE
├── id_cliente
├── nome
├── email
└── telefone

Aqui:

  • CLIENTE → entidade
  • id_cliente → atributo
  • nome → atributo
  • email → atributo
  • telefone → atributo

Atributo no DER

No Diagrama Entidade-Relacionamento (DER), os atributos tradicionalmente são representados por elipses ligadas às entidades.

Exemplo conceitual:

             (nome)
                |
                |
(id_cliente) — CLIENTE — (email)
                |
                |
           (telefone)

Em algumas ferramentas modernas de modelagem, a representação pode ser diferente, mas o conceito continua o mesmo.

Atributo no modelo lógico

Quando transformamos o modelo conceitual em um modelo lógico, os atributos normalmente se tornam colunas de uma tabela.

Por exemplo:

Entidade:
CLIENTE
 ├── id_cliente
 ├── nome
 ├── email
 └── telefone

vira:

CLIENTE
+-------------+----------------+
| id_cliente  | INT            |
| nome        | VARCHAR(100)   |
| email       | VARCHAR(150)   |
| telefone    | VARCHAR(20)    |
+-------------+----------------+

E posteriormente pode ser implementado em SQL:

CREATE TABLE cliente (
    id_cliente INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(150),
    telefone VARCHAR(20)
);

Resumindo

ConceitoSignificado
AtributoCaracterística de uma entidade
ValorInformação armazenada no atributo
IdentificadorAtributo que identifica uma entidade
Atributo simplesNão pode ser dividido
Atributo compostoPode ser dividido em partes
MultivaloradoPode possuir vários valores
DerivadoPode ser calculado a partir de outros dados

Exemplo final:

CLIENTE
│
├── id_cliente     → identificador
├── nome           → atributo simples
├── email          → atributo simples
├── endereço       → atributo composto
└── idade          → atributo derivado

O ponto principal é: entidade representa o "objeto" que queremos armazenar; atributo representa as características desse objeto.
