Especialização e Generalização

Especialização e generalização são conceitos do Modelo Entidade-Relacionamento (MER) usados para representar entidades que possuem características em comum, mas também apresentam características específicas.

Eles são muito úteis quando temos uma entidade genérica que pode ser dividida em tipos mais específicos.

1. Generalização

A generalização acontece quando identificamos características comuns de várias entidades e criamos uma entidade mais geral para representá-las.

Por exemplo, imagine que um sistema tenha:

  • ALUNO
  • PROFESSOR

Ambos possuem:

  • nome
  • CPF
  • data de nascimento
  • endereço

Podemos criar uma entidade mais geral chamada PESSOA:

                 PESSOA
              /          \
             /            \
         ALUNO          PROFESSOR

A entidade PESSOA contém os atributos comuns:

PESSOA
├── id_pessoa
├── nome
├── cpf
└── data_nascimento

Enquanto ALUNO e PROFESSOR possuem suas características específicas:

ALUNO
├── matrícula
└── curso

PROFESSOR
├── registro
└── especialidade

Assim, a generalização parte de entidades específicas e identifica uma entidade mais genérica.

Ideia:

ALUNO + PROFESSOR → PESSOA

2. Especialização

A especialização é o processo inverso.

Partimos de uma entidade geral e criamos entidades mais específicas.

Por exemplo:

                 FUNCIONÁRIO
                /           \
               /             \
          GERENTE          VENDEDOR

FUNCIONÁRIO possui atributos comuns:

FUNCIONÁRIO
├── id_funcionario
├── nome
├── cpf
└── salário

Já GERENTE pode possuir:

GERENTE
└── setor_responsável

E VENDEDOR:

VENDEDOR
└── comissão

Nesse caso:

FUNCIONÁRIO → GERENTE + VENDEDOR

Isso é especialização.

3. Herança

Um conceito importante relacionado à especialização/generalização é a herança.

As entidades especializadas herdam os atributos e relacionamentos da entidade generalizada.

Por exemplo:

             FUNCIONÁRIO
            /            \
           /              \
      GERENTE            VENDEDOR

Se FUNCIONÁRIO possui:

id
nome
cpf
salário

GERENTE e VENDEDOR também possuem essas características.

Além disso, cada uma pode ter seus próprios atributos:

GERENTE
├── id
├── nome
├── cpf
├── salário
└── setor_responsável
VENDEDOR
├── id
├── nome
├── cpf
├── salário
└── comissão

Portanto:

Entidade especializada = atributos herdados + atributos próprios.

5. Especialização total e parcial

A especialização pode ser total ou parcial.

Especialização total

Significa que toda ocorrência da entidade genérica obrigatoriamente pertence a algum subtipo.

Exemplo:

              FUNCIONÁRIO
             /            \
        GERENTE          VENDEDOR

Se a regra do sistema disser que todo funcionário deve ser obrigatoriamente gerente ou vendedor, temos uma especialização total.

Especialização parcial

Significa que uma ocorrência da entidade genérica pode não pertencer a nenhum subtipo.

Por exemplo:

              FUNCIONÁRIO
             /            \
        GERENTE          VENDEDOR

Um funcionário pode ser apenas um funcionário comum, sem ser gerente nem vendedor.

Nesse caso, temos uma especialização parcial.

6. Especialização disjunta e sobreposta

Também podemos definir se uma entidade pode pertencer a um ou vários subtipos.

Disjunta

Uma ocorrência pode pertencer a apenas um subtipo.

Exemplo:

                 FUNCIONÁRIO
                /           \
           GERENTE         VENDEDOR

Um funcionário não pode ser gerente e vendedor simultaneamente.

Sobreposta

Uma ocorrência pode pertencer a mais de um subtipo.

Por exemplo:

                    PESSOA
                   /      \
              ALUNO      FUNCIONÁRIO

Uma pessoa pode ser simultaneamente:

  • aluno;
  • funcionário.

Nesse caso, a especialização é sobreposta.

8. Quando utilizar?

Especialização/generalização é útil quando existem entidades com muitas características em comum, mas algumas características são exclusivas de determinados tipos.

Por exemplo:

                 VEÍCULO
                /       \
               /         \
           CARRO        MOTO

VEÍCULO:

  • placa
  • marca
  • modelo
  • ano

CARRO:

  • quantidade_portas

MOTO:

  • cilindradas

Isso evita repetir os atributos comuns em cada entidade.

Resumo

Generalização é a criação de uma entidade mais geral a partir de entidades específicas.

Especialização é a divisão de uma entidade geral em entidades mais específicas.

Os conceitos principais são:

  • Superclasse → entidade mais geral.
  • Subclasse → entidade especializada.
  • Herança → subclasses recebem características da superclasse.
  • Total → toda ocorrência pertence a algum subtipo.
  • Parcial → algumas ocorrências podem não pertencer a nenhum subtipo.
  • Disjunta → pertence a apenas um subtipo.
  • Sobreposta → pode pertencer a vários subtipos.

Em termos simples:

Generalização agrupa. Especialização divide.
