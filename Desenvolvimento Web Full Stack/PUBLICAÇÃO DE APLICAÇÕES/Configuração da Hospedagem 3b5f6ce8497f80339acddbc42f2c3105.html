Configuração da Hospedagem para a Versão do PHP

A configuração da versão do PHP é uma das etapas mais importantes na publicação de uma aplicação web. Cada aplicação é desenvolvida e testada utilizando uma determinada versão do PHP. Se o servidor estiver configurado com uma versão incompatível, a aplicação poderá apresentar erros, deixar de funcionar ou até mesmo ficar indisponível.

Por isso, antes de publicar um sistema, é fundamental verificar se a versão do PHP instalada na hospedagem é compatível com a utilizada durante o desenvolvimento.

O que é a versão do PHP?

O PHP evolui constantemente, recebendo novas funcionalidades, melhorias de desempenho e correções de segurança.

Cada atualização gera uma nova versão.

Exemplos:

  • PHP 7.4
  • PHP 8.0
  • PHP 8.1
  • PHP 8.2
  • PHP 8.3

Cada versão pode apresentar diferenças de sintaxe, funções disponíveis e comportamento do interpretador.

Por que configurar a versão do PHP?

Imagine que uma aplicação foi desenvolvida utilizando o PHP 8.3.

Se ela for executada em um servidor com PHP 7.4, algumas funções modernas podem não existir, causando erros.

Da mesma forma, aplicações muito antigas podem não funcionar corretamente em versões recentes do PHP, pois algumas funções foram removidas ou modificadas.

A configuração correta garante:

  • Compatibilidade da aplicação.
  • Melhor desempenho.
  • Maior segurança.
  • Menor ocorrência de erros.

Como o PHP funciona no servidor?

Quando o usuário acessa um arquivo .php, o servidor web não envia esse arquivo diretamente ao navegador.

O processo é o seguinte:

  1. O navegador solicita uma página PHP.
  1. O servidor web recebe a requisição.
  1. O interpretador PHP executa o código.
  1. Se necessário, consulta o banco de dados.
  1. O PHP gera um documento HTML.
  1. O servidor envia esse HTML ao navegador.

Fluxo simplificado:

Usuário
    │
    ▼
Servidor Web
    │
    ▼
Interpretador PHP
    │
    ▼
Banco de Dados (opcional)
    │
    ▼
HTML gerado
    │
    ▼
Navegador

Onde configurar a versão do PHP?

A maioria das hospedagens oferece uma ferramenta para selecionar a versão do PHP.

Normalmente ela está disponível em painéis como:

  • cPanel
  • Plesk
  • DirectAdmin
  • VistaPanel (InfinityFree)

Os nomes da ferramenta podem variar.

Exemplos:

  • Select PHP Version
  • PHP Selector
  • PHP Configuration
  • PHP Manager
  • MultiPHP Manager

Configurando no cPanel

Em muitas hospedagens com cPanel, o procedimento é:

  1. Acessar o cPanel.
  1. Localizar Select PHP Version ou MultiPHP Manager.
  1. Selecionar o domínio.
  1. Escolher a versão desejada.
  1. Salvar as alterações.

Após alguns instantes, a nova versão estará ativa.

Configurando no InfinityFree

No InfinityFree, a versão do PHP é definida pela plataforma e não pode ser alterada livremente pelo usuário no plano gratuito. Por isso, é importante verificar qual versão está disponível e garantir que a aplicação seja compatível com ela antes da publicação.

Verificando a versão do PHP

Uma forma simples de verificar a versão instalada é criar um arquivo chamado:

phpinfo.php

Com o seguinte conteúdo:

<?php
phpinfo();
?>

Ao acessar esse arquivo pelo navegador, será exibida uma página com diversas informações sobre a configuração do PHP, incluindo:

  • Versão do PHP.
  • Extensões instaladas.
  • Configurações do servidor.
  • Limites de upload.
  • Fuso horário.
  • Memória disponível.
Importante: após a verificação, remova esse arquivo do servidor, pois ele expõe informações que podem ser úteis para um invasor.

Compatibilidade entre versões

Nem todas as versões são compatíveis entre si.

Exemplo:

Uma aplicação desenvolvida em PHP 5.6 pode apresentar problemas ao ser executada no PHP 8.3.

Por outro lado, aplicações desenvolvidas seguindo boas práticas e utilizando recursos atuais tendem a funcionar sem dificuldades nas versões mais recentes.

Extensões do PHP

Além da versão, a aplicação pode depender de extensões específicas.

Algumas das mais comuns são:

  • mysqli
  • PDO
  • OpenSSL
  • cURL
  • mbstring
  • GD
  • ZIP
  • Fileinfo
  • JSON
  • XML

Se uma extensão necessária estiver desativada, partes da aplicação podem deixar de funcionar.

Exemplos:

  • Sem mysqli ou PDO, a conexão com o banco de dados pode falhar.
  • Sem GD, funções de manipulação de imagens podem não funcionar.
  • Sem ZIP, recursos de compactação podem ficar indisponíveis.

Configurações importantes do PHP

Além da versão, algumas configurações influenciam o funcionamento da aplicação.

memory_limit

Define a quantidade máxima de memória que um script PHP pode utilizar.

Exemplo:

memory_limit = 256M

upload_max_filesize

Define o tamanho máximo permitido para upload de arquivos.

Exemplo:

upload_max_filesize = 64M

post_max_size

Define o tamanho máximo dos dados enviados por formulários HTTP POST.

Exemplo:

post_max_size = 64M

max_execution_time

Determina o tempo máximo que um script pode executar.

Exemplo:

max_execution_time = 60

Significa que o script poderá executar por até 60 segundos.

date.timezone

Configura o fuso horário utilizado pelo PHP.

Exemplo:

date.timezone = America/Sao_Paulo

Erros comuns relacionados à versão do PHP

Durante a publicação, alguns problemas podem ocorrer.

Tela em branco

Pode indicar um erro fatal no código ou incompatibilidade com a versão do PHP.

Função inexistente

Exemplo:

Call to undefined function

Geralmente ocorre quando a função foi removida ou quando uma extensão necessária não está habilitada.

Erros de sintaxe

Podem surgir quando o código utiliza recursos que não existem na versão instalada.

Aplicação não conecta ao banco

Pode ocorrer quando as extensões mysqli ou PDO estão desativadas ou quando o código utiliza funções incompatíveis.

Atualizando uma aplicação para uma nova versão

Ao migrar para uma versão mais recente do PHP:

  1. Faça backup da aplicação.
  1. Teste o sistema em um ambiente de desenvolvimento.
  1. Verifique a compatibilidade das bibliotecas utilizadas.
  1. Atualize dependências, se necessário.
  1. Corrija avisos e funções obsoletas.
  1. Altere a versão do PHP na hospedagem.
  1. Teste todas as funcionalidades antes de disponibilizar a nova versão aos usuários.

Exemplo Prático

Imagine que você desenvolveu um sistema de biblioteca utilizando PHP 8.3.

Ao contratar uma hospedagem:

  1. Acesse o painel da hospedagem.
  1. Verifique a versão do PHP disponível.
  1. Confirme que ela é compatível com a aplicação.
  1. Verifique se as extensões necessárias (como mysqli, PDO e mbstring) estão habilitadas.
  1. Faça o upload da aplicação.
  1. Teste o sistema.
  1. Ajuste configurações como limite de upload ou fuso horário, se necessário.

Vantagens de utilizar versões recentes do PHP

  • Melhor desempenho na execução dos scripts.
  • Correções de falhas de segurança.
  • Novos recursos da linguagem.
  • Melhor gerenciamento de memória.
  • Maior compatibilidade com frameworks e bibliotecas modernas.
  • Suporte ativo e atualizações frequentes.

Desvantagens de utilizar versões antigas

  • Falta de suporte oficial.
  • Ausência de correções de segurança.
  • Menor desempenho.
  • Incompatibilidade com bibliotecas atuais.
  • Maior risco de vulnerabilidades.

Boas práticas

  • Utilize versões do PHP que ainda recebam suporte e atualizações de segurança.
  • Desenvolva e teste a aplicação utilizando a mesma versão disponível na hospedagem ou uma compatível.
  • Verifique se todas as extensões necessárias estão habilitadas.
  • Evite utilizar funções obsoletas ou removidas.
  • Faça backup antes de alterar a versão do PHP.
  • Teste toda a aplicação após qualquer mudança de versão.
  • Remova o arquivo phpinfo.php após utilizá-lo para evitar exposição de informações do servidor.

Resumo

A configuração da versão do PHP é um passo essencial na publicação de aplicações web. Ela garante que o código seja executado corretamente, evita incompatibilidades e melhora o desempenho e a segurança da aplicação. Além de escolher uma versão compatível, é importante verificar as extensões instaladas e ajustar configurações como memória, limite de upload e tempo de execução. Manter o PHP atualizado, testar a aplicação antes da publicação e remover arquivos de diagnóstico, como o phpinfo.php, são práticas fundamentais para garantir um ambiente de produção estável e seguro.
