InfinityFree

O InfinityFree é um serviço de hospedagem gratuita de sites e aplicações web muito utilizado por estudantes, desenvolvedores iniciantes e pessoas que desejam publicar projetos sem custos. Ele oferece suporte a PHP, MySQL/MariaDB, certificados SSL gratuitos, FTP e instalação de sistemas como WordPress. (InfinityFree)

É uma das plataformas gratuitas mais conhecidas para aprender publicação de aplicações web, pois permite colocar projetos reais na Internet sem a necessidade de contratar uma hospedagem paga.

O que é o InfinityFree?

O InfinityFree é uma plataforma de hospedagem que permite publicar sites e aplicações desenvolvidas em tecnologias como:

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL/MariaDB
  • WordPress

Após criar uma conta, o usuário pode enviar os arquivos do projeto para o servidor e disponibilizá-los na Internet por meio de um subdomínio gratuito ou de um domínio próprio. (InfinityFree)

Como funciona?

O processo de publicação é simples:

  1. Criar uma conta no InfinityFree.
  1. Criar uma conta de hospedagem.
  1. Escolher um subdomínio gratuito ou adicionar um domínio próprio.
  1. Enviar os arquivos da aplicação via FTP ou pelo Gerenciador de Arquivos.
  1. Criar o banco de dados MySQL.
  1. Configurar a conexão da aplicação com o banco.
  1. Acessar o site pelo navegador.

Assim, qualquer pessoa com acesso à Internet poderá utilizar a aplicação.

Principais recursos

Segundo o serviço, o plano gratuito inclui:

  • 5 GB de espaço em disco.
  • PHP 8.3.
  • MySQL 8.0 / MariaDB 11.4.
  • Até 400 bancos de dados MySQL.
  • Largura de banda anunciada como ilimitada.
  • Certificados SSL gratuitos.
  • Suporte a arquivos .htaccess.
  • Instalação de mais de 400 aplicações via Softaculous, incluindo WordPress.
  • Subdomínios gratuitos e suporte a domínios próprios. (InfinityFree)

Painel de Controle

O InfinityFree utiliza o VistaPanel, um painel semelhante ao cPanel.

Com ele é possível:

  • Criar bancos de dados.
  • Gerenciar arquivos.
  • Configurar contas FTP.
  • Instalar aplicações.
  • Visualizar estatísticas.
  • Gerenciar domínios e subdomínios.

É um painel intuitivo para quem está começando.

Estrutura de uma aplicação hospedada

Uma aplicação PHP normalmente possui a seguinte organização:

Servidor InfinityFree
│
├── public_html
│     ├── index.php
│     ├── css/
│     ├── js/
│     ├── imagens/
│     └── uploads/
│
├── Banco MySQL
│
└── Arquivos da aplicação

A pasta public_html é o diretório principal onde ficam os arquivos acessíveis pela web.

Banco de Dados

O InfinityFree oferece suporte ao MySQL/MariaDB.

É possível criar bancos de dados para armazenar:

  • Usuários
  • Produtos
  • Clientes
  • Pedidos
  • Mensagens
  • Informações do sistema

Após criar o banco, basta configurar os dados de conexão na aplicação PHP.

Exemplo:

$host = "sqlXXX.infinityfree.com";
$usuario = "epiz_xxxxxx";
$senha = "********";
$banco = "epiz_xxxxxx";

Publicando um projeto PHP

O processo básico é:

  1. Desenvolver o projeto localmente (por exemplo, usando XAMPP).
  1. Testar a aplicação.
  1. Compactar ou enviar os arquivos.
  1. Fazer upload para a pasta public_html.
  1. Criar o banco de dados.
  1. Importar o arquivo .sql.
  1. Configurar a conexão com o banco.
  1. Testar a aplicação online.

Envio dos arquivos

Os arquivos podem ser enviados por:

FTP

Utilizando programas como:

  • FileZilla
  • WinSCP

O FTP facilita a transferência de vários arquivos ao mesmo tempo.

Gerenciador de Arquivos

Também é possível enviar arquivos diretamente pelo navegador utilizando o painel de controle.

Instalação do WordPress

O InfinityFree inclui o Softaculous, que permite instalar o WordPress e centenas de outras aplicações com poucos cliques, sem necessidade de configuração manual. (InfinityFree)

Domínio gratuito

Quem não possui um domínio próprio pode utilizar um subdomínio gratuito.

Exemplo:

meusite.rf.gd

ou

meuprojeto.great-site.net

Também é possível utilizar um domínio registrado em outro provedor.

Certificado SSL

O InfinityFree oferece suporte a certificados SSL gratuitos.

Isso permite utilizar:

https://www.meusite.com

em vez de:

http://www.meusite.com

O HTTPS protege a comunicação entre o navegador e o servidor por meio de criptografia.

Vantagens do InfinityFree

  • Gratuito.
  • Não exige cartão de crédito.
  • Suporte a PHP e MySQL.
  • Certificado SSL gratuito.
  • Sem anúncios obrigatórios no site.
  • Suporte ao WordPress.
  • Permite usar domínio próprio.
  • Excelente para estudos e portfólios. (InfinityFree)

Limitações

Apesar de ser bastante completo para um serviço gratuito, possui algumas limitações:

  • Recursos de processamento menores que em hospedagens pagas.
  • Limites de uso para evitar abusos.
  • Não oferece contas de e-mail no plano gratuito.
  • Suporte baseado principalmente em documentação e fórum da comunidade.
  • Não é recomendado para aplicações críticas ou com grande volume de acessos. (InfinityFree)

Quando utilizar?

O InfinityFree é indicado para:

  • Aprender desenvolvimento web.
  • Trabalhos de faculdade.
  • Portfólios.
  • Sites pessoais.
  • Blogs.
  • Testes de aplicações PHP.
  • Projetos de pequeno porte.

Quando não utilizar?

Não é a melhor escolha para:

  • Grandes lojas virtuais.
  • Sistemas corporativos.
  • Aplicações com milhares de acessos diários.
  • Sistemas que exigem suporte técnico dedicado.
  • Aplicações com requisitos elevados de desempenho.

Nesses casos, uma hospedagem paga ou um serviço em nuvem costuma ser mais adequado.

Exemplo Prático

Imagine que você desenvolveu um sistema de biblioteca em PHP com MySQL.

O fluxo seria:

  1. Desenvolver e testar o sistema localmente.
  1. Criar uma conta no InfinityFree.
  1. Criar a hospedagem.
  1. Criar o banco de dados.
  1. Importar as tabelas do MySQL.
  1. Enviar os arquivos para public_html.
  1. Configurar a conexão com o banco.
  1. Acessar o sistema pelo domínio fornecido.

Em poucos minutos, sua aplicação estará disponível na Internet.

Boas práticas

  • Teste o projeto localmente antes de publicá-lo.
  • Utilize HTTPS.
  • Faça backup do banco de dados regularmente.
  • Evite armazenar arquivos desnecessários na hospedagem.
  • Organize a estrutura de pastas do projeto.
  • Mantenha o PHP e as bibliotecas compatíveis com a versão suportada pelo serviço.
  • Proteja arquivos de configuração que contenham credenciais.

Resumo

O InfinityFree é uma excelente plataforma de hospedagem gratuita para quem está aprendendo a desenvolver e publicar aplicações web. Ele oferece suporte a PHP, MySQL/MariaDB, SSL, FTP, WordPress e domínios próprios, permitindo colocar projetos reais na Internet sem custo. Embora possua limitações de desempenho e recursos quando comparado a hospedagens pagas, é uma opção muito indicada para estudos, portfólios, testes e pequenos projetos, sendo uma das ferramentas mais populares entre estudantes e desenvolvedores iniciantes. (InfinityFree)
