Enviando Arquivos da Aplicação via File Manager

O File Manager (Gerenciador de Arquivos) é uma ferramenta disponível na maioria dos painéis de hospedagem, como cPanel, VistaPanel (utilizado pelo InfinityFree) e Plesk. Ele permite gerenciar os arquivos de um site diretamente pelo navegador, sem a necessidade de instalar programas como o FileZilla.

Por meio do File Manager, é possível fazer upload, download, criar pastas, editar arquivos, compactar, descompactar e excluir arquivos da aplicação.

O que é o File Manager?

O File Manager é um gerenciador de arquivos online que permite acessar os diretórios da hospedagem por meio de uma interface gráfica.

Ele funciona de maneira semelhante ao Explorador de Arquivos do Windows, permitindo organizar os arquivos do servidor de forma simples.

É muito utilizado para:

  • Publicar aplicações web.
  • Atualizar arquivos do site.
  • Organizar pastas.
  • Fazer upload de imagens.
  • Editar pequenos arquivos de configuração.
  • Realizar backups.

Quando utilizar o File Manager?

O File Manager é indicado quando:

  • O projeto é pequeno.
  • Você precisa fazer alterações rápidas.
  • Não deseja instalar um cliente FTP.
  • Precisa editar um arquivo diretamente no servidor.
  • Está utilizando um computador onde não é possível instalar programas.

Para projetos grandes, normalmente é mais eficiente utilizar um cliente FTP ou SFTP, como o FileZilla.

Como acessar o File Manager?

O acesso depende da hospedagem, mas geralmente segue estes passos:

  1. Acesse o painel da hospedagem.
  1. Faça login com seu usuário e senha.
  1. Procure pela opção File Manager ou Gerenciador de Arquivos.
  1. Clique para abrir o gerenciador.

Após isso, será exibida a estrutura de pastas do servidor.

Estrutura de diretórios

Uma hospedagem normalmente apresenta uma estrutura semelhante à seguinte:

/
├── public_html
├── logs
├── backups
├── tmp
└── mail

A pasta mais importante para aplicações web é:

public_html

Ela é a pasta pública do site.

Tudo que estiver nela poderá ser acessado pelo navegador, conforme a configuração da hospedagem.

Organização de uma aplicação

Uma aplicação PHP pode possuir a seguinte estrutura:

public_html
│
├── index.php
├── login.php
├── cadastro.php
├── css
│   └── estilo.css
├── js
│   └── script.js
├── imagens
├── uploads
└── includes

Essa organização facilita a manutenção do projeto.

Enviando arquivos

Após abrir a pasta public_html, o procedimento geralmente é:

1. Abrir a pasta pública

Entre na pasta:

public_html

2. Localizar o botão Upload

Na barra superior normalmente existe a opção:

Upload

3. Selecionar os arquivos

Escolha os arquivos da aplicação no computador.

Exemplo:

SistemaBiblioteca
│
├── index.php
├── css
├── js
├── imagens
└── includes

4. Aguardar a transferência

O painel exibirá o progresso do envio.

Quando finalizar, os arquivos já estarão disponíveis no servidor.

Enviando um arquivo compactado

Uma prática muito utilizada é enviar apenas um arquivo .zip.

Exemplo:

SistemaLoja.zip

Após o upload:

  1. Selecione o arquivo.
  1. Clique em Extract ou Extrair.
  1. Aguarde a descompactação.

Essa técnica é muito mais rápida do que enviar centenas de arquivos individualmente.

Editando arquivos

O File Manager permite editar arquivos diretamente no servidor.

Exemplo:

config.php

Ao clicar em Edit, é possível alterar:

  • Configurações.
  • Senhas.
  • Dados do banco de dados.
  • URLs.
  • Variáveis.

Após salvar, as alterações entram em vigor imediatamente.

Criando pastas

Também é possível criar diretórios.

Exemplo:

uploads

ou

imagens

Isso ajuda a organizar os arquivos da aplicação.

Excluindo arquivos

Caso seja necessário remover um arquivo:

  1. Selecione-o.
  1. Clique em Delete.
  1. Confirme a exclusão.

Essa operação deve ser realizada com cuidado, pois pode tornar a aplicação indisponível.

Renomeando arquivos

Também é possível alterar nomes.

Exemplo:

Antes:

pagina1.php

Depois:

login.php

Compactando arquivos

O File Manager normalmente permite criar arquivos compactados.

Exemplo:

BackupSite.zip

Esse recurso é útil para realizar backups da aplicação.

Descompactando arquivos

Após enviar um arquivo ZIP:

Sistema.zip

Basta utilizar:

Extract

O painel criará automaticamente toda a estrutura de pastas.

Atualizando uma aplicação

Quando houver alterações:

  1. Modifique os arquivos localmente.
  1. Faça upload novamente.
  1. Substitua os arquivos antigos.
  1. Teste a aplicação.

Assim, a nova versão ficará disponível para os usuários.

Cuidados ao enviar arquivos

Alguns erros são bastante comuns.

Enviar para a pasta errada

Correto:

public_html

Errado:

tmp

Se os arquivos forem enviados para a pasta incorreta, o site não será exibido corretamente.

Esquecer o arquivo principal

A maioria das aplicações precisa possuir:

index.php

ou

index.html

Esse é o arquivo inicial que será carregado quando o usuário acessar o domínio.

Não configurar o banco de dados

Mesmo enviando todos os arquivos, a aplicação pode não funcionar caso a conexão com o banco de dados esteja incorreta.

Não importar o banco

Além dos arquivos, é necessário importar as tabelas do banco de dados utilizando uma ferramenta como o phpMyAdmin.

Exemplo Prático

Imagine que você desenvolveu um sistema de cadastro de alunos em PHP.

O processo seria:

  1. Testar o sistema localmente.
  1. Compactar a pasta do projeto em um arquivo ZIP.
  1. Acessar o painel da hospedagem.
  1. Abrir o File Manager.
  1. Entrar na pasta public_html.
  1. Fazer upload do arquivo ZIP.
  1. Extrair os arquivos.
  1. Criar o banco de dados.
  1. Importar o arquivo .sql.
  1. Configurar o arquivo de conexão (config.php).
  1. Acessar o domínio para verificar se a aplicação funciona corretamente.

Vantagens do File Manager

  • Não exige instalação de programas.
  • Acesso pelo navegador de qualquer computador.
  • Interface gráfica simples.
  • Permite editar arquivos diretamente no servidor.
  • Facilita uploads rápidos.
  • Possibilita compactar e descompactar arquivos.
  • Ideal para pequenas atualizações e manutenção.

Desvantagens

  • O upload de muitos arquivos pode ser mais lento do que via FTP/SFTP.
  • Alguns painéis limitam o tamanho máximo de arquivos enviados.
  • Editar arquivos diretamente no servidor aumenta o risco de erros em produção.
  • Menos eficiente para projetos muito grandes.

Boas práticas

  • Organize a aplicação em pastas (css, js, imagens, uploads).
  • Envie arquivos compactados quando o projeto tiver muitos arquivos.
  • Faça backup antes de substituir arquivos importantes.
  • Teste a aplicação após cada atualização.
  • Verifique se os arquivos estão na pasta public_html.
  • Evite editar diretamente arquivos críticos em produção; prefira testar as alterações localmente antes de enviá-las.
  • Mantenha apenas os arquivos necessários no servidor para reduzir riscos de segurança.

Resumo

O File Manager é uma ferramenta integrada aos painéis de hospedagem que permite gerenciar arquivos da aplicação diretamente pelo navegador. Com ele, é possível enviar, editar, excluir, compactar e descompactar arquivos sem utilizar programas externos. Na publicação de aplicações web, os arquivos devem ser enviados para a pasta public_html, que corresponde ao diretório público do site. Embora seja uma solução prática para projetos pequenos e atualizações rápidas, para aplicações maiores o uso de clientes FTP/SFTP costuma oferecer mais velocidade e eficiência.
