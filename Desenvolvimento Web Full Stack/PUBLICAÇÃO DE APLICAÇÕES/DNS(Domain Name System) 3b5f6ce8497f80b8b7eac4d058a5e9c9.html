DNS (Domain Name System)

O DNS (Domain Name System) é um dos componentes mais importantes da Internet. Ele é responsável por traduzir os nomes de domínio (como www.google.com) em endereços IP (como 142.250.190.78), permitindo que computadores encontrem e se comuniquem entre si.

Sem o DNS, seria necessário memorizar o endereço IP de cada site que desejamos acessar, o que tornaria a navegação muito mais difícil.

O que é DNS?

O Domain Name System (Sistema de Nomes de Domínio) é um sistema distribuído que associa nomes de domínio legíveis por humanos a endereços IP utilizados pelos computadores.

Ele funciona como uma lista telefônica da Internet:

  • Você conhece o nome da pessoa (domínio).
  • A lista telefônica informa o número (endereço IP).

Da mesma forma:

  • Você digita www.exemplo.com.
  • O DNS informa ao navegador qual é o endereço IP do servidor onde esse site está hospedado.

Por que o DNS foi criado?

Os computadores se comunicam utilizando endereços IP, não nomes.

Por exemplo:

142.250.190.78

É muito mais fácil lembrar de:

www.google.com

do que memorizar dezenas de números.

O DNS foi criado justamente para tornar a Internet mais amigável para os usuários.

Como o DNS funciona?

Quando um usuário acessa um site, ocorre o seguinte processo:

1. O usuário digita o domínio

Exemplo:

www.exemplo.com

2. O navegador verifica o cache

Primeiro ele verifica se já conhece o IP.

Se encontrar:

  • Usa imediatamente.

Se não encontrar:

  • Consulta um servidor DNS.

3. O servidor DNS procura o endereço IP

O servidor verifica seus registros.

Exemplo:

www.exemplo.com

↓

200.100.50.20

4. O IP é enviado ao navegador

Agora o navegador sabe onde está o servidor.

5. A conexão é estabelecida

O navegador envia a requisição ao servidor utilizando o endereço IP.

6. O servidor responde

A página é enviada ao navegador.

O que é um Domínio?

É o nome utilizado para identificar um site.

Exemplos:

  • google.com
  • microsoft.com
  • uol.com.br
  • ifce.edu.br
  • github.com

Cada domínio possui um endereço IP correspondente.

O que é um Endereço IP?

É o endereço que identifica um dispositivo na rede.

Exemplo IPv4:

192.168.1.10

Exemplo público:

104.26.8.91

O DNS apenas faz a tradução entre domínio e IP.

Tipos de Servidores DNS

O funcionamento do DNS depende de diferentes tipos de servidores, cada um com uma função específica.

Servidor Recursivo (Recursive Resolver)

É o primeiro servidor consultado pelo computador do usuário.

Ele procura a resposta para o domínio solicitado e geralmente mantém um cache para acelerar consultas futuras.

Exemplos:

  • DNS do Google
  • DNS da Cloudflare
  • DNS do provedor de Internet

Servidor Raiz (Root Server)

É o ponto inicial da hierarquia do DNS.

Ele não conhece o IP do site, mas informa qual servidor é responsável pelo domínio de nível superior (TLD).

Servidor TLD (Top-Level Domain)

Gerencia domínios como:

  • .com
  • .org
  • .net
  • .br
  • .edu

Ele indica onde está o servidor autoritativo daquele domínio.

Servidor Autoritativo

É o servidor que possui a resposta definitiva para um domínio.

Exemplo:

www.loja.com

↓

201.50.100.10

Principais Registros DNS

Os registros DNS armazenam informações sobre um domínio.

Registro A

Relaciona um domínio a um endereço IPv4.

Exemplo:

www.site.com

↓

200.100.20.30

Registro AAAA

Relaciona um domínio a um endereço IPv6.

Registro CNAME

Cria um apelido para outro domínio.

Exemplo:

blog.site.com

↓

www.site.com

Registro MX

Indica os servidores responsáveis pelos e-mails do domínio.

Exemplo:

contato@empresa.com

Registro TXT

Armazena informações textuais.

Muito utilizado para:

  • Verificação de domínio
  • SPF
  • DKIM
  • DMARC

Registro NS

Indica quais servidores DNS são responsáveis pelo domínio.

Cache DNS

Para acelerar o acesso aos sites, as respostas DNS ficam armazenadas temporariamente em cache.

O cache pode existir em:

  • Navegador
  • Sistema operacional
  • Roteador
  • Provedor
  • Servidor DNS

Isso evita consultas repetidas.

TTL (Time To Live)

É o tempo que um registro DNS permanece em cache.

Exemplo:

TTL = 3600 segundos

Significa:

Após uma hora, o registro deverá ser consultado novamente.

DNS e Publicação de Aplicações Web

Quando uma aplicação web é publicada, ela normalmente é hospedada em um servidor que possui um endereço IP.

Entretanto, os usuários acessam a aplicação utilizando um domínio.

Exemplo:

Servidor:

177.50.100.15

Domínio registrado:

www.minhaloja.com

O administrador cria um registro A apontando:

www.minhaloja.com

↓

177.50.100.15

Assim, sempre que alguém acessar o domínio, o DNS encaminhará o navegador para o servidor correto.

Vantagens do DNS

  • Facilita a navegação utilizando nomes em vez de IPs.
  • Permite alterar o servidor sem mudar o domínio do site.
  • Organiza os domínios em uma estrutura hierárquica.
  • Melhora o desempenho com o uso de cache.
  • Suporta diferentes tipos de serviços, como sites e e-mails.
  • É escalável e distribuído, atendendo bilhões de consultas diariamente.

Desvantagens e Desafios

  • Alterações podem levar algum tempo para se propagar devido ao cache (propagação DNS).
  • Ataques, como envenenamento de cache (DNS Cache Poisoning) e ataques DDoS contra servidores DNS, podem afetar a disponibilidade.
  • Configurações incorretas podem tornar um site ou serviço inacessível.
  • Dependência da disponibilidade dos servidores DNS para localizar os serviços.

Boas práticas

  • Utilizar provedores de DNS confiáveis e com alta disponibilidade.
  • Configurar corretamente os registros DNS antes de publicar uma aplicação.
  • Definir valores de TTL adequados para facilitar futuras alterações.
  • Proteger o acesso ao painel de gerenciamento do domínio.
  • Monitorar periodicamente os registros DNS.
  • Utilizar DNSSEC, quando disponível, para aumentar a segurança e a autenticidade das respostas DNS.

Resumo

O DNS (Domain Name System) é o sistema responsável por traduzir nomes de domínio em endereços IP, permitindo que usuários acessem aplicações web usando nomes fáceis de lembrar em vez de números. Ele funciona por meio de uma hierarquia de servidores (recursivos, raiz, TLD e autoritativos) e utiliza registros como A, AAAA, CNAME, MX, TXT e NS para armazenar diferentes tipos de informações.

Na publicação de aplicações web, o DNS é indispensável, pois conecta o domínio registrado ao servidor onde a aplicação está hospedada, tornando o acesso simples, rápido e transparente para os usuários. Uma configuração correta do DNS é fundamental para garantir disponibilidade, desempenho e confiabilidade dos serviços na Internet.
