Funções Construtoras

Funções Construtoras em JavaScript

As funções construtoras são uma forma tradicional de criar múltiplos objetos com a mesma estrutura em JavaScript. Antes da introdução das classes no ECMAScript 6 (ES6), elas eram a principal abordagem para implementar conceitos de Orientação a Objetos.

Embora as classes sejam mais utilizadas atualmente, é importante compreender as funções construtoras, pois elas continuam fazendo parte da linguagem e muitos projetos legados ainda as utilizam.

Além disso, as classes do JavaScript são, internamente, uma abstração construída sobre o mesmo mecanismo utilizado pelas funções construtoras e pelos protótipos.

O que é uma Função Construtora?

Uma função construtora é uma função especial utilizada para criar e inicializar objetos.

Seu objetivo é funcionar como um modelo para gerar várias instâncias com propriedades e comportamentos semelhantes.

Exemplo:

function Usuario(nome, email) {
    this.nome = nome;
    this.email = email;
}

Criando objetos:

const usuario1 = new Usuario(
    "Gustavo",
    "gustavo@email.com"
);

const usuario2 = new Usuario(
    "Ana",
    "ana@email.com"
);

Resultado:

{
    nome: "Gustavo",
    email: "gustavo@email.com"
}
{
    nome: "Ana",
    email: "ana@email.com"
}

Cada chamada cria um novo objeto.

Por que Utilizar Funções Construtoras?

Imagine criar vários objetos manualmente:

const aluno1 = {
    nome: "Ana",
    curso: "JavaScript"
};

const aluno2 = {
    nome: "Carlos",
    curso: "JavaScript"
};

const aluno3 = {
    nome: "Maria",
    curso: "JavaScript"
};

Essa abordagem gera repetição de código.

Com uma função construtora:

function Aluno(nome, curso) {
    this.nome = nome;
    this.curso = curso;
}
const aluno1 = new Aluno("Ana", "JavaScript");
const aluno2 = new Aluno("Carlos", "JavaScript");
const aluno3 = new Aluno("Maria", "JavaScript");

O código torna-se mais organizado e reutilizável.

Convenção de Nomenclatura

Por convenção, o nome de uma função construtora começa com letra maiúscula.

Exemplos:

function Pessoa() {}
function Produto() {}
function ContaBancaria() {}

Isso ajuda a indicar que a função deve ser utilizada com o operador new.

O Operador new

O operador new é responsável por transformar uma função comum em uma função construtora.

Quando executamos:

const pessoa = new Pessoa();

O JavaScript realiza os seguintes passos automaticamente:

  1. Cria um novo objeto vazio.
  1. Define o protótipo do objeto.
  1. Faz this apontar para o novo objeto.
  1. Executa a função construtora.
  1. Retorna o objeto criado.

Podemos imaginar esse processo da seguinte forma:

const objeto = {};
Pessoa.call(objeto);
return objeto;

Esse é um modelo simplificado do que ocorre internamente.

A Palavra-chave this

Dentro de uma função construtora, this representa o objeto que está sendo criado.

function Produto(nome, preco) {
    this.nome = nome;
    this.preco = preco;
}
const notebook = new Produto(
    "Notebook",
    3500
);

Internamente:

notebook.nome = "Notebook";
notebook.preco = 3500;

Adicionando Métodos

É possível definir métodos diretamente dentro da função construtora.

function Pessoa(nome) {
    this.nome = nome;

    this.apresentar = function() {
        console.log(
            `Olá, meu nome é ${this.nome}`
        );
    };
}

Uso:

const pessoa = new Pessoa("Gustavo");

pessoa.apresentar();

Resultado:

Olá, meu nome é Gustavo

Problema: Duplicação de Métodos

Quando os métodos são criados dentro da função construtora, cada instância recebe sua própria cópia do método.

const p1 = new Pessoa("Ana");
const p2 = new Pessoa("Carlos");

Cada objeto terá uma função apresentar() diferente na memória.

Isso pode causar desperdício de recursos.

Utilizando o Protótipo

Para evitar duplicação, os métodos podem ser definidos no protótipo.

function Pessoa(nome) {
    this.nome = nome;
}
Pessoa.prototype.apresentar = function() {
    console.log(
        `Olá, meu nome é ${this.nome}`
    );
};

Uso:

const pessoa1 = new Pessoa("Ana");
const pessoa2 = new Pessoa("Carlos");

pessoa1.apresentar();
pessoa2.apresentar();

Agora ambas as instâncias compartilham o mesmo método.

Entendendo o prototype

Todo objeto criado com new possui uma ligação interna com o protótipo da função construtora.

pessoa1
   ↓
Pessoa.prototype

Quando o JavaScript não encontra uma propriedade no objeto, ele procura no protótipo.

Esse mecanismo é chamado de:

Herança prototipal

Funções Construtoras e Classes

As classes introduzidas no ES6 utilizam o mesmo mecanismo interno das funções construtoras.

Função construtora:

function Usuario(nome) {
    this.nome = nome;
}

Usuario.prototype.apresentar = function() {
    console.log(this.nome);
};

Classe:

class Usuario {
    constructor(nome) {
        this.nome = nome;
    }

    apresentar() {
        console.log(this.nome);
    }
}

Ambas produzem resultados semelhantes.

A principal diferença está na sintaxe.

Vantagens das Funções Construtoras

  • Permitem criar múltiplas instâncias.
  • Reduzem a repetição de código.
  • Aproveitam a herança prototipal.
  • São compatíveis com código legado.
  • Ajudam a compreender o funcionamento interno das classes.

Desvantagens

  • Sintaxe menos intuitiva que classes.
  • Exigem maior conhecimento sobre protótipos.
  • Podem causar erros se utilizadas sem new.
  • São menos legíveis em sistemas complexos.

Erro Comum: Esquecer o new

function Pessoa(nome) {
    this.nome = nome;
}

const pessoa = Pessoa("Gustavo");

Sem new, this pode apontar para o objeto global (ou ser undefined no modo estrito).

O correto é:

const pessoa = new Pessoa("Gustavo");

Boas Práticas

  • Utilize nomes iniciados por letra maiúscula.
  • Sempre invoque funções construtoras com new.
  • Defina métodos no prototype.
  • Prefira classes em novos projetos.
  • Estude protótipos para compreender o funcionamento interno do JavaScript.

Quando Utilizar?

Atualmente, as funções construtoras são mais comuns em:

  • Projetos antigos.
  • Bibliotecas legadas.
  • Estudo de protótipos.
  • Compreensão da Orientação a Objetos em JavaScript.

Em aplicações modernas, geralmente utiliza-se:

  • Classes.
  • Funções fábrica (Factory Functions).
  • Módulos.

Resumo

As funções construtoras são uma forma tradicional de criar objetos reutilizáveis em JavaScript. Utilizadas em conjunto com o operador new, elas permitem gerar múltiplas instâncias com a mesma estrutura e comportamento. Embora tenham sido amplamente substituídas pelas classes no ES6, continuam sendo fundamentais para compreender a herança prototipal e o funcionamento interno da Orientação a Objetos na linguagem.
