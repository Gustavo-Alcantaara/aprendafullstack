Operador Rest/Spread

Operador Rest/Spread em JavaScript

O operador ... é um dos recursos mais versáteis introduzidos no ECMAScript 6 (ES6). Dependendo do contexto em que é utilizado, ele pode assumir dois papéis diferentes:

  • Operador Rest (rest parameter)
  • Operador Spread (spread syntax)

Embora utilizem a mesma sintaxe (...), suas finalidades são diferentes.

Diferença entre Rest e Spread

A maneira mais simples de entender a diferença é:

  • Rest: agrupa vários valores em uma única estrutura.
  • Spread: espalha os elementos de uma estrutura.

Em outras palavras:

Rest   → muitos valores → um único elemento
Spread → um elemento → muitos valores

Operador Rest

O operador Rest é utilizado para reunir múltiplos valores em um único parâmetro, geralmente em funções.

Sintaxe

function exemplo(...parametros) {
    // código
}

Os valores recebidos são armazenados em um array.

Exemplo Básico

function somar(...numeros) {
    let total = 0;

    for (const numero of numeros) {
        total += numero;
    }

    return total;
}

console.log(somar(10, 20, 30, 40));

Resultado:

100

Internamente:

numeros = [10, 20, 30, 40];

Rest e Parâmetros Fixos

O operador Rest deve ser sempre o último parâmetro da função.

function apresentar(mensagem, ...nomes) {
    console.log(mensagem);
    console.log(nomes);
}

Uso:

apresentar(
    "Participantes:",
    "Ana",
    "Carlos",
    "Maria"
);

Resultado:

Participantes:
["Ana", "Carlos", "Maria"]

Regra Importante

O parâmetro Rest:

  • Deve ser único.
  • Deve ser o último parâmetro.

Incorreto:

function exemplo(...valores, outro) {}

Isso gera um erro de sintaxe.

Rest em Desestruturação de Arrays

Também é possível agrupar elementos restantes durante a desestruturação.

const numeros = [10, 20, 30, 40, 50];

const [primeiro, segundo, ...restantes] = numeros;

console.log(primeiro);
console.log(segundo);
console.log(restantes);

Resultado:

10
20
[30, 40, 50]

Rest em Desestruturação de Objetos

const usuario = {
    nome: "Gustavo",
    idade: 21,
    cidade: "Fortaleza"
};

const { nome, ...dados } = usuario;

console.log(nome);
console.log(dados);

Resultado:

Gustavo
{ idade: 21, cidade: "Fortaleza" }

Operador Spread

O operador Spread faz o oposto do Rest: ele espalha os elementos de uma estrutura.

Pode ser utilizado com:

  • Arrays
  • Objetos
  • Strings
  • Argumentos de funções

Spread em Arrays

const numeros = [1, 2, 3];

const novosNumeros = [...numeros, 4, 5];

Resultado:

[1, 2, 3, 4, 5]

Copiando Arrays

const original = [10, 20, 30];

const copia = [...original];

Agora os arrays são independentes.

copia.push(40);

console.log(original);
console.log(copia);

Resultado:

[10, 20, 30]
[10, 20, 30, 40]

Concatenando Arrays

const frontend = ["HTML", "CSS"];
const backend = ["Node.js", "SQL"];

const tecnologias = [
    ...frontend,
    ...backend
];

Resultado:

[
    "HTML",
    "CSS",
    "Node.js",
    "SQL"
]

Spread em Strings

Strings são iteráveis.

const nome = "JavaScript";

const letras = [...nome];

console.log(letras);

Resultado:

[
    "J", "a", "v", "a",
    "S", "c", "r", "i",
    "p", "t"
]

Spread em Funções

O Spread permite transformar elementos de um array em argumentos individuais.

function multiplicar(a, b, c) {
    return a * b * c;
}

const valores = [2, 3, 4];

console.log(
    multiplicar(...valores)
);

Resultado:

24

Sem Spread:

multiplicar(valores[0], valores[1], valores[2]);

Spread em Objetos

Introduzido no ES2018, o Spread também pode ser utilizado com objetos.

const usuario = {
    nome: "Gustavo",
    idade: 21
};

const usuarioCompleto = {
    ...usuario,
    cidade: "Fortaleza"
};

Resultado:

{
    nome: "Gustavo",
    idade: 21,
    cidade: "Fortaleza"
}

Copiando Objetos

const original = {
    nome: "Gustavo"
};

const copia = {
    ...original
};

Alterando a cópia:

copia.nome = "Ana";

Resultado:

original.nome → Gustavo
copia.nome → Ana

Mesclando Objetos

const dadosPessoais = {
    nome: "Gustavo"
};

const endereco = {
    cidade: "Fortaleza"
};

const usuario = {
    ...dadosPessoais,
    ...endereco
};

Resultado:

{
    nome: "Gustavo",
    cidade: "Fortaleza"
}

Sobrescrevendo Propriedades

Quando existem propriedades repetidas, o último valor prevalece.

const usuario = {
    nome: "Gustavo",
    idade: 21
};

const atualizado = {
    ...usuario,
    idade: 22
};

Resultado:

{
    nome: "Gustavo",
    idade: 22
}

Cópias Rasas (Shallow Copy)

É importante entender que o Spread cria apenas uma cópia superficial.

Exemplo:

const usuario = {
    nome: "Gustavo",

    endereco: {
        cidade: "Fortaleza"
    }
};

const copia = {
    ...usuario
};

copia.endereco.cidade = "São Paulo";

console.log(usuario.endereco.cidade);

Resultado:

São Paulo

Isso acontece porque objetos aninhados continuam compartilhando a mesma referência.

Rest x Spread na Prática

function cadastrarUsuario(
    nome,
    ...habilidades
) {
    return {
        nome,
        habilidades: [...habilidades]
    };
}

Uso:

const usuario = cadastrarUsuario(
    "Gustavo",
    "HTML",
    "CSS",
    "JavaScript"
);

Resultado:

{
    nome: "Gustavo",
    habilidades: [
        "HTML",
        "CSS",
        "JavaScript"
    ]
}

Nesse exemplo:

  • ...habilidades → Rest
  • [...] → Spread

Comparação com o Objeto arguments

Antes do ES6, utilizava-se arguments.

function exemplo() {
    console.log(arguments);
}

Problemas:

  • Não é um array real.
  • Não funciona em Arrow Functions.
  • Possui menos recursos.

Hoje, o Rest é a abordagem recomendada.

function exemplo(...args) {
    console.log(args);
}

Vantagens

  • Reduz a quantidade de código.
  • Melhora a legibilidade.
  • Facilita a manipulação de arrays e objetos.
  • Simplifica a criação de cópias.
  • Torna funções mais flexíveis.
  • Substitui soluções antigas e complexas.

Erros Comuns

Confundir Rest com Spread

function exemplo(...valores) {}

Aqui é Rest.

const copia = [...array];

Aqui é Spread.

Esquecer que o Spread cria cópias rasas

Objetos aninhados continuam compartilhando referências.

Posicionar o Rest incorretamente

Incorreto:

function exemplo(...args, valor) {}

Utilizar Spread em valores não iteráveis

const numero = 10;

console.log(...numero);

Resultado:

TypeError

Boas Práticas

  • Utilize Rest para funções com quantidade variável de argumentos.
  • Utilize Spread para criar cópias e mesclar estruturas.
  • Evite modificar objetos originais desnecessariamente.
  • Lembre-se das limitações das cópias rasas.
  • Prefira Rest em vez de arguments.

Resumo

O operador ... pode atuar como Rest ou Spread, dependendo do contexto. O Rest agrupa múltiplos valores em um único array ou objeto, enquanto o Spread espalha elementos de estruturas iteráveis ou propriedades de objetos. Esses recursos simplificam a criação de funções flexíveis, a manipulação de arrays e objetos, a desestruturação de dados e a criação de cópias, tornando o código mais limpo, legível e moderno.
