Array Filter

Array.prototype.filter() em JavaScript

O método filter() é um dos métodos mais utilizados para manipulação de arrays em JavaScript. Ele permite criar um novo array contendo apenas os elementos que atendem a uma determinada condição.

Esse método faz parte dos métodos de alta ordem (higher-order functions), pois recebe uma função como argumento.

O que é o filter()?

O filter() percorre todos os elementos de um array e executa uma função de teste para cada item.

Se a função retornar true, o elemento é incluído no novo array.

Se retornar false, o elemento é ignorado.

Ao final, o método retorna um novo array contendo apenas os elementos aprovados no teste.

Sintaxe

array.filter(callback(elemento, indice, array), thisArg);

Parâmetros

ParâmetroDescrição
callbackFunção executada para cada elemento do array
elementoValor atual sendo processado
indicePosição do elemento no array (opcional)
arrayArray original (opcional)
thisArgValor usado como this dentro da callback (opcional)

Estrutura da Callback

const novoArray = array.filter(
    (elemento, indice, array) => {
        return condicao;
    }
);

A callback deve retornar um valor que será convertido para booleano.

  • Valores verdadeiros (truthy) → elemento mantido.
  • Valores falsos (falsy) → elemento removido.

Exemplo Básico

const numeros = [10, 25, 8, 42, 15];

const maioresQue20 = numeros.filter(
    numero => numero > 20
);

console.log(maioresQue20);

Resultado:

[25, 42]

O array original permanece inalterado.

console.log(numeros);

Resultado:

[10, 25, 8, 42, 15]

Como o filter() Funciona Internamente?

O comportamento do método pode ser representado da seguinte forma:

function meuFilter(array, callback) {
    const resultado = [];

    for (const elemento of array) {
        if (callback(elemento)) {
            resultado.push(elemento);
        }
    }

    return resultado;
}

Filtrando Strings

const nomes = [
    "Ana",
    "Carlos",
    "Amanda",
    "Pedro"
];

const nomesComA = nomes.filter(
    nome => nome.startsWith("A")
);

console.log(nomesComA);

Resultado:

["Ana", "Amanda"]

Filtrando Objetos

Um dos usos mais comuns do filter() é trabalhar com arrays de objetos.

const produtos = [
    { nome: "Notebook", preco: 3500 },
    { nome: "Mouse", preco: 100 },
    { nome: "Teclado", preco: 250 }
];

Filtrando produtos acima de R$ 200:

const produtosCaros = produtos.filter(
    produto => produto.preco > 200
);

console.log(produtosCaros);

Resultado:

[
    { nome: "Notebook", preco: 3500 },
    { nome: "Teclado", preco: 250 }
]

Utilizando Múltiplas Condições

const usuarios = [
    { nome: "Ana", idade: 17 },
    { nome: "Carlos", idade: 25 },
    { nome: "Maria", idade: 30 }
];

const adultos = usuarios.filter(
    usuario => usuario.idade >= 18
);

console.log(adultos);

Resultado:

[
    { nome: "Carlos", idade: 25 },
    { nome: "Maria", idade: 30 }
]

Também é possível combinar condições:

const resultado = usuarios.filter(
    usuario =>
        usuario.idade >= 18 &&
        usuario.nome.startsWith("M")
);

Removendo Valores Duplicados

O filter() pode ser usado para eliminar duplicatas.

const numeros = [1, 2, 2, 3, 4, 4, 5];

const unicos = numeros.filter(
    (numero, indice, array) =>
        array.indexOf(numero) === indice
);

console.log(unicos);

Resultado:

[1, 2, 3, 4, 5]

Removendo Valores Falsy

Valores falsy em JavaScript são:

  • false
  • 0
  • ""
  • null
  • undefined
  • NaN

Podemos removê-los facilmente:

const dados = [
    "JavaScript",
    "",
    null,
    0,
    "HTML",
    undefined
];

const filtrados = dados.filter(Boolean);

console.log(filtrados);

Resultado:

["JavaScript", "HTML"]

Encadeando Métodos

O filter() é frequentemente utilizado com outros métodos de arrays.

Exemplo com map():

const produtos = [
    { nome: "Notebook", preco: 3500 },
    { nome: "Mouse", preco: 100 },
    { nome: "Teclado", preco: 250 }
];

const nomes = produtos
    .filter(produto => produto.preco > 200)
    .map(produto => produto.nome);

console.log(nomes);

Resultado:

["Notebook", "Teclado"]

Diferença entre filter() e find()

Embora parecidos, possuem objetivos diferentes.

filter()

Retorna todos os elementos que atendem à condição.

const resultado = usuarios.filter(
    usuario => usuario.idade >= 18
);

Resultado:

[
    { nome: "Carlos", idade: 25 },
    { nome: "Maria", idade: 30 }
]

find()

Retorna apenas o primeiro elemento encontrado.

const resultado = usuarios.find(
    usuario => usuario.idade >= 18
);

Resultado:

{ nome: "Carlos", idade: 25 }

Características Importantes

  • Retorna um novo array.
  • Não altera o array original.
  • Percorre todos os elementos.
  • Ignora posições vazias em arrays esparsos.
  • Retorna um array vazio quando nenhuma condição é satisfeita.

Complexidade

O método percorre todos os elementos do array uma única vez.

Complexidade de tempo:

O(n)

Onde n representa a quantidade de elementos.

Erros Comuns

Esquecer de retornar um valor

Incorreto:

const resultado = numeros.filter(numero => {
    numero > 10;
});

Resultado:

[]

Correto:

const resultado = numeros.filter(numero => {
    return numero > 10;
});

Ou:

const resultado = numeros.filter(
    numero => numero > 10
);

Esperar que o array original seja modificado

numeros.filter(numero => numero > 10);

console.log(numeros);

O array original permanece o mesmo.

Usar filter() quando precisa de apenas um elemento

Se você precisa apenas do primeiro resultado, prefira find().

Boas Práticas

  • Utilize nomes descritivos para a callback.
  • Mantenha as condições simples.
  • Encadeie com map() e reduce() quando necessário.
  • Prefira find() para obter um único elemento.
  • Evite modificar elementos dentro da callback.

Resumo

O método filter() cria um novo array contendo apenas os elementos que satisfazem uma condição definida em uma função de teste. Ele não altera o array original, percorre todos os elementos e é amplamente utilizado para filtrar listas de números, strings e objetos. Sua combinação com outros métodos, como map() e reduce(), torna o código mais declarativo, legível e fácil de manter.
