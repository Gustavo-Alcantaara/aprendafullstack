Criação Dinâmica de Pares Nome/Valor

Objetos Literais — Criação Dinâmica de Pares Nome/Valor

Em JavaScript, os objetos literais são compostos por pares nome/valor (também chamados de chave/valor ou propriedade/valor).

Normalmente, definimos essas propriedades de forma estática:

const usuario = {
    nome: "Gustavo",
    idade: 21
};

No entanto, existem situações em que o nome da propriedade só é conhecido durante a execução do programa. Nesses casos, utilizamos a criação dinâmica de pares nome/valor.

Esse recurso permite que o JavaScript crie propriedades automaticamente com base em variáveis, expressões ou resultados de funções.

O que são Pares Nome/Valor?

Todo objeto é formado por propriedades.

A estrutura básica é:

const objeto = {
    nomeDaPropriedade: valor
};

Exemplo:

const produto = {
    nome: "Notebook",
    preco: 3500
};

Nesse caso:

  • nome → nome da propriedade.
  • "Notebook" → valor associado.
  • preco → nome da propriedade.
  • 3500 → valor associado.

Por que Criar Propriedades Dinamicamente?

A criação dinâmica é útil quando:

  • O nome da propriedade depende da entrada do usuário.
  • Os dados vêm de uma API.
  • As propriedades são geradas automaticamente.
  • O sistema precisa ser flexível.
  • O nome da propriedade é armazenado em uma variável.

Exemplo:

Imagine um sistema de configurações multilíngue:

const idioma = "ptBR";

O nome da propriedade deve ser criado dinamicamente:

const configuracoes = {
    [idioma]: {
        tema: "escuro"
    }
};

Resultado:

{
    ptBR: {
        tema: "escuro"
    }
}

Computed Property Names

O principal recurso utilizado para criar propriedades dinâmicas é o Computed Property Names, introduzido no ECMAScript 6 (ES6).

Sua sintaxe utiliza colchetes [].

Estrutura:

const objeto = {
    [expressao]: valor
};

A expressão dentro dos colchetes é avaliada e seu resultado se torna o nome da propriedade.

Exemplo com Variáveis

const propriedade = "email";

const usuario = {
    [propriedade]: "gustavo@email.com"
};

Resultado:

{
    email: "gustavo@email.com"
}

Sem os colchetes:

const usuario = {
    propriedade: "gustavo@email.com"
};

Resultado:

{
    propriedade: "gustavo@email.com"
}

Observe que o nome da propriedade seria literalmente "propriedade".

Exemplo com Expressões

As propriedades podem ser geradas a partir de expressões.

const prefixo = "user";

const objeto = {
    [`${prefixo}Id`]: 1,
    [`${prefixo}Nome`]: "Gustavo"
};

Resultado:

{
    userId: 1,
    userNome: "Gustavo"
}

Exemplo com Operações

const numero = 10;

const dados = {
    [`valor${numero * 2}`]: 20
};

Resultado:

{
    valor20: 20
}

Exemplo com Funções

Também é possível utilizar o retorno de funções.

function gerarChave() {
    return "token";
}

const sessao = {
    [gerarChave()]: "abc123"
};

Resultado:

{
    token: "abc123"
}

Adicionando Propriedades Dinamicamente Após a Criação

Além de criar propriedades dinamicamente na declaração do objeto, também é possível adicioná-las posteriormente.

Utilize a notação de colchetes:

const usuario = {};

const campo = "telefone";

usuario[campo] = "(85) 99999-9999";

Resultado:

{
    telefone: "(85) 99999-9999"
}

Exemplo Prático: Formulários

Imagine um formulário em que o usuário preenche campos dinamicamente.

const campo = "nome";
const valor = "Gustavo";

const formulario = {
    [campo]: valor
};

Resultado:

{
    nome: "Gustavo"
}

Essa técnica é muito utilizada em aplicações desenvolvidas com bibliotecas como React.

Exemplo:

const campo = event.target.name;
const valor = event.target.value;

setFormulario({
    ...formulario,
    [campo]: valor
});

Nesse caso, cada campo do formulário atualiza automaticamente a propriedade correspondente.

Exemplo Prático: Filtros de Busca

const filtro = "categoria";

const pesquisa = {
    [filtro]: "Tecnologia"
};

Resultado:

{
    categoria: "Tecnologia"
}

Combinando com Property Shorthand

As propriedades dinâmicas podem ser utilizadas junto com outras melhorias dos objetos literais.

const nome = "Gustavo";
const chave = "curso";

const aluno = {
    nome,
    [chave]: "JavaScript"
};

Resultado:

{
    nome: "Gustavo",
    curso: "JavaScript"
}

Vantagens da Criação Dinâmica

  • Maior flexibilidade.
  • Redução de código repetitivo.
  • Facilita a integração com APIs.
  • Simplifica a manipulação de formulários.
  • Permite criar estruturas mais genéricas.
  • Aumenta a reutilização de código.

Cuidados ao Utilizar

Evite nomes de propriedades inesperados

const chave = "";

Resultado:

{
    "": "valor"
}

Valide dados externos

Ao utilizar valores fornecidos pelo usuário, verifique se o nome da propriedade é válido.

Utilize nomes descritivos

Evite criar propriedades difíceis de entender.

Ruim:

const objeto = {
    [valor]: 10
};

Melhor:

const objeto = {
    [nomeDaPropriedade]: 10
};

Erros Comuns

Esquecer os colchetes

Incorreto:

const chave = "email";

const usuario = {
    chave: "gustavo@email.com"
};

Resultado:

{
    chave: "gustavo@email.com"
}

Correto

const usuario = {
    [chave]: "gustavo@email.com"
};

Resultado:

{
    email: "gustavo@email.com"
}

Resumo

A criação dinâmica de pares nome/valor permite definir propriedades de objetos utilizando valores calculados em tempo de execução. Esse recurso é implementado por meio dos Computed Property Names, utilizando colchetes [] para transformar variáveis, expressões ou funções em nomes de propriedades. Essa funcionalidade é amplamente utilizada em formulários dinâmicos, integrações com APIs e aplicações modernas, tornando o código mais flexível, reutilizável e fácil de manter.
