Objetos Literais/Estáticos

Objetos Literais (Objetos Estáticos) em JavaScript

Os objetos literais são a forma mais simples e direta de criar objetos em JavaScript. Eles permitem agrupar dados e comportamentos relacionados em uma única estrutura, utilizando a notação de chaves {}.

Também é comum encontrar o termo objeto estático para se referir a um objeto literal criado diretamente no código. No entanto, é importante destacar que, em JavaScript, o termo técnico mais adequado é objeto literal.

O que é um Objeto Literal?

Um objeto literal é um conjunto de pares chave-valor, onde cada chave representa uma propriedade e cada valor representa a informação armazenada ou uma função associada ao objeto.

Exemplo:

const pessoa = {
    nome: "Gustavo",
    idade: 21,
    profissao: "Desenvolvedor"
};

Nesse exemplo:

  • nome, idade e profissao são as propriedades.
  • "Gustavo", 21 e "Desenvolvedor" são os valores.

Estrutura de um Objeto Literal

A sintaxe básica é:

const objeto = {
    propriedade1: valor1,
    propriedade2: valor2
};

Exemplo:

const carro = {
    marca: "Toyota",
    modelo: "Corolla",
    ano: 2024
};

Acessando Propriedades

Existem duas formas principais de acessar as propriedades de um objeto.

Notação de ponto

É a forma mais comum e legível.

console.log(carro.marca);
console.log(carro.modelo);

Resultado:

Toyota
Corolla

Notação de colchetes

É útil quando o nome da propriedade é dinâmico.

console.log(carro["ano"]);

Resultado:

2024

Também pode ser utilizada com variáveis:

const propriedade = "marca";

console.log(carro[propriedade]);

Resultado:

Toyota

Adicionando e Alterando Propriedades

Os objetos em JavaScript são mutáveis, ou seja, suas propriedades podem ser alteradas após a criação.

Alterando uma propriedade:

carro.ano = 2025;

Adicionando uma nova propriedade:

carro.cor = "Prata";

Objeto atualizado:

{
    marca: "Toyota",
    modelo: "Corolla",
    ano: 2025,
    cor: "Prata"
}

Removendo Propriedades

Utilizamos o operador delete.

delete carro.cor;

A propriedade cor será removida do objeto.

Métodos em Objetos Literais

Além de armazenar dados, objetos podem conter funções chamadas métodos.

Exemplo:

const pessoa = {
    nome: "Gustavo",

    apresentar() {
        console.log(`Olá, meu nome é ${this.nome}`);
    }
};

Uso:

pessoa.apresentar();

Resultado:

Olá, meu nome é Gustavo

A Palavra-chave this

Dentro de um método, this faz referência ao próprio objeto.

const produto = {
    nome: "Notebook",
    preco: 3500,

    mostrarPreco() {
        console.log(this.preco);
    }
};
produto.mostrarPreco();

Resultado:

3500

O this.preco acessa a propriedade preco do próprio objeto.

Objetos Literais Aninhados

Um objeto pode conter outros objetos.

const usuario = {
    nome: "Gustavo",

    endereco: {
        cidade: "Fortaleza",
        estado: "Ceará"
    }
};

Acesso:

console.log(usuario.endereco.cidade);

Resultado:

Fortaleza

Arrays Dentro de Objetos

Objetos também podem armazenar listas.

const aluno = {
    nome: "Gustavo",
    cursos: ["JavaScript", "React", "Node.js"]
};

Acesso:

console.log(aluno.cursos[0]);

Resultado:

JavaScript

Recursos Modernos do ECMAScript 6+

Property Shorthand

Quando o nome da variável é igual ao nome da propriedade:

const nome = "Gustavo";
const idade = 21;

const pessoa = {
    nome,
    idade
};

Equivale a:

const pessoa = {
    nome: nome,
    idade: idade
};

Método Simplificado

Forma moderna:

const calculadora = {
    somar(a, b) {
        return a + b;
    }
};

Forma tradicional:

const calculadora = {
    somar: function(a, b) {
        return a + b;
    }
};

Computed Properties

Permite criar propriedades dinamicamente.

const chave = "email";

const usuario = {
    [chave]: "gustavo@email.com"
};

Resultado:

{
    email: "gustavo@email.com"
}

Quando Utilizar Objetos Literais?

Os objetos literais são indicados quando:

  • Você precisa representar uma única entidade.
  • Não há necessidade de criar várias instâncias.
  • Os dados são simples.
  • O objeto não será reutilizado como modelo.

Exemplos:

  • Configurações de aplicação.
  • Dados de usuário logado.
  • Informações de um produto.
  • Respostas de APIs.
  • Objetos temporários.

Objetos Literais x Classes

Objeto Literal

Representa uma instância específica.

const usuario = {
    nome: "Gustavo"
};

Classe

Define um modelo para criar vários objetos.

class Usuario {
    constructor(nome) {
        this.nome = nome;
    }
}
const usuario1 = new Usuario("Gustavo");
const usuario2 = new Usuario("Ana");

Use classes quando precisar criar múltiplos objetos semelhantes.

Vantagens dos Objetos Literais

  • Sintaxe simples e intuitiva.
  • Criação rápida de objetos.
  • Fácil leitura e manutenção.
  • Ideal para estruturas pequenas.
  • Não exige uso de classes.

Limitações dos Objetos Literais

  • Não favorecem reutilização.
  • Podem gerar duplicação de código.
  • Não são ideais para muitas instâncias semelhantes.
  • Dificultam a manutenção em sistemas complexos.

Exemplo Completo

const aluno = {
    nome: "Gustavo",
    idade: 21,
    curso: "Desenvolvimento Web",

    estudar() {
        console.log(`${this.nome} está estudando.`);
    }
};

console.log(aluno.nome);

aluno.estudar();

Resultado:

Gustavo
Gustavo está estudando.

Resumo

Os objetos literais são a maneira mais simples de criar objetos em JavaScript, utilizando a notação {} para definir propriedades e métodos. Eles são ideais para representar dados únicos e estruturas simples, oferecendo praticidade e legibilidade. Embora sejam muito úteis no desenvolvimento cotidiano, para cenários que exigem múltiplas instâncias e maior reutilização de código, o uso de classes e outros padrões de projeto costuma ser mais adequado.
