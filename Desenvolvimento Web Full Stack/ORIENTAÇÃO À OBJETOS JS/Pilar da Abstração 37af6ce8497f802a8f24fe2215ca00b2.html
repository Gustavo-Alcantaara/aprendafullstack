Pilar da Abstração

Pilar da Abstração

A abstração é um dos quatro pilares fundamentais da Orientação a Objetos (OO), juntamente com encapsulamento, herança e polimorfismo. Ela é responsável por permitir que representemos elementos do mundo real dentro de um sistema de forma simplificada, destacando apenas as características e comportamentos relevantes para o contexto da aplicação.

Em outras palavras, a abstração consiste em responder à pergunta:

"O que esse objeto precisa fazer?"

e não

"Como ele faz isso internamente?"

Dessa forma, a abstração reduz a complexidade do sistema e torna o desenvolvimento mais organizado e intuitivo.

O que é Abstração?

Quando observamos qualquer objeto do mundo real, percebemos que ele possui inúmeras características e comportamentos.

Por exemplo, um carro possui:

  • Motor
  • Sistema elétrico
  • Transmissão
  • Freios
  • Pneus
  • Combustível
  • Computador de bordo
  • Sensores

Porém, ao criar um sistema de locadora de veículos, provavelmente não será necessário representar todos esses detalhes. Talvez seja suficiente armazenar:

  • Marca
  • Modelo
  • Ano
  • Cor
  • Quilometragem

Esse processo de selecionar apenas o que é importante para o sistema é chamado de abstração.

Objetivo da Abstração

O principal objetivo da abstração é:

  • Reduzir a complexidade.
  • Facilitar a modelagem do sistema.
  • Focar apenas nas informações necessárias.
  • Esconder detalhes irrelevantes.
  • Tornar o código mais compreensível.

Sem abstração, os sistemas se tornariam excessivamente complexos e difíceis de manter.

Abstração no Mundo Real

Utilizamos abstração diariamente sem perceber.

Exemplo: Televisão

Ao ligar uma televisão, você pressiona um botão.

Você sabe que:

Botão → Televisão liga

Mas não precisa saber:

  • Como a corrente elétrica é distribuída.
  • Como o processador da TV inicializa.
  • Como os circuitos são ativados.
  • Como a imagem é renderizada.

Toda essa complexidade está escondida.

Você interage apenas com a funcionalidade necessária.

Exemplo: Caixa Eletrônico

Quando você realiza um saque:

Inserir cartão
↓
Digitar senha
↓
Escolher valor
↓
Receber dinheiro

Você não precisa conhecer:

  • Como o banco valida a senha.
  • Como ocorre a comunicação com o servidor.
  • Como o saldo é atualizado.

O sistema abstrai toda essa complexidade.

Abstração na Programação

Em programação, a abstração consiste em criar modelos simplificados de objetos reais.

Por exemplo:

class Carro {
    ligar() {
        console.log("Carro ligado");
    }

    acelerar() {
        console.log("Acelerando...");
    }

    frear() {
        console.log("Freando...");
    }
}

Uso:

const carro = new Carro();

carro.ligar();
carro.acelerar();

O usuário da classe não precisa saber como o motor funciona internamente.

Ele apenas utiliza os métodos disponibilizados.

Processo de Abstração

Ao desenvolver um sistema, normalmente seguimos estas etapas:

1. Identificar a entidade

Exemplo:

Aluno

2. Identificar características

Nome
Idade
Matrícula
Curso

3. Identificar ações

Estudar
Realizar prova
Consultar notas

4. Criar a abstração

class Aluno {
    constructor(nome, matricula) {
        this.nome = nome;
        this.matricula = matricula;
    }

    estudar() {
        console.log(`${this.nome} está estudando.`);
    }
}

A classe representa apenas os aspectos importantes para o sistema.

Abstração e Classes

As classes são uma das principais ferramentas para implementar abstração.

Elas permitem definir:

  • Quais atributos serão expostos.
  • Quais comportamentos estarão disponíveis.
  • Como os objetos serão representados.

Exemplo:

class Produto {
    constructor(nome, preco) {
        this.nome = nome;
        this.preco = preco;
    }

    calcularDesconto(percentual) {
        return this.preco - (this.preco * percentual / 100);
    }
}

O usuário só precisa utilizar o método.

const produto = new Produto(
    "Notebook",
    3000
);

console.log(
    produto.calcularDesconto(10)
);

A lógica do cálculo fica escondida dentro da classe.

Abstração e Encapsulamento

Esses conceitos costumam gerar confusão.

Embora estejam relacionados, possuem funções diferentes.

Abstração

Foca em:

O que o objeto faz?

Exemplo:

conta.sacar(100);

Você sabe que a conta realiza saques.

Encapsulamento

Foca em:

Como os dados são protegidos?

Exemplo:

#saldo

O atributo é protegido e não pode ser acessado diretamente.

AbstraçãoEncapsulamento
Define funcionalidades.Protege informações.
Simplifica o uso.Controla o acesso.
Esconde a complexidade.Esconde a implementação interna.

Exemplos de Abstração no JavaScript

Você utiliza abstração constantemente.

Método forEach()

const numeros = [1, 2, 3];

numeros.forEach(numero => {
    console.log(numero);
});

Você não precisa saber como o JavaScript percorre o array internamente.

Método map()

const dobrados = [1, 2, 3].map(
    numero => numero * 2
);

A lógica interna está escondida.

DOM

document.getElementById("titulo");

Você não precisa conhecer o algoritmo utilizado para localizar o elemento na árvore DOM.

Benefícios da Abstração

1. Redução da Complexidade

Permite trabalhar com sistemas grandes sem precisar entender todos os detalhes internos.

2. Facilidade de Manutenção

Mudanças internas podem ser realizadas sem alterar a forma como o objeto é utilizado.

3. Maior Reutilização

Classes bem abstraídas podem ser reaproveitadas em diferentes projetos.

4. Melhor Organização

Cada objeto possui responsabilidades claras e definidas.

5. Desenvolvimento Mais Rápido

Os programadores podem utilizar funcionalidades sem conhecer sua implementação completa.

Erros Comuns

Abstrair informações demais

Criar classes genéricas demais pode dificultar a manutenção.

Exemplo ruim:

class Sistema {

}

O nome não informa sua responsabilidade.

Abstrair informações de menos

Adicionar detalhes irrelevantes pode tornar a classe complexa.

Exemplo:

class Aluno {
    constructor(
        nome,
        idade,
        altura,
        peso,
        corDoOlho,
        tamanhoDoPe
    ) {}
}

Nem sempre essas informações são necessárias.

Misturar responsabilidades

Uma classe deve representar apenas um conceito principal.

Resumo

A abstração é o pilar da Orientação a Objetos responsável por representar objetos do mundo real de forma simplificada, focando apenas nas características e comportamentos relevantes para o sistema. Ela reduz a complexidade do software, melhora a organização do código e permite que os desenvolvedores utilizem funcionalidades sem precisar conhecer todos os detalhes de sua implementação. Em conjunto com os demais pilares da OO, a abstração torna os sistemas mais claros, reutilizáveis e fáceis de manter.
