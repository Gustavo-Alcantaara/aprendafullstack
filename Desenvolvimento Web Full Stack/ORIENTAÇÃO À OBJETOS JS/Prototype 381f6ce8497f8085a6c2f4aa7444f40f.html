Prototype

Prototype em JavaScript

O prototype é um dos conceitos mais importantes e, ao mesmo tempo, mais desafiadores da linguagem JavaScript. Ele é a base da herança prototipal, mecanismo utilizado pela linguagem para compartilhar propriedades e métodos entre objetos.

Para compreender profundamente a Orientação a Objetos em JavaScript, é essencial entender como os protótipos funcionam.

O que é o prototype?

Em JavaScript, toda função possui automaticamente uma propriedade chamada prototype.

Essa propriedade é um objeto utilizado como modelo para os objetos criados por meio do operador new.

Exemplo:

function Pessoa(nome) {
    this.nome = nome;
}

console.log(Pessoa.prototype);

Resultado:

{
    constructor: Pessoa
}

Inicialmente, o objeto prototype contém apenas a propriedade constructor, que aponta para a própria função.

Entendendo a Herança Prototipal

Diferentemente de linguagens como Java ou C#, que utilizam herança baseada em classes, o JavaScript utiliza herança baseada em protótipos.

Isso significa que os objetos podem herdar características diretamente de outros objetos.

Quando uma propriedade não é encontrada em um objeto, o JavaScript procura essa propriedade em seu protótipo.

Esse processo continua até que a propriedade seja encontrada ou a cadeia de protótipos termine.

Esse mecanismo é chamado de:

Prototype Chain (cadeia de protótipos).

Criando Objetos com Funções Construtoras

Considere o exemplo:

function Usuario(nome) {
    this.nome = nome;
}

Criando uma instância:

const usuario = new Usuario("Gustavo");

Internamente, o JavaScript cria uma ligação entre o objeto e Usuario.prototype.

Podemos representar essa relação da seguinte forma:

usuario → Usuario.prototype → Object.prototype → null

Adicionando Métodos ao prototype

Uma das principais utilidades do prototype é compartilhar métodos entre todas as instâncias.

Exemplo:

function Pessoa(nome) {
    this.nome = nome;
}

Pessoa.prototype.apresentar = function() {
    console.log(`Olá, meu nome é ${this.nome}`);
};

Uso:

const pessoa1 = new Pessoa("Ana");
const pessoa2 = new Pessoa("Carlos");

pessoa1.apresentar();
pessoa2.apresentar();

Resultado:

Olá, meu nome é Ana
Olá, meu nome é Carlos

O método apresentar() existe apenas uma vez na memória e é compartilhado por todas as instâncias.

Por que Utilizar o prototype?

Sem prototype, cada objeto criaria sua própria cópia dos métodos.

Exemplo:

function Pessoa(nome) {
    this.nome = nome;

    this.apresentar = function() {
        console.log(this.nome);
    };
}

Criando objetos:

const p1 = new Pessoa("Ana");
const p2 = new Pessoa("Carlos");

Nesse caso:

p1.apresentar !== p2.apresentar

Cada objeto possui uma função diferente.

Com prototype:

p1.apresentar === p2.apresentar

Os métodos são compartilhados, reduzindo o consumo de memória.

Como o JavaScript Procura Propriedades?

Quando acessamos:

pessoa1.apresentar();

O JavaScript segue esta ordem:

  1. Procura apresentar em pessoa1.
  1. Se não encontrar, procura em Pessoa.prototype.
  1. Se ainda não encontrar, procura em Object.prototype.
  1. Se não existir, retorna undefined.

Exemplo:

console.log(pessoa1.toString());

Mesmo que toString() não tenha sido definido em pessoa1, ele existe em Object.prototype.

A Propriedade Interna [[Prototype]]

Todo objeto possui uma referência interna para seu protótipo.

Essa referência é conhecida como:

[[Prototype]]

Embora seja interna, podemos acessá-la por meio de:

Object.getPrototypeOf(objeto);

Exemplo:

console.log(
    Object.getPrototypeOf(pessoa1)
);

Resultado:

Pessoa.prototype

Também existe a propriedade __proto__, mas seu uso não é recomendado.

console.log(pessoa1.__proto__);

Prefira sempre:

Object.getPrototypeOf(pessoa1);

A Propriedade constructor

Todo protótipo possui uma propriedade chamada constructor.

Exemplo:

console.log(Pessoa.prototype.constructor);

Resultado:

[Function: Pessoa]

Essa propriedade aponta para a função construtora original.

Podemos utilizá-la para identificar quem criou um objeto.

console.log(
    pessoa1.constructor === Pessoa
);

Resultado:

true

Verificando a Cadeia de Protótipos

O operador instanceof verifica se um objeto pertence a determinada cadeia de protótipos.

console.log(
    pessoa1 instanceof Pessoa
);

Resultado:

true

Internamente, o JavaScript verifica se:

Pessoa.prototype

faz parte da cadeia de protótipos do objeto.

Criando Herança com prototype

Podemos conectar protótipos manualmente.

function Animal(nome) {
    this.nome = nome;
}

Animal.prototype.emitirSom = function() {
    console.log("Som genérico");
};
function Cachorro(nome) {
    Animal.call(this, nome);
}

Ligando os protótipos:

Cachorro.prototype = Object.create(
    Animal.prototype
);

Cachorro.prototype.constructor = Cachorro;

Sobrescrevendo métodos:

Cachorro.prototype.emitirSom = function() {
    console.log("Au au!");
};

Uso:

const dog = new Cachorro("Rex");

dog.emitirSom();

Resultado:

Au au!

Classes e prototype

As classes introduzidas no ES6 utilizam protótipos internamente.

Classe:

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }

    apresentar() {
        console.log(this.nome);
    }
}

Internamente, o método é armazenado em:

Pessoa.prototype.apresentar

Ou seja, as classes são uma sintaxe mais moderna para trabalhar com protótipos.

Métodos Importantes Relacionados ao prototype

Object.create()

Cria um objeto com um protótipo específico.

const animal = {
    emitirSom() {
        console.log("Som");
    }
};

const cachorro = Object.create(animal);

Object.getPrototypeOf()

Obtém o protótipo de um objeto.

Object.getPrototypeOf(cachorro);

Object.setPrototypeOf()

Altera o protótipo de um objeto.

Object.setPrototypeOf(cachorro, animal);

Seu uso deve ser evitado em aplicações críticas por questões de desempenho.

Boas Práticas

  • Defina métodos compartilhados no prototype.
  • Utilize Object.getPrototypeOf() em vez de __proto__.
  • Evite modificar Object.prototype.
  • Prefira classes em projetos modernos.
  • Estude a cadeia de protótipos para compreender o funcionamento da linguagem.

Erros Comuns

Confundir prototype com __proto__

  • prototype pertence às funções.
  • __proto__ representa o protótipo de um objeto.

Definir métodos dentro da função construtora

function Pessoa(nome) {
    this.apresentar = function() {};
}

Isso cria uma nova função para cada instância.

Alterar Object.prototype

Modificar o protótipo global pode gerar comportamentos inesperados.

Resumo

O prototype é o mecanismo fundamental que permite a herança em JavaScript. Toda função possui uma propriedade prototype, utilizada como modelo para os objetos criados com new. Quando uma propriedade não é encontrada em um objeto, o JavaScript a procura em sua cadeia de protótipos, processo conhecido como Prototype Chain. Esse mecanismo permite compartilhar métodos entre instâncias, reduzir o consumo de memória e implementar herança prototipal. Embora as classes modernas simplifiquem a sintaxe, elas continuam utilizando protótipos internamente.
