Abstração da Entidade

A abstração da entidade é o processo de identificar e representar apenas as características e comportamentos mais importantes de um elemento do mundo real dentro de um sistema, ignorando detalhes que não são relevantes para o contexto da aplicação.

Quando criamos uma classe em Orientação a Objetos, estamos fazendo uma abstração de uma entidade real. Isso significa que não copiamos a entidade por completo, mas apenas os aspectos necessários para resolver o problema.

O que é abstrair uma entidade?

Abstrair uma entidade significa responder à seguinte pergunta:

"Quais informações e ações dessa entidade são importantes para o meu sistema?"

Por exemplo, imagine a entidade Pessoa.

Uma pessoa real possui inúmeras características:

  • Nome
  • Idade
  • Altura
  • Peso
  • Cor dos olhos
  • Tipo sanguíneo
  • Nacionalidade
  • Impressão digital
  • Preferências pessoais
  • Entre muitas outras

No entanto, um sistema escolar provavelmente não precisa armazenar todas essas informações. Talvez apenas:

  • Nome
  • Matrícula
  • Idade

Nesse caso, a classe representa uma abstração da entidade real.

class Aluno {
    constructor(matricula, nome, idade) {
        this.matricula = matricula;
        this.nome = nome;
        this.idade = idade;
    }
}

Perceba que o sistema não tenta representar tudo sobre uma pessoa, apenas o que é relevante para o contexto escolar.

A abstração depende do contexto

Uma mesma entidade pode ser abstraída de formas diferentes dependendo do sistema.

Em um sistema de escola

class Aluno {
    constructor(nome, matricula, curso) {
        this.nome = nome;
        this.matricula = matricula;
        this.curso = curso;
    }
}

Em um sistema hospitalar

class Paciente {
    constructor(nome, tipoSanguineo, peso) {
        this.nome = nome;
        this.tipoSanguineo = tipoSanguineo;
        this.peso = peso;
    }
}

A entidade real continua sendo uma pessoa, mas a abstração muda de acordo com as necessidades do sistema.

Características e ações abstraídas

Ao abstrair uma entidade, normalmente identificamos:

Características (atributos)

Representam os dados importantes.

class Carro {
    constructor(marca, modelo, velocidade) {
        this.marca = marca;
        this.modelo = modelo;
        this.velocidade = velocidade;
    }
}

Ações (métodos)

Representam os comportamentos importantes.

class Carro {
    acelerar() {
        console.log("Acelerando...");
    }

    frear() {
        console.log("Freando...");
    }
}

Esses métodos representam ações relevantes para a entidade "Carro".

Exemplo prático

Imagine um sistema de banco.

Uma conta bancária real possui diversos processos internos:

  • Comunicação com servidores
  • Criptografia
  • Validações de segurança
  • Registro de operações
  • Auditoria

Porém, para o usuário do sistema, basta enxergar operações simples:

class Conta {
    depositar(valor) {
        console.log(`Depósito de R$${valor}`);
    }

    sacar(valor) {
        console.log(`Saque de R$${valor}`);
    }

    consultarSaldo() {
        console.log("Consultando saldo...");
    }
}

A complexidade interna foi abstraída, expondo apenas as funcionalidades essenciais.

Benefícios da abstração da entidade

  • Reduz a complexidade do sistema.
  • Facilita a modelagem de problemas reais.
  • Torna o código mais organizado.
  • Melhora a manutenção.
  • Evita informações desnecessárias.
  • Permite focar apenas no que é importante para o contexto.

Resumo

A abstração da entidade consiste em criar uma representação simplificada de um elemento do mundo real, selecionando apenas as características e ações relevantes para o sistema. Em vez de modelar todos os detalhes da entidade, a Orientação a Objetos foca apenas nas informações necessárias para resolver o problema proposto, tornando o desenvolvimento mais eficiente e organizado.
