Função Factory

Funções Factory em JavaScript

As Funções Factory (Factory Functions) são funções responsáveis por criar e retornar objetos. Elas representam uma alternativa às funções construtoras e às classes, oferecendo uma forma simples, flexível e moderna de aplicar conceitos de Orientação a Objetos em JavaScript.

O termo factory significa fábrica, pois esse tipo de função atua como uma fábrica de objetos: recebe dados de entrada e produz novas instâncias prontas para uso.

O que é uma Função Factory?

Uma função factory é uma função comum que retorna um objeto literal.

Exemplo:

function criarUsuario(nome, email) {
    return {
        nome,
        email
    };
}

Criando objetos:

const usuario1 = criarUsuario(
    "Gustavo",
    "gustavo@email.com"
);

const usuario2 = criarUsuario(
    "Ana",
    "ana@email.com"
);

Resultado:

{
    nome: "Gustavo",
    email: "gustavo@email.com"
}
{
    nome: "Ana",
    email: "ana@email.com"
}

Cada chamada da função retorna um novo objeto.

Por que Utilizar Funções Factory?

Sem uma função factory, seria necessário criar cada objeto manualmente.

const produto1 = {
    nome: "Notebook",
    preco: 3500
};

const produto2 = {
    nome: "Mouse",
    preco: 100
};

Com uma função factory:

function criarProduto(nome, preco) {
    return {
        nome,
        preco
    };
}
const notebook = criarProduto(
    "Notebook",
    3500
);

const mouse = criarProduto(
    "Mouse",
    100
);

O código torna-se mais organizado e reutilizável.

Estrutura Básica

A sintaxe geral é:

function criarObjeto(parametros) {
    return {
        propriedades,
        metodos
    };
}

Exemplo:

function criarCarro(marca, modelo) {
    return {
        marca,
        modelo
    };
}

Uso:

const carro = criarCarro(
    "Toyota",
    "Corolla"
);

Funções Factory e Property Shorthand

As funções factory utilizam frequentemente o recurso de Property Shorthand, introduzido no ES6.

Sem shorthand:

function criarUsuario(nome, idade) {
    return {
        nome: nome,
        idade: idade
    };
}

Com shorthand:

function criarUsuario(nome, idade) {
    return {
        nome,
        idade
    };
}

Essa sintaxe reduz repetições e melhora a legibilidade.

Adicionando Métodos

As funções factory podem criar objetos com comportamentos.

function criarPessoa(nome) {
    return {
        nome,

        apresentar() {
            console.log(
                `Olá, meu nome é ${nome}`
            );
        }
    };
}

Uso:

const pessoa = criarPessoa("Gustavo");

pessoa.apresentar();

Resultado:

Olá, meu nome é Gustavo

Encapsulamento com Closures

Uma das maiores vantagens das funções factory é a facilidade para criar atributos privados utilizando closures.

function criarConta(saldoInicial) {
    let saldo = saldoInicial;

    return {
        depositar(valor) {
            if (valor > 0) {
                saldo += valor;
            }
        },

        sacar(valor) {
            if (valor > 0 && valor <= saldo) {
                saldo -= valor;
            }
        },

        consultarSaldo() {
            return saldo;
        }
    };
}

Uso:

const conta = criarConta(1000);

conta.depositar(500);

console.log(conta.consultarSaldo());

Resultado:

1500

Tentativa de acesso direto:

console.log(conta.saldo);

Resultado:

undefined

O atributo saldo permanece privado.

O Papel das Closures

Os métodos retornados pela função mantêm acesso às variáveis locais mesmo após a execução da função.

Isso ocorre porque cada método cria uma closure sobre o escopo da função factory.

function criarContador() {
    let valor = 0;

    return {
        incrementar() {
            valor++;
        },

        obterValor() {
            return valor;
        }
    };
}

Cada instância possui seu próprio estado privado.

Funções Factory x Funções Construtoras

Função Factory

function criarUsuario(nome) {
    return { nome };
}

const usuario = criarUsuario("Gustavo");

Características:

  • Não utiliza new.
  • Não utiliza this.
  • Retorna objetos explicitamente.

Função Construtora

function Usuario(nome) {
    this.nome = nome;
}

const usuario = new Usuario("Gustavo");

Características:

  • Utiliza new.
  • Utiliza this.
  • O retorno é implícito.

Funções Factory x Classes

Classe:

class Usuario {
    constructor(nome) {
        this.nome = nome;
    }
}

const usuario = new Usuario("Gustavo");

Factory:

function criarUsuario(nome) {
    return { nome };
}

Classes são mais adequadas quando:

  • Há necessidade de herança.
  • Métodos devem ser compartilhados.
  • O projeto segue uma arquitetura orientada a objetos tradicional.

Factories são mais adequadas quando:

  • O encapsulamento é importante.
  • A simplicidade é prioridade.
  • Não há necessidade de herança.
  • Deseja-se evitar this e new.

Vantagens das Funções Factory

  • Sintaxe simples.
  • Não dependem de new.
  • Evitam problemas com this.
  • Facilitam o encapsulamento.
  • Permitem criar objetos privados facilmente.
  • São flexíveis e fáceis de testar.

Desvantagens

  • Métodos podem ser duplicados entre instâncias.
  • Não utilizam protótipos automaticamente.
  • Podem consumir mais memória.
  • Herança pode ser mais complexa.

Compartilhando Métodos

Para evitar a duplicação de métodos, podemos criar um objeto auxiliar.

const metodos = {
    apresentar() {
        console.log(this.nome);
    }
};
function criarPessoa(nome) {
    return {
        nome,
        ...metodos
    };
}

Outra opção é utilizar Object.create().

const metodos = {
    apresentar() {
        console.log(this.nome);
    }
};

function criarPessoa(nome) {
    return Object.assign(
        Object.create(metodos),
        { nome }
    );
}

Assim, os métodos são compartilhados.

Quando Utilizar Funções Factory?

As funções factory são indicadas para:

  • Objetos com estado privado.
  • Aplicações funcionais.
  • Componentes independentes.
  • Projetos pequenos e médios.
  • APIs simples.
  • Código que exige alta flexibilidade.

Boas Práticas

  • Utilize nomes descritivos, como criarUsuario() ou criarProduto().
  • Retorne apenas o necessário.
  • Aproveite o Property Shorthand.
  • Utilize closures para dados privados.
  • Evite criar métodos desnecessariamente dentro da função quando eles puderem ser compartilhados.

Resumo

As funções factory são funções que criam e retornam objetos, oferecendo uma alternativa simples e flexível às funções construtoras e às classes. Elas dispensam o uso de new e this, facilitam o encapsulamento por meio de closures e permitem criar objetos de forma mais intuitiva. Embora possam gerar duplicação de métodos, são amplamente utilizadas em aplicações modernas devido à sua simplicidade, legibilidade e facilidade de manutenção.
