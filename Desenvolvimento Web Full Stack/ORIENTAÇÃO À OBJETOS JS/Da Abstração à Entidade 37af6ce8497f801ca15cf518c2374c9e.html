Da Abstração à Entidade

Quando desenvolvemos um sistema utilizando Orientação a Objetos, geralmente seguimos um processo que começa na abstração e termina na criação de uma entidade. Esse processo consiste em observar um elemento do mundo real, identificar o que é importante nele e representá-lo através de uma classe ou objeto.

1. Abstração

A abstração é o primeiro passo. Nela, analisamos um objeto ou conceito do mundo real e selecionamos apenas as informações relevantes para o sistema, ignorando detalhes desnecessários.

Por exemplo, imagine que estamos desenvolvendo um sistema para uma escola e precisamos representar um aluno.

No mundo real, um aluno possui inúmeras características:

  • Altura
  • Peso
  • Cor dos olhos
  • Endereço
  • Série
  • Matrícula
  • Notas
  • Turma

Nem todas essas informações serão importantes para o sistema. A abstração serve justamente para filtrar apenas o que será útil.

2. Identificação da Entidade

Após abstrair as informações relevantes, definimos qual entidade será representada.

Neste caso:

Entidade: Aluno

A entidade é o elemento principal que estamos modelando dentro do sistema.

class Aluno {

}

Nesse momento, sabemos apenas que existe uma entidade chamada Aluno.

3. Definição da Identidade

Em seguida, precisamos definir como cada entidade será diferenciada das demais.

Um aluno pode ser identificado por:

  • Matrícula
  • CPF
  • Código interno

Exemplo:

class Aluno {
    constructor(matricula) {
        this.matricula = matricula;
    }
}

A matrícula passa a representar a identidade única de cada aluno.

4. Definição das Características

Agora adicionamos os atributos que descrevem a entidade.

class Aluno {
    constructor(matricula, nome, idade, turma) {
        this.matricula = matricula;
        this.nome = nome;
        this.idade = idade;
        this.turma = turma;
    }
}

Características:

  • nome
  • idade
  • turma

Esses atributos armazenam informações sobre o aluno.

5. Definição das Ações

Por fim, adicionamos os comportamentos que a entidade pode executar.

class Aluno {
    constructor(matricula, nome, idade, turma) {
        this.matricula = matricula;
        this.nome = nome;
        this.idade = idade;
        this.turma = turma;
    }

    estudar() {
        console.log(`${this.nome} está estudando.`);
    }

    fazerProva() {
        console.log(`${this.nome} está realizando uma prova.`);
    }
}

As ações representam aquilo que o objeto pode fazer.

Exemplo Completo

class Aluno {
    constructor(matricula, nome, idade, turma) {
        this.matricula = matricula; // identidade
        this.nome = nome;           // característica
        this.idade = idade;         // característica
        this.turma = turma;         // característica
    }

    estudar() {                    // ação
        console.log(`${this.nome} está estudando.`);
    }

    fazerProva() {                 // ação
        console.log(`${this.nome} está fazendo uma prova.`);
    }
}
const aluno = new Aluno(
    "2026001",
    "Gustavo",
    21,
    "ADS"
);

aluno.estudar();

Fluxo da Abstração à Entidade

Mundo Real
     ↓
Abstração
     ↓
Entidade
     ↓
Identidade
     ↓
Características
     ↓
Ações
     ↓
Classe/Objeto

Resumo

A criação de uma entidade em Orientação a Objetos começa pela abstração, onde identificamos apenas os aspectos importantes de um elemento do mundo real. Em seguida, definimos a entidade, sua identidade, suas características e suas ações. O resultado é uma classe capaz de representar esse elemento dentro do sistema de forma organizada e próxima da realidade.
