Pilar do Polimorfismo

Pilar do Polimorfismo

O polimorfismo é um dos quatro pilares fundamentais da Orientação a Objetos (OO), juntamente com a abstração, o encapsulamento e a herança. A palavra "polimorfismo" tem origem no grego:

  • Poli = muitas
  • Morphos = formas

Portanto, polimorfismo significa literalmente:

"Muitas formas"

Na programação, isso significa que objetos diferentes podem responder à mesma mensagem ou método de maneiras diferentes.

O polimorfismo permite que utilizemos uma única interface para representar diversos comportamentos, tornando o código mais flexível, reutilizável e fácil de expandir.

O que é Polimorfismo?

Imagine que estamos desenvolvendo um sistema para uma clínica veterinária.

Todos os animais podem emitir sons:

  • Cachorro → Au Au
  • Gato → Miau
  • Pássaro → Piu Piu

Embora a ação seja a mesma (emitir som), cada animal executa essa ação de forma diferente.

Essa é exatamente a ideia do polimorfismo.

class Animal {
    emitirSom() {
        console.log("Som genérico");
    }
}
class Cachorro extends Animal {
    emitirSom() {
        console.log("Au Au");
    }
}
class Gato extends Animal {
    emitirSom() {
        console.log("Miau");
    }
}
class Passaro extends Animal {
    emitirSom() {
        console.log("Piu Piu");
    }
}

Uso:

const cachorro = new Cachorro();
const gato = new Gato();
const passaro = new Passaro();

cachorro.emitirSom();
gato.emitirSom();
passaro.emitirSom();

Resultado:

Au Au
Miau
Piu Piu

O método possui o mesmo nome, mas assume comportamentos diferentes dependendo do objeto.

Objetivo do Polimorfismo

O principal objetivo do polimorfismo é permitir que diferentes objetos sejam tratados de maneira uniforme.

Sem polimorfismo, precisaríamos criar várias verificações condicionais:

if(tipo === "cachorro") {
    console.log("Au Au");
}
else if(tipo === "gato") {
    console.log("Miau");
}
else if(tipo === "passaro") {
    console.log("Piu Piu");
}

À medida que novos tipos surgissem, o código cresceria e ficaria mais difícil de manter.

Com polimorfismo:

animal.emitirSom();

Cada objeto sabe como executar a ação.

Como o Polimorfismo Funciona?

O polimorfismo geralmente ocorre através da combinação de:

  • Herança
  • Sobrescrita de métodos (Override)

Primeiro criamos uma classe base:

class Funcionario {
    calcularBonus() {
        return 0;
    }
}

Depois criamos especializações:

class Gerente extends Funcionario {
    calcularBonus() {
        return 5000;
    }
}
class Desenvolvedor extends Funcionario {
    calcularBonus() {
        return 2000;
    }
}

Embora todos possuam o método calcularBonus(), cada classe fornece sua própria implementação.

Sobrescrita de Métodos (Override)

A sobrescrita acontece quando uma subclasse redefine um método herdado.

Classe pai:

class Pessoa {
    apresentar() {
        console.log("Sou uma pessoa.");
    }
}

Classe filha:

class Aluno extends Pessoa {
    apresentar() {
        console.log("Sou um aluno.");
    }
}

Uso:

const aluno = new Aluno();

aluno.apresentar();

Resultado:

Sou um aluno.

O método herdado foi substituído por uma implementação mais específica.

Exemplo Prático: Sistema de Pagamentos

Imagine um e-commerce.

Todos os pagamentos precisam ser processados.

Classe base:

class Pagamento {
    processar() {
        console.log("Processando pagamento...");
    }
}

Métodos de pagamento específicos:

class Pix extends Pagamento {
    processar() {
        console.log("Pagamento realizado via PIX.");
    }
}
class Cartao extends Pagamento {
    processar() {
        console.log("Pagamento realizado com cartão.");
    }
}
class Boleto extends Pagamento {
    processar() {
        console.log("Pagamento realizado por boleto.");
    }
}

Uso:

const pagamentos = [
    new Pix(),
    new Cartao(),
    new Boleto()
];

pagamentos.forEach(pagamento => {
    pagamento.processar();
});

Resultado:

Pagamento realizado via PIX.
Pagamento realizado com cartão.
Pagamento realizado por boleto.

O código principal não precisa saber qual tipo de pagamento está sendo utilizado.

Polimorfismo na Vida Real

Controle Remoto

O botão Ligar existe em diversos aparelhos:

  • Televisão
  • Ar-condicionado
  • Som
  • Projetor

A ação é a mesma:

Ligar

Mas cada aparelho executa essa ação de maneira diferente.

Esse é um exemplo clássico de polimorfismo.

Motoristas e Veículos

Um motorista pode dirigir:

  • Carro
  • Moto
  • Caminhão

A ação:

Dirigir

Permanece a mesma.

Mas cada veículo possui comportamentos específicos.

Polimorfismo de Inclusão

O tipo mais comum em Orientação a Objetos é o Polimorfismo de Inclusão, que ocorre através da herança.

Exemplo:

class Animal {}
class Cachorro extends Animal {}

Como Cachorro é um Animal, podemos fazer:

const animal = new Cachorro();

A variável possui o tipo da classe pai, mas referencia um objeto da classe filha.

Polimorfismo e Arrays

Uma das maiores vantagens do polimorfismo aparece quando trabalhamos com coleções.

const funcionarios = [
    new Gerente(),
    new Desenvolvedor(),
    new Gerente()
];

Percorrendo:

funcionarios.forEach(funcionario => {
    console.log(
        funcionario.calcularBonus()
    );
});

Resultado:

5000
2000
5000

Cada objeto responde de forma diferente à mesma chamada.

Benefícios do Polimorfismo

1. Flexibilidade

Permite adicionar novos comportamentos sem alterar o código existente.

2. Reutilização

A mesma estrutura pode trabalhar com vários tipos de objetos.

3. Escalabilidade

Novas classes podem ser criadas facilmente.

4. Redução de Condicionais

Evita grandes blocos de:

if
else
switch

5. Código Mais Limpo

Cada objeto é responsável pelo próprio comportamento.

Polimorfismo x Herança

Muitas pessoas confundem esses conceitos.

Herança

Define a relação entre classes.

class Animal {}
class Cachorro extends Animal {}

Polimorfismo

Permite que a subclasse altere o comportamento herdado.

class Cachorro extends Animal {
    emitirSom() {
        console.log("Au Au");
    }
}

A herança cria a estrutura.

O polimorfismo cria a flexibilidade.

Polimorfismo x Encapsulamento

EncapsulamentoPolimorfismo
Protege os dados.Permite múltiplos comportamentos.
Controla o acesso às informações.Controla como os objetos respondem às ações.
Foca na segurança.Foca na flexibilidade.

Erros Comuns

Criar herança sem necessidade

Nem toda classe precisa herdar de outra.

Sobrescrever métodos sem manter coerência

O método sobrescrito deve continuar representando a mesma ação.

Ruim:

class Cachorro extends Animal {
    emitirSom() {
        apagarBancoDeDados();
    }
}

O comportamento não corresponde ao propósito do método.

Usar condicionais em vez de polimorfismo

Ruim:

if(tipo === "pix") {
    ...
}
else if(tipo === "cartao") {
    ...
}

Melhor:

pagamento.processar();

Resumo

O polimorfismo é o pilar da Orientação a Objetos que permite que diferentes objetos respondam à mesma ação de maneiras distintas. Ele normalmente é implementado através da herança e da sobrescrita de métodos, permitindo que uma única interface represente vários comportamentos. Seu principal benefício é tornar o código mais flexível, reutilizável, organizado e fácil de expandir, reduzindo a necessidade de estruturas condicionais complexas e tornando os sistemas mais preparados para mudanças futuras.
