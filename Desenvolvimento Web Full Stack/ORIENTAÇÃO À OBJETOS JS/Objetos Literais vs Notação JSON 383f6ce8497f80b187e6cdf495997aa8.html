Objetos Literais vs Notação JSON

Embora objetos literais e JSON possuam uma sintaxe visualmente semelhante, eles são conceitos diferentes e possuem finalidades distintas.

Essa semelhança costuma gerar confusão, especialmente para quem está começando a estudar JavaScript.

De forma resumida:

  • Objeto literal é uma estrutura nativa do JavaScript utilizada para criar objetos.
  • JSON é um formato de texto utilizado para armazenar e transportar dados.

O que é um Objeto Literal?

Um objeto literal é uma forma simples e direta de criar objetos em JavaScript.

Exemplo:

const usuario = {
    nome: "Gustavo",
    idade: 21,

    apresentar() {
        console.log(`Olá, meu nome é ${this.nome}`);
    }
};

Nesse exemplo, usuario é um objeto JavaScript completo, capaz de armazenar:

  • Propriedades
  • Métodos
  • Arrays
  • Outros objetos
  • Funções

Os objetos literais existem apenas durante a execução da aplicação.

O que é JSON?

JSON significa:

JavaScript Object Notation

Apesar do nome, JSON é um formato independente da linguagem JavaScript.

Ele é utilizado para:

  • Troca de dados entre cliente e servidor.
  • Armazenamento de configurações.
  • Persistência de informações.
  • Integração entre sistemas.

Exemplo de JSON:

{
    "nome": "Gustavo",
    "idade": 21
}

JSON é apenas texto.

Ele não executa código nem possui comportamentos.

Sintaxe dos Objetos Literais

Nos objetos literais, as chaves podem ser escritas sem aspas.

const produto = {
    nome: "Notebook",
    preco: 3500
};

Também é possível utilizar aspas.

const produto = {
    "nome": "Notebook",
    "preco": 3500
};

Ambas as formas são válidas.

Sintaxe do JSON

No JSON, as chaves devem estar obrigatoriamente entre aspas duplas.

Correto:

{
    "nome": "Notebook",
    "preco": 3500
}

Incorreto:

{
    nome: "Notebook",
    preco: 3500
}

Métodos em Objetos Literais

Objetos literais podem armazenar funções.

const pessoa = {
    nome: "Ana",

    apresentar() {
        console.log(`Olá, ${this.nome}`);
    }
};

Uso:

pessoa.apresentar();

Resultado:

Olá, Ana

Métodos em JSON

JSON não suporta funções.

Incorreto:

{
    "nome": "Ana",
    "apresentar": function() {}
}

JSON deve conter apenas:

  • Strings
  • Números
  • Booleanos
  • Arrays
  • Objetos
  • null

Comentários

Objetos literais permitem comentários.

const configuracoes = {
    // Tema da aplicação
    tema: "escuro"
};

JSON não permite comentários.

Incorreto:

{
    // Tema da aplicação
    "tema": "escuro"
}

Aspas Simples e Duplas

Objetos literais aceitam aspas simples, duplas e crases.

const usuario = {
    nome: 'Gustavo',
    cidade: "Fortaleza",
    mensagem: `Olá`
};

JSON aceita apenas aspas duplas.

Correto:

{
    "nome": "Gustavo"
}

Incorreto:

{
    'nome': 'Gustavo'
}

Vírgula Final

Objetos literais permitem vírgulas após o último elemento.

const usuario = {
    nome: "Gustavo",
    idade: 21,
};

JSON não permite vírgulas finais.

Incorreto:

{
    "nome": "Gustavo",
    "idade": 21,
}

Conversão entre Objetos e JSON

Como JSON é um formato textual, frequentemente precisamos converter dados.

Convertendo Objeto para JSON

Utilizamos JSON.stringify().

const usuario = {
    nome: "Gustavo",
    idade: 21
};

const json = JSON.stringify(usuario);

console.log(json);

Resultado:

{"nome":"Gustavo","idade":21}

Observe que o resultado é uma string.

Convertendo JSON para Objeto

Utilizamos JSON.parse().

const json = '{"nome":"Gustavo","idade":21}';

const usuario = JSON.parse(json);

console.log(usuario.nome);

Resultado:

Gustavo

O que Acontece com Métodos?

Ao converter um objeto para JSON, os métodos são ignorados.

const usuario = {
    nome: "Gustavo",

    apresentar() {
        console.log("Olá");
    }
};

const json = JSON.stringify(usuario);

console.log(json);

Resultado:

{"nome":"Gustavo"}

A função apresentar() não é incluída.

JSON em APIs

Grande parte das APIs modernas utiliza JSON para enviar e receber informações.

Exemplo de resposta de uma API:

{
    "id": 1,
    "nome": "Gustavo",
    "email": "gustavo@email.com"
}

Ao receber esses dados, normalmente fazemos:

fetch("/usuarios/1")
    .then(resposta => resposta.json())
    .then(usuario => {
        console.log(usuario.nome);
    });

O método json() converte automaticamente o JSON recebido em um objeto JavaScript.

Quando Utilizar Cada Um?

Utilize objetos literais quando precisar:

  • Representar entidades na aplicação.
  • Criar métodos e comportamentos.
  • Organizar dados em memória.

Utilize JSON quando precisar:

  • Armazenar dados.
  • Enviar informações pela internet.
  • Salvar configurações.
  • Integrar sistemas diferentes.

Erros Comuns

Tentar adicionar funções em JSON

{
    "somar": function() {}
}

Esquecer as aspas nas chaves do JSON

{
    nome: "Gustavo"
}

Utilizar aspas simples em JSON

{
    'nome': 'Gustavo'
}

Esquecer de converter JSON para objeto

const json = '{"nome":"Gustavo"}';

console.log(json.nome);

Resultado:

undefined

É necessário utilizar:

const usuario = JSON.parse(json);

Resumo

Embora possuam sintaxes semelhantes, objetos literais e JSON têm propósitos diferentes. Objetos literais são estruturas nativas do JavaScript que podem armazenar propriedades e métodos, enquanto JSON é um formato de texto utilizado para armazenar e transmitir dados. Objetos literais oferecem mais flexibilidade e recursos da linguagem, enquanto JSON possui regras mais rígidas para garantir compatibilidade entre diferentes sistemas e linguagens de programação.
