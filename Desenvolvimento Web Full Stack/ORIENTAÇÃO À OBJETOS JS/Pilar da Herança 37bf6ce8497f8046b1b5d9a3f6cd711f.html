Pilar da Herança

Pilar da Herança

A herança é um dos quatro pilares da Orientação a Objetos, juntamente com abstração, encapsulamento e polimorfismo. Seu objetivo é permitir que uma classe reutilize atributos e métodos de outra classe, evitando a repetição de código e facilitando a manutenção do sistema.

Em outras palavras, a herança permite criar uma nova classe baseada em uma classe já existente, aproveitando suas características e comportamentos.

Conceito de Herança

Imagine que estamos desenvolvendo um sistema escolar. Tanto alunos quanto professores possuem características em comum:

  • Nome
  • Idade
  • CPF

Em vez de repetir esses atributos em várias classes, podemos criar uma classe mais genérica chamada Pessoa e fazer com que Aluno e Professor herdem suas características.

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}
class Aluno extends Pessoa {

}

class Professor extends Pessoa {

}

As classes Aluno e Professor passam a possuir automaticamente os atributos da classe Pessoa.

Classe Pai e Classe Filha

Na herança existem dois conceitos importantes:

Classe Pai (Superclasse)

É a classe que fornece atributos e métodos para outras classes.

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }
}

Classe Filha (Subclasse)

É a classe que herda as características da classe pai.

class Aluno extends Pessoa {

}

Neste caso:

  • Pessoa é a classe pai.
  • Aluno é a classe filha.

Utilizando o extends

Em JavaScript, a palavra-chave extends é utilizada para criar uma relação de herança.

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }

    apresentar() {
        console.log(`Olá, eu sou ${this.nome}`);
    }
}

class Aluno extends Pessoa {

}

Agora qualquer objeto da classe Aluno poderá utilizar o método apresentar().

const aluno = new Aluno("Gustavo");

aluno.apresentar();

Resultado:

Olá, eu sou Gustavo

Mesmo sem existir dentro da classe Aluno, o método foi herdado da classe Pessoa.

Utilizando o super()

Quando uma classe filha possui seu próprio construtor, é necessário chamar o construtor da classe pai através da função super().

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }
}

class Aluno extends Pessoa {
    constructor(nome, curso) {
        super(nome);

        this.curso = curso;
    }
}

Uso:

const aluno = new Aluno(
    "Gustavo",
    "Desenvolvimento Web"
);

console.log(aluno.nome);
console.log(aluno.curso);

O super(nome) executa o construtor da classe pai e inicializa o atributo nome.

Herdando Métodos

Além de atributos, métodos também podem ser herdados.

class Pessoa {
    falar() {
        console.log("Estou falando.");
    }
}

class Professor extends Pessoa {

}
const professor = new Professor();

professor.falar();

Resultado:

Estou falando.

Sobrescrita de Métodos (Override)

Uma classe filha pode modificar um método herdado para implementar um comportamento diferente.

class Pessoa {
    apresentar() {
        console.log("Sou uma pessoa.");
    }
}

class Aluno extends Pessoa {
    apresentar() {
        console.log("Sou um aluno.");
    }
}
const aluno = new Aluno();

aluno.apresentar();

Resultado:

Sou um aluno.

O método da classe filha substitui o da classe pai.

Vantagens da Herança

Reutilização de Código

Evita repetir atributos e métodos em várias classes.

Facilidade de Manutenção

Alterações feitas na classe pai podem beneficiar todas as classes filhas.

Organização

Permite criar hierarquias lógicas entre classes.

Escalabilidade

Facilita a expansão do sistema à medida que novos tipos de objetos são criados.

Exemplo Completo

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }

    apresentar() {
        console.log(`Meu nome é ${this.nome}`);
    }
}

class Aluno extends Pessoa {
    constructor(nome, idade, curso) {
        super(nome, idade);

        this.curso = curso;
    }

    estudar() {
        console.log(`${this.nome} está estudando.`);
    }
}
const aluno = new Aluno(
    "Gustavo",
    21,
    "JavaScript"
);

aluno.apresentar();
aluno.estudar();

Resultado:

Meu nome é Gustavo
Gustavo está estudando.

Resumo

A herança é o pilar da Orientação a Objetos que permite que uma classe herde atributos e métodos de outra classe. Em JavaScript, isso é feito utilizando as palavras-chave extends e super(). A herança promove reutilização de código, organização e facilidade de manutenção, sendo um recurso essencial para o desenvolvimento de sistemas maiores e mais estruturados.
