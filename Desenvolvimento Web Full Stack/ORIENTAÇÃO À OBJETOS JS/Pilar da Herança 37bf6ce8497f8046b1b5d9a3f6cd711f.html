Pilar da Herança

A herança é um dos quatro pilares fundamentais da Orientação a Objetos (OO), juntamente com a abstração, o encapsulamento e o polimorfismo. Seu principal objetivo é permitir que uma classe reutilize atributos e métodos de outra classe, promovendo o reaproveitamento de código e a criação de relações hierárquicas entre objetos.

Em termos simples, a herança permite criar uma nova classe baseada em uma classe já existente. A nova classe herda características e comportamentos da classe original e ainda pode adicionar ou modificar funcionalidades.

O que é Herança?

Imagine um sistema escolar que possui diferentes tipos de pessoas:

  • Alunos
  • Professores
  • Coordenadores

Todas elas possuem características em comum:

  • Nome
  • Idade
  • CPF

Seria repetitivo declarar esses atributos em todas as classes.

Sem herança:

class Aluno {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}

class Professor {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}

Observe a duplicação de código.

Com herança:

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}
class Aluno extends Pessoa {

}

class Professor extends Pessoa {

}

Agora as classes podem reutilizar tudo que foi definido em Pessoa.

Objetivo da Herança

A herança existe para:

  • Evitar repetição de código.
  • Facilitar a manutenção.
  • Organizar o sistema em hierarquias.
  • Promover reutilização de funcionalidades.
  • Tornar o desenvolvimento mais eficiente.

Herança no Mundo Real

A herança pode ser compreendida através da relação:

É UM(A)

Por exemplo:

Aluno é uma Pessoa
Professor é uma Pessoa
Gerente é um Funcionário
Cachorro é um Animal

Quando essa relação faz sentido, geralmente a herança pode ser aplicada.

Conceitos Fundamentais

Superclasse (Classe Pai)

É a classe que fornece atributos e métodos para outras classes.

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }
}

Subclasse (Classe Filha)

É a classe que herda as características da superclasse.

class Aluno extends Pessoa {

}

Neste caso:

  • Pessoa é a superclasse.
  • Aluno é a subclasse.

A Palavra-chave extends

Em JavaScript, utilizamos extends para criar uma relação de herança.

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }
}

class Professor extends Pessoa {

}

A partir desse momento, Professor herda todos os membros públicos de Pessoa.

Herdando Atributos

Exemplo:

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}
class Aluno extends Pessoa {

}

Criando um objeto:

const aluno = new Aluno(
    "Gustavo",
    21
);

console.log(aluno.nome);
console.log(aluno.idade);

Resultado:

Gustavo
21

Embora a classe Aluno esteja vazia, ela herdou os atributos da classe Pessoa.

O Operador super

Quando a subclasse possui seu próprio construtor, ela precisa chamar o construtor da superclasse através do operador super().

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}
class Aluno extends Pessoa {
    constructor(nome, idade, curso) {
        super(nome, idade);

        this.curso = curso;
    }
}

Uso:

const aluno = new Aluno(
    "Gustavo",
    21,
    "JavaScript"
);

O super() executa o construtor da classe pai e inicializa os atributos herdados.

Herdando Métodos

A herança não reutiliza apenas atributos, mas também métodos.

class Pessoa {
    apresentar() {
        console.log(
            `Olá, meu nome é ${this.nome}`
        );
    }
}
class Professor extends Pessoa {

}

Uso:

const professor = new Professor();

professor.nome = "Carlos";

professor.apresentar();

Resultado:

Olá, meu nome é Carlos

O método foi herdado da superclasse.

Especialização de Classes

Uma das maiores vantagens da herança é permitir especializações.

Exemplo:

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }
}
class Aluno extends Pessoa {
    estudar() {
        console.log(
            `${this.nome} está estudando`
        );
    }
}
class Professor extends Pessoa {
    ensinar() {
        console.log(
            `${this.nome} está ensinando`
        );
    }
}

Agora cada classe possui comportamentos específicos além dos herdados.

Sobrescrita de Métodos (Override)

Uma subclasse pode redefinir um método herdado.

Classe pai:

class Pessoa {
    apresentar() {
        console.log(
            "Sou uma pessoa."
        );
    }
}

Classe filha:

class Aluno extends Pessoa {
    apresentar() {
        console.log(
            "Sou um aluno."
        );
    }
}

Uso:

const aluno = new Aluno();

aluno.apresentar();

Resultado:

Sou um aluno.

O método da subclasse substituiu o método da superclasse.

Utilizando super em Métodos

Também é possível chamar o método original da classe pai.

class Pessoa {
    apresentar() {
        console.log(
            "Olá, sou uma pessoa."
        );
    }
}
class Aluno extends Pessoa {
    apresentar() {
        super.apresentar();

        console.log(
            "Também sou um aluno."
        );
    }
}

Resultado:

Olá, sou uma pessoa.
Também sou um aluno.

Exemplo Completo

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }

    apresentar() {
        console.log(
            `Meu nome é ${this.nome}`
        );
    }
}
class Aluno extends Pessoa {
    constructor(nome, idade, curso) {
        super(nome, idade);

        this.curso = curso;
    }

    estudar() {
        console.log(
            `${this.nome} está estudando ${this.curso}`
        );
    }
}
const aluno = new Aluno(
    "Gustavo",
    21,
    "JavaScript"
);

aluno.apresentar();
aluno.estudar();

Resultado:

Meu nome é Gustavo
Gustavo está estudando JavaScript

Vantagens da Herança

Reutilização de Código

Evita repetir atributos e métodos em diversas classes.

Organização

Permite criar hierarquias lógicas dentro do sistema.

Facilidade de Manutenção

Alterações na classe pai podem beneficiar todas as classes filhas.

Extensibilidade

Novas funcionalidades podem ser adicionadas sem modificar classes existentes.

Redução de Duplicação

Seguindo o princípio DRY (Don't Repeat Yourself), a herança ajuda a evitar código repetido.

Desvantagens do Uso Excessivo

Apesar de poderosa, a herança deve ser utilizada com cuidado.

Hierarquias muito profundas

Pessoa
 ↓
Funcionário
 ↓
Gerente
 ↓
Diretor
 ↓
Presidente

Estruturas excessivamente complexas dificultam a manutenção.

Acoplamento elevado

Mudanças na superclasse podem afetar todas as subclasses.

Nem toda relação é herança

Por exemplo:

Carro tem um Motor

Nesse caso, o correto seria utilizar composição, não herança.

Herança x Composição

Muitos sistemas modernos preferem composição quando possível.

Herança:

Aluno é uma Pessoa

Composição:

Carro tem um Motor

Regra prática:

  • É um(a) → Herança.
  • Tem um(a) → Composição.

Resumo

A herança é o pilar da Orientação a Objetos que permite que uma classe reutilize atributos e métodos de outra classe. Em JavaScript, ela é implementada através das palavras-chave extends e super. A herança promove reutilização de código, organização e manutenção mais simples, permitindo criar hierarquias de classes que representam relações do mundo real. Quando utilizada corretamente, reduz a duplicação de código e torna o sistema mais escalável e estruturado.
