Criando Objetos

Funções Construtoras — Criando Objetos

As funções construtoras são um mecanismo do JavaScript utilizado para criar múltiplos objetos com a mesma estrutura e comportamento. Elas funcionam como um modelo que permite gerar várias instâncias de forma organizada e reutilizável.

Antes da introdução das classes no ECMAScript 6 (ES6), as funções construtoras eram a principal forma de aplicar conceitos de Orientação a Objetos em JavaScript.

Mesmo com a popularização das classes, compreender como as funções construtoras criam objetos é essencial para entender o funcionamento interno da linguagem.

Por que Utilizar Funções Construtoras?

Imagine que você precisa criar vários objetos semelhantes.

Sem uma função construtora, seria necessário repetir código:

const aluno1 = {
    nome: "Ana",
    curso: "JavaScript"
};

const aluno2 = {
    nome: "Carlos",
    curso: "JavaScript"
};

const aluno3 = {
    nome: "Maria",
    curso: "JavaScript"
};

Além da repetição, qualquer alteração na estrutura exigiria modificar todos os objetos.

Com funções construtoras:

function Aluno(nome, curso) {
    this.nome = nome;
    this.curso = curso;
}

Agora podemos criar quantos objetos forem necessários.

const aluno1 = new Aluno("Ana", "JavaScript");
const aluno2 = new Aluno("Carlos", "JavaScript");
const aluno3 = new Aluno("Maria", "JavaScript");

Estrutura de uma Função Construtora

A sintaxe básica é:

function NomeDaFuncao(parametros) {
    this.propriedade = valor;
}

Exemplo:

function Produto(nome, preco) {
    this.nome = nome;
    this.preco = preco;
}

Criando objetos:

const notebook = new Produto(
    "Notebook",
    3500
);

const mouse = new Produto(
    "Mouse",
    100
);

Resultado:

{
    nome: "Notebook",
    preco: 3500
}
{
    nome: "Mouse",
    preco: 100
}

O Papel do Operador new

O operador new é responsável por criar o objeto.

Exemplo:

const usuario = new Usuario(
    "Gustavo"
);

Quando o JavaScript encontra o operador new, ele executa automaticamente cinco etapas:

1. Cria um objeto vazio

const objeto = {};

2. Define o protótipo do objeto

O novo objeto é vinculado ao protótipo da função construtora.

objeto → Usuario.prototype

3. Faz this apontar para o novo objeto

Dentro da função:

this.nome = nome;

O this passa a representar o objeto recém-criado.

4. Executa a função construtora

Usuario("Gustavo");

As propriedades são adicionadas ao objeto.

5. Retorna o objeto criado

return objeto;

Tudo isso ocorre automaticamente.

Exemplo Completo

function Usuario(nome, email) {
    this.nome = nome;
    this.email = email;
}

Criando instâncias:

const usuario1 = new Usuario(
    "Gustavo",
    "gustavo@email.com"
);

const usuario2 = new Usuario(
    "Ana",
    "ana@email.com"
);

Acessando propriedades:

console.log(usuario1.nome);
console.log(usuario2.email);

Resultado:

Gustavo
ana@email.com

Entendendo o this

Dentro de uma função construtora, this representa o objeto que está sendo criado.

function Carro(marca, modelo) {
    this.marca = marca;
    this.modelo = modelo;
}

Ao executar:

const carro = new Carro(
    "Toyota",
    "Corolla"
);

O JavaScript faz algo semelhante a:

const carro = {};

carro.marca = "Toyota";
carro.modelo = "Corolla";

Adicionando Métodos

As funções construtoras também podem criar métodos.

function Pessoa(nome) {
    this.nome = nome;

    this.apresentar = function() {
        console.log(
            `Olá, meu nome é ${this.nome}`
        );
    };
}

Uso:

const pessoa = new Pessoa("Gustavo");

pessoa.apresentar();

Resultado:

Olá, meu nome é Gustavo

Atenção ao Uso de Métodos no Construtor

Embora seja possível, essa abordagem possui um problema.

function Pessoa(nome) {
    this.nome = nome;

    this.apresentar = function() {
        console.log(this.nome);
    };
}

Cada objeto criado terá sua própria cópia do método.

const p1 = new Pessoa("Ana");
const p2 = new Pessoa("Carlos");

Isso aumenta o consumo de memória.

A solução é utilizar o prototype.

Criando Métodos com prototype

function Pessoa(nome) {
    this.nome = nome;
}
Pessoa.prototype.apresentar = function() {
    console.log(
        `Olá, meu nome é ${this.nome}`
    );
};

Uso:

const pessoa1 = new Pessoa("Ana");
const pessoa2 = new Pessoa("Carlos");

pessoa1.apresentar();
pessoa2.apresentar();

Agora o método é compartilhado entre todas as instâncias.

Verificando o Tipo do Objeto

Podemos utilizar instanceof para verificar se um objeto foi criado por determinada função construtora.

const pessoa = new Pessoa("Gustavo");

console.log(
    pessoa instanceof Pessoa
);

Resultado:

true

Erro Comum: Esquecer o new

Considere:

function Usuario(nome) {
    this.nome = nome;
}

const usuario = Usuario("Gustavo");

Sem new, a função não cria um objeto corretamente.

No modo estrito ("use strict"), ocorrerá um erro.

O correto é:

const usuario = new Usuario(
    "Gustavo"
);

Convenções Importantes

Por convenção:

  • Funções construtoras começam com letra maiúscula.
  • Devem ser utilizadas com new.

Exemplos:

function Pessoa() {}
function Produto() {}
function ContaBancaria() {}

Funções Construtoras x Objetos Literais

Objeto Literal

Ideal para objetos únicos.

const configuracoes = {
    tema: "escuro"
};

Função Construtora

Ideal para criar múltiplas instâncias.

function Usuario(nome) {
    this.nome = nome;
}
const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Carlos");

Funções Construtoras x Classes

Função construtora:

function Aluno(nome) {
    this.nome = nome;
}

Classe:

class Aluno {
    constructor(nome) {
        this.nome = nome;
    }
}

As classes oferecem uma sintaxe mais moderna e organizada, mas utilizam os mesmos conceitos internamente.

Boas Práticas

  • Utilize nomes iniciados por letra maiúscula.
  • Sempre use o operador new.
  • Defina métodos no prototype.
  • Prefira classes em projetos modernos.
  • Entenda como o this funciona.

Resumo

As funções construtoras permitem criar múltiplos objetos com a mesma estrutura e comportamento em JavaScript. Utilizando o operador new, o JavaScript cria um novo objeto, associa-o ao protótipo da função, define o contexto de this e retorna a instância criada. Embora as classes sejam a abordagem mais comum atualmente, as funções construtoras continuam sendo fundamentais para compreender a herança prototipal e o funcionamento interno da linguagem.
