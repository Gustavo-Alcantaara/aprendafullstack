Prototype - Herança

Prototype — Herança em JavaScript

A herança prototipal é o mecanismo que permite que um objeto reutilize propriedades e métodos de outro objeto. Diferentemente de linguagens como Java ou C#, que utilizam herança baseada em classes, o JavaScript utiliza protótipos para implementar esse conceito.

Com a herança prototipal, um objeto pode acessar características que não foram definidas diretamente nele, mas que existem em sua cadeia de protótipos.

O que é Herança?

Herança é a capacidade de criar novos objetos a partir de estruturas existentes, promovendo:

  • Reutilização de código.
  • Redução de duplicação.
  • Organização hierárquica.
  • Extensibilidade.

Exemplo conceitual:

  • Um Animal possui um método emitirSom().
  • Um Cachorro é um tipo de animal e pode herdar esse comportamento.

Como Funciona a Herança Prototipal?

Todo objeto em JavaScript possui uma referência interna para outro objeto, chamada:

[[Prototype]]

Quando tentamos acessar uma propriedade, o JavaScript segue esta ordem:

  1. Procura a propriedade no próprio objeto.
  1. Se não encontrar, procura no protótipo.
  1. Continua percorrendo a cadeia de protótipos.
  1. Encerra a busca ao chegar em null.

Esse processo é conhecido como:

Prototype Chain (cadeia de protótipos).

Exemplo Simples com Objetos Literais

const animal = {
    emitirSom() {
        console.log("Som genérico");
    }
};

Criando um novo objeto baseado em animal:

const cachorro = Object.create(animal);

cachorro.nome = "Rex";

Uso:

cachorro.emitirSom();

Resultado:

Som genérico

Embora emitirSom() não exista diretamente em cachorro, o método é encontrado em seu protótipo.

Representação:

cachorro → animal → Object.prototype → null

Sobrescrevendo Métodos

Objetos podem redefinir métodos herdados.

const animal = {
    emitirSom() {
        console.log("Som genérico");
    }
};

const cachorro = Object.create(animal);

cachorro.emitirSom = function() {
    console.log("Au au!");
};

Uso:

cachorro.emitirSom();

Resultado:

Au au!

O JavaScript utiliza o método definido no próprio objeto antes de consultar o protótipo.

Herança com Funções Construtoras

Antes das classes do ES6, a herança era implementada conectando protótipos manualmente.

Classe base

function Animal(nome) {
    this.nome = nome;
}

Adicionando métodos ao protótipo:

Animal.prototype.emitirSom = function() {
    console.log("Som genérico");
};

Classe derivada

function Cachorro(nome, raca) {
    Animal.call(this, nome);

    this.raca = raca;
}

A chamada:

Animal.call(this, nome);

executa a função construtora Animal dentro do contexto de Cachorro, herdando as propriedades.

Conectando os Protótipos

Para herdar os métodos:

Cachorro.prototype = Object.create(
    Animal.prototype
);

Agora:

cachorro → Cachorro.prototype → Animal.prototype

Após substituir o protótipo, é necessário restaurar a propriedade constructor.

Cachorro.prototype.constructor = Cachorro;

Sobrescrevendo Métodos Herdados

Cachorro.prototype.emitirSom = function() {
    console.log("Au au!");
};

Uso:

const rex = new Cachorro(
    "Rex",
    "Labrador"
);

rex.emitirSom();

Resultado:

Au au!

Exemplo Completo

function Animal(nome) {
    this.nome = nome;
}

Animal.prototype.emitirSom = function() {
    console.log("Som genérico");
};

function Gato(nome) {
    Animal.call(this, nome);
}

Gato.prototype = Object.create(
    Animal.prototype
);

Gato.prototype.constructor = Gato;

Gato.prototype.emitirSom = function() {
    console.log("Miau!");
};

Uso:

const gato = new Gato("Mimi");

gato.emitirSom();

Resultado:

Miau!

O Papel do Object.create()

O método Object.create() cria um novo objeto utilizando outro objeto como protótipo.

Sintaxe:

const novoObjeto = Object.create(prototipo);

Exemplo:

const veiculo = {
    mover() {
        console.log("Movendo...");
    }
};

const carro = Object.create(veiculo);

carro.mover();

Resultado:

Movendo...

Verificando a Herança

instanceof

Verifica se um objeto pertence à cadeia de protótipos.

console.log(rex instanceof Cachorro);
console.log(rex instanceof Animal);

Resultado:

true
true

Object.getPrototypeOf()

Obtém o protótipo de um objeto.

console.log(
    Object.getPrototypeOf(rex)
);

Resultado:

Cachorro.prototype

Herança com Classes

As classes do ES6 simplificam a sintaxe, mas utilizam protótipos internamente.

class Animal {
    constructor(nome) {
        this.nome = nome;
    }

    emitirSom() {
        console.log("Som genérico");
    }
}
class Cachorro extends Animal {
    emitirSom() {
        console.log("Au au!");
    }
}

Uso:

const rex = new Cachorro("Rex");

rex.emitirSom();

Resultado:

Au au!

Internamente, o JavaScript continua utilizando protótipos.

Cadeia de Protótipos Completa

Considere:

const rex = new Cachorro("Rex");

A cadeia será:

rex
 ↓
Cachorro.prototype
 ↓
Animal.prototype
 ↓
Object.prototype
 ↓
null

Quando o JavaScript procura um método, ele percorre essa sequência.

Vantagens da Herança Prototipal

  • Reutilização de código.
  • Compartilhamento de métodos.
  • Menor consumo de memória.
  • Flexibilidade.
  • Extensibilidade.

Cuidados e Limitações

  • Cadeias de protótipos muito longas podem dificultar a manutenção.
  • Sobrescritas excessivas podem gerar comportamentos inesperados.
  • A sintaxe com funções construtoras pode ser complexa.
  • Alterar protótipos em tempo de execução pode afetar o desempenho.

Boas Práticas

  • Utilize métodos compartilhados no prototype.
  • Prefira Object.create() para criar heranças manuais.
  • Evite modificar Object.prototype.
  • Utilize classes em projetos modernos.
  • Compreenda a cadeia de protótipos antes de implementar herança complexa.

Resumo

A herança prototipal é o mecanismo que permite que objetos em JavaScript reutilizem propriedades e métodos de outros objetos. Esse processo ocorre por meio da cadeia de protótipos, onde cada objeto mantém uma referência para outro objeto chamado protótipo. Quando uma propriedade não é encontrada, o JavaScript percorre essa cadeia até localizá-la ou alcançar null. Embora as classes modernas simplifiquem a sintaxe da herança, elas continuam utilizando protótipos internamente, tornando esse conceito fundamental para compreender a Orientação a Objetos em JavaScript.
