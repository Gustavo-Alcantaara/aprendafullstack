Web Storage

Web Storage em JavaScript

O Web Storage é uma API nativa dos navegadores que permite armazenar dados localmente no dispositivo do usuário na forma de pares chave/valor.

Esse recurso foi introduzido no HTML5 para substituir limitações dos cookies, oferecendo uma maneira mais simples, rápida e eficiente de persistir informações no navegador.

Com o Web Storage, é possível armazenar dados como:

  • Preferências do usuário.
  • Tema da aplicação (claro ou escuro).
  • Dados de login.
  • Conteúdo de formulários.
  • Carrinhos de compras.
  • Configurações da aplicação.

Tipos de Web Storage

A API é dividida em dois mecanismos:

  • localStorage
  • sessionStorage

Ambos possuem a mesma interface e os mesmos métodos. A principal diferença está no tempo de persistência dos dados.

Como o Web Storage Funciona?

Os dados são armazenados no formato:

chave → valor

Tanto a chave quanto o valor são armazenados como strings.

Exemplo:

tema → escuro
nome → Gustavo

localStorage

O localStorage mantém os dados armazenados mesmo após o navegador ser fechado.

Essas informações permanecem disponíveis até serem removidas manualmente pelo usuário ou pelo código.

Salvando Dados

localStorage.setItem("nome", "Gustavo");

Recuperando Dados

const nome = localStorage.getItem("nome");

console.log(nome);

Resultado:

Gustavo

Atualizando Dados

Basta utilizar a mesma chave.

localStorage.setItem("nome", "Ana");

O valor anterior será substituído.

Removendo um Item

localStorage.removeItem("nome");

Limpando Todo o Armazenamento

localStorage.clear();

Todos os dados do domínio serão removidos.

Verificando se um Item Existe

const tema = localStorage.getItem("tema");

if (tema !== null) {
    console.log("Tema encontrado");
}

Se a chave não existir, o método retorna:

null

sessionStorage

O sessionStorage funciona de forma semelhante ao localStorage, mas seus dados existem apenas durante a sessão da aba.

Ao fechar a aba ou a janela, os dados são apagados automaticamente.

Salvando Dados

sessionStorage.setItem("paginaAtual", "perfil");

Recuperando Dados

const pagina = sessionStorage.getItem("paginaAtual");

Removendo Dados

sessionStorage.removeItem("paginaAtual");

Métodos da API

Os dois mecanismos compartilham os mesmos métodos.

MétodoDescrição
setItem(chave, valor)Adiciona ou atualiza um valor
getItem(chave)Obtém um valor
removeItem(chave)Remove um item
clear()Remove todos os itens
key(indice)Retorna a chave de uma posição
lengthRetorna a quantidade de itens

Exemplo:

console.log(localStorage.length);

Percorrendo os Dados

for (let i = 0; i < localStorage.length; i++) {
    const chave = localStorage.key(i);

    console.log(
        chave,
        localStorage.getItem(chave)
    );
}

Armazenando Objetos

Como o Web Storage armazena apenas strings, objetos precisam ser convertidos para JSON.

Convertendo para JSON

const usuario = {
    nome: "Gustavo",
    idade: 21
};

localStorage.setItem(
    "usuario",
    JSON.stringify(usuario)
);

Recuperando Objetos

const dados = localStorage.getItem("usuario");

const usuario = JSON.parse(dados);

console.log(usuario.nome);

Resultado:

Gustavo

Armazenando Arrays

const tecnologias = [
    "HTML",
    "CSS",
    "JavaScript"
];

localStorage.setItem(
    "tecnologias",
    JSON.stringify(tecnologias)
);

Recuperando:

const tecnologias = JSON.parse(
    localStorage.getItem("tecnologias")
);

Exemplo Prático: Tema Escuro

Salvando a preferência:

const tema = "escuro";

localStorage.setItem("tema", tema);

Recuperando ao carregar a página:

const temaSalvo = localStorage.getItem("tema");

if (temaSalvo === "escuro") {
    document.body.classList.add("dark");
}

Assim, o usuário mantém sua preferência entre sessões.

Eventos de Armazenamento

O navegador dispara o evento storage quando os dados são alterados em outra aba.

window.addEventListener(
    "storage",
    (event) => {
        console.log(event.key);
        console.log(event.oldValue);
        console.log(event.newValue);
    }
);

Esse evento é útil para sincronizar informações entre múltiplas abas.

Limitações do Web Storage

  • Armazena apenas strings.
  • Possui limite de espaço.
  • Funciona apenas no navegador.
  • Não suporta consultas complexas.
  • Os dados não são criptografados automaticamente.

Segurança e Boas Práticas

O Web Storage não é um local seguro para armazenar informações sensíveis.

Evite armazenar:

  • Senhas.
  • Dados bancários.
  • Informações pessoais sensíveis.
  • Tokens de autenticação de longa duração.

Qualquer script executado na página pode acessar esses dados.

Exemplo:

localStorage.getItem("token");

Por isso, ataques como XSS (Cross-Site Scripting) podem comprometer informações armazenadas.

Quando Utilizar?

Use localStorage para:

  • Preferências do usuário.
  • Configurações da aplicação.
  • Dados que devem persistir.

Use sessionStorage para:

  • Assistentes de cadastro.
  • Dados temporários.
  • Estado da navegação.
  • Informações válidas apenas durante a sessão.

Erros Comuns

Esquecer de converter objetos para JSON

Incorreto:

localStorage.setItem("usuario", usuario);

Resultado:

[object Object]

Correto:

localStorage.setItem(
    "usuario",
    JSON.stringify(usuario)
);

Não tratar valores nulos

const usuario = JSON.parse(
    localStorage.getItem("usuario")
);

Se a chave não existir, ocorrerá um erro.

Uma alternativa segura:

const usuario = JSON.parse(
    localStorage.getItem("usuario") || "{}"
);

Armazenar dados sensíveis

Evite guardar informações críticas no navegador.

Resumo

O Web Storage é uma API do HTML5 que permite armazenar dados localmente no navegador por meio dos mecanismos localStorage e sessionStorage. Ambos utilizam pares chave/valor e armazenam informações como strings. O localStorage mantém os dados mesmo após o fechamento do navegador, enquanto o sessionStorage os remove ao encerrar a aba. Embora seja uma solução prática para persistência de dados no lado do cliente, o Web Storage possui limitações de capacidade e segurança, exigindo cuidados especiais ao armazenar informações importantes.
