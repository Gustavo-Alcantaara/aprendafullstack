Modificando Valores

Objetos Literais — Modificando Valores

Os objetos literais em JavaScript são estruturas dinâmicas e mutáveis, o que significa que suas propriedades podem ser alteradas, adicionadas ou removidas mesmo após a criação do objeto.

Essa flexibilidade é uma das principais características da linguagem, permitindo que os objetos sejam adaptados conforme as necessidades da aplicação.

O que Significa Modificar um Objeto?

Modificar um objeto significa alterar o conteúdo armazenado em suas propriedades ou sua estrutura interna.

As operações mais comuns são:

  • Alterar valores existentes.
  • Adicionar novas propriedades.
  • Remover propriedades.
  • Atualizar objetos aninhados.
  • Modificar arrays internos.

Exemplo de objeto literal:

const usuario = {
    nome: "Gustavo",
    idade: 21,
    curso: "JavaScript"
};

Alterando o Valor de uma Propriedade

Para modificar uma propriedade existente, basta atribuir um novo valor.

Utilizando a notação de ponto

usuario.idade = 22;

console.log(usuario.idade);

Resultado:

22

Utilizando a notação de colchetes

usuario["curso"] = "React";

console.log(usuario.curso);

Resultado:

React

A notação de colchetes é especialmente útil quando o nome da propriedade é armazenado em uma variável.

const propriedade = "nome";

usuario[propriedade] = "Ana";

Resultado:

{
    nome: "Ana",
    idade: 22,
    curso: "React"
}

Adicionando Novas Propriedades

Se a propriedade não existir, o JavaScript a criará automaticamente.

usuario.email = "gustavo@email.com";

Resultado:

{
    nome: "Ana",
    idade: 22,
    curso: "React",
    email: "gustavo@email.com"
}

Também é possível usar colchetes:

usuario["cidade"] = "Fortaleza";

Removendo Propriedades

Para remover uma propriedade, utiliza-se o operador delete.

delete usuario.curso;

Resultado:

{
    nome: "Ana",
    idade: 22,
    email: "gustavo@email.com",
    cidade: "Fortaleza"
}

Embora funcione corretamente, o uso excessivo de delete pode impactar o desempenho em cenários específicos.

Modificando Objetos Aninhados

Objetos podem conter outros objetos.

const aluno = {
    nome: "Gustavo",

    endereco: {
        cidade: "Fortaleza",
        estado: "Ceará"
    }
};

Para modificar propriedades internas:

aluno.endereco.cidade = "São Gonçalo do Amarante";

Resultado:

{
    nome: "Gustavo",
    endereco: {
        cidade: "São Gonçalo do Amarante",
        estado: "Ceará"
    }
}

Modificando Arrays Dentro de Objetos

Objetos podem conter arrays como propriedades.

const usuario = {
    nome: "Gustavo",
    habilidades: ["HTML", "CSS"]
};

Adicionando um novo elemento:

usuario.habilidades.push("JavaScript");

Resultado:

{
    nome: "Gustavo",
    habilidades: ["HTML", "CSS", "JavaScript"]
}

Removendo elementos:

usuario.habilidades.pop();

Objetos Declarados com const Podem Ser Modificados?

Essa é uma dúvida muito comum.

Considere:

const produto = {
    nome: "Notebook",
    preco: 3500
};

É possível alterar propriedades:

produto.preco = 4000;

Isso funciona normalmente.

Por outro lado, não é possível reatribuir o objeto inteiro.

produto = {
    nome: "Mouse",
    preco: 100
};

Resultado:

TypeError: Assignment to constant variable.

Entendendo a Referência de Memória

Objetos são armazenados por referência.

Quando criamos um objeto:

const usuario1 = {
    nome: "Gustavo"
};

E fazemos:

const usuario2 = usuario1;

Ambas as variáveis apontam para o mesmo objeto na memória.

usuario2.nome = "Ana";

console.log(usuario1.nome);

Resultado:

Ana

Alterar uma referência afeta a outra.

Copiando Objetos Corretamente

Para evitar alterações indesejadas, podemos criar cópias.

Utilizando Spread Operator

const usuario = {
    nome: "Gustavo",
    idade: 21
};

const copia = {
    ...usuario
};

Agora os objetos são independentes.

copia.nome = "Ana";

console.log(usuario.nome);
console.log(copia.nome);

Resultado:

Gustavo
Ana

Atualizando Objetos com Spread

O operador spread também permite atualizar propriedades de forma prática.

const usuarioAtualizado = {
    ...usuario,
    idade: 22
};

Resultado:

{
    nome: "Gustavo",
    idade: 22
}

Essa abordagem é muito utilizada em bibliotecas como:

  • React
  • Redux

Congelando Objetos

Se você deseja impedir modificações, pode utilizar Object.freeze().

const configuracoes = {
    tema: "escuro"
};

Object.freeze(configuracoes);

Tentativa de alteração:

configuracoes.tema = "claro";

O valor permanecerá inalterado.

Selando Objetos

O método Object.seal() impede a adição e remoção de propriedades, mas permite modificar valores existentes.

const usuario = {
    nome: "Gustavo"
};

Object.seal(usuario);

usuario.nome = "Ana";

Isso funciona.

Porém:

usuario.idade = 21;
delete usuario.nome;

Essas operações não serão permitidas.

Boas Práticas

  • Utilize const para declarar objetos sempre que possível.
  • Evite modificar objetos compartilhados em várias partes da aplicação.
  • Prefira criar novas cópias com o operador spread em vez de alterar diretamente o objeto original.
  • Utilize Object.freeze() para dados que não devem ser alterados.
  • Use nomes claros para propriedades.

Erros Comuns

Confundir const com imutabilidade

const usuario = {
    nome: "Gustavo"
};

usuario.nome = "Ana";

Isso é permitido.

Alterar objetos compartilhados

const usuario2 = usuario1;

As duas variáveis apontam para o mesmo objeto.

Usar delete excessivamente

Em muitos casos, criar um novo objeto é uma abordagem mais segura e previsível.

Resumo

Os objetos literais em JavaScript são estruturas mutáveis, permitindo que suas propriedades sejam alteradas, adicionadas ou removidas após a criação. A modificação pode ser feita por meio das notações de ponto e colchetes, enquanto recursos como o operador spread, Object.freeze() e Object.seal() ajudam a controlar e gerenciar essas alterações. Compreender como os objetos funcionam na memória é essencial para evitar efeitos colaterais e desenvolver aplicações mais seguras e previsíveis.
