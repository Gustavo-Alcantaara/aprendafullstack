Introdução

Orientação a Objetos (POO - Programação Orientada a Objetos)

A Orientação a Objetos (Object-Oriented Programming - OOP) é um paradigma de programação baseado na ideia de representar elementos do mundo real por meio de objetos. Em vez de organizar o programa apenas em funções e procedimentos, a POO organiza o código em estruturas que agrupam dados (atributos) e comportamentos (métodos).

Esse paradigma surgiu para facilitar o desenvolvimento de sistemas cada vez maiores e mais complexos, promovendo reutilização de código, organização, manutenção e escalabilidade.

No JavaScript moderno, a Orientação a Objetos ganhou uma sintaxe mais intuitiva com a introdução das Classes no ECMAScript 6.

O que é um Objeto?

Um objeto é uma estrutura que representa uma entidade, contendo características e ações.

Por exemplo, imagine um carro.

Características:

  • Marca
  • Modelo
  • Cor
  • Velocidade

Ações:

  • Acelerar
  • Frear
  • Ligar
  • Desligar

Em JavaScript:

const carro = {
    marca: "Toyota",
    modelo: "Corolla",
    velocidade: 0,

    acelerar() {
        this.velocidade += 10;
    }
};

Nesse exemplo:

  • marca, modelo e velocidade são atributos.
  • acelerar() é um método.

Classes

Uma classe funciona como um molde para criar objetos.

Pense em uma fábrica de carros:

  • A classe é o projeto do carro.
  • Os objetos são os carros produzidos.

Sintaxe

class Pessoa {

}

A classe por si só não cria nenhum objeto. Ela apenas define como os objetos serão construídos.

Instanciando Objetos

Para criar objetos a partir de uma classe, utilizamos o operador new.

class Pessoa {

}

const pessoa1 = new Pessoa();
const pessoa2 = new Pessoa();

Cada objeto criado é chamado de instância.

Construtor

O construtor é um método especial executado automaticamente quando um objeto é criado.

class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }
}

const pessoa = new Pessoa("Gustavo", 21);

Resultado:

{
    nome: "Gustavo",
    idade: 21
}

O método constructor() serve para inicializar os atributos do objeto.

A Palavra-chave this

O this representa o próprio objeto que está executando o método.

class Pessoa {
    constructor(nome) {
        this.nome = nome;
    }

    apresentar() {
        console.log(`Olá, meu nome é ${this.nome}`);
    }
}

const pessoa = new Pessoa("Gustavo");

pessoa.apresentar();

Resultado:

Olá, meu nome é Gustavo

Sem o this, o método não saberia qual objeto está utilizando.

Métodos

Métodos são funções pertencentes a uma classe.

class ContaBancaria {
    constructor(saldo) {
        this.saldo = saldo;
    }

    depositar(valor) {
        this.saldo += valor;
    }

    sacar(valor) {
        this.saldo -= valor;
    }
}

Uso:

const conta = new ContaBancaria(1000);

conta.depositar(500);

console.log(conta.saldo);

Resultado:

1500

Os 4 Pilares da Orientação a Objetos

A POO é baseada em quatro conceitos fundamentais:

1. Encapsulamento

O encapsulamento consiste em proteger os dados internos de um objeto e controlar como eles podem ser acessados.

Imagine um caixa eletrônico:

Você não altera diretamente o saldo armazenado no banco. Você utiliza operações como depósito e saque.

Exemplo:

class Conta {
    #saldo = 0;

    depositar(valor) {
        this.#saldo += valor;
    }

    mostrarSaldo() {
        return this.#saldo;
    }
}

O símbolo # cria um atributo privado.

const conta = new Conta();

conta.depositar(500);

console.log(conta.mostrarSaldo());

Resultado:

500

2. Herança

A herança permite que uma classe aproveite características de outra classe.

Exemplo:

class Animal {
    dormir() {
        console.log("Dormindo...");
    }
}

class Cachorro extends Animal {
    latir() {
        console.log("Au Au!");
    }
}

Uso:

const dog = new Cachorro();

dog.dormir();
dog.latir();

Resultado:

Dormindo...
Au Au!

A classe Cachorro herda os métodos da classe Animal.

3. Polimorfismo

Polimorfismo significa "muitas formas".

Ele permite que classes diferentes utilizem métodos com o mesmo nome, mas comportamentos diferentes.

class Animal {
    emitirSom() {
        console.log("Som genérico");
    }
}
class Cachorro extends Animal {
    emitirSom() {
        console.log("Au Au!");
    }
}
class Gato extends Animal {
    emitirSom() {
        console.log("Miau!");
    }
}

Uso:

const cachorro = new Cachorro();
const gato = new Gato();

cachorro.emitirSom();
gato.emitirSom();

Resultado:

Au Au!
Miau!

O mesmo método produz comportamentos diferentes.

4. Abstração

A abstração consiste em mostrar apenas o necessário para utilizar um objeto, escondendo detalhes internos.

Exemplo:

Quando você dirige um carro, utiliza:

  • Volante
  • Pedais
  • Marcha

Você não precisa conhecer todo o funcionamento interno do motor.

Em programação:

class Carro {
    ligar() {
        console.log("Carro ligado");
    }
}

Quem utiliza a classe não precisa saber como o motor é inicializado internamente.

Classes e Objetos no JavaScript

Embora as classes tenham sido introduzidas no ES6, o JavaScript continua sendo uma linguagem baseada em protótipos.

Quando escrevemos:

class Pessoa {

}

o JavaScript internamente cria protótipos.

As classes são, na prática, uma forma mais amigável de trabalhar com o sistema de herança prototipal da linguagem.

Exemplo Completo

class Produto {
    constructor(nome, preco) {
        this.nome = nome;
        this.preco = preco;
    }

    mostrarDados() {
        console.log(
            `${this.nome} custa R$ ${this.preco}`
        );
    }
}

const produto1 = new Produto(
    "Notebook",
    3500
);

const produto2 = new Produto(
    "Mouse",
    120
);

produto1.mostrarDados();
produto2.mostrarDados();

Resultado:

Notebook custa R$ 3500
Mouse custa R$ 120

Vantagens da Orientação a Objetos

Organização

O código fica dividido em entidades bem definidas.

Reutilização

A herança permite reaproveitar funcionalidades.

Facilidade de manutenção

Alterações podem ser feitas em uma única classe e refletidas em vários objetos.

Escalabilidade

Sistemas grandes tornam-se mais fáceis de expandir.

Modelagem natural

Permite representar elementos do mundo real de forma intuitiva.

Desvantagens

Maior complexidade inicial

Projetos pequenos podem ficar mais complicados do que o necessário.

Consumo ligeiramente maior de memória

Objetos e classes podem exigir mais recursos que abordagens simples.

Excesso de abstrações

Uma modelagem exagerada pode tornar o código difícil de entender.

Resumo

A Orientação a Objetos é um paradigma de programação que organiza o software em objetos contendo atributos e métodos. Seus quatro pilares são Encapsulamento, Herança, Polimorfismo e Abstração. Em JavaScript moderno, a POO é implementada principalmente por meio de classes, construtores e objetos. Esse paradigma é amplamente utilizado no desenvolvimento de sistemas web, aplicações desktop, jogos, APIs e praticamente qualquer software de médio ou grande porte, pois promove organização, reutilização de código e facilidade de manutenção.
