Pilar do Encapsulamento

O encapsulamento é um dos quatro pilares da Orientação a Objetos, juntamente com abstração, herança e polimorfismo. Seu principal objetivo é proteger os dados de um objeto, controlando a forma como eles podem ser acessados ou modificados.

Em vez de permitir que qualquer parte do programa altere diretamente os atributos de um objeto, o encapsulamento cria uma camada de proteção por meio de métodos que definem como esses dados podem ser manipulados.

O que é Encapsulamento?

Imagine uma conta bancária. O saldo da conta não deveria ser alterado livremente por qualquer parte do sistema.

Seria perigoso fazer algo assim:

conta.saldo = -5000;

Isso poderia gerar inconsistências e erros.

Com o encapsulamento, o saldo fica protegido e só pode ser alterado através de métodos específicos, como depositar() e sacar().

Como o Encapsulamento Funciona?

O encapsulamento consiste em:

  • Ocultar atributos importantes.
  • Permitir acesso controlado aos dados.
  • Garantir regras de negócio.
  • Evitar modificações indevidas.

Em JavaScript moderno, atributos privados são declarados utilizando o caractere #.

class Conta {
    #saldo = 0;

    depositar(valor) {
        this.#saldo += valor;
    }

    mostrarSaldo() {
        console.log(`Saldo: R$${this.#saldo}`);
    }
}

Uso:

const conta = new Conta();

conta.depositar(500);
conta.mostrarSaldo();

Resultado:

Saldo: R$500

Protegendo os Dados

Observe o que acontece se tentarmos acessar diretamente o atributo privado:

console.log(conta.#saldo);

O JavaScript gera um erro, pois atributos privados só podem ser acessados dentro da própria classe.

Isso aumenta a segurança e a integridade dos dados.

Encapsulamento com Getters e Setters

Outra forma de aplicar encapsulamento é através dos métodos get e set, que permitem controlar a leitura e a modificação de propriedades.

class Produto {
    constructor(nome) {
        this._nome = nome;
    }

    get nome() {
        return this._nome;
    }

    set nome(valor) {
        if (valor.length < 3) {
            console.log("Nome inválido.");
            return;
        }

        this._nome = valor;
    }
}

Uso:

const produto = new Produto("Notebook");

console.log(produto.nome);

produto.nome = "PC";

console.log(produto.nome);

Nesse caso, o setter impede que nomes muito curtos sejam atribuídos ao produto.

Benefícios do Encapsulamento

1. Segurança dos dados

Impede alterações indevidas nos atributos.

conta.#saldo = 1000000; // Erro

2. Validação de informações

Permite verificar se os dados são válidos antes de armazená-los.

set idade(valor) {
    if (valor < 0) {
        return;
    }

    this._idade = valor;
}

3. Facilidade de manutenção

Mudanças internas na classe não afetam o restante do sistema, desde que a interface pública permaneça a mesma.

4. Organização do código

Toda a lógica relacionada ao objeto fica concentrada dentro da própria classe.

Encapsulamento na Vida Real

Pense em um micro-ondas.

Você utiliza apenas os botões disponíveis:

  • Definir tempo
  • Iniciar
  • Parar

Você não tem acesso direto aos componentes eletrônicos internos.

Da mesma forma, uma classe encapsulada expõe apenas os recursos necessários e esconde os detalhes internos.

Encapsulamento e Abstração

Embora estejam relacionados, são conceitos diferentes.

AbstraçãoEncapsulamento
Define o que o objeto faz.Define como os dados são protegidos.
Oculta a complexidade.Oculta a implementação e controla o acesso.
Foca na funcionalidade.Foca na segurança e integridade dos dados.

Exemplo:

conta.sacar(100);
  • A abstração permite que você use o método sacar() sem conhecer sua implementação.
  • O encapsulamento protege o atributo saldo, impedindo alterações indevidas.

Resumo

O encapsulamento é o pilar da Orientação a Objetos responsável por proteger os dados e controlar o acesso às informações de um objeto. Ele é implementado através de atributos privados, métodos, getters e setters, garantindo maior segurança, organização e confiabilidade ao sistema. Em projetos maiores, o encapsulamento é fundamental para evitar erros e manter a integridade das informações.
