Template String

Template Strings (Template Literals)

As Template Strings (ou Template Literals) são um recurso introduzido no ECMAScript 6 (ES6) que permite criar strings de forma mais simples, legível e poderosa. Elas resolvem diversos problemas das concatenações tradicionais e facilitam a inserção de variáveis, expressões e até mesmo textos com múltiplas linhas.

Uma Template String é delimitada por crases (`), em vez de aspas simples (') ou duplas (").

Sintaxe Básica

const nome = "Gustavo";

console.log(`Olá, ${nome}!`);

Resultado:

Olá, Gustavo!

O trecho ${nome} é chamado de interpolação, pois insere o valor da variável diretamente dentro da string.

Problema das Concatenações

Antes do ES6, era necessário utilizar o operador + para juntar textos e variáveis.

const nome = "Gustavo";
const idade = 21;

console.log("Meu nome é " + nome + " e tenho " + idade + " anos.");

Embora funcione, esse código pode ficar difícil de ler quando a string se torna grande.

Com Template Strings:

const nome = "Gustavo";
const idade = 21;

console.log(`Meu nome é ${nome} e tenho ${idade} anos.`);

O resultado é exatamente o mesmo, mas o código fica mais limpo e natural.

Interpolação de Variáveis

A principal característica das Template Strings é a interpolação.

const produto = "Notebook";
const preco = 3500;

console.log(`O produto ${produto} custa R$ ${preco}.`);

Resultado:

O produto Notebook custa R$ 3500.

Interpolação de Expressões

Dentro de ${} não é obrigatório colocar apenas variáveis. É possível utilizar qualquer expressão JavaScript válida.

const a = 10;
const b = 5;

console.log(`A soma é ${a + b}`);

Resultado:

A soma é 15

Também é possível usar operações mais complexas:

const nota1 = 8;
const nota2 = 9;

console.log(`Média: ${(nota1 + nota2) / 2}`);

Resultado:

Média: 8.5

Chamando Funções

Funções também podem ser executadas dentro da interpolação.

function saudacao(nome) {
    return `Olá, ${nome}!`;
}

console.log(`${saudacao("Gustavo")}`);

Resultado:

Olá, Gustavo!

Isso permite construir mensagens dinâmicas de maneira muito prática.

Strings Multilinha

Antes do ES6, criar textos com várias linhas exigia o uso de \n ou concatenações.

const texto = "Linha 1\n" +
              "Linha 2\n" +
              "Linha 3";

Com Template Strings:

const texto = `
Linha 1
Linha 2
Linha 3
`;

console.log(texto);

Resultado:

Linha 1
Linha 2
Linha 3

Esse recurso é muito útil para criar mensagens longas, blocos HTML e consultas SQL.

Utilização com HTML

Uma das aplicações mais comuns das Template Strings é a geração dinâmica de HTML.

const nome = "Gustavo";
const idade = 21;

const html = `
<div>
    <h2>${nome}</h2>
    <p>Idade: ${idade}</p>
</div>
`;

console.log(html);

Resultado:

<div>
    <h2>Gustavo</h2>
    <p>Idade: 21</p>
</div>

Esse recurso é muito utilizado em aplicações web, frameworks e manipulação do DOM.

Formatação de Valores

Template Strings podem ser combinadas com métodos de formatação.

const preco = 1234.5;

console.log(`Preço: R$ ${preco.toFixed(2)}`);

Resultado:

Preço: R$ 1234.50

Outro exemplo:

const nome = "gustavo";

console.log(`Nome: ${nome.toUpperCase()}`);

Resultado:

Nome: GUSTAVO

Tagged Templates

Além do uso comum, as Template Strings podem ser processadas por funções especiais chamadas Tagged Templates.

function destacar(textos, valor) {
    return `${textos[0]}**${valor}**${textos[1]}`;
}

const nome = "Gustavo";

console.log(destacar`Olá ${nome}!`);

Resultado:

Olá **Gustavo**!

Esse recurso é mais avançado e costuma ser utilizado em bibliotecas, internacionalização e sistemas de templates.

Vantagens das Template Strings

Código mais legível

`Olá, ${nome}`

é mais fácil de entender do que:

"Olá, " + nome

Menos concatenações

Reduz a quantidade de operadores +, tornando o código mais limpo.

Suporte a múltiplas linhas

Permite escrever textos longos sem precisar de \n.

Interpolação de expressões

Aceita cálculos, funções e qualquer expressão JavaScript dentro de ${}.

Facilita a geração de HTML

Muito útil para aplicações web modernas.

Boas Práticas

Utilize Template Strings para textos dinâmicos

✅ Recomendado:

const nome = "Gustavo";

console.log(`Bem-vindo, ${nome}!`);

❌ Menos legível:

console.log("Bem-vindo, " + nome + "!");

Evite excesso de lógica dentro da interpolação

Embora seja possível fazer:

`${idade >= 18 ? "Maior de idade" : "Menor de idade"}`

expressões muito complexas podem dificultar a leitura do código. Nesses casos, vale a pena calcular o valor antes.

Resumo

As Template Strings são uma forma moderna de trabalhar com strings em JavaScript. Introduzidas no ECMAScript 6, elas utilizam crases e permitem interpolação de variáveis, execução de expressões, suporte a múltiplas linhas e construção dinâmica de conteúdos como HTML. Por tornarem o código mais legível e organizado, elas são amplamente utilizadas em aplicações JavaScript modernas e substituem, na maioria dos casos, as concatenações tradicionais com o operador +.
