Arrow Functions

Arrow Functions

As Arrow Functions (funções de seta) são uma forma mais curta e moderna de declarar funções em JavaScript. Elas foram introduzidas no ECMAScript 6 (ES6) com o objetivo de tornar o código mais simples, legível e expressivo, especialmente em callbacks e operações com arrays.

O nome "Arrow Function" vem do operador =>, que lembra uma seta.

Sintaxe Básica

Uma função tradicional pode ser escrita assim:

function somar(a, b) {
    return a + b;
}

Utilizando Arrow Function:

const somar = (a, b) => {
    return a + b;
};

Ambas produzem o mesmo resultado:

console.log(somar(5, 3));

Resultado:

8

Simplificando Ainda Mais

Quando a função possui apenas uma instrução e essa instrução retorna um valor, podemos omitir as chaves e o return.

const somar = (a, b) => a + b;

O JavaScript realiza o retorno automaticamente.

console.log(somar(5, 3));

Resultado:

8

Esse comportamento é chamado de retorno implícito.

Arrow Function Sem Parâmetros

Quando a função não recebe parâmetros, os parênteses são obrigatórios.

const saudacao = () => {
    console.log("Olá!");
};

saudacao();

Resultado:

Olá!

Arrow Function com Apenas Um Parâmetro

Se houver apenas um parâmetro, os parênteses podem ser omitidos.

const dobrar = numero => numero * 2;

console.log(dobrar(5));

Resultado:

10

Embora seja válido, muitos desenvolvedores preferem manter os parênteses por questão de consistência.

const dobrar = (numero) => numero * 2;

Retornando Objetos

Um detalhe importante é que objetos devem ser envolvidos por parênteses quando retornados implicitamente.

❌ Incorreto:

const criarUsuario = () => {
    nome: "Gustavo";
};

O JavaScript interpreta as chaves como um bloco de código.

✅ Correto:

const criarUsuario = () => ({
    nome: "Gustavo"
});

Resultado:

{
    nome: "Gustavo"
}

Arrow Functions em Callbacks

Um dos usos mais comuns das Arrow Functions é em funções de callback.

Antes do ES6

const numeros = [1, 2, 3, 4];

numeros.forEach(function(numero) {
    console.log(numero);
});

Com Arrow Function

const numeros = [1, 2, 3, 4];

numeros.forEach(numero => {
    console.log(numero);
});

O código fica mais compacto e fácil de ler.

Uso com Métodos de Arrays

Arrow Functions são amplamente utilizadas com métodos como map(), filter() e reduce().

map()

const numeros = [1, 2, 3, 4];

const dobrados = numeros.map(numero => numero * 2);

console.log(dobrados);

Resultado:

[2, 4, 6, 8]

filter()

const numeros = [1, 2, 3, 4, 5, 6];

const pares = numeros.filter(numero => numero % 2 === 0);

console.log(pares);

Resultado:

[2, 4, 6]

reduce()

const numeros = [1, 2, 3, 4];

const soma = numeros.reduce(
    (total, numero) => total + numero,
    0
);

console.log(soma);

Resultado:

10

A Grande Diferença: O Comportamento do this

A principal diferença entre uma função tradicional e uma Arrow Function está no tratamento da palavra-chave this.

Função Tradicional

const pessoa = {
    nome: "Gustavo",

    mostrarNome: function() {
        console.log(this.nome);
    }
};

pessoa.mostrarNome();

Resultado:

Gustavo

Nesse caso, this se refere ao objeto pessoa.

Problema em Callbacks

const pessoa = {
    nome: "Gustavo",

    mostrarNome: function() {
        setTimeout(function() {
            console.log(this.nome);
        }, 1000);
    }
};

pessoa.mostrarNome();

Resultado:

undefined

A função passada para setTimeout cria seu próprio contexto e perde a referência ao objeto.

Solução com Arrow Function

const pessoa = {
    nome: "Gustavo",

    mostrarNome: function() {
        setTimeout(() => {
            console.log(this.nome);
        }, 1000);
    }
};

pessoa.mostrarNome();

Resultado:

Gustavo

A Arrow Function não cria seu próprio this. Ela herda o this do escopo onde foi criada.

Esse comportamento é chamado de escopo léxico do this.

Limitações das Arrow Functions

Apesar de muito úteis, elas não substituem completamente as funções tradicionais.

Não podem ser usadas como construtoras

❌

const Pessoa = (nome) => {
    this.nome = nome;
};

const p = new Pessoa("Gustavo");

Resultado:

TypeError

Arrow Functions não funcionam com o operador new.

Não possuem objeto arguments

Funções tradicionais possuem um objeto chamado arguments.

function exemplo() {
    console.log(arguments);
}

Arrow Functions não possuem esse objeto.

const exemplo = () => {
    console.log(arguments);
};

Isso gera erro em muitos contextos.

Quando precisar receber quantidade variável de argumentos, utilize o operador rest:

const exemplo = (...args) => {
    console.log(args);
};

Quando Utilizar Arrow Functions

São excelentes para:

  • Callbacks.
  • Eventos.
  • Métodos de arrays (map, filter, reduce).
  • Funções curtas.
  • Operações matemáticas simples.
  • Situações em que você deseja herdar o this do contexto externo.

Exemplo:

const calcularImposto = valor => valor * 0.1;

Quando Evitar Arrow Functions

Em alguns casos, funções tradicionais são mais adequadas:

Métodos de objetos que dependem do próprio this

const pessoa = {
    nome: "Gustavo",

    mostrarNome() {
        console.log(this.nome);
    }
};

Funções construtoras

function Pessoa(nome) {
    this.nome = nome;
}

Quando precisar do objeto arguments

function exemplo() {
    console.log(arguments);
}

Vantagens das Arrow Functions

  • Sintaxe mais curta e moderna.
  • Código mais limpo e legível.
  • Retorno implícito em funções simples.
  • Melhor integração com métodos de arrays.
  • Herança automática do this.
  • Muito utilizadas em frameworks modernos como React, Vue e Angular.

Resumo

As Arrow Functions são uma forma moderna de criar funções em JavaScript utilizando a sintaxe =>. Introduzidas no ECMAScript 6, elas reduzem a quantidade de código necessária para declarar funções e possuem um comportamento especial em relação ao this, herdando-o do escopo externo. São amplamente utilizadas em callbacks, manipulação de arrays e desenvolvimento moderno com JavaScript, mas não devem substituir completamente as funções tradicionais, especialmente em construtores e métodos que dependem de seu próprio contexto.
