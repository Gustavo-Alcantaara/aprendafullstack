Parâmetros Default

Parâmetros Default (Valores Padrão)

Os parâmetros default (ou parâmetros padrão) são um recurso introduzido no ECMAScript 6 (ES6) que permite definir valores padrão para os parâmetros de uma função. Dessa forma, caso um argumento não seja fornecido durante a chamada da função, o JavaScript utilizará automaticamente o valor definido como padrão.

Esse recurso torna o código mais limpo, reduz a necessidade de verificações manuais e evita erros causados por parâmetros ausentes.

O Problema Antes do ES6

Antes da introdução dos parâmetros default, era comum verificar se um parâmetro havia sido informado e, caso não tivesse, atribuir um valor manualmente.

function saudacao(nome) {
    nome = nome || "Visitante";

    console.log(`Olá, ${nome}!`);
}

saudacao();

Resultado:

Olá, Visitante!

Embora funcione, essa abordagem possui algumas limitações e deixa o código menos intuitivo.

Sintaxe dos Parâmetros Default

Com o ES6, basta atribuir um valor diretamente na declaração do parâmetro.

function saudacao(nome = "Visitante") {
    console.log(`Olá, ${nome}!`);
}

saudacao();

Resultado:

Olá, Visitante!

Se um valor for informado, ele substituirá o valor padrão.

saudacao("Gustavo");

Resultado:

Olá, Gustavo!

Como Funcionam

O valor padrão só será utilizado quando o argumento recebido for undefined.

function mostrarValor(valor = 10) {
    console.log(valor);
}

mostrarValor();

Resultado:

10

Também:

mostrarValor(undefined);

Resultado:

10

Porém:

mostrarValor(null);

Resultado:

null

Isso acontece porque null é considerado um valor válido, enquanto undefined indica ausência de valor.

Múltiplos Parâmetros Default

É possível definir valores padrão para vários parâmetros.

function criarUsuario(nome = "Usuário", idade = 18) {
    console.log(`${nome} possui ${idade} anos.`);
}

criarUsuario();

Resultado:

Usuário possui 18 anos.

Também é possível substituir apenas alguns valores.

criarUsuario("Gustavo");

Resultado:

Gustavo possui 18 anos.

Parâmetros Dependentes de Outros Parâmetros

Um parâmetro padrão pode utilizar o valor de outro parâmetro definido anteriormente.

function calcularArea(largura, altura = largura) {
    return largura * altura;
}

console.log(calcularArea(5));

Resultado:

25

Nesse caso, se a altura não for informada, ela receberá o mesmo valor da largura.

Utilizando Expressões como Valor Padrão

O valor padrão não precisa ser um valor fixo. Ele pode ser resultado de uma expressão.

function calcularDesconto(valor, desconto = valor * 0.1) {
    return valor - desconto;
}

console.log(calcularDesconto(100));

Resultado:

90

Aqui, o desconto padrão é calculado automaticamente.

Utilizando Funções como Valor Padrão

Também é possível chamar funções para gerar o valor padrão.

function gerarCodigo() {
    return Math.floor(Math.random() * 1000);
}

function criarPedido(codigo = gerarCodigo()) {
    console.log(`Pedido #${codigo}`);
}

criarPedido();

Cada vez que a função for chamada sem argumentos, um novo código será gerado.

Parâmetros Default em Arrow Functions

Os parâmetros padrão funcionam normalmente em arrow functions.

const multiplicar = (a, b = 2) => a * b;

console.log(multiplicar(5));

Resultado:

10

Aplicações Práticas

Configurações Padrão

function criarBotao(
    texto = "Clique Aqui",
    cor = "azul",
    tamanho = "médio"
) {
    console.log(texto, cor, tamanho);
}

Caso algum valor não seja informado, a função utilizará as configurações padrão.

Cálculos

function somar(a, b = 0) {
    return a + b;
}

console.log(somar(10));

Resultado:

10

Isso evita erros quando um parâmetro é omitido.

Boas Práticas

Utilize valores padrão quando fizer sentido

Se existe um valor lógico para ser usado na ausência de um argumento, utilize parâmetros default.

function exibirMensagem(
    mensagem = "Nenhuma mensagem informada"
) {
    console.log(mensagem);
}

Evite valores padrão complexos demais

Embora seja possível colocar expressões longas dentro do parâmetro, isso pode prejudicar a legibilidade.

❌

function exemplo(
    valor = calcularValorMuitoComplexo()
) {}

Em situações complexas, pode ser melhor realizar o cálculo dentro da função.

Posicione os parâmetros obrigatórios primeiro

function cadastrar(nome, idade, cidade = "Não informada") {
    // ...
}

Essa organização torna a função mais intuitiva de utilizar.

Vantagens dos Parâmetros Default

  • Reduzem a quantidade de verificações dentro da função.
  • Tornam o código mais limpo e legível.
  • Evitam erros causados por parâmetros ausentes.
  • Facilitam a criação de funções flexíveis.
  • Melhoram a manutenção do código.

Resumo

Os parâmetros default permitem definir valores padrão para os parâmetros de uma função. Introduzidos no ECMAScript 6, eles são utilizados quando um argumento não é fornecido ou recebe o valor undefined. Esse recurso simplifica o código, elimina verificações desnecessárias e torna as funções mais robustas e fáceis de usar. Em aplicações modernas, é uma prática comum utilizar parâmetros padrão sempre que houver um valor lógico a ser assumido na ausência de um argumento fornecido pelo usuário ou pelo sistema.
