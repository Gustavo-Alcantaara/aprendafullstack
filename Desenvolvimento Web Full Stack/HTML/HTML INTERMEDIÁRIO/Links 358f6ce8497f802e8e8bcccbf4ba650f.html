Links

Links no HTML e suas Propriedades

Os links são usados para levar o usuário para outra página, arquivo, seção do site ou site externo. No HTML, eles são criados com a tag <a> (anchor).

Estrutura básica:

<a href="https://google.com">Ir para o Google</a>
  • <a> = tag de link
  • href = destino do link
  • Texto entre as tags = parte clicável

Principal atributo: href

Define para onde o link vai.

Exemplos:

<a href="pagina2.html">Outra página</a>
<a href="https://site.com">Site externo</a>
<a href="#contato">Ir para seção contato</a>

Outras propriedades importantes:

target

Define onde o link será aberto.

<a href="https://google.com" target="_blank">

Valores comuns:

  • _self → mesma aba (padrão)
  • _blank → nova aba

rel

Usado junto com target="_blank" por segurança.

<a href="https://site.com" target="_blank" rel="noopener noreferrer">

title

Mostra dica ao passar o mouse.

<a href="contato.html" title="Fale conosco">

download

Faz download do arquivo ao clicar.

<a href="arquivo.pdf" download>Baixar PDF</a>

Link para e-mail:

<a href="mailto:email@site.com">Enviar email</a>

Link para telefone:

<a href="tel:+5588999999999">Ligar</a>

Resumo rápido:

AtributoFunção
hrefDestino do link
targetOnde abrir
relSegurança/relacionamento
titleDica ao passar mouse
downloadBaixar arquivo

Dica:

Todo link precisa de href. Sem ele, a tag <a> não funciona corretamente como link.
