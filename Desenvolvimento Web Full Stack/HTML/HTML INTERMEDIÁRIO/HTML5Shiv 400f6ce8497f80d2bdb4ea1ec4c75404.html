HTML5Shiv

O HTML5Shiv é uma pequena biblioteca JavaScript criada para permitir que navegadores muito antigos, principalmente o Internet Explorer 8 e anteriores, reconhecessem e permitissem estilizar elementos introduzidos pelo HTML5, como:

<header>
<nav>
<section>
<article>
<aside>
<footer>
<figure>

Esses elementos são chamados de elementos semânticos, pois ajudam a indicar a função de cada parte da página. GitHub

🔹 Qual era o problema?

Quando o HTML5 surgiu, navegadores modernos começaram a entender elementos como:

<header>
<nav>
<section>
<article>
<footer>

Porém, versões antigas do Internet Explorer não conseguiam lidar corretamente com esses novos elementos.

Por exemplo:

<section>
    <h1>Meu site</h1>
    <p>Conteúdo da seção.</p>
</section>

Um navegador moderno entende <section> normalmente e permite que você aplique CSS:

section {
    background: #eee;
    padding: 20px;
}

Já versões antigas do IE tinham problemas para reconhecer e estilizar elementos HTML5 desconhecidos. O HTML5Shiv funcionava como uma solução de compatibilidade para esse problema. SitePoint

🔹 Como o HTML5Shiv funcionava?

O HTML5Shiv utilizava JavaScript para "ensinar" o navegador antigo a reconhecer os elementos HTML5.

Uma das técnicas utilizadas era criar os elementos através de:

document.createElement("section");
document.createElement("article");
document.createElement("nav");

Isso fazia com que o navegador passasse a reconhecer esses elementos e permitisse que fossem estilizados. SitePoint

A biblioteca automatizava esse processo para vários elementos HTML5.

🔹 Como era utilizado?

Tradicionalmente, colocava-se o HTML5Shiv dentro do <head>:

<head>

    <meta charset="UTF-8">

    <!--[if lt IE 9]>
        <script src="html5shiv.js"></script>
    <![endif]-->

</head>

A parte:

<!--[if lt IE 9]>

era uma Conditional Comment do Internet Explorer.

Ela significava aproximadamente:

"Execute este código somente se o navegador for uma versão do Internet Explorer menor que a 9."

Assim, navegadores modernos não precisavam carregar o script. W3SchoolsUA

🔹 Exemplo completo

Imagine uma página HTML5:

<!DOCTYPE html>
<html lang="pt-BR">

<head>
    <meta charset="UTF-8">

    <!-- Compatibilidade com navegadores antigos -->
    <!--[if lt IE 9]>
        <script src="html5shiv.js"></script>
    <![endif]-->

    <style>
        header,
        nav,
        section,
        article,
        footer {
            display: block;
        }
    </style>
</head>

<body>

    <header>
        <h1>Meu Site</h1>
    </header>

    <nav>
        <a href="#">Início</a>
        <a href="#">Sobre</a>
    </nav>

    <section>
        <article>
            <h2>Meu artigo</h2>
            <p>Conteúdo do artigo.</p>
        </article>
    </section>

    <footer>
        <p>Meu site</p>
    </footer>

</body>

</html>

O HTML5Shiv ajudaria navegadores antigos a reconhecer elementos como <header>, <nav>, <section>, <article> e <footer>.

🔹 HTML5Shiv não adiciona todas as funcionalidades do HTML5

Isso é importante.

O HTML5Shiv não transforma um navegador antigo em um navegador moderno.

Ele foi criado principalmente para solucionar o problema de reconhecimento e estilização dos elementos HTML5, especialmente os elementos semânticos. GitHub

Por exemplo, ele não faria um navegador antigo ganhar suporte completo a:

  • APIs modernas;
  • localStorage;
  • WebSockets;
  • recursos avançados de CSS;
  • APIs multimídia;
  • recursos modernos de JavaScript.

Para isso seriam necessárias outras técnicas, como polyfills específicos.

🔹 HTML5Shiv atualmente

Aqui está a parte mais importante para você hoje:

Você praticamente não precisa utilizar HTML5Shiv em projetos modernos.

Chrome, Firefox, Safari e Edge atuais já possuem suporte nativo aos elementos semânticos HTML5. O Internet Explorer também deixou de ser suportado pela Microsoft em 2022. W3docs

Portanto, atualmente você pode simplesmente escrever:

<header>
    ...
</header>

<nav>
    ...
</nav>

<main>
    ...
</main>

<section>
    ...
</section>

<footer>
    ...
</footer>

sem precisar do HTML5Shiv.

🔹 Então por que estudar HTML5Shiv?

Porque ele aparece bastante em cursos antigos de HTML5, CSS3 e desenvolvimento web, principalmente em conteúdos que explicam compatibilidade entre navegadores.

Ele também é um ótimo exemplo histórico de um conceito importante:

Polyfill/Shim: código utilizado para fornecer compatibilidade com funcionalidades que um navegador antigo não possui.

O próprio projeto HTML5Shiv é descrito como uma solução para habilitar elementos de HTML5 em versões antigas do Internet Explorer. GitHub
