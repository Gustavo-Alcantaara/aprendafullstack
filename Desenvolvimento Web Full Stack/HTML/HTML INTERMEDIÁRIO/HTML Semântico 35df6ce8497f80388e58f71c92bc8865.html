HTML Semântico

O HTML semântico é uma forma de estruturar páginas usando tags que descrevem claramente o significado do conteúdo, em vez de apenas sua aparência. Isso melhora a organização do código, a acessibilidade e o SEO.

Principais vantagens

  • Melhor leitura do código: facilita o entendimento por desenvolvedores.
  • Acessibilidade: leitores de tela entendem melhor a estrutura da página.
  • SEO: mecanismos de busca identificam o conteúdo com mais precisão.
  • Manutenção mais fácil: o código fica mais organizado.

Tags semânticas mais usadas

TagFunção
<header>Cabeçalho da página ou seção
<nav>Área de navegação/menu
<main>Conteúdo principal
<section>Seção temática
<article>Conteúdo independente
<aside>Conteúdo complementar/lateral
<footer>Rodapé
<figure>Imagem ou ilustração
<figcaption>Legenda da imagem

Exemplo básico

<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="UTF-8">
<title>Exemplo Semântico</title>
</head>
<body>

<header>
<h1>Meu Site</h1>
</header>

<nav>
<a href="#">Início</a>
<a href="#">Contato</a>
</nav>

<main>
<section>
<h2>Sobre</h2>
<p>Conteúdo da seção.</p>
</section>

<article>
<h2>Notícia</h2>
<p>Texto do artigo.</p>
</article>
</main>

<aside>
    Conteúdo relacionado
</aside>

<footer>
    © 2026 Meu Site
</footer>

</body>
</html>

Diferença entre semântico e não semântico

Não semântico

<div id="topo"></div>
<div class="menu"></div>
<div class="conteudo"></div>

Semântico

<header></header>
<nav></nav>
<main></main>

As tags semânticas informam claramente o papel de cada parte da página.

Conclusão

HTML semântico consiste em usar elementos apropriados para representar o significado do conteúdo. Isso torna sites mais acessíveis, organizados e otimizados para mecanismos de busca.
