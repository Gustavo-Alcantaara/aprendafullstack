Estrutura Básica do HTML

HTML (HyperText Markup Language) é a linguagem usada para estruturar páginas da web. Todo documento HTML segue uma base padrão para organizar o conteúdo corretamente.

Exemplo de estrutura básica:

<!DOCTYPE html>
<htmllang="pt-BR">
<head>
<metacharset="UTF-8">
<metaname="viewport"content="width=device-width, initial-scale=1.0">
<title>Título da Página</title>
</head>
<body>
<h1>Olá Mundo!</h1>
<p>Meu primeiro site.</p>
</body>
</html>

Explicando cada parte:

<!DOCTYPE html>

Informa ao navegador que o documento usa a versão HTML5.

<html>

É a tag principal que envolve todo o conteúdo da página.

lang="pt-BR"

Define o idioma da página, importante para acessibilidade e mecanismos de busca.

<head>

Área de configurações invisíveis da página. Contém informações como:

  • <meta charset="UTF-8"> → suporta acentos e caracteres especiais.
  • <meta name="viewport"> → ajusta o site para celular.
  • <title> → nome exibido na aba do navegador.

<body>

Parte visível do site, onde fica todo o conteúdo mostrado ao usuário:

  • textos
  • imagens
  • botões
  • links
  • listas
  • tabelas
  • formulários

Resumo rápido:

ParteFunção
DOCTYPEDefine HTML5
htmlEstrutura principal
headConfigurações
titleNome da aba
bodyConteúdo visível

Dica importante:

Tudo que o usuário vê fica dentro do body.

Tudo que configura a página fica dentro do head.

Tags <meta> no HTML

As tags <meta> ficam dentro da seção <head> e servem para fornecer informações sobre a página ao navegador, mecanismos de busca e outros sistemas. Elas não aparecem visualmente no site, mas são muito importantes.

Estrutura básica:

<meta atributo="valor">

Principais tags meta:

charset

Define a codificação de caracteres da página.

<meta charset="UTF-8">

Permite usar acentos, ç, símbolos etc.

viewport

Controla a exibição em dispositivos móveis.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Faz o site se adaptar à largura da tela.

description

Descrição da página para buscadores.

<meta name="description"content="Curso de HTML e CSS para iniciantes">

Pode aparecer no Google.

keywords

Palavras-chave relacionadas ao conteúdo.

<meta name="keywords"content="html, css, javascript">

Hoje tem pouca relevância para SEO.

author

Define o autor da página.

<meta name="author"content="Gustavo">

refresh

Atualiza ou redireciona a página automaticamente.

<meta http-equiv="refresh"content="5">

Recarrega em 5 segundos.

Ou redireciona:

<meta http-equiv="refresh"content="3;url=https://site.com">

Resumo rápido:

Dica:

As mais importantes hoje em dia são:

  • charset
  • viewport
  • description

Essas quase todo site usa.
