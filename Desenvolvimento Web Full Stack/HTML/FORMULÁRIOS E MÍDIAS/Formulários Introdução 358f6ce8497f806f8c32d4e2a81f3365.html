Formulários: Introdução

Formulários HTML são usados para coletar dados do usuário em páginas web, como login, cadastro, pesquisa, comentários e compras.

Estrutura básica

O formulário é criado com a tag:

<form>
</form>

Tudo o que estiver dentro dela faz parte do formulário.

Principais elementos

1. Campo de texto

<input type="text">

Usado para nome, usuário etc.

2. Senha

<input type="password">

Esconde os caracteres digitados.

3. Email

<input type="email">

Valida se o texto parece um email.

4. Número

<input type="number">

Aceita números.

5. Botão

<button>Enviar</button>
<button type="submit">Enviar</button>
<button type="reset">Resetar</button>
Por padrão, um botão dentro de um formulário tem a função de "submit"

OU

<input type="submit" value="Enviar"> Enviar dados
<input type="reset" value="Resetar"> Resetar formulário

Podemos também colocar imagens em botões

<button>
<img src="imagem.jpg"> Enviar
</button>

6. Arquivos

Podemos também receber arquivos através de formulários

<input type="file" name="arquivo">

Labels (rótulos)

Servem para identificar campos.

<label>Nome:</label>
<input type="text">

OU

<label>
<input type="text">
</label>

OU

FORMA CORRETA (MAIS UTILIZADA)

<label for="nome">Nome:</label>
<input type="text" name="nome" id="nome">
O for do label aponta para o id do input.

O valor que o input receber será guardado no name.

Melhora acessibilidade.

Placeholder

Texto dentro do campo.

<input type="text" placeholder="Digite seu nome">

Required

Campo obrigatório.

<input type="text" required>

Checkbox

Marcar opções.

<input type="checkbox">

Radio

Escolher apenas uma opção.

<input type="radio" name="sexo" value="M">
<input type="radio" name="sexo" value="F">

Mesmo name = grupo.

Select (lista)

<select name="pais">
<option value="brasil">Brasil</option>
<option value="portugal">Portugal</option>
</select>

Textarea

Campo grande para mensagens.

<textarea></textarea>

Action e Method

Dentro do <form> :

<form action="arquivo.php" method="post">

action

Para onde os dados vão.

method

Como serão enviados:

  • GET: aparece na URL
  • POST: oculto, mais usado

Fieldset e Legend

Fieldset

É um conjunto de campos, podemos colocar inputs de uma mesma categoria dentro dele.

Legend

É a legenda do campo, um indicador

Exemplo:

<fieldset>
<legend>Dados Pessoais</legend>

<label for="nome">Nome</label>
<input type="text" name="nome" id="nome">

<label for="email">Email</label>
<input type="email" name="email" id="email">

</fieldset>

Exemplo Completo

<form action="cadastro.php" method="post">
  <label>Nome:</label>
  <input type="text" required>

  <label>Email:</label>
  <input type="email">

  <button>Enviar</button>
</form>

Resumo final

Formulários HTML servem para entrada de dados.

Os principais elementos são:

  • <form>
  • <input>
  • <label>
  • <textarea>
  • <select>
  • <button>

São essenciais em qualquer site interativo.

Se é campo que o usuário preenche, fica dentro do form
