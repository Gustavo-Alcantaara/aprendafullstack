Criação e Exclusão

Criando e Excluindo Bancos de Dados no MySQL

A criação e a exclusão de bancos de dados são operações fundamentais na administração do MySQL. Antes de criar tabelas e armazenar informações, é necessário ter um banco de dados onde essas estruturas serão organizadas.

No MySQL, essas operações podem ser realizadas de duas maneiras principais:

  • utilizando comandos SQL;
  • utilizando ferramentas gráficas, como o phpMyAdmin.

1. Criando um banco de dados

Para criar um banco de dados no MySQL, utilizamos o comando:

CREATE DATABASE nome_do_banco;

Por exemplo:

CREATE DATABASE loja;

Esse comando cria um banco de dados chamado loja.

Depois de criado, podemos selecioná-lo para trabalhar com suas tabelas:

USE loja;

A partir desse momento, os comandos de criação de tabelas serão executados dentro do banco loja.

2. Verificando os bancos existentes

Para visualizar todos os bancos de dados existentes no servidor MySQL, utilizamos:

SHOW DATABASES;

O resultado poderá ser semelhante a:

information_schema
mysql
performance_schema
sys
loja

Os primeiros bancos normalmente são utilizados pelo próprio MySQL. O banco loja é o que acabamos de criar.

3. Criando um banco somente se ele não existir

Um problema comum ocorre quando tentamos criar um banco que já existe.

Por exemplo:

CREATE DATABASE loja;

Se loja já existir, o MySQL poderá retornar um erro informando que o banco já existe.

Para evitar isso, podemos utilizar:

CREATE DATABASE IF NOT EXISTS loja;

O IF NOT EXISTS significa:

"Crie o banco somente se ele ainda não existir."

Essa é uma prática bastante útil em scripts SQL.

4. Definindo a codificação do banco

Também podemos especificar a codificação de caracteres utilizada pelo banco.

Uma configuração moderna e recomendada é utilizar UTF-8 através de utf8mb4:

CREATE DATABASE loja
CHARACTER SET utf8mb4
COLLATE utf8mb4_0900_ai_ci;

Isso permite trabalhar corretamente com diversos caracteres, incluindo:

  • letras acentuadas;
  • símbolos;
  • caracteres de diferentes idiomas;
  • emojis.

Por exemplo:

João
Informação
Computação
😀

O CHARACTER SET define como os caracteres serão armazenados, enquanto o COLLATE define regras utilizadas para comparação e ordenação de textos.

5. Selecionando um banco de dados

Depois de criar o banco, precisamos informar ao MySQL qual banco queremos utilizar.

Para isso:

USE loja;

Podemos confirmar qual banco está selecionado usando:

SELECT DATABASE();

O resultado será:

loja

Isso é especialmente útil quando estamos trabalhando com vários bancos no mesmo servidor.

6. Criando um banco pelo phpMyAdmin

No phpMyAdmin, a criação é ainda mais simples.

Passos:

  1. Acesse o phpMyAdmin.
  1. Clique em Novo no menu lateral.
  1. Digite o nome do banco.
  1. Escolha a codificação, preferencialmente utf8mb4 quando apropriado.
  1. Clique em Criar.

O phpMyAdmin executará internamente um comando semelhante a:

CREATE DATABASE loja;

Depois disso, o banco aparecerá no menu lateral.

7. Excluindo um banco de dados

Para excluir completamente um banco de dados, utilizamos:

DROP DATABASE nome_do_banco;

Por exemplo:

DROP DATABASE loja;

Esse comando remove o banco de dados inteiro.

Isso significa que serão removidos:

  • tabelas;
  • registros;
  • índices;
  • views;
  • procedures;
  • triggers;
  • demais objetos pertencentes ao banco.

É uma operação destrutiva e deve ser utilizada com muito cuidado.

8. Excluindo somente se o banco existir

Assim como na criação, podemos utilizar IF EXISTS:

DROP DATABASE IF EXISTS loja;

Nesse caso, o MySQL só tentará excluir o banco se ele existir.

Isso evita erros em scripts automatizados.

9. Excluindo um banco pelo phpMyAdmin

No phpMyAdmin:

  1. Selecione o banco de dados.
  1. Acesse a opção Operações.
  1. Localize a opção para remover o banco.
  1. Confirme a exclusão.

Dependendo da versão e configuração do phpMyAdmin, a opção pode aparecer como Remover o banco de dados (DROP).

⚠️ A confirmação deve ser feita com atenção, pois a operação pode apagar definitivamente os dados.

10. Diferença entre DROP, DELETE e TRUNCATE

É muito importante não confundir esses comandos.

DROP DATABASE

Remove o banco inteiro:

DROP DATABASE loja;

DELETE

Remove registros de uma tabela:

DELETE FROM clientes
WHERE id = 5;

A tabela continua existindo.

TRUNCATE

Remove todos os registros de uma tabela, mantendo a estrutura:

TRUNCATE TABLE clientes;

Portanto:

DROP DATABASE
      ↓
Remove o banco inteiro

TRUNCATE TABLE
      ↓
Remove os registros da tabela

DELETE
      ↓
Remove registros específicos

11. Exemplo completo

Imagine que vamos criar um banco para uma loja.

Primeiro:

CREATE DATABASE IF NOT EXISTS loja
CHARACTER SET utf8mb4
COLLATE utf8mb4_0900_ai_ci;

Depois:

USE loja;

Agora podemos criar uma tabela:

CREATE TABLE produtos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    preco DECIMAL(10,2) NOT NULL
);

Inserimos um produto:

INSERT INTO produtos (nome, preco)
VALUES ('Notebook', 3500.00);

Consultamos:

SELECT * FROM produtos;

Teremos algo semelhante a:

idnomepreco
1Notebook3500.00

Se quisermos apagar apenas o banco inteiro, usamos:

DROP DATABASE loja;

Depois disso, o banco loja e tudo que estava dentro dele serão removidos.

12. Cuidados ao excluir bancos

O comando DROP DATABASE deve ser utilizado com extremo cuidado.

Antes de executá-lo em um ambiente importante, é recomendado:

  • verificar o nome do banco;
  • confirmar se realmente é necessário excluí-lo;
  • realizar um backup;
  • verificar se alguma aplicação depende dele;
  • confirmar que não é um banco de produção.

Por exemplo, executar acidentalmente:

DROP DATABASE sistema_empresa;

pode causar uma perda completa dos dados daquele sistema.

Por isso, nunca execute DROP DATABASE sem ter certeza da consequência.

Resumo

No MySQL, o comando CREATE DATABASE é utilizado para criar novos bancos de dados, enquanto DROP DATABASE é utilizado para removê-los completamente. O comando SHOW DATABASES permite visualizar os bancos existentes e USE seleciona o banco que será utilizado.

Por meio do phpMyAdmin, essas mesmas operações podem ser realizadas através de uma interface gráfica, facilitando o gerenciamento para iniciantes. Entretanto, compreender os comandos SQL é fundamental, principalmente para trabalhar com scripts, automação e ambientes profissionais.

A principal diferença que deve ser lembrada é:

CREATE DATABASE → cria um banco
USE              → seleciona um banco
SHOW DATABASES   → lista os bancos
DROP DATABASE    → exclui um banco inteiro
