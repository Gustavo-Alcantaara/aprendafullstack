Funções - Parâmetros variáveis

Parâmetros Variáveis em JavaScript

Os parâmetros variáveis permitem que uma função receba uma quantidade indefinida de argumentos. Isso é útil quando não sabemos quantos valores serão passados para a função.

Problema sem parâmetros variáveis

Imagine uma função para somar números:

function somar(a,b) {
return a + b;
}

console.log(somar(10,20));

Funciona para 2 números, mas e se quisermos somar 3, 4 ou 10 números?

Objeto arguments

Antes do ES6, utilizava-se o objeto especial arguments.

function somar() {
console.log(arguments);
}

somar(10,20,30);

Resultado:

[10, 20, 30]

O arguments contém todos os argumentos passados para a função.

Exemplo com soma

function somar() {

let total = 0;

for (let i = 0; i < arguments.length; i++) {
total += arguments[i];
  }

return total;
}

console.log(somar(10,20,30,40));

Resultado:

100

Limitações do arguments

  • Não é um array verdadeiro.
  • Não funciona em Arrow Functions.
  • Hoje é pouco utilizado.

Rest Parameter (...)

A forma moderna de trabalhar com parâmetros variáveis é usando o operador rest.

Sintaxe:

function nome(...parametros) {

}

Exemplo

function somar(...numeros) {
console.log(numeros);
}

somar(10,20,30);

Resultado:

[10,20,30]

Observe que numeros já é um array real.

Somando valores

function somar(...numeros) {

let total = 0;

for (const numero of numeros) {
total += numero;
  }

return total;
}

console.log(somar(10,20,30,40));

Resultado:

100

Rest + Arrow Function

const somar = (...numeros) => {

let total=0;

numeros.forEach(numero => {
total += numero;
  });

return total;
};

Misturando parâmetros normais e variáveis

O parâmetro rest deve ficar por último.

function cadastro(nome,idade, ...telefones) {

console.log(nome);
console.log(idade);
console.log(telefones);

}

Chamada:

cadastro(
"Gustavo",
21,
"99999-9999",
"88888-8888"
);

Resultado:

nome = "Gustavo"
idade = 21
telefones = [
"99999-9999",
"88888-8888"
]

Regra importante

❌ Errado:

function teste(...valores,nome) {

}

O parâmetro rest deve ser sempre o último.

Spread e Rest

Apesar de usarem ..., possuem funções diferentes.

Rest

Recebe vários argumentos.

function somar(...numeros) {

}

Spread

Espalha valores de um array.

const numeros = [10,20,30];

console.log(...numeros);

Resultado:

10 20 30

Quando usar parâmetros variáveis?

São muito úteis para:

  • Somatórios
  • Calculadoras
  • Listas de produtos
  • Sistemas de tags
  • APIs
  • Funções genéricas

Resumindo

Os parâmetros variáveis permitem que uma função receba qualquer quantidade de argumentos.

Principais formas:

Antiga

arguments

Moderna

function exemplo(...valores) {

}

Vantagens do ...rest:

  • Mais legível
  • Funciona com arrays
  • Compatível com Arrow Functions
  • É o padrão utilizado atualmente

Esse recurso é muito comum em projetos modernos desenvolvidos com React, Node.js e JavaScript moderno em geral.
