Funções de Callback

Em JavaScript, funções de callback são funções passadas como argumento para outra função, para serem executadas depois.

Elas são um dos conceitos mais importantes do JavaScript, principalmente em:

  • eventos
  • timers
  • requisições
  • assincronismo
  • manipulação de arrays

O que é um callback?

Uma função recebe outra função:

function executar(callback) {
callback();
}

Uso:

executar(function() {
console.log("Função executada");
});

Como funciona

A função principal decide:

  • quando executar
  • quantas vezes executar
  • em qual contexto executar

Exemplo simples

function saudacao(nome,callback) {
console.log(`Olá,${nome}`);

callback();
}

function despedida() {
console.log("Tchau!");
}

saudacao("Gustavo",despedida);

Resultado:

Olá, Gustavo
Tchau!

Callback anônimo

Muito comum:

saudacao("Gustavo",function() {
console.log("Até mais!");
});

Callbacks em timers

setTimeout

Executa depois de um tempo:

setTimeout(function() {
console.log("Executou");
},2000);

setInterval

Executa repetidamente:

setInterval(function() {
console.log("Rodando");
},1000);

Callbacks em eventos

Muito usados no navegador:

button.addEventListener("click",function() {
console.log("Clicou");
});

A função só executa quando o evento acontecer.

Callbacks em arrays

Métodos modernos usam callbacks.

forEach

const numeros = [1,2,3];

numeros.forEach(function(numero) {
console.log(numero);
});

map

const numeros= [1,2,3];

const dobrados = numeros.map(function(numero) {
return numero * 2;
});

Arrow function com callback

Muito comum atualmente:

numeros.forEach(numero => {
console.log(numero);
});

Callback síncrono

Executa imediatamente:

[1,2,3].forEach(numero => {
console.log(numero);
});

Callback assíncrono

Executa depois:

setTimeout(() => {
console.log("Depois");
},1000);

Callback Hell

Problema causado por muitos callbacks aninhados:

funcao1(() => {
funcao2(() => {
funcao3(() => {
console.log("Fim");
    });
  });
});

Isso deixa o código difícil de ler.

Soluções modernas

Hoje usamos muito:

  • Promises
  • async/await

Mas callbacks continuam sendo a base do assincronismo no JavaScript.

Callback ≠ executar função

Errado:

executar(minhaFuncao());

Certo:

executar(minhaFuncao);

Sem os parênteses, você passa a função em vez de executá-la.

Resumindo

Callbacks:

  • são funções passadas para outras funções
  • permitem execução dinâmica
  • são fundamentais no assincronismo
  • são muito usados em eventos, timers e arrays

Praticamente todo o ecossistema moderno de Node.js e React utiliza callbacks de alguma forma.
