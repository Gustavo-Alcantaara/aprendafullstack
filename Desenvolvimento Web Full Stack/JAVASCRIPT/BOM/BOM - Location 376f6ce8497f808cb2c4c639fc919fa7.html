BOM - Location

Objeto location em JavaScript

O objeto location faz parte do BOM (Browser Object Model) e fornece informações sobre a URL atual da página.

Além de consultar informações da URL, ele também permite:

  • redirecionar páginas
  • recarregar páginas
  • alterar partes da URL
  • obter parâmetros da URL

Acessando o objeto

console.log(location);

Ou:

console.log(window.location);

Os dois são equivalentes.

URL completa

href

Retorna a URL completa da página.

console.log(location.href);

Exemplo:

https://www.meusite.com/produtos?id=10

Alterando a URL

Também podemos redirecionar o usuário.

location.href = "https://www.google.com";

O navegador navegará para a nova página.

Protocolo

protocol

Retorna o protocolo utilizado.

console.log(location.protocol);

Resultado:

https:

Host

host

Retorna domínio + porta.

console.log(location.host);

Resultado:

www.meusite.com

Hostname

hostname

Retorna apenas o domínio.

console.log(location.hostname);

Resultado:

www.meusite.com

Porta

port

Retorna a porta utilizada.

console.log(location.port);

Exemplo:

8080

Se nenhuma porta for especificada, normalmente retorna uma string vazia.

Caminho

pathname

Retorna o caminho da URL.

console.log(location.pathname);

Exemplo:

URL:

https://www.meusite.com/produtos/lista

Resultado:

/produtos/lista

Parâmetros da URL

search

Retorna a query string.

URL:

https://site.com?id=10&nome=joao

Código:

console.log(location.search);

Resultado:

?id=10&nome=joao

Fragmento (âncora)

hash

URL:

https://site.com/#contato

Código:

console.log(location.hash);

Resultado:

#contato

Recarregando a página

reload()

location.reload();

Atualiza a página atual.

Equivale ao usuário pressionar F5.

Substituindo página

replace()

location.replace(
"https://www.google.com"
);

Diferença:

  • href adiciona uma entrada ao histórico.
  • replace() substitui a página atual no histórico.

Com replace(), o botão "Voltar" não retorna para a página anterior.

Atribuindo URL

assign()

location.assign(
"https://www.google.com"
);

Semelhante a:

location.href = "https://www.google.com";

Trabalhando com parâmetros

URL:

https://site.com?id=10

Forma moderna:

const params =
newURLSearchParams(location.search);

console.log(
params.get("id")
);

Resultado:

10

Exemplo prático

Verificar se a página usa HTTPS:

if (location.protocol === "https:") {
console.log("Conexão segura");
}

Exemplo de redirecionamento

if (!usuarioLogado) {
location.href="login.html";
}

Muito comum em sistemas de autenticação.

Casos de uso

O objeto location é muito utilizado para:

  • Redirecionamentos
  • Controle de rotas
  • Leitura de parâmetros da URL
  • Sistemas de login
  • Navegação entre páginas
  • Aplicações SPA (Single Page Application)

Resumindo

O objeto location fornece informações sobre a URL atual e permite controlar a navegação do usuário.

Exemplo:

console.log(location.href);
console.log(location.pathname);

location.reload();
location.href = "home.html";

Ele é uma das partes mais importantes do BOM e é amplamente utilizado em aplicações web modernas para navegação e controle de rotas.
