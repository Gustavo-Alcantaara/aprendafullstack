BOM - Introdução

BOM (Browser Object Model)

O BOM (Browser Object Model) é o conjunto de objetos fornecidos pelo navegador que permite ao JavaScript interagir com a janela do navegador e seus recursos.

Enquanto o DOM trabalha com a página HTML, o BOM trabalha com o próprio navegador.

BOM x DOM

DOM

Manipula elementos da página.

document.getElementById("titulo");

Exemplos:

  • textos
  • imagens
  • formulários
  • estilos

BOM

Manipula o navegador.

window.alert("Olá!");

Exemplos:

  • janelas
  • abas
  • URL
  • histórico
  • tamanho da tela

Objeto window

O objeto principal do BOM é o window.

Tudo no BOM deriva dele.

window.alert("Olá");

Pode ser escrito também como:

alert("Olá");

Pois window é implícito.

Principais objetos do BOM

window
├── document (DOM)
├── location
├── history
├── navigator
├── screen

alert()

Exibe uma caixa de mensagem.

alert("Bem-vindo!");

confirm()

Exibe uma caixa de confirmação.

const resposta = confirm(
"Deseja continuar?"
);

console.log(resposta);

Retorna:

true

ou

false

prompt()

Solicita uma informação ao usuário.

const nome = prompt(
"Digite seu nome:"
);

console.log(nome);

Objeto location

Contém informações sobre a URL atual.

console.log(location.href);

Exemplo:

https://meusite.com

Redirecionar página

location.href = "https://google.com";

Recarregar página

location.reload();

Objeto history

Permite navegar pelo histórico.

Voltar

history.back();

Avançar

history.forward();

Navegar posições

history.go(-2);

Volta duas páginas.

Objeto navigator

Fornece informações sobre o navegador.

console.log(navigator.userAgent);

Exemplo:

Mozilla/5.0 ...

Idioma

console.log(navigator.language);

Resultado:

pt-BR

Objeto screen

Fornece informações sobre a tela.

console.log(screen.width);
console.log(screen.height);

Resultado:

1920
1080

Tamanho da janela

console.log(window.innerWidth);
console.log(window.innerHeight);

Abrindo nova janela

window.open(
"https://google.com"
);

Fechando janela

window.close();

⚠️ Geralmente só funciona para janelas abertas pelo próprio JavaScript.

Temporizadores

O BOM também fornece funções de tempo.

setTimeout()

Executa uma vez após um intervalo.

setTimeout(() => {
console.log("Executou!");
},3000);

Resultado após 3 segundos:

Executou!

clearTimeout()

Cancela um timeout.

const timer = setTimeout(() => {
console.log("Executou!");
},3000);

clearTimeout(timer);

setInterval()

Executa repetidamente.

setInterval(() => {
console.log("Olá");
},1000);

Resultado:

Olá
Olá
Olá
...

clearInterval()

Interrompe o intervalo.

const timer = setInterval(() => {
console.log("Olá");
},1000);

clearInterval(timer);

Exemplo prático

Relógio digital:

setInterval(() => {

const agora = new Date();

console.log(
agora.toLocaleTimeString()
  );

},1000);

Casos de uso

O BOM é usado para:

  • Redirecionamentos
  • Controle de navegação
  • Pop-ups
  • Temporizadores
  • Informações do navegador
  • Informações da tela
  • Interação com o usuário

Resumindo

O BOM (Browser Object Model) permite que o JavaScript interaja com o navegador.

Principais objetos:

ObjetoFunção
windowJanela do navegador
locationURL atual
historyHistórico de navegação
navigatorInformações do navegador
screenInformações da tela

Principais funções:

alert()
confirm()
prompt()

setTimeout()
setInterval()

location.href
history.back()

O BOM é fundamental para criar aplicações web interativas, pois conecta o código JavaScript ao ambiente do navegador onde ele está sendo executado.
