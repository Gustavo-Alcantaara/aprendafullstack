BOM - Window

Objeto window em JavaScript

O window é o objeto principal do BOM (Browser Object Model). Ele representa a janela ou aba do navegador onde a página está sendo executada.

Tudo que está relacionado ao navegador deriva do objeto window.

O objeto global do navegador

Quando você cria uma variável ou chama determinadas funções no navegador, está utilizando o window implicitamente.

Exemplo:

alert("Olá!");

Na verdade:

window.alert("Olá!");

Os dois códigos fazem exatamente a mesma coisa.

Propriedades da janela

Largura interna

console.log(window.innerWidth);

Exemplo:

1366

Altura interna

console.log(window.innerHeight);

Exemplo:

768

Tamanho externo

console.log(window.outerWidth);
console.log(window.outerHeight);

Inclui bordas e elementos do navegador.

Abrindo janelas

window.open(
"https://www.google.com"
);

Abre uma nova aba ou janela.

Fechando janelas

window.close();

⚠️ Normalmente só funciona em janelas abertas pelo próprio JavaScript.

Exibindo mensagens

Alert

window.alert("Mensagem");

Confirm

const resposta =
window.confirm("Deseja sair?");

Retorna:

true

ou

false

Prompt

const nome=
window.prompt("Digite seu nome:");

Retorna o texto digitado.

Temporizadores

setTimeout

Executa uma única vez após um intervalo.

window.setTimeout(() => {
console.log("Executou");
},3000);

clearTimeout

Cancela o timeout.

const timer = setTimeout(() => {
console.log("Executou");
},3000);

clearTimeout(timer);

setInterval

Executa continuamente.

window.setInterval(() => {
console.log("Olá");
},1000);

clearInterval

Interrompe o intervalo.

const timer = setInterval(() => {
console.log("Olá");
},1000);

clearInterval(timer);

Eventos da janela

Quando a página carrega

window.onload = function() {
console.log("Página carregada");
};

Quando a janela é redimensionada

window.onresize = function() {
console.log("Redimensionou");
};

Quando o usuário tenta sair

window.onbeforeunload = function() {
return"Deseja realmente sair?";
};

Scroll da página

Posição vertical:

console.log(window.scrollY);

Posição horizontal:

console.log(window.scrollX);

Rolando a página

window.scrollTo(0,500);

Move a página para a posição especificada.

Variáveis globais

Variáveis declaradas com var no escopo global tornam-se propriedades de window.

var nome = "Gustavo";

console.log(window.nome);

Resultado:

Gustavo

Com let e const isso não acontece.

Acessando o DOM

O objeto document pertence ao window.

window.document

Por isso:

document.getElementById("titulo");

é equivalente a:

window.document.getElementById("titulo");

Verificando o objeto global

console.log(window);

O navegador exibirá um enorme objeto contendo todas as propriedades e métodos disponíveis.

Casos de uso

O objeto window é utilizado para:

  • Exibir mensagens
  • Abrir e fechar janelas
  • Trabalhar com temporizadores
  • Obter tamanho da tela
  • Controlar scroll
  • Capturar eventos da janela
  • Acessar objetos do navegador

Resumindo

O window é o objeto global do navegador e a base do BOM.

Principais recursos:

RecursoFunção
alert()Exibe mensagem

prompt()Solicita entrada de dados
setTimeout()Executa após um tempo
setInterval()Executa repetidamente

Praticamente tudo que envolve interação entre o JavaScript e o navegador passa, direta ou indiretamente, pelo objeto window.
