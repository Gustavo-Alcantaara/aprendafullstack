BOM - Timing

Timing em JavaScript

Timing é o conjunto de recursos utilizados para executar código após um determinado tempo ou em intervalos regulares.

Esses recursos fazem parte do BOM e são muito utilizados para:

  • relógios
  • cronômetros
  • animações
  • notificações
  • atualizações automáticas
  • atrasos programados

Os principais métodos são:

  • setTimeout()
  • clearTimeout()
  • setInterval()
  • clearInterval()

setTimeout()

Executa uma função uma única vez após um intervalo de tempo.

Sintaxe

setTimeout(funcao,tempo);

O tempo é informado em milissegundos.

1000 ms = 1 segundo
2000 ms = 2 segundos
5000 ms = 5 segundos

Exemplo

setTimeout(() => {
console.log("Executou!");
},3000);

Resultado após 3 segundos:

Executou!

Função tradicional

setTimeout(function() {
console.log("Olá");
},2000);

Retorno do setTimeout

O método retorna um identificador.

const timer = setTimeout(() => {
console.log("Executou");
},3000);

Esse identificador pode ser usado para cancelar a execução.

clearTimeout()

Cancela um timeout antes que ele seja executado.

const timer = setTimeout(() => {
console.log("Executou");
},3000);

clearTimeout(timer);

Resultado:

(nada acontece)

setInterval()

Executa uma função repetidamente em um intervalo de tempo.

Sintaxe

setInterval(funcao,tempo);

Exemplo

setInterval(() => {
console.log("Olá");
},1000);

Resultado:

Olá
Olá
Olá
Olá
...

Executa para sempre até ser interrompido.

clearInterval()

Interrompe um intervalo.

const timer = setInterval(() => {
console.log("Olá");
},1000);

clearInterval(timer);

Exemplo prático: relógio digital

setInterval(() => {

const agora = newDate();

console.log(
agora.toLocaleTimeString()
  );

},1000);

Resultado:

14:30:01
14:30:02
14:30:03
...

Exemplo prático: contador regressivo

let contador = 10;

const timer = setInterval(() => {

console.log(contador);

contador--;

if (contador < 0) {
clearInterval(timer);
  }

},1000);

Resultado:

10
9
8
...
0

Funções anônimas e Arrow Functions

São muito utilizadas com timing.

setTimeout(() => {
console.log("Fim");
},2000);

Ordem de execução

JavaScript não pausa o código enquanto espera.

console.log("Início");

setTimeout(() => {
console.log("Timeout");
},2000);

console.log("Fim");

Resultado:

Início
Fim
Timeout

Isso acontece por causa do Event Loop.

Event Loop (visão geral)

Quando um timer termina:

  1. A função vai para a fila de tarefas.
  1. O Event Loop verifica se a pilha está livre.
  1. A função é executada.
Call Stack
↓
Web APIs
↓
Callback Queue
↓
Event Loop

Esse mecanismo permite que JavaScript seja assíncrono.

Diferença entre setTimeout e setInterval

setTimeout

Executa uma vez.

setTimeout(() => {
console.log("Executou");
},1000);

setInterval

Executa repetidamente.

setInterval(() => {
console.log("Executou");
},1000);

Casos de uso

Os recursos de timing são utilizados para:

  • Relógios
  • Cronômetros
  • Carrosséis de imagens
  • Notificações
  • Animações
  • Atualizações automáticas
  • Jogos
  • Requisições periódicas

Boas práticas

✅ Sempre armazene o identificador retornado.

const timer = setInterval(...);

✅ Utilize clearInterval() quando não precisar mais do timer.

✅ Evite criar muitos intervalos simultâneos.

Resumindo

Timing é o conjunto de funções responsáveis por executar código após um tempo determinado.

Principais métodos:

MétodoFunção
setTimeout()Executa uma vez
clearTimeout()Cancela timeout
setInterval()Executa repetidamente
clearInterval()Cancela intervalo

Exemplo clássico:

setTimeout(() => {
console.log("Olá");
},2000);

Esses recursos são fundamentais para criar aplicações dinâmicas, animações, atualizações automáticas e funcionalidades assíncronas em JavaScript.
