Eventos de Teclado

Em JavaScript, eventos de teclado permitem detectar teclas pressionadas pelo usuário. Eles são muito usados em:

  • formulários
  • atalhos
  • jogos
  • validações
  • sistemas interativos

Os eventos normalmente são adicionados com:

addEventListener()

keydown

Executa quando a tecla é pressionada.

document.addEventListener("keydown",function(evento) {
console.log("Tecla pressionada");
});

Esse é o evento mais usado.

keyup

Executa quando a tecla é solta.

document.addEventListener("keyup",function(evento) {
console.log("Tecla liberada");
});

keypress

Evento antigo usado para caracteres digitáveis.

document.addEventListener("keypress",function(evento) {
console.log("Digitou");
});

⚠️ Hoje ele é considerado obsoleto em muitos casos.

Prefira:

  • keydown
  • keyup

Objeto do evento

Os eventos recebem um objeto com informações da tecla:

document.addEventListener("keydown",function(evento) {
console.log(evento);
});

event.key

Retorna a tecla pressionada:

document.addEventListener("keydown",function(evento) {
console.log(evento.key);
});

Resultado:

a
Enter
Shift

event.code

Retorna o código físico da tecla:

console.log(evento.code);

Exemplo:

KeyA
Space
ArrowUp

Diferença entre key e code

keycode
Valor digitadoTecla física
Pode mudar com idiomaNormalmente fixo

Detectando tecla específica

Enter

document.addEventListener("keydown",function(evento) {
if (evento.key === "Enter") {
console.log("Pressionou Enter");
  }
});

Setas do teclado

if (evento.key === "ArrowUp") {
console.log("Seta para cima");
}

Barra de espaço

if (evento.code === "Space") {
console.log("Espaço");
}

Atalhos de teclado

Ctrl + S

document.addEventListener("keydown",function(evento) {
if (evento.ctrlKey && evento.key==="s") {
evento.preventDefault();

console.log("Salvar");
  }
});

Teclas especiais

PropriedadeUso
ctrlKeyCtrl
shiftKeyShift
altKeyAlt
metaKeyWindows/Command

preventDefault()

Impede ação padrão da tecla:

evento.preventDefault();

Muito usado para:

  • impedir envio de formulário
  • bloquear atalhos
  • evitar scroll

Eventos em inputs

<input type="text" id="campo">
constcampo=document.getElementById("campo");

campo.addEventListener("keydown",function(evento) {
console.log(evento.key);
});

Digitando em tempo real

campo.addEventListener("keyup",function() {
console.log(campo.value);
});

Jogos com teclado

Muito usados em jogos web:

document.addEventListener("keydown",function(evento) {
if (evento.key === "w") {
console.log("Mover para frente");
  }
});

Eventos repetidos

Segurar uma tecla faz o keydown repetir várias vezes.

console.log(evento.repeat);

Resumindo

Eventos de teclado permitem:

  • detectar teclas
  • criar atalhos
  • validar formulários
  • controlar jogos
  • criar interfaces interativas

Eles são essenciais em aplicações modernas feitas com React, editores de texto, jogos e sistemas web.
