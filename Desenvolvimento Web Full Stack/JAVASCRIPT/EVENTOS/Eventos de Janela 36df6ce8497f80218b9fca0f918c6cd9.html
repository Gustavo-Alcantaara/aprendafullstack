Eventos de Janela

Em JavaScript, eventos de janela são eventos relacionados ao navegador ou à própria janela da página. Eles permitem detectar mudanças como:

  • carregamento da página
  • redimensionamento
  • rolagem
  • foco
  • fechamento da aba

Esses eventos normalmente são usados no objeto:

window

load

Executa quando toda a página termina de carregar:

window.addEventListener("load", function() {
console.log("Página carregada");
});

Esse evento espera:

  • HTML
  • CSS
  • imagens
  • scripts

DOMContentLoaded

Executa quando o HTML termina de carregar.

document.addEventListener("DOMContentLoaded", function() {
console.log("HTML carregado");
});

⚠️ Não espera imagens nem arquivos externos.

resize

Executa quando a janela muda de tamanho:

window.addEventListener("resize",function() {
console.log(window.innerWidth);
});

Pegando tamanho da tela

window.innerWidth
window.innerHeight

scroll

Executa durante a rolagem da página:

window.addEventListener("scroll",function() {
console.log(window.scrollY);
});

Posição do scroll

window.scrollY

Rolando automaticamente

window.scrollTo(0,500);

Scroll suave

window.scrollTo({
  top:500,
  behavior:"smooth"
});

focus

Executa quando a janela recebe foco:

window.addEventListener("focus",function() {
console.log("Janela ativa");
});

blur

Executa quando a janela perde foco:

window.addEventListener("blur",function() {
console.log("Janela perdeu foco");
});

Muito usado para:

  • pausar jogos
  • detectar troca de aba

beforeunload

Executa antes da página ser fechada:

window.addEventListener("beforeunload",function(evento) {
evento.preventDefault();
});

unload

Executa ao sair da página.

window.addEventListener("unload",function() {
console.log("Saiu");
});

⚠️ Hoje possui limitações em navegadores modernos.

online

Detecta conexão com internet:

window.addEventListener("online",function() {
console.log("Internet conectada");
});

offline

Detecta perda de conexão:

window.addEventListener("offline",function() {
console.log("Sem internet");
});

hashchange

Executa quando a URL muda após #

window.addEventListener("hashchange",function() {
console.log(location.hash);
});

Exemplo:

site.com/#home

Temporizadores da janela

O objeto window também possui:

setTimeout

setTimeout(() => {
console.log("Executou");
},1000);

setInterval

setInterval(() => {
console.log("Rodando");
},1000);

Eventos muito usados em interfaces

EventoUso
loadInicialização
resizeResponsividade
scrollEfeitos e animações

offlineDetectar internet

Performance

Eventos como:

  • scroll
  • mousemove
  • resize

disparam muitas vezes por segundo.

Por isso muitas aplicações usam técnicas como:

  • debounce
  • throttle

Resumindo

Eventos de janela permitem:

  • controlar carregamento da página
  • detectar scroll e tamanho da tela
  • responder a foco e conexão
  • criar experiências dinâmicas

Eles são fundamentais em aplicações modernas feitas com React, dashboards, jogos e interfaces web responsivas.
