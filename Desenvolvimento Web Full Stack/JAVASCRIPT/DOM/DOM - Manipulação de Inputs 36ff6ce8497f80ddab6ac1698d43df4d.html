DOM - Manipulação de Inputs

Em DOM, a manipulação de valores de inputs permite capturar, alterar e validar dados digitados pelo usuário em campos de formulário usando JavaScript.

Isso é muito usado em:

  • login
  • cadastro
  • pesquisas
  • formulários
  • validações
  • sistemas interativos

Criando um input

HTML

<input type="text"id="nome">

Selecionando o input

const nome=
document.getElementById("nome");

Pegando o valor do input

Usamos:

.value

Exemplo:

console.log(nome.value);

Exemplo completo

<input type="text"id="nome">
<button id="botao">Mostrar</button>
const nome=
document.getElementById("nome");

const botao=
document.getElementById("botao");

botao.addEventListener("click",function() {
console.log(nome.value);
});

Alterando o valor do input

nome.value="Gustavo";

Limpando input

nome.value="";

Capturando enquanto digita

Evento input

nome.addEventListener("input",function() {
console.log(nome.value);
});

Executa a cada alteração.

Evento change

Executa quando o usuário termina a edição e sai do campo.

nome.addEventListener("change",function() {
console.log(nome.value);
});

Diferença importante

EventoQuando acontece
inputEnquanto digita
changeAo finalizar alteração

Validando campos vazios

if (nome.value==="") {
console.log("Campo vazio");
}

Removendo espaços

Muito usado com:

nome.value.trim()

Exemplo:

if (nome.value.trim()==="") {
console.log("Digite algo");
}

Convertendo valores

Inputs sempre retornam strings.

let idade = Number(input.value);

Trabalhando com números

<input type="number"id="idade">
const idade=
document.getElementById("idade");

console.log(Number(idade.value));

Placeholder

Texto de dica:

<input
type="text"
placeholder="Digite seu nome"
>

Desabilitando inputs

nome.disabled = true;

Habilitando novamente

nome.disabled = false;

Focando automaticamente

nome.focus();

Tirando foco

nome.blur();

Selecionando texto

nome.select();

Trabalhando com maxlength

HTML

<input type="text" maxlength="10">

Verificando tamanho

console.log(nome.value.length);

Transformando texto

nome.value =
nome.value.toUpperCase();

Máscaras simples

Exemplo CPF:

input.addEventListener("input",function() {
console.log(input.value);
});

Inputs em tempo real

Muito usados em:

  • busca instantânea
  • autocomplete
  • filtros
  • validação dinâmica

Obtendo múltiplos inputs

const inputs=
document.querySelectorAll("input");

Percorrendo inputs

inputs.forEach(function(input) {
console.log(input.value);
});

Segurança importante

Nunca confie apenas na validação frontend.

O backend também deve validar os dados.

Resumindo

Manipular valores de inputs permite:

  • capturar dados do usuário
  • validar informações
  • alterar valores dinamicamente
  • criar formulários interativos
  • melhorar experiência do usuário

Esse conceito é essencial em aplicações modernas feitas com React, sistemas web e interfaces interativas.
