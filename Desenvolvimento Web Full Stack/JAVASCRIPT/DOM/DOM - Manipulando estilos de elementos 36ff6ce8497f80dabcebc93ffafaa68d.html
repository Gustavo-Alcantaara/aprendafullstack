DOM - Manipulando estilos de elementos

Em DOM, a manipulação de estilos permite alterar a aparência dos elementos HTML dinamicamente usando JavaScript.

Com isso é possível:

  • mudar cores
  • alterar tamanhos
  • esconder elementos
  • criar animações
  • responder a eventos
  • construir interfaces interativas

Selecionando um elemento

HTML

<h1 id="titulo">Olá</h1>

JavaScript

const titulo=
document.getElementById("titulo");

Alterando estilos com .style

titulo.style.color = "red";

Alterando tamanho

titulo.style.fontSize = "40px";

⚠️ Valores precisam ser strings.

Alterando fundo

titulo.style.backgroundColor = "black";

CSS em camelCase

No JavaScript, propriedades CSS usam:

Exemplos:

CSSJavaScript
background-colorbackgroundColor
font-sizefontSize

Alterando múltiplos estilos

titulo.style.color = "white";
titulo.style.backgroundColor = "blue";
titulo.style.padding = "20px";

Escondendo elementos

titulo.style.display = "none";

Mostrando novamente

titulo.style.display = "block";

Visibilidade

titulo.style.visibility = "hidden";

Diferença:

  • display: none remove do layout
  • visibility: hidden apenas esconde

Alterando transparência

titulo.style.opacity = "0.5";

Trabalhando com classes

O mais recomendado geralmente é manipular classes CSS.

Adicionar classe

titulo.classList.add("ativo");

Remover classe

titulo.classList.remove("ativo");

Alternar classe

titulo.classList.toggle("ativo");

Verificar classe

titulo.classList.contains("ativo");

CSS

.ativo {
  color:white;
  background:blue;
}

Por que usar classes?

Melhor:

  • organização
  • manutenção
  • reutilização
  • performance

Pegando estilos atuais

console.log(titulo.style.color);

⚠️ Só pega estilos inline.

Pegando estilos reais

const estilo=
getComputedStyle(titulo);

console.log(estilo.color);

Eventos + estilos

Muito comum:

botao.addEventListener("click",function() {
titulo.style.color="green";
});

Criando efeitos

Hover manual

titulo.addEventListener("mouseenter",function() {
titulo.style.color="red";
});

titulo.addEventListener("mouseleave",function() {
titulo.style.color="black";
});

Transições

CSS:

#titulo {
  transition:0.3s;
}

JavaScript:

titulo.style.transform = "scale(1.2)";

Trabalhando com dimensões

Largura

titulo.style.width = "300px";

Altura

titulo.style.height = "100px";

Manipulando posição

titulo.style.position = "absolute";
titulo.style.left = "100px";

Tema escuro simples

document.body.style.backgroundColor = "black";
document.body.style.color = "white";

Alterando CSS Variables

document.documentElement.style.setProperty(
"--cor-primaria",
"blue"
);

Performance

Alterar estilos muitas vezes rapidamente pode causar:

  • reflows
  • repaints

Por isso frameworks como React usam otimizações.

Boas práticas

  • Prefira classes ao invés de muitos estilos inline
  • Evite manipular estilos repetidamente
  • Use CSS para aparência
  • Use JavaScript para comportamento

Resumindo

Manipulação de estilos permite:

  • alterar aparência dinamicamente
  • criar animações
  • esconder e mostrar elementos
  • criar interfaces interativas
  • responder a eventos do usuário

Esse conceito é fundamental no desenvolvimento frontend moderno e muito usado em React, Vue.js e aplicações web modernas.
