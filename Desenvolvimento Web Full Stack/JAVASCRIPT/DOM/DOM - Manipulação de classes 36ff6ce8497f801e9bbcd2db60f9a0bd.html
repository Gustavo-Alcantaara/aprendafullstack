DOM - Manipulação de classes

Em DOM, a manipulação de classes permite adicionar, remover e controlar classes CSS dinamicamente usando JavaScript.

Isso é extremamente importante para:

  • mudar estilos
  • criar animações
  • alternar temas
  • abrir menus
  • mostrar/modificar elementos
  • criar interfaces interativas

O que são classes?

Classes são usadas no CSS para estilizar elementos.

HTML

<h1 class="titulo">Olá</h1>

CSS

.titulo {
  color:blue;
}

Selecionando elemento

const titulo=
document.querySelector(".titulo");

classList

O JavaScript manipula classes usando:

elemento.classList

add()

Adiciona uma classe:

titulo.classList.add("ativo");

Exemplo completo

CSS

.ativo {
  color:white;
  background:black;
}

JavaScript

titulo.classList.add("ativo");

remove()

Remove uma classe:

titulo.classList.remove("ativo");

toggle()

Alterna classe:

  • adiciona se não existir
  • remove se existir
titulo.classList.toggle("ativo");

Muito usado em:

  • menus
  • dark mode
  • modais

Exemplo de menu

menu.classList.toggle("aberto");

contains()

Verifica se a classe existe:

console.log(
titulo.classList.contains("ativo")
);

Resultado:

true

replace()

Substitui uma classe:

titulo.classList.replace(
"ativo",
"inativo"
);

Trabalhando com múltiplas classes

titulo.classList.add(
"ativo",
"grande",
"destaque"
);

Removendo várias

titulo.classList.remove(
"ativo",
"grande"
);

Pegando todas as classes

console.log(titulo.classList);

className

Forma antiga:

titulo.className="ativo";

⚠️ Isso substitui todas as classes existentes.

Diferença importante

MétodoComportamento
classNameSubstitui tudo
classListManipula individualmente

Hoje preferimos:

classList

Eventos + classes

Muito comum:

botao.addEventListener("click",function() {
titulo.classList.toggle("ativo");
});

Dark mode simples

CSS

.dark {
  background:black;
  color:white;
}

JavaScript

document.body.classList.toggle("dark");

Criando animações

CSS:

.animar {
  transform:scale(1.2);
}

JavaScript:

elemento.classList.add("animar");

Mostrar e esconder elementos

CSS

.oculto {
  display:none;
}

JavaScript

elemento.classList.toggle("oculto");

Boas práticas

✅ Prefira classes ao invés de muitos estilos inline

✅ Use CSS para aparência

✅ Use JavaScript para lógica e interação

✅ Organize nomes de classes

Convenções comuns

BEM

Exemplo:

card__title
menu--active

Performance

Manipular classes geralmente é mais performático do que alterar vários estilos diretamente.

Resumindo

Manipulação de classes permite:

  • controlar estilos dinamicamente
  • criar animações
  • alternar estados visuais
  • organizar interfaces
  • melhorar manutenção do código

Esse conceito é fundamental em aplicações modernas feitas com React, Vue.js e praticamente qualquer frontend moderno.
