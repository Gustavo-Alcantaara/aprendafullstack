Criação de Elementos

Criação de Elementos em JavaScript

A criação de elementos é uma das funcionalidades mais importantes do DOM (Document Object Model). Ela permite adicionar novos elementos HTML à página de forma dinâmica, sem precisar editar o HTML original.

Com JavaScript, podemos criar:

  • <div>
  • <p>
  • <img>
  • <button>
  • <li>
  • qualquer outra tag HTML

Por que criar elementos dinamicamente?

Imagine uma lista de tarefas, um chat ou uma tabela de produtos. Os dados podem vir de uma API ou serem digitados pelo usuário, então os elementos precisam ser criados durante a execução da página.

Exemplo:

<ul id="lista"></ul>

Adicionar itens pelo JavaScript:

const lista = document.getElementById("lista");

const item = document.createElement("li");

item.textContent = "Estudar JavaScript";

lista.appendChild(item);

Resultado:

<ul id="lista">
    <li>Estudar JavaScript</li>
</ul>

createElement()

O método principal para criar elementos é:

document.createElement()

Sintaxe:

const elemento = document.createElement("tag");

Exemplo:

const paragrafo = document.createElement("p");

Nesse momento o elemento existe apenas na memória, ainda não aparece na página.

Adicionando conteúdo

textContent

Define o texto do elemento.

const titulo = document.createElement("h1");

titulo.textContent = "Meu Site";

Resultado:

<h1>Meu Site</h1>

innerHTML

Permite inserir HTML.

const div = document.createElement("div");

div.innerHTML = "<strong>Olá Mundo</strong>";

Resultado:

<div>
    <strong>Olá Mundo</strong>
</div>

⚠️ Deve ser usado com cuidado para evitar problemas de segurança.

Inserindo na página

Criar um elemento não é suficiente. É necessário adicioná-lo ao DOM.

appendChild()

Adiciona um elemento como último filho.

document.body.appendChild(titulo);

Resultado:

<body>
    <h1>Meu Site</h1>
</body>

Exemplo completo

const titulo = document.createElement("h1");

titulo.textContent = "Bem-vindo";

document.body.appendChild(titulo);

Criando elementos com atributos

setAttribute()

const imagem = document.createElement("img");

imagem.setAttribute(
  "src",
  "foto.jpg"
);

imagem.setAttribute(
  "alt",
  "Minha foto"
);

Resultado:

<img src="foto.jpg" alt="Minha foto">

Manipulando propriedades diretamente

Forma mais comum:

const imagem = document.createElement("img");

imagem.src = "foto.jpg";
imagem.alt = "Minha foto";

Adicionando classes

const card = document.createElement("div");

card.className = "card";

Ou:

card.classList.add("card");

Adicionando estilos

const caixa = document.createElement("div");

caixa.style.backgroundColor = "blue";
caixa.style.padding = "20px";

Criando vários elementos

for (let i = 1; i <= 5; i++) {

  const item = document.createElement("li");

  item.textContent = `Item ${i}`;

  document
    .getElementById("lista")
    .appendChild(item);

}

Resultado:

<li>Item 1</li>
<li>Item 2</li>
<li>Item 3</li>
<li>Item 4</li>
<li>Item 5</li>

Criando estruturas complexas

const card = document.createElement("div");

const titulo = document.createElement("h2");

const descricao = document.createElement("p");

titulo.textContent = "Notebook";

descricao.textContent =
  "Notebook Gamer";

card.appendChild(titulo);
card.appendChild(descricao);

document.body.appendChild(card);

Resultado:

<div>
    <h2>Notebook</h2>
    <p>Notebook Gamer</p>
</div>

Métodos modernos de inserção

append()

Pode adicionar texto e múltiplos elementos.

container.append(elemento);

prepend()

Adiciona no início.

container.prepend(elemento);

before()

Insere antes do elemento.

elemento.before(novoElemento);

after()

Insere depois do elemento.

elemento.after(novoElemento);

Removendo elementos

elemento.remove();

Exemplo:

const titulo =
  document.querySelector("h1");

titulo.remove();

Exemplo prático: botão dinâmico

const botao =
  document.createElement("button");

botao.textContent = "Clique Aqui";

document.body.appendChild(botao);

Exemplo prático: lista de tarefas

const tarefa =
  document.createElement("li");

tarefa.textContent =
  "Estudar DOM";

document
  .getElementById("tarefas")
  .appendChild(tarefa);

Boas práticas

✅ Utilize createElement() para criar elementos.

✅ Utilize textContent para inserir textos.

✅ Prefira classList para manipular classes.

✅ Evite usar innerHTML quando não for necessário.

Resumindo

A criação de elementos permite gerar conteúdo HTML dinamicamente através do JavaScript.

Principais métodos:

MétodoFunção
createElement()Cria elemento
appendChild()Adiciona ao DOM
append()Adiciona elementos
prepend()Adiciona no início
before()Insere antes
after()Insere depois
remove()Remove elemento

Exemplo clássico:

const p = document.createElement("p");

p.textContent = "Olá Mundo";

document.body.appendChild(p);

A criação dinâmica de elementos é a base para construir interfaces interativas, listas, tabelas, cards, menus e praticamente qualquer aplicação web moderna feita com JavaScript.
