Manipulação de Datas

Em JavaScript, a manipulação de datas é feita principalmente através do objeto:

Com ele é possível:

  • criar datas
  • pegar dia, mês e ano
  • trabalhar com horários
  • calcular diferenças de tempo
  • formatar datas

Criando datas

Data atual

const data = newDate();

console.log(data);

Criando data específica

const data = newDate(2026,4,27);

⚠️ Os meses começam do zero:

NúmeroMês
0Janeiro
1Fevereiro
4Maio

Criando por texto

const data = newDate("2026-05-27");

Pegando informações da data

getFullYear()

Retorna o ano:

console.log(data.getFullYear());

getMonth()

Retorna o mês:

console.log(data.getMonth());

⚠️ Janeiro = 0

getDate()

Retorna o dia do mês:

console.log(data.getDate());

getDay()

Retorna o dia da semana:

ValorDia
0Domingo
1Segunda
console.log(data.getDay());

Trabalhando com horas

Hora

console.log(data.getHours());

Minutos

console.log(data.getMinutes());

Segundos

console.log(data.getSeconds());

Alterando datas

Alterar ano

data.setFullYear(2030);

Alterar mês

data.setMonth(11);

Alterar dia

data.setDate(15);

Timestamp

Datas internamente funcionam como milissegundos desde:

Pegando timestamp

console.log(Date.now());

Diferença entre datas

const inicio = newDate();
const fim = newDate();

const diferenca = fim - inicio;

console.log(diferenca);

Resultado em milissegundos.

Convertendo milissegundos

Segundos

milissegundos/1000

Minutos

milissegundos/1000/60

Formatando datas

toDateString()

console.log(data.toDateString());

toLocaleDateString()

Formato regional:

console.log(data.toLocaleDateString("pt-BR"));

toLocaleTimeString()

console.log(data.toLocaleTimeString("pt-BR"));

Formatando completo

console.log(
data.toLocaleString("pt-BR")
);

Comparando datas

const d1 = newDate("2026-01-01");
const d2 = newDate("2027-01-01");

console.log(d1 < d2);

Resultado:

true

Cuidado com fusos horários

Datas podem variar dependendo do:

  • país
  • navegador
  • timezone

Por isso muitas aplicações usam bibliotecas como:

  • Day.js
  • date-fns

UTC

JavaScript também possui métodos UTC:

data.getUTCFullYear()

ISO Date

Formato padrão muito usado em APIs:

console.log(data.toISOString());

Resultado:

2026-05-27T00:00:00.000Z

Resumindo

As funções nativas de datas permitem:

  • criar datas
  • formatar horários
  • comparar períodos
  • calcular diferenças
  • trabalhar com calendários e timestamps

Manipulação de datas é essencial em sistemas financeiros, agendas, autenticação, APIs e aplicações modernas feitas com React e Node.js.
