Manipulação de Strings

Em JavaScript, existem várias funções nativas para manipulação de strings. Elas permitem alterar, buscar, dividir e formatar textos de forma prática.

O que é uma string?

String é um tipo de dado usado para textos:

let nome="Gustavo";

length

Retorna a quantidade de caracteres:

let texto="JavaScript";

console.log(texto.length);

Resultado:

10

toUpperCase()

Converte para maiúsculo:

let texto="javascript";

console.log(texto.toUpperCase());

Resultado:

JAVASCRIPT

toLowerCase()

Converte para minúsculo:

let texto="JAVASCRIPT";

console.log(texto.toLowerCase());

trim()

Remove espaços no início e fim:

let texto="   Olá   ";

console.log(texto.trim());

includes()

Verifica se existe determinado texto:

let frase="Olá mundo";

console.log(frase.includes("mundo"));

Resultado:

true

startsWith()

Verifica se começa com determinado texto:

console.log("JavaScript".startsWith("Java"));

endsWith()

Verifica se termina com determinado texto:

console.log("arquivo.pdf".endsWith(".pdf"));

replace()

Substitui parte do texto:

let frase="Olá mundo";

console.log(frase.replace("mundo","Gustavo"));

Resultado:

Olá Gustavo

replaceAll()

Substitui todas as ocorrências:

let texto="a-b-c";

console.log(texto.replaceAll("-","/"));

slice()

Recorta parte da string:

let texto="JavaScript";

console.log(texto.slice(0,4));

Resultado:

Java

substring()

Parecido com slice():

console.log("JavaScript".substring(0,4));

split()

Divide a string em array:

let frase="maçã,banana,uva";

console.log(frase.split(","));

Resultado:

["maçã", "banana", "uva"]

join()

Usado em arrays para unir textos:

let nomes= ["Gustavo","Carlos"];

console.log(nomes.join(" - "));

Resultado:

Gustavo - Carlos

charAt()

Retorna caractere pela posição:

let texto="JavaScript";

console.log(texto.charAt(0));

Resultado:

J

indexOf()

Retorna a posição de um texto:

let texto="JavaScript";

console.log(texto.indexOf("Script"));

lastIndexOf()

Busca da direita para esquerda:

let texto="banana";

console.log(texto.lastIndexOf("a"));

repeat()

Repete o texto:

console.log("Oi ".repeat(3));

Resultado:

Oi Oi Oi

Template Strings

Forma moderna de manipular textos:

let nome="Gustavo";

console.log(`Olá,${nome}`);

Escape de caracteres

Permite usar caracteres especiais:

console.log("Ela disse:\"Olá\"");

Strings são imutáveis

Métodos não alteram a string original:

let texto="java";

texto.toUpperCase();

console.log(texto);

Resultado:

java

É necessário salvar o retorno:

texto = texto.toUpperCase();

Resumindo

As funções nativas de string permitem:

  • buscar textos
  • validar conteúdos
  • formatar dados
  • dividir informações
  • substituir palavras
  • manipular entradas de usuário

Elas são extremamente importantes em aplicações web, APIs e sistemas modernos feitos com Node.js e React.
