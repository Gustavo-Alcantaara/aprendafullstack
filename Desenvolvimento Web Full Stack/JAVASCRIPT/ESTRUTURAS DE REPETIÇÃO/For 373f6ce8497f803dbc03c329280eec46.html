For

Estrutura for em JavaScript

A estrutura de repetição for é uma das mais utilizadas em JavaScript. Ela é ideal quando sabemos previamente quantas vezes um bloco de código deve ser executado.

Sua principal vantagem é reunir em uma única linha:

  • a inicialização da variável de controle;
  • a condição de repetição;
  • o incremento ou decremento.

Sintaxe

for (inicialização;condição;incremento) {
// código a ser repetido
}

Exemplo:

for (let i = 1; i <= 5; i++) {
console.log(i);
}

Resultado:

1
2
3
4
5

Entendendo cada parte

for (let i = 1; i <= 5; i++)

Inicialização

let i = 1

Executa apenas uma vez, no início do loop.

Condição

i <= 5

Enquanto for verdadeira, o loop continua.

Incremento

i++

Executa ao final de cada repetição.

Percorrendo Arrays

Uma das utilizações mais comuns.

const frutas = ["Maçã","Banana","Uva"];

for (let i = 0; i < frutas.length; i++) {
console.log(frutas[i]);
}

Resultado:

Maçã
Banana
Uva

Utilizando break

Interrompe o loop imediatamente.

for (let i = 1; i <= 10; i++) {

if (i === 5) {
break;
  }

console.log(i);
}

Resultado:

1
2
3
4

Utilizando continue

Pula a iteração atual.

for (let i = 1; i <= 5; i++) {

if (i === 3) {
continue;
  }

console.log(i);
}

Resultado:

1
2
4
5

Loops aninhados

Um for dentro de outro.

for (let linha = 1; linha <= 3; linha++) {

for (let coluna = 1; coluna <= 3; coluna++) {
console.log(linha,coluna);
  }

}

Resultado:

1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

Muito usado em:

  • matrizes
  • tabelas
  • jogos
  • algoritmos

Variável de escopo

Quando usamos let:

for (let i = 0; i < 5; i++) {
console.log(i);
}

A variável i existe apenas dentro do loop.

console.log(i);

Isso gerará erro.

Quando usar for?

Use for quando:

✅ Você sabe quantas repetições serão necessárias.

✅ Precisa percorrer arrays utilizando índices.

✅ Precisa controlar precisamente o incremento ou decremento.

Comparação com outras estruturas

EstruturaMelhor uso
forQuantidade conhecida de repetições
whileRepetição baseada em condição
do...whileExecutar pelo menos uma vez
for...ofPercorrer elementos de arrays
forEach()Percorrer arrays de forma moderna

Resumindo

A estrutura for é a forma mais comum de criar repetições em JavaScript.

Principais características:

  • Possui inicialização, condição e incremento.
  • É ideal para contagens e percorrer arrays.
  • Permite usar break e continue.
  • Pode ser aninhada para trabalhar com matrizes e tabelas.

É uma das estruturas mais importantes da linguagem e aparece em praticamente todo projeto desenvolvido com Node.js ou React.
