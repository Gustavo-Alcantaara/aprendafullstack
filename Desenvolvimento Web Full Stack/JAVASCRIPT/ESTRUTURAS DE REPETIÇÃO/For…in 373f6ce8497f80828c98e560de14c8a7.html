For…in

Estrutura for...in em JavaScript

A estrutura for...in é utilizada para percorrer as propriedades (chaves) de um objeto.

Ela percorre os nomes das propriedades, e não os valores diretamente.

Sintaxe

for (const chave in objeto) {
// código
}

Exemplo básico

const pessoa = {
  nome:"Gustavo",
  idade:21,
  cidade:"Fortaleza"
};

for (const chave in pessoa) {
console.log(chave);
}

Resultado:

nome
idade
cidade

Observe que o for...in retorna as chaves (propriedades) do objeto.

Obtendo os valores

Para acessar os valores, utilizamos a chave:

const pessoa = {
  nome:"Gustavo",
  idade:21,
  cidade:"Fortaleza"
};

for (const chave in pessoa) {
console.log(pessoa[chave]);
}

Resultado:

Gustavo
21
Fortaleza

Exibindo chave e valor

const pessoa = {
  nome:"Gustavo",
  idade:21
};

for (const chave in pessoa) {
console.log(chave +": "+ pessoa[chave]);
}

Resultado:

nome: Gustavo
idade: 21

for...in em Arrays

Também funciona com arrays, mas normalmente não é a melhor opção.

const frutas = ["Maçã","Banana","Uva"];

for (const indice in frutas) {
console.log(indice);
}

Resultado:

0
1
2

O que é retornado são os índices.

Para acessar os valores:

for (const indice in frutas) {
console.log(frutas[indice]);
}

Resultado:

Maçã
Banana
Uva

Diferença entre for...in e for...of

for...in

Percorre chaves ou índices.

for (const indice in frutas) {
console.log(indice);
}

Resultado:

0
1
2

for...of

Percorre os valores diretamente.

for (const fruta of frutas) {
console.log(fruta);
}

Resultado:

Maçã
Banana
Uva

Quando usar for...in?

É recomendado principalmente para objetos.

const carro = {
  marca:"Toyota",
  modelo:"Corolla",
  ano:2025
};

for (const propriedade in carro) {
console.log(propriedade);
}

Verificando propriedades

Pode ser combinado com:

Object.hasOwn()

Exemplo:

for (const chave in objeto) {

if (Object.hasOwn(objeto,chave)) {
console.log(chave);
  }

}

Isso evita percorrer propriedades herdadas da cadeia de protótipos.

Casos de uso

O for...in é útil para:

  • Percorrer objetos
  • Listar configurações
  • Exibir propriedades de usuários
  • Trabalhar com objetos JSON
  • Criar relatórios dinâmicos

Resumindo

A estrutura for...in percorre as propriedades de um objeto.

Características principais:

  • Retorna chaves (propriedades).
  • Pode ser usada em arrays, mas não é a opção mais indicada.
  • É ideal para objetos.
  • Permite acessar valores usando objeto[chave].

Exemplo clássico:

for (const chave in objeto) {
console.log(chave);
console.log(objeto[chave]);
}

No dia a dia, o for...in é muito utilizado para percorrer objetos e dados recebidos de APIs em aplicações feitas com Node.js e React.
