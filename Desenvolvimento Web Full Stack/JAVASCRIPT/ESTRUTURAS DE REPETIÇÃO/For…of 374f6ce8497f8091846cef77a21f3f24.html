For…of

Estrutura for...of em JavaScript

A estrutura for...of é utilizada para percorrer os valores de objetos iteráveis, como arrays, strings, mapas e conjuntos.

Ela foi introduzida no ES6 e é considerada uma forma mais simples e legível de percorrer coleções.

Sintaxe

for (const elemento of colecao) {
// código
}

A cada repetição, a variável recebe o valor atual da coleção.

Exemplo com Array

const frutas = ["Maçã","Banana","Uva"];

for (const fruta of frutas) {
console.log(fruta);
}

Resultado:

Maçã
Banana
Uva

Observe que o for...of retorna os valores diretamente.

Comparação com o for

For tradicional

const frutas = ["Maçã","Banana","Uva"];

for (let i = 0; i < frutas.length; i++) {
console.log(frutas[i]);
}

For...of

for (const fruta of frutas) {
console.log(fruta);
}

O for...of é mais simples quando só precisamos dos valores.

Exemplo com String

Strings também são iteráveis.

const nome = "Gustavo";

for (const letra of nome) {
console.log(letra);
}

Resultado:

G
u
s
t
a
v
o

Utilizando break

const numeros = [10,20,30,40];

for (const numero of numeros) {

if (numero === 30) {
break;
  }

console.log(numero);
}

Resultado:

10
20

Utilizando continue

const numeros = [10,20,30,40];

for (const numero of numeros) {

if (numero === 30) {
continue;
  }

console.log(numero);
}

Resultado:

10
20
40

Percorrendo Arrays de Objetos

Muito comum em aplicações reais.

const usuarios = [
  { nome:"João" },
  { nome:"Maria" },
  { nome:"Carlos" }
];

for (const usuario of usuarios) {
console.log(usuario.nome);
}

Resultado:

João
Maria
Carlos

Obtendo índice e valor

O for...of retorna apenas os valores.

Se precisar do índice:

const frutas = ["Maçã","Banana","Uva"];

for (const [indice,fruta]of frutas.entries()) {
console.log(indice,fruta);
}

Resultado:

0 Maçã
1 Banana
2 Uva

Diferença entre for...in e for...of

for...in

Percorre chaves ou índices.

const frutas = ["Maçã","Banana","Uva"];

for (const indice in frutas) {
console.log(indice);
}

Resultado:

0
1
2

for...of

Percorre valores.

for (const fruta of frutas) {
console.log(fruta);
}

Resultado:

Maçã
Banana
Uva

Quando usar for...of?

Use quando:

✅ Precisar percorrer os valores de um array.

✅ Trabalhar com strings.

✅ Trabalhar com listas de objetos.

✅ Precisar usar break ou continue.

Quando não usar?

Evite quando precisar:

❌ Das propriedades de um objeto → use for...in.

❌ Transformar arrays → use map().

❌ Filtrar elementos → use filter().

Comparação rápida

EstruturaPercorre
forÍndices e valores
for...inChaves ou índices
for...ofValores
forEach()Valores via callback

Vantagens do for...of

  • Código mais limpo.
  • Fácil leitura.
  • Funciona com arrays e strings.
  • Permite usar break e continue.
  • Não exige controle manual de índices.

Resumindo

O for...of é uma estrutura de repetição usada para percorrer os valores de coleções iteráveis.

Exemplo clássico:

for (const item of colecao) {
console.log(item);
}

É uma das formas mais utilizadas atualmente para percorrer arrays em aplicações desenvolvidas com React, Node.js e JavaScript moderno.
