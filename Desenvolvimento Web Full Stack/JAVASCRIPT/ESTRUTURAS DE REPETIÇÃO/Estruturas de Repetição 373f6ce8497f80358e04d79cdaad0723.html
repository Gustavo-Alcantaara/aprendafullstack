Estruturas de Repetição

Estruturas de Repetição em JavaScript

As estruturas de repetição (ou loops) são mecanismos que permitem executar um bloco de código várias vezes de forma automática, evitando a repetição manual de instruções.

Elas são utilizadas quando precisamos percorrer coleções de dados, realizar cálculos repetitivos, processar arrays, validar informações ou executar tarefas enquanto uma determinada condição for verdadeira.

Principais estruturas de repetição

while

Executa o bloco de código enquanto uma condição for verdadeira.

let contador = 1;

while (contador <= 5) {
console.log(contador);
contador++;
}

do...while

Semelhante ao while, mas garante que o código seja executado pelo menos uma vez.

let contador = 1;

do {
console.log(contador);
contador++;
}while (contador <= 5);

for

É a estrutura mais utilizada quando sabemos quantas repetições serão necessárias.

for (let i = 1; i <= 5; i++) {
console.log(i);
}

O for possui três partes:

  • Inicialização
  • Condição
  • Incremento/Decremento

for...of

Utilizado para percorrer elementos de arrays, strings e outros objetos iteráveis.

const frutas = ["Maçã","Banana","Uva"];

for (const fruta of frutas) {
console.log(fruta);
}

for...in

Percorre as propriedades de um objeto.

const pessoa = {
  nome:"Gustavo",
  idade:21
};

for (const chave in pessoa) {
console.log(chave);
}

forEach()

Método específico para arrays.

const numeros = [1,2,3];

numeros.forEach(numero => {
console.log(numero);
});

Controle de repetição

break

Interrompe completamente o loop.

for (let i = 1; i <= 10; i++) {
if (i === 5) {
break;
  }

console.log(i);
}

continue

Pula a iteração atual e continua para a próxima.

for (let i = 1; i <= 5; i++) {
if (i === 3) {
continue;
  }

console.log(i);
}

Cuidados

É importante que a condição de parada seja atingida. Caso contrário, ocorre um loop infinito.

let contador = 1;

while (contador > 0) {
console.log(contador);
}

Esse código nunca termina.

Resumindo

As estruturas de repetição permitem executar um conjunto de instruções várias vezes de forma controlada e eficiente. Os loops mais utilizados em JavaScript são:

  • for → quando sabemos o número de repetições.
  • while → quando a repetição depende de uma condição.
  • do...while → quando o código precisa executar pelo menos uma vez.
  • for...of → para percorrer arrays e iteráveis.
  • forEach() → para percorrer arrays de forma moderna.

Elas são fundamentais para trabalhar com arrays, objetos, processamento de dados, algoritmos e praticamente qualquer aplicação desenvolvida em Node.js ou React.
