Foreach()

Método forEach() em JavaScript

O forEach() é um método nativo dos arrays que permite percorrer todos os elementos de um array de forma simples e moderna.

Ele executa uma função para cada elemento do array, na ordem em que eles aparecem.

Sintaxe

array.forEach(function(elemento) {
// código
});

Exemplo:

const frutas = ["Maçã","Banana","Uva"];

frutas.forEach(function(fruta) {
console.log(fruta);
});

Resultado:

Maçã
Banana
Uva

Parâmetros da função callback

O forEach() pode receber até três parâmetros:

array.forEach(function(valor,indice,array) {
// código
});

Valor

Representa o elemento atual.

const frutas = ["Maçã","Banana","Uva"];

frutas.forEach(function(fruta) {
console.log(fruta);
});

Índice

Representa a posição do elemento.

const frutas = ["Maçã","Banana","Uva"];

frutas.forEach(function(fruta,indice) {
console.log(indice,fruta);
});

Resultado:

0 Maçã
1 Banana
2 Uva

Array

Representa o array completo.

frutas.forEach(function(fruta,indice,array) {
console.log(array);
});

Utilizando Arrow Functions

Forma moderna:

const frutas = ["Maçã","Banana","Uva"];

frutas.forEach(fruta => {
console.log(fruta);
});

Se houver apenas uma instrução:

frutas.forEach(fruta => console.log(fruta));

Somando valores

const numeros = [10,20,30];

let soma = 0;

numeros.forEach(numero => {
soma += numero;
});

console.log(soma);

Resultado:

60

Trabalhando com objetos

const usuarios = [
  { nome:"João" },
  { nome:"Maria" },
  { nome:"Carlos" }
];

usuarios.forEach(usuario => {
console.log(usuario.nome);
});

Resultado:

João
Maria
Carlos

Modificando elementos

const numeros = [1,2,3];

numeros.forEach((numero,indice,array) => {
array[indice] = numero * 2;
});

console.log(numeros);

Resultado:

[2,4,6]

⚠️ Embora funcione, geralmente é melhor usar map() quando o objetivo é transformar valores.

Diferença entre for e forEach()

For

for (let i = 0; i < frutas.length; i++) {
console.log(frutas[i]);
}

forEach

frutas.forEach(fruta => {
console.log(fruta);
});

O forEach() costuma ser mais legível e simples.

Limitação importante

O forEach() não pode ser interrompido com break.

Isso gera erro:

frutas.forEach(fruta => {

if (fruta === "Banana") {
break;
  }

});

❌ Não funciona.

Se precisar interromper o loop, prefira:

for
while
for...of

forEach() retorna valor?

Não.

const resultado = frutas.forEach(fruta => {
return fruta;
});

console.log(resultado);

Resultado:

undefined

Por isso ele não substitui:

  • map()
  • filter()
  • find()

Quando usar forEach()?

Use quando quiser:

✅ Percorrer todos os elementos.

✅ Executar ações em cada item.

✅ Exibir dados.

✅ Fazer cálculos acumulativos.

Quando não usar?

Evite quando precisar:

❌ Retornar um novo array → use map().

❌ Filtrar elementos → use filter().

❌ Encontrar elementos → use find().

❌ Interromper a repetição → use for ou for...of.

Resumindo

O forEach() é um método de array utilizado para percorrer todos os elementos e executar uma função para cada um deles.

Principais características:

  • Simples e legível.
  • Recebe uma função callback.
  • Percorre todos os elementos.
  • Não pode ser interrompido com break.
  • Não retorna um novo array.

É uma das formas mais utilizadas para percorrer listas em aplicações feitas com React, Node.js e JavaScript moderno.
