Método de Pesquisa

Em JavaScript, os métodos de pesquisa são utilizados para localizar elementos dentro de arrays. Eles permitem verificar se um valor existe, encontrar sua posição ou retornar o próprio elemento.

indexOf()

Procura um valor e retorna sua posição (índice).

const frutas= ["Maçã","Banana","Uva"];

console.log(frutas.indexOf("Banana"));

Resultado:

1

Se não encontrar:

console.log(frutas.indexOf("Laranja"));

Resultado:

-1

lastIndexOf()

Procura da direita para a esquerda.

const numeros = [10,20,30,20];

console.log(numeros.lastIndexOf(20));

Resultado:

3

includes()

Verifica se um elemento existe.

const frutas= ["Maçã","Banana","Uva"];

console.log(frutas.includes("Banana"));

Resultado:

true

Se não existir:

console.log(frutas.includes("Laranja"));

Resultado:

false

find()

Retorna o primeiro elemento que atende uma condição.

const numeros = [10,20,30,40];

const resultado = numeros.find(numero => {
returnnumero > 25;
});

console.log(resultado);

Resultado:

30

findIndex()

Retorna o índice do primeiro elemento encontrado.

const numeros = [10,20,30,40];

const indice = numeros.findIndex(numero => {
return numero > 25;
});

console.log(indice);

Resultado:

2

findLast()

Retorna o último elemento que atende à condição.

const numeros = [10,20,30,40];

const resultado = numeros.findLast(numero => {
return numero > 15;
});

console.log(resultado);

Resultado:

40

findLastIndex()

Retorna o índice do último elemento encontrado.

const numeros= [10,20,30,40];

const indice = numeros.findLastIndex(numero => {
return numero > 15;
});

console.log(indice);

Resultado:

3

some()

Verifica se pelo menos um elemento atende à condição.

const numeros= [10,20,30];

const existe = numeros.some(numero => {
return numero > 25;
});

console.log(existe);

Resultado:

true

every()

Verifica se todos os elementos atendem à condição.

const numerosj= [10,20,30];

const todos = numeros.every(numero => {
return numero > 5;
});

console.log(todos);

Resultado:

true

Pesquisando objetos

Muito comum em aplicações reais:

const usuarios= [
  { id:1, nome:"João" },
  { id:2, nome:"Maria" },
  { id:3, nome:"Carlos" }
];

const usuario = usuarios.find(u =>u.id===2);

console.log(usuario);

Resultado:

{id:2,nome:"Maria" }

Comparação dos métodos

MétodoRetorna
indexOf()Índice do valor
lastIndexOf()Último índice
includes()true ou false
find()Elemento encontrado
findIndex()Índice do elemento
findLast()Último elemento encontrado
findLastIndex()Índice do último encontrado
some()Se algum atende à condição
every()Se todos atendem à condição

Quando usar cada um?

  • Quer saber se existe? → includes()
  • Quer a posição? → indexOf() ou findIndex()
  • Quer o elemento completo? → find()
  • Quer verificar condições? → some() ou every()
  • Trabalha com objetos? → find() é geralmente a melhor opção

Resumindo

Os métodos de pesquisa permitem localizar informações dentro de arrays de forma rápida e eficiente. Os mais usados no dia a dia são:

  • includes()
  • find()
  • findIndex()
  • some()
  • every()

Eles aparecem constantemente em sistemas web, APIs, filtros de dados e aplicações desenvolvidas com React e Node.js.
