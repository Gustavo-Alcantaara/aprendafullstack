Eventos de Mouse

Em JavaScript, eventos do mouse são ações realizadas pelo usuário com o mouse dentro da página. Eles permitem criar interatividade em sites e aplicações web.

Esses eventos normalmente são usados junto ao DOM e elementos HTML.

O que é um evento?

Evento é algo que acontece na página:

  • clique
  • movimento do mouse
  • scroll
  • tecla pressionada
  • envio de formulário

click

Executa quando o usuário clica:

<button id="botao">Clique</button>
const botao = document.getElementById("botao");

botao.addEventListener("click",function() {
console.log("Clicou");
});

dblclick

Executa no clique duplo:

botao.addEventListener("dblclick",function() {
console.log("Duplo clique");
});

mousedown

Executa quando o botão do mouse é pressionado:

botao.addEventListener("mousedown",function() {
console.log("Mouse pressionado");
});

mouseup

Executa quando o botão é solto:

botao.addEventListener("mouseup",function() {
console.log("Mouse liberado");
});

mousemove

Executa sempre que o mouse se move:

document.addEventListener("mousemove",function() {
console.log("Movendo mouse");
});

⚠️ Esse evento dispara muitas vezes por segundo.

Pegando posição do mouse

document.addEventListener("mousemove",function(evento) {
console.log(evento.clientX);
console.log(evento.clientY);
});

mouseenter

Executa quando o mouse entra no elemento:

botao.addEventListener("mouseenter",function() {
console.log("Entrou");
});

mouseleave

Executa quando o mouse sai:

botao.addEventListener("mouseleave",function() {
console.log("Saiu");
});

mouseover

Parecido com mouseenter, mas considera elementos filhos.

botao.addEventListener("mouseover",function() {
console.log("Passou por cima");
});

mouseout

Executa ao sair do elemento.

botao.addEventListener("mouseout",function() {
console.log("Saiu");
});

contextmenu

Executa no clique direito:

document.addEventListener("contextmenu",function(evento) {
evento.preventDefault();

console.log("Clique direito");
});

Objeto do evento

Toda função de evento recebe um objeto com informações:

botao.addEventListener("click",function(evento) {
console.log(evento);
});

Informações úteis do evento

Coordenadas

evento.clientX
evento.clientY

Elemento clicado

evento.target

Botão pressionado

evento.button
ValorBotão
0Esquerdo
1Meio
2Direito

preventDefault()

Impede comportamento padrão:

evento.preventDefault();

Muito usado em:

  • formulários
  • links
  • menu direito

stopPropagation()

Impede propagação do evento:

evento.stopPropagation();

Inline Events

Forma antiga:

<button onclick = "alert('Olá')">
  Clique
</button>

Hoje o mais recomendado é:

addEventListener()

Arrow functions em eventos

botao.addEventListener("click", () => {
console.log("Clicou");
});

Eventos mais usados em interfaces

Resumindo

Eventos do mouse permitem:

  • detectar ações do usuário
  • criar interfaces interativas
  • responder a cliques e movimentos
  • controlar elementos dinamicamente

Eles são fundamentais em aplicações feitas com React, jogos, dashboards e interfaces modernas da web.
