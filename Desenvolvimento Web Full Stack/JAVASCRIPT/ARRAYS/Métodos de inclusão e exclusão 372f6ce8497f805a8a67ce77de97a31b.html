Métodos de inclusão e exclusão

Em JavaScript, existem vários métodos para incluir e excluir elementos de um array. Esses métodos são muito utilizados para manipular listas de dados.

Métodos de Inclusão

push()

Adiciona um ou mais elementos ao final do array.

const frutas = ["Maçã","Banana"];

frutas.push("Uva");

console.log(frutas);

Resultado:

["Maçã","Banana","Uva"]

unshift()

Adiciona elementos no início do array.

const frutas = ["Banana","Uva"];

frutas.unshift("Maçã");

console.log(frutas);

Resultado:

["Maçã","Banana","Uva"]

splice()

Também pode ser usado para inserir elementos em qualquer posição.

const frutas = ["Maçã","Uva"];

frutas.splice(1,0,"Banana");

console.log(frutas);

Resultado:

["Maçã","Banana","Uva"]

Explicando:

splice(indice,quantidadeRemovida,elemento)

Métodos de Exclusão

pop()

Remove o último elemento.

const frutas = ["Maçã","Banana","Uva"];

frutas.pop();

console.log(frutas);

Resultado:

["Maçã","Banana"]

shift()

Remove o primeiro elemento.

const frutas = ["Maçã","Banana","Uva"];

frutas.shift();

console.log(frutas);

Resultado:

["Banana","Uva"]

splice()

Remove elementos de qualquer posição.

const frutas = ["Maçã","Banana","Uva"];

frutas.splice(1,1);

console.log(frutas);

Resultado:

["Maçã","Uva"]

Explicação:

splice(1,1);
  • começa no índice 1
  • remove 1 elemento

Removendo vários elementos

const numeros = [1,2,3,4,5];

numeros.splice(1,3);

console.log(numeros);

Resultado:

[1,5]

Encontrando e removendo um elemento

const frutas = ["Maçã","Banana","Uva"];

const indice = frutas.indexOf("Banana");

if (indice !== -1) {
frutas.splice(indice,1);
}

Resultado:

["Maçã","Uva"]

Método moderno: filter()

Cria um novo array sem o elemento desejado.

const frutas = ["Maçã","Banana","Uva"];

const novaLista = frutas.filter(fruta => {
return fruta !== "Banana";
});

console.log(novaLista);

Resultado:

["Maçã","Uva"]

⚠️ O array original não é alterado.

Diferença entre os métodos

MétodoAção
push()Adiciona no final
unshift()Adiciona no início
pop()Remove do final
shift()Remove do início
splice()Adiciona ou remove em qualquer posição
filter()Cria um novo array filtrado

Exemplo prático

Lista de tarefas:

const tarefas= [];

tarefas.push("Estudar JavaScript");
tarefas.push("Fazer exercícios");

console.log(tarefas);

Removendo a última tarefa:

tarefas.pop();

Resultado:

["Estudar JavaScript"]

Resumindo

Os métodos mais importantes para manipulação de arrays são:

  • push() → adiciona no final
  • unshift() → adiciona no início
  • pop() → remove do final
  • shift() → remove do início
  • splice() → adiciona ou remove em qualquer posição
  • filter() → cria uma nova lista removendo elementos conforme uma condição

Esses métodos aparecem constantemente em aplicações desenvolvidas com React, Node.js e APIs modernas.
